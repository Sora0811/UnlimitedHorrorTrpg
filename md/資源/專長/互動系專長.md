# 洞察人心（ 1~3 ）

> 來源：`資源/專長/互動系專長`

**前提**：需求感知 3 ，感受技能 3 級

## 1 級

**正文**

人物在進行感受 技能 相關檢定時獲得等同於本專長等級的專長加值。

## 2 級

**正文**

每天一次，在進行感受（察言觀色）相關檢定時，若你對結果不滿意，則可以重投該次檢定，但你必須接受重投之後的結果，儘管其可能更差。

## 3 級

**正文**

人物在防禦上獲得 3 點洞察加值 。

# 鼓舞士氣（ 1~3 ）

**前提**：需求風度 3 ，表達技能任意子項達到 3 級

## 1 級

**正文**

人物在進行表達 技能 相關檢定時獲得等同於本專長等級的專長加值。

## 2 級

**正文**

只要友方輪迴者位於人物敏感範圍內，其（不包括人物自身）便可以在攻擊檢定上獲得 1DP 士氣加值。

## 3 級

**正文**

每天一次，人物可以消耗一個小時進行一次風度 + 表達 檢定 ，爲自己敏感範圍內的友方輪迴者（包括自身在內）恢復等同於該次檢定成功數 \*1 點意志力，透過此法恢復的意志力上限爲施展者的表達技能。無論如何，每個單位 每天最多隻能透過本專長恢復 1 次意志力 。

# 酒吧蒼蠅（ 1~3 ）

**前提**：交際 1 ，擁有收集情報專業

## 1 級

**正文**

人物在進行交際（收集情報）相關檢定時獲得等同於本專長等級的專長加值。

## 2 級

**正文**

當人物位於酒館，夜總會或是類似的環境下時（具體由 ST 裁定 ），人物進行“收集情報”動作時所需的總時間減半。

## 3 級

**正文**

每天一次，當人物位於酒館，夜總會或是類似的環境下時，人物在進行交際（收集情報）相關檢定時可以進行兩次檢定，並取其中成功數較高者作爲該次檢定的結果。 ===========================================================================================================

# 美麗陷阱（ 2 ）

## 2 級

**正文**

人物可以以風度代替操控作爲關鍵屬性進行掩飾 技能 相關檢定。

# 魔鬼律師（ 1~3 ）

**前提**：需求操控 3 ，掩飾技能 3 級

## 1 級

**正文**

人物在進行掩飾 技能 相關檢定時獲得等同於本專長等級的專長加值。

## 2 級

**正文**

當你透過一個整輪動作進行“匆忙的唬騙檢定”時，你因此所需承受的無名減值減少 3DP 。

## 3 級

**正文**

每天一次，人物可以花費 1 個自由動作並支付 1 點意志力來進行一次操控 + 掩飾（唬騙）檢定。若該次檢定成功數大於 5 ，則記錄下所有成功骰，之後直到切換場景之前，你可以將記錄的成功骰與之後進行檢定所投出來的失敗骰相互替換，但透過此法替換的骰子無法獲得任何加骰，同時每次替換最多隻能替換 5 個，且只能替換自己的投骰。你可以在一次投骰結束後並得知行動失敗之後再替換骰子以改變結果。

特殊的，這個專長無法對機運骰和開啓基因鎖的檢定產生效果。

# 千面人（ 1~3 ）

**前提**：需求智力 3 ，掩飾技能 3 級

## 1 級

**正文**

人物在掩飾（易容）與掩飾（僞裝）相關檢定中獲得 1DP 專長加值。

## 2 級

**正文**

人物進行“易容”與“僞裝”動作時所需的時間減半。

## 3 級

**正文**

人物在掩飾（易容）與掩飾（僞裝）相關檢定中獲得 1 個附加成功 。

# 聽我怒吼（ 1~3 ）

**前提**：需求脅迫技能 3 級

## 1 級

**正文**

人物在進行脅迫技能相關檢定時獲得等同於本專長等級的專長加值。

## 2 級

**正文**

人物現在可以對自身敏感範圍內的目標進行“咆哮”，同時對方仍需能夠看見人物。

## 3 級

**正文**

人物所有由脅迫技能的專業所獲得的專業加值提升至 3 點，同時在脅迫（咆哮）相關檢定上獲得 1 個附加成功。

# 馴獸師（ 1~3 ）

**前提**：操控 3 ，動物溝通技能 3 級

## 1 級

**正文**

人物在進行動物溝通技能相關檢定時獲得等同於本專長等級的專長加值。

## 2 級

**正文**

智力不高於 3 的動物會對你產生本能的好感，這表現爲其對你的態度上升 1 級，最高提升至“親切”（關於態度，詳見“交際”技能說明）。但是你依舊可能因爲交涉不當導致你們成爲敵對狀態。

## 3 級

**正文**

人物可以額外指定一個單位，使該單位可以自由命令人物的所有動物夥伴。每天一次，人物可以以一個自由動作更改指定的單位。

# 幽默（誤）大師（ 1~3 ）

**前提**：操控 3 ，交際技能 3 級

## 1 級

**正文**

人物在進行交際 技能 相關檢定時獲得等同於本專長等級的專長加值。

## 2 級

**正文**

你可以消耗自由動作並支付 1 點意志力，指定一個位於你敏感範圍內的目標，使其下一次檢定如同其本人使用了意志力基礎用法一般獲得相應的 DP 完美 加值，這視爲目標已經使用了意志力的基礎用法。

## 3 級

**特殊**：只有 PC 本人在 扮演 中說出符合情景的吐槽 / 笑話的時候纔可以獲得本專長的效果。 ST 有權判定 PC 所說的吐槽 / 笑話是否合適。

**正文**

你可以消耗整輪動作並支付 3 點 意志力，之後選定等同於你傳奇操控 +1 個距離你不超過 50 米的單位並 進行一次操控 + 交際（交涉）檢定，對其造成等同於該次檢定成功數的精神束縛點數，不可疊加，目標以意志豁免，這是一個 C 級影響心靈的效果。
