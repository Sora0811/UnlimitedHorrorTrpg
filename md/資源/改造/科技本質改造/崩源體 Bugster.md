# 崩源體 Bugster

> 來源：`資源/改造/科技本質改造/崩源體 Bugster`

**價格**：C+1000

**本質**：科技本質

**描述**

<ul>
<li>感染人類並在其腦內寄生成長的微型計算機病毒。可隨着感染者的人類的壓力而增殖併發作Bugster病毒感染症（通稱遊戲病），後奪取人類的身體從而實體化爲3D的數據體。</li>
<li>奪取感染者身體並實體化後，感染者再分離後便能化爲讓等身大的怪人態。但是，寄生的時候可以通過全息影像探知到與怪人態一樣的身姿，增生到一定程度使得遊戲病發作，直至實體化後方能行動。感染者的壓力到達峯值便能取締感染者的存在並實體化爲“完全體”，成爲完全體後便能以成爲全世界的支配者一事作爲目的進行活動。</li>
<li>基本上Bugster是通過遊戲數據的獲取，化爲該遊戲的Boss等的相似的怪人態。</li>
<li>最經典的橫版動作遊戲類型，靠着超羣的運動神經與勇氣，通過奔跑跳躍等操作，向強大的敵人發起攻擊。</li>
<li>FPS(First-person Shooter)第一人稱視角射擊遊戲，顧名思義就是以玩家的主觀視角來進行射擊遊戲。玩家們不再像別的遊戲一樣操縱屏幕中的虛擬人物來進行遊戲，而是身臨其境的體驗遊戲帶來的視覺衝擊。</li>
<li>另類摩托車競技遊戲，玩家將參加非法的暴力摩托車比賽，可以利用各種手段去阻止其他車手，其他車手也會利用各種暴力方法攻擊玩家和彼此互鬥。</li>
<li>飛行射擊類的彈幕遊戲，玩家操控戰機對來襲的大量敵人進行攻擊，並在過程中升級、強化自我的能力，最終打敗頭目。</li>
<li>Jet Up：獲得等同基礎速度的完美飛行能力。外在表現爲具現化出噴射機翼帶着自己飛行。</li>
<li>Rocket On：使用一個整輪動作將你的實彈槍械進行巨炮具現化，此時你的槍械可以發射炮彈，保留你槍械的所有能力，當炮彈的效果與槍械的效果衝突時，使用彈炮的效果爲準，若效果重疊則取高。</li>
<li>【Drago Knight Hunter Z （龍騎士獵人Z）】</li>
<li>雖然是那麼野性與暴力，但後世者仍然回味這個令人目眩的數個世紀。大地、晴空、住在那時代的所有居民，</li>
<li>合成這個洋溢着最大生命力的時代，</li>
<li>世界比起現在，已經變得非常單純，</li>
<li>那便是――狩獵，或被狩獵。</li>
<li>《龍騎士獵人Z》玩家要在遊戲中不斷的完成任務，獲得金錢和裝備與各種素材，並讓自己的獵人等級上升。</li>
<li>戀愛類的avg遊戲，你是劇本中主角,圍繞你着你身邊的有多個異性角色,你的目的就是完成劇本的劇情,透過分支劇情的選擇,提升角色好感度來攻略角色，實現和其中一位異性角色的"完美結局"。</li>
<li>心跳砰砰的旋律（DOKIDOKIリズム）：在自己回合你可以以一個移動動作進行一個準備動作，當自身受到單體攻擊時，可以觸發這個準備動作，進行一個操控+交涉的檢定，每有1個成功數，目標的攻擊檢定減少1個成功數。</li>
</ul>

**技能樹**

<ul>
<li>開啓技能樹</li>
<li>主神的改造讓Bugster不在侷限於一種遊戲，你可以每花費C+1000獲得一個。</li>
<li>【Mighty Action X（全能動作X）】</li>
</ul>

**特性**：超凡體質（雙特性）、怪人態（雙特性）

**特殊**：一次性改造，額外獲得2個特性。

**價格**：C+1000

**其他標籤**

**超凡體質**：進行這個改造之後，作爲Bugster你無需飲食和睡眠，也免疫自然本質的疾病和毒素。

**怪人態**

<ul>
<li>在戰鬥中，你可以以一個移動動作獲得一個隨機BUFF，這些BUFF只會持續1輪，在你下回合開始時結束，你每回合只能獲得一個BUFF，進行一個1D10檢定，根據結果獲得以下效果：</li>
<li>1-筋肉化 你的天生武器傷害以及人造武器傷害獲得等同自身最高傳奇屬性的提升。</li>
<li>2-高速化 立即獲得一個標準動作。</li>
<li>3-鋼鐵化 你的天生防禦獲得自身最高傳奇屬性的提升。</li>
<li>4-伸縮化 本輪在攻擊之後可以立刻對受到你攻擊的目標進行一次摔絆或擒抱。</li>
<li>5-透明化 你隱身了，這是一個C級特異本質的反偵測效果。</li>
<li>6-挑釁 如果你進行格擋，則你獲得等於你格擋對應技能上附加成功數的防禦附加成功。（如白刃6，進行白刃格擋，則獲得1點防禦附加成功）</li>
<li>7-反射 你攻擊時，受到你攻擊的目標無法針對你的攻擊使用反射動作。</li>
<li>8-回覆 立即將相當於你最高傳奇屬等額的生命值轉爲完好。</li>
<li>9-巨大化 你的體積翻倍。</li>
<li>10-縮小化 你的體積縮小爲1/2。</li>
</ul>

**跳躍強化**：動作遊戲賦予了你超絕的運動神經，你跳躍檢定的最終成功數的米數\*10，同時你免疫墜落傷害。

**撼地猛擊**

<ul>
<li>當你身處半空中的時候，可以立刻以一個標準動作向一個與你水平距離不超過所在高度的目標發起一次墜落攻擊，攻擊檢定爲力量+運動（跳躍），傷害上限爲力量+運動，本次攻擊享受你與目標指尖高度差的加值，每差1米則獲得1DP，由此獲得的加值最多20點，並且你可以將自身體積加入攻擊檢定中，同時本次攻擊若命中則對目標額外造成墜物傷害。</li>
<li>【Bang Bang Shooting （砰砰射擊）】</li>
</ul>

**狂暴射手**：你所持的實彈槍械視爲無限彈藥，這個特性影響的範圍只限普通的槍械彈藥，不包括具有特殊功能的彈藥（包括特殊子彈，附魔子彈等）和炮彈。與此同時你在進行連射和點射時不會因爲攻擊多個目標獲得減值。

**精準射手**

<ul>
<li>當你瞄準一個目標後對該目標進行射擊時，你每瞄準一輪，則你可以無視1點特定部位減值，同時你還可以無視對方1點防禦附加成功。</li>
<li>【Bakusou Bike （爆走機車）】</li>
</ul>

**狂暴加速**：你操控的載具麻吉克速度將翻倍。

**疾風馭手**

<ul>
<li>你操作載具的任何檢定若爲敏捷/智力取低，變爲敏捷/智力取高。</li>
<li>【Jet Combat （噴射戰鬥）】</li>
</ul>

**武器大師**：獵人們會使用各種各樣的武器來狩獵不同的怪物，對任何武器都具有極高適應性，因此在使用任何武器的時候其“前提”中的屬性和技能以及專業要求全部視爲滿足。

**迴避極致**

<ul>
<li>對獵人來說，巨型怪物的攻擊並不是可以靠着防禦力就可以承受的存在，怪物的撞擊和甩尾就能給獵人帶來極大的傷害，因此對於攻擊，翻滾回避將是最好的選擇，若你已經獲得“健步如飛3”專長，則其中的“迅捷動作”改爲“迅捷動作或者反射動作”。</li>
<li>【Toki Meki Crisis（心跳危機）】</li>
</ul>

**戀愛分支**：你獲得天賦“直覺”。
