# 人機改-呼吸系統

> 來源：`資源/改造/科技本質改造/人機改造/呼吸系統`

**本質**

<ul>
<li>科技本質</li>
<li>能耗特性中的增幅可以與其他人機改造中的對應增幅效果疊加，分別計算上限，但是加值可以疊加。</li>
</ul>

## 人工肺

**位置**：肺

**描述**：用人工的過濾和空氣產生系統代替了天然肺，可以讓使用者更有效地進行呼吸。

**特性**：人工肺、運動增強、水下呼吸（三特性）、能耗

**特殊**：由於沒有能量池和屬性，額外獲得3個特性。

**能耗**：佔據3點能源 上限。當你進行運動相關的檢定時，以一個自由動作，每消耗1點能源，運動檢定再獲得1點器械加值，消耗的上限爲2點。

**其他標籤**

**人工肺**：你免疫所有自然本質呼吸性毒素。

**水下呼吸**：你的肺現在可以過濾水中的氧氣，你獲得水下呼吸。

**運動增強**：可以增強運動力。在運動檢定上獲得3DP的器械加值，可以與人機改造中的其他器械加值疊加。


## 嘴部激光炮

**位置**：肺

**前提**：人工肺

**描述**：是人工肺的升級版，擁有其全部功能，但安裝了一門特種激光炮，勝在防不勝防。開炮時必須張開嘴，但不影響說話。可以接吻時使用。

**特性**：武器化（雙特性）、聲音模擬（雙特性）、能耗

**分類**：炮

**武器基本屬性**：武器傷害12L，破甲6，基本射程300米。

**武器特殊屬性**：【能量武器】【炮擊】

**能耗**

<ul>
<li>每次發射消耗3點能量。</li>
<li>佔據9點能源 上限，當你進行運動相關的檢定時，以一個自由動作，每消耗1點能源，運動檢定再獲得2點器械加值，消耗的上限爲4點。</li>
</ul>

**其他標籤**

**聲音模擬**：你現在可以模擬任何一個你聽過的聲音，在只根據聲音進行判斷的掩飾（僞裝）檢定上獲得2點附加成功，並且當你面對聲音鎖或者類似裝置時，無需檢定自動成功。

**武器化**：安裝有一門微型粒子炮。

**音波武器**：本武器造成的傷害爲音波傷害。

**炮擊修正**：武器的體積視爲你的體積。


## 龍息

**價格**：B+2000

**位置**：肺

**前提**：嘴部激光炮

**描述**：這是科技模仿魔法的產物，用人工喉模擬龍息與其產生器官，能在需要時釋放出焚盡一切的吐息。

**特性**：龍息（三特性）、次聲波、能耗

**特殊**：由於沒有屬性，額外獲得2個特性

**能耗**

<ul>
<li>佔據30點能源 。當你進行運動相關的檢定時，以一個自由動作，每消耗1點能源，運動檢定再獲得1點附加成功，消耗的上限爲4點。</li>
<li>每次發射消耗5點能量。</li>
<li>佔據15點能源 。當你進行運動相關的檢定時，以一個自由動作，每消耗1點能源，運動檢定再獲得1點附加成功，消耗的上限爲4點。</li>
</ul>

**分類**：炮

**武器基本屬性**：武器傷害20L，破甲6，基本射程500米。

**武器特殊屬性**：【能量武器】

**價格**：B+2000

**其他標籤**

**次聲波**：你可以使用次聲波來進行偵查，你獲得相當於你耐力值/米的盲視。啓動本能力時，你必須張着嘴，這會讓你無法使用需要“語言”相關的能力。

**龍息**

<ul>
<li>你現在失去C級的武器化特性，改爲本特性。</li>
<li>你可以模擬龍息進行攻擊。</li>
</ul>

**能量武器**：你可以從 【灼熱】【寒冰】【腐蝕】【光能】【雷電】中選擇一種傷害，每次切換需要花費一個整輪動作。

**噴吐**：本武器只能造成範圍傷害，角度爲120°，範圍內所有目標進行反射豁免，你進行敏捷+運動（噴吐）或者敏捷+槍械（炮）取高的攻擊檢定，每有1點成功，則目標的反射檢定失去1DP。

**深呼吸**：你在使用時可以額外花費5點能量，進行1輪蓄力，增加10點武器傷害，最多蓄力1輪。蓄力1輪後必須進行噴吐，否則能量將消散。


## 使徒十字光線

**位置**：肺 前提：龍息

**描述**：使用時，可以看到使用者喉嚨處發出十字形的閃光，伴隨着空氣的爆鳴和尖嘯，同時在目標地點發生劇烈的爆炸，光芒會直衝天際，形成100米高的光之十字架。 特性：範圍抹殺（四特性）、能耗

**特殊**：由於沒有屬性，額外獲得2個特性

**分類**：炮

**武器基本屬性**：武器傷害24L，破甲6，基本射程1000米。

**武器特殊屬性**：【能量武器】

**能耗**

<ul>
<li>每次發射消耗10點能量。</li>
<li>佔據30點能源。當你進行運動相關的檢定時，以一個自由動作，每消耗1點能源，運動檢定再獲得1點附加成功，消耗的上限爲6點。</li>
</ul>

**其他標籤**

**能量武器**：你可以從【灼熱】【寒冰】【腐蝕】【光能】【雷電】中選擇一種傷害，每次發射前自由選擇。 範圍抹殺：你可以使用本武器造成範圍傷害，若如此做，你選擇射程內的一個點，然後以該點爲中心，半徑100米範圍內所有目標造成等於你武器傷害的範圍傷害。所有目標進行反射豁免。你可以進行一個敏捷+運動（噴吐）或者敏捷+槍械（炮）取高的攻擊檢定，每有1點成功，則目標的反射檢定失去1DP。

**集中攻擊**：你可以使用本武器只對一個目標造成傷害，若如此做，選擇一個目標，對其進行正常的攻擊檢定，使用敏捷+運動（噴吐）+武器傷害或者敏捷+槍械（炮）+武器傷害進行攻擊檢定，傷害傷害爲武器傷害\*2+所用技能。本次攻擊額外擁有【貫穿】特性。
