# 惡魔附身者

> 來源：`資源/改造/魔幻本質類改造/惡魔附身者`

**本質**：魔幻本質

**價格**：A+4000

**技能樹**：無

**特性**：惡魔侵蝕（負特性），沐浴邪血（雙特性），惡魔附身（雙特性），共存的適應（四特性）

**特殊**：一次性改造，額外獲得2個特性，由於沒有屬性和技能樹，額外獲得3個特性。

**描述**：這惡魔並不是傳統意義上的惡魔，而是一個世界的人類對殘暴統治的單體異族的稱呼，每當面對殘暴統治，總會有揭竿而起。然而殺死“惡魔”的人類會被“惡魔”附身，最終變成新的“惡魔”。

**例**：侵蝕值14時，你受到16點恐懼狀態點數，則此時14點不生效，你只受到2點恐懼點數的作用效果，當依靠休息或者其他能力豁免恐懼點數時，你需要如常豁免16點，此時你受到當你每有1點恐懼點數則受到1點傷害的效果時，你按照16點計算。

**價格**：A+4000

**其他標籤**

**惡魔侵蝕**

<ul>
<li>每次戰鬥結束或場景切換你都需要進行一次DC爲1的意志檢定，失敗則獲得1點侵蝕值，並且累積的DC歸0。成功，則下一次檢定DC提升1點。每有1點侵蝕值，則你的意志值下降1點，這會使你的意志檢定，意志力等相關內容全部下降。</li>
<li>當你的意志值下降爲0時，侵蝕值不會再增加，除非你的意志值增加。臨時增加的意志值上限不會影響侵蝕值增加的上限。</li>
<li>侵蝕值可以在主神處降低，每點花費100點獎勵點。</li>
</ul>

**沐浴邪血**：你的基礎防禦增加相當於侵蝕值/點。

**惡魔附身**

<ul>
<li>你可以以一個整輪動作啓動變身，變身後成爲黑暗生物，若你此時沒有盔甲防禦且沒有穿戴盔甲值，你獲得相當於侵蝕點的盔甲防禦。</li>
<li>變身狀態下，你每輪進行一個意志檢定，DC爲當前的侵蝕點，若你失敗，則你將無法避免的陷入暴走狀態。</li>
<li>進入暴走狀態後，你無法控制，每輪將儘可能的攻擊距離最近的目標，若有同時最近，則優先攻擊原本的敵對目標。</li>
<li>此時，你的力量與敏捷相關檢定獲得相當於侵蝕點的DP褻瀆加值。</li>
<li>暴走狀態下，你每輪進行一個意志檢定，當成功數累積至5次後，脫離暴走狀態。</li>
<li>在暴走狀態下，即使你的生命值被惡性傷害填滿，你可以將侵蝕值作爲第二條生命值繼續如常戰鬥，如果第二條生命值也被惡性傷害填滿或戰鬥結束時你所受的總傷害數仍然填滿了你的第一條生命值，你會正常死去。若此時，你清除了任何1點侵蝕值，則會立即死亡。</li>
</ul>

**共存的適應**：當你受到任何不良狀態點數時，低於你侵蝕值部分的不良狀態如常累積，但是並不生效，超出的部分正常生效，你需要如常豁免這些不良狀態點數。針對不良狀態點數的效果可以如常針對你身上的所有不良點數。
