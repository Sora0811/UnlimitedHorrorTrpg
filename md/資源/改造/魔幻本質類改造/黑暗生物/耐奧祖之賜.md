# 耐奧祖之賜

> 來源：`資源/改造/魔幻本質類改造/黑暗生物/耐奧祖之賜`

**本質**：魔幻本質

**價格**：B+2000

**前提**：黑暗生物，意志值在5以上

**描述**

<ul>
<li>巫妖之王耐奧祖在寒冰王座之中無時不在向整個多元宇宙延伸它的感知，誘惑那即使是稍具邪惡的精神加入它的控制之下，它同樣也會賜予相應的力量作爲回報。</li>
<li>主神處的強化可以讓你連接上耐奧祖的感知，聆聽其誘惑，但要想獲得力量而不受其控制對強化者來說也是相當的挑戰。</li>
</ul>

**屬性**：耐力+3 沉着+4 決心+4

**特性**：鋼鐵意志（雙特性）、絕望之寒、絕望領域

**特殊**：由於一次性改造，額外獲得2個特性，由於沒有技能樹，額外獲得3點屬性。

**價格**：B+2000

**其他標籤**

**鋼鐵意志**：你因巫妖王在你腦海中不斷的誘惑和喋語而永久失去5點意志值上限，但你的意志力變的更強，當你進行意志檢定的時候獲得4點附加成功 ，同時你免疫魅惑和心靈控制能力 。

**絕望之寒**：火焰無法消融寒冰王座的寒氣，寒冷更是無法企及，針對一次傷害，你可以用反射動作進行意志檢定，抵消成功數一半的傷害。

**絕望領域**：啓動和關閉都是一個迅捷動作，花費1點意志力，你風度\*10米範圍內的所有生物獲得1點無視傷害吸收，傷害抵消，傷害忽略，傷害減免的寒冷傷害，同時受到1點不可避免可疊加的凍結點數，目標離開範圍後，凍結點數每輪自動下降1點。
