# 改造-惡魔人

> 來源：`資源/改造/魔幻本質類改造/惡魔人`

**本質**：魔幻本質

**前提**：接受此改造前，必須爲人類。

**描述**：被惡魔附體後，擁有堅定意志的人類是不會被惡魔肆意操控的。而是變成擁有惡魔的肉體與人類心靈的惡魔人。以惡魔人crybaby爲基準撰寫。

**特殊**

<ul>
<li>任何通過複製、拷貝、模仿等方式獲得該血統中任何一種或者多種能力。必須不可避免的承受“飢渴”特性。</li>
<li>由於沒有技能樹和分數翻倍以及一次性改造，額外獲得4個特性</li>
</ul>

**價格**：A+8000

**屬性**：力量+4 耐力+4 決心+4

**能量池**：無

**技能樹**：無

**特性**：惡魔變身（五特性），合體惡魔（三特性），惡魔人（負特性），飢渴（負特性）

**價格**：A+8000

**其他標籤**

**惡魔變身**

<ul>
<li>你可以用移動動作將人類肉體變身爲惡魔之軀，頭上生角，牙齒鋒利，手腳變爲爪子，下半身長出毛髮以及一條尾巴，身後長出蝙蝠翅。</li>
<li>此時，你的體積增加4點，你的天生武器的武器傷害獲得相當於你傳奇耐力與傳奇決心之和的提升，並且獲得【魔法】【黑暗】特性。此時你使用你的天生武器攻擊，若成功命中，則對目標額外造成傳奇力力量/點火焰嚴重傷害。</li>
<li>並且，你獲得相當於你傳奇耐力與傳奇決心之和的天生防禦。你的肉體獲得【防彈】【防能量武器】特性。同時獲得4點全傷害吸收以及4點全能量抗力。</li>
<li>你的基礎移動速度增加40米，並且你計算基礎移動速度的公式變爲力量\*2+體積，而非力量+敏捷+體積。獲得相當於你基礎移動速度的完美飛行能力。</li>
<li>此變身能力可以一直維持，解除變身是一個迅捷動作。</li>
<li>變身後禁止心靈上的軟弱。只有變身後，角色的決心再21以上才能完美掌控更加強大的惡魔肉體，否則惡魔之魂佔據主動權，角色將陷入狂暴狀態，一切以慾望爲目標行動，色慾，食慾，貪慾，暴虐，殺戮，縈繞心頭，此狂暴狀態無法被驅散。此時角色每輪開始時自動獲得6點不可避免，可疊加的亢奮點數。</li>
</ul>

**合體惡魔**：惡魔人可以發動惡魔的結合特性，可以掠奪敵人的軀體強化自身。當惡魔人親手殺死力量與耐力之和高於惡魔人的力量與耐力之和時，惡魔人可以選擇自身的一點力量或者一點耐力獲得提升，因此獲得的力量和耐力每分別擁有2點，則獲得1點快速醫療，獲得的快速醫療的上限爲傳奇決心/點。持續一場恐怖片。

**惡魔人**：惡魔人永久變爲黑暗生物，並且由於惡魔崇尚肉體力量，即便是惡魔人也受其影響。變身狀態下不可以使用除自身天武外的其他武器。

**飢渴**

<ul>
<li>維持惡魔之軀需要大量能量，每日正常進食的食物是常人的十倍。惡魔在變身的狀態下食用任何食物都不會產生噁心或者其他附加效果。</li>
<li>同時，角色在面對肉食（如動物，肉類，怪物肉等），面對色慾（由該角色性取向決定），面對比自身弱小的生物（如無助狀態的目標），都要分別進行意志檢定。初始DC爲4，每次檢定成功則下次檢定DC增加2點。你可以通過完成以下事情使DC降回初始DC，食慾需要進行一次肉類飽食。色慾需要進行一次房事（自慰無效）。殘暴需要進行一次戰鬥並且殺死敵人。若檢定失敗，則進入狂暴狀態，之後角色由ST控制，角色必須以失敗項作爲自身準則進行行動，直至該DC降回初始DC。</li>
</ul>
