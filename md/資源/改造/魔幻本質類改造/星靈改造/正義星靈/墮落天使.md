# 墮落天使

> 來源：`資源/改造/魔幻本質類改造/星靈改造/正義星靈/墮落天使`

## C 級

**前提**：正義星靈D級，暗與光中選擇“黑影”

**價格**：C+2000

**屬性**：智力+3，耐力+3

**技能樹**：無

**特性**：加值轉換，靈魂吸取（二特性），束縛的雙翼，黑暗生物（負特性）

**特殊**：由於沒有技能樹並且分數翻倍，額外獲得2個特性

**描述**：你選擇 束縛自己的雙翼並擁抱了人性，還將自己的痛苦和怨恨施加給那些失信和墮落之人。

**加值轉換**：本改造獲得的屬性加值爲增強加值

**價格**：C+2000

**其他標籤**

**靈魂吸取**：你施展的法術，若關鍵詞中有【暗】，則施法檢定獲得本改造等級\*4點內在DP加值.

**魔力榨取**：每當你通過法術造成8點嚴重傷害或者4點惡性傷害，你就可以回覆1點魔力，每輪你最多恢復不超過自身傳奇智力/點魔力。


## B 級

**價格**：B+4000

**屬性**：智力+4，耐力+4

**技能樹**：開啓墮落天使B級技能樹

**特性**：加值轉換，靈魂吸取―提升，束縛的雙翼

**特殊**：由於分數翻倍，額外獲得1個特性。

**描述**：現在，你的背後伸出潔白的四翼，你飛翔在天空，距離神界更近一步。

**加值轉換**：本改造獲得的屬性加值爲增強加值

**價格**：B+4000

**其他標籤**

**靈魂吸取―提升**：你施展的法術中若關鍵詞有【暗】，其威力值額外增加3點。

**束縛的雙翼**：與正義天使不同，雖然你們都生出雙翼，但你不想通過這漆黑的羽翼來飛翔，你可以以反射/迅捷動作並消耗3點魔力來進行一次移動距離不超過你基礎移動速度1/10的傳送，這是一個C級別的空間傳送能力。

**屬性**：智力+6，耐力+6

**技能樹**：無

**特性**：加值轉換，靈魂鐐銬（雙特性），墮落天使

**特殊**：由於沒有技能樹並且分數翻倍，額外獲得2個特性

**加值轉換**：本改造獲得的屬性加值爲增強加值

**價格**：A+8000

**其他標籤**

**靈魂鐐銬**

<ul>
<li>一場景一次，你可以以一個標準動作消耗7點意志力選擇敏感範圍內不超過你傳奇智力/名目標，在他們的靈魂上戴上鐐銬，鐐銬持續3輪，你進行一個施法檢定，受影響的目標意志豁免，若其失敗，則受到差值可疊加的糾纏點數，同時在每輪結束時都會得到不可避免的相當於你傳奇智力值/點的可疊加的糾纏點數，在3輪後鐐銬破碎，目標會陷入昏迷，昏迷持續1輪，並且同時對目標造成相當於其身上所有因本能力糾纏點數/點褻瀆嚴重傷害。</li>
<li>被靈魂鐐銬綁定的目標與你身上會出現一道淡紫色的鎖鏈，你可以通過鎖鏈得到被只針對你鎖住目標的真實視覺。</li>
<li>若目標超出你的敏感範圍則鎖鏈會斷開，斷開後不會因爲目標再次回到你的敏感範圍而重新連上。</li>

### 暗之禁錮

**關鍵字**：【暗】

**價格**：B+3000

**專業**：咒法

**威力值**：6

**動作**：標準動作

**能耗**：5

**成分**：語言、姿勢

**射程**：智力值\*20米

**目標**：一個目標

**範圍**：無

**描述**：你 擲出一團星火來禁錮命中的第一個敵人。

**效果**：你進行一次施法檢定，本次檢定獲得12DP褻瀆加值，向一個目標擲出一團星火，目標以反射豁免，若失敗則會受到差值的褻瀆嚴重傷害，並受到傷害等額的可疊加糾纏點數，糾纏點數以反射豁免。

**價格**：B+3000

### 折磨之影

**關鍵字**：【暗】

**價格**：B+3000

**專業**：咒法、 死靈

**威力值**：6

**動作**：移動動作

**能耗**：5

**成分**：語言、姿勢

**射程**：智力值\*20米

**目標**：所有敵對目標

**範圍**：以落點爲圓心，半徑爲神祕學/米的圓形

**持續**：神祕學/輪

**描述**：點燃一個區域，對站在其中的所有人造成傷害。

**效果**：你指定一個區域，你進行一次施法檢定，站在其中的所有角色都需要在你輪結束時進行一次強韌豁免與你此次的施法檢定進行對抗，若失敗則受到本法術威力值+傳奇智力+你神祕學等級帶來的附加成功/點腐蝕嚴重傷害，若目標因此受到傷害，且當前沒有完好生命，最差的生命爲惡性生命，則額外再受到同等於其當前惡性生命值/點的褻瀆嚴重傷害，最大爲威力值+傳奇智力+神祕學等級帶來的附加成功。

**增幅**：你每有一級施法者等級，則可以額外支付3點魔力來使範圍增加神祕學/米。

**價格**：B+3000

### 黑暗之盾

**關鍵字**：【暗】

**價格**：B+ 3 000

**專業**：咒法、 防護

**威力值**：6

**動作**：移動動作

**能耗**：5

**成分**：語言、姿勢

**射程**：智力值\*20米

**目標**：一個目標

**範圍**：無

**持續**：神祕學/輪

**描述**：製造黑暗之盾來守護一名角色

**效果**：你爲一名目標製造黑暗之盾，該盾能夠爲目標提供等同你（傳奇智力+神祕學技能等級帶來的附加成功）/點法術抗力，你進行一次施法檢定，記錄成功數。當該法術抗力成功降低相當於該成功數的成功後，本效果結束。

**價格**：B+3
