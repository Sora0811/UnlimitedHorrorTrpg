# 空間震精靈系列

> 來源：`資源/改造/魔幻本質類改造/空間震精靈改造/總綱`

**屬性增強**：空間震精靈改造本身不直接提供屬性，只有在身着靈裝後纔會得到本改造提供的屬性，但當你解除着裝後屬性會恢復正常，因此無法將此屬性用於滿足兌換條件或物品製作。

**認主**：所有靈裝獲得【認主】特性。

**注**：如無特殊說明，本改造下所有“施法檢定”皆爲智力+神祕學+改造等級（D1C2B3A4）\*2

**其他標籤**

**概念武裝**：靈裝都是概念武裝，佔用概念武裝位，以及角色的護甲位。

**召喚靈裝**

<ul>
<li>召喚與解除靈裝爲一個自由動作。若無特殊說明，穿着靈裝是一個標準動作，靈裝會依附在你目前穿着的衣物或盔甲上，同時會改變你當前的衣着造型，具體造型見描述。</li>
<li>持續使用者的意志值\*1分鐘。此外，若你在展示靈裝狀態被人以任意方式親吻，則靈裝立刻解除。</li>
</ul>

**額外特性**：由於穿着靈裝需要一個標準動作同時靈裝佔用概念武裝位，因此如無特殊說明，空間震精靈每級額外獲得一個同級特性，並且靈裝提供的屬性皆爲增強加值。

**召喚天使**

<ul>
<li>召喚天使爲一個移動動作，如無特殊說明，那麼即便在你未穿着靈裝的時候也能夠如常召喚天使，天使沒有持續時間。</li>
<li>召喚天使後通常會讓你解鎖一些新技能，這些技能只有在天使狀態下纔可以使用。</li>
</ul>
