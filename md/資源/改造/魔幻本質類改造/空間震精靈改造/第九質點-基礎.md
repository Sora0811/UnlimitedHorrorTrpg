# 第九質點

> 來源：`資源/改造/魔幻本質類改造/空間震精靈改造/第九質點-基礎`

**描述**：上身穿着中空袖子以及花邊狀光帶，下面則穿着有着光之褶皺邊的裙子的光之禮服，頭上佩戴有月亮狀的裝飾物。能力爲操控聲音，一旦被美九以灌注靈力的聲音“請求”，沒有靈力的一般人類都會無從抵抗的順從。

## D 級

**價格**：D+1000

**屬性**：見靈裝

**能量池**：無

**技能樹**：無

**特性**：加值轉換，神威靈裝-九番（雙特性），天使：破軍歌姬（三特性）

**特殊**

<ul>
<li>由於沒有技能樹和能量池，額外獲得2個特性 ；由於分數翻倍，額外獲得一個特性。</li>
<li>神威靈裝-九番：獲得神威靈裝-九番(Shaddai El Kai)，穿着靈裝爲你帶來以下好處：</li>
</ul>

**屬性增強**：靈裝爲主人在風度和操控上提供2點增強加值。

**價格**：D+1000

**其他標籤**

**感人肺腑**：身着靈裝的情況下，進行以風度或者操控爲關鍵屬性的檢定時，都會獲得1點內在加值。

**天使**

<ul>
<li>破軍歌姬（Gabriel）：</li>
<li>有着光之鍵盤的巨大管風琴，並彈奏出不同的音樂。召喚天使需要一個移動動作。</li>
<li>投風度+表達，根據音樂的不同其效果也不同。</li>
<li>如果要維持效果，你需要每輪花費一個整輪動作。</li>
<li>同一時間你只能進行一種曲目的演奏。</li>
<li>由於天使加護的存在，你在施展天使解鎖的技能時獲得1點全傷害吸收，你不會因受到攻擊打斷演奏，但你仍然可能被因爲被擒抱，眩暈或其他消除聲音的能力而打斷演奏。</li>
</ul>

**你解鎖了一個新技能**：進行曲（March）。


### 進行曲（March）

**動作**：整輪動作

**能耗**：無

**射程**：無

**目標**：操控附加成功值+1個目標

**範圍**：以自身爲中心半徑爲操控\*1米的範圍

**持續**：啓動後每輪花費一個整輪動作維持演奏，持續至停止演奏。

**描述**：能夠使指定的聽衆獲得強大的力量。

**效果**：整輪動作啓動後，使範圍內最多不超過你傳奇操控+1個單位獲得1點快速醫療，之後以整輪動作維持，期間可以透過自動動作更改受影響的單位。

### 獨奏（Solo）

**動作**：整輪動作

**能耗**：無

**射程**：無

**目標**：操控附加成功值+1個目標

**範圍**：以自身爲中心半徑爲操控\*10米的範圍

**持續**：啓動後每輪花費一個整輪動作維持演奏，持續至停止演奏。

**描述**：能夠通過音樂來控制聽衆的思想，並控制他們。

**效果**

<ul>
<li>投擲一次風度+表演（演奏）檢定，選擇範圍內最多不超過傳奇操控+1個目標，對方投意志檢定進行對抗。若目標失敗則會在你的控制下行動，直到你的演奏停止，這是一個A級影響心靈的效果。</li>
<li>你每輪可以以自由動作控制所有受影響的單位，受到影響的單位每輪只剩下一個標準動作，同時移動速度和所有檢定的成功數減半（若爲造成傷害的能力，則傷害在計算傷害減免等能力前減半）。</li>
<li>你不可以發出類似自殺的命令，也不可以發出直接對目標不利的命令（例如：讓目標跳入岩漿），但你可以令受控制的單位攻擊對你有敵意的其他單位，但如果目標不具備攻擊對方的能力（如動作不足，能量不足等），則如常消耗動作，但不產生任何效果。</li>
<li>每次輪到目標行動前目標都可以進行一次意志檢定，DC爲你發動該技能時投擲的演奏檢定成功數，該DC每回合都會下降2點，若目標意志檢定成功或是你的演奏因任何原因中斷，目標會立刻擺脫“獨奏”的影響，且不會失去當前輪的動作。</li>
<li>此外，受影響的目標每次受傷，他們都會立刻得到一次與你成功數對抗的機會，每次對抗都會使DC降低2點。</li>
<li>特殊的，在你停止維持本技能後，你必須隔一個回合才能再次啓動本技能。</li>
</ul>
