# 第二質點，Chhokmah。智慧

> 來源：`資源/改造/魔幻本質類改造/空間震精靈改造/第二質點-智慧`

**描述**

<ul>
<li>靈裝爲佩帶十字架，法衣上添加了筆的半透明修道服。全知天使--&lt;囁告篇帙（Ratziel）&gt;，是一本類似聖典的帶有十字架巨大的書。天使本身包括情報檢索頁和空白頁。能力是獲取情報的全知能力，要是有未來以外的事情、現在起發生的事情、誰在做什麼等等自己想要的情報都可以在情報檢索頁上得知。</li>
<li>由於信息片段缺失，因此本改造爲未完全版，暫缺靈裝反轉後提供的能力。</li>
</ul>

**屬性**：見靈裝

**能量池**：無

**技能樹**：開啓智慧技能樹

<li>在某些特殊的場景和時間點（例如問題涉及的人物具有屏蔽預言的能力），ST有權不向你提供任何情報。</li>
</ul>

## 未來記載

**價格**：A+4000

**動作**：整輪動作

**能耗**：5點意志力

**射程**：感知\*10米

**目標**：一個目標

**範圍**：無

**持續**：立即

**描述**：手持天使的情況下，用靈裝佩戴的鋼筆在空白頁進行描述。

**效果**

<ul>
<li>使用一個標準動作在天使上寫下目標的下次行動，描述中不可以有包含結果的語句（如你可以寫下“對方以殺傷力最強的攻擊手段攻擊某人的頭部。”，但你不能寫下“對方以最強的攻擊手段對某人造成了X點傷害/斬下了某人的手。”）。</li>
<li>在輪到對方行動時，對方可以先進行一次意志檢定對抗你的施法檢定，若成功則不受影響。</li>
<li>若對方對抗失敗或選擇不抵抗，被描述的人物會強制執行你爲其描述的行爲，前提是他必須掌握你所描述的能力，若目標沒有足夠的動作，則不受影響；若該能力目標會消耗能量池或使用次數，而目標沒有足夠的能量或使用次數驅動能力，則目標同樣不受影響。</li>
<li>除此之外，若有任何原因導致目標無法實踐你記載的行動（例如目標在行動前昏迷），目標的行動亦不會受到“未來記載”影響。</li>
<li>該技能被同時視爲一個C級影響心靈和C級因果律的效果，只需具備其中一種免疫能力便能免疫該技能影響。。</li>
</ul>

**例**

<ul>
<li>PC1使用未來記載，描述自己的隊友PC2在下一輪使用一次炎陽炮攻擊某個指定目標。輪到PC2行動時，PC2選擇不抵抗，並掌握陽炎炮法術，擁有足夠的能量與動作且目標在射程範圍內，則PC2使用陽炎炮攻擊指定目標，如常消耗PC2的動作和能量。若在PC2進行攻擊前，指定目標逃離了PC2能夠攻擊到的範圍，則“未來記載”失效。</li>
<li>這是一個A級影響心靈和因果律的效果。</li>
<li>當你至少有一項S級或以上的強化時，你可與支付49點XP將本技能升至S級，這會使該技能被視爲S級影響心靈和S級因果律的效果。</li>
</ul>

**價格**：A+4000

**正文**

在召喚天使後，你獲得情報檢索能力。

針對當前劇情，你可以向ST提出一個問題，並進行一次 智力+學識 檢定。ST根據你的成功數，回答你相關的情報答案，情報必須真實，但是不一定完善。每場景你可以使用這個能力1次，戰鬥中使用需要一個標準動作。
