# 第四質點，Chesed。慈悲

> 來源：`資源/改造/魔幻本質類改造/空間震精靈改造/第四質點-慈悲`

**描述**：用一件綠色的長裙外套覆蓋身體，頭上帶有一個兔耳的帽子。

## D 級

**價格**：D+1000

**屬性**：見靈裝

**能量池**：無

**技能樹**：無

**特性**：加值轉換，神威靈裝四番（雙特性），天使：冰結傀儡（三特性）

**特殊**

<ul>
<li>分數翻倍，獲得1個額外特性；由於沒有能量池和技能樹，額外獲得2個特性。</li>
<li>召喚天使需要一個標準動作，並且自動開啓“寒冰結界”。召喚天使後，你會出現在天使的肩上，這視爲你正在騎乘該構裝體。</li>
<li>天使視爲一個你直接操縱的構裝體，構裝體體積爲10，擁有3點天生防禦，10點生命值，30米基礎移動速度（未計入屬性影響），沒有心智類屬性，其他屬性和技能皆爲4（無專業）。控制構裝體行動一輪是一個整輪動作，構裝體和一般人一樣每輪也有迅捷、移動、標準動作。</li>
<li>若天使死亡，在切換場景後可以以一個移動動作重新召喚。</li>
</ul>

**屬性增強**：靈裝爲主人在智力上提供2點增強加值，在感知和操控上提供1點增強加值。

**價格**：D+1000

**其他標籤**

**長裙弱氣**：敵人認爲你沒有危害，只要你不主動做出攻擊和敵對行爲（包括但不限於威嚇，說服，給隊友上 BUFF ，給目標上 DEBUFF ），敵人在進行攻擊時，不會優先於你作爲目標（如其射程內有你和另外一個目標，其會優先攻擊另外那個）。這是一個D級影響心靈的效果。

**天使**

<ul>
<li>冰結傀儡（Zadkiel） ：</li>
<li>巨大的傀儡，能在周圍展開雨水和冰凍形成的保護結界，在結界中任何物體都會被凍結，包括隨意領域，防禦力驚人。</li>
</ul>

**寒冰結界**：使你和天使在防禦上獲得額外3點環境加值。結界範圍爲半徑等同於你傳奇風度上\*5米（最少爲5）的範圍。結界內，你可以指定的最多不超過你的傳奇操控+1的目標，其每回合開始時受到1點寒冷衝擊傷害。

### 凍鎧

**動作**：標準動作

**能耗**：無

**射程**：無

**目標**：自身

**範圍**：無

**持續**：5輪

**描述**：冰潔傀儡的二段技能，裝着冰之鎧甲的同時，可以使用寒氣旋風。

**效果**：以一個標準動作，在冰潔傀儡身上召喚寒冰鎧甲，冰潔傀儡在原有防禦的基礎上，額外獲得10點盔甲防禦，持續5輪。

**升級**：當第四質點提升至B級，獲得的盔甲防禦提升至20點；當第四質點提升至A級，獲得的盔甲防禦提升至30點。

## 寒氣旋風

**動作**：標準動作

**能耗**：無

**射程**：無

**目標**：自身

**範圍**：以自身爲中心，半徑爲操控值\*100米的範圍

**持續**：立即

**描述**：在你周身召喚出巨大的寒氣旋風。

**效果**

<ul>
<li>必須在裝備凍鎧的情況下使用，以一個標準動作，召喚出巨大的寒氣旋風。投一個施法檢定，在這次檢定中，額外增加等同於智力值的增強加值，之後造成等同於成功數的範圍傷害，反射豁免。</li>
<li>如果在本技能下受到了10點以上的傷害，則在其行動的下一輪會失去一個移動動作，釋放寒氣旋風后會解除凍鎧效果。</li>
</ul>
