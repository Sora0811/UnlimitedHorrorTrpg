# 縫合怪/生體改造

> 來源：`資源/改造/魔幻本質類改造/縫合怪\_生體改造/總綱`

**本質**：魔幻本質

**描述**：當你每次購買本改造後，你會立即被傳送至主神空間最負盛名的特邀縫合改造大師神虛・索托斯的私人實驗室中接受長達支線等級（D1S5）\*7天的漫長改造，並且被進行一些微不足道的的小實驗。

**特殊**

<ul>
<li>本改造的使用者，視爲具有神虛-索托斯的信仰導向，這並不是一個負特性並且可以與其他信仰導向兼容，但若要購買本改造的S級兌換則不可以具有其他信仰導向。</li>
<li>本能力若沒有特殊說明，則每一級的效果並不疊加，而是替換，包括屬性和效果。</li>
</ul>

**分類**：【移植】【異化】【特殊植入】

**內耗**

<ul>
<li>任何生物都有其對於改造的承載力，每一次的改造都會產生一定的內耗點數，只要改造器官仍在身體上，這些內耗點數就會被佔用。一個生物基礎的內耗點數爲體積+耐力值/點。例如，你現在的內耗上限是40，則你購買了一個內耗20的部件，則你的內耗上限則還剩餘20.</li>
<li>無論如何，你佔用的內耗點數不得超過你的上限。若因爲某些原因，內耗上限降低了，並導致佔用的內耗點數超過了你的上限，則你選擇對應的改造立即停止生效，直至佔用的內耗點數下降至上限以內。</li>
</ul>

**其他標籤**

**移植**：移植是以其他生物的器官代替和強化原生部分，受改造者可以對多個器官進行單獨移植，這種情況下，新的器官會代替原本的器官。同部位只能改造一次，特殊的。內臟部分如果具有多個內臟則每個內臟都可以進行一次改造，但沒有特殊說明同樣的改造不可重複購買。

**異化**：異化是對已有器官進行特殊的培育誘導促進其產生向特定方向變異。

**特殊植入**：難以直接分類的試驗品植入都在此列。

**損耗**：一些特殊的改造擁有一些可以主動啓動的特殊能力。啓動這些特殊能力有的時候會產生一些額外的內耗，這些內耗只能佔用剩餘的內耗上限，若沒有特殊能力，內耗消耗後無法恢復。
