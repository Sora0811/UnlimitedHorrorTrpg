# Jenova 神羅戰士 改造

> 來源：`資源/改造/魔幻本質類改造/神羅戰士`

**本質**：魔幻本質

**價格**：C+2000

**屬性**：6點自由屬性, 單項屬性可分配的上限至多爲3

**能量池**：無

**技能樹**：無

**特性**：加值轉換，屬性自由分配，改造宿主，心靈鏈接

**特殊**：由於沒有技能樹，額外獲得1個特性，由於分數翻倍，額外獲得1個特性。

**描述**

<ul>
<li>Jenova是一種來自於外星的生物，它是“從天而降的災厄”。這種寄生生命通過宇宙中的隕石進行旅行，一旦夠降落到有生命的星球，它們就會逐漸的復甦並通過寄生該地的原住民來進行自身的發展，直到將該星球上的物質和能量榨取一空。Jenova在諾路斯帕的墜落幾乎使古代種Cetra滅絕，直到倖存者將其封印在地下。2000年後，神羅公司發現了一個深埋於古代遺蹟的感染了Jenova細胞的古代種個體，並提取其細胞進行人體試驗，期望以此創造出無所不能的戰士。</li>
<li>由於其侵略性和不可控性，主神抹去了Jenova細胞的自我意識，新的Jenova細胞不會控制宿主的心靈，但也因此失去了獨有的一些能力。</li>
</ul>

**加值轉換**：本級改造提供的屬性加值爲增強加值。

**價格**：C+2000

##  級　神羅精銳戰士

**價格**：B+4000

**屬性**：8點自由屬性，單項屬性可分配的上限至多爲4

**技能樹**：無

**特性**：加值轉換，屬性自由分配，提升-改造宿主，戰鬥本能

**特殊**：由於沒有技能樹，額外獲得1個特性，由於分數翻倍，額外獲得1個特性。

**描述**：你現在是精銳戰士了。

**加值轉換**

<ul>
<li>本級改造提供的屬性加值爲增強加值。</li>
<li>提升-改造宿主：人物免疫自然和超自然本質毒素，疾病的影響，並且在受到噁心、耳鳴、目眩效果影響時，可免受等同於改造等級（D1C2B3……）\*1點相應的不良點數。</li>
</ul>

**價格**：B+4000

**其他標籤**

**戰鬥本能**：人物可以在白刃、肉搏或槍械中選擇一項，使其進行相關檢定時獲得【9加骰】，若已是9加骰，則獲得2點附加成功；人物在進行反射、強韌和意志檢定時可以獲得3DP內在加值。


##  級　神羅精銳戰士

**價格**：A+8000

**屬性**：12點自由屬性，但單項屬性可分配的上限至多爲6

**技能樹**：無

**特性**：加值轉換，屬性自由分配，分支選擇（雙特性）

**特殊**：由於沒有技能樹，額外獲得1個特性，由於分數翻倍，額外獲得1個特性。

**描述**：Jenova細胞的作用發揮到了極限，人物需在此等級選擇進化方向。

**加值轉換**：本級改造提供的屬性加值爲增強加值。

**價格**：A+8000

**其他標籤**

**分支選擇**

<ul>
<li>人物從以下特性選擇一個獲得。</li>
<li>地上最強生物（克勞德）：人物獲得2點快速醫療，且可以在C級選擇的白刃、肉搏或槍械提升到【8加骰】，若已是【8加骰】，則再額外獲得3點附加成功。</li>
<li>此外，人物在攻擊檢定上獲得6點增強加值，天生防禦增加6點。</li>
<li>片翼天使（薩菲羅斯）：人物免疫所有負面心靈效果帶來的影響。</li>
<li>人物可以以一個迅捷/反射動作生出一隻黑色的羽翼，使人物獲得等同於基礎速度四倍的飛行速度，機動性爲完美。</li>
<li>赤紅的地獄犬（文森特）：人物獲得無限壽命，並免疫一切衰老和即死效果；人物獲得2點再生和2點全傷害吸收；人物天生武器傷害提高3點，並可以在肉搏和槍械中選擇一項，在進行相關檢定時獲得6點褻瀆加值。</li>
</ul>


**其他標籤**

**改造宿主**：人物獲得6點天生防禦。

**心靈鏈接**：人物不會因爲傷勢失去意識，並且生命上限提升4點。
