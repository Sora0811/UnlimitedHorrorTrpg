# Giga-lo-maniacs『妄想症候羣』

> 來源：`資源/改造/魔幻本質類改造/妄想症候羣`

**本質**：特異本質

**價格**

<ul>
<li>C+2000</li>
<li>屬性；感知 +3 智力+3</li>
</ul>

**特性**：妄念、 Di-Sword （四特性）、加值轉換

**特殊**：由於是一次性改造，額外獲得兩個特性，由於沒有技能樹，額外獲得1個特性，分數翻倍，額外獲得1個特性

**描述**

<ul>
<li>如果使粒子無限制的接近負向，那麼就會產生對生成現象。</li>
<li>所謂的對生成現象，是指迪拉克之海的空孔中出現的『真空的崩壞』現象。</li>
<li>在空洞產生的瞬間，『世界』的抑制力會出現微小的盲點。</li>
<li>透過這個盲點，使周圍的存在認知自己的妄想的話，那麼妄想就會變成現實。</li>
<li>因爲是妄想，所以基本上什麼都能夠實現。</li>
<li>反過來說，如果沒有存在可以提供認知的話，那麼妄想也就不會成立。</li>
<li>因此其實什麼都做不到。</li>
<li>所以，你能夠區分出『現實』和『妄想』麼？</li>
</ul>

**加值轉換**：本改造提供的屬性加值爲 增強 加值。

**價格**：C+2000

**其他標籤**

**妄念**

<ul>
<li>你立刻獲得15點額外的XP紅利，並且之後每場影片結束後，你可以立即獲得3點XP作爲經驗紅利。任何情況下，紅利無法產生紅利。</li>
<li>Di-Sword ： 你獲得了以一個標準動作召喚或者遣返 Di-Sword的能力， Di-Sword只能召喚一把。</li>
</ul>


# Di-Sword

**本質**：特異本質

**分類**：長劍

**前提**：妄想症候羣

**描述**：以迪拉克之海的反因子構成，能夠隨意的與現實的物質反應，從而產生對生成現象，是把妄想變成現實的捷徑。未構成時，只有同爲Giga-lo-maniacs的人才能看到，是散發出藍色光譜的，擁有類似『劍』的外形的古怪武器。只有在構成之後，才能作爲武器被使用。一般來說，Giga-lo-maniacs若是沒有持有Di-Sword的話，是無法使用Real boot能力的。

**武器基本屬性**：武器傷害10L，【8加骰】

**武器特殊屬性**：【魔法】【幽冥】【認主】

**其他標籤**

**幻象武器**：本武器雖爲白刃武器，但不是人造武器，無法通過任何形式的附魔和改造。同時，本武器造成的所有影響皆爲幻象。

**神祕之劍**：持有者神祕學提升至3級，若已經到3級則獲得神祕學所有相關專業。並且本武器使用智力和神祕學取代力量和白刃進行攻擊檢定，並且使用智力代替力量，神祕學代替白刃作爲傷害上限。

**不穩定幻象**

<ul>
<li>本武器獲得相當於你傳奇智力+神祕學附加成功數的點數，每次攻擊之前，可以將該點數分配給破甲或者破魔，由你選擇。</li>
<li>（舉例：你智力13，神祕學8，共有3點，則你在攻擊前可以分配給破甲3，破魔0或者破甲2，破魔1等不同的方式）</li>
</ul>
