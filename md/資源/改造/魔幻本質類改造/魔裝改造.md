# 魔裝改造

> 來源：`資源/改造/魔幻本質類改造/魔裝改造`

**本質**

<ul>
<li>魔幻本質</li>
<li>這種融合了生物，魔法和科學的改造在高魔世界米德其路達世界因道德問題而被列爲禁止的研究課題之一。顯然的魔裝改造被視爲一種改造。</li>
</ul>

## D 級　人造魔導師

**價格**：D+500

**屬性**：智力+2，感知+1，耐力+2

**能量池**：魔力

**特性**：魔道天賦， 魔裝體

**特殊**：由於沒有技能樹，額外獲得1點屬性

**描述**：通過科學與生物手段將被改造者的基因以人工方式向那些傳說中的大魔導士的基因進行變異，在某種程度上可以說是人工產生的變種人。這種改造會使人獲得魔法資質並對魔法產生極大的親和力，現時空管理局三巨頭之一的菲特・T・哈洛溫便是培養者之一。

**價格**：D+500

**其他標籤**

**魔道天賦**：你獲得魔法力體質。

**魔裝體**：你無需食物和水。


## C 級　戰鬥機人

**價格**：C+1000

**屬性**：智力+3，感知+2，耐力+3

**特性**：魔裝體，魔力親和

**特殊**：由於沒有技能樹，額外獲得2點屬性

**描述**：培養者在絕大多數受體出現排異反應而失敗，有天才之稱的斯卡利艾蒂嘗試利用魔科技將人體與機械融合而非簡單拼裝，戰鬥機人由此誕生。

**價格**：C+1000

**其他標籤**

**魔裝體**：你可以用魔力供給維持身體運轉的必要成分，你無需睡眠和呼吸。

**魔力親和**：對魔法的親和力使你不用主動冥想也能獲得魔力恢復，你每小時都能進行一次魔力關鍵屬性判定，恢復成功數點魔力，若成功數大於6，可以分攤到每10分鐘上，這屬於一種自然恢復。


## B 級　序列者

**價格**：B+2000

**屬性**：智力+4，耐力+4

**特性**：提升-魔裝體（雙特性），無機物潛行

**特殊**：由於沒有技能樹，額外獲得1個特性

**描述**

<ul>
<li>由於戰鬥機人雖然獲得成功，卻需要投入大量的時間和精力才能完成一個，斯卡利艾蒂博士因而將目光轉向以功能特化爲目的的量產型，即爲序列者。</li>
<li>提升-魔裝體：你免疫B級以下的疾病和毒素，並具備常識性防護，只要溫度變化不足以造成傷害，你就不會感到有所不適，你可以在真空，海底等活動，不受輻射水壓等影響。</li>
</ul>

**價格**：B+2000

**其他標籤**

**無機物潛行**：序列者能讓自身，攜帶的物品和接觸的生物一併遁入無機物中，它如同靈體般穿過他們。將這視爲序列者可以以一個迅捷動作讓自己在靈體與實體之間切換，當切換成靈體時，人物獲得所有靈體特性。如靈體一般自由穿越固體、液體，但依然受視線和效果線影響，這意味着其遁入無機物中時可能因爲無法視物而迷失方向。


## A 級　TYPE ZERO

**價格**：A+4000

**屬性**：感知+4，智力+6，耐力+6

**特性**：限制解除（雙特性）

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得4點屬性</li>
<li>TYPE ZERO是斯卡利艾蒂研究的最初且最優秀的成果，也是序列者系列的理論依據，作爲魔科學的完全融合體，TYPE ZERO有極強的爆發力。</li>
</ul>

**價格**：A+4000

**其他標籤**

**限制解除**

<ul>
<li>當你在戰鬥中出現某種極其強烈的負面情感波動，如憤怒，絕望，悲傷等時，你可以進入限制解除的狀態。</li>
<li>在這個狀態中，你的沉着被視爲0，但不會受到沉着歸零的負面效果影響，你無視任何基於心靈影響的能力，這視爲S級的免疫效果，但會失去控制地追打引發你這種情緒的目標，直到他死亡、離開你的視線、你自己的魔力耗盡或你失去意識。</li>
<li>在這種狀態下，你在進行任何檢定或者受到攻擊時可以投入魔力來換取能量加值，每點魔力消耗可以換取1DP（或者1點防禦），以及1點傷害上限，每投入5點還可以獲得1個附加成功（或者1點防禦附加成功），魔力投入上限是你的耐力值。此外，該狀態每持續一輪，你便需要支付1點意志力。</li>
<li>進入這種狀態的條件通常由ST判斷，主動啓動需要以一個自由動作支付1點意志力並選定一個目標。</li>
<li>特殊的，你若因他人的能力效果而使沉着下降到0，也會陷入這個狀態，目標爲能力的使用者。當目標死亡、離開你的視線、你魔力耗盡或你昏迷後，你脫離限制解除狀態。</li>
</ul>
