# 食腦祕術

> 來源：`資源/改造/特異本質改造/食腦祕術`

**本質**：特異本質

**價格**：B+2000

**屬性**

<ul>
<li>無</li>
<li>你可以選擇你的一個屬性，在該屬性上獲得相當於死者對應該屬性的傳奇屬性的褻瀆加值。每點屬性會佔用 1 點容量。</li>
<li>針對同一個屬性，你無法重複選擇。</li>
</ul>

**技能樹**：無

**特性**：光影遊離（負特性），食腦儀式（八特性）

**特殊**：由於一次性改造，額外獲得 2 個特性，由於沒有屬性和技能樹，額外獲得 3 個特性。

**描述**

<ul>
<li>“喫了你的腦子，我就能和鹹魚說話了！”―來自大猩猩格魯德與海王的對話。</li>
<li>人類還曾矇昧的時候，曾經相信喫了死去生物就可以繼承他們的身前的力量，某些食人族喫人的習俗就來源於此。</li>
<li>這種儀式是那個時期流傳下來古老而黑暗的巫術之一，可通過食用死者的大腦來繼承他的生前的力量。</li>
</ul>

**稱號**

<ul>
<li>你可以獲得死者生前具備的一個稱號，這個稱號不能超過你的最高強化等級或者死者生前的等級。該稱號必須從低級到高級開始繼承，每繼承 1 級稱號則佔用 4 點容量。</li>
<li>針對同一個稱號，你不能重複獲得（有特殊說明的除外，如戰士稱號可以分別獲得武器，狂暴，防禦三次）。</li>
<li>招式，技藝，法術：你可以獲得一種死者生前具備的法術、技藝或者能力，必須滿足前提條件。如果此技藝來自於專屬技能樹，你必須先滿足其血統 / 改造 / 稱號 / 施法者等級 / 能量 / 屬性 / 技能等級等要求。通過本方式每習得一個招式，技藝，法術都會佔用 3 點容量。</li>
<li>若該能力有等級判定（如施法者等級等），則使用你自己的進行判定，若死者將該能力進行了研發或者升階，則你只能獲得最低級的效果，你不會獲得死者的研發和升階效果，並且你也無法使用該能力的升階或者研發效果。</li>
<li>針對同一個招式，技藝，法術，你不能重複獲得。</li>
</ul>

**專長**

<ul>
<li>你可以獲得死者所具備的一個普通專長或者輪迴隊專長，該專長必須從低級到高級開始繼承，每繼承 1 級專長則佔用 1 點容量，每繼承 1 級輪迴隊專長則佔用 2 點容量。同時你也無法使用 XP 提升這種方式獲得的專長。</li>
<li>針對同一個專長，你不能重複獲得。</li>
</ul>

**技能**

<ul>
<li>你可以選擇你的一個技能，在該技能的等級上提升相當於死者對應該技能的附加成功 / 點，通過此法帶來的技能等級不會帶來額外的 XP 減免。每等級技能會佔用 1 點容量。</li>
<li>針對同一個技能，你無法重複選擇。</li>
</ul>

**價格**：B+2000

**其他標籤**

**光影遊離**：施展這個可怕儀式的代價，施法者將成爲遊離於光明與黑暗之間的陰影。他將同時承受光明與黑暗生物不利的一面，但不能得到相關的優勢，這包括不能獲得得以光明黑暗生物爲前提條件的能力。

**食腦儀式**

<ul>
<li>舉行儀式需要花費一個場景的時間，這個過程中不能被人打擾，否則需要重新來過。被食用的大腦必須還保持着新鮮和完整，支離破碎或者腐爛的腦組織無法讓儀式使用者獲得力量，另外每天你只能進行一次這個儀式。</li>
<li>你最多可以獲得相當於耐力或者感知取高的容量，同時你每擁有 1 點傳奇感知和傳奇耐力，則容量額外增加 1 點。</li>
<li>通過本儀式，你可以獲得包括死者生前具備的非生理系屬性、技能、稱號、專長、通用法術、技藝，一旦獲得不可改變。</li>
<li>而能力，能量、血統、改造、瞳術、魔導書、物品等等無法通過這種形式得到繼承。</li>
</ul>
