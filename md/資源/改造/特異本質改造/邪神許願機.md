# 邪神許願機

> 來源：`資源/改造/特異本質改造/邪神許願機`

**本質**：特異本質

**價格**：B+2000

**描述**

<ul>
<li>神明在於許願還願，受衆生心願，還以衆生奇蹟，有人說神是法則，有人說神是偉大，但當六萬萬衆生的信仰彙集成就的信仰的神明，神明就是夢想</li>
<li>將鮮血獻給你，祈求你實現他的願望</li>
</ul>

**特殊**

<ul>
<li>本修真的祈求者、許願者必須完全發自自願纔可以滿足判定要求，不可以受到脅迫而進行許願，是否受到脅迫由ST判定。</li>
<li>人造生命無法使用任何本能力下的能力，也無法觸發。</li>
<li>一次性改造，額外獲得2個特性</li>
</ul>

**屬性**：風度+8

**技能樹**：開啓邪神許願機技能樹

**特性**：神祗儀態、許願平安、單屬性突破上限、還願、渴求、信仰導向（負特性）、

**價格**：B+2000

## 神明態

**價格**：D+500

**動作**：被動

**效果**

<ul>
<li>敵人認爲你沒有危害，只要你不主動做出攻擊和敵對行爲（包括但不限於威嚇，說服，給隊友上BUFF，給目標上DEBUFF），敵人在進行攻擊時，不會優先於你作爲目標（如其射程內有你和另外一個目標，其會優先攻擊另外那個）。</li>
<li>特殊的因爲他人祈願使你釋放的主動能力，主不視爲你進行的惡意行動，而視爲祈願者的行爲。</li>
<li>這是一個影響心靈的D級效果。</li>
</ul>

**價格**：D+500

## 延壽

**價格**：D+500

**動作**：10分鐘

**能耗**：5點意志力

**射程**：接觸

**目標**：一個目標

**範圍**：無

**持續**：永久

**效果**：你使該目標的壽命延長相當於你傳奇風度+1年。

**特殊**

<ul>
<li>每個目標只能承受一次本效果。</li>
<li>當你對該目標施展本能力時，只計算你施展能力時的傳奇風度，之後你的傳奇風度增加或者減少都不會改變目標增加過的生命。</li>
</ul>

**價格**：D+500

## 願或是債

**價格**：D+500

**動作**：被動

**效果**

<ul>
<li>每次向你成功發動“許願平安”或“渴求”的目標都會在身體中積累1點“債”，目標體內的“債”最大不得超過目標當前的生命值上限。</li>
<li>當你針對一個體內存在對於你的“債”的目標進行檢定時，若檢定的結果爲正面效果（如治療），則每點債令你失去1點成功。若檢定的結果爲負面效果（如造成傷害），則每點債令你獲得1DP表現加值，可以疊加。</li>
<li>之後，清空目標體內的債。</li>
</ul>

**特殊**：若一個能力無法判斷結果爲善意和惡意，則無視其體內的債，具體由ST判斷。

**價格**：D+500

## 九出十三歸

**前提**：習得“願或是債”

**價格**：D+500

**動作**：被動

**效果**：一個目標體內每積累9點針對你的“債”，則體內的“債”再增加四點，由九出十三歸產生的“債”不會二次觸發九出十三歸。

**價格**：D+500

## 強制還願

**前提**：習得“願或是債”

**價格**：C+1000

**動作**：標準動作

**射程**：模糊範圍

**目標**：一個目標

**範圍**：無

**持續**：立即

**效果**

<ul>
<li>你可以隨時令一個你所知道的目標使其強制還願，本能力只能對體內存在對於你的“債”的目標使用。</li>
<li>使用後，該目標立即受到相當於體內所有“債”的不可避免的嚴重傷害，然後清空目標體內的債。</li>
</ul>

**價格**：C+1000

## 等價替換

**前提**：習得“願或是債”

**價格**：B+2000

**動作**：反射動作

**能耗**：3點意志力

**射程**：模糊範圍

**目標**：自身

**範圍**：無

**持續**：立即

**效果**

<ul>
<li>當你受到一次傷害或不良狀態時，若射程內有體內存在對於你的“債”的目標，則你可以啓動本能力。</li>
<li>你可以將本次受到的任意點傷害和不良狀態點數轉移到目標身上。</li>
<li>每轉移一點，則清空目標體內的1點“債”。</li>
<li>因這種方式造成的傷害或不良點數不可避免。</li>
</ul>

**價格**：B+2000

## 衆生願力

**價格**：A+4000

**動作**：被動

**描述**：你完成衆生的願望，而衆生的感激的感激也守護着你。

**效果**

<ul>
<li>計算你所有完成過的“還願”，每完成一次則你在防禦和豁免上獲得1DP幸運加值，上限爲你的風度值。</li>
<li>若在本次劇情世界若有你完成過的“還願”的劇情人物，則每個再爲你在防禦以及豁免上提供1DP幸運加值，這種方式提供的加值沒有上限。</li>
<li>在劇情上視爲你的身上環繞着無盡的感激與讚美之聲將所有的惡意擋在了外面。</li>
</ul>

**價格**：A+4000

**其他標籤**

**神祗儀態**：初次與你產生接觸（即曾經未曾聽聞、未曾有過任何相互影響）的生物對你的態度不會低於冷漠。

**許願平安**

<ul>
<li>任何一個目標在主動進行一項檢定時，可以用迅捷動作向你許願，若你接受他的許願，則他可以選擇對自己造成最多不超過1點不可避免的惡性傷害，然後本檢定獲得3DP褻瀆加值。</li>
<li>任何一個目標，可以以反射動作向你祈求平安，消耗其相當於1+你傳奇風度/點意志力，若你接受他的許願，則其可以獲得所消耗的意志力\*2的臨時生命，持續你傳奇風度/輪。本臨時生命本場景只能獲得一次。</li>
</ul>

**還願**

<ul>
<li>任何一個目標，當他向你提出要求時，你可以用一個反射動作接受這個願望，此時契約建立。但這個要求必須發自其本心，並且在你接受要求時，目標需明確知道後果，不可以因爲脅迫或類似的能力而提出。</li>
<li>當你完成這個要求時，這立即視爲契約達成，他將強制向你還願，支付給你相當於你傳奇風度+1點的生命上限，這部分生命上限將變爲持續時間爲永久的可疊加的臨時生命，因此能力獲得的臨時生命最大不超過你的生命值。</li>
</ul>

**渴求**

<ul>
<li>任何一個目標，可以以反射動作或者迅捷動作向你許願。其受到X點耐力傷害，若你接受他的許願，則其根據承受的耐力傷害獲得以下效果，如果你接受則可以按以下表格進行兌換，具有支線對抗的能力等級不可超過本血統的等級，並且由於本方式造成的耐力臨時傷害不可以通過任何方式恢復，僅能通過休養的方式自然恢復。</li>
<li>1、1再生 2點耐力傷害 最多許願本血統等級/次，可以疊加，持續一場景</li>
<li>2、斷肢再生 2點耐力傷害 只能接續斷肢 不能回覆傷害</li>
<li>3、D級隱形 3點耐力傷害 每額外支付3點耐力傷害則反偵察等級提升一級，持續一個場景</li>
<li>4、D級偵查 3點耐力傷害 每額外支付3點耐力傷害則反偵察等級提升一級，範圍等同於目標的視距，持續一個場景</li>
<li>5、貨幣 每1點耐力臨時傷害相當於當地三口之家七天的生活花銷，特殊的，目標可以用永久耐力來換取貨幣，每1點相當於儲存100分的特殊信用卡所對應的貨幣，並且該貨幣可以通過任何（即使你自己無法做到）的方式支付到目標手上</li>
<li>6、解除D級毒素 3點耐力傷害，每額外再支付3點耐力傷害則可解除的毒素提升一級</li>
<li>7、食物 每1點耐力傷害可以換取一人三天份的食物</li>
<li>8、水 每1點耐力傷害可以換取一人三天份的食物</li>
<li>9、物資 每1點耐力傷害可以換取1件不超過500分的無支線物品3天的使用權，若期間物品損壞或遺失，目標將永久失去1點耐力。</li>
</ul>

**信仰導向**：這是一個信仰邪神的導向能力。
