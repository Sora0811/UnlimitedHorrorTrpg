# 腦內限制解除

> 來源：`資源/改造/特異本質改造/腦內限制解除`

**本質**：特異本質

**價格**：B+2000

**屬性**：力量+4 耐力+4

**能量池**：無

**特性**：鋼鐵之軀（四特性），以力破巧，完美防禦，箭在弦上（負特性）

**特殊**：由於沒有技能樹，額外獲得1個特性 ；一次性改造，額外獲得兩個特性

**描述**

<ul>
<li>人體的潛力，遠比你想象中的大很多。</li>
<li>人類就算認爲已經使出全力，但通常都不是「真正的全力」。</li>
<li>筋肉會自然做出保留，讓人類將比原本還要大幅縮小的力量當成「全力」。</li>
<li>腦部之所以保留全力，是爲了要保護自身的關節與筋肉。界限這個詞就如同字面上的意義是界限，要是給予過大的負荷，筋肉與骨頭就只有毀壞一途。</li>
<li>然而，如果有一天大腦無法控制筋肉的力量了，那麼人又會變成怎麼樣呢？</li>
<li>如果肉體最終沒有自毀的話，那麼就會走上另一條進化的道路。</li>
<li>雖然體內的肌肉纖維想要不斷變粗，但不斷被逼迫到極限的肉體卻不給細胞那樣的時間。</li>
<li>然後，不知是必然還是奇蹟，細胞選擇了另一條路。肌肉纖維放棄變得比現在更粗，選擇維持在那般纖細下變得更強韌。最低限度的再生。爲了變得更強韌，就連關節與骨頭也配合這種進化而改變了成長方式。骨頭變得像鐵一般堅硬，關節在不斷脫臼中――超越了習慣性而進化得更爲強韌。</li>
</ul>

**價格**：B+2000

**其他標籤**

**鋼鐵之軀**

<ul>
<li>你的身體獲得2點硬度與2點傷害抵消。接受改造後，你每有1點傳奇力量便使身體硬度再增加1點，每有1點傳奇耐力便能使你再獲得1點傷害抵消。（注：本改造提供的傷害抵消能力與化勁、渾天寶鑑提供的傷害抵消能力取高計算，但與傷害吸收、減免、忽略能力疊加。）</li>
<li>由於你的身體內在已經產生了巨大的變化，通常的鍛鍊方法已經不適用於你的肉體，你在花費分數提升身體屬性時，要支付等於當前屬性值\*2的XP就可以如常提升。</li>
<li>最後，你自然恢復的速度提升爲原本的一倍，並且你每具有一級死硬專長，你的生命值就額外增加一點。</li>
</ul>

**以力破巧**：你在進行任何與生理屬性相關的檢定時，相當於你該屬性基礎值（即除去增強、修行、幸運等加值後的數值）的DP視爲擲出了10，但不會因此而獲得加骰，你其餘部分的DP照常進行檢定和加骰。

**完美防禦**：你防禦上基於敏捷和感知的附加成功可以反覆使用。

**箭在弦上**：你不能在進行生理屬性相關檢定時選擇留手，除非你支付一點意志，並且進行一次意志檢定，在這次檢定中，你每獲得一個成功數，你便能留手一個成功數。
