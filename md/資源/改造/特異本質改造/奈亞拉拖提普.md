# 奈亞拉拖提普（改造）

> 來源：`資源/改造/特異本質改造/奈亞拉拖提普`

**本質**：特異本質

## D 級　銀色的不可名狀

**價格**：D+500

**屬性**：決心 +2 敏捷 +2 風度 +2

**能量池**：無

**技能樹**：無

**特性**：不可名狀，吾即是奈亞（此世之鍋），伏行的混沌，加值轉換，克蘇魯信仰（負特性）

**特殊**：由於沒有技能樹，額外獲得一個特性，由於沒有能量池，額外獲得兩點屬性

**加值轉換**：本改造給的屬性加值變爲增強加值。

**價格**：D+500

**其他標籤**

**不可名狀**

<ul>
<li>美麗的少女，身着華貴，精美呃摺扇，一顰一笑都藏在摺扇後面，真想看到她完整的容貌。</li>
<li>當你使用摺扇或其他物品遮擋住你眼睛以下面部時，你在進行意志檢定時，獲得 3DP 內在加值。</li>
<li>吾即是奈亞（此世之鍋）：無論是 coc 又或者別的地方，出了什麼問題把鍋扔給奈亞就對了。</li>
<li>當面對突發情況時，你可以宣佈對此負責，所有人都會下意識認爲這就是你乾的，並將注意力轉移至你，這視爲一個 D 級的心靈影響效果。特殊的你也可以以遠坂時辰，西行寺世界，爽哥等身份表示對此負責。</li>
</ul>

**伏行的混沌**

<ul>
<li>光有搞事的能力還不夠，還要能生存，這就是奈亞能存活至今的原因之一。</li>
<li>當你站在陰影中時，消耗一個移動動作消失不見，表現爲你化爲黑暗遁入陰影之中，所有人都會以爲你離開了，但你的位置實際不會有任何改變，只是他們看不見你了，這不是一個隱身效果，而是一個 D 級的心靈影響效果，這個效果持續到你離開陰影籠罩範圍或者你做出任何行動，本能力每場景只能發動一次。</li>
</ul>

**克蘇魯信仰**：這是一個克蘇魯信仰導向的能力。


## C 級　陰影中的罪惡

**價格**：C+1000

**屬性**：決心 +3 風度 +3

**技能樹**：無

**特性**：提升 - 伏行的混沌，無貌之神，加值轉換

**特殊**：由於沒有技能樹，額外獲得一個特性

**加值轉換**：本改造給的屬性加值變爲增強加值。

**價格**：C+1000

**其他標籤**

**伏行的混沌**

<ul>
<li>我就是始終面帶微笑伏行到你身邊的混沌，奈亞拉拖提普參上！</li>
<li>你仍需要陰影才能使用本能力，但你可以離開陰影進行移動，這並不會影響伏行效果，同時升級爲 C 級心靈影響效果。</li>
</ul>

**無貌之神**：奈亞拉拖提普擁有無數的容貌。每個場景一次，你可以隨時改變自己的外貌，身體構造，甚至是性別，但這並不會爲你帶來任何體積上的改變，這不會使你通過任何指紋，虹膜等驗證方式。但所有目睹你變身的單位，不分敵我需要進行一個 DC 爲你傳奇風度與表達技能等級之和的意志豁免，若其失敗，獲得差值的恐懼點數。


## B 級　千面之神

**價格**：B+2000

**屬性**：決心 +4 風度 +4

**技能樹**：無

**特性**：提升 - 伏行的混沌，古神的低語，加值轉換

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得一個特性</li>
<li>升級特性 - 伏行的混沌：你現在不需要陰影也可以發動這項能力，同時提升爲 B 級心靈影響效果。於此同時，每個場景一次，你可以釋放你不可名狀的氣息，所有目睹你消失的敵對單位都需與你進行一次意志對抗，若你成功，則目標失去差值意志力。</li>
</ul>

**加值轉換**：本改造給的屬性加值變爲增強加值。

**價格**：B+2000

**其他標籤**

**古神的低語**

<ul>
<li>I'a …… l …… .Cth ……發糖，大白兔奶糖。</li>
<li>你可以花費 1 點意志力與一個整輪動作，鎖定一名你正在注視的目標（你必須親眼注視該目標）。然後你可以在目標耳邊低語（無視距離嗎，哪怕在宇宙中，對方是聾子也可以聽到你的聲音），訴說任何東西，通常爲模糊不清難以理解的語言。聆聽到這些聲音的單位需要與你進行一次意志對抗，若你成功則目標失去差值的意志力，若你失敗則對方不受影響，每個目標每場景只會受到本效果影響一次。</li>
</ul>


## A 級　永遠和平的締造者

**價格**：A+4000

**屬性**：風度 +6 決心 +6

**技能樹**：無

**特性**：提升 - 伏行的混沌，古神的侵蝕，加值轉換

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得一個特性。</li>
<li>升級特性 - 伏行的混沌：你就站在他們身邊，而他們對你一無所知。</li>
<li>你現在進行伏行是一個迅捷動作，即使你站在他們身邊，他們也不會發現你，這是一個 A 級心靈影響效果。即使其免疫對應的心靈影響效果，其也必須在你發動本能力時，與你進行一次意志對抗，若你成功，則其依然會受到本效果影響。</li>
</ul>

**加值轉換**：本改造給的屬性加值變爲增強加值。

**價格**：A+4000

**其他標籤**

**古神的侵蝕**

<ul>
<li>不可名狀的力量在侵蝕你心靈的同時也在腐化你的內在。</li>
<li>每當你的感知範圍內有目標失去意志力（包括其自己使用或者其他原因減少意志力時）時，都會受到相當於你血統等級的不可避免的嚴重褻瀆傷害，以及同等數額的噁心點數（可以疊加），同時你可以選擇誰不受到影響。</li>
</ul>


## S 級　伏行的混沌

**價格**：S+8000

**屬性**：風度 +8 決心 +8 沉着 +8

**技能樹**：無

**特性**：提升 - 伏行的混沌，幻夢境之主，加值轉換

**特殊**：由於沒有技能樹，額外獲得一個特性。

**注**

<ul>
<li>所有無需檢定的能力可以正常影響你。</li>
<li>所有以你爲目標且造成傷害的能力可以正常影響你。</li>
<li>你只能無視傷害部分，若其同時造成多種效果，則非傷害部分對你一樣有效。</li>
</ul>

**加值轉換**：本改造給的屬性加值變爲增強加值。

**價格**：S+8000

**其他標籤**

**伏行的混沌**

<ul>
<li>混沌之力保護着你不會讓你受到無端的侵擾，畢竟，你是奈亞拉拖提普。</li>
<li>現在這升級爲一個 S 級的影響心靈效果，並且所有不以你爲目標，但是會對你造成傷害的效果，則其進行該次傷害的攻擊或者施法檢定時，都需要與你進行一次意志對抗，若其失敗，則其該次傷害無法影響到你。</li>
</ul>

**幻夢境之主**

<ul>
<li>瘋狂吧，哀嚎吧，在幻夢境之中，誰也無法逃離。</li>
<li>歡迎來到我的地盤，我是這裏的主人，只想和你們玩一個遊戲罷了。</li>
<li>每當你的感知範圍內有單位使用意志力時，則你可以無需動作發起與目標進行一次意志對抗，若你成功則目標失去差值的意志力。</li>
</ul>
