# 毒液改造

> 來源：`資源/改造/特異本質改造/毒液改造`

**描述**：一罐黑色黏膠狀物在燒瓶中翻滾掙扎。作爲來自驚奇世界的造物，“毒液”因其給予凡人力量之強大和道德掙扎之激烈而知名。也正是因此，主神對其改良之後加入進裝備庫供冒險者選擇。

**價格**：D+500

**其他標籤**

**共生體**

<ul>
<li>角色獲得“毒液”作爲共生體。</li>
<li>角色可以通過一個移動動作將共生體完全展現或回收。展現情況下，共生體會覆蓋角色指定的位置，但只有至少覆蓋軀幹主體才能使其正常生效，此時“毒液”視爲衣物，佔據盔甲裝備位，此時角色獲得回收狀態和展現狀態的全部特性。</li>
<li>回收狀態下，共生體由角色體表滲入體內，此時盔甲裝備位視爲閒置，角色可裝備其他盔甲並正常獲得其效果，但角色也不能享受任何“毒液”展現時給予的能力和特性。</li>
<li>由於其生物本能，共生體排斥非基因和生物體類型的血統，這意味着共生體只能與不改變生物類型的血統兼容（如黑暗生物，光明生物，不死生物等血統皆無法兼容）。任何選用不兼容具的血統的角色都會永久失去“毒液”改造，已付出支線無法退回。共生體主要生存在宿主的腦部，心臟等主要臟器，因此在判定位置時，融合後的共生體視爲佔據宿主的主要臟器所在位置及生理循環系統，這包括了大腦，心臟，肺等主要臟器。</li>
</ul>

**正文**

角色可以通過一個自由動作在共生體展現和神器顯現狀態之間互換。神器顯現狀態下，一團類似粘稠的網狀膠體粗略的組成一個不穩定的人形外表包覆着宿主，數根相同材質的觸手狀附肢由角色胸背肩等處伸出。和其他神器不同，共生體必須依靠宿主才能存活。因此展現狀態下的共生體只能在角色觸及範圍內移動。但因爲和宿主聯繫緊密，展現狀態下共生體可代替宿主對環境產生影響。神器顯現狀態下，角色獲得相當於器魂心智屬性的觸手狀附肢，附肢視爲角色一部分，如正常肢體般進行使用並受相同限制。此狀態下，角色觸及範圍獲得相當於親和屬性的 5 倍的加值。

**其他標籤**

**蛛行術**：角色可以如蜘蛛一般在垂直表面上攀爬移動，甚至天花板上也可以。在這種情況下，人物必須騰出雙手來爬行。他獲得等同於基礎速度的攀爬速度，並且在垂直或水平表面（甚至是天花板頂下）爬時不需要進行運動檢定。使用此能力時防禦不會有減值，但在爬行時不能奔跑。

**體質增強**：穿戴者的生理屬性各獲得改造等級 / 點器械加值。

**融合**：本改造等級每比 D 級高一級，共生體戰衣提供的盔甲加值便增加 2/2 點。
