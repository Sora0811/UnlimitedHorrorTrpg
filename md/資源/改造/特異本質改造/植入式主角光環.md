# 植入式主角光環

> 來源：`資源/改造/特異本質改造/植入式主角光環`

**本質**：特異本質

**描述**：道路級邪神集會萬象組織收集諸世界主角光環研究分析其降智原理，所創造的人工主角光環

## D 級　你要這智力有何用

**價格**：D+500

**屬性**：感知+2、操控+2

**能量池**：無

**技能樹**：無

**特性**：加值轉換、降智（三特性）

**特殊**：由於沒有能量池、技能樹，額外獲得2個特性

**描述**：故事裏的龍套總是懵懵懂懂的在主角的說服下忽略了明顯的漏洞，但至少這樣可以活得更長不是麼

**價格**：D+500

**其他標籤**

**降智**

<ul>
<li>當你進行操控爲主屬性的社交檢定時，目標若需要感受作爲對抗檢定，則其對應的屬性在本次檢定中降低相當於你改造等級/點，若降低至0，則其該對抗直接失敗，若計算成功數，則成功數爲0。</li>
<li>同時，目標不會因爲對你的態度或者任何DC加成。</li>
</ul>


### 這是一個D級影響心靈的能力

**加值轉換**：本級改造提供的屬性加值爲器械加值。

## C 級　理性蒸發

**價格**：C+1000

**屬性**：感知+3、操控+3

**技能樹**：無

**特性**：加值轉換、理性蒸發（雙特性）

**特殊**：由於沒有技能樹，額外獲得1個特性

**描述**：洗白的反派，在故事裏爲主角擋下致命的一擊不是最王道的發展嘛，至於你是不是自願洗白的誰管你啦。

**加值轉換**：本級改造提供的屬性加值爲器械加值。

**價格**：C+1000

**其他標籤**

**理性蒸發**：你可以消耗一個標準動作，消耗X點意志力，開啓主角的魅惑之力，以你爲中心，操控值\*10米範圍內的所有生物，每輪承受相當於你傳奇操控/點可疊加的魅惑點數。目標以意志進行豁免檢定，DC爲你的操控值，若其成功，則不受魅惑點數影響，否則受到全部魅惑點數影響，光環持續X輪，魅惑點數持續時間如常。


## B 級　主角魅力

**價格**：B+2000

**屬性**：感知+4、操控+4

**技能樹**：無

**特性**：加值轉換、主角魅力（雙特性）

**特殊**：由於沒有技能樹，額外獲得1個特性

**描述**：現在退去還來得及，三十年河東三十年河西，你知道的，如果讓我真的說出來，九天十地沒人救得了你

**加值轉換**：本級改造提供的屬性加值爲器械加值。

**價格**：B+2000

**其他標籤**

**主角魅力**：當你受到一次檢定時，你可以用反射動作消耗5點意志力進行一次以操控爲主屬性的社交檢定，該次檢定每有1點成功數則目標的該次檢定失去1DP，這是無名減值，這是一個B級影響心靈的能力。


## A 級　真・主角光環

**價格**：A+4000

**屬性**：感知+6、操控+6

**技能樹**：無

**特性**：加值轉換、主角光環、心智破碎

**特殊**：由於沒有技能樹，額外獲得1個特性

**描述**：你眼中閃過異彩，明明只是第一次見面，卻爲何覺得如此心動

**加值轉換**：本級改造提供的屬性加值爲器械加值。

**價格**：A+4000

**其他標籤**

**心智破碎**：你可以以整輪動作消耗5點意志力選擇能感知到你的一個目標，然後進行一個以操控爲主屬性的社交檢定對抗目標意志，若勝出則可以命令對方進行一個不涉及知識也不直接傷害自我的動作（即白卡時就可以進行的，衝鋒、普通攻擊、說話、移動、格擋等），目標在其下輪若可以執行，則必須優先執行該行爲並消耗其相應動作，這是一個A級影響心靈的能力。

**主角光環**

<ul>
<li>你啓動“主角魅力”之後，在持續時間內任何以你爲目標的行動，如果會對你產生任何負面效果，你可以隨時啓動本能力：</li>
<li>行動者需要進行意志豁免檢定，DC爲你的操控值+其對你產生的魅惑點數之和，若其失敗，則其無法對你進行本行動，同時失去對應的動作，本效果每場景你可以使用你的傳奇操控/次，這是一個A級影響心靈的能力。</li>
</ul>
