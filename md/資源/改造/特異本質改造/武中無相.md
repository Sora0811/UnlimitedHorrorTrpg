# 武中無相

> 來源：`資源/改造/特異本質改造/武中無相`

**本質**：特異本質

**前提**：智力7、感知7、科學5、神祕學5、電腦5

**價格**：A+4000

**屬性**：無

**能量池**：無

**特性**：天心鎖魄（雙負特性），招式分析（三特性），推理演算，天位力量（五特性）

**特殊**：不提供屬性，額外獲得兩個特性；由於沒有技能樹，額外獲得1個特性；一次性改造，額外獲得兩個特性。

**描述**：通過特殊方法，將自身力量上限永久鎖在小天位程度，換來無限接近太天位的天心意識。可以瞬間理解、破解出任何能力的原理和使用方法。用以配合任何技能都能以最完美的方式達成目標。

**價格**：A+4000

**其他標籤**

**天心鎖魄**

<ul>
<li>你所有能量池上的限皆鎖定爲90點，超過90點的能量值仍然存在，但會被鎖定，無法使用；你單項屬性上限鎖定爲21點，超過屬性上限的屬性仍然存在，可以作爲某些強化或裝備要求的前提，但不會爲你提供任何好處，包括檢定、衍生屬性、附加成功等，該限制同時對所有增加屬性值的方式（包括內在加值、修行加值與臨時加值）生效。</li>
<li>此外你無法再使用洗點系統。</li>
</ul>

**招式分析**

<ul>
<li>當任何生物在你的敏感範圍內施展過BB級或以下的『招式』和『技能』時，你每輪可以進行一次[智力+感知]的延長檢定，DC爲對方所使用技能的支線等級（D1C3S9）的平方數，若你的智力在11以下，這是一個移動動作，超過11後是一個迅捷動作。在你成功的分析完一個技能前不能同時分析別的技能，否則損失之前分析未完成的進度。</li>
<li>成功分析完成之後，對曾在你感知範圍內使用過此技能的人，你在針對他的攻擊、施法檢定和防禦上獲得等於此技能支線等級的洞察加值加值。</li>
<li>同時，若你滿足此技能前提，則你可以隨時如同自創技能一般獲得這個技能，遵循自創技能規則，但消耗的XP減半，你最多以此法自創4個技能。</li>
<li>特殊的，你可以透過支付XP來提升可分析的等級上限。支付7點XP，你可分析學習的招式等級上限提升至A級；支付28點XP，你可分析學習的招式等級上限由A提升至AA級；支付54點XP，你可分析學習的招式等級上限由AA級提升至S級。</li>
</ul>

**推理演算**

<ul>
<li>你的大腦如同最高級的電子計算機一般不斷的對周圍的情報進行着推理演算。</li>
<li>只要你並非措手不及，你在防禦上獲得等同你在智力和感知中較高者的環境加值。</li>
</ul>

**天位力量**：你獲得了天心意識。

**萬物元氣鎖**：達到齋天位的高手能夠利用萬物的元氣封鎖敵人的力量。要這麼做，你必須先成功的擊中對方並造成至少一點傷害，接着雙方可以各自選定自己一個能量池，支付其中最多不超過該能量池上限一半的能量，之後以支付的能量作爲DP數一個對抗檢定，若對方失敗，則被萬物元氣鎖封鎖。你可以選擇下列效果其中一個施加於其身上：

**天位力量封鎖**：將對方的天位力量封鎖到小天位程度，永久生效，這是一個A級詛咒效果。本效果對天位力量與你同級的強者無效。

**能量封鎖**：對方無法使用任何能量，持續一個場景。對方可以消耗一個整輪動作並支付1點經驗，然後再次選定自身擁有的一個能量池，支付其中最多不超過能量池上限一半的能量並以支付的能量作爲DP數，與你先前的判定結果對抗，若取勝則可解除能量封鎖效果。

**能量波動**：你可以以一個移動動作引發感知範圍內一名已受到你萬物元氣鎖中“天位力量封鎖”或“能量封鎖”效果影響的單位的內氣波動。選定其擁有的一個能量池，對方進行一次DP值等同於該能量池剩餘能量的檢定，該次檢定中每有一個失敗數則使對方失去一點該能量，同時受到一點嚴重傷害，之後該單位身上的封鎖效果會被解除。


**正文**

若你已成功開啓過一階基因鎖，則能夠邁入小天位。你在使用任何消耗能量的技能時，能耗減少1點，最多減少到0。你的傷勢和能量的自然恢復速度加倍。你可以以自身基礎速度的兩倍進行飛行，機動性良好。

若你已成功開啓過二階基因鎖，則能夠邁入強天位。你在使用任何消耗能量的技能時，可減少的能耗提升至3點，最多減少到0。現在你可以以基礎移動速度的五倍進行飛行，機動性完美。

若你已成功開啓過三階基因鎖，則能夠邁入齋天位，你每輪都會自動恢復1點惡性或6點嚴重或18點衝擊傷害，你可以以基礎速度的十倍進行飛行，機動性爲完美，除此之外你可以透過天心意識觀察以自身爲中心，半徑爲你的感知值\*10公里的範圍，這是一個A級魔幻本質的偵測能力，但此能力只能模糊的感知到氣息的存在和狀況，無法做到精確觀察，即使透過本能力偵測到了任意目標，但若沒有其他能力能夠使你對其進行精確定位的話，你至多隻能對其進行模糊定位。

當你已成功開啓過四階基因鎖，你就進入了天位的最高階級――太天位。在這個級別，你的一舉一動都可以說代表着天意。當你處在四階基因鎖狀態下時，你失去“天心鎖魄”特性。
