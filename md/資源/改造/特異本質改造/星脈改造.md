# 星脈改造（來源：學戰都市Asterisk）

> 來源：`資源/改造/特異本質改造/星脈改造`

**本質**：特異本質

**作者**：刀藤綺凜

**描述**：受到萬應素影響而誕生的新人類。身體能力遠遠超越既有的人類，同時還具備叫做「星辰力」的靈氣。由於擁有遠超越一般人的體能與力量因此在與論與行動上受到許多限制，特別是傷害他人時，就算是受害者也會被質疑成過度防禦，經常被判處比犯人更重的責罰。其中能以肉身和萬應素連結的異能者，女性叫做魔女（Strega），男性叫做魔術師（Dante）。

**前提**：星脈世代是受到萬應素侵蝕和改造的新人類，PC必須爲純血人類或者調整者、七夜血脈等其他與人類相差不同的血統，一切非人類強化都無法與本改造共存。

## D 級　萬應素感應

**價格**：D+1000

**屬性**：敏捷+2，耐力+2

**能量池**：星辰力

**技能樹**：無

**特性**：獅鷲，鳳凰，王龍（雙特性），加值轉換

**特殊**：因爲沒有技能樹並且分數翻倍，額外獲得兩個特性

**描述**：你現在已經可以感應到萬應素的存在，但是並不能對其進行多少的運用。

**加值轉換**：本級改造提供的屬性加值爲增強加值。

**價格**：D+1000

**其他標籤**

**獅鷲**：在獅鷲星武祭中，行動速度對你的團隊有着巨大的幫助。你的基礎移動速度提升10米。

**鳳凰**：在鳳凰星武祭中，掌握敵人的動向有助於你協助隊友擊敗敵人。星辰力的強化極大的增幅了你的視力，你獲得黑暗視覺。

**王龍**：在王龍星武祭中，你所做的一切都是爲了展現出自己最強大的實力而戰勝敵人。你的攻擊檢定獲得自身傳奇耐力/點增強加值，這可以與本改造帶來的同類別加值疊加；你進行近戰白刃攻擊時，可以使用敏捷屬性代替力量屬性進行攻擊檢定。


## C 級　萬應素掌握

**價格**：C+2000

**屬性**：敏捷+3，耐力+3

**技能樹**：無

**特性**：提升-獅鷲，提升-鳳凰，提升-王龍,加值轉換

**特殊**：因爲沒有技能樹並且分數翻倍，額外獲得兩個特性

**描述**

<ul>
<li>從現在起你已經是一個合格的星脈世代了，你對於星辰力已經具有了熟悉的掌握。</li>
<li>提升-獅鷲：你的基礎移動速度在D級別改造的基礎上再增加20米。</li>
<li>提升-鳳凰：你的感知變得更加敏銳，哪怕在無光的夜晚你也能輕易洞察附近的一切動靜，你獲得等同自身敏感範圍的盲感。</li>
<li>提升-王龍：你現在進行敏捷相關檢定時，會額外獲得自身傳奇耐力/點增強加值，這會和本改造帶來的同類加值疊加。</li>
</ul>

**加值轉換**：本級改造提供的屬性加值爲增強加值。

**價格**：C+2000

**技能樹**：無

**特性**：提升-獅鷲，提升-鳳凰，提升-王龍, 加值轉換

**特殊**：因爲沒有技能樹並且分數翻倍，額外獲得兩個特性

**描述**

<li>提升-獅鷲：你現在以敏捷屬性決定自己的基礎防禦而不是敏捷/感知取低。</li>
<li>提升-鳳凰：你的感知更加銳利使得敵人幾乎無從遁形，你在C級時獲得的盲感變爲盲視並且你的敏感範圍提升1倍，同比擴大模糊範圍。</li>
<li>提升-王龍：你現在使用敏捷屬性代替力量屬性進行攻擊檢定時，可以同步使用敏捷屬性代替力量屬性計算傷害上限。</li>
</ul>

**加值轉換**：本級改造提供的屬性加值爲增強加值。

**價格**：B+4000

**描述**

<li>提升-獅鷲：你的基礎移動速度翻倍；無需任何動作，支付1點星辰力，你可以獲得等同自身基礎移動速度2倍的飛行速度，機動性爲完美，持續傳奇敏捷/輪。</li>

## S 級　星脈世代

**價格**：S+16000

**屬性**：敏捷+8，耐力+8，沉着+8

**技能樹**：無

**特性**：提升-獅鷲，提升-鳳凰，提升-王龍,加值轉換

**特殊**：因爲沒有技能樹並且分數翻倍，額外獲得兩個特性

**描述**

<ul>
<li>並不需要其他的稱呼，星脈世代，便代表了你的身份。</li>
<li>提升-獅鷲：你風馳電掣的速度已經扭曲了光影，在他人的視線裏，你的身形已經完全消失無形。你進行近戰白刃攻擊檢定時會獲得當前先攻值一半/點速度加值（最大不超過你的敏捷屬性/點）；你每進行一次攻擊，你的先攻值便提升傳奇敏捷/點，這會改變先攻順序，當你的先攻順序爲爲第一時，當你本輪結束後，你可以 立即獲得一個全新的一輪，當新的一輪結束後， 你的先攻值下降爲1， 按照新的先攻權進行結算，並且跳過你本回合原本的行動輪。 此時你需要從零開始累積先攻值。</li>
<li>提升-鳳凰：你立於未來的雲端俯瞰過去，你的感知曉空洞明，你已經短暫的看到未來的景象，正如克勞蒂雅・恩菲爾德一樣，你最大甚至可以預測五分鐘的風景，在戰鬥中，這已經改變一切戰局的進程，你免疫S級以下的措手不及效果。</li>
<li>提升-王龍：你進行近戰白刃攻擊檢定時，若你每進行一次攻擊，下一次攻擊同一目標，你便額外獲得傳奇敏捷/個附加成功，你獲得的攻擊附加成功最多不超過你敏捷值/個。若你中途改變目標或者停止攻擊（無論主動放棄還是因爲心控類、嘲諷類、結界類能力而被迫轉變目標或者哪怕是因爲觸及範圍不足以進行攻擊，而導致有一輪未能成功對其進行攻擊），則你立即失去全部的額外附加成功，此時你需要重新累積。</li>
</ul>

**加值轉換**：本級改造提供的屬性加值爲增強加值。

**價格**：S+16000
