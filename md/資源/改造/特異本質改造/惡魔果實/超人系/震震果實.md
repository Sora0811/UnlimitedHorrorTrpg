# 震震果實（超人系 -超能力 ）

> 來源：`資源/改造/特異本質改造/惡魔果實/超人系/震震果實`

**價格**：A+4000

**技能樹**：無

**特性**：震！（三特性），環境鉅變（雙特性），空碎（雙特性），震開

**特殊**：由於沒有屬性，技能樹和一次性改造，額外獲得5個特性。

**描述**

<ul>
<li>“ONE PIECE！是真實存在的！”</li>
<li>世界最強的男人，白鬍子所使用的果實.可以隨意引發震動，全力發動時足以讓大地，海洋，甚至天空碎裂的強大果實.</li>
</ul>

**說明**

<ul>
<li>X爲你的傳奇耐力+自身最高支線等級。</li>
<li>你可以通過以下方法增加X。</li>
<li>每花費8XP，則X增加1點。</li>
</ul>

**價格**：A+4000

**其他標籤**

**震！**

<ul>
<li>你現在獲得一種新的能力，可以引發物體的震動，造成毀天滅地的效果，你可以使用以下方法使用本能力：</li>
<li>你可以將本能力凝聚在自己的實體武器攻擊中，若如此做，你的本次攻擊的傷害類型變爲力場傷害，武器傷害提升 X點， 並且可以造成遠程攻擊，最大射程爲 X\*100米， 破甲增加 X點 ，並且相當於 X點 的傷害提升爲惡性傷害。</li>
</ul>

**環境鉅變**：你可以使用本能力造成巨大的環境影響，製造地震，海嘯，分裂大地和海面，引發火山爆發這些環境效果，可改變的最大射程爲X\*100米，範圍爲X\*50米的半徑。

**空碎**：你可以以一個標準動作，以力量/敏捷取高+肉搏作爲遠程接觸攻擊檢定，射程爲耐力\*10米，若成功命中目標，則對目標造成相當於X\*2的力場惡性傷害。

**震開**：當你受到物理傷害時，你可以以震動來化解本次傷害，你可以抵消相當於X點物理傷害。
