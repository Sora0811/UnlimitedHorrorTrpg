# 甜甜果實（超人系 -超能力 ）

> 來源：`資源/改造/特異本質改造/惡魔果實/超人系/甜甜果實`

**價格**：C+1000

**屬性**：無

**描述**：大海上最美麗的女人波雅・漢庫克擁有的惡魔果實。愛情是人與人之間的強烈的依戀、親近、嚮往，以及無私專一併且無所不盡其心的情感。甜甜果實能力者則是將愛情玩弄於股掌的恐怖能力者，並且擁有將愛情當作武器和石化的能力。

**特性**：美杜莎之吻 （三特性），非凡美貌， 愛情的俘虜 （三特性）。

**技能樹**：開啓甜甜果實技能樹

**特殊**：由於沒有屬性和一次性改造，額外獲得4個特性。

**價格**：C+1000

## 芳香腳

**價格**：12XP

**描述**

<ul>
<li>愛情一記重拳將我擊倒。</li>
<li>當甜甜果實能力者使用天生武器 或者甜甜果實的招式 攻擊對手 時 ，可以將你的傾城之貌專長等級作爲 完美 加值加在你的攻擊 檢定 上 和傷害上限上 。</li>
</ul>

**價格**：12 XP

## 槍吻

**價格**：32XP

**描述**

<ul>
<li>愛情就像一顆幸福的子彈，不愛就不會受傷。</li>
<li>以一個標準動作，用風度+表達+武器傷害（惡魔果實等級+傾城之貌等級）進行一次遠程攻擊檢定，基礎射程和最大射程皆爲80米，擁有高速5特性，造成嚴重精神傷害。傷害上限爲武器傷害\*2+表達。</li>
</ul>

**升階**

<ul>
<li>花費8XP</li>
<li>奴隸之箭</li>
<li>基礎射程和最大射程提升爲200米。</li>
<li>同時你可以發動火力壓制，若如此做 ，範圍內的所有目標反射豁免，你可以進行風度 +表達檢定，每有1個成功數，則目標的反射豁免失去1DP。</li>
</ul>

**價格**：32 XP

## 甜甜甘風

**價格**：64XP

**描述**

<ul>
<li>愛情就象龍捲風，愛情來臨的時候，想逃也逃不開。</li>
<li>以一個 整輪動作， 選擇100 米內一個 9\*9米的範圍區域。你進行風度+表達檢定，你傾城之貌每有1級，則本次檢定獲得1點附加成功。然後範圍內所有目標進行意志豁免。若目標失敗，則每有1點差值獲得1點精神束縛，可與原先的精神束縛相疊加。</li>
</ul>

**價格**：64 XP

**其他標籤**

**美杜莎之吻**：當你使用 甜甜果實的招式 或者以自身天生武器進行肉搏攻擊時，每造成1點傷害，則會對目標造成1點精神束縛，意志豁免。本 點數不能疊加，並且這個狀態點數每輪都會下降１點。因甜甜果實能力造成的精神束縛狀態點數超過決心或沉着的較高者，則人物進入石化狀態。 甜甜果實的 能力者只需花費迅捷動作輕輕揮手就可以簡單地遠程解除甜甜果實造成的 精神束縛點數 ，在主神空間也可以花費 100 分解除甜甜果實造成的石化狀態。

**傾城之貌**：你的傾城之貌專長無需同種族的審美即可生效。

**愛情的俘虜**：只要目標可以感知到你，你就可以讓其所有攻擊，防禦，豁免檢定全部受到相當於你傳奇風度+傾城之貌等級的士氣減值。對手身上每有1點劇痛點數，則可以無視2點本士氣減值。

**修煉**：無需逐級修煉
