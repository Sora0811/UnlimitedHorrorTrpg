# 橡膠果實（超人系 -超人體 ）

> 來源：`資源/改造/特異本質改造/惡魔果實/超人系/橡膠果實`

**價格**

<ul>
<li>A+4000</li>
<li>16XP</li>
<li>32XP</li>
<li>64XP</li>
</ul>

**屬性**：無

**描述**

<ul>
<li>喫下這個外型好似哈密瓜，可是味道特難喫的果實以後，你永遠地變成了旱鴨子，你的身體變成了充滿彈性的橡膠，可以任意拉伸也不會受傷。這使你不再害怕鈍擊傷害和電流。</li>
<li>噴射氣。將橡膠身體當作泵，通過給腿部打氣加速血液的流動，使用二檔時身體會發紅，並冒出蒸汽，如同使用興奮劑一般。普通人使用這招會導致血管爆裂身亡，橡膠人雖然可以承受，但經常使用也會縮短壽命。</li>
<li>花費1點意志力以一個迅捷動作啓動，持續5輪，持續時間結束後你可以花費1點意志力繼續維持，當結束二擋狀態時，你受到不可避免的相當於二擋持續時間的衝擊傷害。</li>
<li>啓動後你在進行肉搏攻擊時獲得3DP速度加值。並且獲得5點高速，並且你的陸行速度增加10米。</li>
<li>同時，若目標第一次受到二擋狀態下的你攻擊時，其視爲措手不及，這視爲D級措手不及。</li>
<li>骨氣球。把空氣吹入骨頭裏，讓骨頭膨脹成爲骨氣球，讓手腳變成如同巨人一般大小，擁有如同鋼鐵一般的硬度，只有橡膠人纔可以使用的招式。</li>
<li>花費3點意志力以一個迅捷動作啓動，最多持續10輪。持續時間結束後，體積縮小爲原先的一半（向下取整），持續時間爲維持三檔的時間。</li>
<li>啓動後你的天生武器傷害和破甲獲得相當於你力量附加成功數的提升，同時你在進行肉搏攻擊時獲得6DP增強加值，並且獲得【擊飛】特性。並且在摔絆，衝撞，擒抱檢定中體積視爲原先的二倍。</li>
<li>四檔是往肌肉裏面吹氣從而變成韌性超強的彈跳人，比 二檔 速度更快，比 三檔 力量更大，並且還能利用彈力噴射在空中移動。覆蓋武裝色霸氣的橡膠能把攻擊全部彈開，施展“大蛇拳”攻擊還能追蹤敵人，十分強大。</li>
<li>花費5點意志力以一個迅捷動作啓動，持續5輪，啓動本能力時，必須同時啓動武裝色霸氣。持續時間結束後，你10分鐘之內無法再次使用四擋，並且無法啓動武裝色霸氣。</li>
<li>啓動後你的基礎移動速度下降10米，你的肉搏攻擊獲得12DP能量加值，並且獲得【眩暈】特性。在此狀態下，你每受到1點傷害，則下次攻擊再增加3DP能量加值，沒有上限。你的天生武器傷害增加你力量附加成功數\*霸氣等級/點。</li>
</ul>

**特性**：橡皮體質（六特性），隨意拉伸

**技能樹**：開啓橡膠果實技能樹

**特殊**：由於沒有屬性和一次性改造，額外獲得4個特性。

**前提**：擁有武裝色霸氣

**價格**：A+4000

**其他標籤**

**橡皮體質**：角色從此免疫鈍擊傷害和雷電傷害，並且你免疫實彈武器造成的物理傷害。

**隨意拉伸**：你可以隨意拉伸自己，這表現爲你的觸及擴大八倍。

**覺醒**：暫無
