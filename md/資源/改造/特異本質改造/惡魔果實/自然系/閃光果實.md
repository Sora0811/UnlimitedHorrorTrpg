# 閃光 果實（ 自然 系）

> 來源：`資源/改造/特異本質改造/惡魔果實/自然系/閃光果實`

**價格**：A + 40 00

**描述**：閃閃果實是動漫《 海賊王 》裏一種自然系 惡魔果實 。食用效果：體質變成光，普通攻擊對其無效，同時擁有光的速度，能通過身體發出激光，發出的激光能產生大範圍爆炸。

**特性**：光之化身（四特性），致盲，超級速度，速度即質量

**技能樹**：開啓閃光果實技能樹

**特殊**：由於沒有屬性和一次性改造，額外獲得4個特性。

**價格**：A+40

## 光速踢

**價格**：18XP

**描述**

<ul>
<li>將光子積蓄於小腿上，將腿以光速踢出，也能射出一道激光，威力足以毀滅一顆巨大的紅樹。</li>
<li>以一個標準動作，你可以進行遠程肉搏攻擊，攻擊檢定爲你敏捷/力量取高+肉搏（踢擊）+天生武器傷害，本次攻擊的最大射程爲你的耐力值\*5米，擁有【能量武器】【高速8】特性，造成光能傷害。</li>
</ul>

**價格**：18 XP

## 鐳射光線

**價格**：24XP

**描述**

<ul>
<li>用手指發出的激光射穿敵人，同時能產生大範圍爆炸。</li>
<li>以一個標準動作，你可以進行遠程攻擊，攻擊檢定爲敏捷+運動（射線）+武器傷害，武器傷害爲你最高支線等級+耐力附加成功數。本次攻擊的最大射程爲你耐力值\*20米，擁有【貫穿】【能量武器】【高速12】特性，造成光能傷害。計算貫穿後，在最後無法貫穿的目標處發生爆炸，爆炸範圍爲你耐力附加成功\*10米，造成相當於武器傷害數的範圍光能嚴重傷害，反射豁免。</li>
</ul>

**價格**：24 XP

## 八咫瓊勾玉

**價格**：32XP

**描述**

<ul>
<li>躍上空中發射無數耀眼光彈，密集程度能把人打成篩子。屬於大範圍攻擊招式。</li>
<li>以一個整輪動作，先進行一個跳躍檢定，記錄其成功數。然後進行一次火力壓制，火力壓制攻擊檢定中的屬性爲敏捷，技能爲運動（射線），武器傷害爲你最高支線等級+耐力附加成功數，本次攻擊造成光能傷害，擁有【能量武器】特性。火力壓制的最大射程爲你跳躍檢定成功數\*10米120度角的錐形範圍。</li>
</ul>

**價格**：32 XP

**其他標籤**

**光之化身**：你現在免疫光能傷害，並且你 現在的近戰攻擊可以造成光能傷害。

**致盲**：以一個標準動作，對所有能看見你的目標造成相當於你耐力值的目眩點數，該點數不會累積，強韌豁免，可以造成毀滅後果。

**超級速度**：你現在的基礎移動速度翻四倍。

**速度即質量**：當你進行近戰攻擊時，你可以用敏捷代替力量進行檢定和傷害上限，並且可以額外獲得傳奇力量所帶來的傷害上限。

**修煉**：無需逐級修煉
