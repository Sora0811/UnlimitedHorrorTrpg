# 火焰果實 （自然系）

> 來源：`資源/改造/特異本質改造/惡魔果實/自然系/火焰果實`

**價格**

<ul>
<li>A+4000</li>
<li>16XP</li>
<li>以一個標準動作，召喚出相當於力量附加成功數與你耐力附加成功數之和的小火苗。你以力量/敏捷取高+運動進行一次遠程接觸攻擊檢定，基本射程爲10米，你可以選擇分配你的火苗，若你分配的火苗超過1個目標，則需要分別檢定。若成功命中，則目標受到相當於分配數的火焰嚴重傷害，並且受到等額的燃燒點數，可疊加，無法豁免。</li>
<li>16XP</li>
<li>以一個標準動作，你可以丟出相當於你天生武器傷害的火球，基礎射程10米，最大射程用耐力而非力量，攻擊檢定爲力量+運動（輕投擲武器），本次攻擊造成火焰嚴重傷害，若成功造成傷害，則成相當於造成傷害數的燃燒點數，強韌豁免，可以疊加。</li>
<li>24XP</li>
<li>被動-你現在使用天生武器進行的肉搏攻擊觸及範圍擴大爲你的耐力\*5米。</li>
</ul>

**描述**：火拳艾斯擁有的果實，喫下此果實後，可以丟出火焰彈或將身體化爲火焰進行攻擊，威力逐漸提升，消耗體能，需要大量進食補充。

**特性**：火焰免疫（四特性），火拳（三特性）

**技能樹**：開啓火焰果實技能樹

**特殊**：由於沒有屬性和一次性改造，額外獲得4個特性。

**價格**：A+4000

## 大炎戒 ・炎帝

**價格**

<ul>
<li>64XP</li>
<li>整輪動作啓動，花費3點意志力，你可以製造一個巨大的火球。火球傷害爲你力量附加成功與耐力附加成功之和，其體積等於其傷害。你可以花費標準動作，以敏捷/力量+運動將其投擲出去，其基本射程等於你的耐力值/米。命中後炎帝將產生爆炸，對其體積\*10米範圍內的所有目標造成等於炎帝傷害的火焰惡性傷害，反射豁免，你的檢定每有1點成功數，則目標的反射豁免失去1DP。目標反射豁免每有1點成功數，則可以將1點傷害下降1級。同時，目標每受到1點火焰傷害，則目標受到1點燃燒點數，無豁免，可疊加。</li>
</ul>

**增幅**：你額外對炎帝進行蓄力，蓄力是一個標準動作，每蓄力一次，炎帝的傷害提升相當於你力量附加成功數與耐力附加成功數之和，最大不得超過你的力量值或者耐力值取低。炎帝最多存在你的決心值/輪。

**價格**：64 XP

**其他標籤**

**火焰免疫**：你免疫火焰傷害和高溫環境減值和環境效果，你免疫燃燒點數。

**火拳**：你現在使用天生武器或者近戰白刃武器進行攻擊可以造成火焰傷害，若成功命中，則造成相當於造成傷害數的燃燒點數，強韌豁免，可以疊加。

**修煉**：無需逐級修煉
