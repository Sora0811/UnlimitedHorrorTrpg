# 岩漿果實（自然系）

> 來源：`資源/改造/特異本質改造/惡魔果實/自然系/熔岩果實`

**價格**：A+4000

**描述**：海軍大將“赤犬”所使用的果實，食用後體質變成岩漿，普通攻擊對其無效。可以通過身體制造岩漿，甚至可以燃燒火。

**特性**：火焰免疫（四特性），熔岩直拳，焚燒，高溫皮膚

**技能樹**：開啓岩漿果實技能樹

**特殊**：由於沒有屬性和一次性改造，額外獲得4個特性。

**價格**：A+4000

## 犬齧紅蓮

**價格**：16XP

**描述**

<ul>
<li>暴熱！熔岩！紅蓮拳！</li>
<li>你的天生武器在造成火焰傷害時，擁有【能量武器】特性。</li>
<li>當你 使用天生武器 成功 造成傷害並且該傷害爲火焰傷害時 ，你每造成1點火焰傷害，則對手受到等額的【燃燒 點數 】。該點數持續時間爲你的耐力附加成功+1/輪 。</li>
</ul>

**價格**：16 XP

## 大噴火

**價格**

<ul>
<li>32XP</li>
<li>以一個標準動作，你的近戰攻擊可以攻擊遠距離的目標， 射程 爲力量/米 ，若如此做，你本次造成的傷害必須爲火焰傷害 。你也可以將本次攻擊變爲 火焰 範圍攻擊，距離爲力量/米，範圍爲九十度錐形，傷害爲你的天生武器傷害，你進行一次力量+肉搏的判定， 每有1點 成功 則 目標 的 反射檢定 失去1DP 。</li>
</ul>

**價格**：32 XP

## 流星火山

**價格**

<ul>
<li>64XP</li>
<li>以一個整輪動作花費5點意志力，你以天生武器進行一次攻擊檢定，本次攻擊額外獲得你力量\*5米的射程。若成功造成傷害，則以該目標爲中心，造成等於你本次傷害一半的範圍火焰嚴重傷害，範圍最大爲你的體積\*3米，所有目標範圍豁免，被你直接命中的目標不會受到二次傷害。</li>
<li>同時，若有目標受到範圍傷害，則其受到其受到傷害數一半的【眩暈】【目眩】【耳鳴】點數，分別進行強韌豁免。</li>
<li>另外此範圍內相當於受到煙霧彈的效果。</li>
</ul>

**價格**：64 XP

## 燃燒火焰

**價格**

<ul>
<li>80XP</li>
<li>你現在造成的火焰傷害無視目標的能量抗力，傷害吸收能力。</li>
<li>在面對火焰免疫或者類似的特性時，目標的火焰免疫特性變爲16點火焰傷害抵消。</li>
</ul>

**價格**：80 XP

**其他標籤**

**火焰免疫**：你免疫火焰傷害和高溫環境減值和環境效果，你免疫燃燒點數。

**熔岩直拳**：你令自己的天生武器覆蓋岩漿， 你現在使用天生武器進行攻擊可以造成火焰傷害，並且若成功 命中 ，可以 額外造成 8點火焰嚴重傷害。

**焚燒**：若你對目標成功造成火焰傷害，則目標所有的快速醫療或者再生下降2點，持續你耐力附加成功數/輪。

**高溫皮膚**：當你受到近戰攻擊時，攻擊者若成功命中你，其受到8點火焰嚴重傷害。

**修煉**：無需逐級修煉
