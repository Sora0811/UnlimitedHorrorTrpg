# 究極生命體

> 來源：`資源/改造/特異本質改造/究極生命體`

**本質**：特異本質

**價格**：C+1000

**屬性**：無

**特性**：無窮潛能（雙特性），高位生命體（三特性），能量爆發，純淨而唯一 ( 負特性 )

**特殊**：一次性改造，額外獲得兩個特性，由於沒有技能樹，額外獲得一個特性。

**描述**

<ul>
<li>主神從一個宇宙發現的究極生命體，因其擁有無限的潛力，於是收集其胚胎存入資料庫。</li>
<li>經過幾百億年從自然界重重困難中殺出來的究極生命體 ( 的初始形態 ) 。</li>
</ul>

**價格**：C+1000

**其他標籤**

**無窮潛能**：每經歷一場恐怖片，在恐怖片結束時你獲得 3 點屬性，這是永久內在加值。當最高屬性與最低屬性相差 15 點時，自動將 1 自由屬性點加到最低屬性，如果有多個自由屬性，則按照本人意願分配。

**高位生命體**：你獲得等於你最高屬性的傳奇屬性 / 點的全傷害吸收和快速醫療。

**能量爆發**

<ul>
<li>你以標準動作選擇消耗 1 點屬性內在加值，這 1 點屬性必須是你由本改造獲得的，將自身部分潛能短時間爆發出。所有由本改造獲得的屬性翻倍，持續一場景，一部影片可以使用三次。</li>
<li>若你使用本技能後，你的最高屬性與最低屬性相差超過 15 ，則超過部分的屬性暫不生效，直至你將最低屬性重新購買上來。</li>
</ul>

**純淨而唯一**：此改造一旦購買，則無法使用洗點系統，除非強化本改造，否則無法以任何方式獲得或模擬本改造的特性。
