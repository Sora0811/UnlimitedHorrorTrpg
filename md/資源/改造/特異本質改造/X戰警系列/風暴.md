# 風暴能力組

> 來源：`資源/改造/特異本質改造/X戰警系列/風暴`

**價格**

<ul>
<li>D+500</li>
<li>C+1000</li>
<li>B+4000</li>
</ul>

**屬性**

<ul>
<li>風度+2 感知+2</li>
<li>風度+3 感知+3</li>
<li>風度+4 感知+4</li>
</ul>

**能量池**：無

**特性**

<ul>
<li>大氣掌控（雙特性），操縱天氣（雙特性）</li>
<li>操縱天氣（提升雙特性），召喚閃電</li>
<li>操縱天氣（提升雙特性），召喚閃電（提升特性）</li>
</ul>

**特殊**

<ul>
<li>由於沒有技能樹和能量池，獲得2個特性</li>
<li>由於沒有技能樹，額外獲得1個特性</li>
<li>由於沒有技能樹，額外獲得1個特性</li>
</ul>

**價格**：D+500

**其他標籤**

**大氣掌控**：你可以感知到1公里\*感知範圍內的天氣在一小時內的變化，如果範圍內有不自然的氣象產生，你可以得知其是來自於科學還是超自然力量的影響。你免疫天氣與溫度變化對你的影響。

**操縱天氣**

<ul>
<li>你獲得了控制天氣的能力。以一個整輪動作並消耗一點意志，你可以改變10米\*感知範圍內的 氣溫 ，你可以將氣溫升高或降低一級，例如從“嚴寒”降低爲“極寒”，或是“高溫”到“極度高溫”。持續一個場景。</li>
<li>操縱天氣的範圍提升爲20米\*感知。現在你 除了氣溫之外，你還可以調節天氣， 你 可以 改變風力，可以將風力提升或降低一級，例如從“強風”提升到“烈風”，或是“龍捲風”降低到“颶風 ”。並且你可以 操縱降水，你在範圍內造成“降雨”，並且若氣溫不高於“寒冷”，“降雨”將轉變爲“降雪”。</li>
<li>操縱天氣的範圍提升爲100米\*感知。你現在可以以一個標準動作同時操縱氣溫與天氣，並且操縱天氣的能力可以同時改變降水與風力。你獲得機動性完美的飛行能力，速度等於基礎速度。</li>
</ul>

**召喚閃電**

<ul>
<li>你現在可以從手中射出一道閃電來打擊你視線範圍內的一個目標，投感知+運動（射線攻擊）作爲接觸命中判定，只要有一個成功便視爲命中，造成改造等級\*2+傳奇感知+生存技能附加成功的雷電嚴重傷害，擁有【能量武器】特性。</li>
<li>你獲得了召喚閃電的新用法。以一個標準動作召喚一道閃電，在你的操縱天氣範圍內造成半徑爲感知米的範圍攻擊，造成與單體攻擊相同的點擊傷害，反射豁免，並且你投感知+運動（射線攻擊），每有一點成功，對方在反射檢定上失去1DP。若對方受到傷害，則進行一次強韌檢定，DC等於受到的傷害，若失敗則每有一點差值都會受到一點麻痹（不疊加只取高），若對方離開操縱天氣的範圍，則麻痹點數每輪下降一點。</li>
</ul>
