# 冰人能力組

> 來源：`資源/改造/特異本質改造/X戰警系列/冰人`

**價格**

<ul>
<li>D+500</li>
<li>C+1000</li>
<li>B+2000</li>
</ul>

**屬性**

<ul>
<li>敏捷+2 耐力+2 決心+2</li>
<li>敏捷+3 耐力+3 決心+2</li>
<li>敏捷+4 耐力+4 決心+3</li>
</ul>

**能量池**：無

**特性**

<ul>
<li>寒冷抗性，寒冰之觸（雙特性）</li>
<li>寒冰之觸（提升特性），寒冰噴射</li>
<li>冰之化身，寒冰護身</li>
</ul>

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得一個特性，由於沒有能量池，額外獲得2點屬性。</li>
<li>由於沒有技能樹，額外獲得2點屬性。</li>
<li>由於沒有技能樹，額外獲得3點屬性。</li>
</ul>

**價格**：D+500

**其他標籤**

**寒冷抗性**：你獲得改造等級\*2的寒冷抗力。

**寒冰之觸**

<ul>
<li>每當你用天生武器命中敵人或被敵人使用天生武器命中時，對其造成一點不可豁免的凍結點數，此點數每輪減少一點，可疊加。特殊的，當你與敵人處於擒抱或類似狀態下時，每輪還會再額外造成一點不可豁免的凍結點數。</li>
<li>冰人的能力發揮與他的身體狀況密切相關。造成的凍結點數變爲其耐力附加成功數，最低爲1。</li>
</ul>

**寒冰噴射**：進行一次敏捷+運動的遠程接觸攻擊判定，射程爲10米\*耐力，若命中，對敵人造成寒冰之觸的效果以及與造成的凍結點數相同的寒冷傷害。

**冰之化身**：以一個移動動作消耗一點意志，你可以化身成冰人，持續1分鐘\*耐力.在你的10米\*耐力的範圍內，你每有2點耐力附加成功，則氣溫下降一個等級（“極端炎熱”-“炎熱”-“常溫”-“寒冷”-“極端寒冷”），並且你在低溫環境下全檢定獲得低溫等級\*改造等級\*2的環境加值（例如B級時，在極寒環境下你的全檢定獲得3\*2\*2=12點加值）。

**寒冰護身**：你獲得相當於寒冷抗力的天生防禦，若你已有其他來源的天生防禦，則改爲獲得抵破甲（該抵破甲只對天生防禦生效，不對護甲防禦生效）。
