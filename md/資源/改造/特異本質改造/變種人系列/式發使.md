# 式發使

> 來源：`資源/改造/特異本質改造/變種人系列/式發使`

**本質**：特異本質

**前提**：操控6、風度4

**描述**

<ul>
<li>頭髮原本是無法靠自我的意志來操縱的東西。</li>
<li>但是對於具有這項異能的你來說，頭髮反而是最爲犀利的武器。</li>
<li>能夠自由操縱頭髮進行戰鬥的你，彷彿是千手的異形。</li>
</ul>

## D 級

**價格**：D+500

**屬性**：操控+2 風度+2

**特性**：髮型變化（雙特性），如臂如指（雙特性）

**技能樹**：無

**特殊**：由於沒有能量池和技能樹，額外獲得2個特性

**價格**：D+500

**其他標籤**

**髮型變化**：你可以自如的操縱你的頭髮，使其伸長出最多10米的距離，或者是隨意的調整發色和髮質，這會使你在掩飾檢定上獲得1DP的加值。你可以隨時以反射動作使你的頭髮成爲武器傷害4L，造成鈍擊或穿刺或揮砍傷害的天生武器，視爲擁有【長柄武器】【軟兵器】特性。

**如臂如指**

<ul>
<li>你可以視爲使用自己的慣用手一般操縱你的頭髮，但是頭髮的力量值等於你的風度值而敏捷值等於你的操控值，這不被視爲基於你的風度值或操控值的檢定。</li>
<li>操縱頭髮和操縱雙手一樣，需要消耗相應的動作。但是當你操縱頭髮進行行動時，即使只操縱一束也會耗去你這一輪的動作。</li>
</ul>


## C 級

**價格**：C+1000

**屬性**：操控+3 風度+3

**技能樹**：無

**特性**：髮質硬化（雙特性），雙馬尾

**特殊**：由於沒有技能樹，額外獲得1個特性

**價格**：C+1000

**其他標籤**

**髮質硬化**：你的頭髮作爲天生武器時獲得【9加骰】並且武器傷害獲得改造等級的提升。你每有1點傳奇風度，武器傷害就額外增加1點。你每有1點傳奇操控，就可以忽視1點掩蔽減值或1點攻擊特定部位的減值。你在使用頭髮作爲武器時，必須使用頭髮本身的屬性值進行相關檢定。

**雙馬尾**：你可以將頭髮分成兩束，並且同時操縱它們。但如果你這麼做，頭髮的屬性值視爲比原本的低3點。這不會讓你有更多的動作，或更多次的攻擊。


## B 級

**價格**：B+2000

**屬性**：操控+4 風度+4

**技能樹**：無

**特性**：卷積髮式，千變武裝，散發如瀑

**特殊**：由於沒有技能樹，額外獲得1個特性

**價格**：B+2000

**其他標籤**

**卷積髮式**：若你至少操縱兩束頭髮進行相同的行動，那麼每一束額外頭髮都會爲所有參與行動的頭髮的相關檢定帶來+1DP的加值，包括但不限定於攻擊、防禦、打字或畫圖等任何你可以用手完成的行動。若至少有四束參與行動，則再獲得一個額外的附加成功，若這個行動是攻擊，則目標視爲措手不及。

**千變武裝**：如果你在白刃技能上擁有某種武器專業，那麼你可以額外支付3XP，如果你這麼做，那麼你在使用頭髮作爲武器時，可以視爲在使用該專業的武器。在判定上頭髮仍然視爲是你的天生武器，但可以使你滿足使用某些招式技能的條件。變更當前模擬的武器專業是一個迅捷動作。

**散發如瀑**

<ul>
<li>你在操控上每有一個附加成功，你就能再額外操縱一束頭髮，但是每多操縱一束，頭髮的屬性值就視爲比原本的再低3點。你不能使頭髮的屬性值降低到1以下。</li>
<li>你在風度上每有一個附加成功，你就能使你在操縱複數頭髮時所承受的罰值減少3點。</li>
</ul>


## A 級

**價格**：A+4000

**屬性**：操控+6 風度+6

**技能樹**：無

**特性**：強健髮根，黑絲叢林，髮香入髓

**特殊**：由於沒有技能樹，額外獲得1個特性

**價格**：A+4000

**其他標籤**

**強健髮根**：你在計算頭髮的能力時，視爲你的風度/操控值比原本要高相當於你在力量/敏捷上的附加成功數的數值，這裏的能力包括延展距離、操縱數目、以及屬性值，等等。這個數值的提高有可能會帶來新的附加成功。

**黑絲叢林**：你的頭髮可以延展的距離變爲兩倍於你的操控值，並且對於在你頭髮延展的範圍之內目標的行爲不會措手不及，同時也可以忽略他的掩蔽效果。所有在你的頭髮延展範圍之內開始行動的敵意目標，都會受到等於你操控值的糾纏效果的影響。這個效果可豁免，並且只要離開範圍就會自動消失。但所有要離開此範圍的敵意目標都必須和你進行擒抱對抗，在此對抗中你可以直接以風度值作爲擒抱檢定的結果，若對方對抗失敗，則直接進入定身狀態。這是一個擒抱效果，但不會導致你失去防禦。

**髮香入髓**：現在你可以將風度上的附加成功數加到糾纏效果值上，並且將操控上的附加成功數加到擒抱對抗的檢定結果中。對於被你的頭髮定身的敵人（無論是因爲糾纏效果還是因爲脫離失敗），你在自己的行動開始時，可以以一個自由動作對其造成等於你在風度和操控上附加成功數之和的嚴重傷害，這視爲一個範圍傷害效果。
