# 操能使

> 來源：`資源/改造/特異本質改造/變種人系列/操能使`

**本質**：特異本質

**描述**

<ul>
<li>操能使，顧名思義就是操縱某種能量程度的能力，是一種非常常見的能量放出系超能力。</li>
<li>操焰使，電擊使以及冰凍的超能力是非常常見的操能使分類</li>
<li>操能使本身的強度雖然由操能能力決定，但每種能量都可能有些特殊的作用或引發其他物理現象，從而使使用者可以衍生出新的用法。</li>
<li>對於常態的物理現象，強度判定由ST決定。</li>
<li>當你選擇操能使作爲改造時，必須選擇一種具體的能量，以下以常見的冰，火，電爲例，不得選擇光能和力場。</li>
<li>覺醒超能力改變了你的內在本質，本改造提供的屬性加值是內在加值</li>
</ul>

##  級　LV1-低能力 D+500

**屬性**：風度+2 耐力+2

**能量池**：相關能量

**特性**：能量放出（三特性）

**特殊**：由於沒有技能樹，額外獲得1個特性。

**其他標籤**

**相關能量**：在這一等級，你獲得了釋放能量的能力，並獲得一個相關能量池，基礎值爲風度+耐力，這個能量池只爲計算方便而存在，並不算你實際擁有某種能量池，這個能量池每天會回覆三倍於能量池上限的能量，並平均分配到每個小時。


### 這種能量具有兩種基本用法：

**其他標籤**

**能量放出**

<ul>
<li>你能以三種方式來釋放你的能量</li>
<li>第一種，消耗1點相關能量，以一個標準動作進行一次能量射擊，這次攻擊檢定使用風度+科學（對應能量）進行，武器傷害爲4L，造成相應能量傷害，具有【能量武器】特性，射程爲風度\*10米，傷害上限爲武器傷害\*3。</li>
<li>第二種，消耗1點相關能量，以一個標準動作轟擊一個區域，在風度\*10米半徑內選擇一個不超過風度值的範圍，造成4L相應能量傷害的範圍攻擊，躲閃這個範圍攻擊的反射檢定需要承受能量武器的高速減值，並且你如同【火力壓制】一般進行一次攻擊檢定（同樣是風度+科學的判定）來減少對方的反射檢定。</li>
<li>第三種，消耗1點相關能量，你以一個自由動作使能量纏繞在自身或手持近戰武器上，你在防禦和近戰攻擊上獲得1DP能量加值，並獲得1點對應能量抗力，效果持續一個場景。</li>
</ul>


**正文**

第一，你的能量可以引發常態物理現象，例如火可以點燃物質，電可以導通電路，冰可以封凍液體等，但在這一等級你的能力尚不足以產生非常直觀的效果。

第二，這個能量可以用於作爲購買能量射擊技能樹時綁定的能量，而且你可以購買等級不超過你改造等級的能量射擊技巧如同你已經達成購買前提，你可以將能量射擊技巧應用於你本改造中的“能量放出”特性。

最後，你免疫你自己放出的能量。

##  級　LV2-異能力 C+1000

**屬性**：風度+3 耐力+3

**特性**：提升-能量放出（雙特性），能量強化

**特殊**：由於沒有技能樹，額外獲得1個特性。

**其他標籤**

**能量放出**

<ul>
<li>你對於能量的物理現象的顯現現在變得更爲直觀，其用法不應限於下數，但強度和消耗的能量可以下數作爲參考。</li>
<li>你的火焰能點燃目標，支付3點能量，讓你可以在造成火焰傷害後給予等量的燃燒點數，反射豁免，不可疊加。同時使目標受到該傷害一半的劇痛點數（向下取整，該傷害會獨立計算到下一輪），強韌豁免，不可疊加。</li>
<li>你的電力能導通電路，支付3點能量，讓你可以在造成電擊傷害後給予等量的麻痹點數，該點數需要正常解除和豁免。你也可以支付3點能量以一個整輪動作來提供相當於一枚標準能量電池的電力</li>
<li>你的寒冷能凍結液體，支付3點能量，讓你可以在造成寒冷傷害後給予等量的凍結點數，該點數需要正常解除和豁免。你也可以支付3點能量以一個移動動作啓動，啓動你移動過的地方會覆蓋冰面，這會讓你獲得水上行走的能力（請注意，本身炎熱的液體不會受到本能力影響，如岩漿），持續一個場景。</li>
<li>消耗2點額外能量，你可以強化D級能量放出中的三種模式：</li>
</ul>

**\*第一種**：武器傷害提升至8L

**\*第二種**：範圍傷害提升至8L

**\*第三種**：相關加值提升至3

**能量強化**：你的相關能量池大小+5點，你進行能量射擊時能附加的能量射擊技巧上限提升至2
