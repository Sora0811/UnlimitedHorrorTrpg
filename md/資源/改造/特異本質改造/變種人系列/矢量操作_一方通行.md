# 矢量操作

> 來源：`資源/改造/特異本質改造/變種人系列/矢量操作\_一方通行`

**本質**：特異本質

**前提**：智力6，科學5

**描述**

<ul>
<li>所謂的矢量操作，就是隻要經過皮膚碰觸，就可以自由操縱動能、熱能、電能等所有能量的方向。這種能力可以「反射」所有物理攻擊，只要一點點力量就能產生絕大的破壞力，將腳上的力量方向集中於一點就能暫時飛向天空。</li>
<li>特殊要求，全程科學：每一個等級都要求不同的物理學科專業作爲先決條件，假如不能滿足其先決條件則無法提升等級。</li>
</ul>

**特殊**：本資源下當你反射傷害時，你反射的傷害數爲你所能反射能力的傷害上限。並且你反射傷害之前，你如果通過某些能耗啓動了傷害減免等類似能力，則該能耗如常消耗。

##  級　LV1-低能力

**價格**：D+500

**前提**：在科學技能上擁有力學專業

**屬性**：智力+2 感知+2

**能量池**：無

**技能樹**：無

**特性**：反射（三特性），力能衝擊

**特殊**：由於沒有能量池和技能樹，額外增加2個特性。

**描述**：在這個級別裏，你獲得操作動能的能力。

**價格**：D+500

**其他標籤**

**反射**

<ul>
<li>從現在你可以消耗1點意志力和一個反射動作來發動一次“反射”。矢量操作可以計算出對你有害的動能，並且將這些動能完全反射。例如所有撞擊、擒抱、墜落，以及會對你造成任何的物理傷害，都可以進行動能反射。當你發動矢量操作時，投智力+科學，專業爲力學，和這一次有害動能進行對抗，如果你勝出，則有害動能被抵消，並且可以使用目標對你造成有害動能時的DP數給予有害動能的來源一次反擊，無視對方的防禦，但是對方的傷害減免，吸收，抵消，抗力等類似能力可以正常生效，並且繼承其攻擊類型（鈍擊，穿刺，揮砍）。如果你失敗，則反射效果完全無效，照常受到傷害或影響，如果雙方平手，則力量被抵消，但是並不會被反射。</li>
<li>通常來自敵人的攻擊的有害動能一般指的是目標的物理攻擊而造成的最終傷害值，如果承受的是範圍傷害，則使用動能操作的結果和範圍傷害值對抗。</li>
</ul>

**力能衝擊**：你可以主動發動動能操作的能力來攻擊敵人。花費1點意志力和一個標準動作，用你的天生武器對目標進行一次接觸攻擊判定，這次攻擊不會造成實際傷害，只需命中即可。命中之後，投智力+科學進行傷害判定，專業依然爲力學，成功數直接給予對手嚴重物理傷害，對手可以用耐力+生存的強韌判定來豁免這一傷害，每成功數使傷害減少1點。


##  級　LV2-異能力

**價格**：C+1000

**前提**：科學技能上擁有熱學專業

**屬性**：智力+3 感知+3

**技能樹**：無

**特性**：反射，能量集束（雙特性）

**特殊**：由於沒有技能樹，額外獲得1個特性。

**描述**：在這個級別裏，你獲得操作熱能和電能的能力。

**價格**：C+1000

**其他標籤**

**反射**：從現在起，“反射”的持續時間延長爲1輪，在這一輪中，所有有害動能，有害熱能都能反射。

**有害動能**：任何以你爲對象的物理傷害，以你爲對象的撞擊、擒抱、墜物、墜落傷害。

**有害熱能**：會你受到環境減值的高低溫氣候、會使你造成不良狀態點數或傷害的灼熱或凍寒能量。

**能量集束**：你可以主動發動矢量操作的能力來攻擊敵人。花費1點意志力和一個標準動作，收集身體周圍的熱量或靜電，對指定的目標以智力+科學（對應能量）+武器傷害的一次遠程能量攻擊，武器傷害爲（傳奇智力+科學技能帶來的附加成功數），射程爲（智力+矢量操作等級）\*10米。根據你選擇的專業不同，造成火焰嚴重傷害，寒冰嚴重傷害。此外你也可以選擇以力學作爲專業，壓縮身體周圍的空氣進行遠程物理傷害。能力達到B級時可以造成音波嚴重傷害和雷電嚴重傷害，專業爲聲學。能力達到A級時可以造成光能嚴重傷害，專業爲光學。使用本方式造成的傷害上限爲科學+武器傷害\*2.


##  級　LV3-強能力

**價格**：B+2000

**前提**：科學技能上擁有聲學、電磁學專業

**屬性**：智力+4 感知+4

**技能樹**：無

**特性**：反射，能量爆發（雙特性）

**特殊**：由於沒有技能樹，額外獲得1個特性。

**描述**：在這個級別裏，你獲得操作化學反應、聲音的能力。

**價格**：B+2000

**其他標籤**

**反射**：從現在起，“反射”的持續時間延長爲1輪/智力。啓動後，在持續時間內，所有遇到有害動能，有害熱能，有害聲波，有害電能都能反射。

**有害聲波**：會使你受到不良狀態點數或傷害的音波。

**有害電能**

<ul>
<li>會使你受到不良狀態點數或傷害的雷電能量。</li>
<li>反射音波傷害，雷電傷害和不良狀態點數時和熱能相似，和C級時一樣，你可以自由修改反射的項目，甚至可以隔絕一切聲音使自己進入安靜的無聲世界，如果在睡眠之中這麼作有可能會使矢量操作使用者失去對外界的反應。</li>
</ul>

**能量爆發**：從現在你的可以發動矢量操作的能力來進行範圍攻擊。花費1點意志力和一個標準動作，收集身體周圍的某種類型矢量（熱量、電力、空氣、聲波等等），最大範圍爲自身爲中心1米/智力值範圍內的所有目標進行一次範圍攻擊。你自身不會承受這次攻擊的傷害，此外你還可以額外花費1點意志，選擇範圍內最多智力和科學上附加成功數的目標不受這次範圍傷害影響。進行一次智力+科學的判定，每1點成功數造成1點範圍傷害，專業爲你所選擇的矢量的相關專業，傷害上限爲你的智力+科學，所有目標反射豁免。物理傷害專業爲力學、火焰或者寒冰傷害專業爲熱學、雷電傷害專業爲電學、聲波傷害專業爲聲學。能力達到A級時，可以使用光能傷害，專業爲光學。


##  級　LV4-大能力

**價格**：A+4000

**前提**：科學技能上擁有光學、重力學

**屬性**：智力+6 感知+6

**技能樹**：無

**特性**：反射，引力控制（雙特性）

**特殊**：由於沒有技能樹，額外獲得1個特性。

**描述**：在這個級別裏，你獲得操縱光、核聚變的能力。

**價格**：A+4000

**其他標籤**

**反射**：從現在起，“反射”的持續時間延長爲1分鐘/智力。啓動後，在持續時間內，所有遇到有害動能，有害熱能，有害電能，有害聲波，有害電能，友愛光能，有害力場都能反射。

**有害光能**：會使你受到環境減值或不良狀態點數的紫外線，會使你造成傷害的光能量。

**有害力場**：會使你受到環境減值或傷害的力場效果。

**引力控制**：你現在可以花費1點意志力和一個迅捷動作來調節自身的重力，加入你完全隔絕地球對你的引力，會被拋出大氣層。矢量操作可以讓你自身的重力向任何方向飛行，加速度最大爲重力加速度，速度上限爲音速，機動性良好。這一技能可以完全對引力波雷達隱形，視爲在無重力環境下運動。效果持續1小時/智力或消解，矢量操作達到S級時無時間限制，機動性提升爲完美。


## S 級　LV5-超能力

**價格**：S+8000

**前提**：科學技能上擁有量子力學、生物物理學專業

**屬性**：智力+6 感知+6 決心+6 敏捷+6

**技能樹**：無

**特性**：反射，內部精密操控（雙特性）

**特殊**：由於沒有技能樹，額外獲得1個特性

**描述**

<ul>
<li>“無用的長物。從這裏開始是一方通行，乖乖地夾着尾巴哭着回去吧…！”</li>
<li>學園都市僅有的七名超能力者（Level 5）排名第一位，性別未知，能力爲「矢量操作」，代號「一方通行」。</li>
<li>在這個級別裏，你獲得微觀粒子、生物電流、血液流動等能力。</li>
</ul>

**價格**：S+8000

**其他標籤**

**反射**

<ul>
<li>反射：從現在起，開啓和關閉“反射”是一個自由動作，而且無需消耗意志力，除非你主動選擇關閉，否則只要你的意志池不爲空，“反射”就會24小時處於開啓狀態。啓動後，在持續時間內，所有遇到有害動能，有害熱能，有害電能，有害聲波，有害電能，友愛光能，有害力場都能反射。</li>
<li>同時你的反射不再是比對雙方成功數，而是改爲你每有1點成功數，則可以抵消目標造成的一點傷害，若正好全部抵消，則不會反射。若抵消之後你的成功數還有剩餘，則如常反射。</li>
</ul>

**內部精密操控**

<ul>
<li>你可以用矢量操作生物物理學的能力來使敵人的血液或生物電流倒流而死。花費1點意志力和一個標準動作，用你的天生武器對目標進行一次接觸攻擊判定，這次攻擊不會造成實際傷害，只需命中即可。命中之後，投智力+科學進行一次傷害判定，專業爲生物物理學，成功數直接給予對手相當於成功數的惡性傷害，以及相當於成功值的噁心、耳鳴、劇痛、麻痹、目眩、疲乏六種不良狀態點數，這些不良狀態點數可以疊加，也可以造成嚴重甚至毀滅性後果，對手可以用耐力+生存的強韌判定來豁免這一傷害和這些不良狀態點數，每1成功數可以使傷害和每種不良狀態點數全都減少1點。這些不良狀態點數可以通過超自然能力恢復或者休息的方式自然恢復。</li>
<li>你也可以利用矢量操作生物物理學的能力來讀取生物電流以讀取他人的記憶。花費1點意志力和一個標準動作，用你的天生武器對目標進行一次頭部的接觸攻擊判定，這次攻擊也不會造成實際傷害，只需命中即可。你可以進行一次智力+科學的判定，專業爲生物物理學，對目標的記憶進行一次探索，目標可以用意志進行對抗，矢量操作勝出的話可以讀取其表層思維，勝出數超過3點的話可以讀取其深層思維。</li>
<li>除了傷害他人以外，生物物理學也擁有改變生物體內物理運行，完成救死扶傷的能力。花費1點意志力和一個標準動作，對自己或目標生物進行一個接觸判定。投智力+科學，專業爲生物物理學，每1成功數可以移除1點衝擊傷害，每2成功數可以移除1點嚴重傷害，每4成功數可以移除1點惡性傷害，每1成功數可以移除1點創傷、毒素、藥物、疾病類的輕度不良狀態點數，每2成功數可以移除1點創傷、毒素、藥物、疾病類的重度不良狀態點數。</li>
</ul>


**其他標籤**

**如**：你擁有重力牆，目標以200dp造成了50L傷害，力場牆吸收了40點 。最後需要對抗的是10L，當你勝出之後，你反彈200DP，但是這200DP只能造成10L傷害，並且力場牆如常扣除40點能量。
