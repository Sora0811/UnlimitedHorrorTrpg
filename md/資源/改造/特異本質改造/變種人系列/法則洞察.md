# 異能・法則洞察

> 來源：`資源/改造/特異本質改造/變種人系列/法則洞察`

**本質**：特異本質

**描述**

<ul>
<li>法則洞察是看破世間萬物運行規律的異能，即使不能理解事物運作原理，卻可以依所感受的到運作規律來將事物再現或將事物改變的能力。</li>
<li>覺醒異能改變了你的內在本質，本改造賦予的屬性視爲內在加值</li>
</ul>

##  級　LV1-低能力 D+500

**屬性**：感知+2 操控+2

**能量池**：無

**技能樹**：無

**特性**：物質解析（雙特性），生物解析（雙特性）

**特殊**：沒有能量池和技能樹，獲得2個額外特性

**其他標籤**

**物質解析**

<ul>
<li>你能洞悉自然本質和科技本質物品的運作原理，若你有一件實物，你可以使用感知判定來進行延長判定，週期爲一天，DC等同於將其視爲製造物品的圖紙解析，成功解析後，你如同已經解讀了該造物的圖紙，解讀時無需滿足智力和科學條件即可解讀，但是若要製作則必須滿足。</li>
<li>你完成對物品的解析後，你在使用該種物品時獲得1點加值（取決於物品本身的使用方式，例如載具則是駕駛判定，武器則是攻擊和格擋防禦，盔甲則是盔甲防禦，若物品提供對抗範圍攻擊的加值你也能獲得）</li>
</ul>

**生物解析**：你能觀察生物的運作機制，能從生物的行動中獲悉其生理屬性，並在其使用技能時獲悉其所用生理技能等級，你能以一個標準動作觀察目標生物，從其行動中尋找對策，你對該生物攻擊和防禦上獲得+1加值，受其能力影響進行的豁免和對抗中也獲得+1加值，持續一場恐怖片。


##  級　LV2-異能力 C+1000

**屬性**：感知+3 操控+3

**技能樹**：無

**特性**：提升-物質解析，提升-生物解析，能力解析

**特殊**：由於沒有技能樹，額外獲得1個特性。

**其他標籤**

**物質解析**：現在你可以解析魔法本質的物品，並可以製造他們，但必須爲該物品每支線等級支付8點XP（D1-S5，無支線0.5，雙支線+0.5，高低支線搭配的按雙支線計算）。

**生物解析**：現在你能從生物的行動中推斷其行爲模式，你獲悉其社交屬性和心智屬性，並在其使用技能時獲悉其所用心智技能等級和社交技能等級。

**能力解析**：你能從生物使用的能力中解析其原理，若生物使用一個能力且未高於你的改造等級，你自動了解這個能力的效果，學習這個能力的前提條件，若你滿足所有前提條件，你可以以自創技能的形式學習這個能力，通過這一效果，你能以自創技能的形式學習稱號的最低等級。


##  級　LV3-強能力 B+2000

**屬性**：感知+4 操控+4

**技能樹**：無

**特性**：提升-物質解析（雙特性），提升-生物解析

**特殊**：由於沒有技能樹，額外獲得1個特性。

**其他標籤**

**物質解析**：每當你成功解析一種物品，你獲得相當於其支線等級的XP。

**生物解析**：現在你能解析生物的弱點，瞭解其dr，能抗，傷害吸收，包括速度，防禦極其構成，以及生命值，並瞭解其具有的能量池以及相關等級。


##  級　LV4-大能力 A+4000

**屬性**：感知+6 操控+6

**技能樹**：無

**特性**：法則解析（三特性）

**特殊**：由於沒有技能樹，額外獲得1個特性。

**其他標籤**

**法則解析**

<ul>
<li>你已經完成了對規律的解析，有人嘗試修改時你會獲得感應，你免疫因果律，時間與空間的影響，這是一個A級免疫。除非你主動願意接受。</li>
<li>你的生物解析只要具有生物的殘骸你就能瞭解其所有能力和特性。</li>
</ul>
