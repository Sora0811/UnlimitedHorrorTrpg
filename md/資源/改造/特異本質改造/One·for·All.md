# One・for・All

> 來源：`資源/改造/特異本質改造/One·for·All`

**本質**：特異本質

**前提**：生理系屬性不低於6，擁有美德：正義，種族與血統皆爲人類

**價格**：CC+2000

**描述**

<ul>
<li>在中國的輕慶市，出現了“發光的嬰兒”出生的事件，人類自此開始了異變。之後，獲得超能力的人類在世界各地被發現。隨着時間的流逝―――。</li>
<li>世界上超過80%的人類擁有了名爲“個性”的力量。但隨之而來的是，因爲有了“個性”而在世間作惡的人極速增多，於是產生了打擊犯罪、解救他人的熱門新職業“英雄”。</li>
<li>一般在4歲之後仍然沒有覺醒任何“個性”的人，這輩子都不可能再覺醒“個性”，而One・for・All實際上是“能夠儲存力量”和“賦予他人”兩種個性的混合個性，可以造成巨大破壞的衝擊或肉眼難以捕捉的高速移動。</li>
</ul>

**特殊**

<ul>
<li>由本改造造成的肢體妨害點數只要超過你耐力值的兩倍，便同樣會使你該肢體陷入肢體殘障狀態。</li>
<li>此外，如無特殊說明，本改造造成的肢體妨害點數無法通過任何本改造以外的方式消除（即使復活，洗點，主神修復，斷肢再生也不行），因本能力而殘障的肢體/手指在通過再生能力恢復時，所需的時間增加10倍，並且無法透過再生以外的任何能力恢復因此殘障的肢體（即使復活，洗點，主神修復，斷肢再生也不行），該肢體妨害點數造成的影響（包括但不限於其帶來的減值和毀滅性後果）無法通過任何方式避免和免疫。</li>
<li>你每次因本改造下的能力（包括技能樹中的能力）而使一條肢體累積獲得超過你當前耐力值的肢體妨害點數或是陷入肢體殘障狀態，你這條肢體便會永久且不可避免地承受2點肢體妨害點數，除本改造下技能樹的效果外，無論如何（即使復活，洗點，主神修復，斷肢再生也不行）也無法消除該肢體妨害點數，該肢體妨害點數可疊加，可陷入毀滅性後果，其造成的影響無法通過任何方式避免和免疫。</li>
</ul>

**價格**：CC+2000

## C 級

**屬性**：無

**技能樹**：開啓One・for・All技能樹

**特性**：英雄意志，傳承的力量（八特性）

**特殊**：由於支線分數翻倍且沒有屬性，額外獲得5個特性；由於是一次性改造，額外獲得2個特性。

**描述**：剛獲得這一力量的你，還無法很好地適應這份代代傳承下來的龐大力量，目前的你只能調動其中一部分力量。

**其他標籤**

**英雄意志**：你不會因傷勢嚴重而昏迷。此外，你每次觸發美德：正義後，你在所有檢定上獲得1個附加成功，持續一個場景。

**傳承的力量**

<ul>
<li>你在進行通過你的肢體作出的行動時，若該需要進行關鍵屬性包含生理系屬性的檢定決定結果，你可以預先聲明你該次行動使用哪些肢體（左手/左腳/右手/右腿）併爲該次檢定設定一個“出力數值”（這無需動作），該數值每有1點，你便可以在該次檢定中獲得1個附加成功並在該次檢定結束後受到1點不可避免的衝擊傷害。若該數值高於你的傳奇耐力，你還會在該次檢定結束後再立刻不可避免地受到等同於該次出力數值兩倍的惡性傷害，你該次行動所使用的肢體也會不可避免地受到等同於該次出力數值兩倍的肢體妨害點數，該肢體妨害點數可疊加，可進入毀滅性後果，你因本能力所受的惡性傷害每恢復1點，該肢體妨害點數便會自動消除1點。</li>
<li>此外，你每次進行移動時，若你該次移動方式爲陸行/游泳/攀爬，則你也可以爲該次移動設置一個“出力數值”（這無需動作），該出力數值每有2點便可使你該次移動中陸行/游泳/攀爬速度提升1倍，“出力數值”帶來的影響與上述影響相同。</li>
</ul>

### One・for・All全覆蓋

**價格**：33XP

**動作**：整輪動作

**能耗**：無

**射程**：無

**目標**：自身

**範圍**：無

**持續**：見下

**描述**：你學會將One・for・All佈滿全身之後，可以在不受傷的情況之下爆發One・for・All的力量，隨着你對本技巧的不斷錘鍊，你對One・for・All的掌控會越來越純熟。

**效果**

<ul>
<li>每場景傳奇沉着\*1次，你可以花費一個整輪動作開啓本狀態，之後你每輪需要花費一個迅捷動作維持，這需要你專注維持，否則本狀態會立刻結束。本狀態持續期間，你在生理系屬性上獲得1點能量加值，並且四肢的天生武器傷害提升2L。</li>
<li>你每次開啓本能力並將其維持至少10輪後，你便會獲得1點“錘鍊”點數，但如果你在連續兩個場景中沒有獲得過“錘鍊”點數，則你當前所有“錘鍊”點數會立刻清空。</li>
<li>你可以爲自己訂製一個特效，例如渾身上下纏繞着綠色的電弧，身體像氣球一樣膨脹一圈變成肌肉壯漢等，該特效會在你處於本狀態下時顯示出來，一旦確定特效後不可更改，這是一個純畫面效果。特殊的，若你生命槽中超過一半的生命值被不可治癒的傷害所佔據，則你平時看起來會像一個乾癟的人幹一樣，只有處於本狀態下才能夠恢復原本的模樣。</li>
</ul>

**價格**：33 XP

</ul>


### Smash-Finger

**價格**：48XP

**動作**：整輪動作

**能耗**：無

**射程**：見下

**目標**：多個目標

**範圍**：見下

**持續**：見下

**描述**：將One・for・All的力量集中在手指，一瞬間爆發出強大風壓與力量，但之後回將整個手指廢掉，最大輸出是9發。

**效果**

<ul>
<li>在施展本能力時，你必須先聲明你其中一根手指並設置一個“局部出力數值”，“局部出力數值”最大爲你的傳奇力量+傳奇耐力，之後你以該手指作爲天生武器進行一次近戰肉搏攻擊，該次攻擊本身不會造成任何效果，而是改爲會對你正前方寬、高、長皆爲你力量值\*10米的區域內所有單位造成等同於你天生武器傷害+“局部出力數值”/點力場嚴重傷害，反射豁免，但受影響單位在該次反射檢定上承受等同於你該次檢定成功數的無名減值，此外影響範圍內的風力會提升2級，持續1輪。</li>
<li>之後你所聲明的手指會立刻進入肢體殘障狀態，你每有1根手指進入肢體殘障狀態，你便會在使用包含該手指的手所進行的任何行動上（包括但不限於計算拿東西的負重，武器力量需求，攻擊等）視作你的力量比當前力量值低2點，並在相關檢定上失去4個成功數。同時，你會立刻受到等同於該次“局部出力數值”\*2點惡性傷害，該惡性傷害在你這隻手指的肢體殘障狀態消除後會自動恢復，除此之外無法透過任何方式恢復（即使復活，洗點，主神修復，斷肢再生也不行）。</li>
<li>僅僅是手指殘障並不會視作你這隻手陷入肢體殘障，只有在你這隻手上的所有手指皆陷入肢體殘障狀態後，你這隻手纔會視作陷入肢體殘障狀態。</li>
</ul>

**價格**：48 XP
