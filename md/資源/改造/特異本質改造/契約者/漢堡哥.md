# 漢堡哥能力組

> 來源：`資源/改造/特異本質改造/契約者/漢堡哥`

**價格**：C +1 0 00

**屬性**：力量+3 敏捷+3 耐力+2

**特性**：超急速閃避（四特性）

**技能樹**：無

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得2點屬性</li>
<li>一次性改造，獲得2個特性</li>
</ul>

**價格**：C+1

**其他標籤**

**代價**：喫一個漢堡包，最小也要兒童型

**超急速閃避**

<ul>
<li>你的基礎移動速度增加10米。漢堡哥的能力是超高速移動。你可以以反射動作選擇向一個方向移動1D10米，同時下一輪的基礎速度增加20米。</li>
<li>每日可使用你敏捷/次，之後每次使用需消耗1點意志力。</li>
</ul>
