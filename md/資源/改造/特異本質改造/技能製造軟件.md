# Angel Player技能製造軟件

> 來源：`資源/改造/特異本質改造/技能製造軟件`

**本質**：特異本質

**前提**

<ul>
<li>電腦3級</li>
<li>Angel Palyer，簡稱AP，死後世界裏立華奏使用過的程序，通過該程序使用者可以在死後世界裏製造物品和調整人物屬性，甚至能改造周圍的環境。這個程序提供的只是一個類似的開發平臺,能開發到什麼程度就看使用者本人。原本該程序的能力只能在死後世界這種電腦世界中運用，但是主神通過後未來的量子力學科技，使其在任何一個世界都能發揮作用，而它的本質也就原本的科技本質轉換爲了特異本質。</li>
</ul>

**特殊**：此級改造一旦購買，則無法使用洗點系統，除非強化本改造，否則無法以任何方式獲得或模擬本改造的特性和技能。

##  級　初心者

**價格**：D+1000

**屬性**：智力+2 感知+2

**能量池**：無

**技能樹**：開啓D級技能樹

**特性**：加值轉換，不死之身，掃描系統（三特性），施法漏洞（負特性）

**特殊**：由於沒有能量池和分數翻倍，額外獲得2個特性。

**描述**：你從主神處購買了AP改造，你獲得了一臺搭載了AP程序的虛擬機，AP程序運載後會開始掃描周圍的環境，你的身體結構優先被掃描，掃描完成後你的身體結構會在三維建模重組後呈現在AP程序的內置界面上，你的生理參數詳情也會在分析完成後呈現出來，之後你便可以通過AP程序在你身體的某個部位生成你通過AP程序製造的武器，例如Handsonic；亦或是直接對你自身的生理參數進行調整，例如Overdrive。

**加值轉換**：本級改造提供的屬性加值爲增強加值。

**價格**：D+1000

**其他標籤**

**不死之身**：在無數次體驗過死亡的痛楚後，你對疼痛的忍耐力遠超常人。你不會因爲傷勢失去意識。

**掃描系統**

<ul>
<li>你獲得一臺無形的虛擬計算機用以運載AP，可投射出全息界面進行操作而不用再攜帶常規計算機。此虛擬機實際上就是你的大腦，因此硬件能力取決於你的大腦開發程序。此虛擬機時刻與主神保持無線網絡連接，並可通過特異本質的電磁波與其他科技裝置進行有線或無線連接（可能需要投射出接口界面）。雖然它投射出的窗口及虛擬鍵盤等是無形的，但卻匪夷所思的可被所有者觸碰、點擊或拖動。虛擬機默認只接受你一人的操作。虛擬機內的AP的專業型電腦輔助系統會對你身邊的環境進行掃描，然後迅速在程序內置界面上將掃描到的物體進行三維建模重組，讓你在黑暗中也能清楚地掌握周圍的情況。</li>
<li>你獲得等同於敏感範圍的黑暗視覺和D級特異本質的特異本質偵測能力。</li>
<li>若你通過其他能力獲得了一臺虛擬機（如觀察者，信息員，超鏈等），掃描系統帶來的好處改爲：在5米\*感知的範圍內，你可以進行感知＋電腦判定以掃描周圍的物體，以此來代替偵查檢定。你獲得等同於掃描範圍的黑暗視覺和D級特異本質的特異本質偵測能力。</li>
</ul>

**施法漏洞**：進行AP改造後的人體在施法體系上產生了漏洞，AP使用者的施法者等級皆不可超過改造等級，同時在所有施法檢定上都須承受等同於改造等級\*3DP內在減值。
