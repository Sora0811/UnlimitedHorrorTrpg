# 流魂街居民血統（來源：BLEACH）

> 來源：`資源/血統/非人類/魔幻本質/其他生物/流魂街居民血統`

**本質**：魔幻本質

**作者**

<ul>
<li>赤鳴</li>
<li>當人類死去，而內心存續着強烈的怨念亦或是不甘、亦或是眷戀，便會化爲魂靈，繼續徘徊於世，這是死者的靈魂，以其生前的樣貌再度現身於世間。這種無法順利往生的人，往往會成爲可怖的怨靈，但是在屍魂界的死神的引導下，它們大多轉生至流魂街以全新的生命再度降生。塵世間的死者，在多年以來的積累下，便形成了一個獨特而龐大的族羣。</li>
</ul>

**特殊**：強化本血統後，你不兼容虛化以外的任何改造，這會爲你D級別的血統額外提供一個特性。

**特性**：亡者身軀（三特性），靈力技能，改造封鎖（負特性）

**特殊**：由於沒有技能樹，額外獲得一個特性

**價格**：D+600

**其他標籤**

**靈力技能**：你現在可以使用和學習相當於血統等級的靈力通用技能。

**其他標籤**

**魂魄身軀**

<ul>

<li>同時，雖然你失去了基因鎖，但是這不影響你進行開鎖檢定，同時也不影響你的基因鎖開鎖超凡表現。</li>
</ul>

**再燃的心火**

<ul>

</ul>

**描述**

<ul>
<li>在現世死去的人類靈魂，離開現世後、透過死神魂葬後，會來到屍魂界的流魂街，被派發“整理券”，依照死亡先後、順序分配至東南西北的八十個地區。第一區治安、居住環境均理想，食物豐足，第八十區則寸草不生，饑荒遍野，各人的魂魄互相殺戮來決定何人取得生存的權利。如此類推，隨區號數字增加，各區治安情況及居住條件會下降，愈趨惡劣。在死神的魂葬下獲得新生的你便是來自第八十區的一名新生的魂魄，在如此惡劣艱難的環境下你也頑強的生存了下來。</li>
<li>四大貴族是屍魂界四個最古老的家族，與王族血統相近，本身互相亦爲親戚，代代皆出具有不凡靈力、或能力出衆的人，接受英才教育，於護廷十三番隊及其他組織擔任要職，捍衛王室，身懷爲屍魂界大衆立下榜樣的義務，惟近代成員不是被屍魂界流放就是無子嗣。儘管你原本只是低下的平民，卻也在一步步的階梯之下，成爲了屍魂界新的顯貴。</li>
</ul>

**價格**：A+7200

**其他標籤**

**苦難的層積**：出生無盡，含融空有，那便是你的原本，你的心包容太虛、量周沙界。你從此獲得自身傳奇決心/點全傷害忽略。

**聞見的止符**：新生的經歷給了你面對未來的勇氣，執着於過去並無意義，執着是個妄想，不是萬物的真實。你從此免疫A級以下的負面心靈影響效果；對於你不免疫的負面心靈影響效果，你在對抗時額外獲得自身傳奇沉着/點附加成功。

**崧生嶽降**：傲慢與無禮並不能彰顯高貴，與之相反，真正的高貴，是那願意俯下身子卻依舊無法被人靠近。真正的品節，不因隻輪不返而傾頹，也不因強大而屈委。你的意志值增加自身沉着值+決心值/2點。

**怨靈附身**

<ul>
<li>死後的魂魄，也能再度驅使人身的行動。以一個整輪動作並消耗3點意志力，你可以附身進入自身觸及範圍內一個自願或者處於無助狀態的目標身體內。處於無助狀態的目標無法拒絕你的附身動作，但是其依舊可以拒絕你的控制，若其不願接納你的附身控制，你進行一次意志檢定，目標進行意志豁免，若你成功，則你成功控制目標的身軀，目標的靈魂暫時被你壓制，你可以控制目標的身軀，在控制身軀期間，你使用目標的生理屬性並獲得基於血統或者改造的特性，除此之外你不會獲得其他能力；心智和互動系屬性使用你自己的屬性，並且技能和技藝也使用你自己的（包括生理系技能在內），並且目標的對抗每有1點成功數，則你接下來的所有檢定承受等額的無名減值。</li>
<li>若你對抗失敗，則你佔據失敗並且受到差值/點不可避免的嚴重傷害。</li>
<li>你可以驅使該軀體的持續時間爲你成功數/分鐘，本血統提升至A級時變爲你成功數/小時。若是自願目標則可以持續到直至返回主神空間或者你自行解消效果爲止，解消效果無需任何動作，你無法將劇情世界裏獲得的身體帶回主神空間。</li>
<li>在佔據期間，你的靈魂被肉體所保護，具備【幽冥】或者【神兵】特性的物品和攻擊會在對你肉體造成傷害的同時對你本身造成肉身所受傷害的等額傷害，除此之外，你免疫除力場傷害，精神傷害之外的一切傷害，但是目標的身軀會如常受到傷害，若肉身死亡，則你立即脫離目標的身軀並且無法再度使用該身軀。</li>
<li>特殊地，你無法操控本狀態下的目標進行自殘或者類似行爲（除非目標是自願的），若你要如此做，則目標會立即進行一次意志豁免檢定，每有1點成功數，則可以減少你對應單位的持續時間，若持續時間降低爲0，則你立即被強制送出。並且，若你通過本能力將目標的肉體自殺成功，目標不判定爲你所殺。</li>
<li>（自殘類包括站着不動放棄所有防禦捱揍，跳樓，自溺，上吊，主動將自己放置在真空環境等一系列主觀對自己造成傷害和不良影響的行爲）</li>
<li>特殊地，若你佔據的是自己造人的身軀，你可以永久獲取該肉體，並如同強化自身一般繼續對其肉身進行強化血統、改造和瞳術，你無法通過該肉身獲得和使用基因鎖，但是肉身受到傷害同你本身受到傷害一般可以進行開鎖檢定，並且正常獲得超凡表現（更換肉身並不會使你獲得更多的超凡表現次數），強化該肉身所消耗的支線和分數使用你自己的。</li>
<li>特殊的，這是一個S級影響心靈的能力。</li>
</ul>

**都頭異姓**：屍魂界的貴族也是所有死神的典範，以維護與執行屍魂界的定則爲職責。當你現身時，與你處於同一場景下所有能感知到你的非友方目標承受你決心值/點不可避免的精神束縛點數，持續至無法感知到你爲止。

**不貲之軀**：屍魂界的貴族的強大並不僅僅在於身份，更在於那份與生俱來的強大。你的對抗性檢定獲得自身決心屬性/點DP內在加值。
