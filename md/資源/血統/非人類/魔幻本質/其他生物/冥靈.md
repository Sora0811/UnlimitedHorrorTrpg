# 冥靈血統

> 來源：`資源/血統/非人類/魔幻本質/其他生物/冥靈`

**本質**

<ul>
<li>魔幻本質</li>
<li>你看到一個絕色的身影，它有着一種超凡的美感。只是伴隨着你的注視，你覺得它的身影模糊不清，宛如一個蒼白的影子。</li>
<li>存在於世界接縫當中，有一種名爲“冥靈”的生靈。組成它們物質和靈魂的“頻率”，遠遠低於主物質位面。這使得它們位於一種令人難以想象的特殊狀態，也就是“虛”。它們接近於位面本源中陰性的部分，熵力、虛無以及死亡。</li>
<li>一個冥靈通常是不穩定的。它們依靠汲取心靈當中的精神力量凝聚自己的形體。</li>
</ul>

## D 級　魂之序幕

**屬性**：感知 +1 決心 +1 風度 +2

**能量池**：熵池

**技能樹**：開啓 D 級存在法

**特性**：靈言（雙特性），初級熵力守護，畏懼光能（負特性）

**特殊**：無

**其他標籤**

**靈言**：你現在可以自由地看到靈體並與靈體溝通，你獲得靈感視覺。你可以如常影響靈體，並且你的語言，動作，會自動轉化爲目標靈體可以理解的方式。

**初級熵力守護**：靈魂遁入熵之源的結果是，虛無的存在在冥冥中保護着冥靈。熵力守衛護盾的數值相當於你的傳奇風度與傳奇決心之和，在計算護盾作用效果時，其相當於你的臨時生命。但是若你受到傷害，你必須通過一個反射動作，纔可以使其生效。你可以花費一分鐘的冥思，以溝通熵之源，恢復你所有的守衛力量。

**畏懼光能**：當你受到的光能傷害時，該傷害提升一級。


## C 級　血之交鳴

**屬性**：感知 +1 決心 +2 風度 +3

**技能樹**：開啓 C 級存在法

**特性**：中級熵力守護（雙特性）

**特殊**：無

**其他標籤**

**中級熵力守護**：熵力守衛護盾現在變爲你風度值與決心值取高，並且你現在不再需要反射動作即可使用。


## B 級　體之輪奏

**屬性**：感知 +2 決心 +2 風度 +4

**技能樹**：開啓 B 級存在法

**特性**：虛體，高級熵力守護（雙特性）， 魂熵共生（正負特性）

**特殊**：無

**其他標籤**

**虛體**：你獲得虛體生物特性。

**高級熵力守護**：熵力守衛護盾現在變成你風度值與決心值之和。同時，你可以消耗一個整輪動作，花費體內的全部熵，回覆消耗數 X3 的護盾。（不可超過上限）

**魂熵共生**

<ul>
<li>你的生命幾乎被熵力替代。你的生命值不再使用耐力與體積來計算，改爲風度 + 決心，你失去傳奇耐力提供的生命值，但是你的傳奇風度和傳奇決心如同傳奇耐力一般爲你提供額外的生命值。</li>
<li>同時，你無法使用普通休息來回復生命值，藥水，快速醫療，再生，回覆生命值的能力都無法生效，只能通過連續八個小時的冥思後，你將會立刻恢復全部生命值。</li>
<li>你無法獲得任何增加生命值上限的強化，如死硬，生命值強化等方法也無法強化你的生命池（但是其其他部分如常生效）。</li>
</ul>


**正文**

熵難以自然恢復。只有在你敏感範圍內的生物使用意志力，觸發惡德，觸發美德時，你恢復一點熵。

你還可以使用自由動作，耗費自己不超過自己傳奇風度 / 點意志力來回復等額的熵，這種方法恢復的熵每天不可超過你的風度值。

D 級存在法：

### 熵池

**其他標籤**

**熵池的基礎用法**：以一個自由動作，消耗 1 點熵，你回覆 1 點熵力守衛護盾，最大不可超過你的熵力守衛護盾上限。


**正文**

熵池是一個西方通用能量池。

毀滅之力，虛無之力。

熵池的上限等於你的風度 + 感知。
