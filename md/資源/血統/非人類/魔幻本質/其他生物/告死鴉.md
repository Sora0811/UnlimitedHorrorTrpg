**總描述**

<ul>
<li>“凶兆之鳥，爾等需以水銀爲血，荊棘爲冠――”</li>
<li>死亡不是藝術，不是恩賜，不是禮讚，不是惡作劇....它不是任何美好的東西.</li>
<li>死亡就是死亡，裏面只有痛苦和無盡的寒冷.一種...向內收縮的無力感，一種存在的理由被否定，人生的創造性和高度從中截斷的無力感.</li>

## D 級　祈禱者

**屬性**：感知+2，沉着+2

**能量池**：負能量池

**技能樹**：開啓D級告死鴉技能樹

**特性**：祈禱者（三正特性一負特性）

**特殊**：無

**描述**

<ul>
<li>你是聖者長眠導師奈若拉的信徒，你從此失去靈魂上的不死性，任何使你靈魂上獲得不死性的效果都對你無效。</li>
<li>長眠導師的形象爲身着黑袍的少女，過長的劉海遮住了半邊臉頰，黑髮直垂到地上.其坐在一幅兩米多高的黑曜石棺木上，雙腿優雅的交疊，右腿在下而左腿在上.</li>
</ul>

**其他標籤**

**祈禱者**

<ul>
<li>無論如何，你的壽命都無法通過任何方式延長，並且死亡後不可被任何方式復活（特殊的，若PC位於本血統對應的影片中，則可被長眠導師所復活），但你免疫等同於本血統等級的即死效果。</li>
<li>此外，你每次進入影片時，若該影片世界擁有宗教勢力存在，你可以選擇其中一個宗教勢力併成爲該宗教最低級的傳教者，你的名字會以合理的方式出現在對應宗教勢力的成員名單中，同時獲得一份能夠證明你是該宗教傳教者的合法身份證明文件，但這不會使你獲得任何額外的記憶或人際關係。</li>
</ul>

## B 級　告死鴉

**屬性**：感知+4，耐力+4

**技能樹**：開啓B級告死鴉技能樹

**特性**：水銀之血（五特性），寒冷易傷（負特性），金屬過敏（負特性）

**特殊**：無

**描述**

<ul>
<li>你被舉行了注銀儀式，在水銀所制的荊棘纏繞的華貴座椅上，加熱的水銀荊棘纏繞，沿着皮膚被劃破的裂口收緊入體內，血液沿着中空的柔軟荊棘流入座椅後方，水銀蒸汽溫和的注入了你的血管，代替了血液的空缺.略微的高溫將藤蔓軟化，座椅向後躺平，這時，你大約已經死了.</li>
<li>一個巨大的，刻滿防腐符文的水晶罩子將你扣住，填滿水銀，封口，放入棺材.</li>
<li>你的靈魂變得沉重，而無法升入天堂.</li>
<li>然後，長眠導師復活了你―――</li>
<li>歡迎，新的告死鴉.</li>
</ul>

### 水銀在更高的層面上代表着意志.

**其他標籤**

**水銀之血**

<ul>
<li>現在你可以不喫不喝不睡不呼吸，並且不會因傷勢嚴重而昏迷。你免疫等同於本血統等級的毒素與疾病效果。</li>
<li>此外，你開啓一個名爲水銀槽的刻度，水銀槽上限等同於你的感知+耐力值。在非戰鬥場景中，你每輪行動開始時水銀槽都會自動增加不超過你的傳奇耐力\*1點；在戰鬥場景中，每輪一次，你可以花費自由動作對自己造成不超過你傳奇耐力\*1點不可避免的嚴重傷害並獲得等額的水銀槽刻度。</li>
<li>只要水銀槽不爲空，你便會獲得3DR/鈍擊與2點再生，該再生能力可以以1/4的速度來恢復惡性傷害（即每兩輪便可以通過本再生恢復1點惡性傷害），你每以該再生恢復自身1點嚴重傷害便會消耗1點水銀值，每以該再生恢復自身1點惡性傷害會消耗2點水銀值，你可以花費自由動作開啓或關閉本再生能力。</li>
<li>你無法進行任何基於肉體的改造和強化，若你在此之前已經擁有對應的改造或兌換，則其立刻失去所有效果，但仍會佔據你對應的模版位置。</li>
<li>不過，你獲得了名爲“聖銀武裝”的能力：你可以花費一個移動動作獲得一把基礎近戰冷兵器列表中的武器，你可以在不使用任何肢體持握該武器的情況下仍如同你正持握該武器一般使用它，該武器免疫擊落武器與擊破武器，武器傷害提升本血統等級\*2L並獲得【魔法】【神聖】【幽冥】特性，該武器的持續時間爲永久，消解該武器是一個移動動作，你同一時間能夠以此法獲得多把基礎近戰冷兵器列表中的武器，但每把武器持續期間都會佔用你等同於該武器體積\*5點水銀槽上限。</li>
<li>這在畫面效果上表現爲你可以將身體任意一部分化作流着銀灰色光芒的武器。</li>
</ul>

**寒冷易傷**

<ul>
<li>你受到的寒冰傷害會提升1級（衝擊――嚴重――惡性）。當你一次性承受超過你當前生命值上限二分之一的寒冰傷害或陷入凍結狀態，則你還會同時陷入晶化狀態，並且失去本血統提供的快速醫療、再生與DR能力，以及“祈禱者”特性帶來的免疫即死效果。</li>
<li>另外，在你承受由寒冷環境帶來的減值、傷害與凍結點數時，其會在計算你的傷害降低能力與對應的豁免能力前翻倍計算。</li>
<li>最後，當你在晶化狀態下受到物理傷害或火焰傷害時，該傷害在計算你的傷害降低能力後翻倍計算。</li>
</ul>

**金屬過敏**：當你接觸除水銀外的金屬物體時（包括但不限於隔着衣物和手套主動觸摸金屬物品，穿着鞋子走在金屬地面上，被敵人使用鐵鏈捆綁等，具體可由ST裁定），你在所有檢定上承受12DP無名減值，並且在每輪行動開始時受到5點不可避免且無法疊加的精神束縛點數，持續至你不再與該金屬物體有接觸爲止。


**正文**

你獲得一副半亡靈的軀體，但這裏的亡靈指的並非是那些骯髒的低等野獸，而是繼承了蒼銀榮光的守護者，在戰場上提着頭怒吼着衝鋒的不滅戰魂.你的身軀一部分可以完全化爲祝福聖銀，任意部分都可以變形，甚至在體外構成簡單的形狀，但變形而成的那部分外表總是流動的銀灰色。

然而，現在的你甚至比一個火元素更畏懼寒冷，並對金屬嚴重過敏――也許你該考慮一下僞鐵武器？

**屬性**：感知+6

**技能樹**：開啓A級告死鴉技能樹

**特性**：基石要素（四特性）

**特殊**：無

**描述**

<ul>
<li>靈魂本應進入輪迴.</li>
<li>軀殼下沉，靈魂上升.在日常的鍛鍊中飽含秩序力量的屍體不會浪費，被人體過濾一遍的秩序力量會沉入大地，一直滲透到最底層的蓋亞之牆上，用以修補漏洞.</li>
<li>而靈魂會上升，一直到奧姆之牆上被粘住，然後隨着法則的流動在七日內到最北方的極地，而後送入地獄.隨後，靈魂將被洗去記憶，但保留部分天賦，重新輪迴.</li>
<li>如此循環.</li>
<li>而如果後人的靈魂足夠堅韌，它們若追溯到最開始的那一代，理清其中的記憶和思念――那麼將得到所有遺留下來的力量中最精華的那一部分.</li>
</ul>

**選開**：你必須在兌換“起源：流動”或“起源：穩定”中的一項後纔可兌換本血統的S級。

</ul>

</ul>

</ul>

### 這個儀式被稱爲覺醒之路.

**其他標籤**

**來自作者的話**：我個人能力有限，歡迎有能力者撰寫新的基石要素/起源。

**基石要素**

<ul>
<li>在下列“基石要素”選定1個並獲得對應的好處（但不會獲得“基石化”後帶來的好處），一旦選定不可更改，你最多隻能擁有5個“基石要素”。</li>
<li>在選定之後，你可以隨時以A+4000或108XP一個的價格購買其他“基石要素”，或者支付54XP來將你已擁有的一個“基石要素”“基石化”並獲得對應的好處，同一種“基石要素”只能擁有一個，但“基石要素”提供的屬性無法與其他“基石要素”疊加。</li>
</ul>


**正文**

基石化，每一個基石要素都是對自身起源其中一個方向的描述.基石化的越早，就意味着力量在靈魂內更加深入.

起源覺醒者並不知道自己的起源是什麼，並且若是意志不夠還會有異化的風險，不過好心的主神抹去了風險和不穩定性，爲此歡呼吧.
