# 聖寶石體質

> 來源：`資源/血統/非人類/魔幻本質/其他生物/聖寶石體質`

**本質**：魔幻本質

**描述**：艾斯柯尼加聖寶石是魔力之源，具有強大而神祕的力量。通過逐步將身體與這種變化莫測的礦質融合，人類變得更加高貴而睿智。

## D 級　聖寶石接觸

**屬性**：智力 +2 ，感知 +1 ，風度 +1

**能量池**：魔力

**特性**：聖寶石光輝，魔力提升（雙特性）

**技能樹**：無

**描述**：少量聖寶石晶粒化入你的身體，與你的身體融合，使你的身體機能更加安定，精神更加完備。聖寶石的內在之光與你的靈魂同在，若你願意，你可以使聖寶石晶質在你的體表呈現出來，你的皮膚出現細碎的晶瑩反光，如同特殊的化妝品一樣。

**特殊**：由於沒有技能樹，額外獲得 1 個特性。

**其他標籤**

**聖寶石光輝**：你在意志檢定上獲得 3DP 內在加值。

**魔力提升**：你獲得等同於血統等級的施法者等級，以及學習和購買通用法術的能力。你的魔力池上限增加5點。


## C 級　聖寶石移植

**屬性**：智力 +3 ，風度 +2 ，感知 +1

**特性**：聖寶石顯現，聖寶石護身，音波敏感（正負特性），提升 - 魔力提升

**技能樹**：無

**描述**：聖寶石的細碎晶體植入你的體內，取代了你的少量血肉。這進一步強化了你的變化。你可以用晶化的部位攻擊敵人，也可以將傷口處的血肉寶石化，從而使從傷口進入體內的異物質被凝固在寶石中。你可以選擇讓這些寶石化作折射七彩光芒的煙塵而崩碎，令毒質無法浸染你的身體。

**特殊**：由於沒有技能樹，額外獲得 1 個特性。

**其他標籤**

**聖寶石顯現**：你能夠發射聖寶石光線，花費一個標準動作，使用智力 + 神祕學（塑能）進行一次遠程攻擊檢定，這次攻擊射程等同於你的風度值 \*1 米，擁有【能量武器】特性，造成光能嚴重傷害，傷害上限爲你的智力 + 神祕學技能。

**聖寶石護身**：你免疫 C 級以下的疾病與毒素效果。

**音波敏感**

<ul>
<li>你在調查（聆聽）相關檢定中獲得 6DP 內在加值，你爲對你造成耳鳴點數或耳聾效果的能力而進行對抗時失去等同於血統等級 \*2 個成功數。</li>
<li>提升 - 魔力提升：你的魔力池上限再增加1 0 點。</li>
</ul>


## B 級　聖寶石融合

**屬性**：智力 +4 ，風度 +3 ，感知 +1

**特性**：提升 - 聖寶石光輝，提升 - 聖寶石護身，提升 - 聖寶石顯現，提升 - 魔力提升

**技能樹**：無

**描述**：聖寶石的晶體與你的身體融合，你的血細胞中布細碎的晶核，這進一步強化了你的變化。

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得 1 個特性。</li>
<li>提升 - 聖寶石光輝：你在意志檢定上再獲得 12DP 內在加值。</li>
<li>提升 - 聖寶石護身：當你受到任何毒素與疾病效果或是試圖侵入你體內的寄生體（如異形幼崽等，具體可由 ST 裁定）影響時，你可以對自己造成等同於該效果的支線等級之和（ D1C3B5A7S9 ） \*2 點惡性傷害，之後免受該效果影響，這無需動作。這在視覺效果上表現爲你以將細胞晶化並崩碎的方式來祛除侵入你體內的病毒與寄生物。</li>
<li>提升 - 聖寶石顯現：你能夠發射聖寶石光線，花費一個標準動作，使用智力 + 神祕學 + 武器傷害進行一次遠程攻擊檢定，武器傷害等同於本血統等級 \*2L ，這次攻擊射程等同於你的風度值 \*10 米，擁有【能量武器】特性，造成光能嚴重傷害，傷害上限爲你的智力 + 神祕學 + 武器傷害。你可以額外支付魔力值強化這次攻擊，每額外支付 1 點魔力值，便可以使該次攻擊的武器傷害提升 1 點，你爲此支付的魔力值上限等同於你的血統等級。本特性代替 C 級同名特性。</li>
<li>提升 - 魔力提升：你的魔力池上限再增加2 0 點。</li>
</ul>

## A 級　聖寶石身軀

**屬性**：智力 +6 ，風度 +4 ，感知 +2

**特性**：提升 - 聖寶石護身，提升 - 聖寶石顯現，提升 - 魔力提升，片刻預知

**技能樹**：無

**描述**：聖寶石晶體與你的身體合一，你的身體成爲聖寶石質的存在。若你願意，你可以將你的部分或全部外表還原爲聖寶石的本來形態，成爲精美的寶石雕像。

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得 1 個特性。</li>
<li>提升 - 聖寶石護身：你獲得 8 點硬度。</li>
<li>提升 - 聖寶石顯現：你可以以一個自由動作將你的外形變成精美的寶石雕像，這是單純的視覺效果變化，不會帶來任何實際效果。每輪一次，你可以花費一個自由動作支付任意點魔力來回復生命值，每支付 1 點魔力便可以獲得 1 點“修補”點數， 1 點“修補”點數可以恢復 1 點衝擊傷害， 3 點“修補”點數可以恢復 1 點嚴重傷害， 5 點“修補”點數可以恢復 1 點惡性傷害，你可以任意分配“修補”點數，每輪可透過此法恢復的衝擊傷害與嚴重傷害沒有上限，但每輪透過此法恢復的惡性傷害上限爲你的決心值。</li>
</ul>

**其他標籤**

**片刻預知**：你免疫多次攻擊減值，同時獲得 B 級免疫措手不及的能力。


## S 級　聖寶石精華身軀

**屬性**：智力 +8 ，風度 +8 ，感知 +4 ，耐力 +2 ，沉着 +2

**特性**：提升 - 聖寶石光輝，提升 - 聖寶石顯現，提升 - 聖寶石護身，提升 - 片刻預知

**技能樹**：無

**描述**：聖寶石晶體變得更爲精純，你的所有細胞都由細微的晶核構成，你的身體與精神更加完美。若你願意，你可以將你的部分或全部外表還原爲聖寶石精化的形態，成爲精美華貴無可匹敵的寶石雕像。這是一個自由動作。

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得 1 個特性。</li>
<li>提升 - 聖寶石光輝：你在意志檢定上再獲得 48 點內在加值。</li>
<li>提升 - 聖寶石顯現：你的聖寶石光束現在改爲造成光能惡性傷害。你受到的所有能量傷害下降一級。</li>
<li>提升 - 聖寶石護身：你獲得 16 點全傷害吸收。</li>
<li>提升 - 片刻預知：你在防禦上增加等同於你感知值的洞察加值。</li>
</ul>
