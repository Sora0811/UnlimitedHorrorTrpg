# 毒茸之侵略者

> 來源：`資源/血統/非人類/魔幻本質/其他生物/毒茸之侵略者`

**本質**：魔幻本質

**描述**

<ul>
<li>在陽光無法照耀到的角落，陰暗潮溼的陰影中，誰也沒有注意到的時候，菌類悄無聲息的生長着。</li>
<li>攜帶着信息素的粉塵在空中飛舞，隱藏在黑暗的牀底王國的菌類們悄悄地密謀着……</li>
<li>是在交換着致命的毒素嗎？</li>
<li>是在謀劃着侵略人類的計劃嗎？</li>
<li>噓，這是蘑菇們的祕密……</li>
<li>此刻，真菌的支配者、地底王國的王者，悄然甦醒……</li>
<li>D 級： Wake Up ！</li>
<li>在淤泥中生長的王者不相信夢想、否定夢想、拒絕夢想，生於陰暗角落的菌類討厭陽光，一旦接受了這個血統，人類的身份將會消失，取而代之的是有着人類外形的菌類，你的髮色與瞳色會變爲灰色，髮型會變爲及腰的長髮。</li>
<li>作爲毒素之主的身體也染上劇烈的毒素。</li>
<li>真菌之主獲得了召喚孢子的能力，此外你可以將自身化爲劇毒的標槍，對膽敢站在你對面的敵人施以處罰。</li>
<li>只能生存在黑暗角落的菌類，在朝日初生之時便會燃燒爲灰燼，但是永遠不會熄滅的，是少女的夢想……</li>
<li>你即是毒素本身，劇毒的君主，灰色的長髮上會出現七縷如同挑染一樣的不同的髮色，對應你掌握的七種毒素。</li>
</ul>

**特殊**

<ul>

<li>由於沒有技能樹，額外獲得 2 點屬性。</li>
<li>由於沒有技能樹，額外獲得 3 點屬性。</li>

<li>由於沒有技能樹，額外獲得 5 點屬性。</li>
</ul>

**其他標籤**

**拒絕夢想的地下民**：你無法學習基於靈力、魔力、念力池的能力，當受到自身以及菌類生物以外以心智屬性爲基礎或者影響心智的能力時（包括但不限於以其作爲能耗，以其作爲學習前提的能力等），無論其對自身是否有利，你都必須立刻進行一次決心檢定，之後使該能力的檢定失去等同於你決心檢定成功數的成功數，並且本次檢定無法使用留手。

**蠢蠢欲動的黑暗之聲**

<ul>
<li>當你位於昏暗或黑暗環境下時，只要你不主動做出交互類行爲或是攻擊和敵對行爲（包括但不限於交涉，威嚇，說服，給隊友上 BUFF ，給目標上 DEBUFF ），敵人就會下意識地忽視你的存在（但你仍可能被範圍攻擊誤傷），這是一個 D 級影響心靈的效果。</li>
<li>當你被陽光直射或處於等同於陽光亮度的光源照射下時（具體可由 ST 裁定），你的全檢定上承受 1DP 內在減值。</li>
<li>流離零落的碎屑拼湊成的毒之王：你的種族不再是人類，而是變爲植物，但目前仍不會使你獲得任何植物生物的特性，你的食物將從凡俗人類的食物轉變爲腐爛的木料等菌類喜歡的食物，喫下人類的食物並不能給你提供營養以及無法滿足你的飲食需求。你免疫 D 級以下的疾病與毒素效果。</li>
<li>你能夠花費 1 個移動動作並支付 1 點意志力，給你的天生武器或正在持用的體積不超過你自身體積 -2 點的，能夠造成揮砍或穿刺傷害的白刃武器附加以下兩種毒素中的一種：</li>
<li>\1. 麻痹毒素：附加的武器造成傷害後你可以立刻對目標發起一次耐力對抗，若你勝出，則對目標造成等同你勝出數的麻痹點數，不可疊加。</li>
<li>\2. 狂躁毒素：附加的武器造成傷害後你可以立刻對目標發起一次耐力對抗，若你勝出，則對目標造成等同你勝出數的亢奮點數，該亢奮點數不可豁免，不可疊加。</li>
<li>若無特殊說明，同一樣武器最多維持一種毒素，你可以給不同部位的天生武器或不同的白刃武器分別附加不同的毒素，每次附加新毒素會覆蓋之前的毒素，附加毒素的持續時間爲你的耐力值 \*1 分鐘，本血統提供的毒素是一個等同於你血統等級 -1 級的超自然毒素效果。</li>
<li>C 級： Cut Up ！</li>
</ul>

**延頸企踵的螺紋**

<ul>
<li>你可以如同給你的武器附加毒素一般給自己的身體附加、更換或消解已獲得的一種毒素（只能選擇本血統給予你的毒素），每當你被任何單位的近戰攻擊命中時（包括衝撞、擒抱等），你可以如同你對目標造成傷害一樣發動你在身體上所附加毒素的效果。</li>
<li>在黑暗淤塞陰涼之處悄悄孕育的猛毒：你掌握的毒素增加以下三種：</li>
</ul>

**衰弱毒素**

<ul>
<li>附加的武器造成傷害後可以立刻對目標發起一次耐力對抗，若你勝出，使該單位基於生理屬性的檢定以及基礎防禦和先攻、基礎移動速度受到等同你勝出數的無名減值，該無名減值不可與其他無名減值疊加（包括本血統其他毒素帶來的無名減值），持續一個場景。</li>
<li>\2. 蝕心毒素：附加的武器造成傷害後可以立刻對目標發起一次耐力對抗，若你勝出，使該單位基於心智與互動屬性的檢定以及先攻受到等同你勝出數的無名減值，該無名減值不可與其他無名減值疊加（包括本血統其他毒素帶來的無名減值），持續一個場景。</li>
<li>\3. 腐蝕毒素：附加的武器造成傷害後可以立刻對目標發起一次耐力對抗，若你勝出，使該單位的盔甲防禦、天生防禦與盾牌防禦總共下降等同你勝出數 \*1 點，可疊加，持續一個場景。但這不會使目標的防具失去效果與特性。</li>
<li>B 級： Slash Down ！</li>
</ul>

**植物**：你的生物類型變爲植物，並獲得植物生物的所有特性，但是你可以如常使用人造武器。

**上升的不快指數**

<ul>
<li>你一次可在自身以及武器上同時附加的毒素提升至兩種，同時你獲得兩種新的毒素：</li>
<li>\1. 殘血毒素：附加的武器造成傷害後可以立刻對目標發起一次耐力對抗，若你勝出，使該單位受到等同你勝出數的“殘血”點數，目標每輪行動開始時會受到等同於“殘血”點數的毒素嚴重傷害，“殘血”點數在目標每輪行動結束後下降 1 點，取高計算，不可疊加。</li>
<li>\2. 熄滅毒素：附加的武器造成傷害後可以立刻對目標發起一次耐力對抗，若你勝出，使該單位每輪受到等同你勝出數的“熄滅”點數，目標每輪行動開始時其當前擁有的能量最高的能量池會失去等同於“熄滅”點數的能量，“熄滅”點數在目標每輪行動結束後自動下降 1 點，取高計算，不可疊加。</li>
<li>A 級： Mash Up ！</li>
</ul>

**七度復活的劇毒之槍**

<ul>
<li>你可以花費 7 點意志和一個整輪動作，對自身決心值 \*10 米範圍內的一個單位進行一次攻擊，武器傷害等同你的耐力，具有等同你傳奇耐力 \*3 的破甲，等同你傳奇決心 \*3 的破魔，等同你傳奇決心與傳奇耐力之和的高速，使用決心 + 運動（重武器投擲） + 武器傷害進行攻擊檢定，傷害上限爲你的運動等級 + 武器傷害，這次攻擊會同時觸發你已掌握的 7 種毒素的效果，並且 7 種毒素效果的等級皆視作 A 級。本能力一個場景中只能使用一次，一個星期至多使用 7 次。</li>
<li>S 級： Invade ！</li>
</ul>

**於七彩中怒放的毒之花**：你一次可在自身以及武器上同時附加的毒素提升至五種，你身上永遠附加着你已掌握的七種毒素。

**於晨露中燃燒的夢之花**

<ul>
<li>在你死亡後，你會立刻吸收以你爲中心半徑等同於你決心值 \*100 米球型範圍內所有單位身上的毒素效果（包括但不限於會造成毒素傷害的 DEBUFF ，屬於超自然毒素或自然毒素效果的狀態等，具體可由 ST 裁定），在你的身體原本所在的位置附近會出現一朵七彩的小蘑菇，蘑菇獲得等於你生前生命值的裝甲和結構值，在防禦上獲得等同於你意志值的力場加值以及等同於你生理系屬性的所有傳奇屬性之和的硬度。</li>
<li>這朵蘑菇攜帶了第 8 種毒素――夢之毒，以蘑菇爲中心半徑等同於你決心值 \*10 米球型範圍內的的所有非植物生物的單位每輪都會如同被你攻擊並造成傷害後一般受到你的七種毒素影響（注意，不包括夢之毒），他們必須分別進行一次耐力檢定， DC 爲你死亡時的耐力值，若檢定未通過則會根據對應的毒素承受對應的效果。與此同時，位於該範圍內的所有單位每輪都會失去 7 點意志池上限，而你會獲得等同等額的夢之毒素，當你收集的夢之毒素達到你死亡時的意志值 + 耐力值的五倍時，你會立刻從蘑菇的位置復活，“夢之毒”也會隨之消散，但若在這之前蘑菇被摧毀，則你徹底死亡。特殊的，蘑菇免疫毒素傷害，而且蘑菇每受到 3 點傷害，便會給你提供 1 點夢之毒素。</li>
<li>若你在處於蘑菇狀態時迴歸主神空間，你只需支付修復惡性傷害與肢體的分數便可復活。</li>
<li>特殊的，因爲這個特性而降低的上限視爲一個 S 級詛咒效果，並且因此意志池上限歸零的單位或者生命被惡性填滿的單位會化爲一朵蘑菇，蘑菇的顏色爲其生前的髮色。目標會保留一切意識、屬性和能力，但是無法行動也無法發聲，這視爲一個 S 級詛咒效果。</li>
</ul>
