# 律者血統

> 來源：`資源/血統/非人類/魔幻本質/其他生物/律者血統/總綱`

**作者**：QB

**本質**：魔幻本質

**描述**

<ul>
<li>在這個星球上崩壞伴隨着文明而生，人類的文明越是發展崩壞的抑制也越是強大。每次崩壞必然伴隨着大量生物的滅亡，且每次的大型崩壞都會伴隨着一名律者的產生，每個律者的能力也不同。</li>
<li>崩壞，相當於這個世界的神，律者，類似於神的使者。自身擁有強大的崩壞能，造成的破壞力極爲可怕。每擊敗一位律者，人類都要付出慘重的代價。</li>
<li>上個文明的律者一共有十四位，而第十四位律者的力量遠超其他律者。</li>
<li>在『最後的律者』面前，人類的結局只有滅亡……</li>
<li>並非所有生命體都能成爲律者，沒有資質的人類只會在崩壞中變爲死士，沒有資質的動物則會成爲崩壞獸，只有天生對崩壞具有抗性（親和力）的生命才能在崩壞中覺醒律者的力量。當然，如果是從上個世代而來的“前律者”，再次取回自己的力量也不會有什麼困難吧……</li>
<li>爲了能覺醒律者的力量，本血統會先行提升肉體對崩壞的抗性，隨後在一場主神控制下僅爲你自身範圍的崩壞中，自行覺醒爲律者。</li>
<li>每一位律者都是獨一無二的，每個律者在主神空間中只有一個。</li>
<li>在覺醒成爲律者之時，本血統並不會改變你原有的生物分類。但是當你覺醒爲律者形態後，你在計算時，變爲非人類。律者在覺醒後會形成獨特的瞳型（瓦爾特、芽衣的豎瞳，西琳的X型瞳），因此本血統無法兌換瞳術，其他方法獲得的瞳術也會在覺醒後失去。</li>
</ul>

## D 級　律者候選

**屬性**：共4點屬性，自由分配，最高不超過2

**能量池**：崩壞能

**特性**：自由屬性分配，崩壞親和（四特性），失去基因鎖（負特性），失去瞳術（負特性）

**技能**：無

**特殊**：由於沒有技能樹，額外獲得1個特性。

**其他標籤**

**崩壞親和**：你獲得死硬1級，2級，3級。並且你的傷勢、意志力的自然恢復速度提升一倍。


## C 級　初次覺醒

**屬性**：共6點屬性，自由分配，最高不超過3

**特性**：自由屬性分配，律者形態（四特性），失去基因鎖（負特性），失去瞳術（負特性）

**技能**：無

**特殊**

<ul>
<li>因爲沒有技能樹，額外獲得一個特性</li>
<li>若你選擇了“擬似第四律者，毒之律者”，則你無法強化本血統至A級，最大到B級。</li>
</ul>

**其他標籤**

**律者形態**

<ul>
<li>如同一階基因鎖解鎖條件，投擲一個機運骰，結果爲10或以上時，你將進入律者形態。選擇B級的律者形態之一，你獲得之，一旦選擇不可更改。</li>
<li>然後你立即獲得該形態的能量池以及特性。</li>
<li>第一次進入律者形態將獲得一個超常表現（同基因鎖規則），律者形態持續時間爲你的耐力和風度取低\*1輪，你可以以自由動作解除律者形態，結束時你將不可避免的陷入昏迷，昏迷時間爲開啓時間/分鐘。</li>
</ul>


## B 級　律者

**屬性**：特殊

**技能樹**：特殊

**特性**：律者（六特性），人類之敵（負特性），天道適應（正負特性），失去基因鎖（負特性），失去瞳術（負特性）

**特殊**：無

**其他標籤**

**人類之敵**：你在面對人類中的救世主（ST判定，大部分災難影片中都很好辨認，但有些影片沒有救世主）時，全檢定以及防禦承受相當於其風度值的表現減值。

**天道適應**

<ul>
<li>你在完全不存在人類（或者不存在世界意識的世界比如主神空間或半位面、虛擬世界等）或者人類與世界和諧相處的世界（或者人類在爲了世界而與異世界敵人作戰的世界）中全檢定獲得12DP內在減值。</li>
<li>你在任何具有人類的世界（需有世界意識，大部分地球場景都視爲具有世界意識，某些小場景影片也視爲具有世界意識，例如僅有一個森林但是森林裏的怪物在攻擊人類之類的影片也視爲這片森林就是世界意識）或者世界正在執行消滅人類的世界（《飛躍巔峯》，鋼之大地之類的世界），你獲得1點再生。</li>
</ul>

**律者**

<ul>
<li>你覺醒成爲了這個世代的一位律者，好好感受下這份力量吧。</li>
<li>此時你可以以一個移動動作消耗1點意志力主動進入C級選擇的律者形態。你可以以自由動作解除律者形態，此時結束後你不會昏迷，而是改爲獲得相當於風度值的疲乏點數，耐力豁免，可疊加。</li>
<li>你獲得對應律者帶來的屬性，技能樹以及特性。</li>
<li>（對應律者帶來的屬性將如同正常的血統一般加上角色的屬性上）</li>
<li>（角色在非對應律者形態下，無法使用對應律者的技能樹以及特性）</li>
</ul>


## A 級　最後的律者

**屬性**：特殊

**技能樹**：特殊

**特性**：律者（三特性），律者人格（負特性），提升――天道適應（正負特性），失去基因鎖（負特性），失去瞳術（負特性），反救世主（三特性）

**特殊**：無

**其他標籤**

**律者**

<ul>
<li>你可以以一個迅捷動作消耗1點意志力主動嘗試進入C級選擇的律者形態。律者形態持續時間爲你的耐力和風度取高\*1輪，你可以以自由動作解除律者形態，持續時間結束時你將獲得相當於風度值的疲乏點數，強韌豁免，可疊加。</li>
<li>你獲得對應律者帶來的屬性，技能樹以及特性。</li>
<li>（對應律者帶來的屬性將如同正常的血統一般加上角色的屬性上）</li>
<li>（角色在非對應律者形態下，無法使用對應律者的技能樹以及特性）</li>
</ul>

**天道適應**

<ul>
<li>你在完全不存在人類（或者不存在世界意識的世界比如主神空間或半位面、虛擬世界等）或者人類與世界和諧相處的世界（或者人類在爲了世界而與異世界敵人作戰的世界）中全檢定獲得24DP內在減值。</li>
<li>你在任何具有人類的世界（需有世界意識，大部分地球場景都視爲具有世界意識，某些小場景影片也視爲具有世界意識，例如僅有一個森林但是森林裏的怪物在攻擊人類之類的影片也視爲這片森林就是世界意識）或者世界正在執行消滅人類的世界（《飛躍巔峯》，鋼之大地之類的世界），你獲得1點再生，並且你在死亡時不會死亡，而是將崩壞能池作爲第二條生命槽，這條生命槽只有嚴重傷勢，你每受到1點傷害就會減少3點崩壞能，當崩壞能歸0時，你將死亡。</li>
</ul>

**律者人格**

<ul>
<li>只有撕裂人類的心，才能成爲真正的律者。作爲崩壞意志的使徒，律者的心靈中會誕生出一個憎恨人類、渴望毀滅人類的人格，在現在的階段，這個人格開始奪取你的意志了。每當你進入律者形態時，投擲一個1D10（這不是一次檢定），若結果小於10則無事發生，但下一次的骰數+1，累計疊加該加值。</li>
<li>若結果爲10或以上，則你的意識立即被律者人格所取代，你失去角色控制權，由ST代爲控制該角色。</li>
<li>此時你需要度過心魔（詳情看4階基因鎖），若你度過心魔失敗，則你永久失去本角色。若你度過心魔成功，則你永久失去本特性。</li>
</ul>

**反救世主**：你不再是被人類打倒的存在，你是……毀滅人類的最後的律者啊！所有人類敵人在針對你的攻擊、防禦、對抗性檢定上受到相當於你風度值的表現減值。這包括會影響到你的範圍攻擊檢定，如打你腳下的地面等。


**正文**

當你進行攻擊時，你可以無需動作，消耗1點崩壞能，使該次檢定獲得2DP能量加值。

當你受到攻擊時，你可以無需動作，消耗1點崩壞能，使防禦獲得2DP能量加值。

崩壞能會在使用時侵蝕宿主，如果你使用崩壞能時處於非律者形態，則此時你每使用或消耗1點崩壞能就會受到不可避免的1點嚴重傷害。

如果說人類是病毒，那崩壞能就是世界的免疫因子，它們對人類有着深深地惡意，因此該能量池的恢復和當前世界與人類之間的仇視程度有關。

\1. 在完全不存在人類（或者不存在世界意識的世界比如主神空間或半位面）或者人類與世界和諧相處的世界（或者人類在爲了世界而與異世界敵人作戰的世界）內，人物每天需要進行一個風度+沉着檢定，能且僅能恢復等同於檢定成功數的崩壞能。

\2. 在世界正在執行消滅人類的世界（《飛躍巔峯》，鋼之大地之類的世界），人物每小時都可以進行一個風度+沉着檢定，立即恢復等同於檢定成功數的崩壞能。

崩壞能不會受到任何能量回復加快的效果影響。

### 崩壞能

**描述**

<ul>
<li>崩壞能是一種迷之能量，已知具有一定智能並且不符合已知物理定律，是崩壞發生的元兇，高級形態就是所謂的崩壞意志。</li>
<li>崩壞能作爲崩壞爆發時散佈在崩壞區域的特殊能量，一般以擁有律者核心的律者爲中心，作爲聽命於律者意志的武器而存在。非律者或者不具有崩壞抗性的生物接觸到崩壞能就會被其侵蝕、變異，人類被侵蝕後會成爲喪屍一般的死士，動物被崩壞能侵蝕後一般會變成樓房高的崩壞獸……被侵蝕的個體往往會服從崩壞意志，開始消滅人類。只有特殊的方法才能使用崩壞能而不被侵蝕，像琪亞娜有很高的崩壞能抗性，而常人接觸這種能量易被侵蝕成爲被崩壞控制的存在（身上有傷口則更甚）。崩壞粒子與崩壞鏈是高濃度的崩壞能穩定存在形式，通過生產和利用這種形式的崩壞能能夠生產出與崩壞抗衡的武器。</li>
<li>經過天命和逆熵組織長期的研究和律者展現的一些能力來看，崩壞能可以轉換成物質（崩壞獸憑空增加的質量，西琳構造裝甲）構成力場（芽衣的翅膀、瓦爾特的黑洞）轉換形態（電流、火焰）使用權能（電磁操控，重力操控，死亡操控），簡直是堪比神力的萬能性，或者說這本就是世界爲了消滅人類而彰顯出的諸相。</li>
<li>一般情況下，具有崩壞能池的生物將被“世界的意識”（蓋亞等）視作友善，這對相關的生物也有效（比如《飛躍巔峯》中的宇宙怪獸眼中你屬於同類而非人類）；對於“人類的意識”（阿賴耶等）而言，你將被視爲邪惡，在某些同人類意識鏈接緊密的人（帶領人類族羣抵禦外敵的主角等）的眼中，你的形象可能會污濁、怪異或不可名狀化。值得注意的是，這些效果都是在極爲宏觀的層面上生效的，在大部分時候都不會引發有益或有害的影響，也不會影響主神發佈的任務（即你對阿賴耶來說是-50聲望，但對於大部分人類來說也不過就是-0.5的聲望，他們感受不到那份敵意）。</li>
<li>崩壞能的大小爲風度+沉着。</li>
<li>這是一個特殊能量池。</li>
</ul>
