# 第二律者，空之律者

> 來源：`資源/血統/非人類/魔幻本質/其他生物/律者血統/第二律者，空之律者`

## B 級

**屬性**：決心+4 風度+4

**技能樹**：開啓空之律者技能樹

**特性**：於苦痛的淤泥中誕生、在刺骨的地獄裏綻放、因復仇而熾烈的心中，唯有那恨意紮根而下、虛數空間

**描述**：操控虛數內能，轉化虛數空間。

**其他標籤**

**於苦痛的淤泥中誕生**：你免疫劇痛點數。

**在刺骨的地獄裏綻放**

<ul>
<li>選擇本律者後，此時你在非律者狀態下使用崩壞能也不會再受到崩壞能帶來的傷害。並且你在覺醒成爲第二律者的時刻額外獲得兩個超常表現，你需要在此次覺醒的律者形態持續時間內自由使用掉這些超常表現，覺醒結束後失去本特性。</li>
<li>因復仇而熾烈的心中，唯有那恨意紮根而下：面對人類敵人時，你獲得相當於風度值的防禦和攻擊上的褻瀆加值，上限爲你的感受技能等級，你的感受技能上每有一個附加成功上限就再增加1點。</li>
</ul>

**虛數空間**：你在進入律者形態時，可以消耗5點崩壞能進入虛數空間。之後，在本次律者形態的持續時間內，你獲得真空生存力，無視水壓對你的影響，無視困難地形。你獲得相當於你敏感範圍的盲感。你免疫墜落傷害，並且可以站立在任何表面。你可以非直線路徑衝鋒。


### 虛數彎曲

**前提**：虛數空間

**價格**：B+2000

**動作**：被動動作

**描述**：虛數空間是另一個空間，沒有人可以看得到另一個空間中的你。

**效果**

<ul>
<li>你在進入虛數空間時，可以再消耗5點崩壞能進入虛數彎曲。</li>
<li>你可以在虛數空間中啓動虛數彎曲，從而改變虛數空間和現實空間之間的空間曲率，這會使你進入隱形狀態，這是一個A級的特異本質反偵測能力。</li>
<li>這種能力除了原本識破的方法外，若目標具備免疫A級以上空間效果的能力也會看破此效果。</li>
<li>並且你“因復仇而熾烈的心中，唯有那恨意紮根而下”的特性中的上限取消。</li>
</ul>

**價格**：B+2000

**前提**：虛數空間

**價格**：B+2000

**動作**：被動動作

**描述**：虛數空間是另一個空間，沒有人可以碰到另一個空間中的你。

**效果**

<ul>
<li>你在進入虛數空間時，可以再消耗5點崩壞能進入虛數扭曲。</li>
<li>你可以在虛數空間中啓動虛數扭曲，從而改變虛數空間和現實空間之間的空間曲率，這會使你增加相當於你風度值的力場防禦，這可以與其他力場防禦疊加。</li>
</ul>

**價格**：B+2000

## A 級

**屬性**：決心+6風度+6

**技能樹**：開啓空之律者技能樹

**特性**：虛數內能（雙特性），虛數移動

**其他標籤**

**虛數內能**：你可以使你造成的近戰物理傷害變爲力場傷害，並且你的近戰物理攻擊變爲A級接觸攻擊。

**虛數移動**：你的移動方式變爲傳送。


### 虛數能量

**動作**：包含在一次攻擊動作中

**能耗**：7點崩壞能

**射程**：見下

**目標**：見下

**範圍**：見下

**持續**：立即

**效果**

<ul>
<li>當你進行攻擊時，你可以啓動本能力，使用本能力後，你的本次攻擊檢定必定命中。這視爲在你進行攻擊時，無論你攻擊DP和目標的防禦爲多少，你直接視爲命中，這視爲你在計算目標的防禦附加成功後，還剩餘1點成功數。</li>

### 虛數

**動作**：反射動作

**能耗**：7點崩壞能

**射程**：無

**目標**：自身

**範圍**：無

**持續**：見下

**描述**：虛數乃是不存在之數，虛數空間乃是不存在之空間。

**效果**

<ul>
<li>當你受到攻擊時，你可以啓動本能力。此時你退出本空間，若本次攻擊沒有空間效果，則免疫本次攻擊。</li>
<li>本能力有兩種結束時間，你在施展時選擇：</li>
<li>\1. 當前輪行動結束後。</li>
<li>\2. 在你輪結束後結束後。</li>
<li>若你選擇2，則到你的輪時，你可以如常進行行動，但是你無法以任何形式影響其他目標，直接本效果結束。</li>
</ul>
