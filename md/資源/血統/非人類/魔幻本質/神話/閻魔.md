# 閻魔

> 來源：`資源/血統/非人類/魔幻本質/神話/閻魔`

**本質**：魔幻本質

**描述**

<ul>
<li>又名夜摩天，是天龍八部中的天部的神。此處結合了各地的地藏特色設定而成的。</li>
<li>這是因爲閻魔王與地藏菩薩被糅合到一起，看做是同一種存在了。</li>
<li>本職是裁決死者的靈魂，以及到人間去說教，警告人們積累善行，以免被判下地獄。</li>
</ul>

**特殊**：本血統帶來的神器無法損毀，只能由血統保持者使用，血統保持者可以隨時以一個自由動作將神器召喚至身邊。

## D 級

**屬性**：風度 +2 ，決心 +1 ，感知 +1

**能量池**：無

**特性**：淨琉璃之鏡（雙特性），悔悟之棒（雙特性）

**技能樹**：無

**特殊**：由於沒有能量池和技能樹，額外獲得 2 個特性。

**描述**：閻摩的身軀並非是血肉之軀，而是冥府能量的聚合體。

**其他標籤**

**悔悟之棒**：獲得閻摩的特殊神器“悔悟之棒”，具體屬性見下。

**淨琉璃之鏡**：獲得閻摩的特殊神器“淨琉璃之鏡”，具體屬性見下。


# 淨琉璃之鏡

**本質**：魔幻本質

**分類**：小盾

**前提**：擁有閻魔血統。

**體積**：1

**描述**

<ul>
<li>閻魔大人所持有的寶鏡。用這面鏡子映照受審者，受審者過去的一切言行都將在鏡中得到再現。託這面寶鏡的福，審判得以獲得公正的裁決，不過這同時也是讓閻魔大人厭倦繁瑣枯燥的審判的罪魁禍首。</li>
<li>在在這面寶鏡面前，死者沒有隱私可言，任何蹩腳的掩飾皆徒勞無功，是一件毫無保留地榨乾個人信息的恐怖到地獄的道具。</li>
</ul>

**其他標籤**

**盾牌基本屬性**：0B

**盾牌特殊屬性**：【認主】，失去【格擋】特性。

**罪行知查**：使用移動動作，進行一次感知 + 調查檢定，與自身敏感範圍內一個目標的操控 + 掩飾進行對抗，若你勝出，則目標獲得差額的“罪行”點數（由這寶鏡帶來的罪行點數取高不疊加），並映照出來（該寶鏡最多隻能維持一名目標的全部罪行，當你使用寶鏡映照另一單位的罪行時，上一個單位身上的“罪行”點數會自動清空），該效果每場恐怖片只能對每一個目標使用一次。

**罪行之果**

<ul>
<li>當目標擁有“罪行”點數時，這個目標對寶鏡的持有者進行攻擊，施法檢定時都需要承受等同於“罪行”點數的表現減值。</li>
<li>持有者可以使用自由動作開啓或者關閉“罪行之果”的效果。無論開啓與否，這不會消除該目標身上的“罪行”點數。</li>
</ul>

**罪行懺悔**：身上具有“罪行”點數的單位可以通過每日一次虔誠的懺悔自身的罪行來減少 1D3 點身上的“罪行”點數。


# 悔悟之棒

**本質**：魔幻本質

**分類**：戰錘

**體積**：3

**描述**

<ul>
<li>閻魔大人時刻持於手中的棒。是用來書寫受審者的罪孽，並用其擊打受審者的道具。</li>
<li>生前犯下罪孽的人類，被敲打的次數與犯下罪過的次數成正比，會一直敲打至此人懺悔自己生前的罪過爲止。</li>
<li>棒的重量，與此人生前犯下罪孽的深重程度相等。</li>
<li>還有就是，罪行不是現世的罪，和法律無關。罪行完全由閻魔所決定。</li>
<li>值得一提的是，罪孽和現實中的犯罪有別，與是否受到法律懲處制裁無關。閻魔大人能以自己的一己之見裁定受審者的罪孽。</li>
</ul>

**武器基本屬性**：武器傷害 0B

**武器特殊屬性**：【認主】

## C 級

**屬性**：風度 +3 ，感知 +2 ，決心 +1

**特性**：提升 - 淨琉璃之鏡，提升 - 悔悟之棒，閻羅之軀

**技能樹**：無

**特殊**：由於沒有技能樹，額外獲得 1 個特性。

**描述**：淨琉璃之鏡可以在閻摩身邊環繞，主動抵擋一些攻擊，悔悟之棒開始對身上揹負罪行的角色產生物理上無法解析的重壓。

**其他標籤**

**閻羅之軀**

<ul>
<li>你無須飲食和呼吸，同時免疫無支線毒素與疾病效果。</li>
<li>提升 - 淨琉璃之鏡：淨琉璃之鏡的體積提升至 4 點，並獲得【格擋】特性，當使用淨琉璃之鏡進行格擋時，可以以調查技能代替白刃技能。同時，當你使用這面盾牌進行格擋時，你無法進行全力防禦。</li>
<li>提升 - 悔悟之棒：使用悔悟之棒在攻擊有“罪行”點數的目標時，目標每有 1 點“罪行”便選擇提升 1 點武器的破魔或者破甲，且悔悟之棒造成的傷害變爲嚴重傷害。</li>
</ul>

**特性**：提升 - 悔悟之棒，閻王的舞空，是非曲直的裁斷

<li>所有的存在對於閻摩來說都無法說謊。</li>

</ul>

**其他標籤**

**是非曲直的裁斷**：你獲得黑與白之瞳 D-C 級的全部效果，若你已有瞳術，則無法獲得本能力。此外，你可以隨時知道與你處於同一位面內身上擁有“罪行”點數的目標的具體位置並精確定位，這是一個 B 級魔幻本質偵測能力。

# 天雷

**本質**：魔幻本質

**分類**：長矛

**體積**：6

**描述**：天龍八部衆之中，夜摩天用來審判衆生的神雷。

**武器基本屬性**：武器傷害等同自身的傳奇風度，破甲 10

**武器特殊屬性**：【認主】【神兵】【光明】

**其他標籤**

**審判衆生**：天雷可以同時對觸及範圍內至多 7 名單位進行攻擊。

**判罪**：若被天雷攻擊的目標身上有“罪行”點數，其每次因天雷的攻擊而受到傷害時需要進行一次耐力檢定， DC 爲自身的“罪行”點數，若檢定未通過，則分別承受差額的麻痹點數與精神束縛點數，點數取高計算，不疊加。

**招雷**：使用本武器進行近戰白刃攻擊時可以用風度代替力量，任意表達技能子項代替白刃技能進行檢定，使用本武器進行攻擊檢定時爲 A 級接觸攻擊，並且無視目標防禦上的偏斜加值，武器觸及範圍等同於自身感知值，造成電擊嚴重傷害或精神嚴重傷害（由攻擊者在攻擊前選擇）。
