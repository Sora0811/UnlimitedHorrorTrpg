# 血統

> 來源：`資源/血統/非人類/魔幻本質/類人生物/魔女`

**本質**

<ul>
<li>魔幻本質</li>
<li>魔女（ witch ）即女巫。在拉丁文中代表“智慧”，因此她們擁有的所謂的魔法其實就是指利用超自然力量探究知識與智慧。</li>
<li>一般來說，魔女有使用白魔法的善良魔女和使用黑魔法的邪惡魔女兩種。</li>
<li>善良的魔女會給人類帶來福音，從聖者和信徒虔誠的靈魂得到魔力；</li>
<li>而邪惡的魔女與死神撒旦訂契約，然後藉着惡魔或是惡靈的力量得到魔力。</li>
<li>爲了探尋世間的真理，她們捨棄良多。</li>
<li>但是呀，愚昧的人們如何分辨善良和邪惡？</li>
<li>魔女的力量是如此強大、神祕和充滿智慧，大人物們卻又如此惜命，人們對未知的恐懼讓魔女們遭受毀滅性的排斥――</li>
<li>嗜血亂倫食人的謠言（對普通人）</li>
<li>食魔女肉能增長修爲的誘惑（對妖魔）</li>
<li>聖光之敵（對宗教）</li>
<li>神鬼莫測的毀滅與死亡（對高位者）</li>
<li>……</li>
<li>於是乎，無論是其親人、朋友，甚至只是名邂逅的路人，善良的、邪惡的……至今的空氣中依然迴響着他們靈魂的哀鳴。</li>
<li>閉目聆聽魔女低吟，抬腳踏入修羅之道。</li>
<li>沒人再向我訴說真理，沒人再給我留條活路。</li>
<li>我知道的，永遠是存在的，</li>
<li>世界是充滿着幸福的。</li>
<li>爲了實現不滅的美麗和不滅的世界，</li>
<li>硃紅的月亮，它劃破了滿溢着災禍的靜寂的時刻。</li>
<li>從迷霧深處的森林裏出現的妖異的玻璃之城，</li>
<li>乘着夜風飄散開來的聲音，是嘆息嗎？還是悔恨？</li>
<li>浸滿血液的旋律……那是烙印着死亡印記的詩歌。</li>
</ul>

## D 級

**屬性**：智力 +2 ，感知 +2

**能量池**：魔力

**技能樹**：無

**特殊**：由於沒有技能樹，額外獲得 1 個特性

**特性**：真理追尋之道（雙特性）、誓約的心（正負特性）、魔法精油

**其他標籤**

**真理追尋之道**

<ul>
<li>無論你是否認識它，無論你是否承認它，該存在的總是存在，就是這麼簡單。</li>
<li>對於我們現存的魔女來說，美貌與力量是非常重要的真理。你的施法檢定獲得 3DP 內在加值，並且傾城之貌無視前提提升 1 級。</li>
</ul>

**誓約的心**

<ul>
<li>魔女即使悲傷也不能流淚，當淚水滑落的時候，身上的魔力會完全失去，從而成爲普通人類。</li>
<li>當你傳承了魔女之血，即許下誓言，爲了實現不滅的美麗和不滅的世界，必須堅強的活着，爲未來而戰，你獲得相當於血統等級的施法者職能。如若流下軟弱的淚水（比如沮喪嚴重異常、眼部被嚴重刺激等類似情況就是必然流淚），將失去全身所有魔力，魔力池直接歸 0 。</li>
</ul>

**魔法精油**

<ul>
<li>這是與四大元素（地水風火）鏈接的最重要的媒介（總是視爲你有，但最多同時生效 1 件物體），你可以花費 1 點魔力，耗時 2 小時使用玄奧的手法塗抹在一件體積不超過 7 的物體上（比如掃帚、萬聖節南瓜、華貴的馬車），令其獲得飛行能力。</li>
<li>之後你使用它可以進行機動性笨拙，速度等於你基礎移動速度減半的飛行。</li>
<li>當你不需要它時，使用自由動作打個響指，它會遁入虛空（僅限於此物體），直到你再次以響指將其召喚出來。當你的血統等級達到 C 級時，你獲得機動性爲普通，移動速度爲你移動力的飛行能力。</li>
</ul>


## C 級

**屬性**：智力 +3 ，感知 +3

**技能樹**：無

**特殊**：由於沒有技能樹，額外獲得 1 個特性

**特性**：炙熱的情感、真知、魔女的使靈

**其他標籤**

**炙熱的情感**

<ul>
<li>向魔法女神密斯特拉的祈禱終於獲得了回應，魔女們可以從中汲取力量，代價是難以遏制的對愛的渴望。</li>
<li>你在施法檢定上再獲得 3DP 內在加值。</li>
<li>爲了抵禦這慾望，魔女們築起心防，以「生人勿近」的冷漠拒絕所有人的親近，以求獲得更多研習魔法的時間。</li>
<li>你獲得 3 點力場防禦。</li>
</ul>

**真知**

<ul>
<li>在真理的海洋麪前，我只是一個在淺灘上拾取貝殼的孩子。</li>
<li>對 C 級及以下的毒素，疾病，只要在有自然界花草或生物的地方，你總能採集到足夠的材料，以一定順序置入大鍋中，以睿智的魔女之名製作一份解藥。</li>
<li>這過程需要 1 點魔力和 2 小時。</li>
</ul>

**魔女的使靈**：魔女有時常相伴的寵物，它可能是以下 3 種的其中一種――

**①黑貓**：會說貓語，能說人話，能指揮普通的貓羣，上躥下跳相當靈活。 7HP ，閃避 5 ，基礎移動力 11 米。無視困難地形。

**②烏鴉**：會說鳥語，能說人話，能指揮普通的烏鴉羣。 4HP ，閃避 3 ，基礎移動力 10 米，具有飛行能力。

**③有路燈的柱子**

<ul>
<li>不會說話，能直立能彎腰，走路一蹦一跳的，基礎移動力 10 米， 8 點結構值， 1dr/- ，可以號令其半徑 20 米範圍內的燈火明滅。</li>
<li>一經選定無法更改，你在其 1 米範圍內，以標準動作和 1 點意志的消耗下令，使其達成你的一項任務，則必須是很直觀，很簡單的一件事，有效距離是你的施法骰成功數 \*100 米。</li>
<li>作爲魔女的使靈，其若死亡，你可以立刻知道有誰參與，並且使靈會在第二天零時復活到你身邊。</li>
<li>當你不需要它（不包括其死亡）時，使用自由動作跺腳，它會遁入虛空（僅限於此物體），直到你再次跺腳將其召喚出來。</li>
<li>特殊的，你可以花費 D+500 的價格，獲得另外 2 種使靈。</li>
</ul>


## B 級

**屬性**：智力 +4 ，感知 +4

**技能樹**：無

**特殊**：由於沒有技能樹，額外獲得 1 個特性

**特性**：修羅之道、夜宴（雙特性）、魔法女神的護佑

**其他標籤**

**修羅之道**

<ul>
<li>面對殘酷的歷史，有了一定實力的魔女們將背起重擔，將昔日的苦痛盡皆返還。即使是從聖者和信徒虔誠的靈魂中獲取力量的善良的魔女一脈，也不例外。</li>
<li>向魔法女神密斯特拉祈願，執掌裁決之力，每次成功命中敵人時，都能附加 1 點無法被豁免的能量傷害。</li>
<li>你在面對光明 / 黑暗生物時，使用的魔法對其都能產生剋制作用，如同魔法帶有黑暗 / 光明的材質一般。</li>
</ul>

**魔女之夜**

<ul>
<li>「沒人再向我訴說真理，沒人再給我留條活路。」</li>
<li>舞臺設備的魔女（統稱魔女之夜 / 本名不詳 ) 其性質爲無助。是不斷徘徊旋轉的愚者的象徵。是從古到今傳頌的傳說中的魔女 , 周遊世界（舞臺就是這星球的球體），舞臺大小爲體積 5 ，直到將整個世界（現實意義）都變作戲劇。當平常在顛倒位置的人偶移到上部時，就會如同暴風一樣將範圍內的文明在一剎那搞得天翻地覆。</li>

<li>「呢喃着祕密話語的少女獨自一人</li>
<li>從沒感受過沒有屋檐的世界</li>
<li>……</li>
<li>渴求鮮紅的血液，彷徨而又可悲的怪物</li>
<li>沒有罪業的家裏散佈着悲鳴痛哭的痕跡</li>
<li>……」</li>
<li>每一輪，沒能離開這片區域的敵人都會遭受 2 點恐懼點數，無法豁免。或是繚繞耳際的哀鳴，或是徘徊隱藏於黑暗中蠕動的深淵怪物，或是未來自己慘死的幻像……</li>
<li>對於想在這區域內移動的敵人來說，都需要過「感知 / 智力 + 求生」與你的施法骰相對抗來辨識方向，若是成功則可以看破黑暗走出魔女之夜，如若失敗即爲原地打轉，這是 B 級詛咒來源效果。</li>
<li>「……注意聆聽的話，你也聽到吧</li>
<li>以苦痛爲食，殘酷地終結的夜晚，開幕了。」</li>
<li>在第三輪，沒能離開這片區域的敵人會注意到舞臺下倒掛的旋轉的人偶已經離舞臺上方剩下一半距離，從這輪開始，每一輪區域內的敵人都會遭受一定程度的傷害，每輪骰一個意志與施法者的施法骰抗衡，造成失敗數的精神嚴重傷害，這也是一個 B 級詛咒來源效果。</li>

## A 級

**屬性**：智力 +6 ，感知 +6

**技能樹**：無

**特殊**：由於沒有技能樹，額外獲得 1 個特性

**特性**：無限之魔女（雙特性）、黃金碑文、神選者

**其他標籤**

**無限之魔女**

<ul>
<li>取自魔女中的賢者瓦爾基莉亞的力量。</li>
<li>「如果未來是辛酸與苦澀的，那麼，我們從過去再一次開始。」</li>
<li>――她挽起裙角如是說。</li>
<li>使用一個整輪動作消耗 10 點魔力，把你三輪前的狀態覆蓋到當前狀態中。每場景僅限使用一次。</li>
</ul>

**黃金碑文**

<ul>
<li>以滿是黃金的幻境來封印將死之人。</li>
<li>順川而下，終會到達“裏”。</li>
<li>在這“裏”尋找兩人開口之岸。</li>
<li>此處沉眠着通往黃金鄉的鑰匙。</li>
<li>當你將目標的生命槽惡性填滿的一瞬間，你可以用自由動作唸誦封印其存在的咒文――</li>
<li>「你在那裏將會聽到絕望的慘叫，將會看到遠古的幽靈在受煎熬，他們都在爲要求第二次死而不斷呼號，你還會看到有些鬼魂甘願在火中受苦……」</li>
<li>這能力可以使被你親手殺死的目標無法復活，這是一個 A 級的封印效果。</li>
</ul>

**神選者**

<ul>
<li>被密斯特拉女神所選中，作爲她在人間的代言人。</li>
<li>你的施法檢定，可以將你風度值作爲神聖加值加在 DP 上，用以執行神的意志。</li>
</ul>
