# 鴿子

> 來源：`資源/血統/非人類/特異本質/動物/鴿子`

**本質**：特異本質

**描述**

<ul>
<li>咕咕咕咕咕？</li>
<li>咕咕咕咕？</li>
<li>咕咕咕！</li>
</ul>

**特殊**：本血統所有關於鴿子的名詞可以替換爲鳳凰，若如此則可以將描述替換爲更貼近鳳凰的名詞，比如祕技・咕變爲鳳凰威勢（衛視？）等，效果不變。

## D 級

**屬性**：敏捷 +2 ，感知 +1 ，風度 +1

**能量池**：無

**技能樹**：無

**特性**：神速鴿子（雙特性），自由之鴿（雙特性）

**描述**

<ul>
<li>“你居然以爲你能限制住一隻鴿子！ naive ！”</li>
<li>我不知道你在說什麼，因爲我只是隻普通的鴿子啊。</li>
</ul>

**特殊**：由於沒有技能樹和能量池，額外獲得 2 個特性。

**其他標籤**

**神速鴿子**：你的種族改爲鴿子，並獲得特殊的語言專長：鳥語 1 級，並且可以如常提升等級。你的基礎移動速度增加血統等級 \*3 米。

**自由之鴿**：你可以忽略等同於你血統等級 \*1 點會影響你任意移動速度的不良狀態點數（如糾纏點數、失速點數等）。每輪一次，你可以花費一個迅捷動作移動不超過你體積值 \*1 米。


## C 級

**屬性**：敏捷 +3 ，感知 +2 ，風度 +1

**技能樹**：開啓 C 級鴿子技能樹

**特性**：祕技・咕！，超速鴿子

**描述**

<ul>
<li>“你跟得上我的 speed 嗎？弱者！”</li>
<li>我覺得你們可能對真正的咕咕一無所知。</li>
</ul>

**特殊**：無

**其他標籤**

**祕技・咕**：每場景一次，你可以用一個自由動作說出“呀！我發現我還有事沒做”或類似的話，然後下輪額外獲得一個只能用於移動的移動動作，且你下輪的標準動作也只能轉化成只能用於移動的移動動作。

**超速鴿子**：你可以免疫困難地形帶來的影響。你每有一點傳奇敏捷，你的基礎移動速度便再增加 5 米。

### 咕的一聲就消失了

**價格**：C+1000

**動作**：標準動作

**能耗**：無

**射程**：無

**目標**：無

**範圍**：無

**持續**：立即

**描述**：“咕的一聲他就從我的眼前消失了，簡直就像魔法 . ”

**效果**：你可以花費整輪動作進行一次移動，在這次移動中你可以選擇自身除基礎移動速度外，基於基礎移動速度決定其速度的一項移動速度（如飛行速度，陸行速度，游泳速度，攀爬速度等）使其提升等同於你血統等級 \*1 倍，具體提升哪一項速度由你在進行該次移動前決定。你這次移動視作一次瞬間移動。

**價格**：C+1000

### 鴿翼天翔

**價格**：C+1000

**動作**：被動

**描述**：“我在滑行啊咕，快看這裏啊咕！”

**效果**

<ul>
<li>當你進行移動時，由於你速度過快，其他單位將無法捕捉你的身形，如同你隱形了一般，這是一個 B 級自然本質的反偵測能力。</li>
<li>若你在一個回合中只進行了移動而沒有做任何其他動作（包括自由動作說話），則你也視作獲得隱形，這同樣是一個 B 級自然本質的反偵測能力，持續 1 輪。</li>
</ul>

**價格**：C+1000

## B 級

**屬性**：敏捷 +4 ，感知 +2 ，風度 +2

**技能樹**：開啓 B 級鴿子技能樹

**特性**：正在鹿上，和平象徵，極速鴿子

**描述**

<ul>
<li>“我馬上就到了！我在鹿上了！”</li>
<li>戰爭結束時，人們互鴿以示友好。</li>
</ul>

**特殊**：無

**其他標籤**

**正在鹿上**：每天一次，你可以花費 1 個自由動作宣告自己“正在鹿上”，你化爲鴿子跳到一隻突然出現的鹿頭上蹲着看戲，此時任何目標都無法影響你，同樣你也無法影響別人。你可以隨時宣佈“你到了”，結束本狀態。若處於戰鬥中，你正常投擲先攻，並且在下輪進入戰鬥。

**和平象徵**：你進入戰鬥時，該戰鬥場景中的所有人（包括自己）在所有檢定上失去等同於你傳奇風度 +1 個成功數。

**極速鴿子**：你可以用一個移動動作化身爲毛色雪白的鴿子，裝備變爲羽毛或加持在身體上，體積變爲 1 ，但不接受體積調整，之後獲得等同自身基礎移動速度兩倍的飛行速度，機動性完美，你仍然可以說人話，但我推薦說鴿語，變回來是一個自由動作。

**價格**：B+4000

**動作**：整輪動作

**能耗**：無

**射程**：接觸

<li>\2. 進行一次衝鋒攻擊，該次衝鋒攻擊可以自由轉向，無須沿直線移動，同時你可以對沖鋒路徑上的所有敵人各進行一次近戰肉搏攻擊，你該次攻擊增加 8 點【高速優勢】，並且每次攻擊都能獲得衝鋒攻擊帶來的增強加值，同時目標視作陷入措手不及，這是一個 B 級措手不及效果。</li>
