# 血統

> 來源：`資源/血統/非人類/特異本質/其他生物/Vendread`

**本質**：特異本質

**前提**：曾經死亡過

**選開**：如果PC背景合理，ST可以允許PC使用人物背景中的死亡經歷來滿足本血統的強化前提。

## D 級

**屬性**：力量+2，決心+2

**能量池**：無

**技能樹**：無

**特性**：歸來者（負特性），復仇死者，屠魔俠（四特性）

**特殊**：由於沒有技能樹和能量池，額外獲得2個特性。

**其他標籤**

**歸來者**：你每隔24小時便會失去1點意志力。

**復仇死者**：僅針對不死生物，你在攻擊與防禦上分別獲得1個附加成功。

**屠魔俠**：你無視前提獲得並可以使用輪迴隊專長：除魔獵人。


## C 級

**屬性**：力量+3，決心+3

**技能樹**：無

**特性**：核，黑夜夢魘，復仇死者誕生

**特殊**：由於沒有技能樹，額外獲得1個特性。

**其他標籤**

**核**：你獲得1點全傷害吸收能力。

**黑夜夢魘**：你獲得C級免疫措手不及的能力。

**復仇死者的誕生**：每回合一次，當你生命值中最好的狀態爲[L]時，你可以支付1點意志力並立刻將自身生命槽中1點惡性傷害或2點嚴重傷害恢復爲完好，並在所有檢定上獲得1DP內在加值，該內在加值可疊加，持續一個場景，這無需動作。


## B 級

**屬性**：力量+4，決心+4

**技能樹**：無

**特性**：阿尼瑪・你的女神，復仇死者之夜，地獄犬與斯特里克斯（雙特性）

**特殊**：由於沒有技能樹，額外獲得1個特性。

**其他標籤**

**阿尼瑪・你的女神**：由你造成的傷害不會觸發護命玉佩或支線等級低於本血統等級的，與護命玉佩效果類似的能力（包括但不限於替身甲，“福星高照”特性等，具體可由ST裁定）。

**復仇死者之夜**：你獲得不死生物特性。

**地獄犬與斯特里克斯**

<ul>
<li>你失去6點意志力上限，之後你可以在以下兩頭召喚生物中選擇一頭，一旦選定不可更改，之後你可以花費5分鐘召喚該生物，持續時間爲永久。</li>
<li>你同一時間最多擁有1名以此法召喚的生物，在輪到其行動時，你能夠如同操控自己人物一般操控其行動，該生物死亡或被解除召喚後會立刻化作光點完全消失，不會遺留任何痕跡，解除召喚是一個整輪動作。</li>
<li>每次召喚時，召喚生物都會重置所有狀態，但召喚生物死亡後必須在8小時後才能再次召喚，主動解除召喚則必須在2個場景後才能再次召喚。</li>
</ul>


### 地獄犬

**體積**

<ul>
<li>3</li>
<li>力量16 敏捷11 耐力16</li>
<li>智力6 感知11 決心6</li>
<li>風度6 操控6 沉着11</li>
</ul>

**技能**

<ul>
<li>肉搏10 求生10 運動10</li>
<li>躲藏5 調查5 脅迫5</li>
<li>感受5</li>
</ul>

**專長**：精通先攻3 輕靈戰士4

**攻擊**：擁有武器傷害爲12L的天生武器與16點天生防禦。

**其他標籤**

**心靈鏈接**：你與地獄犬共享視野並具有“心靈鏈接”。

**不死生物**：地獄犬是不死生物

**疾病撕咬**：地獄犬的近戰肉搏攻擊造成的傷害類型爲毒素傷害，這是一個B級毒素效果，並且其在肉搏技能上擁有全專業，在求生與運動技能上擁有自我保護專業。


### 斯特里克斯（烏鴉）

**體積**

<ul>
<li>1</li>
<li>力量6 敏捷16 耐力6</li>
<li>智力6 感知16 決心6</li>
<li>風度6 操控6 沉着6</li>
</ul>

**技能**

<ul>
<li>肉搏4 求生8 運動8</li>
<li>躲藏8 調查10 感受4</li>
</ul>

**專長**：警覺3

**攻擊**：擁有武器傷害爲3L的天生武器與3點天生防禦。

**其他標籤**

**心靈鏈接**：你與斯特里克斯共享視野並具有“心靈鏈接”。

**不死生物**：斯特里克斯是不死生物

**高空索敵**：斯特里克斯擁有等同於自身基礎移動速度兩倍的飛行速度，機動性爲完美，並且其在調查技能上擁有全專業。

**鷹眼視覺**：斯特里克斯擁有B級特異本質偵測能力，範圍等同於其敏感範圍。

**死亡指名**：斯特里克斯可以花費一個標準動作選擇一名位於其敏感範圍內的單位，之後被選定的目標在受到針對不死生物起效的能力時被視同不死生物，但這不會對目標本身帶來任何實質的影響，該效果持續一個場景。斯特里克斯同一時間只能指定一名目標，主動取消指定是一個迅捷動作。


## A 級

**屬性**：力量+6，決心+6

**技能樹**：無

**特性**：爆誕，誅邪俠（雙特性），白晝黎明

**特殊**：由於沒有技能樹，額外獲得1個特性。

**其他標籤**

**爆誕**：你可以花費一個標準動作開啓本特性，效果持續期間只要你位於敵人攻擊範圍內，所有感知到你存在的敵人都必須優先攻擊你，這是一個A級影響心靈的效果，持續一個場景，關閉本特性是一個標準動作。

**誅邪俠**：僅針對不死生物，當你對其成功造成傷害時，你可以將該次傷害中不超過你決心值\*1點傷害提升至惡性傷害，並且以此法造成的惡性傷害無法治療與恢復，這是一個A級詛咒效果，持續時間爲永久。

**白晝黎明**

<ul>
<li>只有在具白晝與黑夜之分的位面或星球，你才能獲得本特性提供的好處。</li>
<li>每8小時一次，當時間由黑夜轉換至白晝時，你所有生命值恢復至完好並清除身上所有不良狀態點數。</li>
</ul>
