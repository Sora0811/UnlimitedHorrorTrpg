# 雙王血統

> 來源：`資源/血統/非人類/特異本質/其他生物/雙王血統`

**本質**：特異本質

## D 級　揹負者

**屬性**：7 點屬性自由分配，單項最高 2 點

**能量池**：無

**技能樹**：無

**特性**：屬性自由分配，寄宿本能，抗性軀殼，阻礙導體 ( 負特性 )

**特殊**：由於沒有能量池和技能樹，額外獲得 3 點屬性

**描述**

<ul>
<li>你是神與魔共不承認的被拋棄者，你因此失去了一切可以學習的根源，流落凡塵，但你也可以因此而自主的選擇自己的道路而非按照他人指引的前進。</li>
<li>你混跡人羣之中，在喋血的沙場中生存，月光皓明而照映於地面，當所有的夥伴都正享受難得的安寧時，你卻因爲痛苦而從夢境痛苦驚醒，你意識到自己體內的光暗又再次躁動而起，爲了壓制此時暴躁不堪的它們，只有咬牙苦撐的限制着，否則就是死亡在等待着你。</li>
</ul>

**其他標籤**

**抗性軀殼**：在長期的元素的衝突下，你的身軀逐漸變得耐久和堅韌。你因此獲得 3 點天生防禦。

**寄宿本能**

<ul>
<li>你與生俱來的力量使得你操控光暗元素的能力得心應手，你進行的攻擊，若其擁有【光明】或【褻瀆】特性，則攻擊檢定獲得 4DP 的內在加值。</li>
<li>阻礙導體 ( 負特性 ) ：你體內的光暗元素主導着整個身體，稍微疏忽就會出現平衡崩解，這點在進行劇烈的行動時更加明顯，迫使你必須要在任何時刻分心注視他們。</li>
<li>如果當你使用不含【光明】或【褻瀆】特性的攻擊時，攻擊檢定則會承受 3DP 的內在減值。當你進行運動技能檢定時，則會承受 1DP 的內在減值。</li>
</ul>


## C 級　抗衡者

**屬性**：8 點屬性自由分配，單項最高3 點

**技能樹**：無

**特性**：屬性自由分配，戰場歷練

**特殊**：由於沒有技能樹，額外獲得 2 點屬性

**描述**：隨着長劍啜飲的鮮血越多，你的力量也在歷練的過程中逐步增長，但對於自身體內寄宿的兩個惡魔不定時的肆虐，你依舊難以抗衡，於是，爲了淬鍊意志，掌控自己的命運，你一次又一次的衝向戰場。

**其他標籤**

**戰場歷練**：爲了擁有控制體內元素的力量，你衝向了戰場並從生與死之間歷練和感悟。你從肉搏、槍械、白刃中選擇一個技能，一旦選擇不可更改，選擇後對應技能的攻擊檢定獲得【 9 加骰】，若已經獲得【 9 加骰】則改爲攻擊檢定獲得兩個附加成功。


## B 級　持有者

**屬性**：11 點屬性自由分配，單項最高4 點

**技能樹**：無

**特性**：屬性自由分配，堆積死亡，超凡入聖

**特殊**：由於沒有技能樹，額外獲得 3 點屬性

**描述**：不知不覺間，你已經有足夠的能力強行壓制下身體裏光暗的躁動，在你戰鬥的時，光與暗已經隨侍於側，你的意志已經足夠抗衡體內躁動的光暗元素，此時此刻起，他們不再是你的阻力，而是你的助力，藉由這份天賦，你隨意的縱橫在戰場之中無人能敵，你終於擺脫了枷鎖，似乎即將從此迎向黎明，然而真正的考驗才正要開始…因爲你所壓制力量終於獲得解放，查覺到這一切的敵人將會用盡一切代價不惜殺死你。

**其他標籤**

**堆積死亡**

<ul>
<li>在戰場上的歷練以及感悟，已經使你得戰鬥技巧出神入化，任何的一動一靜、一前一退。都帶有無上的奧妙以及推衍無盡的變化，於是，你的敵人在這攻擊之下毫無懸念的死去。</li>
<li>你 C 級選擇的技能，該技能的攻擊檢定獲得【 8 加骰】，若已經獲得【 8 加骰】則改爲攻擊檢定獲得四個附加成功。</li>
</ul>

**超凡入聖**：千錘百煉的意志足以改變生命本質。你的意志值上限增加 6 點，生命值上限增加 6 點，同時，你失去“阻礙導體”特性。

<ul>

<li>不過，這場漫長的戰爭依舊在持續着，並使得所有生物感受到疲憊以及倦怠，在你的眼中，一隻又一隻的軍團奔赴戰場，卻如同被巨獸吞噬一般，毫無生息，而它的排泄物則是堆積成山的白色信箋，然而，終將有人終結這一切的，帶領飽受欺壓的凡界重新奪回自主與和平，或許你還不自知，但是你就是那所選之人。</li>
<li>於是，有一天命運降臨了，一場邂逅觸動了你，於是你奔向戰場，握起劍，揮舞劍。</li>
</ul>

**量能制衡**

<ul>
<li>你的天賦便是執掌光暗，擁有輕而易舉的操弄它們各自的能力，你可以讓出身體部分的控制權，運用光明與黑暗來達到自己的目的。</li>
