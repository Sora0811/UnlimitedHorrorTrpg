## D 級

**屬性**：耐力+2

**能量池**：精神力

**技能樹**：開啓變異D級技能樹

**特性**：怪物（雙負特性）、蟲巢幽能、進化（三特性）、生存者（雙特性）、原始抗拒（負特性）基因編輯（負特性）

**特殊**：無

**進化**：當你購買了原始異蟲血統後，你從下列兩種進化方向中選擇一種，選擇後不可更改：

**其他標籤**

**怪物**

<ul>
<li>“我不需要城牆，我能進化護甲。我不需要武器，我能進化利爪。他們，一成不變，而我，永遠改變。” 理所當然的，你是一隻怪物，你看起來像一隻可怕的蟲子，事實也確實如此。</li>
<li>購買本血統後，你不能穿戴人類使用的鎧甲，不能使用人造武器和盾牌，並且你恐怖的外表使得任何第一次見到你的非蟲類生物對你的態度下降1級。</li>
<li>從此後，你失去所有人類的語言能力（這意味着你無法使用任何包含“語言”成分的能力），你雖然能聽懂並能獲得，但由於生理結構而不能說，你的種族分類變爲蟲，不再屬於人類，你獲得異蟲語4級，可以與蟲類對話。</li>
</ul>

**蟲巢幽能**

<ul>
<li>你的精神力能量池與一般的精神力能量池不同，蟲巢幽能的外在表現是純粹的紫色。</li>
<li>並且你現在精神力的恢復方法改爲在飽食後通過一個4-8小時的睡眠，恢復全部的精神力。</li>
<li>同時，基礎用法改爲當你承受關鍵屬性爲生理屬性的不良狀態點數時，消耗1點精神力，你的對抗豁免檢定獲得2DP增強加值。</li>
</ul>

**生存者**

<ul>
<li>只是爲了活下去。</li>
<li>你的傷勢不會惡化，並且你即使在惡性傷害槽完全填滿的狀態下也不會失去意識。</li>
<li>只要你吞喫了至少體積1的肉食或高營養食物，則你獲得快速醫療1，持續1輪。你在獲得這個快速醫療時，每再吞噬體積1的肉食或高營養食物，則快速醫療持續時間+1輪，最多耐力/輪。</li>
<li>當本血統等級到達A級時，快速醫療改爲再生。</li>
<li>在戰鬥中進食體積1的食物是一個移動動作，進食體積不超過（你體積/2）的食物是一個標準動作，進食體積等同你體積的食物是一個整輪動作。</li>
</ul>

**巨獸**

<ul>
<li>力量+2</li>
<li>外形爲一隻通體覆蓋着厚重表皮的巨獸，如同擁有強壯手臂，頭部略小的暴龍，粗短的脖頸和相比後肢更加強壯的類人前肢，以及背部凸起的刀狀甲殼使你成爲了一個活體戰爭機器。</li>
<li>你的體積增大1點，你的身軀堅硬的足矣彈開槍支的攻擊，你的肉體獲得【防彈】特性，並且生命值上限獲得等同血統等級/1點。</li>
</ul>

**獵手**

<ul>
<li>敏捷+2</li>
<li>外形類似蜥蜴和犬類的混合體，但是表皮上有着古怪的鑲在皮膚裏的紋路，行動迅速並且有較長的劍尾。</li>
<li>你的體積降低1點，你的基礎移動速度增加血統等級\*5米，可以在牆壁和天花板上半速移動並停留，可以用敏捷代替力量進行攻擊檢定。</li>
<li>當你衝鋒時，你可以不使用衝鋒，而是改爲你進行一個敏捷+運動（跳躍）檢定，目標以感知+調查（偵查）進行對抗，若目標失敗，則針對本次攻擊，目標陷入D級措手不及。</li>
</ul>

<li>你每有1點傳奇決心，則獲得1點全能量抗力。</li>

## B 級

**屬性**：耐力+8

**技能樹**：開啓變異B級技能樹

**特性**：單屬性上限突破、吞食（三特性）、精華吞噬者、原始抗拒（負特性）、基因編輯（負特性）

**載具**：本能力每造成1點傷害就獲得1點臨時生命。

**其他標籤**

**吞食**

<ul>
<li>你獲得了一位原始異蟲領袖的基因，你學會了使用自己強有力的消化器官和舌頭將敵人拖拽至你的口中然後大快朵頤，不僅能滿足食慾還能獲取一定的臨時強化。</li>
<li>以一個標準動作，也許還伴隨着“呱”的一聲和受害者的慘叫，你對一個你體積/米內的目標使用天生武器-牙進行一次近戰肉搏攻擊，本次攻擊你無視目標的硬度，若你造成的傷害大於目標的耐力值，那麼目標視爲被你嚼碎了吞噬，立即死亡，這是一個B級即死效果。</li>
<li>你使用本能力後，無論目標是否死亡，目標每有1點耐力值，則本能力需等待1輪後才能使用。</li>
<li>不論如何，如果你成功造成了傷害，那麼你可以根據目標的生物類型獲得強化，持續時間爲你的傳奇耐力/輪，每個生物類型帶來的好處持續時間內只能獲得一次，如果一個目標又多個生物類型，則可以疊加獲得：</li>
</ul>

**生物**：本能力每造成1點傷害就恢復1點嚴重或衝擊傷害。

**黑暗生物**：天生武器獲得【幽冥】【魔法】【褻瀆】特性。

**光明生物**：天生武器獲得【幽冥】【魔法】【光明】特性。

**構裝體**

<ul>
<li>每造成1點傷害就增加1點天生防禦。</li>
<li>擁有魔力池/幻想魔法生物：獲得傳奇耐力\*2點魔法抗力。</li>
</ul>

**擁有精神力池**：吞食技能和血統技能的冷卻時間縮短一半。

**泥型生物**：獲得傳奇耐力/點物理傷害吸收。

**精華吞噬者**

<ul>
<li>你獲得一個計數槽，名爲【精華】。</li>
<li>精華上限初始爲100點，你每親手殺死一個目標則可以獲得精華，等同其最高支線等級的平方（即無支線的目標無法獲得精華），但不會超過你血統等級的平方，這意味着你即使殺死了高等級的敵人也只會獲得有限的精華。</li>
<li>精華填滿後，你可以進化，獲得可疊加的（被填滿精華槽上限的百分之一）/1的體積，每部影片最多進化一次，精華每被填滿一次，上限翻倍。</li>
</ul>


## A 級

**屬性**：耐力+12

**技能樹**：開啓變異A級技能樹

**特性**：單屬性突破上限、有機重組（三特性）、完美巨獸、原始抗拒（負特性）、基因編輯（負特性）

**其他標籤**

**有機重組**：每次你的精華到達上限時，若你選擇進化，則你獲得以下一個能力獲得，每個能力只能選擇一次，往前不追溯：

**堅韌不屈**：你通過“生存者”獲得的快速醫療變爲4點。

**腎上腺素狂暴**：你每輪獲得一個額外的標準動作。

**強化骨質板甲**：你獲得等同傳奇耐力/點全傷害吸收，並獲得等同體積值的臨時生命值，這個臨時生命在被消耗後，會在你脫離戰鬥後每分鐘恢復1點。

**巨型體態**：你提升8點體積。

**蠻橫衝撞**：你在進行衝鋒攻擊時，你通過沖鋒獲得的增強加值僅受限於你的力量值，如果衝鋒的減值超出了你的基礎防禦，則直到你下一次行動前，所有攻擊你的敵人在攻擊上獲得超出部分等額的命中加值。

**絕對適應**：你忽視環境減值，可以在任何自然環境中行動自如。

**永恆君王**：只要你還在場上且沒有昏迷或被殺死，則你決心\*10米內的所有友方單位（包括你）都在全檢定上獲得等同你傳奇決心/1點士氣加值，並且在你倒下之前都不會因爲傷勢而倒下。

**古老之王**

<ul>
<li>當你進入戰鬥時，任何生物都會將目光投向你，你是如此的高貴而強大，並且不可侵犯，只要站在你的面前，任何生物都會顫抖。</li>
<li>一個場景一次，自由動作開啓古王威儀，決心\*10米內所有的敵對生物受到等同你決心值的恐懼點數，目標意志豁免，不可疊加。若目標爲昆蟲類或巢羣生物，則受到的的恐懼點數會變爲爲等額魅惑點數，關閉古王威儀是一個自由動作。</li>
</ul>

**完美巨獸**：你不會再因體積而受到命中減值和防禦上的閃避減值，你從傳奇力量中獲得的DP現在並非取高，而是疊加。

</ul>

<li>變異D級技能樹</li>
</ul>

**飛撲**：原始爆裂蟲可以以整輪動作進行一次衝鋒，本次衝鋒獲獲得B級接觸攻擊能力，若其命中目標，則其可以立即自爆，針對該目標，本次自爆傷害無法豁免。
