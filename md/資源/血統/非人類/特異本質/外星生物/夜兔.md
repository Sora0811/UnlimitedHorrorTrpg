# 夜兔

> 來源：`資源/血統/非人類/特異本質/外星生物/夜兔`

**本質**：特異本質

**總描述**：夜兔出自日漫《銀魂》，是該世界的三大傭兵種族之一，夜兔普遍皮膚白皙，身材嬌小，但是在嬌小的身體之中卻蘊含着足以撕裂鋼鐵的恐怖力量。夜兔和吸血鬼一樣，有着極強的再生能力和討厭陽光的特性，不過這兩點都比不上吸血鬼，他們會討厭陽光照射自己的感覺而不會見光死，除非是長時間的暴曬，而對於常人來說足以致命的傷勢對於夜兔而言也只是輕傷罷了。在整個宇宙，夜兔的數目都非常的稀少，這是因爲夜兔血脈之中對於戰鬥的狂熱熱衷和弒親的傳統，他們愛着家庭又想將家人親手殺死。

## D 級　夜兔族人

**屬性**：力量+2，敏捷+1，耐力+1

**能量池**：無

**技能樹**：無

**特性**：飽食（雙特性），厭光（負特性），夜兔血液（正負特性），殺戮機器（雙特性）

**特殊**：由於沒有技能樹和能量池，額外獲得2個特性。

**描述**

<ul>
<li>在烙陽星，參差的房屋阻擋着陽光的落下，討厭陽光的感覺在夜兔的基因之中繼承着，她們是戰鬥的種族，狂暴的血液在他們的體內流動着。</li>
<li>夜兔族的食量非常的巨大，是因爲夜兔們可以通過進食在自己的體內積累能量，以提供在戰鬥時的超常發揮。</li>
</ul>

**其他標籤**

**飽食**：當你感到餓的時候，你所有檢定承受1DP減值。面對豐盛的酒宴時，你需進行意志檢定來決定能否抵制住食物的誘惑，DC爲20。如果失敗，你將不顧後果地大喫大喝。並且在進食後1小時內，你每花費1點意志力，使自身的一項生理系屬性可以獲得1點內在加值，單項屬性同一時間能以此法提升的屬性數值不得超過本血統等級，持續時間爲進食後1小時內。

**厭光**

<ul>
<li>當你身體任意部分被陽光直接照射時（具體可由ST裁定），你每輪行動開始時都需要進行一次DC爲2的耐力檢定，若檢定未通過則使你生理系屬性降低1點，該DC每輪增加1點，在你進行一次長休息後DC會重置，當你任意一項生理系屬性因此降爲0時，你會不可避免地死亡。</li>
<li>因此降低的生理系屬性只能在你位於沒有陽光照射的地方進行一次短休息後纔會完全恢復，除此之外無法以任何其他方式恢復。</li>
<li>你可以採取保護措施（如穿袍子戴面具撐遮陽傘等）來避免本特性的影響。</li>
</ul>

**夜兔血液**：在你進入戰鬥場景後，你每輪行動開始時都需要通過一次DC爲你已經歷的回合數\*4的意志豁免檢定，若檢定未通過則會進入“狂暴狀態”。在該狀態下，你的全部生理系屬性上再獲得1點內在加值，但是會敵我不分地優先攻擊距離你敏感範圍內戰鬥力最強的目標，並且不會逃跑，該狀態持續至你敏感範圍內沒有生物或你失去意識或切換場景爲止。

**殺戮機器**：你不會因爲傷勢失去意識，並且你的生命值若恰好被惡性填滿也不會死亡，但在這種情況下只要你受到任意1點傷害便會立刻死亡。


## C 級　夜兔傭兵

**屬性**：力量+3，敏捷+1，耐力+2

**技能樹**：無

**特性**：百戰之身，戰鬥風格（雙特性）

**特殊**：由於沒有技能樹，額外獲得1個特性。

**描述**：長期的戰鬥之中你學會了如何控制自己的身體攝入更多的能量和如何降低體力的支出，身爲宇宙最強種族的夜兔無疑是殺戮的高手，而他們的嗜戰同樣積累了無數的戰鬥經驗。

**其他標籤**

**百戰之身**：你的肉身獲得【防彈】特性，你的天生武器增加等同於本血統等級的【破甲】。

**戰鬥風格**：在兌換本級血統時，你必須選擇一項生理系技能，選定後不可更改，之後你在通過自學能力規則自學基於該技能的專長或能力時，你所需支付的XP降低本血統等級\*1點。


## B 級　夜兔精英

**屬性**：力量+4，敏捷+2，耐力+2

**技能樹**：無

**特性**：提升――百戰之身（三特性）、君臨戰場之王

**特殊**：由於沒有技能樹，額外獲得1個特性。

**描述**：從殺戮之中走出，無窮無盡的殺戮技巧銘刻在你的記憶之中化爲了你的肌肉本能，自無數的戰場之中淬鍊而出的這一具身體，就是夜兔戰鬥之時的最強依仗。哪怕就是在飛船艦炮的星戰時代，夜兔也依然依靠自己的雙手進行着戰鬥。

**其他標籤**

**百戰之身**：你的肉身獲得【防能量武器】特性，並獲得等同於本血統等級DR/-的傷害減免。

**君臨戰場之王**：當你受到目標包含你在內的攻擊時，若該次攻擊需要進行檢定，你可以花費反射動作進行一次力量+敏捷檢定，隨後使攻擊方在其該次攻擊檢定上承受等同於你這次檢定成功數的D無名減值。這表現爲你以精妙的技巧格擋攻擊、打出拳風擊爆法術等。


## A 級　夜王

**屬性**：力量+6，敏捷+3，耐力+3

**技能樹**：無

**特性**：夜兔之王（四特性），逐日者（正負特性）

**特殊**：由於沒有技能樹，額外獲得1個特性。

**描述**

<ul>
<li>“我族亦是羨慕那行走在陽光之下的種族，縱然不喜，仍舊羨慕着啊。”夜兔不被陽光所接受，但即使是這樣，夜兔們仍然在憧憬着陽光。</li>
<li>最初的夜王也僅僅是一個普通的夜兔而已，但是依賴的就是那份超乎尋常的成長速度，而今成長成爲夜兔之王的你，已經是無數夜兔之王，是君臨整個宇宙的最強者。當你置身戰場之時，你的血液會變得亢奮，無論是何種襲擊，你都可以瞬間反制。</li>
</ul>

**其他標籤**

**夜兔之王**

<ul>
<li>你免疫A級以下影響心靈的負面效果。</li>
<li>此外，每部影片3次，你每次親自殺死一名當前最高支線等級不低於你的敵人時，你永久獲得1點屬性與1個技能點，該屬性與技能點僅能分配在生理系屬性與技能上。</li>
</ul>

**逐日者**

<ul>
<li>現在你不會再受到D級“厭光”特性影響。</li>
<li>但是，當你感知到陽光的存在時，你每輪行動開始時都需要通過一個DC爲15的意志檢定，該DC每輪都會增加2點，持續至你沒有再感知到陽光的存在爲止，而該DC只有在你花費30分鐘凝神靜氣後纔會重置。</li>
<li>若檢定未通過，你會不可避免地以自己最快的速度移動至當前正被陽光照射的範圍內，並且無法主動離開該範圍。當你位於被陽光照射的範圍內的輪數超過你當前最低的一項生理系屬性時，你會立刻死亡，該輪數會在你離開該範圍後重新計算。這在畫面效果上表現爲你帶着滿足的笑容化成灰燼。</li>
</ul>
