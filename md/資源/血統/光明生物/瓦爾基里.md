# 瓦爾基里

> 來源：`資源/血統/光明生物/瓦爾基里`

## D 級　Valkyrie 變化

**本質**：魔幻本質

**描述**

<ul>
<li>女武神「瓦爾基里」，這個名字來源於 Wolkenthrut( 風之力 ) 和 Mist( 迷霧 ) 。</li>
<li>女武神們一般是來自地上國王的女兒，或是奧丁自己的女兒，或是發誓侍奉神而被諸神選中上天的處女戰士。他們被稱爲「奧丁的侍女」</li>
<li>她們是身披閃亮盔甲，騎着駿馬在天空中飛行的少女戰士。爲瓦爾哈拉殿堂尋找和收集陣亡的勇士。</li>
<li>瓦爾基里擔負奧丁所賦予的任務直接參加地上所進行的混戰，賜勝於一方，其外貌變化即爲戰爭行將爆發的象徵。</li>
<li>本血統只有女性角色纔可以選擇。</li>
<li>D+600</li>
</ul>

**屬性**

<ul>
<li>敏捷 +1 ，感知 +1 ，耐力 +1 ，決心 +1 ，風度 +2</li>
<li>敏捷 +1 ，感知 +1 ，耐力 +1 ，決心 +1 ，風度 +2</li>

**價格**：D+600

**其他標籤**

**神賜甲冑**

<ul>
<li>瓦爾基里購買魔幻本質的重甲時，該甲冑自動獲得【認主】特性，並且由她自行設定樣式，該盔甲的盔甲防禦提升女武神的傳奇風度點。並且獲得【封閉 2 】特性，盔甲減值提升 2 點。（如原本盔甲減值爲2，購買後變爲4）</li>
<li>瓦爾基里擁有連續作戰的能力，其傷勢恢復速度遠快於常人，獲得快速醫療 1 ，當你穿着神賜甲冑時，你可以獲得相當於風度上自動成功數 -1 的全傷害吸收（至少有 1 ）。</li>
<li>提升 - 神恩：現在你自 D 級神恩中獲得的內在加值在先攻也獲得同一加值。</li>
<li>B+3600</li>
</ul>

**神恩**

<ul>
<li>瓦爾基里是神選者，爲諸神所賜福，她們的防禦獲得相當於傳奇風度的內在加值。</li>
<li>C+1200</li>
</ul>

**榮耀的光輝**：瓦爾基里可以爲自己的神賜甲冑賦予榮譽的光輝這一概念武裝。

**神導**

<ul>
<li>作爲戰爭神使，瓦爾基里每日每血統等級一次可以尋求奧丁的指引，將風度值加到白刃判定的 DP 中，並將風度上的自動成功加到白刃判定的自動成功中，這些加值均視爲內在加值。你也可以以自身意志發動這一效果，這視爲一個標準動作，並消耗 3 點意志力，並且本次攻擊使用風度替代力量作爲傷害上限。</li>
<li>A+7200</li>
</ul>

**戰爭神使**：瓦爾基里是勝利的象徵，只要她出現己方就可帶來極大的士氣，現在瓦爾基里的快速醫療提升到 4 點，當瓦爾基里進行先攻擲骰時，若其先攻高於所有戰鬥參加者，則可以同時進行一次風度 + 表達檢定，每個成功數能爲你及所有能看到你的友方進行的技能判定以及防禦上提供 1 點士氣加值，若先攻並非最高，則可在第一輪使用一個整輪動作來達到這一效果。持續一個場景或直到你失去意識。

**神性威儀**：現在瓦爾基里來自神恩中的內在加值延伸至所有檢定和防禦上。並且瓦爾基里在防禦上獲得相當於風度值一半的偏斜加值。
