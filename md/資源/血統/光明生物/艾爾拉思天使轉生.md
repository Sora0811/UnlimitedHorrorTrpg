# 艾爾拉思天使轉生

> 來源：`資源/血統/光明生物/艾爾拉思天使轉生`

##  級　耳語傾者

**價格**：D+600

**屬性**：7 點自由屬性 ( 單屬性上限不能超過 2)

**能量池**：無

**特性**：耳語之聲（雙特性），自由屬性分配，天堂活力，光明生物（負特性），信仰導向（負特性）

**技能樹**：無

**特殊**：由於沒有能量池和技能樹，額外獲得 3 點屬性

**描述**：你與逝去天使的靈魂相連接。

**價格**：D+600

**其他標籤**

**耳語之聲**

<ul>
<li>在死去天使的靈魂向你低語，訴說着艾爾拉思之子的智慧與對無面者的仇恨，這使你在白刃、肉搏、神祕學、學識技能上不會受到沒有專業懲罰。</li>
<li>任何時候你都能一眼辨認出具備黑暗血統的存在，你以一個整輪動作，進行一個感知 + 感受（察言觀色）的檢定與對方的智力 / 操控 + 掩飾（唬騙）進行對抗，如果成功就可以得知目標是否爲黑暗生物。</li>
</ul>

**天堂活力**：爲了容納天使之力，你的肉體生命力被強化了，天使的力量也使你的鬥志更爲高昂。你額外獲得如同你血統等級的生命值。

**技能樹**：無

**特殊**：由於沒有技能樹，額外獲得 1 個特性

**描述**：你容納了一些來自天使的力量。

**價格**：C+1200

**其他標籤**

**光輝之顏**

<ul>
<li>天使們有一層獨一無二的靈氣覆蓋在面貌上，可以稍微轉變其外表，使其看上去與同他們接觸的生靈相似。因此，在精靈眼中，天使會略有精靈的外表；而獸人眼中他們則有獸人的外貌特徵等等。無論如何，在別人的眼中，天使總是具有無上的美貌，並且始終顯得十分年輕。</li>
<li>你的互動系相關檢定獲得了相當與你的血統等級的 DP 內在加值，並且任何生物與人物交流時，對人物的初始態度提高一級。</li>
</ul>

**天使本質**：你獲得黑暗視覺與靈視，並且你可以正常影響靈體。

**其他標籤**

**狂熱**：你激發了一個盟友或者自身內心潛藏的對戰鬥的狂熱，花費一個整輪動作，進行一個風度 + 表達的檢定，選擇敏感範圍內的一個目標，使其攻擊，防禦和技能以及對抗檢定上他將獲得想當於此檢定同等 DP 的士氣加值。你可以花費意志進行增幅，每額外花費 1 點意志力，則可以額外影響一個目標，上限爲你的風度值。持續時間一場景。

**超凡存在**：你獲得超凡神聖，等級爲 0 級。


**正文**

本血統雖然名爲天使轉生，但是實際上與基督教關係不大。該天使實際上指艾爾拉思的天使們。

艾爾拉思領導着光靈和天使。

光之龍被當做太陽神來崇拜，其神職包括權威、真相、忠誠和正義。

他的信徒尋求照亮黑暗之處，征服邪惡，追尋個人榮譽和英雄主義。

他的信徒主要是天使，但是天使在長老之戰中損失慘重。

艾爾拉思是神聖帝國（聖堂勢力）的主神。

這是一個信仰導向的能力。
