# 血祭支配者

> 來源：`資源/血統/黑暗生物/血祭支配者`

**本質**：魔幻本質

## D 級

**屬性**：操控+2、耐力+2

**能量池**：無

**技能樹**：開啓血祭支配者D級技能樹

**特性**：黑暗生物（負特性）、微操、敗血（雙特性）

**特殊**：由於沒有能量池，額外獲得一個特性。

**其他標籤**

**黑暗生物**：你變爲黑暗生物。

**微操**：你能夠使用操控代替力量作爲關鍵屬性進行近戰白刃攻擊檢定。

**敗血**

<ul>
<li>你開啓一個刻度，名爲恩賜點，恩賜點上限等同於你的耐力值。每輪一次，你可以花費一個自由動作對自己造成不超過血統等級\*2點不可避免的嚴重傷害，每以此法對自己造成1點嚴重傷害，你便獲得1點恩賜點，以此法獲得的恩賜點在切換場景時會自動清空。</li>
<li>在進行任意一次檢定時，你可以額外支付不超過血統等級/點的恩賜點，每以此法支付1點恩賜點，便會使你在進行該次檢定時獲得1DP內在加值，這無需動作。</li>
</ul>


## C 級

**屬性**：操控+3、耐力+3

**技能樹**：開啓血祭支配者C級技能樹

**特性**：血祭適宜體（雙特性）

**特殊**：無

**其他標籤**

**血祭適宜體**：你獲得1點再生。你身體所有部位（包括但不限於骨頭，器官，大腦等）都可以視同肢體來被再生點數再生，當你通過再生點數再生肢體時，所需的時間單位由小時降低至分鐘。


## B 級

**屬性**：操控+4、耐力+4

**技能樹**：開啓血祭支配者B級技能樹

**特性**：提升-微操、疤痕之體（雙特性）

**特殊**：無

**描述**

<ul>
<li>無數次的獻祭，你的身體充滿了傷疤，但這傷疤的痛苦也讓你的操控更加精準。</li>
<li>提升-微操：當你使用操控代替力量作爲關鍵屬性進行近戰白刃攻擊檢定時，你還可以使用操控代替力量作爲關鍵屬性計算該次傷害上限。</li>
</ul>

**其他標籤**

**疤痕之體**：你獲得等同於你耐力值三分之一的劇痛點數，該劇痛點數可與其他劇痛點數疊加，持續時間爲永久，無法以任何方式消除，並且其帶來的影響不可以任何方式避免。同時，你在進行任意一次檢定時，可以支付2點恩賜點，使該次檢定獲得等同於你操控值的表現加值。


## A 級

**屬性**：操控+6、耐力+6

**技能樹**：無

**特性**：血祭場域（三特性）、 血色連鎖

**特殊**：由於沒有技能樹，額外獲得一個特性。

**其他標籤**

**血祭場域**：每當你消耗恩賜點時，你便會在所有檢定與防禦上獲得等同於該次消耗的恩賜點\*1點褻瀆加值，該褻瀆加值可與本血統提供的其他褻瀆加值疊加計算，持續一個場景，你最多隻能以此法獲得不超過自身當前恩賜點數額的褻瀆加值。

**血色連鎖**：每當你使用本血統技能樹下的能力殺死任意一個目標後，你可以立即得知對方在血緣上9代以內的族親，之後你可以立刻選擇其族親中的一名單位，並施展本血統技能樹下任意一項你已掌握的能力對其進行一次攻擊，該次攻擊視作你能夠對其精確定位且具備視野線，同時射程與觸及範圍無限大，這無須動作，是一個 A 級因果律效果，這意味着如果被你以此法殺死或攻擊的目標能夠免疫S級因果律效果，則本特性無法生效。


## S 級

**屬性**：操控+8、耐力+8、感知+8

**技能樹**：無

**特性**：提升-敗血、獨目（三特性）

**特殊**：由於沒有技能樹，額外獲得一個特性。

**描述**

<ul>
<li>你向偉大的存在獻祭了一隻眼球，現在你剩餘的眼球獲得了奇異的力量。</li>
<li>提升-敗血：當你施展本血統技能樹下的能力時，若你通過該能力成功對目標造成傷害，則額外對目標造成等同於你該次攻擊傷害值的耐力傷害，目標以強韌豁免，之後你獲得等同於目標因此承受的耐力傷害一半點恩賜點，若該次能力造成了複數傷害，則選擇對其中一個目標造成的耐力傷害獲得恩賜點。</li>
</ul>

**其他標籤**

**獨目**

<ul>
<li>你不可避免地隨機失去一隻眼睛，並且失去的眼睛無法以任何方式恢復，同時你的視距最終值減半。</li>
<li>當你親眼目睹（這意味着你需要對該次攻擊擁有視野線）任何一次持續時間爲立即的攻擊時（包括不限於使用槍械進行的遠程攻擊，能量武器發出的射線，施展法術發射的火球等，具體可由ST裁定），你可以 無視其反偵測等級 立刻對該次攻擊的施展者精確定位，持續1輪，這是一個S級因果律能力，這意味着如果對方能夠免疫S級因果律效果則你無法通過本能力對其進行定位。</li>
<li>當你施展本血統技能樹下的能力對其他目標進行攻擊時，若你能夠對其精確定位，則你該次攻擊的射程與觸及範圍視作無限大。</li>
</ul>
