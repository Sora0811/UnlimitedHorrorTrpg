# 夜之君血統

> 來源：`資源/血統/黑暗生物/夜之君`

**本質**：魔幻本質

**前提**：人類。

**總描述**：經與妖魔的君王「夜之君」戰鬥結束後，人類終於迎來了勝利。然而，在「夜之君」即將消散之際，他撒向四方的污穢之血卻種下了禍根。凡接觸到那藍色血液之人的性質都將改變，變成稱之爲「邪妖」，會奪走人們夜晚的怪物。自此之後，當陽光灑落地面時，就是人們活動的時間，而當夜幕降臨之際，邪妖蠢動，人們無法安眠入睡。不知從何時起，此地就有了「無夜國度」之稱。

## D 級　蒼血半妖

**屬性**：決心 +2 ，風度 +2

**能量池**：妖力

**技能樹**：無

**特性**：超凡恢復，蒼血半妖（正負特性）、純粹之血（正負特性）、妖魔技能、 啜飲蒼血

**特殊**：因爲沒有技能樹，額外獲得1個特性。

**描述**：一名因沾染藍色血液得到吸血詛咒之力的少女，爲了無夜國度中擔驚受怕的人民以及一名被當作夜之祭品的少女，展開了她賭上性命在夜晚中與無數妖魔全力以赴的戰鬥。

**其他標籤**

**超凡恢復**：你現在可以休息長休息一半的時間就達到長休息的效果，或着是進入假寐狀態長休息，在這狀態時妳雖然是睡眠，但不會因爲睡眠陷入無助狀態。

**蒼血半妖**：你不再是一名人類，而是被夜之君血液所侵蝕的半妖。你變成黑暗生物，並且壽命延長到 300 年，並不會因爲時間更迭而衰老。

**純粹之血**：蒼之血是排異的血，唯有人類才能接受，其力量的根源倚仗血液流動。因此不能接受科技本質改造，且兌換後也無法進行增加肢體相關的兌換。但也因此蒼之血給你帶來 D 級的免疫變形。

**啜飲蒼血**：每當看見一個死亡不超過 5 分鐘的、使用妖力的生物屍體，你可以上前飲用血液，能夠飲用的額度最高等於對方的體積，每因此飲用一點恢復等於對方最高支線的妖力。

**妖魔技能**：你現在可以使用和學習相當於血統等級的妖力通用技能。


## C 級　初步覺醒

**屬性**：決心 +3 ，風度 +3

**技能樹**：開啓蒼血半妖 C 級技能樹

**特性**：高速復原、隱藏血脈

**特殊**：無

**描述**：在永無止盡的斬殺和被斬殺中，蒼藍的血淌滿了少女的身軀，伸出細舌打轉將噴灑到脣旁的蒼血入喉，那腥臭的味道甘美異常。

**其他標籤**

**高速復原**：初步覺醒的血脈讓你的身軀遠比一般的人類還要堅韌。你獲得1點再生。

**隱藏血脈**：人們總是會敬畏和恐懼異己，儘管在暗夜中你爲他們而戰，但只有隱藏好這些才能在白日享受難得的愜意。除非你主動暴露或是遭到檢測，否則單從外觀上無法看出你是黑暗生物。同時，當你因黑暗生物特性而受到神聖傷害提升一級時，你可以將等於傳奇風度 \*3點的神聖傷害不提升 一級，同時你獲得黑暗視覺。
