# 血統

> 來源：`資源/血統/黑暗生物/復仇死者`

**本質**：特異本質

**前提**：不死生物，或被隊友復活過

## D 級

**屬性**：力量+2，感知+2，決心+2

**能量池**：無

**技能樹**：無

**特性**：歸來者（三負特性），復仇死者（三特性），屠魔俠（三特性）

**特殊**：由於沒有技能樹，額外獲得1個特性，由於沒有能量池，額外獲得2點屬性,

**其他標籤**

**歸來者**：你睡眠與長休息時間延長一半才能將狀態回滿，你每天自動失去1點意志力。當你意志力歸0或者你生命值被惡性填滿時，你的復仇死者核心會佔據你的身體，你將不可避免的立即死亡，屍體上會誕生一個混骸鬼，獲得混骸鬼特性，被視爲喪屍，只要這個喪屍存在，你就不可以復活。你的任何死亡觸發的能力，在混骸鬼死亡時觸發。混骸鬼由主神控制，不再視爲輪迴隊員。

**復仇死者**：你在面對不死生物時，你的所有相關檢定獲得血統等級/點附加成功。

**屠魔俠**：你獲得輪迴隊專長：除魔獵人。


## C 級

**屬性**：力量+3，決心+3

**技能樹**：無

**特性**：阿尼瑪・核，黑夜夢魔，白晝黎明

**特殊**：由於沒有技能樹，額外獲得1個特性

**其他標籤**

**阿尼瑪・核**：被你殺死的單位無法變成不死生物，被你殺死的不死生物無法復活，這是一個C級詛咒效果。

**黑夜夢魔**：取出你的心臟作爲祭器，你花費一個整輪動作可以吞噬觸及範圍內的一個完整的屍體，屍體體積不小於5,每吞噬一個屍體，你都可以將一點生命值轉爲完好。

**白晝黎明**：每天白晝開始時，你會回覆1點意志力並且你可以將你的所有生命值回覆1級（惡性――嚴重――衝擊――完好），額外的若太陽依然沒有升起，該效果不生效（若在某些星球或者宇宙上，沒有太陽，則本效果也不生效）。


## B 級

**屬性**：力量+4，決心+4

**技能樹**：無

**特性**：復仇死者、地獄犬與斯特里克斯、救世俠、誅邪俠

**特殊**：由於沒有技能樹，額外獲得1個特性

**其他標籤**

**復仇死者**：你獲得不死生物特性。

**地獄犬與斯特里克斯**：你獲得一隻地獄犬或者一隻烏鴉，二選一，一旦選擇不可更改，它們是不死生物，烏鴉平常寄居在你的喉嚨中，地獄犬寄居在你的腹中，他們分別具有以下屬性。

**斯特里克斯**：具有你的全部心智系屬性與互動系屬性，生理屬性全部爲5，體積1，天防2，調查，生存技能8，可用相當於你基礎移動速度的3倍速度飛行，機動性完美，與你共享視野，沒有標準動作，每輪兩個移動動作，你可以與烏鴉進行心靈交流。

**刻耳柏洛斯**

<ul>
<li>具有你的全部生理屬性與互動系屬性，心智屬性全部爲5，體積2，天防2，肉搏技能8，肉搏技能全專業，陸行速度相當於你基礎移動速度的兩倍，進行肉搏攻擊時，每將對方一點生命值變爲惡性，自身一點生命值可以變爲完好。</li>
<li>斯特里克斯或者刻耳柏洛斯如果死亡，你可以在一個不小於5的完成屍體上使其復活，這需要一個整輪動作。</li>
</ul>

**救世俠**：以你的心臟爲祭器，放置於屍體周圍，只要祭器存在，你周圍模糊範圍內的屍體都會燃起淡金色的火焰，這火焰不會擴散，可以燃燒24小時，在火焰燃燒期間，死者的靈魂會直接顯現，這些靈魂可以如同活着的時候進行溝通以及接觸，火焰燃燒後，這些屍體不會變爲不死生物。

**誅邪俠**：在陽光下纔可以使用，以一個標準動作，對自己造成5點惡性傷害，你取出你自己的心臟，對你可以看到的任意一單位造成詛咒效果，這是一個B級詛咒，持續時間爲一場恐怖片。


### 詛咒效果因目標類型不同而不同：

**其他標籤**

**白晝黎明**：每日6點到8點，白晝開始時，你的狀態會恢復到完美狀態，額外的6-8點太陽依然沒有升起，該效果不生效。


**正文**

當目標爲不死生物時，目標會有一種灼燒的感覺，感官上會如同陽光直射，天生防禦每天降低1點，生命值上限降低相當於你傳奇決心+傳奇感知/點，若因此歸0則直接灰飛煙滅。

當目標爲活物時，目標會感覺到自己漸漸變得枯萎和蒼白，目標可強韌豁免，DC爲你的決心或者感知取低/點，若失敗，他的面部和皮膚會隨着醜陋的皺紋和裂縫的出現而迅速老化，受術者天生防禦每天降低1點，每天受到相當於你傳奇決心+傳奇感知/點的褻瀆嚴重傷害。

受術者可以立即獲知詛咒的相關效果，並且直接感受到你的位置，同時其會在睡夢中夢到施術者的相貌。

## A 級

**屬性**

<ul>
<li>力量+6 決心+6</li>
<li>繼承復仇死者死亡時，所有屬性技能。</li>
</ul>

**技能樹**：無

**特性**：復仇死者之夜、爆誕、再生俠、破曉魂歸

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得1個特性</li>
<li>混骸鬼</li>
</ul>

**本質**：特異本質

**其他標籤**

**復仇死者之夜**：你現在失去的不死生物特性中的負面效果。

**爆誕**：陽光可以成爲你的助力，虛假生命生效的時間段內，只要你沐浴陽光，便可以獲得4點再生。

**再生俠**：每場恐怖片相當於你傳奇決心/次，但是每場景只能使用一次，你可以免疫一次傷害，並免疫本次傷害帶來的一切效果，若爲AOE傷害，則你只免疫你自己的。

**破曉魂歸**：每日六點到八點，白晝開始時，以十具屍體爲儀式材料，骰一個百面骰，骰出1-5時，可以將10個屍體變爲聽命與你的喪屍，骰出6-94時，可製造一個存在一天的喪屍，骰出95-100時，儀式失敗，不會有任何變化。

**奇美拉**：以一個整輪動作，吞噬一個體積小於自己的無助的單位，回覆那單位生命值的生命值。

**巨人觀**：體積增長每血統等級兩點，但天生防禦減少血統等級兩點。

**續魂再結**：獲得復仇死者血統等級\*1的再生點數
