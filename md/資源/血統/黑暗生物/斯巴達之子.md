# 斯巴達之子(血統)

> 來源：`資源/血統/黑暗生物/斯巴達之子`

**本質**：魔幻本質

**作者**：堇色昔年

**總描述**

<ul>
<li>詳情請玩家購買鬼泣系列遊戲進行遊玩了解。本血統意在將斯巴達之子這一系列中“力量源於信念”的主題展現給無限的輪迴者們。</li>
<li>獲得本血統後，本血統的魔力顏色取決於角色戰鬥風格，角色可以自選一種顏色作爲自身魔力的顏色，此後在使用斯巴達之子相關技能時產生的光效爲角色所選顏色。</li>
</ul>

## D 級

**價格**：D+600

**屬性**：耐力+2，決心+2

**能量池**：魔力

**技能樹**：斯巴達之子D級技能樹

**特性**：黑暗生物，斯巴達之子（負特性），刃之魔人（三特性），鋼之魂

**特殊**：無

**描述**：身爲斯巴達之子即使角色的父親拯救了人界，但他惡魔的身份同樣不被人忽視即使只是繼承了他們血脈的角色。 黑暗生物：角色成爲黑暗生物。 斯巴達之子：斯巴達之子不被神所接受，角色不能強化帶有信仰導向的能力。 刃之魔人：角色的白刃技能中每擁有一個武器種類的專業，則使用該白刃技能的對應專業時，專業加值增加1點，增加的DP上限爲血統等級\*2點。 鋼之魂：角色在使用意志力的基礎用法爲行動增加DP（或增加防禦）時，額外獲得2DP完美加值。

**價格**：D+600

<li>這條手臂作爲天生武器的武器傷害增加血統等級\*1L，破甲增加2點，並獲得【魔法】【格擋】特性。角色可以用它正常影響虛體與靈體，使用該手臂進行格擋時，體積視爲3點。 首度覺醒</li>

**研發**：支付24XP進行研發，之後角色的肉體獲得（傳奇耐力-1）點硬度。 二次研發：支付36XP進行研發，之後角色免疫多次攻擊減值同時角色免疫特殊部位攻擊造成的影響。

**價格**：D+500

**動作**：移動動作

**能耗**：1

**射程**：接觸

**目標**：一件武器

**範圍**：無

**持續**：立即

</ul>

**價格**：D+500

### 渴望魔力

**前提**：惡魔之腕

**價格**：D+1000

**動作**：被動

**描述**：它在呼喚着，什麼？

**效果**

<ul>
<li>當這一技能生效時，角色的惡魔之腕上手掌和白色鱗片部分會以一定頻率閃爍出淡淡的白色光芒。</li>
<li>角色可以將一件具有【魔法】特性的武器儲存在惡魔之腕中，取出和儲存是一個反射/迅捷動作。只要角色持握或是儲存這把武器，角色的魔力池上限就增加該武器支線等級\*5點。</li>
</ul>

**研發**

<ul>
<li>當角色的血統等級到達C級時，支付24XP進行研發，之後當角色的敏感範圍感內存在D級及以上魔法本質的物品或生物時，角色能對它模糊定位，這是一個等同於血統等級的魔法本質偵測能力。</li>
<li>當角色的血統等級到達B級時，支付36XP，本能力可以進行精確定位。</li>
</ul>

**價格**：D+1000

</ul>

**價格**：C+1200

**其他標籤**
