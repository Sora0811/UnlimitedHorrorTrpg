# 日本妖怪怪談―「雪女」―血統

> 來源：`資源/血統/黑暗生物/妖怪/雪女`

**本質**：魔幻本質

**前提**：女性限定，並且擁有「嫉妒」「縱慾」「懶惰」這三個惡德中的一種。

**描述**

<ul>
<li>傳說是被愛人遺棄在雪山中的女子哦。隱於雪山的風雪中，在傳說中，有着美豔外表與賢惠的性格的妖怪，但對違背誓言之人也毫不留情……大抵如是。</li>
<li>「首先是愛意。就像那些老套的公主小說裏面寫的，愛，是距離恨最近的。既然愛那麼深，那麼現在就試着去恨他，這不是很簡單的事嗎？殺了他，把他的身體留在雪山裏，把他的靈魂喫進喉嚨裏，這樣就永遠都在一起了。愛他的你做不到，那就讓恨他的你來做。」</li>
<li>……啊？什麼啊？這什麼玩意啊？</li>
</ul>

## D 級　/ 雪童子言爲霜雹欲降

**屬性**：風度 +2 ，耐力 +2

**能量池**：妖力

**特性**：使役雪山而有別人者（雙特性），雪之化身（雙特性），妖魔技能，黑暗生物（負特性），本土的古代妖怪（負特性）

**技能樹**：無

**特殊**：由於沒有技能，額外獲得 1 個特性

**其他標籤**

**使役雪山而有別人者**

<ul>
<li>“……善於操控風雪。”</li>
<li>花費 1 點妖力，雪女獲得一個新的天生武器，即是有如臂使的暴風雪。這個天生武器如同一般的任何天生武器那樣被使用，比如掌或者踢擊，這使得你可以使用該天生武器應用某些肉搏招式和武學，但是這個天生武器無法被其他增強天生武器類的能力加強，包括但不限於武器：拳套，戒指，專長： KONGFU ，稱號：武鬥家，能量池：氣操縱等。這個天生武器的傷害爲 2+ 傳奇風度/L，，並且視爲【能量武器】，造成寒冷傷害，使用這個天生武器攻擊時，只能以風度作爲這次攻擊的關鍵屬性。這是一個魔幻本質的長效類法術，因此會放出法術靈光以被某些能力偵測，這時這陣暴風雪的等級視爲 D 級；但在任何能夠抑制這陣暴風雪的能力前，這陣暴風雪的等級爲雪女的血統等級。雪女可以用一個迅捷動作來散去或者聚集暴風雪，來使用或者隱藏這個天生武器。</li>
</ul>

**雪之化身**：人物雪女的部分明朗起來，毛髮的色澤逐漸接近流銀般，而皮膚則華麗如同初雪，這使雪女獲得等同血統等級的傾城之貌專長。無論是否調用暴風雪，雪女的身周的溫度始終會比常溫更低，這讓雪女免疫低溫環境帶來的影響，同時高溫環境帶來的影響對雪女翻倍，並且雪女獲得 1 點寒冰抗力。

**妖魔技能**：你現在可以使用和學習相當於血統等級的妖力通用技能。

**本土的古代妖怪**：選擇雪女血統後，也隨之無法再強化或使用任何具有科技本質的資源，而如果已經有類似強化，則無法選擇本血統。同時，雪女作爲最盛傳的妖怪之一，本能地排斥任何科幻本質的改造類強化。


## C 級　/ 霜雪若至則殘櫻將死

**屬性**：風度 +3 ，耐力 +3

**特性**：永遠留下的方法（雙特性），雪之化身

**技能樹**：無

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得 1 個特性</li>
<li>永遠留下的方法（凍住，不許走！）：“……會與癡迷她的容貌的男子接吻，那男子的身體會化作冰鮮，而靈魂會被她吞噬。”</li>
<li>雪女如果以暴風雪作爲天生武器進行攻擊檢定，若成功造成傷害，則對目標額外造成相當於傷害值的凍結點數，強韌豁免，可以疊加，同時每 15 分鐘的短休息就能再豁免並消減這個異常點數一次，這個效果檢定上這會是個詛咒效果，此外，如果希望的話，單純的不造成傷害的親密接觸（接吻以上）也能造成如此的效果，此時造成的「冰凍」點數爲每血統等級 3 點。</li>
</ul>

**其他標籤**

**雪之化身**：雪女的冰霜抗力提升至 2 點，同時若其處於雪中，或者溫度低於 0 度的環境下，獲得 1 點快速醫療，並且從現在開始，當雪女受到火焰傷害時，這些傷害對雪女全部轉化爲惡性。


## B 級　/ 山愈高則積雪愈深

**特性**：……情念也愈加讓人窒息（雙特性），雪之化身（雙特性）

**技能樹**：無

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得 1 個特性</li>
<li>……情念也愈加讓人窒息：“……成年之後，雪女的身邊會常伴着暴風雪。”</li>
<li>雪女在使用暴風雪作爲天生武器攻擊時，獲得接觸攻擊，並且可以以風度代替力量決定肉搏攻擊的傷害上限。</li>
</ul>

**其他標籤**

**雪之化身**：這個等級的雪女已經完全地化身爲暴風雪，雪女獲得敏感範圍的盲視，冰霜抗力提升至 4 點，並且其每有 1 點傳奇風度，則可以將相當於自身敏感範圍內的溫度下降 1 級。


**正文**

風度 +4 ，耐力 +4

## A 級　/ 越後國一樵夫口不能述事

**屬性**：風度 +6 ，耐力 +6

**技能樹**：無

**特性**：冬日瀧上三尺冰寒（三特性），雪之化身

**特殊**：由於沒有技能樹，額外獲得 1 個特性

**其他標籤**

**冬日瀧上三尺冰寒**

<ul>
<li>“……那之後，雪女就會融化在愛人的懷抱裏……”</li>
<li>雪女化身爲暴風雪，此時雪女的暴風雪觸及範圍變爲你的敏感範圍，並且此時雪女免疫單體傷害，只有範圍攻擊命中暴風雪時，纔會對雪女造成傷害。並且雪女可以以一個迅捷動作在敏感範圍內自由行動，這視爲某種瞬間移動的能力。這可能使雪女漂浮在空中，也可能使雪女出現在某人懷中……</li>
</ul>

**雪之化身**：你的冰霜抗力提升至 8 點。


## S 級　/ 雪山姬

**屬性**：風度 +8 ，耐力 +8 ，決心 +8

**特性**：易折易斷易碎易化（雙特性），雪之化身（雙特性）

**技能樹**：無

**特殊**：由於沒有技能樹，額外獲得 1 個特性

**其他標籤**

**易折易斷易碎易化**

<ul>
<li>“……而作爲人類的她，會在融化的雪水中重生。”</li>
<li>一個場景一次，以一個反射動作將先攻順序安排至現在先攻序列任意一個新的位置，但是這不會實際改變你的先攻數值，並且透支下一次的回合中的所有動作，在此時立刻獲得一個回合的動作（由於你的迅捷動作已經被反射動作消耗，所以只有移動動作和標準動作），但這會使你下一個回合的先攻位置變回之前的位置，同時在提前的這一回合結束之後，並且在正常到達你被跳過的那個回合之前被視爲無助。</li>
<li>當雪女處於暴風雪中時，除火焰傷害之外受到的全部傷害下降一級。</li>
</ul>

**雪之化身**：你現在免疫冰霜傷害。並且當你死亡時，若你處於有冰雪以及低溫環境中，在 1D10 天后你可以完全復活。（前提是在你復活之前，這些冰霜和低溫環境沒有消失）。
