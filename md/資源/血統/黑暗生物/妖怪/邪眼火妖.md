# D 級

> 來源：`資源/血統/黑暗生物/妖怪/邪眼火妖`

**屬性**：感知 +2 耐力 +1 風度 +2

**特性**：邪眼（雙特性），妖魔技能，忌子（負特性）

**技能樹**：無

**特殊**：由於沒有技能樹，額外獲得 1 點屬性

**本質**：特異本質

**描述**：此血統來源於幽遊白書位面的某個 S 級妖魔，僅從戰鬥力評價的話雖然在該位面也可以排上第一梯隊，但如果從個性（中二度）上，於無限世界的位面中也可名列前十，兌換後人物所有治療形式都會表現爲繃帶，不論治療噴霧或者法術都會留下明顯的可拆卸的綁在傷口上的布條，原因不明。

## C 級

**屬性**：耐力 +1 ，感知 +2 ，風度 +3

**特性**：邪眼全開，邪王炎殺煉獄焦（雙特性）

**技能樹**：無

**特殊**：由於沒有技能樹，額外獲得 1 個特性

**其他標籤**

**邪眼全開**

<ul>
<li>血統的增強讓你的邪眼也增加了，你睜開邪眼後，你的身上也會出現邪眼，算上你原有的眼睛，現在你有二十隻眼了。</li>
<li>你現在每次可以束縛的目標不再侷限於 1 個，而是範圍內所有你想束縛的目標。</li>
</ul>

**邪王炎殺煉獄焦**

<ul>
<li>邪王炎殺拳的技巧讓你能召喚火焰並控制，這時你還只能使用凡火。</li>
<li>你可以以一個迅捷動作花費 3 點妖力召喚火焰，你可以投擲它或者將其運用在近戰攻擊中。如果你使用投擲，則它的武器傷害爲 3L ，基礎射程 10 米，同時若成功造成傷害，則對目標造成等同於你造成傷害的燃燒點數；如果你使用在近戰攻擊中，則會令你的武器在命中時額外造成相當於你消耗的妖力值的火焰嚴重傷害，效果維持一個場景。</li>
</ul>


## B 級

**屬性**：耐力 +1 ，感知 +3 ，風度 +4

**技能樹**：無

**特性**：邪眼隱藏，分屍連斬（三特性）

**特殊**：由於沒有技能樹，額外獲得 1 個特性

**其他標籤**

**邪王炎殺劍**

<ul>
<li>你不需要武器，你的火焰就是無堅不摧的武器。</li>
<li>你可以用一個迅捷動作凝結火焰使它等同於某一類武器，從基礎冷兵器模板中選擇，以適用於你所擁有的任何針對一類武器的能力。你也可以用它增加武器的觸及範圍，上限爲你感知 \*1 米，炎殺劍的武器傷害爲 8L ，破甲 3 ，破魔 3. 擁有【魔法】【黑暗】特性。</li>
</ul>

**分屍連斬**

<ul>
<li>你全力驅動自己的身體，以難以想象的高速斬擊將對手切成屍塊。</li>
<li>以一個標準動作進行一次白刃攻擊，若你的攻擊對對手至少造成了 1 點傷害，你可以以這次攻擊 DP 的一半再度攻擊，以後每次再減少一半 DP （向下取整），直到剩餘 DP 爲 0 或者某次擲骰沒有獲得任何成功數爲止，這不視爲一次攻擊。</li>
</ul>


**其他標籤**

**能量場**：妖力

**邪眼**：你的額頭長出了一隻邪眼，你可以以迅捷動作控制它打開或關閉，張開邪眼每輪花費 1 點妖力。在邪眼睜開的時候，你只能束縛一個敵人。花費一個標準動作選擇一個你視線內的目標，你以風度 + 脅迫進行檢定，目標以意志豁免。造成失敗點的精神束縛，不可疊加。每次你只能束縛一個目標，，你亦可以一個反射動作進行束縛。

**忌子**

<ul>
<li>母體血統來源爲雪女卻天生擁有火焰之力，你被他人稱爲冰河忌子。</li>
<li>你現在成爲黑暗生物，但是現在你由於光明或黑暗生物帶來的弱點與你的實際情況相反，這意味着你雖然是黑暗生物卻不恐懼黑暗生物的弱點，而是恐懼光明生物的弱點，但你仍然被視作黑暗生物。例如，當你被帶有【光明】特性的武器攻擊時，不會受到【光明】特性帶來的額外傷害，但是會受到帶有【黑暗】特性武器造成的額外傷害，同時一個七夜仍可得知你是黑暗生物並進入退魔衝動中。同時，你依然無法與光明生物共存。</li>
</ul>

**妖魔技能**：你現在可以使用和學習相當於血統等級的妖力通用技能。
