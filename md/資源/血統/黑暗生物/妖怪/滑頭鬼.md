# 滑頭鬼

> 來源：`資源/血統/黑暗生物/妖怪/滑頭鬼`

**本質**

<ul>
<li>魔幻本質</li>
<li>滑頭鬼是映於鏡裏之花，浮於水中之月。也就是鏡花水月。是將夢幻具現化的妖怪。</li>
<li>日本民間傳說中的滑頭鬼：據說這種妖怪是妖怪的大首領。不過，他做的事可沒什麼領袖風範。傍晚時分，人人都忙得不可開交時，他便會不請自來，走進家裏，隨便坐在客廳喝茶。家裏人也會尋思這到底是哪位，但終究會因爲太忙而分心，未能看透他的真面目。這種妖怪的特徵就是專門會在這種時候出現，很善於鑽人心的空子。</li>
<li>他會走進富豪的大房子裏，拿起主人的菸斗吞雲吐霧，隨後又消失得無影無蹤，不夠細心的人便很難察覺。另外，也搞不清楚他到底會做些什麼事。他的外表有時像僧人，但更多時候更像商人，好似一個豪門大老爺一樣不緊不慢地踱着步。</li>
</ul>

## D 級

**屬性**：風度 +2 敏捷 +1 耐力 +1

**能量池**：妖力

**特性**：鏡花水月（雙特性）、畏、妖魔技能、黑暗生物（負特性）

**技能樹**：無

**特殊**：由於沒有技能樹，額外獲得 1 個特性

**其他標籤**

**鏡花水月**

<ul>
<li>滑頭鬼屬於幻系妖怪，所有招數是從水中映月的道理而得來，像是虛假，又像是真實，讓人無法辨認，如水中映月一般，映出來的如真是一般，可這是虛假的。</li>
<li>花費 1 點妖力，滑頭鬼以一個標準動作發動其作爲妖怪的本質，這是一個等同於血統等級的隱形能力，維持是一個迅捷動作，每輪花費 1 點妖力。</li>
</ul>

**畏**

<ul>
<li>身爲妖怪，讓人感到恐嚇、威嚴、或尊敬之念，是作爲妖怪的存在感。</li>
<li>當滑頭鬼與敵人發生基於妖力的對抗 ( 造成傷害、躲避攻擊、潛行成功 ... 等 ) 並獲勝時，給予對方等同於自身血統等級的無法豁免的恐懼點數，不會疊加。</li>
</ul>

**妖魔技能**：你現在可以使用和學習相當於血統等級的妖力通用技能。


## C 級

**屬性**：風度 +3 敏捷 +3 耐力 +2

**特性**：鏡花水月 ( 提升特性）、百鬼夜行

**技能樹**：無

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得 2 點屬性</li>
<li>鏡花水月 ( 提升特性）：鏡花水月的力量進一步提升，滑頭鬼在開啓鏡花水月時可以在任意檢定上獲得相當於血統等級的 DP 內在加值。</li>
</ul>

**其他標籤**

**百鬼夜行**

<ul>
<li>起初，百鬼夜行是個口耳相傳的傳說，最初記載已不可考。只知大約是在平安時代仿長安而建的平安京內不僅生活着人類，而且是個怨靈出沒、鬼怪橫行的世界。一旦黑暗來臨，蟄伏於各個角落的鬼怪，就在京都的大道上成羣結隊的遊行起來。它們毫不掩藏，恣意狂歡。這時候，如果哪個人無意中瞥到一眼，就會因受到詛咒無疾而終。</li>
<li>在滑頭鬼的敏感範圍內如果存在友方的黑暗生物，每有一隻則滑頭鬼與其他符合條件的單位在攻擊和防禦上各獲得 1DP 的環境加值，上限爲滑頭鬼血統等級的三倍。</li>
</ul>


## B 級

**屬性**：風度 +4 敏捷 +2 耐力 +2

**特性**：鬼憑（雙特性）、業 ( 鬼纏）（雙特性）

**技能樹**：無

**特殊**：由於沒有技能樹，額外獲得 1 個特性

**其他標籤**

**鬼憑**

<ul>
<li>歲月流逝，妖怪增加，不知覺的開始了妖怪間的地盤爭奪戰，因而進入畏的下一階段，即發揮自我特性的「畏」作爲攻擊方式 - 「鬼憑」。</li>
<li>滑頭鬼在進行攻擊或對抗檢定時，若目標身上有恐懼點數，則該檢定獲得等同於該目標身上恐懼點數總和 \*2 的士氣加值（哪怕其恐懼點數的源頭不是你）。</li>
<li>業 ( 鬼纏）：妖怪首領與百鬼夜行的力量關聯，又稱「御業」，只有百鬼夜行統領才能使用的「畏」。當百鬼夜行的首領變得更加強悍，獲得百鬼夜行羣衆的強烈信賴與羈絆時，百鬼夜行的力量就會回到妖怪首領身上，成爲妖怪首領的力量來源。將此種「畏」注入自己體內組合而成的奧義，相互交疊的「畏」會發揮出數倍的力量，又稱作「鬼纏」。</li>
<li>滑頭鬼能和受其百鬼夜行影響的一名同伴聯手進行攻擊，該次攻擊的發起方可以是滑頭鬼也可以是同伴，主動方可以發動一次攻擊，該次攻擊檢定獲得聯合方對應的屬性和技能作爲表現加值，同時傷害上限也獲得聯合方的主屬性和技能對應提升（若槍械類那些無需屬性和技能決定的傷害上限則不獲得提升）。主動方除了原本的攻擊動作外需要額外消耗一個迅捷動作而被動方需要消耗一個反射動作。</li>
</ul>
