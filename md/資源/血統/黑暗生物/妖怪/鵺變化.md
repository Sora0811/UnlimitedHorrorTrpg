# 鵺變化

> 來源：`資源/血統/黑暗生物/妖怪/鵺變化`

**本質**：魔幻本質

**描述**

<ul>
<li>鵺是非常不可思議的妖怪。每次都被人傳說爲不同的姿態。在某個傳說中，它的樣貌是：頭是猿、體是狸、手腳是虎、尾是蛇。在另一個傳說中，樣貌是：頭是貓、體是雞、尾是蛇。</li>
<li>可是那些傳說畢竟是傳說，沒有任何一個是準確的。或者說，它從未在人們面前出現過。它從遠處看着人們害怕着、編造着各種關於自己的傳說。這便是它每天非做不可的事。</li>
</ul>

## D 級

**屬性**：敏捷 +2 ，耐力 +1 ，感知 +1

**能量池**：妖力

**特性**：無法感知，正體不明，妖魔技能，不明處的襲擊，黑暗生物（負特性）

**技能樹**：無

**特殊**：由於沒有技能樹，額外增加 1 個特性

**其他標籤**

**無法感知**：鵺的恐怖便在於別人對其的外貌根本無從所知。這意味着目標雖然可以如常看到鵺，但是隻有鵺在目標敏感範圍內且爲感知 \*5 米 + 傳奇感知 \*10 米以內，才視爲其處於目標的敏感範圍，否則哪怕鵺在目標的敏感範圍，則視爲其一直處於該目標的模糊範圍內。

**正體不明**：當其處於你的敏感範圍內，你也無法辨識鵺的長相，哪怕用拍照，掃描之類的技術得出的照片，其長相也是一團黑霧或者馬賽克。若你處於目標的敏感範圍內，則目標每輪都可以花費一個迅捷動作對你進行辨識，其進行感知 + 調查（偵查）檢定對抗你的敏捷 + 隱藏檢定，若其成功，則其本場景內可以辨識你的長相。

**不明處的襲擊**：鵺能發出各種奇怪的聲響，讓人對它的攻擊點誤判，變成不知從何處發來的攻擊。當你處於目標的模糊範圍內時，若你的攻擊造成傷害，可以進行一次敏捷 + 躲藏檢定，目標意志豁免，若其失敗，則受到相當於你血統等級 / 點恐懼點數，無法疊加。

**妖魔技能**：你現在可以使用和學習相當於血統等級的妖力通用技能。


## C 級

**屬性**：敏捷 +3 ，耐力 +1 ，感知 +2

**特性**：不明飛行物，不明攻擊方式，黑霧迷蹤

**技能樹**：無

**特殊**：由於沒有技能樹，額外增加 1 個特性

**其他標籤**

**不明飛行物**：鵺有着一雙形狀根本不相同的翅膀，因此使人很容易錯認它的外形。你的躲藏檢定上獲得 1 點附加成功，同時你獲得相當於你基礎速度一半的良好飛行能力。

**不明攻擊方式**：鵺能夠通過波的扭曲，來實現遠距離的近戰攻擊。若你處於目標的模糊範圍內，並且目標沒有辨認你，針對該目標你的近戰攻擊觸及變爲你的血統等級 \*10 米。

**黑霧迷蹤**：鵺在黑霧裏能夠隱藏自己的身型，彷彿自己不存在一般，你每次攻擊時可以進行一個敏捷 + 隱藏對抗目標的感知 + 調查（偵查）檢定，若成功，則本次攻擊獲得 C 級措手不及。若成功造成措手不及，則“不明出的襲擊”中目標無法進行意志豁免。


## B 級

**屬性**：敏捷 +4 ，耐力 +3 ，感知 +4

**特性**：不明光束髮射，線與粒的變換，不明因子製造

**技能樹**：無

**特殊**：由於沒有技能樹，額外增加 3 點屬性

**其他標籤**

**不明光束髮射**：若 鵺攻擊沒有辨認自己的目標，則其攻擊看起來好像如同一道光束一般。該次攻擊獲得 8 點高速，並且可以進行連射攻擊， 就如它進行遠程槍械攻擊一樣。

**線與粒的變換**：鵺通過波的扭曲將光變爲一個個光彈。你消耗 X 點妖力，以一個標準動作，對你敏感範圍內所有沒有辨識你的目標造成範圍傷害。範圍傷害爲你的敏捷值，反射豁免。 X 爲你敏捷值的一半。

**不明因子製作**：鵺可以製作一些蛇狀的不明因子，它們在附在任何物品上後會讓物品變成另一種形狀，形狀一般爲人無法理解卻又認知的物體。比如漂浮的木頭附上不明因子後，就會變成小型 UFO 。消耗 3 點妖力，你可以製作一個不明因子。不明因子的移動速度與你相同，沒有任何戰鬥能力也無法負重，也沒有任何碰撞體積，沒有生命，無法被摧毀。你每輪可以花費一個自由動作控制不明因子靠近某個目標，每有一個不明因子進入目標的敏感範圍內，則你立即進行一次敏捷 + 躲藏檢定，目標意志豁免，若其失敗，則獲得 2 點可以疊加的恐懼點數，這些恐懼點數來源爲你，每個不明因子只能觸發一次本效果。你可以以迅捷動作收回所有的不明因子，每回收一個則你下一次攻擊檢定獲得 1DP 增強加值，不明因子的上限爲你的傳奇耐力 \*2 個。


## A 級

**屬性**：敏捷 +6 ，耐力 +4 ，感知 +6

**特性**：U?N?KNOWN ，黑霧下的幻想鄉，不明正體

**技能樹**：無

**特殊**：由於沒有技能樹，額外增加 4 點屬性

**其他標籤**

**光粒彈幕**：你現在現在你進行光束攻擊時，光束在攻擊完後不會繼續前進，而是分裂成粒子對範圍進行掃射，然後同一直線的粒子再聚集成光束前進。 B 級基礎上，在無法辨認狀態時，你進行完光束連射攻擊後，你可以再進行一次火力壓制，此時武器傷害視爲你敏捷的一半。

**U?N?KNOWN**：你成爲完全不明的存在。 D 級的“無法感動”中的感知範圍變爲感知 \*1 米 + 傳奇感知 \*2 米。針對無法辨識你的目標，你的防禦增加 8 點閃避加值。同時，當你攻擊無法辨識你的目標時，目標身上每針對你有 1 點恐懼點數，則你攻擊檢定獲得 1DP 增強加值。

**黑霧下的幻想鄉**：你可以花費 7 點妖力，黑霧將覆蓋整個戰場，你每有 1 點傳奇感知，黑霧的半徑擴展 1000 米。黑霧中視爲黑暗環境，黑暗視覺無法看破這片黑霧。在黑霧中，你獲得懸浮能力，你的移動方式變爲傳送。在你每次傳送後，原地將產生一個你的黑霧。任何對你的恐懼點超過他沉着一半的目標都會將其錯認爲你，並且無法找到你的真身，只有在他攻擊了那個黑霧之後纔會發現黑霧是假的，並且找到你的真身，這視爲一個 A 級反偵測能力。

**不明正體**：由於沒有人知道你的本來面目，所以你免疫等級不超過 A 級的詛咒和因果律效果 .
