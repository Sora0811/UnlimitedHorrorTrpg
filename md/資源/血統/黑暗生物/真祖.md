# 真祖

> 來源：`資源/血統/黑暗生物/真祖`

**本質**：特異本質

**描述**

<ul>
<li>行星本身即是一種存在，地球也不例外。</li>
<li>這顆被人類以『蓋亞』作爲認識的行星卻無法容忍人類的存在。</li>
<li>以確保自身的存在爲最優先事項的蓋亞認定人類爲自身生態系統中最危險的破壞性因素，卻由於沒有自己的代行者（ UO ）而無法與人類迴避自身破滅的統合意識阿賴耶識相抗。</li>
<li>近在咫尺的衛星――月球察覺到了蓋亞對於自身未來的擔憂，而向蓋亞發出了邀請。</li>
<li>“代替無法自由行動的你、就由我來守護你吧。”</li>
<li>蓋亞回應了月之王的請求，以其爲範本製造出自己的星球代行者――真祖</li>
</ul>

## D 級

**屬性**：風度 +2 耐力 +1 感知 +1

**能量池**：無

**技能樹**：無

**特性**：吸血種（三正一負），吸血衝動（負特性），階級論（三特性）

**特殊**：由於沒有能量池和技能樹，額外獲得 2 個特性

**其他標籤**

**吸血種**

<ul>
<li>真祖的存在本身是月之王的陰謀，他想借着身爲吸血種的自己的複製品，以生態入侵的方式佔領地球。雖然主神空間中的版本真祖並不具備創造衍體的能力，但作爲吸血種的特性仍然保留了下來。</li>
<li>真祖是黑暗生物，真祖在任意判定上都被視爲血族（諸如紫外線彈這樣的特效武器，始祖之血這樣的改造，血之曉之類的物品等）</li>
<li>與血族相類似，真祖是不朽的存在，成爲真祖之後人物的肉體不會再產生衰老，真祖免疫衰老影響。免疫D級疾病和毒素效果，真祖也不會因暴飲暴食而受到任何不利影響。</li>
<li>作爲吸血種，你天生武器的傷害獲得 1L 的提升，如果你尚未擁有以“齧咬”作爲專業的天生武器（牙齒），那麼你現在獲得傷害爲 1L 的以“齧咬”作爲專業的天生武器（這是天生武器傷害提升帶來的效果）。</li>
</ul>

**吸血衝動**

<ul>
<li>作爲吸血種，所有真祖對於鮮血都有着與生俱來的渴求，本來是最高等最純潔的受肉聖靈的他們，一旦接觸了血液就會墮落成爲惡魔。</li>
<li>真祖每個月的月初都必須進行一次意志判定，其最初的 DC 爲 2 ，每成功一次會使下一次判定的 DC+1 ，每失敗一次會使所有判定上都承受 -1 減值，這個減值可以無限累計。</li>
<li>真祖可以用長眠來封印自己的吸血衝動，只要一直保持睡眠，就無須進行意志判定。</li>
<li>但要解除這個減值只有一個辦法，那就是滿足自己的吸血衝動，滿足吸血衝動後減值清 0 ，意志判定的 DC 也回到最初的 2 。</li>
<li>作爲一次齧咬攻擊的一部分，只要造成了至少 1 點傷害（不能對自己），你就可以宣佈吸食對方的血液，從而進入『吸血衝動』的狀態。</li>
<li>在吸血衝動狀態下時，人物失去理智，本能的攻擊在場的一切生物。但你可以設定一些優先條件，例如優先攻擊在場的最強者，被吸血的對象又或者是最後攻擊被吸血的對象等等，需要 ST 的認可。</li>
<li>在吸血衝動狀態下，你每一輪都可以以自由動作進行一次 DC=5 的意志檢定，若成功，則可以主動解除。當人物失去意識時自動解除。當人物的視線中沒有任何生物時自動解除。</li>
<li>無論如何，吸血衝動結束後 1 分鐘內，所有檢定失去 4DP 。</li>
<li>在吸血衝動中，你獲得力量 +1 ，風度 +1 ，你的牙和指甲會略微變長，這使你的天生武器傷害提升 1L 。</li>
</ul>

**階級論**

<ul>
<li>作爲星球的代行者，從存在階級上而言，真祖處於自然的高位，因此可以有限的命令自然，通過操縱自然的概率來使自己所想之事成爲現實，這個能力也被稱爲『空想具現化』。</li>
<li>在進行任何對抗性判定時，真祖獲得傳奇風度的 DP 環境加值。</li>
<li>以一個標準動作支付 1 點意志力，真祖可以令敏感視線範圍內某處的環境發生小幅度變化，空氣凝聚壓縮化爲風刃或空氣錘，溫度驟升或驟降形成灼燒和寒冷，光線聚焦成爲光能，電子聚合形成電擊等等。這是一個針對單體的攻擊，使用風度 + 交涉（說服） + 武器傷害來進行遠程攻擊檢定，武器傷害等於傳奇風度，傷害上限爲武器傷害 \*3. 因爲可以直接在對手身邊成形，因而視同具有 8 點高速優勢，造成的傷害，程度可以在嚴重和衝擊中選擇，現階段只能造成物理傷害，可以在穿刺和鈍擊中選擇，雖然空想具現化本身是個特異能力，但造成的傷害具有自然本質，因此絕對無法獲得諸如【魔法】或攻擊靈體之類的特性。</li>
</ul>


## C 級

**屬性**：風度 +3 耐力 +2 感知 +1

**技能樹**：無

**特性**：階級論（三特性）

**特殊**：沒有技能樹，額外獲得一個特性

**其他標籤**

**階級論**

<ul>
<li>現在你自 D 級階級論中獲得環境加值延伸到一切判定上，並在防禦上獲得同一加值。</li>
<li>以一個標準動作支付 3 點意志力，真祖可以以自己的想象創造出單個無生命的物體。此物不能有任何可移動部分也不能有多種原料組成，也不能經過人爲加工，它總是以方形或圓形出現（因此具現出一根鋼棍是可能的，但一把劍是不可能的）。它會出現在你手中，如果拿不下則是面前，至多爲 1 立方米的立方形大小，最後，真祖只能具現自然本質的事物。黃金可以正常具現，但是鈔票不行，精金也一樣。被真祖具現的事物持續時間爲永久。</li>
<li>並且你現在使用 D 級的階級論除了物理傷害之外，還可以造成純能量傷害，火焰傷害，寒冰傷害以及電擊傷害。</li>
</ul>


## B 級

**屬性**：風度 +4 耐力 +3 感知 +1

**技能樹**：無

**特性**：階級論（雙特性），月之民（雙特性）

**特殊**：沒有技能樹，額外獲得一個特性

**其他標籤**

**階級論**

<ul>
<li>現在空想具現化的範圍會變的更大，對於 D 級的階級論而言，你可以在敏感視線範圍內選擇不超過風度個 1 立方米大小的範圍內爆發，這些格可以是連續的也可以不是，但彼此不會重疊。範圍傷害爲武器傷害 \*3. 目標反射豁免，你如常進行攻擊檢定，每有 1 個成功數，目標的範圍豁免失去 1DP 。</li>
<li>並且你現在還可以選擇造成音波傷害，腐蝕傷害。</li>
</ul>

**月之民**：真祖免疫任意來源的 B 級及以下的疾病和毒素效果，並且在滿月之下，真祖能在風度和力量屬性上各獲得 3 點環境加值。
