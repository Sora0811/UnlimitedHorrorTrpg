# 影族

> 來源：`資源/血統/黑暗生物/影族`

**本質**：魔幻本質

**描述**：終日生活在黑暗之中的種族，與陰影爲伴。有人稱他們爲影魔，影妖，或者其它的什麼，但實際上他們只是純粹的黑暗血統，與善良和邪惡無關。

## D 級

**屬性**：智力 +2 ，感知 +1 ，敏捷 +1 ，沉着 +1

**能量池**：魔力

**特性**：黑暗生物（負特性），光線敏感（正負特性），暗影視覺，魔力池強化，魔法體質

**技能樹**：無

**特殊**：由於沒有技能樹，額外獲得 1 點屬性。

**其他標籤**

**黑暗生物**：你獲得黑暗生物特性。

**光線敏感**：當你位於昏暗或黑暗環境下時，你在躲藏技能相關檢定上獲得等同於血統等級的內在加值，反之你處於非昏暗或黑暗環境下時則在躲藏技能相關檢定上承受等同於血統等級的內在減值。

**暗影視覺**：你獲得黑暗視覺。

**魔力池強化**：你的魔力池上限增加5點。

**魔法體質**：你獲得等同於你血統等級的施法等級，以及學習和購買通用法術的能力。


## C 級

**屬性**：智力 +3 ，感知 +2 ，沉着 +2 ，敏捷 +1

**特性**：光線敏感（雙負特性），陰影生物（雙特性），暗影直覺，提升 - 魔力池強化

**技能樹**：無

**描述**：只要你身處非充分照明的區域，別人就看不清你的表情和動作。

**特殊**：由於沒有技能樹，額外獲得 2 點屬性。

**其他標籤**

**光線敏感**：你每次承受目眩點數時，該點數翻倍計算。當你位於非昏暗、黑暗環境下時，你在躲藏技能相關檢定上失去等同於你血統等級的成功數。

**陰影生物**：當你位於昏暗或黑暗環境下時，你在躲藏和掩飾技能相關檢定上獲得等同於你傳奇沉着與傳奇敏捷之和的內在加值。

**暗影直覺**

<ul>
<li>你獲得等同於你敏感範圍的盲感。</li>
<li>提升 - 魔力池強化：你的魔力池上限再增加1 0 點。</li>
</ul>


## B 級

**屬性**：智力 +4 ，感知 +2 ，沉着 +3 ，敏捷 +2

**特性**：提升 - 陰影生物，提升 - 暗影直覺，提升 - 魔力池強化

**技能樹**：無

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得 3 點屬性。</li>
<li>提升 - 陰影生物：當你位於昏暗或黑暗環境下時，你在躲藏和掩飾技能相關檢定上獲得等同於你血統等級的附加成功。</li>
<li>提升 - 暗影直覺：你的敏感感知範圍翻倍，這意味着你某些以敏感範圍定義的能力在範圍上同樣翻倍計算。</li>
<li>提升 - 魔力池強化：你的魔力池上限再增加2 0 點。</li>
</ul>

## A 級

**屬性**：智力 +6 ，感知 +2 ，沉着 +2 ，敏捷 +2

**特性**：提升 - 魔力池強化，提升 - 陰影生物，提升 - 暗影直覺，存在感降低

**技能樹**：無

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得 1 個特性。</li>
<li>提升 - 魔力池強化：你的魔力池上限再增加4 0 點。</li>
<li>提升 - 陰影生物：陰影生物特性帶來的所有加值與附加成功現在可以應用在你所有檢定中。</li>
<li>提升 - 暗影直覺：你獲得真實視覺。</li>
</ul>

**其他標籤**

**存在感降低**：只要你位於陰影中，除非你主動攻擊別人（包括但不限於威嚇，說服，給隊友上 BUFF ，給目標上 DEBUFF 等，具體可由 ST 裁定），否則別人不會主動攻擊你（如其射程內有你和另外一個目標，其會優先攻擊另外那個，但是這意味着你仍可能被範圍攻擊誤傷），這是一個 S 級影響心靈的能力。
