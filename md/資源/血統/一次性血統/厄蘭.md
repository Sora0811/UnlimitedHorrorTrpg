# 厄蘭（Elan）

> 來源：`資源/血統/一次性血統/厄蘭`

**本質**：特異本質

**價格**：C+1200

**總描述**

<ul>
<li>厄蘭並不是被生育出來的；而是被製造出來的。人類申請者將會被厄蘭理事會篩選。隨後他們將在幾個祕密的厄蘭領土接受一系列的靈能儀式；隨後他們就放棄了作爲人類的身體而具有了新的，靈能活力的存在。因此厄蘭並不是從生理上被製造的，而是通過一個只有厄蘭所知的儀式在靈能上被製造的。即使這樣他們的“孩子”也往往是完全發育的成年人。非人生物從來沒有被製造出來，也許因爲這個儀式僅僅對人類有效。</li>
<li>厄蘭就像原來的人類一樣具有適應性，能夠變通並且雄心勃勃。由於厄蘭恆遠的壽命有時會讓人產生極度糟糕的聯想--尤其是關於他們的起源――厄蘭對此表現出理所當然的牴觸情緒。在其他方面厄蘭表現出多樣的人格。</li>
<li>厄蘭站立時不到6英尺體重大約180磅，男性通常比女性要更高更重。因爲選擇厄蘭的候選者的理事會對於外表有自己的喜好，所以每一“代”都會有類似的特別的生理結構。現在的理事會更喜歡有蒼白膚色，紅色頭髮和年輕氣息的候選者。不過總體來說厄蘭在外表上就和人類一樣多變。厄蘭在着裝上會遵循她所居住地方的典型風俗（從而盡力混在人類中），包括使用特別的髮型，奇怪的服飾，紋身，在身體上穿孔或者類似的東西。</li>
</ul>

**屬性**：智力+3，沉着+3

**能量池**：無

**技能樹**：無

**特性**：無限制的生命跨度（雙特性）；天生異能；抗力；

**特殊**：由於沒有技能樹，額外獲得1個特性。一次性血統獲得2個特性。

**價格**：C+1200

**其他標籤**

**無限制的生命跨度**：角色現在免疫衰老，同時角色免疫C級的影響心靈效果。並且，現在角色可以進行4小時的冥想來取代8小時睡眠，這作爲一次長休息，獲得8小時睡眠可以帶來的全部好處。

**天生異能**

<ul>
<li>你獲得靈能能量池。</li>
<li>當你傳奇決心與傳奇沉着之和超過2點時，你可以可以學習和使用D級通用靈能。當你傳奇決心與傳奇沉着之和超過5 點時，你可以學習和使用C級通用靈能。當你傳奇決心與傳奇沉着之和超過8點時，你可以學習和使用B級通用靈能。當你傳奇決心與傳奇沉着之和超過12點時，你可以學習和使用A級通用靈能。當你傳奇決心與傳奇沉着之和超過20點時，你可以學習和使用S級通用靈能。你使用靈能時，無法進行增幅效果。</li>
</ul>

**抗力**：角色可以使用一個反射動作支付3點靈能，直到角色使用下一個動作之前，所有對抗檢定獲得6DP內在加值。

**減傷**：角色在受到傷害時，可以使用一個反射動作，每支付1點靈能，就抵消2點傷害，優先抵消最輕的傷害。這是一個傷害抵消能力，最多支付相當於角色傳奇決心與傳奇沉着取低/點，最低爲1。
