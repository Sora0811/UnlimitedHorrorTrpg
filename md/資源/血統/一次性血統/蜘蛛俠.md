# 蜘蛛俠強化

> 來源：`資源/血統/一次性血統/蜘蛛俠`

**本質**：特異本質

**價格**：B+3600

**屬性**：力量 +1 敏捷 +4 感知 +4 耐力 +2

**特性**：蜘蛛敏銳（雙特性），蛛絲運動，蛛絲（雙特性）

**特殊**

<ul>
<li>一次性血統，額外獲得兩個特性，由於沒有技能樹，額外獲得 3 點屬性</li>
<li>本血統視爲人類血統。</li>
</ul>

**價格**：B+3600

**其他標籤**

**蜘蛛敏銳**：蜘蛛俠的平衡器官大幅度增強，獲得敏感範圍內的顫動感知，以及免疫 B 級的措手不及，同時由於超凡的感官，蜘蛛俠免疫 8 點高速。

**蜘蛛運動**：蜘蛛俠獲得蛛行術，如蜘蛛一般在垂直表面上攀爬移動，甚至天花板上也可以。在這種情況下，蜘蛛俠必須騰出雙手來爬行。他獲得等同於基礎速度的攀爬速度，並且在垂直或水平表面（甚至是天花板頂下）爬時不需要進行運動檢定。使用此能力時防禦不會有減值。同時在非戰鬥相關的運動（平衡感）相關的檢定直接成功，

**蛛絲**

<ul>
<li>蜘蛛俠可從手腕處射出蛛絲。蛛絲可如捕網一般進行糾纏攻擊。蛛絲基礎射程與最大射程皆爲蜘蛛俠耐力 \*10 米。</li>
<li>蜘蛛俠可以用蛛絲進行遠程擒抱。</li>
<li>蜘蛛俠可以用蛛絲進行遠程捆綁，這變爲一個標準動作，並且目標並非必須處於無助或者自願狀態。</li>
<li>在進行捆綁檢定時，若對手當回合沒有掙脫，則蜘蛛俠每回合可以以一個標準動作進行加固，每次加固，對手的掙脫 DC 增加 3 點。</li>
<li>蜘蛛俠還可以利用蛛絲協助移動，在任何周圍有高大物體的地區，以一個移動動作，蜘蛛俠可以移動相當於基礎陸行速度 \*3 米的，無視困難地形影響，並且可如飛行一般到達高度不超過所在位置周圍 3 米內最高大物體的高處。高度變化需要計算在移動距離之內。</li>
</ul>
