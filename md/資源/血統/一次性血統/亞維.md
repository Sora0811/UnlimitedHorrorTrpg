# 亞維血統

> 來源：`資源/血統/一次性血統/亞維`

**本質**：特異本質

**價格**：D+600

**屬性**：耐力 +1 ，智力 +1 ，感知 +1 ，沉着 +2 ，決心 +2

**特性**：空識知覺（雙特性），亞維正義，低重力體質

**特殊**：因爲爲一次性血統，額外獲得兩個特性，由於沒有技能樹和能量池，額外獲得 3 點屬性。

**描述**：你的頭髮變成青藍色系（由你指定具體顏色），相貌俊美，呈現出明顯的亞維人特徵。你的額頭生出空識知覺器官。這些特徵使你在某些環境下在互動行爲上受到影響。

**價格**：D+600

**其他標籤**

**空識知覺**

<ul>
<li>亞維人原本是被創造爲太空工作者的勞役種族，他們可以通過連接特定的裝置獲得空識知覺。</li>
<li>你前額長出空識知覺器官，這是一塊 1 釐米見方的菱形的感覺器官，乍看上去像是寶石額飾，細看下會發現如昆蟲複眼般的結構。你可以使用亞維頭環和空識知覺設備。當你兌換此血統時，自動獲得亞維士族頭環。</li>
</ul>

**亞維正義**：亞維人將絕不屈服於威脅、一切以團隊爲上的執念寫入核酸螺旋之中。當你面對威脅時，你會本能地選擇決不屈服（面對人質脅迫，典型的亞維式做法是：殺死人質，並且將劫持人質者送入“亞維人造地獄”之中爲人質報仇，這是亞維人數十上百世代的宇宙商隊生涯所留下的保護色）。若你選擇屈服於威脅，則你接下來的全檢定會承受 3DP 的內在減值，持續一場景。而當你正面對抗威脅時，則你接下來的全檢定獲得 3DP 的內在加值，持續一場景。

**低重力體質**：亞維人的標準重力是地球的 1/2 ，並且長期在太空設備中生活。因此亞維人在正常地球重力環境中活動時，耐力相關檢定承受 1DP 環境減值。在低重力或無重力環境中，亞維人可以無減值活動，並且全檢定獲得 1DP 環境加值。

**頭環**

<ul>
<li>亞維人的頭環並不是裝飾，而是一種必須品。這是一種科技偵測裝備，並且可以與亞維人的空識知覺器官直接相連，爲亞維人提供空識知覺。在失去頭環之後，大多數亞維人都會惶恐不安。</li>
<li>不同的頭環同時也代表了身份和地位，因此頭環是不做額外裝飾的。但頭環的佩帶者不一定擁有如頭環名稱般的政治地位，軍銜或軍功也是佩帶頭環的先決條件，而且可能更受重視。</li>
<li>所有頭環都擁有一定程度的空間探測能力，同時備有插槽，可以連接亞維探測設備或駕駛操縱系統或接入插件。</li>
</ul>


**正文**

亞維人具有獨特的生理結構和身體特性，因此他們發展出了特別的技術手段來輔助自己。其中大多數，都與亞維人與地上人的最大區別――空識知覺有關。

# 亞維士族頭環

**本質**：特異本質

**價格**：D+500

**分類**：頭盔

**前提**：擁有空識知覺器官（擁有亞維血統）

**描述**：式樣樸素的頭環，金屬原色或銀白色，在空識知覺器官的位置帶有簡單的徽記型裝飾，鬆緊可調節。

**價格**：D+500

**其他標籤**

**感知探索**：佩戴者獲得相當於敏感範圍的盲感能力。


# 亞維貴族頭環

**本質**：特異本質

**價格**：DD+1000

**分類**：頭盔

**前提**：擁有空識知覺器官（擁有亞維血統），擁有亞維士族頭環

**描述**：銀色的頭環，帶有優雅的紋飾，花紋一般是亞維人所喜歡的植物形態。有爵位者的頭環上往往有簡化的家徽紋記。

**升級**：本物品由亞維士族頭環升級而成。

**價格**：DD+1000

**其他標籤**

**感知探索**：佩戴者獲得相當於敏感範圍的盲感能力。並且獲得 C 級特異本質的偵查能力，範圍爲你的敏感範圍。


# 亞維皇族頭環

**本質**：特異本質

**價格**：C+1000

**分類**：頭盔

**前提**：擁有空識知覺器官（擁有亞維血統），亞維貴族頭環

**描述**：裝飾典雅的頭環，通常帶有身份標記。

**升級**：本物品由亞維皇族頭環升級而成。

**價格**：C+1000

**其他標籤**

**感知探索**：佩戴着獲得相當於其敏感範圍的盲視能力。並且獲得 B 級特異本質的偵查能力，範圍爲你的敏感範圍。


# 頭環精英插件

**本質**：特異本質

**價格**：CC+2000

**分類**：插件

**前提**：擁有亞維士族頭環或者亞維貴族頭環或者亞維皇族頭環

**價格**：CC+2000

**其他標籤**

**感知擴張**：插入本插件後，該頭環“感知探索”的盲感或者盲視範圍擴大，擴大爲原本的十倍。

**偵查提升**：亞維貴族頭環和亞維皇族頭環的“感知探索”能力帶來的偵查能力提升 1 級。

**超級感應**：亞維皇族頭環的佩戴者可以消耗 5 點意志力，將“感知探索”的能力帶來偵查能力再提升 1 級，持續佩戴者的決心值 / 輪。
