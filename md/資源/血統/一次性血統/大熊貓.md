# 大熊貓

> 來源：`資源/血統/一次性血統/大熊貓`

**本質**：特異本質

**價格**：B+3600

**屬性**：力量+4 耐力+4 風度+3

**技能樹**：無

**特性**：大熊貓，萌貨，熊人族無所畏懼！（雙特性），熊掌

**特殊**：一次性血統，額外獲得兩個特性，由於沒有技能樹，額外獲得3點屬性

**描述**：世界上最萌的是什麼？蘿莉？貓咪？還是毛絨玩具？不不不，這些都不萌，最萌的動物是來自中國的“滾滾”！！

**價格**：B+3600

**其他標籤**

**大熊貓**：你的外貌變成一隻大熊貓，具體的毛皮的黑白花紋佈置你可以自己選擇，但是必須遵守大熊貓的普遍規律，你獲得3級或者是你的母語當前等級的熊族語(你可以照常說人話)，你獲得“攀爬”專業，並且進行相關檢定時獲得2點附加成功。由於你肥嘟嘟的身體，你針對原本就造成衝擊傷害的衝擊傷害獲得4點傷害忽略。

**萌貨**

<ul>
<li>沒有任何人可以抵抗滾滾的誘惑！沒有！</li>
<li>你每有1點傳奇風度，那麼敵人對你進行攻擊時獲得2點士氣減值，你的傾城之貌可以對人類起效。由於你太肥了，所以你的脖子“沒了”，敵人攻擊你咽喉時額外獲得4點特定部位減值。在你進行任何交際的相關檢定時的時候，你可以以風度替換操控進行檢定。</li>
</ul>

**熊人族無所畏懼！**：你的基礎移動速度增加40米，衝鋒時你的基礎防禦增加6點，這意味着你可以多衝鋒一些距離，當你進行擒抱相關檢定時你的體積視爲增加5點。

**熊掌**

<ul>
<li>有的人說熊貓這種萌物沒有啥戰鬥力，你對此表示：老子是一隻熊誒，給我一點起碼的尊重好嗎？！</li>
<li>你的熊掌擁有鋒利的爪子和恐怖的力量，你熊掌是天生武器，擁有等於你傳奇力量+1L的武器傷害，傷害類型爲鈍擊/揮砍/穿刺。當你以天生武器進行肉搏攻擊且成功命中目標時，你可以立即以一個移動動作對目標展開擒抱。</li>
<li>但是你由於你的熊掌，你無法使用體積小於3的槍械，因爲那玩意兒太小了點，你沒法扣動它的扳機。</li>
</ul>
