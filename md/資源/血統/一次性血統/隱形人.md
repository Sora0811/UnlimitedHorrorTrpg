# 隱形人

> 來源：`資源/血統/一次性血統/隱形人`

**本質**：特異本質

**價格**：D+600

**屬性**：耐力 +2 感知 +2 決心 +1 沉着 +2

**特性**：永久隱形（四特性）

**特殊**

<ul>
<li>一次性血統，額外獲得兩個特性，由於沒有技能樹和能量池，額外獲得 3 點屬性</li>
<li>本血統視爲人類血統。</li>
</ul>

**描述**：隱形對於某些人來說是一項夢寐以求的能力，但對於某些人來說，這更像是一個詛咒。

**價格**：D+600

**其他標籤**

**永久隱形**：你獲得永久隱形，這視爲 C 級特異本質的反偵察效果。這個隱形能力一旦購買便處於開啓狀態，並且你無法將這個能力關閉。但是，這個隱身能力的範圍僅限於你本身，並不包括你身上的物品（輪迴者手錶除外）（除非物品本身也有反偵測效果），當你持有或穿戴任何物品裝備時，別人可以輕鬆地分辨出你的位置，你在進行偵測對抗時視作失去該隱形效果。
