# 夜魔俠強化

> 來源：`資源/血統/一次性血統/夜魔俠`

**本質**：特異本質

**價格**：C+1200

**屬性**：力量 +2 敏捷 +2 感知 +2 耐力 +2

**特性**：盲感提升 棍術精通（雙特性） 天主的惡魔

**特殊**

<ul>
<li>一次性血統，額外獲得兩個特性，由於沒有技能樹，額外獲得 2 點屬性</li>
<li>使用本特性，將視爲角色擁有基督教的信仰導向。</li>
<li>本血統視爲人類血統。</li>
</ul>

**價格**：C+1200

**其他標籤**

**盲感提升**：夜魔俠獲得永久的目盲，本目盲無法通過任何方式治癒，這意味着夜魔俠無法使用任何基於眼睛的能力，包括瞳術。夜魔俠獲得相當於敏感範圍內的盲感能力，並且忽略 8 點高速減值，同時免疫 C 級的措手不及。

**棍術精通**：夜魔俠通常攜帶兩把多功能摺疊棍，外形類似盲人柺杖。角色在使用分類爲短棍的武器時，可以用肉搏技能來代替白刃決定 DP 以及傷害上限，並且角色使用對應武器時的攻擊檢定獲得 3 點 DP 加值，使用對應武器進行格擋時，格擋防禦額外增加 3 點。

**天主的惡魔**：馬特默多克是一個忠誠的天主教徒。角色可以進行一次 1 個小時的懺悔禱告，視爲角色觸發了一次美德，這個效果每場恐怖片只能發動一次。
