# 阿修羅

> 來源：`資源/血統/人類/特異本質/鬼劍士/阿修羅`

## C 級

**屬性**：智力 +3 ，耐力 +3

**特性**：魔力親和，超凡感知（正負特性），堅韌戰士

**技能樹**：開啓 C 級阿修羅技能樹

**特殊**：無

**描述**：爲了感知到波動，阿修羅們選擇自戕雙眼。

**其他標籤**

**超凡感知**：你失去雙目，陷入不可避免的永久目盲狀態，並且無法透過任何方式恢復，但你獲得等於你敏感範圍的盲感。

**魔力親和**：你開啓魔力池，你獲得相當於本血統等級的施法者等級，但是本血統的施法者等級只對本血統下的法術有效，並且不能籍此學習和使用通用法術。

**堅韌戰士**：當你穿着重甲時，你的盔甲防禦增加等同於血統等級/點，同時你不受盔甲減值影響。


## B 級

**屬性**：智力 +4 ，耐力 +4

**特性**：挫折意志（三特性）

**技能樹**：開啓 B 級阿修羅技能樹

**特殊**：無

**其他標籤**

**挫折意志**：你每回合第一次受到源自敵人的傷害或對敵人造成傷害（範圍攻擊無論影響到多少敵人都視爲一次傷害）時都會使你施展本血統技能樹下的技能時所造成的所有與數值相關的最終效果提升 1 點（包括但不限於傷害，成功數，不良狀態點數等），該效果持續一個場景，以此增加的效果上限爲你的智力值。


## A 級

**屬性**：智力 +6 ，耐力 +6

**特性**：超凡感知，超凡意志

**技能樹**：開啓 A 級阿修羅技能樹

**特殊**：無

**其他標籤**

**超凡感知**：你在 C 級獲得的盲感提升爲盲視，且範圍擴大至你的模糊範圍。

**超凡意志**：你在意志檢定上獲得等同於你智力值的內在加值。

**大暗黑天**：你現在免疫 A 級以下影響心靈的效果。


## S 級

**屬性**：智力 +8 ，感知 +8 ，耐力 +8

**特性**：覺醒（雙特性），大暗黑天

**技能樹**：S 級阿修羅技能樹

**特殊**：無

**其他標籤**

**大暗黑天**：你現在免疫 S 級以下負面影響心靈的效果。

**覺醒**：你在施展本血統技能樹下的技能時所造成的所有與數值相關的最終效果翻倍（包括但不限於傷害，成功數，不良狀態點數等），該翻倍效果不計算其他能力帶來的效果（包括但不限於額外的附加成功與傷害，將 DP 轉換爲附加成功的能力等），並在計算這些效果之前結算，但本能力帶來的額外效果不計入傷害與法術上限中。
