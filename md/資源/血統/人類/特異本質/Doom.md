# Doom

> 來源：`資源/血統/人類/特異本質/Doom`

**本質**：特異本質

**屬性**：力量 +2 耐力 +2 決心 +2

**能量池**：無

**技能樹**：無

**特性**：狂暴槍術，槍械大師，槍械充能

**特殊**：由於沒有技能樹，額外獲得一個特性，由於沒有能量池，額外獲得兩點屬性

## C 級　誰纔是惡魔

**屬性**：力量 +3 耐力 +3 決心 +2

**技能樹**：無

**特性**：緩衝修正，暴力拆取

**特殊**：由於沒有技能樹，額外獲得 2 點屬性

**其他標籤**

**緩衝修正**：毀滅戰士不會像獵人與不死人那樣脆弱，不會因爲摔落而受到任何傷害。毀滅戰士免疫墜落傷害。

**暴力拆取**：毀滅戰士可以在擒抱或壓制對方時如常使用自身所持有的武器進行攻擊檢定。


## B 級　夢魘

**屬性**：力量 +4 耐力 +4 決心 +3

**技能樹**：無

**特性**：壯烈擊殺，武器重擊，亞金能源

**特殊**：由於沒有技能樹，額外獲得 3 點屬性

**其他標籤**

**壯烈擊殺**

<ul>
<li>毀滅戰士體內流淌着暴力的因子，他喜歡踢斷惡魔的膝蓋，踩碎它的頭顱，又或者拆掉惡魔的四肢順便將其撕碎。</li>
<li>毀滅戰士可以使用一個標準動作對生命值低於毀滅戰士力量值且沒有完好生命值的敵人發動一次壯烈擊殺，如常使用攻擊檢定，若成功命中目標，則本次不造成傷害，而是改爲目標的生命值全部變爲惡性，這是一個即死效果。</li>
</ul>

**武器重擊**

<ul>
<li>對於毀滅戰士來說太過於接近的敵人，不用那麼麻煩，直接揮動手中的槍械砸碎它。</li>
<li>你可以使用手中的槍械進行近戰判定，武器傷害爲武器體積，同時你可以使用槍械技能代替白刃進行攻擊檢定（但是依然視爲白刃攻擊），若你已經擁有類似能力，則現在你可以以槍械代替白刃計算傷害上限。</li>
</ul>

**亞金能源**

<ul>
<li>這種奇特的能量能被毀滅戰士所吸收，並轉化爲相應的力量。</li>
<li>毀滅戰士獲得傳奇耐力一半（向下取整）的快速治療。</li>
</ul>


## A 級　Doom slayer

**屬性**：力量 +6 耐力 +6 決心 +4

**技能樹**：無

**特性**：提升 - 壯烈擊殺，種族毀滅者，護盾汲取

**特殊**：由於沒有技能樹，額外獲得 4 點屬性

**其他標籤**

**壯烈擊殺**：毀滅戰士撕碎敵人不止能帶來毀滅，還能吞噬他人的力量，當你使用“壯烈擊殺”時，你可以回覆相當於目標傳奇耐力值的生命值。同時被壯烈擊殺殺死的目標將無法復活（時間倒回等類似能力不受本效果影響），這可能會使目標的某些復活能力直接失效。

**種族毀滅者**

<ul>
<li>毀滅戰士憑藉一己之力撕碎了火星與地獄所有能找到的惡魔，他對惡魔甚至比它們本身還了解它們。</li>
<li>毀滅戰士的敏感範圍內每有 1 個敵對目標，則其攻擊檢定獲得 1DP 士氣加值，上限爲毀滅戰士的決心值，若其中的敵對目標支線等級不低於毀滅戰士的支線等級，則毀滅戰士的攻擊檢定額外獲得 1 點附加成功，上限爲毀滅戰士的傳奇決心。</li>
</ul>

**護盾汲取**

<ul>
<li>毀滅戰士注重的不止有攻擊，也會有防禦。</li>
<li>毀滅戰士每輪第一次成功對目標造成傷害時，其獲得相當於手中武器傷害的護盾點數，每點點數可以抵消 1 點傷害，護盾不會疊加，新的會覆蓋舊有的，護盾上限最大不得超過你耐力值的一半。</li>
</ul>


**其他標籤**

**D**：用力打我啊！

**狂暴槍術**：毀滅戰士可以使用力量代替敏捷進行槍械相關的攻擊檢定。

**槍械大師**：毀滅戰士能夠完美的使用任何槍械，這是流淌在血液裏的力量。槍械技能等級提升 1 級，上限爲 5 級。

**槍械充能**

<ul>
<li>毀滅戰士經常改造自己的武器，不過這些需要特殊的工具，而主神優化了這一點。</li>
<li>毀滅戰士可以消耗一個迅捷動作進行武器充能，使用該武器進行的下一次攻擊，其攻擊檢定獲得 4DP 器械加值。</li>
</ul>
