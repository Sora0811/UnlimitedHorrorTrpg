# 祈禱者教派 復仇派系

> 來源：`資源/血統/人類/特異本質/源能武者/復仇派系`

**本質**

<ul>
<li>特異本質</li>
<li>與起源於古老東方並且廣爲人知的新星和黑洞派系不同，源自神靈崇拜而不斷演變成如今模樣的祈禱者教派隱藏在星空的影幕中，注視着一切。與吞噬分解一切能量的黑洞或注重釋放爆發能量的新星相比，信仰使祈禱者教派的武者們的力量變得神祕莫測――不，也許稱呼他們爲神官，遵從自己內心的選擇並將其稱之爲天意的，天命者。</li>
<li>首先，祈禱者在那些剛剛出生就已成爲孤兒的孩子中挑選有潛力的人，教授他們知識，使他們很早就變得相當成熟，之後，他們挑選出其中擁有最堅韌意志的孩子培養成繼承人，只有在極少數情況下，他們會選擇十歲以上的孩子――那些充滿着沒有經過引導的仇恨，憤怒和孤獨感的孩子，通常是災難中的倖存者。一個祈禱者一生只會收一個弟子，他們不會結婚，不會爭奪權力，因此這些弟子對他們來說就相當於孩子。當然，他們很喜歡雙胞胎，沒有人會討厭自己多一個孩子的感覺。</li>
<li>此血統是復仇派系的傳承。</li>
<li>共有救贖，復仇，審判，混沌四個派系，混沌由審判演變而來，復仇由救贖演變而來。</li>
<li>復仇教派的神官對施法者都有着刻骨銘心的仇恨，他們用瘟疫，精神攻擊和可怕的持久戰能力讓每一個施法者都恐懼，連死亡也恐懼這些留着血淚的靈魂。實際上，復仇者們往往多才多藝，他們掌握着最多的技巧。</li>
</ul>

## D 級

**屬性**：風度+2、決心+2

**技能樹**：D級祈禱者教派技能樹

**能量池**：源能

**特性**：吾主在此（正負特性）心靈共感（雙特性）

**特殊**：無

**描述**：你在身體的某個部位形成了一個模糊的圖案，你的信念不可動搖，你的信仰堅如磐石――但你只信仰自己。

**其他標籤**

**吾主在此**

<ul>
<li>你的信仰導向爲【自我】，因此不能擁有其他信仰導向能力。</li>
<li>每當你受到心靈影響的不良狀態點數時，你忽略相當於血統等級/1點。</li>
</ul>

**心靈共感**

<ul>
<li>你可以感知到敏感範圍內生物的情緒，並且你能感知到你敏感範圍內在最近等同於血統等級\*1小時內是否有單位施展過法術，當其他位於你敏感範圍內的單位施展法術時，你會立刻得知這一點，但你無法以此知道其位置。</li>
<li>最後，當你施展或在一次攻擊中攀附本血統技能樹下的能力時，你可以使用決心代替力量進行檢定。</li>
</ul>
