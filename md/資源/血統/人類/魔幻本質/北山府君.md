# 北山府君

> 來源：`資源/血統/人類/魔幻本質/北山府君`

**本質**：魔幻本質

**前提**：人物國籍出生中國，且必須爲漢族。

**描述**：東方古老的象徵着自然的一部分的無名神靈，覺察到人類對於自然的破壞，暴怒的從時間的長河中降下化身，展開這終末的神罰。

## D 級　遊蕩着的無名迷茫者

**價格**：D+600

**屬性**：力量+2，耐力+2

**能量池**：無

**技能樹**：無

**特性**：來自遠古的誓約（四特性）

**特殊**：由於沒有技能樹和能量池，額外獲得2個特性。

**描述**

<ul>
<li>爲人類所擊墜的化身啊，失去了與主體的聯繫，失去了過往的榮耀，僅僅餘下殘缺的意志，亦要履行着那遠古的誓約。</li>
<li>來自遠古的誓約(四特性)：迷茫的遊蕩者吶，即使失去了一切，但只要仍舊在履行着誓約，便會獲取着來自這誓約的加護，獲取近乎於無限的可能性。</li>
<li>你的基礎移動速度增加10米；並且你獲得6點天生防禦。</li>
</ul>

**價格**：D+600

## C 級　世界眷顧的地之子嗣

**價格**：C+1200

**屬性**：力量+3，耐力+3

**技能樹**：無

**特性**：大地母親最喜歡的崽兒、神性的視野（雙特性）

**特殊**：由於沒有技能樹，額外獲得1個特性。

**描述**：懵懂中的遊魂吶，終有一天，你會發現你將非你，深受着世界的眷顧的你，爲了履行着誓約，踏上了歸來的旅程。

**價格**：C+1200

**其他標籤**

**大地母親最喜歡的崽兒**

<ul>
<li>慈愛的大地之母吶，願你庇護着這塵世間的一切。只要你的身體的一部分接觸到大地，你便獲得1點再生。</li>
<li>神性的視野（雙特性）：自然界的生物在神靈的目光之下，無所遁形。</li>
<li>你獲得黑暗視覺與靈感視覺，你的近戰攻擊可以如常影響靈體，但是這不視爲你擁有【幽冥】特性；同時你免疫C級以下的措手不及的效果。</li>
</ul>


## B 級　行走於大地之上的聖者

**價格**

<ul>
<li>B+3600</li>
<li>A+7200</li>
</ul>

**屬性**

<ul>
<li>力量+4，耐力+2，感知+2</li>
<li>力量+6，耐力+3，感知+3</li>
</ul>

**技能樹**

<ul>
<li>無</li>
<li>無</li>
</ul>

**特性**

<ul>
<li>復甦的神性之軀、浸染大地的紅蓮之血、大地韻律的脈搏（雙特性）</li>
<li>此世的眷顧、神血的恩賜、居於彼岸的眷念者</li>
</ul>

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得1個特性。</li>
<li>由於沒有技能樹，額外獲得1個特性。</li>
<li>本能力洗點後，再次獲得也不會刷新次數。</li>
<li>若角色擁有其他復活類能力，則優先其他復活類能力。</li>
<li>本能力不會佔用復活次數。</li>
<li>觸發本能力時，角色無法觸發任何死亡可以觸發的能力。</li>
<li>若時間內，對應的隊友死亡，則本能力宣告啓動失敗，你將無法復活，這也正常佔用你的次數。</li>
</ul>

**描述**

<ul>
<li>踏上了漫漫歸來之路，隨着和本體聯繫開始加深，身體裏的神性開始復甦。逐漸迴歸着的你，感覺到了世界的痛楚和哀嚎。</li>
<li>在一場轟轟烈烈的抗爭着，仿若流星般的你，燃盡自己的一切，成就那最璀璨的剎那，在河流上輕輕蕩起了漣漪，引動了本體的關注，而你那遺留在夥伴記憶的印象，便是你存在的最好的證明，於此刻端坐於岸邊的“祂”再一次投下了石子，憑依着友人的記憶，你宛若新生，再次歸來。</li>
</ul>

**能量池**：無

**價格**：B+3600

**其他標籤**

**復甦的神性之軀**：來自於你體內的與大地相關聯的神性在沸騰，喚醒了你的一部分本質，獲取了來自於大地的加護，只要你的身體有任一部位未離開大地，便會獲取大地的加護所提供的源源不斷的祝福，你的肉身獲得3點硬度。

**浸染大地的紅蓮之血**

<ul>
<li>身負紅蓮，淨土琉璃。感受到世界痛楚的你，正如同平靜的大地核心孕育着暴烈的岩漿一般，燃燒這的心火將你的血液轉變成滾燙而又熾熱的岩漿，當你受到攻擊時，攻擊者每次成功命中你且造成傷害，會使得你如同岩漿般的血液四處濺射，血液濺落在大地上面，會將大地浸染成岩漿態，於岩漿之上盛開出虛幻的緋紅色的蓮花，蓮花最大數量等同於玩家的傳奇耐力/朵。</li>
<li>綻放的蓮花會在你敏感範圍內形成一道結界，每綻放一朵蓮花都會使結界內部溫度提高。每回合開始時，結界範圍內的所有敵方單位將會受到等同於蓮花數量/點不可豁免的火焰嚴重傷害。</li>
<li>新的蓮花會取代舊的蓮花，蓮花最多持續一個場景。</li>
</ul>

**大地韻律的脈搏**：擁吻大地，與這大地融爲一體，你的心臟與大地的脈絡相鏈接，每場景一次，消耗3點意志力和一個反射動作，你可以立即進行一次移動，你在自身敏感範圍內任意一個地點聚集土石，再次形成你的身體，但是這個地點必須和大地有着接觸，這是一個B級別的空間傳送。

**A級**：呼喚吧！吶喊吧！歸來吧！北山府君

**此世的眷顧**：深愛着世界，也會爲這世界所深愛着，在具有世界意識或者自然生態尚未被完全破壞的劇情世界裏（如鋼之大地之類世界意識死亡，生態圈被完全破壞的世界裏無法獲取），你將獲得4點再生。

**神血的恩賜**

<ul>
<li>迴歸了本質，跨越了人與非人的界限，非人的你的血液對於普通人來說也是一種難以獲取的天材地寶，此時的你每對自己造成2點不可避免的耐力傷害，可以憑藉自己的意願流出一份沸騰的神之血，以標準動作服用下神之血的單位（因爲神之血存在於你身體內部，所以神之血對你本身及沒有肉體的單位無效），三項生理屬性各獲得1點能量加值，持續10分鐘（重複飲用神之血不會疊加效果；並且每個單位每24小時最多隻能享受一次神之血的效果）。神之血只能保存不超過48小時，超過時間後會失去沸騰的活性（這意味着此時飲用神之血不會有任何效果）。</li>
<li>居於彼岸的眷念者（雙特性）：本體跳出了河面，在岸邊的你，本不應該再對這條河流進行着任何的干涉，但是因爲着你的眷念與執着，促使着你一次又一次的向着河流中你熟悉的位置拋下了石子，濺起那一陣又一陣的波紋，形成着一個又一個的化身，來完成那久遠的未竟的誓約，直至被那條河流所排斥，再也無法做出任何干涉。</li>
<li>當你死亡時，選擇一名隊友，然後在1D10天后，你以該隊友的位置爲目標，錨定座標，於早晨七點整重新降臨你的化身。你的生命值全滿，全部的通用能量池和意志力爲空，清空全部的異常狀態和不良點數。</li>
<li>你可以重複購買本能力，每次花費C+4000，最多購買6次，總計7次。</li>
</ul>
