# 古典巫師

> 來源：`資源/血統/人類/魔幻本質/古典巫師`

**本質**：魔幻本質

**描述**

<ul>
<li>迷戀魔法，完全以魔法爲原動力的異類，稱爲魔法使。</li>
<li>有些魔法使是天生的，但也有修行魔法的人類通過習得“舍食”和“舍蟲”的法術而成爲魔法使。凡人往往以爲他們捨棄人類的身份換來的是強大的力量，不過正相反，他們所得到的不過是不受歲月限制的悠長壽命，而力量則是積年累月研究魔法的必然結果。</li>
<li>他們在大多數人類世界並不受歡迎，特別是在逐漸科技化的世界裏，他們大多找地方隱居。弱小的魔法使隱藏身份混在普通人之中，研究不可名狀之奧祕的魔法使藏身在敦威治和阿卡姆，追尋消逝幻想的魔法使前往幻想鄉，精進學問的魔法使託身於 [ 學園 ] 之內。也有些魔法使遁入祕夢境、天上之國。</li>
</ul>

## D 級

**屬性**：智力 +2 ，感知 +2

**能量池**：魔力池

**特性**

<ul>
<li>魔法本源、法術精通（雙特性）</li>
<li>由於沒有技能樹，額外獲得 1 個特性</li>
</ul>

**技能樹**：無

**其他標籤**

**法術精通**：魔法使瞭解法術，你在施展法術和對抗法術的豁免檢定上獲得 3D 內在加值。

**魔法本源**：你獲得相當於你血統等級的施法者等級。


## C 級

**屬性**：智力 +3 ，感知 +3

**能量池**：魔力池

**特性**

<ul>
<li>舍蟲、舍食、法術精通</li>
<li>由於沒有技能樹，額外獲得 1 個特性</li>
</ul>

**技能樹**：無

**其他標籤**

**法術精通**：你施展法術時，威力值增加1點。

**舍蟲**：你的年齡不會再增長，因此不會受到壽命的限制。你免疫衰老效果。

**舍食**：你無需食物和水。


## B 級

**屬性**：智力 +4 ，感知 +4

**特性**

<ul>
<li>舍眠、堅韌、法術精通（雙特性）</li>
<li>由於沒有技能樹，額外獲得 1 個特性</li>
</ul>

**技能樹**：無

**其他標籤**

**舍眠**：你需要長期保持清醒，睡眠對你來說是一種愛好而非必要。你無需睡眠，並且免疫睡眠效果。你每小時進行一次魔力的關鍵屬性檢定，每有1點成功數則恢復1點魔力，若超過6點，則平均到每10分鐘上。

**堅韌**：你無需食物和水。並且當你受到任何不良狀態點數時，當你身上有不良狀態時，你可以立即消耗 1 點意志力，使你身上的一種不良狀態減少你傳奇智力與傳奇感知之和的點數，每回合只能使用一次。

**法術精通**：當你施展法術時的施法檢定獲得相當於你傳奇感知的附加成功，施展法術時，威力值再增加2點。


## A 級

**屬性**：智力 +6 ，感知 +6

**特性**

<ul>
<li>魔法身軀、舍息、法術精通（雙特性）</li>
<li>由於沒有技能樹，額外獲得 1 個特性</li>
</ul>

**技能樹**：無

**其他標籤**

**魔法身軀**：你的身體成爲魔法力量的中樞，魔法反饋到身體上。當你每次恢復魔力池的時候，你獲得臨時生命，其數值等於你的傳奇智力與傳奇感知之和，不可疊加。

**舍息**：你可以完全用魔力維持身體，在極端環境下保持自己的生命，你免疫環境帶來的不良影響。

**法術精通**：你施展法術時無需支付其基礎的能耗。但是其額外的增幅需要正常消耗。並且你現在面對一個法術時（包括不限於正在施法，結界等）你自動得知其效果。同時當你施展法術時，威力值再增加4點。
