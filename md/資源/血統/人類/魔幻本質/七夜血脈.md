# 七夜血脈

> 來源：`資源/血統/人類/魔幻本質/七夜血脈`

**本質**

<ul>
<li>魔幻本質</li>
<li>自古以來，七夜便在不與外界混血的狀況下流傳下來。</li>
<li>近親交配所誕生的異種大多在出產時便被掐死，然而能夠成長起來的孩子便宿有強大的力量。</li>
<li>原本變異遺傳性的“超能力”僅限一代，然而卻能夠明顯地被遺傳下來，說起來也是由於這種不斷重複幾近偏執的交配行爲。</li>
<li>再加上，七夜作爲暗殺者不斷地磨練技術，學習着能夠讓被一次性使用的超能力者生還的方法。</li>
<li>結果。</li>
<li>身爲人卻擁有着超越人的能力，並且能夠將人類的身體機能鍛鍊至極限的七夜一族誕生了。</li>
<li>在誕生的一瞬間，他們便已不再是擁有超能力這種特異能力的一族，而是化作了繼承人類所擁有的退魔意志的特異一族。</li>
<li>這也是被混血所迫害的異能者家系―――七夜爲了生存下來而去尋求自身能力的結果。</li>
<li>因此，七夜便成爲了退魔勢力中決定性的戰鬥力。</li>
<li>自那以後又經過了漫長且無聊的時間。</li>
<li>……七夜依然作爲暗殺者的頂點存在着。</li>
</ul>

**其他標籤**

**黑暗洞察**

<ul>
<li>本能地察覺到黑暗氣息的存在。針對感知 \*5 米範圍內的黑暗生物或其他黑暗存在（由 ST 定義），但是你無法通過本能力對其定位。你只會覺得心跳加速，冷汗直冒，難以剋制心中的沸騰殺意。這是一個被動能力。你可以大致地估計出來源的強度，比如是“可以輕易轟下“或者“絕對打不過，動手就會死”。只有特殊的力場（如結界或時空類效果）才能阻隔這個效果。</li>
<li>洞察黑暗的力量更強。對於感知 \*10 米內的黑暗存在，開始有更加精確的感應能力，現在你能夠對其模糊定位，這視爲比血統等級高一級的偵測手段。</li>
</ul>

**退魔衝動**

<ul>
<li>一旦確切感應到附近的黑暗力量，就自動進入退魔衝動狀態。</li>
<li>在這個狀態下，本血統提供的敏捷和感知額外增加一點，沉着相關檢定獲得 3DP 內在減值，效果持續一個場景。退魔衝動結束後 1 分鐘內，全檢定獲得 3DP 內在減值，並且一小時內不能主動啓動。</li>
<li>退魔衝動中，你能清醒的知道自己在幹什麼，也能分清敵友，但斬殺妖魔就像無比甘美的誘惑一樣驅動着你，“殺了它殺了它殺了它殺了它殺了它”，這樣的字眼在腦中不斷迴響，讓你不由自主地衝上去砍殺妖魔。你可以強行壓抑下攻擊妖魔的衝動，這不會造成任何 DP 上的減值，但你會有些口乾舌燥，心理上也會造成無比的飢渴和焦燥。</li>
<li>同時你在面對 B 級或以上的黑暗存在時，必須進行一個額外的意志檢定， DC 爲自己的沉着，若失敗，則必須攻擊對方，即使對方的強度是“動手就會死”也一樣。對 C 級以下的黑暗存在則不用進行『必須攻擊』的意志檢定。但無論如何，不管是否通過檢定， 24 小時都不會再對同一個黑暗存在產生必須攻擊的衝動。</li>
<li>如果你在進行『必須攻擊』時的檢定失敗了，那麼之後的每一輪，你都可以重複檢定，如果成功，則可以自由選擇撤退，否則只能一直戰鬥到底。</li>
<li>你無法主動對非黑暗生物開啓這個效果。</li>
<li>退魔之血的能力增強，只有對 A 級或以上的黑暗存在才需要進行“必定攻擊”的意志檢定。你通常不能主動對非黑暗存在開啓這個效果，但可以通過一個 DC 爲 5 的意志檢定，在移動動作中強行啓動它。如果失敗，你會被反噬震懾一輪。在退魔衝動的狀態下，取代 D 級的效果，本血統提供的敏捷和感知額外增加 3 點，沉着和操縱相關檢定受到 6DP 內在減值。退魔衝動結束後 1 分鐘內，全檢定受到 3DP 內在減值，並且一小時內不能主動啓動。其他規則與 D 級的描述相同。</li>
<li>現在只需要對 S 級或更高的黑暗存在進行“必須攻擊”的檢定。在退魔衝動的狀態下，取代 C 級的效果，本血統提供的敏捷和感知額外增加 4 點，沉着和操縱相關檢定受到 9DP 內在減值，同時在本狀態下，你可以用敏捷代替力量作爲近戰攻擊檢定以及傷害上限。你能以一個自由動作開啓退魔衝動的效果。即使沒有感知到黑暗氣息，也可以通過一個 DC 爲 4 的意志檢定來強行啓動退魔衝動，如果失敗，會因爲反噬暈眩一輪。退魔衝動結束後 1 分鐘內，全檢定受到 2DP 內在減值，並且一小時內不能主動啓動。除此之外的描述同 C 級的退魔衝動。</li>
</ul>

**黑暗正義**

<ul>
<li>爲了對抗邪惡，狡猾的敵人，七夜之血的人工進化中，融入了一代代的七夜對他們的仇恨和敏銳。在對抗幻術和影響心靈的負面效果時，相關對抗檢定獲得 1DP 內在加值。</li>
<li>在對抗幻術和影響心靈的負面效果時改爲獲得 3DP 內在加值，無論成敗，都會直接激發退魔衝動。</li>
<li>你免疫 B 級以下的幻術效果以及影響心靈的負面效果。當你受到類似效果影響時，自動進入退魔衝動・魂之爆發。</li>
<li>七夜家的暗殺術是人類以本身的肉體發展出的最可怕的技巧之一，三次元的高速移動，急停，轉向，能做出視力無法捕捉的動作，攻擊對方瞬間出現的死角，威力異常恐怖。</li>
<li>七夜暗殺術</li>
<li>七夜的族人爲了配合優異到近乎妖異的行動力而在實戰中千錘百煉得出的暗殺技術。即便是高位的死徒，面對七夜家的暗殺技術時仍然會被迫回憶起生而爲人的痛覺。據說曾有七夜的末裔只用粗淺的暗殺術就在瞬間將人體切割成十七塊。</li>
<li>這是基於七夜體術的戰鬥技巧，也唯有在配合七夜的家傳體術時才能發揮出最大的殺傷力。暗殺術的技巧已經銘刻在了七夜的 DNA 中，流淌在七夜的血管裏，只要是七夜的血脈，在拿起武器之時就會自然而然的領悟出屬於自己的暗殺術，這需要花費一定的經驗值。七夜暗殺術只有在七夜體術中才能使用。</li>
</ul>

**衝動**：沉着相關檢定受到 6DP 內在減值。

**淨眼覺醒**：七夜之血在你體內充分覺醒，也會覺醒相應的瞳術。你可以選擇一種 C 級或以下的瞳術，直接免費獲得它，或者獲得高級瞳術的 C 級版（如果有 D 級則包含在內）。如果之前已經死亡過一次並且復活，可直接選擇 B 級的點線魔眼。

**退魔衝動・魂之爆發**

<ul>
<li>七夜之血完全覺醒的狀態，退魔衝動的頂點。你現在可以控制自己的情緒，不再需要進行“必須攻擊”的檢定。</li>
<li>・本血統提供的敏捷和感知額外增加 6 點，力量和耐力額外增加 2 點，沉着和操縱相關檢定受到 9DP 內在減值，取代 B 級的退魔衝動。</li>
<li>・可以將感知或者智力中較高的一項加在所有戰鬥相關投骰上（但無法與開啓基因鎖或其他類似狀態疊加），戰鬥相關的投骰包括“戰戰戰”目錄下的所有相關檢定以及由於對方發動某些能力而你需要進行的對抗性檢定。</li>
<li>・在這種狀態下，免疫所有影響心靈的魅惑，操控和脅迫效果。</li>
<li>・你可以用反射動作啓動這種血脈能力，在附近有極爲強大的黑暗存在的情況下，也會自動啓動。如果在沒有黑暗存在的情況下強行啓動它，則需要通過一個 DC 爲 3 的意志檢定，失敗則這一輪除了移動之外不能做其他事情。退魔衝動結束後不再有 DP 減值，但一小時內依然無法再次主動啓動。</li>
</ul>


## C 級　七夜體術

**價格**：C+2000

**動作**：迅捷動作

**消耗**：1 點意志力

**持續**：耐力值 \*1 輪

**被動**：潛行技能提升一級，最高不超過 8

**主動**

<ul>
<li>基礎移動速度增加 10 米。並且你的攻擊檢定獲得 4DP 速度加值，防禦增加 4 點閃避加值。</li>
<li>你攻擊特定部位的減值減少 3 點（最低減到 0 ）</li>
<li>你可以在移動的過程中進行一次攻擊之後再次移動，移動的總距離不超過你的基礎移動速度。移動範圍中可以包括垂直於地面的部分，但回合結束的時候必須在穩定的支撐點上，否則就會墜落。</li>
<li>這是一個身法。</li>
</ul>

**價格**：C+2000

**效果**：現在你在啓動招式的同時還視爲進行了格擋，並且你的格擋防禦額外增加相當於高速優勢點數的加值。根據攻擊模式的不同，你在攻擊檢定上獲得一個 / 兩個 / 三個附加成功，分別對應短點射 / 長點射 / 連射。若你在攻擊的同時使用一點意志力，那麼在你下輪行動開始前，目標的全檢定獲得相當於本次受到傷害數的 DP 無名減值。

<li>在判定上這視爲兩次攻擊，但是同時發生。</li>
</ul>
