# 荒古聖體

> 來源：`資源/血統/人類/魔幻本質/荒古聖體`

**本質**：魔幻本質

**描述**：這是和遮天世界的葉天帝一樣的體質，本來曠古絕倫的體質在無限空間裏由於沒有足夠的天地靈氣和法則支持，只有最基本的能力。

**選開**：荒古聖體有着一個金色的苦海，堅硬而不可撼動，這是他們天生的劣勢也是優勢。人物從獲得該血統後， 其必須爲自己當前已擁有的每個能量分別 額外支付 5 00 分，之後每次 開啓 新的 能量池時 都需要額外支付500分 。 之後人物每服用1枚支線等級不低於D級的丹藥，其便可以選擇自身一個東方背景的能量池並使其上限增加2點，以此法增加的能量上限之和不得超過你當前擁有的能量池\*3點。

## D 級　天賦異稟

**屬性**：力量+2、耐力+2

**能量池**：無

**特性**：聖殼無雙（四特性）

**技能樹**：無

**特殊**：由於沒有能量池和技能樹，額外獲得2個特性

**描述**：荒古聖體的力量天下第一，除卻死敵蒼天霸體之外無有敵手。你比一般人都壯實，而且力量強大。

**其他標籤**

**聖殼無雙**

<ul>
<li>人物的自然恢復速度翻倍。</li>
<li>此外，僅在判斷你是否會因不良狀態點數而進入重度不良狀態時，你的關鍵抵抗屬性視作比當前要高傳奇決心\*1點。在忍耐不良狀態點數時，你可以多忍耐等同於自身傳奇耐力\*1點。</li>
<li>最後，你現在的肉搏攻擊的觸及範圍增加你傳奇力量/米。</li>
</ul>


## C 級　聖體初醒----輪海祕境命泉境

**屬性**：力量+3、耐力+3

**技能樹**：無

**特性**：提升-聖殼無雙，碎天之力，一力破萬法

**特殊**：由於沒有技能樹，額外獲得1個特性

**描述**：荒古聖體無與倫比的力量讓他們對付任何法術的時候有了一種新的選擇：管你千般妙法，我只管一拳轟出！

**其他標籤**

**碎天之力**

<ul>
<li>你在力量相關檢定上獲得1個附加成功。</li>
<li>提升-聖殼無雙：你獲得1點快速治療。</li>
</ul>

**一力破萬法**：人物在受到任何法術影響（包括對抗或者是被攻擊）的時候，若該法術需要施法檢定，則可以使用1點意志力以反射動作進行一次力量+肉搏檢定，之後使對方該次施法檢定承受等同於你該次檢定成功數\*1DP無名減值。


## B 級　聖體初醒----輪海祕境彼岸境

**前提**：人物必須至少服用過一種C級以上的藥物（包括但不限於藥水、草藥等，具體可由ST裁定）或者丹藥，亦或者服用過的藥物或者丹藥總價值超過一萬分纔可兌換本級血統，此外，這些藥物或丹藥價格中的每個D級支線可折算爲3000分。特殊的，神源、源、龍髓僅在計算本級血統的前提條件時，其總分數視作比原本高一倍。

**屬性**：力量+4、耐力+4

**特性**：提升--聖殼無雙（雙特性），萬邪不侵（雙特性）

**技能樹**：無

**特殊**：由於沒有技能樹，額外獲得1個特性

**描述**：荒古聖體，萬邪不侵！

**其他標籤**

**聖殼無雙**：由本血統C級特性提供的快速醫療增加1點並且變爲再生，同時你每有3點耐力或1點傳奇耐力，你便再獲得1點生命值上限。

**萬邪不侵**：當你受到任何來自黑暗生物的攻擊，或者是帶有【魔法】【能量武器】【黑暗】特性的攻擊時，如果此次攻擊附帶需要進行對抗或者豁免檢定的效果，你能夠在相關檢定上獲得等於你耐力值一半的內在加值。


## A 級　聖體初醒----道宮祕境

**屬性**：力量+6、耐力+6

**特性**：無雙體魄（雙特性），提升-一力破萬法，無雙神力

**技能樹**：無

**特殊**：由於沒有技能樹，額外獲得1個特性

**其他標籤**

**無雙體魄**

<ul>
<li>你在恢復傷勢時（包括但不限於自然恢復、治療等），你的惡性傷害可以當做嚴重傷害來進行恢復。</li>
<li>提升-一力破萬法：你現在使用本能力不再需要消耗反射動作，但是消耗的意志力提升至5點，並且目標現在承受的不再是DP減值而是改爲失去等額的成功數。</li>
</ul>

**無雙神力**：你在進行近戰肉搏攻擊時，獲得相當於你力量值一半的破甲，並且你可以選擇目標的盔甲進行擊破武器的攻擊，如果你的天生武器具有【貫穿】特性，那麼你在擊破其盔甲之後可以按照【貫穿】特性的規則對目標進行攻擊。


## S 級　聖體初醒---道宮祕境巔峯

**屬性**：力量+8、耐力+8、決心+8

**特性**：荒古（雙特性）、聖體、碎天神力

**技能樹**：無

**特殊**：由於沒有技能樹，額外獲得1個特性

<ul>
<li>本級別爲完全的展覽品，本書作者沒有經過任何審覈，所以建議不開放，若開放請ST自行善後。</li>
<li>SSS SS + 576 00</li>
</ul>

**其他標籤**

**荒古**：你免疫S級以下的即死效果，並且無視任何低於S級的法術造成的不良狀況，這包括：法術導致環境的改變從而造成的不良狀態（禁魔場、時間結界等）、時間停止（the world等）、不良點數等。

**聖體**：你每1分鐘都視作進行了一次短休息，每半小時都視作進行了一次長休息，這在影響所有短休息和長休息相關的其他方面也如此，例如：能量的恢復、異常狀態或者不良點數的移除等。

**碎天神力**

<ul>
<li>你的天生武器的傷害從“L”變爲“A”。（如：天生武器3L變爲天生武器3A）</li>
<li>完全大成荒古聖體遠不止這樣的強度，但是由於缺乏對應的修行功法以及法則碎片，所以以下的部分只能當做展示用的擺設品，但是ST完全有理由讓某些PC獲得這些強化。</li>
</ul>


##  級　聖體小成--四極祕境

**屬性**：力量+8、耐力+8、決心+8

**特性**：絕對力量（四特性），荒古聖體（四特性），終極戰體（三特性），無窮神力（四特性）

**特殊**：由於支線翻倍4次，額外獲得8個特性，由於分數翻倍3次，額外獲得6個特性，由於沒有技能樹，額外獲得1個特性。

**其他標籤**

**絕對力量**：你的力量的所有加值變得可以疊加，你的基礎力量翻倍計算，並且你的肉搏攻擊除了造成傷害以外，還會在造成傷害之前先對目標的生命值上限造成傷害，數值等於你的傳奇力量。

**荒古聖體**：你的耐力的所有加值變得可以疊加，在計算生命值時耐力翻倍計算，同時你獲得的所有強化生命值上限的效果也翻倍，你在面對需要使用耐力、決心進行檢定的場合，可以直接使用耐力作爲結果。

**終極戰體**：你免疫所有的不良效果，包括不良點數、標記、固有不良狀態。

**無窮神力**：你在進行肉搏攻擊時，每消耗12點意志力，你的力量值便翻一倍，最多支付9次，這個效果持續一個場景。
