# 瞳人語

> 來源：`資源/瞳術/瞳人語`

**本質**：魔幻本質

**價格**：C+1200

**前提**：擁有佛力池，或學識技能大於4級

**描述**

<ul>
<li>生眯目不可開。才一拭視，而車馬已渺。驚疑而返。覺目終不快。倩人啓瞼撥視，則睛上生小翳；經宿益劇，淚簌簌不得止；翳漸大，數日厚如錢；右睛起旋螺，百藥無效。懊悶欲絕，頗思自懺悔。聞《光明經》能解厄。持一卷，浼人教誦。初猶煩躁，久漸自安。旦晚無事，惟趺坐捻珠。持之一年，萬緣俱淨。</li>
<li>忽聞左目中小語如蠅，曰：“黑漆似，叵耐殺人！”右目中應雲：“可同小遨遊，出此悶氣。”漸覺兩鼻中，蠕蠕作癢，似有物出，離孔而去。久之乃返，復自鼻入眶中。又言曰：“許時不窺園亭，珍珠蘭遽枯瘠死！”生素喜香蘭，園中多種植，日常自灌溉；自失明，久置不問。忽聞此言，遽問妻：“蘭花何使憔悴死？”妻詰其所自知，因告之故。妻趨驗之，花果槁矣。大異之。靜匿房中以俟之，見有小人自生鼻內出，大不及豆，營營然竟出門去。漸遠，遂迷所在。俄，連臂歸，飛上面，如蜂蟻之投穴者。如此二三日。又聞左言曰：“隧道迂，還往甚非所便，不如自啓門。”右應雲：“我壁子厚，大不易。”左曰：“我試闢，得與而俱。”遂覺左眶內隱似抓裂。少頃，開視，豁見幾物。喜告妻。妻審之，則脂膜破小竅，黑睛熒熒，才如劈椒。越一宿，幛盡消。細視，竟重瞳也，但右目旋螺如故，乃知兩瞳人合居一眶矣。生雖一目眇，而較之雙目者，殊更了了。由是益自檢束，鄉中稱盛德焉。</li>
</ul>

**價格**：C+1200

## C 級

**技能樹**：無

**特性**：瞳人（七特性）

**特殊**：由於沒有屬性和技能樹，額外獲得3個特性；一次性瞳術，額外獲得兩個特性。

**描述**：獲得此能力後，你雙瞳會成爲擁有智慧的瞳人。

**其他標籤**

**瞳人**

<ul>
<li>你的雙瞳會成爲擁有智慧的瞳人，你可以聽見並聽懂它們的之間的對話，但是隻有你自己可以聽見，如果你的交際技能在4級以上，則你可以與其進行對話。</li>
<li>這兩個瞳人被視爲一種體積值爲1的靈體，具有靈體特性。</li>
<li>它們的的互動系屬性和心智系屬性等同於你的感知值，調查技能與躲藏技能爲6級，其他數值皆與你剛進入影片時的數值相同，但臨時獲得的數值（包括但不限於天使之賜福提供的屬性，護身粘濘提供的全傷害吸收能力等）不會計算在內。</li>
<li>它們具備黑暗視覺和靈感視覺，擁有專長：廣博知識，道德值爲8。</li>
<li>你每次獲得XP時，它們也可同時獲得，但僅可用於爲其購買專長，提升其調查技能與躲藏技能等級。</li>
<li>兩個瞳人視作擁有C級特異本質與自然本質的偵測能力，只要有任意一名瞳人位於你眼睛內，你便視作擁有同樣的偵測能力，瞳人能夠以一個自由動作隱形，這是一個C級特異本質與自然本質的反偵測能力，在進行偵測與反偵測對抗時，瞳人的偵測與反偵測能力本質取優者決定。</li>
<li>無論如何這兩個瞳人不會參與，也沒能力進行戰鬥，它們也不會做任何違反其道德值級別的事。</li>
<li>當它們離開你的眼睛或死亡的時候，你視作失去對應的眼睛，這可能會使你陷入目盲狀態。</li>
<li>特殊的，瞳人可以隨時獲得你當前擁有的偵測與反偵測能力，並且它們能夠離開你自由行動，但需要注意的是本瞳術並不會給予你和它們進行心靈溝通的能力。</li>
</ul>
