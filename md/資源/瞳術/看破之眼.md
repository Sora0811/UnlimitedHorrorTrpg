# 看破之眼

> 來源：`資源/瞳術/看破之眼`

**本質**：特異本質、

**價格**：C+1200

**屬性**：感知+3，決心+3

**技能樹**：無

**特性**：識破（五特性）

**特殊**：沒有技能樹，額外獲得1個特性；由於是一次性瞳術，額外獲得2個特性。

**描述**

<ul>
<li>生物在說出言不由衷的話時，不管受過如何嚴格的訓練，都會出現“不自然”，而看破眼就能發覺這不自然，而生物注意力的改變也是能被洞察到的。</li>
<li>看破之眼並不是強大的動態視力或鷹一般的超視力，而是一種看似普通的遺傳能力――能發現生物細微的動作規律變化，經過特殊訓練後，可清楚察覺對方的肌肉細微運動。</li>
</ul>

**價格**：C+1200

**其他標籤**

**識破**：你在感受技能相關檢定上獲得6DP洞察加值，並且獲得該技能上的全部專業。此外，你在攻擊檢定與防禦上分別獲得6DP洞察加值，同時先攻增加6點。你在針對位於你敏感範圍內的目標進行感受技能相關檢定如果是“察言觀色”，則你該次感受技能檢定再獲得1點附加成功，並且若本次對抗勝出時，你在針對該目標進行的脅迫技能與說服技能相關檢定時獲得2個附加成功，持續一個場景。
