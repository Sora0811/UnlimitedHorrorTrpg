# 黑與白之瞳

> 來源：`資源/瞳術/黑與白之瞳`

**本質**：魔幻本質

**描述**

<ul>
<li>“紫色的櫻，是罪孽深重的人類靈魂寄宿的花。你就在那不斷飄落紫色櫻花的樹下，接受定罪吧！”</li>
<li>黑與白，是人類過去所做過的種種事物之稱。而這一切，全部都裸露在黑與白之瞳下。沒有任何人能夠欺騙它，它所看到的，是一切事物的真實的歷史。</li>
</ul>

## C 級

**價格**：C+1200

**屬性**：共6點屬性自由分配，最高項不超過3。

**技能樹**：無

**特性**：自由屬性分配，是與非的判別（雙特性），黑與白的裁決（雙特性）

**特殊**：由於沒有技能樹，額外獲得1個特性，由於爲一次性瞳術，額外獲得2個特性。

**描述**：現在你能通過黑與白之瞳，完全地瞭解他人所做過的任何事。

**價格**：C+1200

**其他標籤**

**是與非的判別**

<ul>
<li>你可以花費自由動作選擇一名位於你敏感範圍內的單位，之後你可以向其詢問一個答案爲“是”或“否”的問題（目標不需要聽到你的問題亦可生效，但是你一定要親口說出來，這意味着這是一個基於語言發動的能力），這個問題不能是目標的計劃或打算（如“你明天會不會開團”，“你在兩小時後會不會咕咕”等，具體由ST裁定），只能是已發生的事實（如“你有沒有鴿過我的團”，“你是不是女裝大佬。”等）。之後你就可以“看到”答案――這個答案以使用者能理解的方式漂浮在目標身邊，只有你能夠看見，這個答案必然爲“是”或“否”，不會有曖昧的回答，如果你的問題會造成曖昧的回答，則視爲該次你沒有使用本能力，這個能力不會給你任何加值或對目標和環境造成任何影響。它只會讓你知道你問題的答案。這是一個C級影響心靈的效果。</li>
<li>本能力與“黑與白的裁決”公佔使用次數，每天最多可以使用不超過你互動系傳奇屬性之和+1/次。</li>
</ul>

**黑與白的裁決**

<ul>
<li>你可以花費自由動作選擇一名位於你敏感範圍內的單位，之後你可以向其詢問一個問題，你不能提出任何會造成曖昧的回答的答案，否則會視作你該次沒有使用本能力。你可以得到該問題的答案（目標不需要聽到你的問題亦可生效，但是你一定要親口說出來，這意味着這是一個基於語言發動的能力），這個問題不能是目標的計劃或打算（如“你明天會不會開團”，“你在兩小時後會不會咕咕”等，具體由ST裁定），只能是已發生的事實（如“你有沒有鴿過我的團”，“你是不是女裝大佬。”等）。之後你就可以“看到”答案――這個答案以使用者能理解的方式漂浮在目標身邊，只有你能夠看見，但是你所能獲得的答案最多隻有20個字，如果超過20個字，那麼只會顯示前20個字，你在使用本瞳術的能力時可以選擇額外消耗任意次使用次數，每額外消耗1次使用次數便可以使答案多顯示20字，你必須在使用該次能力前選擇你總共要消耗的次數。這是一個C級影響心靈的效果。</li>
<li>本能力與“是與非的判別”公佔使用次數，每天最多可以使用不超過你互動系傳奇屬性之和+1/次。</li>
</ul>
