# 直死之魔眼

> 來源：`資源/瞳術/直死魔眼`

**本質**：特異本質

**描述**

<ul>
<li>凡事有始必有終，在這個因果關係下，所有事物都必定有終結、消滅的時候。而這個終結的時間在事物誕生的一瞬間就早已被決定，也就是所謂的死期。直死之魔眼是能夠直視萬物之死，並誘發其死亡之果，從而產生死亡之因的瞳術。</li>
<li>要看到事物的死，首先必須能夠理解事物的死。在對目標使用直死魔眼之前，必須先成功理解目標的死，這不需要進行判定。攻擊事物之死時，死線和死點並不真正佔據空間，因此範圍攻擊無法使用直死之魔眼。</li>
</ul>

**選開**：若目標爲概念：則你的感知必須至少達到10才能夠看到其死點或死線，並且神祕等級由ST判斷。（假定切斷一輪內時間的流動性難度爲20）

**特殊**：如無特殊說明，高級的直死之魔眼會替代低級的直死之魔眼特性。本瞳術下的所有效果（包括但不限於你攻擊目標死點或死線時的所有效果），皆爲等同於本瞳術等級的因果律效果。若要攻擊目標的死線，你必須先通過自身瞳術提供的“感知死亡”能力看見對方的死線後才能對其死線進行攻擊。

## D 級

**能量池**：無

**技能樹**：無

**特性**：線魔眼（六特性）

**特殊**：由於沒有能量池、技能樹與屬性，額外獲得4個特性。

**描述**：在這個等級，對於你能夠理解其死亡的事物，你可以看到像塗鴉般縱橫交錯的線在事物的表面上浮現，他代表着「容易將對象分割破壞的線」。在這個階段，你只能模糊的看到目標的死線，概念不存在分割，只有存在或消亡兩象，因此這個等級無法消滅概念。

**其他標籤**

**線魔眼**

<ul>
<li>若目標爲生物，攻擊生物的死線時，無視生物本身的盔甲防禦和盾牌防禦，但是不代表你擁有足夠高的破甲，這意味着這些盔甲盾牌的其他能力依然生效。由於生物的行動會使死線的位置產生變化，因此你在攻擊時受到無名減值，相當於目標當前的基礎防禦與閃避防禦之和。</li>
<li>目標因你攻擊死線而受到的本次傷害的一半提升1級，並且這些傷害的治療難度上升1級（其中的惡性傷害無法被主神以外的手段治癒）。</li>
<li>若目標爲物品，若該物品擁有基礎防禦（如穿着在身上的盔甲，拿在手中的武器，正在移動的載具等），則你在攻擊時受到的減值如同目標爲生物。若沒有基礎防禦，則你的攻擊不受減值，你攻擊死物的死線時，無視目標的裝甲值，直接對物品的結構值造成傷害。</li>
<li>每次你攻擊一個目標的死點或死線後，你不可避免的受到1點嚴重傷害，該嚴重傷害恢復難度等同於惡性傷害。</li>
</ul>


## C 級

**特性**：點線魔眼（五特性）

**特殊**：由於沒有技能樹和屬性，額外獲得3個特性

**描述**：通過對於“線”的瞭解，你慢慢明白了“點”的存在。

**其他標籤**

**點線魔眼**

<ul>
<li>若目標爲生物，攻擊生物的死線時，無視生物本身的盔甲防禦和盾牌防禦，某種意義上這代表着你擁有足夠高的破甲，這意味着這些盔甲盾牌的與破甲相關的能力不再生效。由於生物的行動會使死線的位置產生變化，因此你在攻擊時受到無名減值，相當於目標當前的（基礎防禦+閃避防禦）\*2。</li>
<li>目標因你攻擊死線而受到的本次傷害的一半提升1級，並且只能被主神治癒。</li>
<li>在攻擊死線或死點時，你可以選擇對目標進行特定部位攻擊，但這次攻擊你需要承受雙倍的特定部位攻擊減值，若你這麼做，則由該次特定部位攻擊帶來的不良狀態點數累積至重度不良狀態時，會視作進入毀滅性後果。</li>
<li>若目標爲物品，若該物品擁有基礎防禦（如穿着在身上的盔甲，拿在手中的武器，正在移動的載具等），則你在攻擊時受到的減值如同目標爲生物。若沒有基礎防禦，則你的攻擊不受減值，你攻擊死物的死線時，無視目標的裝甲值與一半硬度，直接對物品的結構值造成傷害。</li>
<li>每次你攻擊一個目標的死點或死線後，你不可避免的受到2點嚴重傷害，該嚴重傷害恢復難度等同於惡性傷害。</li>
</ul>

## A 級

**技能樹**：無

**特性**：方正魔眼（五特性）

**特殊**：由於沒有技能樹和屬性，額外獲得3個特性

**描述**：死點表示「事物的死」。在這個等級，對於你能夠理解其死亡的事物，對於你能夠理解其死亡的事物，你可以看到事物的死點，甚至包括概念。

**其他標籤**

**方正魔眼**

<ul>
<li>現在你啓動“感知死亡”只需要花費一個迅捷動作。</li>
<li>若目標爲生物，攻擊生物的死點時，由於死點並不在生物身上，並且沒有硬度的概念，所以無視生物的硬度，無視生物本身的天生防禦，盔甲防禦和盾牌防禦，並且無視這些盔甲盾牌的其他能力。</li>

<li>攻擊概念的死點時，你的攻擊不受減值，但是必須獲得相當於該概念神祕等級的成功數纔可將你所理解的概念毀滅。你應當在攻擊前與ST在概念毀滅的效果上取得一致，然後再進行對概念之死的理解。</li>

## S 級

**技能樹**：無

**特性**：直死魔眼（五特性）

**特殊**：由於沒有技能樹和屬性，額外獲得3個特性

**描述**：你現在可以完全理解死點的意義，並引導目標之死。

**其他標籤**

**直死魔眼**

<ul>
<li>現在你啓動“感知死亡”只需要花費一個迅捷動作，並且可以無視所有S級或以下的免疫因果律的效果。</li>
<li>若目標爲生物，攻擊生物的死點時，由於死點並不在生物身上，並且沒有硬度的概念，所以無視生物的硬度，無視生物本身的天生防禦，盔甲防禦和盾牌防禦，並且無視這些盔甲盾牌的其他能力。</li>
<li>但是生物的行動會使死點的位置產生變化，因此你在攻擊時受到無名減值，相當於目標當前的（基礎防禦+閃避防禦）\*5。</li>
<li>只要你命中死點，則目標宣告死亡，這是一個S級的即死效果。</li>
<li>但若你該次攻擊因你的DP數爲0或更低而只能投擲機運骰來決定是否可以命中，並在該次機運骰中擲出10而獲得成功，那麼目標也能進行一次機運骰，若目標也擲出10，你對死點的干涉由於某種不可抗力因素而失敗。</li>
<li>若目標免疫即死效果，則其因你攻擊死點而受到的傷害皆爲惡性傷害，並且只能被主神治癒。並且該傷害無視目標的傷害減免，傷害忽略，傷害吸收和傷害抵消能力。</li>
<li>在攻擊死線或死點時，你可以選擇對目標進行特定部位攻擊，但這次攻擊你需要承受雙倍的特定部位攻擊減值，若你這麼做，則由該次特定部位攻擊帶來的不良狀態點數累積至重度不良狀態時，會視作進入毀滅性後果。</li>
<li>若目標爲物品，若該物品擁有基礎防禦（如穿着在身上的盔甲，拿在手中的武器，正在移動的載具等），則你在攻擊時受到的減值如同目標爲生物。若沒有基礎防禦，則你的攻擊不受減值，你攻擊物品的死點時，無視物品的裝甲值和硬度，物品的結構值直接降低爲0而毀滅，因此毀滅的事物其原本的功用一概無法發揮（比如手雷）。</li>
<li>攻擊概念的死點時，你的攻擊不受減值，只要至少獲得1個成功即可將你所理解的概念毀滅。你應當在攻擊前與ST在概念毀滅的效果上取得一致，然後再進行對概念之死的理解。</li>
<li>每次你攻擊一個目標的死點或死線後，你不可避免的受到5點嚴重傷害，該嚴重傷害恢復難度等同於惡性傷害。</li>
</ul>


**其他標籤**

**感知死亡**：你花費一個標準動作來選擇一個在你敏感範圍視線內的目標，選擇後，你的感知值必須大於目標的神祕等級纔可以看到其死點或者死線。（若你無法看到死線，則動作也不返還）

**若目標爲生物**：則神祕等級爲1+目標的最高兌換能力等級\*3（D1,C2,B3以此類推）+最高傳奇屬性。

**若目標爲物品**

<ul>
<li>則神祕等級爲1+目標的支線等級+目標體積或硬度取高。</li>
<li>當你無法理解事物之死時，你可以嘗試強迫自己去理解。每對自己造成1點不可避免的智力傷害，你可以使你理解時的有效感知值提高1點，你能對自己造成的傷害總數至多相當於你的決心值，這結合在啓動“感知死亡”的標準動作內。</li>
<li>你無法得知你需要對自己造成多大的傷害才能理解目標之死，也無法在對自己造成傷害後反悔來撤消。</li>
<li>若所受傷害使你智力降低到0，那麼你將陷入昏迷直到恢復1點智力。因此造成的智力傷害你可以每進行1小時良好的休息和恢復1點。</li>
<li>當你看到目標的死線或者死點後，然後下次攻擊纔可以攻擊目標的死線或者死點，無論如何，針對同一名目標，你每回合只能攻擊一次對方的死線或死點。</li>
<li>看到目標的死線或者死點後，一旦目標退出你的敏感視線範圍，則下次需要重新觀察。</li>
<li>若目標免疫因果律，則你無法看到目標的死線或者死點。</li>
</ul>
