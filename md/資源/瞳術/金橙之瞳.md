# 金橙之瞳

> 來源：`資源/瞳術/金橙之瞳`

**本質**：魔幻本質

**前提**：需求智力6，力量6，擁有道力或真氣

**描述**：金橙之瞳，又名軒轅重瞳，在上古神話裏記載有重瞳的的人一般都是聖人，中國史書上記載有重瞳的只有八個人：倉頡、虞舜、重耳、項羽、呂光、高洋、魚俱羅、李煜。倉頡是黃帝時代的造字聖人；虞舜是禪讓的聖人，孝順的聖人，三皇五帝之一；晉文公重耳是春秋五霸之一；項羽則是曠古絕今的“西楚霸王”；呂光則是十六國時期橫掃西域的後涼國王；高洋是北齊建立者；魚俱羅相傳是用計設殺猛將李元霸隋朝名將；李煜是五代十國時南唐後主，著名的詞人，文學家。

**特殊**：購買本瞳術時，你必須在道力和真氣中選擇一項進行綁定，選定後不可更改，之後本瞳術所消耗的能量皆爲你綁定的能量池。

## D 級

**能量池**：無

**技能樹**：無

**特性**：心靈，力量，智慧，天命（三特性）

**特殊**：由於沒有技能樹、能量池和屬性，額外獲得4個特性。

**描述**

<ul>
<li>開啓瞳術後，華夏經典快速閃過你的眼睛，映入你的大腦，你的氣質也爲之一變，內聖外王。虹膜表面會有金色流光閃過，同時瞳孔變爲金色，微微擴大，生出內瞳，變爲內外兩個。</li>
<li>兩個瞳孔，象徵內聖外王，裏面的瞳孔，閃過日月星辰，象徵宇宙洪荒，智之巔――鴻鈞。</li>
<li>外面的瞳孔閃過山川草木，象徵天地玄黃，力之極――盤古。</li>
<li>在開啓本瞳術後，你對精神與身體的控制達到極致，可以進行內視，並且能夠從華夏經典裏獲得無數知識，洞悉萬事萬物的運作規律，使你獲得華夏氣運加身，成爲天選之人。</li>
</ul>

**其他標籤**

**心靈**：開啓本瞳術無須動作，但主動關閉本瞳術是一個自由動作，你可以在任何時候開啓本瞳術，即使你處於不良點數的毀滅狀態甚至無助中也一樣，開啓本瞳術需要支付1點意志力與1點能量，並且你每輪行動開始時都需要支付1點意志力與1點能量（這無需動作）或對自己造成2點不可避免的疲乏點數（該疲乏點數造成的效果無法被任何能力免疫，該疲乏點數只能通過一次短休息清除，且你在該次短休息中不會獲得其他由短休息帶來的好處。）以維持本瞳術，否則本瞳術會立刻關閉。在本瞳術開啓期間，你免疫相當於本瞳術等級的影響心靈效果。

**力量**：本瞳術開啓期間，你在力量相關檢定上獲得2DP洞察加值。

**智慧**：本瞳術開啓期間，你在智力相關檢定上獲得2DP洞察加值。

**天命**：本瞳術開啓期間，你在進行基因鎖解鎖檢定或任何機運骰檢定時在檢定結果上增加1點。


## C 級

**技能樹**：無

**特性**：提升-力量（雙特性），提升-智慧（雙特性），後發先至

**特殊**：由於沒有技能樹與屬性，額外獲得3個特性。

**描述**：瞳術啓動後，你洞悉了萬事萬物的運行規律，以不變應萬變，後發先制。

**其他標籤**

**力量**：本瞳術開啓期間，你在力量相關檢定上再獲得4DP洞察加值。

**智慧**：本瞳術開啓期間，你在智力相關檢定上再獲得4DP洞察加值。

**後發先至**：每回合一次，本瞳術開啓期間，你可以花費一個反射動作獲得一個移動動作，但你失去你下回合所有迅捷與移動動作。


## B 級

**技能樹**：無

**特性**：提升-力量（雙特性），提升-智慧（雙特性），提升-後發先至

**特殊**：由於沒有技能樹與屬性，額外獲得3個特性。

**其他標籤**

**力量**：本瞳術開啓期間，你在力量相關檢定上再獲得相當於你傳奇決心與傳奇風度之和的洞察加值。

**智慧**

<ul>
<li>本瞳術開啓期間，你在智力相關檢定上再獲得相當於你傳奇決心與傳奇風度之和的洞察加值。</li>
<li>提升-後發先至：每回合一次，本瞳術開啓期間，你可以花費一個反射動作獲得一個標準動作，但你失去你下回合所有迅捷與標準動作。</li>
</ul>


## A 級

**技能樹**：無

**特性**：神人（雙特性），至人（雙特性），提升-後發先至

**特殊**：由於沒有技能樹與屬性，額外獲得3個特性。

**描述**：無

**其他標籤**

**神人**：本瞳術開啓期間，你能夠以學識技能完全代替神祕學與科學技能（包括但不限於代替進行檢定，計算上限，取代其關鍵字，例如射程、法術效果、持續時間等等），同時你在學識技能上獲得【8加骰】。

**至人**

<ul>
<li>每部影片一次，你可以無需動作直接回復你所有意志力。</li>
<li>提升-後發先制：每回合一次，本瞳術開啓期間，你可以花費一個反射動作獲得一個整輪動作，但你失去你下回合所有移動動作。這取代本瞳術B級與C級同名特性。</li>
</ul>
