# 遠與近之瞳

> 來源：`資源/瞳術/遠與近之瞳`

**本質**：魔幻本質

**描述**

<ul>
<li>擁有操控距離程度的能力，可以將空間延伸或縮短，模糊遠近的界限，擁有者的瞳中不再具有遠近的概念，</li>
<li>而是無數個空間座標的點與線，投過兩個點將空間摺疊，或者將空間的曲線延展拉長</li>
<li>你的雙眸失去了正常的視覺，遠與近的界限在你的視線中模糊。</li>
</ul>

**屬性**：感知+2，沉着+2

**能量池**：無

**技能樹**：無

**特性**：遠與近的境界（四特性）

**特殊**：由於沒有技能樹和能量池，額外獲得2個特性。

## C 級

**屬性**：感知+3，沉着+3

**技能樹**：無

**特性**：遠與近的境界（三特性）

**特殊**：由於技能樹，額外獲得1個特性。

**描述**：物質的阻礙在你的眼中失去了效果，你可以直接看到不同距離的景象

**其他標籤**

**遠與近的境界**

<ul>
<li>你現在可以花費一點意志力，以一個移動動作或者反射動作調整空間上2個點的距離，持續1輪。</li>
<li>你最多可以將相當於你感知值\*10米的距離進行延長或者縮短。</li>
<li>需要注意的是，這種擴大和縮小改變的是座標上的2個點，這兩個點都必須處於你的視野範圍內，但無需效果線。</li>
<li>任何處於兩個點上的目標和單位都會受到影響，並且該影響將如同真實的距離一般影響雙方的移動距離，射程範圍，視距等。</li>
</ul>

**舉例而言**

<ul>
<li>一個目標攻擊你，你可以以反射動作啓動，然後擴大你與攻擊者之間的距離，從而“移動”出目標的攻擊範圍。</li>
<li>原本一個目標在你隊友的射程之外，你可以以移動動作，然後縮小目標與你隊友之間的距離，從而讓目標進入你隊友的射程範圍內。</li>
</ul>


## B 級

**屬性**：感知+4，沉着+4

**技能樹**：無

**特性**：遠與近的境界（三特性）

**特殊**：由於技能樹，額外獲得1個特性。

**描述**：我看到了！我看到了！一切的影像都是虛假的幻影，所有的一切不過是物質在不同空間座標的排序。

**說明**：具體位置表現爲你去過該地點，或者你可以準確描述該地點。

**其他標籤**

**遠與近的境界**

<ul>
<li>當你知道任何一個地點的具體位置時，你可以消耗3點意志力以一個整輪動作，將視覺切換到該點，你可以如同身臨其境一般觀測該點爲中心視距範圍內的具體情況，但這會讓你暫時失去你對自身周圍環境的視覺，直到你將視覺切換回自身。</li>
<li>請注意，這種方法只能讓你偵查該地點，你無法通過任何方式藉助本能力來影響該區域。（如施展射程無限，只需視野線的能力）</li>
</ul>


**其他標籤**

**遠與近的境界**

<ul>
<li>你可以用雙目操控距離的遠近，你可以自由調節你的視距，你可以將你的視距擴大或者縮小相當於你感知屬性\*10米的距離。</li>
<li>舉例而言，若你的視距爲20米，但敵人在距離你30米的位置，你的感知屬性爲4，則你可以上調40米，從而看見他。</li>
</ul>
