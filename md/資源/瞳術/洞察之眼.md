# 洞察之眼

> 來源：`資源/瞳術/洞察之眼`

**本質**：魔幻本質

**前提**：需求神祕學技能3級以上，擁有魔力，生命之力，靈力，精神力，罪或血量之一的能量池。

**描述**：通過對現實之外的世界的探索，你現在獲得了一種特殊的視力，可以看到現世以外的東西--魔法，靈體，甚至過去與未來。

**特殊**：購買本瞳術時，你必須在魔力，生命之力，靈力，精神力，罪或血量中選擇一個進行綁定，選定後不可更改，之後本瞳術所消耗的能量皆爲你綁定的能量池或刻度，若選擇靈力，則會直接積累與能耗等額的靈感疲勞。

## D 級　魔法探知

**能量池**：無

**技能樹**：無

**特性**：魔法探知（六特性）

**特殊**：由於沒有技能樹、能量池和屬性，額外獲得4個特性。

**描述**：通過與界域間神祕力量的聯結， 你獲得了第二重視覺，可以看到魔法的靈光。開啓瞳術後，你的瞳孔會偏向藍色

**其他標籤**

**魔法探知**

<ul>
<li>你可以花費標準動作支付1點能量開啓本瞳術，之後你每過5輪便需要在當前輪行動開始時支付1點能量以維持本瞳術（這無需動作），否則本瞳術會立刻關閉。主動關閉本瞳術是一個自由動作。</li>
<li>本瞳術開啓期間，針對魔幻本質的物品或擁有關鍵屬性包含心智系屬性能量池的單位，你視作擁有B級魔幻本質的偵測能力，範圍等同於你的敏感範圍。</li>
</ul>


## C 級　奧術視覺

**技能樹**：無

**特性**：奧術視覺（雙特性），洞悉未來（三特性）

**特殊**：由於沒有技能樹和屬性，額外獲得3個特性。

**描述**：現在，你可以更輕鬆的瞭解周圍的一切魔法現象。開啓瞳術後，你的雙眼會變成湖藍色，深不見底，瞳孔彷彿通往另一個世界。現在你已經可以在一定程度上看到未來。通過將自己的意識向未來延伸數秒鐘，你得以更好地閃避對方的攻擊，或者繞開對方的防禦以擊中對手。

**其他標籤**

**奧術視覺**：本瞳術開啓時，你可以額外最多支付最多瞳術等級\*2點能量，每點能量可以讓你的心智系屬性獲得1點內在加值，單屬性最大分配爲你的最大瞳術等級.

**洞悉未來**：你在防禦和所有檢定上獲得等同於你傳奇感知的洞察加值。


## B 級　高等奧術視覺

**技能樹**：無

**特性**：高等奧術視覺（雙特性），廣域能量池探知，高等洞悉未來，看透表象

**特殊**：由於沒有技能樹和屬性，額外獲得3個特性。

**描述**：你現在洞悉一切魔法，魔力在你眼前無所遁形。

**其他標籤**

**高等奧術視覺**：現在本瞳術D級提供的偵測能力提升至A級，此外，你可以針對每種被你感應到的持續性效果分別進行一次感知+神祕學檢定來辨識他的效果，與其施展者的意志檢定進行一次對抗，若你勝出則可以立刻得知該持續性能力的具體效果，若你失敗則本場景內無法再對該持續性效果進行辨識。

**廣域能量池探知**：本瞳術開啓期間，你每輪可以以一個自由動作選定你敏感範圍內一名單位，你進行一次感知+神祕學檢定，之後對方以意志豁免，若你勝出，則你可以立刻得知目標當前所擁有的所有能量池，以及這些能量池當前的上限、剩餘能量數值與其基礎用法，並且針對目標擁有的每一個能量池，你可以分別得知目標當前所擁有的，能夠以該能量池驅動的能力數量以及這些能力各自的支線等級。若你失敗，則你得到的信息並非“失敗”，而是“對方沒有相關能量池”。

**高等洞悉未來**：每回合一次，你可以無需動作隨時支付3點能量，使“洞悉未來”的效果改爲使你在防禦和所有檢定上獲得等同於你傳奇感知的附加成功，持續1輪。

**看透表象**：你免疫B級以下的幻覺效果。


## A 級　真實之眼

**技能樹**：無

**特性**：真實之眼，提升-看透表象，提升-洞悉未來（三特性）

**特殊**：由於沒有技能樹和屬性，額外獲得3個特性。

**描述**：對超自然世界的探知使得你可以免疫某些物理的影響，甚至能夠將意識投射到非常遠的未來，以獲得某些信息。在瞳術開啓期間，你的雙眼瞳仁會與眼白融爲一體，都變成朦朧的灰黑色。

**其他標籤**

**真實之眼**

<ul>
<li>現在開啓本瞳術無須動作，並且你可以直接看穿所有易容、僞裝以及A級以下的變形效果帶來的外形變化。</li>
<li>提升-看透表象：針對魔幻本質的物品或擁有關鍵屬性包含心智系屬性能量池的單位，你獲得真實視覺。此外，你的偵測能力完全不會受到目盲的負面影響（你依然會陷入目盲），這在畫面上表現爲你的瞳術使你能夠在目盲的情況下看到的一切魔法效果、超自然靈光，並可以保持朦朧的視覺，可以大致分辨瞳術範圍內的物體輪廓。本特性取代B級“看透表象”特性。從此你不會因爲失去眼珠或者目盲等效果失去你由於瞳術帶來的一切效果。</li>
<li>提升-洞悉未來：本瞳術開啓期間，每輪開始時你都會獲得等同於你傳奇感知\*3的“洞悉”點數，“洞悉”點數會當輪結束時清零，你在進行任意檢定時可以無須動作直接消耗任意點“洞悉”點數，使該次檢定等額的骰子自動取10，但這不會帶來加骰。</li>
</ul>
