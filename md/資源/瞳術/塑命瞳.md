# 塑命瞳

> 來源：`資源/瞳術/塑命瞳`

**本質**：特異本質

**描述**：塑命瞳擁有干涉命運的力量，它能使擁有者觀察，預知，對抗甚至更改命運，是一種強力的瞳術，但只有意志堅強的人才能不被所見的命運洪流淹沒。

## D 級

**能量池**：無

**技能樹**：無

**特性**：預知眼（六特性）

**特殊**：由於沒有技能樹、能量池和屬性，額外獲得4個特性。

**描述**：購買此種瞳術後，瞳孔的中心部分會變爲金色，但外圍仍是黑色。你成爲了命運的預知者，能看到3秒之後的世界。

**其他標籤**

**預知眼**

<ul>
<li>你可以花費一個自由動作支付1點意志力主動開啓本瞳術，持續1輪。在瞳術開啓期間，你獲得以下兩項效果：</li>
<li>\1.你在所有技能相關檢定上獲得4DP洞察加值。</li>
<li>\2.你在進行一個結果立即可見的行動時（例如幾乎所有的標準動作和移動動作可以完成的事，攻擊，撞門，跑跳等等，具體由ST裁定），你可以額外支付1點意志力，之後若該行動需要且僅需進行一次檢定，則你可以照常進行該次檢定，並在得知該次行動的結果後選擇是否接受該結果，若你接受該結果則這次行動如常進行，若你不接受該結果則你這次行動視作沒有進行，但你本輪無法再進行該行動。本能力無須動作即可發動，但你無法使用本能力進行任何基因鎖相關的檢定。</li>
</ul>


## C 級

**技能樹**：無

**特性**：觀察眼（五特性）

**特殊**：由於沒有技能樹和屬性，額外獲得3個特性

**描述**：你的瞳孔完全變成金色。你成爲了命運的觀察者，能在瞬間將你這雙眼睛曾經看到過的事物在腦海中重放，利用這瞬間完成的效果，在戰鬥中可以反覆觀察來推測和分析對手的動作。

**其他標籤**

**觀察眼**

<ul>
<li>你每次受到攻擊後，無論該次攻擊是否有命中你，只要你親眼看見了目標這次攻擊的整個過程（這意味着如果對方在施法或攻擊你的途中進入了隱身或類似狀態，則視作你沒有親眼看見整個過程），那麼你便可以記錄目標該次攻擊的攻擊方式（攻擊方式細分爲：使用槍械進行的遠程攻擊、使用弓箭進行的遠程攻擊、使用近戰白刃武器進行的近戰攻擊、使用施法檢定進行的遠程攻擊/近戰攻擊等，具體可由ST裁定），之後在本場景內你再次被同一目標以你這次記錄的攻擊方式所攻擊，則僅針對該次攻擊，你可以選擇立刻獲得1個額外的反射動作，該反射動作不會消耗你下一輪的迅捷動作，但只能針對對方該次攻擊使用。</li>
<li>在場景切換後，無論如何你都必須重新記錄攻擊者的攻擊方式才能獲得以上效果，你每輪最多隻能通過此法獲得2個額外的反射動作。</li>
</ul>


## B 級

**技能樹**：無

**特性**：自塑眼（五特性）

**特殊**：由於沒有技能樹和屬性，額外獲得3個特性

**描述**：你金色的瞳孔外出現一圈環繞的銀線。你成爲了命運的自塑者，通過調整自身來對抗命運。

**其他標籤**

**自塑眼**

<ul>
<li>本瞳術主動開啓期間，在進行任意檢定時，若你對檢定結果不滿意，你可以無須動作支付1+本場景已透過本能力重投的次數/點意志力重投該次檢定，你可以反覆重投，但是無論結果如何你都必須接受最後一次重投後的結果，你每天可在此法上支付的意志力不得超過你意志力池的一半。</li>
<li>此外每場景一次，你可以花費自由動作支付不超過本瞳術等級（D1C2B3A4）點意志力，每支付1點意志力你便可以選擇自身一項屬性並使其獲得4點洞察加值，同一項屬性不可多次選擇，加值持續一個場景。</li>
</ul>


## A 級

**技能樹**：無

**特性**：外塑眼（三特性），操縱命運（雙特性）

**特殊**：由於沒有技能樹和屬性，額外獲得3個特性

**描述**：你金色的瞳孔和瞳孔外的銀線之間，由以奇異的軌跡互相纏繞的金線和銀線相連。你成爲了命運的干涉者，你可以直接調整命運。

**其他標籤**

**外塑眼**

<ul>
<li>本瞳術主動開啓期間，你再獲得以下兩項效果：</li>
<li>\1.你可以花費反射動作將你視距內的一個單位時間回溯，效果等同於“三秒輪迴”，這是一個A級時間效果。無論如何，本能力每場景僅能施展一次。</li>
<li>\2.當你視距範圍內任意一名單位進行一次檢定時，你可以在得知其該次檢定結果後花費反射動作令其重投該次檢定，之後由你選擇將其中一次檢定結果作爲其該次檢定的最終結果，這是一個A級因果律效果。無論如何，本能力每場景僅能施展一次。</li>
</ul>

**操縱命運**：每次切換場景時，你額外獲得2個準備動作，該準備動作可以在你任意一輪中宣言使用，並且宣言該準備動作既不會消耗你的標準動作也不會使你下一輪失去任何動作。
