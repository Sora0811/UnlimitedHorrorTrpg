# 石化魔眼

> 來源：`資源/瞳術/石化魔眼`

**本質**：魔幻本質

**前提**：擁有一個通用能量池

**描述**：神話時代由魔獸美杜沙所持有的瞳，具有將直接看到此瞳者石化的力量，一旦獲得不分敵我，無法封閉。將本來用"看"來得到情報的眼球的機能，作爲用"看"來向對手施以魔術的手段來使用的能力被稱爲魔眼。美杜莎有着即使在魔眼之中也是相當於最高等級的石化魔眼"Cybele"。在持有者有意識的催谷該瞳術的前提下，可以發揮一些額外的效果

**特殊**：如無特殊說明，本瞳術造成的所有效果皆視爲與本瞳術同等級的詛咒效果。本瞳術被動生效，但你與目標必須互相擁有視野線（即你們必須能互相看見對方，若目標處於目盲狀態下，則無視你本瞳術帶來的一切效果）且你們必須互相位於對方的敏感範圍內，否則該目標便不會受到本瞳術影響。

## D 級

**屬性**：耐力+1 感知+1 風度+2

**能量池**：無

**技能樹**：無

**特性**：凝固（四特性）

**特殊**：由於沒有技能樹和能量池，額外獲得2個特性。

**其他標籤**

**凝固**

<ul>
<li>受本瞳術影響的目標，其在與生理系屬性相關的檢定以及基礎防禦、格擋防禦和閃避防禦上分別承受1點無名減值。</li>
<li>你可以花費1個自由動作支付X點通用能量（但你每次增幅只能以同一種能量進行增幅，即你不能分別支付1點魔力與1點內力來增幅一次本瞳術效果。）對本瞳術的效果進行增幅，使本瞳術帶來的無名減值暫時增加X點，X爲你的傳奇風度，持續1輪。</li>
</ul>


## C 級

**屬性**：耐力+2 感知+1 風度+3

**技能樹**：無

**特性**：提升-凝固（三特性）

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得1個特性。</li>
<li>提升-凝固：除D級特性外，每回合一次，當你對本瞳術效果進行增幅時，若你以此法支付的能量超過3點，你可以花費一個移動動作使所有受到本瞳術影響的單位立刻分別與你進行一次意志對抗，若你勝出則對目標造成等同於你勝出數的晶化點數，該晶化點數持續一個場景，不可疊加，當目標不再受到本瞳術影響時，該晶化點數會在目標每回輪開始時降低1點。</li>
<li>現在X爲你的傳奇風度+瞳術等級\*2。</li>
</ul>

## B 級

**屬性**：耐力+2 感知+2 風度+4

**技能樹**：無

**特性**：提升-凝固（三特性）

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得1個特性。</li>
<li>提升-凝固：現在你的D級特性不會使其受到無名減值，而是改爲使受影響目標在生理系屬性相關檢定上失去等同於該無名減值的成功數，以及等額的防禦附加成功。</li>
<li>此外，你現在C級能力造成的晶化點數可以疊加。</li>
<li>你現在可以選擇不超過你傳奇感知/名單位，使其不受到本瞳術影響，每回合開始時，你可以隨時更改你以此法選擇的單位，這無需動作。</li>
</ul>

## A 級

**屬性**：耐力+3 感知+3 風度+6

**技能樹**：無

**特性**：提升-凝固（三特性）

**特殊**

<ul>
<li>由於沒有技能樹，額外獲得1個特性。</li>
<li>提升-凝固：現在本瞳術造成的晶化點數只要超過目標的力量值或意志值（兩者取低），便會使目標陷入毀滅性後果。</li>
<li>此外，本瞳術造成的所有效果同時屬於A級因果律和詛咒效果，這意味着目標需要同時免疫這兩者才能夠免疫本瞳術效果影響。</li>
<li>現在X爲你的風度值。</li>
</ul>
