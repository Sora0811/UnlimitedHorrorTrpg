# 火眼金睛

> 來源：`資源/瞳術/火眼金睛`

**本質**：魔幻本質

**屬性**：無

**價格**：C+1200

**技能樹**：無

**特性**：火眼金睛（七特性）

**特殊**：一次性瞳術獲得2個特性。由於沒有技能樹，額外獲得1個特性。由於沒有屬性，額外獲得2個特性。

**價格**：C+1200

**其他標籤**

**火眼金睛**

<ul>
<li>角色可以直接看破B級以下的幻覺、變形效果。同時角色免疫幻覺。</li>
<li>角色在視覺模糊敏感範圍內獲得透視能力，可以直接透視任何支線等級不超過B級的障礙物，並且可以自行決定不透視一些指定材質。</li>
<li>角色可以無需動作支付1點意志力，在3輪內，免疫幻覺與看破變形能力的支線等級提升1級。</li>
</ul>
