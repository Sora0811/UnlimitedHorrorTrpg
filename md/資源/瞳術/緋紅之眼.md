# 緋紅之眼

> 來源：`資源/瞳術/緋紅之眼`

**本質**：魔幻本質

**價格**：D+600

**能量池**：念能力

**技能樹**：無

**特性**：絕對時間（七特性）

**特殊**：由於沒有技能樹和屬性，額外獲得3個特性；由於爲一次性瞳術，額外獲得2個特性。

**描述**：窟廬塔族族人，原來在窟廬塔的深山地區隱居。當他們情緒激動的時候，瞳孔會變成緋紅色。擁有“世上七大美色”之一的窟廬塔族族人，引來了爲了奪取[緋紅之眼]的十三隻蜘蛛――幻影旅團的襲擊，最後，窟廬塔族就只剩下酷拉皮卡一人。

**價格**：D+600

**其他標籤**

**絕對時間**

<ul>
<li>當你陷入憤怒中（具體由ST裁定）或觸發惡德：憤怒時，本瞳術會強制開啓，此時你的瞳孔會變爲緋紅色。你也可以花費自由動作支付1點念能力主動開啓本瞳術，之後你每過5輪便需要在當前輪行動開始時支付1點能量以維持本瞳術（這無需動作），否則本瞳術會立刻關閉。主動關閉本瞳術是一個自由動作。</li>
<li>瞳術開啓期間你會在風度上獲得2點表現加值，決心上獲得2點表現加值。</li>
<li>並且在使用念能力下的能力時不會因爲念能力系別不同而承受減值，同時還可以如同你的念能力同時屬於念能力所有系別一般獲得對應的加值（比如說，使用應用技“纏”“練”“周”“硬”“堅”時，可以如同強化系能力者一樣獲得DP加值。使用應用技“隱”時，可以如同具現化系能力者一樣獲得DP加值。），如果你已開啓念能力能量池，則無論你的念能力原本爲哪種系別，你的念能力都會改爲特質系，持續一個場景。</li>
</ul>
