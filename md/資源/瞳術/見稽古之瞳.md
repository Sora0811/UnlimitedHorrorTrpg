# 見稽古之瞳

> 來源：`資源/瞳術/見稽古之瞳`

**本質**：魔幻本質

## D 級　見稽古・明

**能量池**：無

**技能樹**：無

**特性**：鷹視（雙特性），看破（三特性）、洞察

**特殊**：由於沒有技能樹、能量池與屬性，額外獲得4個特性。

**描述**：無論是什麼東西，是書面文字，武器的使用，還是各種奇異的武術、甚至是體質，像是其他種族的遺傳能力，幾乎是世界上的所有東西，只要親眼看過一遍，便可完全瞭然於心並且熟練使用，是一種近似怪物的技術/能力。――《刀語》

**其他標籤**

**鷹視**：你在攻擊檢定與防禦上分別獲得3DP洞察加值。

**看破**：你在感知相關檢定上獲得1個附加成功。

**洞察**：你在調查相關檢定上獲得3DP洞察加值。


## C 級　見稽古・曉

**技能樹**：無

**特性**：提升-鷹視，洞察（三特性），提升-看破

**特殊**：由於沒有技能樹和屬性，額外獲得3個特性

**描述**

<ul>
<li>看破對手的行動只是第一步，見稽古之眼的能力還遠未達到極限。</li>
<li>提升-鷹視：你在攻擊檢定和防禦上再分別獲得3點洞察加值。</li>
<li>提升-看破：你在感知相關檢定上再獲得2個附加成功。</li>
</ul>

**其他標籤**

**洞察**

<ul>
<li>你以一個標準動作，消耗1點意志力，觀察一個目標，進行一個感知+調查（偵查）的檢定，然後當你攻擊該目標時，你獲得相當於你檢定成功數的修行加值，持續一個場景，你同一時間只能觀察一個目標。同時根據成功數，你得知該目標對應的信息，具體如下表：</li>
<li>成功數 效果</li>
<li>3 得知對方慣用的武器類別。</li>
<li>5 得知對方所有生理技能值的具體數值。</li>
<li>8 得知對方曾被你親眼目睹過的一項技藝的大致效果。</li>
<li>12 得知對方曾被你親眼目睹過的一項技藝的數值構成（如關鍵屬性、加值類型等）。</li>
</ul>


## B 級　見稽古・悟

**技能樹**：無

**特性**：提升-鷹視，提升-看破，記憶（三特性）

**特殊**：由於沒有技能樹和屬性，額外獲得3個特性

**描述**

<ul>
<li>見稽古的觀察效果進一步提升，現在你對在戰場上發生的所有情況瞭然於胸。</li>
<li>提升-鷹視：你在攻擊檢定和防禦上再分別獲得6DP洞察加值。</li>
<li>提升-看破：你在感知相關檢定上再獲得4個附加成功。</li>
</ul>

**其他標籤**

**記憶**

<ul>
<li>當你親眼目睹任何單位施展了任意一項能力（包括但不限於血統、稱號技能樹下的技能、魔導書下的法術等）後，你可以一個反射或迅捷動作進行一次感知+調查（偵查）檢定來“看穿”對方的招式，DC爲對方該技能支線等級的五倍（D1C3B5……無支線招式視爲0.5級），向上取整。</li>
<li>在看穿成功的情況下，你可以立即複製該能力，但此能力只能複製支線等級不超過本瞳術等級的能力。之後在本場景中，你可以施展你複製過來的能力，同時你必須滿足使用條件（即必須擁有推動那種招式或技能的同類型能量，以及滿足技能使用前提。比如在沒有選擇七夜血脈時，你不能複製七夜體術；不是血族則無法複製血族異能；在沒有劍修C級時，也不能複製“紅塵一步終”的劍招，如果是法術，必須完整看到對方施法的全過程，並且自己也擁有相同等級的、對應的施法者職能，並且你習得的法術無論對方是否升階和研發，你只能獲得最初版本，同時你也無法複製有使用次數限制的能力。</li>
<li>你可以隨時遵循自學技能規則，自學被你“看穿”的能力，但在以此法自學能力時，你只能自學支線等級不超過你見稽古之瞳等級的能力，這項能力必須是能主動開啓的技能，不能是被動能力。同時你必須滿足使用條件，即便已經切換場景你也能隨時花費相應的經驗進行自學。</li>
</ul>


## A 級　見稽古・破

**技能樹**：無

**特性**：明晰，提升-記憶（三特性），提升-看破

**特殊**：由於沒有技能樹和屬性，額外獲得3個特性

**描述**：你看事物的眼睛變得更加明晰，就像破開迷霧，這也進一步強化了你對技藝和能力的領悟。

**其他標籤**

**明晰**

<ul>
<li>你從“鷹眼”特性中獲得的洞察加值再提升12點。</li>
<li>提升-記憶：現在針對你能夠親眼目睹的單位，你可以每輪消耗一個標準動作進行一次感知+調查（推演）的延長檢定，當成功數達到60個時，你可以“看穿”對方，得知對方所有A級或以下的主動和被動能力的具體效果，並且你現在可以複製和自學被你“看穿”的被動能力，但在自學時你仍需滿足其使用條件並遵循自學技能規則。</li>
<li>（複製被動能力包括純被動的能力，以及持續時間爲永久的能力，若該能力需要啓動，則你依然需要啓動，對於無需啓動的能力，則你直接獲得該效果）</li>
<li>提升-看破：你在感知相關檢定上再獲得8個附加成功。</li>
</ul>
