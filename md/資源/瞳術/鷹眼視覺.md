# 鷹眼視覺

> 來源：`資源/瞳術/鷹眼視覺`

**本質**：特異本質

**描述**：鷹眼視覺是先行者後裔們所具有的一種特殊感官，擁有此天賦者能夠本能的感受到人們和物體與自己的關聯，並以不同的彩色輝光作爲標示。

## D 級　鷹之感官

**能量池**：無

**技能樹**：無

**特性**：黑暗視覺，鷹之覺察（雙特性），察覺敵意（三特性）

**特殊**：由於沒有屬性、技能樹和能量池，額外獲得4個特性。

**描述**：鷹眼視覺是是人類被第一文明創造的結果。儘管每個人都具備這種潛質，但那些曾與自身創造者交合的人類後裔擁有更多啓用這種感官的必要基因，因而更有可能展現這種能力。主動開啓本瞳術後，你眼中的一切色彩都會褪去，彷彿是褪色的老相片，又彷彿在水底望向天空。

**其他標籤**

**黑暗視覺**：你獲得黑暗視覺。

**鷹之覺察**：你在調查和感受技能相關檢定上獲得2DP內在加值。

**察覺敵意**

<ul>
<li>以一個標準動作，支付1點意志力主動開啓本瞳術，本瞳術開啓期間，你失去你的模糊範圍。本瞳術最多持續等於你沉着值的輪數，主動關閉本瞳術是一個自由動作。</li>
<li>但本瞳術開期間，你獲得相當於C級特異本質的偵測能力，範圍等同於你的敏感範圍。並且你可以感應到任何處於你敏感視覺範圍內的“敵意目標”的生物（這包括不死生物，構裝體等在內），若敵意目標位於你敏感範圍內，你針對該目標的攻擊視作擁有C級免疫措手不及能力。</li>
<li>通常來說，生物必須與你進行過某種程度的互動纔會對你產生敵意，但你不一定能夠察覺這次互動。舉例而言，敵方的輪迴者通過心靈掃描確定了你敵人的身份並對你產生了敵意，儘管你並不知道這件事情，但你仍然能夠察覺對方的敵意。</li>
</ul>


## C 級　真實視域

**技能樹**：無

**特性**：察言觀色，提升-察覺敵意（四特性）

**特殊**：由於沒有屬性和技能樹，額外獲得3個特性。

**描述**：在你能夠嫺熟的操控鷹眼視覺之後，就有可能使其昇華爲更爲強大的形態。它能增進使用者全部官能，使他們能探測到特定區域內目標的心跳，甚至預知目標的行蹤。

**其他標籤**

**察言觀色**

<ul>
<li>你只需要通過觀察就能瞭解他人的想法，每輪一次，針對一個目標，你可以用感知+感受（察言觀色）對抗對方的智力/操縱+掩飾，如果你勝出，則可以讀取對方的表面情緒。你能感覺到基礎的需求、動力和情緒。口渴、飢餓、恐懼、疲乏、痛苦、憤怒、憎恨、懷疑、好奇、友善，以及其他種種感情都可被感知，這無需動作。</li>
<li>提升-察覺敵意：本瞳術開啓期間，本瞳術提供的偵測與免疫措手不及能力提升至B級，並且現在“敵意目標”還包括能夠對你產生威脅的機關、陷阱或自然環境的存在，你還可以判斷出該存在的強度（以你自身強度作爲標準數值，得到的結果不會很精確，只能大概瞭解“比我強一點，互懟的話說不好誰贏”又或者“比我強很多，爆發底力也可能會死”等等。）和類別（例如是人類、生物、人造陷阱還是危險的自然環境，但你需要相關的知識來判定種類）。</li>
</ul>


## B 級　未來視界

**技能樹**：無

**特性**：提升-察覺敵意（五特性）

**特殊**：由於沒有屬性和技能樹，額外獲得3個特性。

**描述**

<ul>
<li>當你睜開鷹眼時，一切僞裝在你的眼中都無所遁形，你的雙眼能夠看到萬事萬物的真實面目――直到最後，先行者的後裔們覺醒了和他們最早的祖先相同的能力，他們的雙眼能夠看穿時間的長河，從無限的未知中選擇最恰當的可能性。</li>
<li>提升-察覺敵意：本瞳術開啓期間，本瞳術提供的偵測能力提升至A級，並且每回合一次，你在進行攻擊檢定時，可以檢定兩次，你的第一次檢定不造成實際效果，而是使你的第二次檢定獲得等於你第一次檢定成功數的DP洞察加值（上限爲你的當前敏捷值），這被視爲你通過觀測未來而知曉應該如何恰當行動。</li>
</ul>
