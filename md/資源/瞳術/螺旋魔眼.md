# 螺旋魔眼

> 來源：`資源/瞳術/螺旋魔眼`

**本質**：魔幻本質

**描述**：以視線開啓迴轉軸：左眼爲左迴轉，右眼爲右迴轉，可扭曲注視物體的能力。 這個能力所取決的並不是對象的堅硬度而是體積，無論多麼堅固的物體都可以無視其強度而輕易的予以扭曲。

## D 級

**能量池**：無

**技能樹**：無

**特性**：扭曲（九正特性三負特性）

**特殊**：由於沒有屬性、技能樹和能量池，額外獲得4個特性。

**描述**：開啓本瞳術時，別人可以看到你的瞳孔中有不斷扭曲成螺旋的彩色光圈，在此時你只能看到包裹物體的輪廓線，但你可以隨時在自己視線中描繪迴轉軸，你可以如常看到靈體。

**其他標籤**

**扭曲**

<ul>
<li>你可以花費標準動作主動開啓或關閉本瞳術，在本瞳術開啓期間，你失去模糊範圍，並且當你進行需要指定目標的行動時（例如用手拿東西，攀爬山岩，用槍械進行連射等），你在與該行動相關的檢定上承受6DP無名減值。</li>
<li>本瞳術開啓期間，你獲得靈感視覺。</li>
<li>你可以花費標準動作指定一名位於你敏感範圍內的單位，之後以決心+感知+本瞳術等級（D1C2B3）檢定對其進行一次遠程接觸攻擊，該次攻擊需承受本瞳術帶來的無名減值，並且本攻擊必須且僅需你對目標擁有視野線便可發動，造成物理嚴重傷害，該次攻擊傷害上限爲你的決心值，你每天只能以本方式進行不超你決心值\*1次攻擊，若超過則每次以本方式進行攻擊時都會立刻受到1點不可避免的疲乏點數，該疲乏點數可疊加，可進入毀滅性後果。</li>
</ul>


## C 級

**技能樹**：無

**特性**：提升-扭曲（五特性）

**特殊**：由於沒有屬性和技能樹，額外獲得3個特性。

**描述**

<ul>
<li>現在你可以在一個物體上開啓兩個迴轉軸，從兩個螺旋的交界處捻斷物體。</li>
<li>提升-扭曲：現在本瞳術開啓期間你不會再失去模糊範圍，並且在進行需要指定目標的行動時不會再受到本瞳術帶來的減值，並且本瞳術能力造成的傷害改爲力場嚴重傷害。</li>
</ul>

## B 級

**技能樹**：無

**特性**：提升-扭曲（五特性）

**特殊**

<ul>
<li>由於沒有屬性和技能樹，額外獲得3個特性。</li>
<li>提升-扭曲：現在本瞳術開啓期間可以透視原本會阻隔你視線的屏障，比如你現在可以隔着牆壁或魔法屏障看到其後面的生物，但是B級以上的超自然性質的屏蔽或類似效果仍可以阻隔你的視線。</li>
<li>此外，當你以本瞳術的能力進行攻擊時，可以選擇位於你視距內的單位作爲該次攻擊目標，並且你每有1點傳奇感知，則可以將你造成傷害中的2點傷害提升1級（嚴重-惡性）。本次攻擊能夠分別忽略目標不超過你傳奇決心\*2點的傷害減免和硬度，還會對目標造成等同於該次攻擊造成傷害數的肢體妨害點數，該肢體妨害點數可疊加，不可豁免。</li>
</ul>
