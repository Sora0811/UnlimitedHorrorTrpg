# 法力

> 來源：`資源/能量池/法力`

**本質**

<ul>
<li>魔幻本質</li>
<li>法力是一個特殊能量池。</li>
</ul>

**描述**

<ul>
<li>當然，它一般被俗稱爲“藍”，或者MP。</li>
<li>你選擇自身的一個生理系屬性和一個心智系屬性作爲關鍵屬性。</li>
<li>法力池的上限爲2個關鍵屬性之和。</li>
</ul>

**正文**

獲得法力能量池時，你選擇獲得以下兩種基礎用法中的一個，一旦選擇，不可更改：

\1. 當你進行生理系技能檢定時，你可以無需動作，消耗1點法力，使該次檢定獲得1DP增強加值。

\2. 當你進行心智系技能檢定時，你可以無需動作，消耗1點法力，使該次檢定獲得1DP增強加值。

法 力的恢復方式：每天你可以獲得3倍法力值力總值的恢復量，平均到每小時上。若每小時回覆的超過6點，則平均到每10分鐘上。
