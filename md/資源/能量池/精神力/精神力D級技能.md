# 網域服務器快取污染

> 來源：`資源/能量池/精神力/精神力D級技能`

**價格**：D+500

**動作**：標準動作

**能耗**：1點精神力

**規則**：\*

**射程**：決心\*10米

**目標**：一個目標

**範圍**：無

**持續**：見下

**描述**：侵入目標腦內污染目標對他人認知的記憶。

**效果**

<ul>
<li>你進行一次意志檢定並記錄成功數，隨後目標以意志檢定與你該次意志檢定進行對抗，若你在該次對抗中勝出，你便可使目標對一名單位的態在本能力持續期間對該單位的友善度降低或提高1級，你每輪都需要花費一個迅捷動作專注維持本能力，否則本能力會立刻結束。</li>
<li>此外，目標每輪行動開始時都會被動進行一次意志檢定，DC爲你該次意志檢定的成功數，該DC每輪都會降低2點，若目標檢定通過，則本能力同樣會立刻結束。</li>
</ul>

**增幅**

<ul>
<li>在施展本能力時，你可以同時使用或取下列方式之一增幅本能力：</li>
<li>\1.每額外支付1點意志力，你便可以在該次意志檢定中獲得1個附加成功。</li>
<li>\2.額外支付2點意志力，隨後將目標改爲“不超過你傳奇決心\*1名目標”。</li>
</ul>

**價格**：D+500

# 堆疊式緩衝區

**價格**：D+500

**動作**：標準動作

**能耗**：1點精神力

**規則**：\*

**射程**：決心\*10米

**目標**：一個目標

**範圍**：無

**持續**：見下

**描述**：向目標腦內不斷添加快取記憶直到目標緩衝溢位，導致記憶喪失。

**效果**

<ul>
<li>你進行一次意志檢定並記錄成功數，隨後目標以意志檢定與你該次意志檢定進行對抗，若你在該次對抗中勝出，你能夠在本能力持續期間刪除目標對一名單位的所有相關記憶，你每勝出3點，便可刪除目標對一名單位的記憶，記憶的丟失只會讓目標受到一些劇情效果，不會讓目標以往其任何學會的技能和技藝，同時若目標得到提醒，則可以回想其這部分記憶（本效果由ST擁有最終解釋權），這是一個D級影響心靈的效果。</li>
<li>目標每分鐘都會被動進行一次意志檢定，DC爲你該次意志檢定的成功數，該DC每輪都會降低2點，若目標檢定通過，則本能力同樣會立刻結束。</li>
</ul>

**增幅**

<ul>
<li>在施展本能力時，你可以同時使用或取下列方式之一增幅本能力：</li>
<li>\1.每額外支付1點精神力，你便可以在該次意志檢定中獲得1個附加成功。</li>
<li>\1.額外支付2點精神力，持續時間單位從“分鐘”變爲“10分鐘”，再額外支付4點精神力，持續時間單位從“10分鐘”變爲“小時”。</li>
<li>\2.額外支付3點精神力，隨後將目標改爲“不超過你傳奇決心\*1名目標”。</li>
<li>\3.每額外支付5點精神力，本能力的影響心靈效果等級便提升1級。</li>
</ul>

**價格**：D+500

**持續**：立即

**描述**：你可以偵測異能範圍內你可看到的任何生物的表面情緒。

**效果**：你能感覺到基礎的需求、動力和情緒。口渴、飢餓、恐懼、疲乏、痛苦、憤怒、憎恨、懷疑、好奇、友善，以及其他種種感情都可被感知。並且接下來你對其進行的互動系檢定獲得 6DP 洞察加值，持續一個場景。

**增幅**：每額外支付 1 精神力，本異能的作用區域半徑增加 5 米。

**價格**：D+500

**射程**：無

# 危險感知

**價格**：D+500

**動作**：標準

**消耗**：1 點精神力

**規則**：無

**射程**：無

**目標**：自身

**範圍**：無

**持續**：意志值 / 分鐘（解消）

**描述**

<ul>
<li>當本異能持續時，你將覺察到範圍內敵意生物的存在和方向 ( 但無法得知他們的具體位置 ) 。本異能偵測的是積極的侵略意識，而非警戒意識。例如，若你走向背後藏有刺客的一扇門，你將覺察到有與此門相關的敵意存在；然而本異能不會對一名被安排守衛此門的士兵產生反應。</li>
<li>同時，你能在正常感覺到危險之前覺察到它的存在。你的直覺提醒你存在陷阱的威脅，你在躲避陷阱時的對抗檢定獲得 4DP 洞察加值，或者被陷阱攻擊時的防禦獲得 4 點洞察加值。</li>
<li>此外，本異能持續時，你免疫 D 級措手不及。</li>
</ul>

**增幅**

<ul>
<li>你可以同時使用或取下列方式之一增幅本異能。</li>
<li>\1. 每額外支付 1 精神力，本異能的持續時間提升 1 倍。</li>
<li>\2. 你每分別有 2 點傳奇決心和傳奇沉着，則你可以額外支付 3 點精神力，使免疫措手不及等級提升 1 級。</li>
</ul>

**價格**：D+500
