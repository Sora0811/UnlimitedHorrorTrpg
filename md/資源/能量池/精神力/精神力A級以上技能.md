# 精神分裂

> 來源：`資源/能量池/精神力/精神力A級以上技能`

**價格**：A+4000

**動作**：標準動作

**消耗**：7 點精神力

**規則**：無

**射程**：無

**目標**：自身

**範圍**：無

**持續**：意志值 / 輪（解消）

**效果**

<ul>
<li>你的心智分裂成兩個獨立的部分。每個部分都完全自主的行動，就好像一個身體中有兩個人格一樣。</li>
<li>你的次要心智無法控制身體，但是其每輪都可以如常獲得動作，從召喚後的下一輪纔可以行動，其無法使用任何需要使用姿勢，動作，語言等能力。但是其他能力其可以使用，若該能力消耗能量池，則消耗你自己的能量池，若有能量使用上限或者次數要求，則你和次要心智共享上限和次數。</li>
<li>計算你次要心智的屬性時，其屬性與你自己相同。</li>
<li>你兩個心智完全心靈相通。</li>
<li>若在持續時間內，你受到任何影響心靈的效果時，包括異常情緒點數等，則你可以讓次要心智承受該效果，若次要心智消失，則該效果全部解除。</li>
<li>若在持續時間內，你進入的昏迷狀態，則你可以讓次要心智陷入昏迷，從而不受到該效果影響。</li>
<li>若在持續時間內，你受到任何精神傷害或者損失意志力等類似效果，則你如常受到傷害和損失，次要心智無法幫助你。</li>
</ul>

**價格**：A+4000

# 奴役術

**價格**：S+8000

**動作**：標準動作

**消耗**：9 點精神力

**規則**：\*

**射程**：意志值 \*10 米

**目標**：一個目標

**範圍**：無

**持續**：意志值 / 輪

**效果**

<ul>
<li>你進行意志檢定，所有受到影響的目標進行意志豁免檢定，若你成功，則你可以永久控制該生物，甚至可以強制他進行近乎自殘或者極度危險的行動。</li>
<li>要注意的是， NPC 人物即使受到該異能影響也無法帶回主神空間（非自願），而主神的修復會同時清除此異能影響。</li>
<li>這是一個影響心靈的能力。</li>
<li>你每奴役一個目標，則你的精神來池上限下降 10 點。</li>
<li>你一旦進入昏迷或者死亡，奴役自動結束。當你與目標處於不同的位面時，奴役失效。</li>
<li>在奴役狀態下，你並不視爲擁有目標的感官，所以當你與目標不處於同一環境下時，你無法感知被奴役目標感知到的情況。</li>
</ul>

**增幅**：你可以在啓動的時候額外支付 3 點精神力，使持續時間變爲意志值 / 分鐘，也可以再額外支付 5 點精神力，使持續時間變爲意志值 / 小時，也可以再額外支付 7 點精神力，使持續時間變爲意志值 / 天，也可以再額外支付 9 點精神力，使持續時間變爲永久。

**價格**：S+8000
