# 靈力

> 來源：`資源/能量池/靈力/靈力概述`

**本質**：魔幻本質

**描述**

<ul>
<li>靈力是一種精神力量，擁有這種力量的人可以行走於生國與死境之間，模糊了魂與物的界限。靈力是精神的體現，因此使用靈力並不一定需要“付出”特定的能量。</li>
<li>靈力是一個特殊能量池。</li>
</ul>

**增幅**

<ul>
<li>你可以以增幅的形式使用靈力，主動提升 DC 以獲得額外的好處。使用靈力物品：有些靈力物品擁有啓動 DC ，啓動它們的方式與使用靈力技能相同，但靈力物品提供的能量總是視爲增幅過的。因此，你的成功數必須高於其啓動 DC 的一半，才能成功啓動。</li>
<li>由於靈力的特殊性，若靈力技能獲得“視爲你已經增幅了X點”的增益效果。</li>
<li>則其視爲啓動DC檢定後，DC降低X點，但是這不會改變啓動DC的上限。</li>
</ul>

**例**

<ul>
<li>你意志值10，則靈力池爲10，此時你可以啓動DC爲5以下的技能，然後你啓動了DC爲3的技能，並且其可以增幅3點DC，同時擁有視爲你已經增幅了1點的能力。</li>
<li>則此時，你可以將DC啓動調整爲5（基礎3+增幅2），使用技能後，你的啓動檢定結果爲3，則你原本應該獲得2點靈感疲勞，但是由於你視爲已經增幅了1點，所以獲得1點靈感疲勞。</li>
</ul>

**其他標籤**

**靈力池**：你能承受的靈力使用限度的大小稱爲“靈力池”。你的靈力池大小等於你意志值。 靈力池無法獲得提升能量池上限的效果，當獲得類似效果時，將改爲積累的靈感疲勞上限增加相當於提升能量池上限/點的點數。並且你每有 1 點傳奇決心和傳奇沉着，則積累的靈感疲勞上限增加 2 點上限。

**使用靈力**

<ul>
<li>使用靈力需要進行一次意志檢定，本次檢定稱之爲靈力啓動檢定， DC 依技能不同而不同。即使檢定失敗，你依然正常使用該靈能，但每低於 DC 一點，會造成一點“靈感疲勞”。當你累積的靈感疲勞點數填滿你的靈力池時，你無法使用靈力。</li>
<li>若靈力技能的 DC 高於你靈力池上限的一半，你無法使用該技能。</li>
</ul>

**能量兼容**：若有任何其他能量技能兼容靈力，則使用該技能所需的靈力 DC ＝該技能消耗能量值 +5 或該技能消耗能量值 \*2 ，取高者。

**能量抵消**

<ul>
<li>當你擁有東方通用能量池時，你可以用該能量來抵消你的靈感疲勞。</li>
<li>當你形成靈感疲勞時，你可以同時支付該能量，每 3 點能量抵消一點靈感疲勞。若如此做，你無論支付多少能量，都會至少受到 1 點靈感疲勞。你無法以能量抵消已經形成的靈感疲勞。你每天以此方法抵消的靈感疲勞不能超過你的決心值。</li>
</ul>

**靈力的基礎用法**：靈力攻擊。當你攻擊時，你可以啓動本能力，無需動作，靈力啓動 DC 爲 1 ，啓動後，你的近戰攻擊可以正常地攻擊靈體（但你的攻擊並不視爲“幽冥”屬性）。


**正文**

一、精神修煉一小時或睡眠四小時，你可以恢復相當於沉着點數的靈感疲勞。此處的精神修煉包括但不限於冥想、入定、禪坐、演練招式等，你可以選擇任何你擅長的方式。你每天以此方法恢復的靈感疲勞不會超過你的意志值。

二、每當你恢復意志點數時，你恢復兩倍的靈感疲勞。

三、這一條是可選規則。選擇一個執念（如正義、金錢或情慾），當你爲了達成這一執念而冒大風險努力時，你可以恢復 3 點靈感疲勞。
