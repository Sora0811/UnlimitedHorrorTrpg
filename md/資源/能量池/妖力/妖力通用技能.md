# 妖化武器

**價格**：D+500

**消耗**：見下

**動作**：整輪動作

**目標**：自身

**射程**：無

**範圍**：無

**持續**：消耗的妖力 / 輪

**效果**：從列表武器中選擇一把冷兵器，消耗等同於該武器體積的妖氣，在手中凝結一把妖氣武器，這把武器擁有【魔法】【黑暗】特性，可以正常攻擊靈體，但是並不視爲擁有【幽冥】特性。

**增幅**：你每有 1 點傳奇風度/傳奇耐力取高，則可以額外花費 1 點妖力增幅，使武器傷害提升 1 點，破甲提升 1 點。

**價格**：D+500

# 雙腿強化

**價格**：D+500

**能耗**：1 點妖力

**動作**：迅捷動作

**目標**：自身

**射程**：無

**範圍**：無

**持續**：消耗的妖力 / 輪

**效果**：開啓後，將釋放的妖力聚集到雙腿上使其完全覺醒的能力，這會使的雙腿呈現妖魔形態。但其帶來了許多好處，你的陸行速度增加 10 米，並且跳躍的米數 \*3， 獲得蛛行術。

**增幅**：你每有 1 點傳奇風度/傳奇耐力取高 ，則可以額外花費 1 點妖力增幅，使陸行速度再增加 10 米。

**價格**：D+500

# 風斬

**價格**：D+500

**能耗**：1 點妖力

**動作**：標準

**目標**：自身

**射程**：觸及

**範圍**：無

**持續**：立即

**描述**：在瞬間完成拔劍、斬擊、收劍這一系列單純的動作，僅靠蠻力是無法完成的，省略一切不必要的動作，舞動刀劍瞬擊的高難度拔刀術。

**效果**：你如常進行一次近戰白刃攻擊，針對本次攻擊，目標視爲措手不及，這是一個 C 級的措手不及能力，同時你的本次攻擊獲得相當於你傳奇敏捷的 DP 招式加值，並且你的攻擊額外獲得【擊飛】特性。

**價格**：D+500

**價格**：C+1000

# 妖風

**價格**：C+1000

**消耗**：3 點妖力

**動作**：標準動作

**目標**：自身

**射程**：無

**範圍**：無

**持續**：消耗的妖力 / 輪

**描述**：你形成一股黑色的妖風帶你飛行。

**效果**：你獲得相當於你基礎移動速度的飛行能力，機動性爲靈活。你也可以攜帶其他人一同飛行，但是目標每有 5 點體積，則你額外支付 1 點妖力，同時此時目標不能離開你的風度值 / 米範圍內，攜帶他人額外支付的妖力不會計入持續時間中。

**增幅**：你每有 1 點傳奇風度/傳奇耐力取高 ，則可以額外花費 1 點妖力增幅，使機動性提升 1 級或者飛行速度翻倍。

**價格**：C+1000

# 炎殺黑龍波

**本質**：特異本質

**前提**：擁有妖力能量池，黑暗生物

**價格**：A +4000

**消耗**：見下

**動作**：標準動作

**目標**：見下

**射程**：見下

**範圍**：見下

**持續**：見下

**被動**：你現在造成的所有火焰傷害同時具備【褻瀆】性質，必須同時抵抗這兩種傷害類型的效果纔可以減免此傷害，你所造成的所有火焰傷害額外獲得相當於你傳奇風度的提升。

**效果**

<ul>
<li>花費你現有的全部妖力，你從手中召喚黑炎龍。</li>
<li>需要注意的是，黑龍波只能由妖力來施展，任何可以代替妖力的能量池（哪怕真元力）無法施展黑龍波。</li>
<li>黑炎龍召喚時計算本場景內所有消耗過的妖力，加上你本次召喚黑炎龍所消耗的妖力，得到黑炎龍的妖力池。</li>
<li>黑炎龍的先攻與你相同，召喚出的當回合可以立即行動，你可以每輪用一個迅捷動作引導它移動並攻擊。黑炎龍的體積等於你的風度值，擁有等於自身妖力池的生命值，獲得元素生物特性。黑炎龍的移動速度等於你的移動速度，每輪黑炎龍會花費 1 點妖力維持自己存在，當妖力值爲 0 時，黑龍消散。黑炎龍沒有任何負重能力，黑炎龍的攻擊 DP 爲黑炎龍當前妖力值，並且額外獲得相當於你傳奇風度的附加成功，黑炎龍的傷害上限爲你的耐力值 + 風度值。黑炎龍在生命值歸 0 後會自爆，造成等於它當前妖力值的範圍傷害，範圍體積 / 米。黑龍波造成的所有傷害都是火焰傷害，並且擁有【褻瀆】性質。</li>
<li>每個角色同一時間只能召喚一條黑炎龍。</li>
<li>召喚者免疫自己所召喚的黑炎龍造成的一切傷害。</li>
</ul>

**升級**

<ul>
<li>花費 98XP</li>
<li>現在當黑龍召喚後，你可以獲得以下幾種新的用法：</li>
<li>\1. 你可以以一個迅捷動作命令黑龍攻擊你視野範圍內的全部敵人。這視爲範圍攻擊，造成相當於黑龍當前妖力值的範圍傷害。目標反射豁免，並且其的反射檢定失去相當於你風度值的 DP 。</li>
<li>\2. 你可以以一個自由動作，讓黑龍吞噬你所受到的所有不良狀態，每吞噬 1 點不良狀態點數需要消耗黑龍的 1 點能量。（無法吞噬不死鳥由血統帶來的不良點數）</li>
<li>\3. 以一個迅捷動作，你與黑龍合體，你的攻擊和防禦獲得相當於黑龍當前妖力值的 DP 能量加值，持續你的傳奇風度 + 傳奇耐力 / 輪。效果結束後你獲得無法豁免的等同於耐力值的疲乏狀態，需要經過 6 小時的休息才能消除。</li>
</ul>

**價格**：A+4000
