# 龍氣

> 來源：`資源/能量池/龍氣`

**其他標籤**

**龍氣的基礎用法**

<ul>
<li>龍氣沒有本身的基礎用法。</li>
<li>當你習得龍氣之後，你立即吞噬其他所有符合要求的能量池，並且也無法再次獲得其他的能量池，甚至包括真元力。</li>
<li>龍氣每吞噬一個符合要求的能量池，則其獲得對應的基礎用法。</li>
<li>由於原本的能量池被龍氣吞噬，所以若原本的能量池擁有某些限制，則現在解除。</li>
<li>擁有龍氣之後，你可以學習其他符合要求的能量池爲前提的招式，技能，稱號等。若其有能量池的要求，則你的龍氣池達到要求即視爲滿足。其原本的消耗變爲龍氣。</li>
<li>所有綁定原先能量池施展的招式，技能，稱號等，全部改爲綁定龍氣。</li>
</ul>

**符合要求的能量池包括**

<ul>
<li>東方通用能量池或者東西方通用能量池（龍氣無法吞噬精神力和罡氣），同時這些能量池必須爲非黑暗性質的能量池。</li>
<li>龍氣無法與不符合要求的能量池，黑暗，邪惡的血統，改造，稱號兼容，若你之前擁有或者之後兌換，則會立即爆體而亡。</li>
<li>龍氣無法被降低消耗，除了來自其指明龍氣可以降低消耗的特性。</li>
</ul>

**龍氣的恢復**

<ul>
<li>經過 8 小時的靜養（睡覺，坐禪，冥想，或者其他類似狀態）你可以恢復之前消耗的全部龍氣，或者你處於一處山林之中，你可以經過 4 小時的靜養（睡覺，坐禪，冥想，或者其他類似狀態）你可以恢復之前消耗的全部龍氣。</li>
<li>你只能通過這種方式來自然回覆龍氣。這種靜養如同你良好休息一般。</li>
</ul>


**正文**

東方人心目中逐漸成長飛騰的龍，這並非真實存在的龍，而是將傳承而來的信念具現化的精神象徵。人人心中都沉睡着龍，只是看你有沒有力量喚醒他。這個能量池無法兼容其他任何能量池，因爲龍氣乃帝王象徵，具備非常嚴格的獨佔性。

龍氣池的大小爲感知 + 決心，你每有 1 點傳奇感知或者 1 點傳奇決心，則龍氣池上限增加 5 點。

這是一個東方通用能量池。
