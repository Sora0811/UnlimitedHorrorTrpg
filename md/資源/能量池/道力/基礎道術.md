## 指地成鋼

**花費**：1 點

**成分**：言語、姿勢

**射程**：視線

**範圍**：見描述

**持續**

<ul>
<li>1 輪 / 每成功數</li>
<li>以土生金之理，臨時把土屬性的泥石沙土變爲金屬。你在視線內選擇一箇中心點，進行施法鑑定，把以中心爲球心，半徑 1 米 / 每成功數的球形空間內的泥土沙石變成金屬，金屬硬度等於施法者 ( 神祕學技能 + 神祕學附加成功數 ) ，外形類似鋼鐵。你可以選擇只轉變區域內的部分金屬。若你要轉變的物品被人持有或操控，則其以意志對抗你的施法鑑定，該物品每個支線等級令其在對抗中額外獲得兩個附加成功。</li>
<li>( 特殊的，這個法術可以對土元素生命施展，此時造成等於鑑定成功數的惡性傷害，強韌減免 )</li>
</ul>

**增幅**：你每額外支付 3 點能量，在施法鑑定上額外獲得一個成功數，上限爲施法者等級 \*3 。

**升階**

<ul>
<li>C 級時，範圍提升到 2 米 / 每成功數。</li>
<li>B 級時，你轉換出的金屬硬度對光能、音波傷害也有一半生效，你在增幅時投入的每點能量還同時提高一點金屬硬度。</li>
<li>A 級時，你轉換出的金屬硬度對所有類型傷害生效，範圍提升到 10 米 / 每成功數，持續時間提升到 1 分鐘 / 每成功數。</li>
</ul>

**其他標籤**

**變體**：根據五行生剋，還可以演化出指金 / 水 / 木 / 火生水 / 木 / 火 / 土，此時把指金生水中的硬度替換爲可影響的金屬物品硬度，把指木生火中的硬度替換爲範圍火焰傷害。


## 御劍術

**消耗**：1

**射程**：感知 \*10 米

**持續**：立即

**描述**：雖然名爲御劍術，但這只是因爲多數道教徒用此術操劍而得名。

**效果**

<ul>
<li>用道力驅動的此術可以操縱任何近戰武器進行遠程攻擊，你將手中的一把近戰武器當作投擲武器進行一次攻擊檢定，用敏捷 + 白刃代替敏捷 + 運動來進行這次攻擊檢定，被投出的武器會在你行動結束時回到你手中，因此你無法進行多次攻擊。</li>
<li>如果你擁有劍氣，這個道術也可以用劍氣來驅動，此時只能作用於劍類武器。</li>
</ul>

**增幅**：每有一個 C 級以上的施法者等級，你可以額外消耗 1 點道力，額外攻擊 1 個目標，在 S 級時到達 5 個。

**升階**：到達 C 級之後，你可以在使用的時候額外花費 1 點道力，使你的攻擊獲得【高速】特性，每花費 1 點道力，本輪所有的御劍術都獲得等額的【高速】。

**可選**：劍修可以購買此招式，購買後此道術可以以劍氣驅動，此時只對劍有效。

## 五行咒

**消耗**：1

**射程**：感知 / 米

**範圍**：一個目標

**持續**：你的感知與風度取低。

**描述**：對於修道之人來說，對五行的接觸比五靈更早，你可以喚起金，木，水，火，土五行之中的力量強化物體或生物。

**效果**：施展此道術時選定五行之中的一種，要切換到另一種需要再施展一次此道術，之後由第二個效果將第一個效果覆蓋。

**升階**：每升階一次，則可以在施展的同時，可以額外選擇 1 個效果。

**其他標籤**

**烈火**：目標爲範圍內一件武器，包括天生武器和徒手，目標被熊熊火焰所圍繞，但並不對目標本身造成傷害。目標武器在造成傷害時額外追加 1 點自動成功的火焰傷害。

**洪水**：目標爲範圍內一個生物，目標體內的生命能量循環如洪水般奔流不息，目標獲得快速醫療 1 。

**銳金**：目標爲範圍內一件武器，包括天生武器和徒手，目標武器變的更爲鋒利，沉重，目標武器傷害值額外提升 2 ，但不改變能造成的傷害類型。

**厚土**：目標爲範圍內一個生物，目標身邊被層疊的道力所覆蓋，因而獲得全傷害吸收 1 。

**巨木**：目標爲範圍內的任意一格，指定位置上體積 3 ，長約 2 米的巨木破土而出（圓形或方形由你決定），爲與它相鄰的目標提供 1/2 的掩蔽防禦。巨木只能從大地中出現，若被金屬地板所阻隔則此道術無效，出現的巨木已被牢牢固定，可以承重。

<li>對於任何你能精確感知其能量變化的物品，你可以如親眼看到般應對。除非你無法行動，否則以這類物品對你進行攻擊，不會因你被突襲或無法查覺等效果而受到好處。</li>
</ul>

## 泰山咒法 鎮壓

**消耗**：1

**動作**：標準，語言或姿勢

**範圍**：感知\*10米內的 一個目標

**持續**：輪 / 決心

**描述**：取泰山之巍峨正大，匯聚土行之力鎮壓敵手。

**效果**

<ul>
<li>投施法骰或者進行一次不造成傷害的普通近戰攻擊，這視爲接觸攻擊。若命中，則咒法開始匯聚環境中的土行之力，並在下一輪生效 ( 若在海洋 高空等遠離陸地的地方，再延後一輪生效 ) 。這表現爲土黃色的氣流向目標聚集。</li>
<li>在此階段，若目標擁有通用能量池，且該能量池等級不低於你，則可以以一個移動動作消耗等於你消耗的的能量 \*2 點打散未生效咒法。若目標能量池等級低於施法者，可以以移動動作支付等於你消耗的能量令其再延後一輪生效。若延後輪數超過咒法持續時間，則咒法失效。</li>
<li>同一個目標在同一時間只能被一個本法術影響一次。</li>
<li>聚集了足夠的土行之力後，咒法生效。目標負重增加能量消耗 \*50KG 。目標負重超過重載極限後，不能移動，失去基礎防禦和閃避防禦，超過重載極限的兩倍後，則被定身。</li>
<li>咒法生效期間，目標周身會出現模糊的山巒投影將其籠罩。能量等級越高，投影越清晰越接近實質。投影形象與消耗能量有關，如 : 水屬性會有云霧，飛瀑，雷屬性會有電流環繞，金屬性會是兵戈林立 ( 這是一個視覺效果，沒有實際影響 ) 。</li>
<li>擊破投影則可解除咒法效果。投影體積爲目標體積 + 消耗能量數，生命值等於能耗，擁有等於能耗的 DR/ 神兵， A 級以上變爲等額全傷害吸收。山巒投影對目標防禦爲 0 ，對其餘採取目標的基礎防禦與閃避防禦作爲防禦。</li>
</ul>

**增幅**

<ul>
<li>當你擁有 C 級能量池時，你施展本咒法時，消耗的能量最大爲 3 點。 B 級時最大爲 5 點，以此類推。</li>
<li>施展時你可以額外消耗 1 點意志，則咒法即時生效。</li>
</ul>
