# 符咒之術

> 來源：`資源/能量池/道力/符咒之術`

## 符咒術

**注**

<ul>
<li>所有符咒之術的固定 DP 無法花費意志增加其 DP 。</li>
<li>開天眼。</li>

</ul>

**正文**

要使用符咒術，你必須先畫好一張相應的符咒。這是一個智力 + 神祕學的延長檢定，週期爲十分鐘。只要檢定的成功數達到了符咒的基礎 DC 並支付足夠的道力，你就成功的畫好了一張符咒，接着只要簡單的將這張符咒丟出去（遠程接觸檢定，攻擊檢定爲敏捷+運動）或者貼到目標上（近戰接觸檢定，攻擊檢定爲力量+肉搏）就會產生相應的效果。

這些符咒可以貼在近戰白刃武器以及弓箭上進行發射，這需要需要一個標準動作貼上，然後如常進行攻擊檢定，若成功命中，除了造成武器和弓箭原本效果（如傷害），還會觸發符咒效果。

你可以在主神空間以 10 分的價格購買繪製符咒所必須的各種道具和材料，而基本的符紙則是 1 分可以購買 10 張。或者你可以在任務世界中找到這些東西。

繪製好的符咒，可以交由任何人使用，但其增幅效果只有擁有道力的人才能使用。特別的，符咒總是視爲可以接觸到靈體。

由於符咒之術是將書寫者一部分的精氣神封入符咒之中，因此一個人同時能書寫的符咒不能超過他在耐力和決心中較低者的數值。達到這個上限之後，除非用掉舊的符咒，否則不能書寫新的符咒。

特別的，當你在智力和神祕學上各有一個附加成功時，你可以爲每個符咒術支付每支線等級 7 點 XP ，使得你可以不透過符紙也能施展出符咒術（亦即無需繪製符咒也能施展符咒術），這是一個標準動作。

你可以花費 23 點 XP ，使你學會的所有符咒的固定 DP 增加 5 點。

你可以花費 38 點 XP ，使你學會的所有符咒的固定 DP 再增加 5 點。

術者，道之用也。所謂道家“五術”，就是“山、醫、命、相、卜”這五學問。它是以道家自渡渡人爲目標的學問，道與術常相輔相成，以法術衛身，以玄功成真。以《易經》爲理論指導思想，研究人體、天體和宇宙的一門獨具特色的技術。五術與易相伴爲伍，命、卜、醫、相常用來濟世渡人，以成就三千功行，山術實爲仙術，就是研究超脫命運的一種方法。

其中，符咒之術是一種通靈、修煉的法術，其主要作用是調動靈界的能量，避邪鎮煞、趨吉避凶等的一種方術，是道家修煉的重要組成部分。祝者咒也，所謂的咒術，其實就是用語言告訴神明要求懲罰惡人，並向神明發誓的一種祝詞。道家的符咒咒語，就是起源於古時的巫祝，只不過是改而將祝詞以特殊的方式書寫於符紙之上而已。

你獲得道力能量池，關鍵屬性爲感知 + 風度，你每掌握一個符咒術，道力池的上限就增加 1 點。若你之前已經通過其他途徑獲得了道力作爲能量，那麼你的道力池額外擴大 5 點。
