# \2. 學習五靈仙術，會讓你對相應的不良狀態有一定的抗性：

> 來源：`資源/能量池/道力/五靈仙術`

**前提**

<ul>
<li>擁有道力能量池，神祕學 4+</li>
<li>以仙劍的五靈仙術爲藍本整合改進的仙術，需要以道力作爲能量來源。通過學習五靈仙術也可獲得一定量的道力池。</li>
<li>\1. 每學習一個新的仙術，會額外增加 1 點道力上限。學習五靈仙術必須要先學會這一系的前一個仙術纔可以繼續學習這一系的下個仙術，不可跳過。</li>
<li>沒有特殊說明的話，所有五靈仙術都需要語言和動作成分，並且消耗爲道力，在判定上五靈仙術爲道術。</li>
<li>\2. 學習五靈仙術，會讓你對相應的不良狀態有一定的抗性：</li>
<li>每學習一個水系仙術，你獲得對凍結的抗性，每次受到凍結點數時，先減去等於你學習的水系仙術數的凍結點數，當你學會所有水系仙術時，你免疫凍結；</li>
<li>每學習一個火系仙術，你獲得對燃燒的抗性，每次受到燃燒點數時，先減去等於你學習的火系仙術數的燃燒點數，當你學會所有火系仙術時，你免疫燃燒；</li>
<li>每學習一個風系仙術，你獲得對暈眩的抗性，每次受到暈眩點數時，先減去等於你學習的風系仙術數的暈眩點數，當你學會所有風系仙術時，你免疫暈眩；</li>
<li>每學習一個土系仙術，你獲得對晶化的抗性，每次受到晶化點數時，先減去等於你學習的土系仙術數的晶化點數，當你學會所有土系仙術時，你免疫石化；</li>
<li>每學習一個雷系仙術，你獲得對麻痹的抗性，每次受到麻痹點數時，先減去等於你學習的雷系仙術數的麻痹點數，當你學會所有雷系仙術時，你免疫麻痹；</li>
<li>\3. 五靈仙術裏所有的施法檢定皆爲感知 + 神祕學（道術），同時法術的有效上限也改爲感知 + 神祕學。</li>
<li>\4. 如果沒有額外註明，學習每個五靈仙術的基本價格如下：</li>
</ul>
