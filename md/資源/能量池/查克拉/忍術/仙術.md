# 仙術・兩生之術

> 來源：`資源/能量池/查克拉/忍術/仙術`

**前提**：已掌握仙人模式

**專業**：召喚

**威力值**：2

**價格**：D+500

**動作**：迅捷動作

**能耗**：1點仙術查克拉

**成分**：姿勢，語言

**射程**：無

**目標**：自身

**範圍**：無

**持續**：神祕學技能等級\*1輪

**描述**：召喚出妙木山的兩大仙人――深作大人與志麻大人，蛤蟆仙人與施術者身軀融爲一體，寄生在施術者的肩膊上。

**效果**：效果持續期間，你在每輪行動開始時可以選擇將最多不超過你傳奇感知\*1點查克拉轉換爲仙術查克拉，以此法轉換的仙術查克拉在仙人模式結束後會自動清空。

**價格**：D+500

# 仙法・五右衛門

**專業**：咒法

**威力值**：6

**價格**：B+3000

**動作**：標準動作

**能耗**：5點仙術查克拉

**成分**：姿勢，語言

**射程**：見下

**目標**：見下

**範圍**：見下

**持續**：立即

**描述**：利用風遁和火遁來製造上千度的滾油，理論上可以吞噬一切有形物質。

**效果**

<ul>
<li>本忍術只有在“仙術・兩生之術”持續期間纔可施展。</li>
<li>你選擇一個方向並進行一次施法檢定，對該方向距離你不超過你感知值\*100米範圍內的所有單位（包括建築與物品在內）造成等同於你該次施法檢定成功數的範圍火焰嚴重傷害和劇痛點數，該火焰傷害忽略等同於本忍術威力值的火焰能量抗力，並且在作用於物體或有硬度的生物時，能夠造成全部傷害，受影響的目標以反射檢定豁免傷害，以強韌檢定豁免劇痛點數，劇痛點數可以疊加。</li>
<li>你能夠選擇範圍內不超過你感知值\*1名單位，使其免受該忍術影響。</li>
</ul>

**價格**：B+3000

# 仙法・蛤蟆臨唱

**專業**：幻象

**威力值**：6

**價格**：B+3000

**動作**：標準動作

**能耗**：5點仙術查克拉

**成分**：姿勢

**射程**：以自身爲中心

**目標**：多個目標

**範圍**：半徑等同於感知值\*50米的範圍

**持續**：立即

**描述**

<ul>
<li>一旦聽到即成魔幻之虜，一聽必殺之二重唱！！</li>
<li>遵循在妙木山流傳的祕傳音節，由兩隻以上的蛤蟆配合歌唱，可將聽者誘入束縛精神的幻術世界。</li>
</ul>

**效果**

<ul>
<li>本忍術只有在“仙術・兩生之術”持續期間纔可施展。</li>
<li>你進行一次施法檢定，對範圍內所有敵人造成等同於該次檢定成功數的精神束縛點數，該精神束縛點數不可豁免，可疊加，當目標因此法承受的精神束縛點數而進入重度不良狀態時，目標改爲陷入無助狀態，這是一個相當於本法術等級的幻覺與影響心靈的效果，必須同時免疫兩者才能夠免疫本忍術造成的影響。</li>
</ul>

**價格**：B+3000
