# 通用武功

> 來源：`資源/能量池/內力/通用武學`

**本質**：特異本質

**描述**：有些能力對於有着高深武功的人們來說不需要特別進行學習即可通曉。這些不過是一些運氣小訣竅，在整個江湖上壓根稱不上祕密或是絕學。

## 草上飛

**價格**：D+500

**前提**

<ul>
<li>擁有內力池</li>
<li>動作；迅捷動作啓動</li>
</ul>

**消耗**：1點內力

**目標**：自身

**持續**：耐力/輪

**特殊**：這是一個身法

**描述**：運用你所習得的輕功後，你的體重和負重都會會減輕，使你可以站立在樹枝、草尖以及薄薄的冰面上而不導致起其破碎或折斷，你還可以無聲無息的移動。

**效果**：你的陸地移動速度提高 10 米。你的潛行檢定獲得3DP增強加值，地形的障礙對你而言，已經不是一種阻礙。你無視困難地形效果。

**價格**：D+500

## 千斤墜

**價格**：D+500

**前提**

<ul>
<li>擁有內力池</li>
<li>動作；反射動作啓動</li>
</ul>

**消耗**：1點內力

**目標**：自身

**持續**：耐力/輪

**特殊**：這是一個身法

**描述**：氣沉丹田增加以自身重量，你的軀體變得沉重，下盤變得穩固。類似摔絆以及衝撞的能力難以對你發揮作用。

**效果**：你在進行摔絆、衝撞或其他類似能力的對抗時，你可以在其對抗判定上額外獲得如同內力支線等級（ D1A4 ） \*2的DP增強加值。若你同時支付 1 點內力，還可以額外再獲得1點附加成功。

**價格**：D+500

## 壁虎遊牆術

**價格**：D+500

**前提**

<ul>
<li>擁有內力池</li>
<li>動作；迅捷動作啓動</li>
</ul>

**消耗**：1點內力

**目標**：自身

**持續**：耐力/輪

**特殊**：這是一個身法

**描述**：以內氣吸附在垂直牆壁、冰面甚至天花板上，你可如同壁虎一般在牆上游走。

**效果**

<ul>
<li>你獲得等同你基礎速度的攀爬速度。</li>
<li>啓用壁虎遊牆術時，你必須將身體的一部分緊貼牆面。這會是你失去閃避防禦，不過在進行全防禦或者計算其他基本防禦相關能力數值時，你被視爲沒有失去自己的基礎防禦。</li>
<li>使用壁虎遊牆術之後，你的運動檢定獲得6 DP 增強加值。</li>
</ul>

**價格**：D+500

## 縮骨易容功

**價格**：D+500

**前提**

<ul>
<li>C 級內力，需求醫學技能 3 。</li>
<li>動作；五個整輪動作啓動</li>
</ul>

**消耗**：5點內力（每輪1點）

**目標**：自身

**持續**：見下

**描述**：運起內氣改變自己的肌肉和骨骼，從而改變自己的樣貌、體型以及氣質。

**效果**

<ul>
<li>你可以將自己的體型減小 3 點或者增加 2 點，你的體型的改變不會導致生命和屬性上的的更改。改變容貌時，你可以在掩飾（易容）的相關檢定上獲得3個附加成功。</li>
<li>雖然改變體型和麪目需要五個整輪，但恢復原貌只需要一個反射動作。</li>
<li>使用此能力維持期間將佔據一點內力上限，只要內氣池不空就可以長期維持。</li>
</ul>

**價格**：D+500

## 掌風 / 劍氣 / 指勁

**價格**：C+1000

**前提**：C 級內力，一種消耗內力的招式

**描述**：武林高手可以將自己的內力外放攻擊對手，即使一些一般的招式也有這樣潛力。

**效果**

<ul>
<li>購買此能力可以使原本需要近戰攻擊的招式得到能量外放的能力，每次購買此能力選擇一個原本消耗內力的招式獲得本效果。</li>
<li>能量外放有兩種模式――增加招式的觸及範圍，或者使用招式的時候妨礙敵人，你必須在使用招式前做出選擇。</li>
<li>第一種可以使你的觸及範圍額外延伸你的內力支線等級 \* 5米。</li>
<li>第二種可以在一定範圍內妨礙敵人，使你的招式更容易擊中敵人。</li>
<li>此用法的作用範圍和第一種用法可以延伸的觸及範圍相同，你使用招式時，在此範圍內敵人在基礎防禦和反射檢定上會受到如同你的內力支線等級\*2的減值。</li>
</ul>

**價格**：C+1000

## 隔山打牛

**價格**：C+1000

**前提**：C 級內力

**描述**：武林高手可以在不打碎鐵門的同時將門內側的鎖震碎，或是藉着一個普通人身體傳遞內力與另一個高手決鬥。

**效果**

<ul>
<li>此效果可以成爲某種招式攻擊攻擊的一部分。</li>
<li>你必須可以定位（至少是模糊定位）你的攻擊對象，並且你與該對象之間須有固體相連。你可以支付內力以穿越物體，並且你需要爲你穿透的每米支付 1 點內力。</li>
<li>啓用後此能力效果後，你可以使內力穿過障礙物攻擊後面躲藏的敵人，這意味着你的近戰攻擊可以如同對方全掩蔽無效一般進行攻擊，並可以無視他的掩蔽防禦。</li>
<li>內力的傳遞距離終有衰竭。你能穿過的障礙物厚度不能超過你內力等級 \*2 米的範圍，在肉搏 / 白刃技能上（取決於你以什麼技能進行攻擊）擁有兩個附加成功數以後，你可以額外延伸的觸及範圍變爲內力等級 \* 技能上附加成功數 \*1 米。</li>
<li>此外，你能以消耗更多的內力爲代價，通過介質（比如大地）出其不意的攻擊對手。 這視爲你在使用隔山打牛的技巧時，以移動動作使用虛招，且以肉搏 / 白刃取代掩飾技能進行檢定，爲此你需要額外爲穿透距離每 1 米支付 1 點內力。</li>
</ul>

**價格**：C+1000

## 爆發推進

**價格**：C+1000

**動作**：移動動作

**前提**：C 級內力

**能耗**：3 點內力

**射程**：無

**目標**：自身

**範圍**：無

**持續**：立即

**描述**

<ul>
<li>在很多影視作品裏，都有大俠或者配角用力在虛空一拍，隨後就可往反方向爆射而去。這種發力技巧被主神命名爲爆發推進，加入了兌換裏。</li>
<li>經過計算後的移動距離每有 200 米都會產生一處空爆的動畫效果。</li>
</ul>

**效果**

<ul>
<li>你必須使用手或者腿作爲天生武器來施展本招式。</li>
<li>你可以選擇一個方向並進行一次肉搏攻擊檢定，之後你會立刻朝反方向移動等同於你傳奇力量（最低爲 1 ）的五倍 \* 你該次檢定成功數與你力量值之和 \*1 米，這是一次直線移動，並且在移動過程中你不會受到自然本質的引力影響，這意味着你可能可以使用本招式來躍過懸崖或類似的地形，但在該次移動結束後，若你沒有在空中滯留的能力，你仍會如常墜落。</li>
<li>若你在移動途中撞到任何障礙物，則你會立刻停止移動並受到不可避免的，等同於剩餘米數 \*1 點衝擊傷害。</li>
</ul>

**增幅**：你可以在施展本招式時最多可以額外支付 X 點內力，每額外支付 3 點內力，在施展本招式時你的傳奇力量便視爲比原本要高 1 點。 X 爲你的傳奇耐力 \*3.

**價格**：C+1000

**其他標籤**

**控制自如**：支付 28XP 進行研發，之後若你在移動途中撞到任何障礙物，則你不再會因此受到傷害，而是改爲對該障礙物進行一次衝撞。此外，你可以隨時在移動途中停止移動。

**爆發**：支付 36XP 進行研發，之後你在施展本招式時你的傳奇力量視作比原本要高 5 點。同時每輪一次，你可以在你一次肉搏攻擊結束後以一個迅捷動作施展本招式。此外，當你增幅本招式時，效果改爲每額外支付 3 點內力，在施展本招式時你的傳奇力量便視爲比原本要高 2 點。
