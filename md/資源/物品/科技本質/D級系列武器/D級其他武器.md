# Gerbera（噴射拳）

> 來源：`資源/物品/科技本質/D級系列武器/D級其他武器`

**本質**：科技本質

**價格**：D+1000

**前提**：需求力量6

**分類**：拳套

**體積**：1

**武器基本屬性**

<ul>
<li>提升雙手天生武器傷害0L</li>
<li>【格擋】</li>
</ul>

**能耗**：一枚標準電池可以噴射10次，更換電池是一個整輪動作。

**價格**：D+1000

**其他標籤**

**噴射**：以一個迅捷動作，向任意方向移動5米。之後角色獲得速度爲自身體積的飛行能力（如常需要移動動作），機動性爲笨拙，持續1輪。

**蓄力光束**：角色站立在穩定的平面上時，可以以一個標準動作消耗一枚標準電池，對20米範圍內的一個單位噴射出直徑爲20CM白色的能量光線，持續5輪，對路徑上的所有其他單位造成每輪2L能量嚴重傷害。

**散射光線**：角色在空中時，可以以一個標準動作消耗一枚標準電池，對當前場景所有其他單位造成2L能量嚴重傷害，若當前場景爲小型封閉的空間（體積小於240立方米的空間）則受到的傷害增加1L。這在畫面上表現爲無數光束噴射而出，在狹窄的空間內來回彈射。

**價格**：D+1000

**前提**：需求力量3

**分類**：拳套

**體積**：1

**武器基本屬性**

<ul>
<li>提升雙手天生武器傷害0L</li>
<li>【格擋】</li>
</ul>

**能耗**：一枚標準電池可以釋放雷掌10次，更換電池是一個整輪動作。

**價格**：D+1000

**其他標籤**

**雷掌**：以一個標準動作，選擇觸及範圍內一個目標，然後以其爲中心範圍1米的所有其他單位（不包括你自己）造成3點雷電嚴重傷害。

**爆破**：以一個標準動作對觸及範圍內一個單位進行一次近戰肉搏接觸攻擊，本次攻擊不造成傷害，若成功命中則會將OverTure埋入該單位體內，角色失去本物品，之後角色的任意攻擊若對目標成功造成傷害，則該目標爲中心，半徑2米範圍內所有其他單位將受到3點物理嚴重傷害。這在畫面效果上表現爲角色將OverTure直接插入敵人體內之後將其引爆。

**堆疊爆破**：同一個單位每被額外埋入1個OverTure，引爆時最終傷害增加1點。
