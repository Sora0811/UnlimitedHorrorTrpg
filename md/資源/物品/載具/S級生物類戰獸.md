# 墨麒麟 S+10000

> 來源：`資源/物品/載具/S級生物類戰獸`

**特性**

<ul>
<li>警覺3，精通先攻3</li>
<li>心智免疫，戰鬥勇猛，靈魂綁定</li>
</ul>

**武器**

<ul>
<li>天生武器 12L ，破甲4，破魔12 ，8加骰，【神器】</li>
<li>只允許主人乘坐，可飛行，機動性完美</li>
</ul>

**其他標籤**

**靈魂綁定**：墨麒麟一生只認一個主人，當你購買後墨麒麟將與你綁定，你們視爲擁有範圍無限大的心靈鏈接效果，但是依然不可穿越位面。如果你死了，墨麒麟將追隨你而去，待你復活的時候，墨麒麟會再次出現在你身邊。若墨麒麟死了，你可以在主神空間花費B+7000復活它。同時它殺死的目標或者完成的任務若可以獲得支線和分數，則計入你的分數和支線上。

**心智免疫**：免疫S級或以下基於心智屬性卻不基於生理屬性的能量或類能量對自己造成的效果（魔力、原力，道力等），但不影響不針對自己的效果（例如施法者自身），或針對環境的效果（如範圍攻擊，儘管你自己免疫那個範圍攻擊），你可以主動壓制這個能力來承受效果，這不需要動作。同時，若主人乘坐在其身上，則主人可一同享受該效果，不過主人免疫的效果變爲B級。

**戰鬥勇猛**：墨麒麟每次攻擊後，下一次攻擊獲得+2DP士氣加值，最多爲墨麒麟的決心值。若主人此時乘坐在墨麒麟身上，則主人也享受該加值，該加值變爲主人和墨麒麟的決心值取高。
