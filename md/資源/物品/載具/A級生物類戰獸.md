# 生命縛誓者的僕從

> 來源：`資源/物品/載具/A級生物類戰獸`

**價格**：A+8000

**分類**：坐騎/駝獸

**描述**：生命縛誓者阿萊克斯塔薩是紅龍一族的女王，爲艾歐娜選中的守護巨龍，是生命的守護者。與其他顏色的龍不同，紅龍對凡間種族偏愛有加，它們儘可能地幫助那些年輕的種族，指引他們進步。作爲生命縛誓者的子嗣，紅龍們儘管高傲卻又十分溫和，它們願意接納凡人種族的騎乘。

**專長**：鋼鐵意志5，死硬5，精通先攻3，警覺3，廣博知識，過目不忘

**體積**：20

**攻擊**：本生物載具擁有天生武器傷害爲16L牙齒和爪子

**防禦**：擁有24點天生防禦

**特殊**：生命縛誓者的僕從性別有雄性也有雌性，PC在向主神購買本載具時必須立即選定自己的坐騎的性別，一經選定不可更改。

**價格**：A+8000

**其他標籤**

**翱翔天際**：本生物載具擁有等同於自身基礎移動速度六倍的飛行速度，機動性爲完美。

**生命之息**：本生物載具可以花費1個標準動作對以距離其不超過300米的任一點爲中心，半徑50米範圍內的所有目標造成40點火焰嚴重傷害，目標以反射檢定豁免。

**奧法編織**：本生物載具擁有B級施法者職能與魔力池，購買本生物載具時，你必須立刻在通用法術列表中選定1個B級法術或2個C級法術或4個D級法術，隨後本生物載具會獲得你選定的法術（但若不滿足施展該法術的前提條件，則依舊無法施展該法術）。

**形態變化**

<ul>
<li>爲了近距離的觀察凡人種族，紅龍們往往學會了變爲凡人種族的辦法，出於某些原因，紅龍們大多選擇了高等精靈的樣貌作爲自己的第二形態。</li>
<li>本生物載具可以花費一個整輪動作並支付3點魔力，隨後將自己變爲人型（在外貌上必然與魔獸世界中的高等精靈相同），這會使本生物載具暫時失去死硬5專長，獲得4級的傾城之貌專長，並降低15點體積，持續至本生物載具花費一個標準動作解除本狀態爲止，這是一個B級變形效果。</li>
</ul>

# 奧的灰燼

**價格**：A+4000

**分類**：坐騎/駝獸

**描述**：鳳凰是艾澤拉斯世界最美麗，最耀眼的生物。從奧的灰燼裏浴火重生，周身帶着耀眼的光芒，在天空留下一道火焰的印記，每一個親眼看到她的人都會目不轉睛的注視着那徇麗的豐麗身姿。

**專長**：鋼鐵意志5，死硬5， 鼓舞士氣3

**體積**：20

**攻擊**：擁有天生武器傷害爲8L的利喙和爪子

**防禦**：天生防禦12點

**價格**：A+4000

**其他標籤**

**飛行**：本生物載具擁有等同於自身基礎移動速度八倍的飛行速度，機動性爲完美。

**烈焰之舞**：本生物載具可以花費1個標準動作對以距離其不超過300米的任一點爲中心，半徑50米範圍內的所有目標造成40點火焰嚴重傷害，目標以反射檢定豁免。

**抗性皮膚**

<ul>
<li>該載具免疫原本消耗基於心智系能量卻不基於生理系能量（如魔力，原力等）且原本支線等級不高於B級的能力，法術（升階後按原本等級計算），招式，技能對其造成的效果（包括傷害），但不影響不針對其本身的效果（如施法者自身），或針對環境的效果（如範圍攻擊，儘管你自己免疫那個範圍攻擊），同時該載具還能夠使對手擁有的，能夠影響到其的相關效果無效化，但不會限制對手對自身或環境的效果（如範圍攻擊）。該載具可以主動壓制這個能力來承受效果，這不需要動作。</li>
<li>舉例而言，魔法飛彈對本載具無效；其與幻像發生互動時立刻能識破該幻象，但是該幻象依然存在；本載具無視護盾及類似法術帶來的防禦或掩蔽防禦；對手針對其的攻擊中若有以心智系能量爲能耗的能力所提供的加值，則對手會失去該加值；對手用心智系能量製造出來的物品（如投影魔術，幻象）也無法對其起效，但是若該幻象施展高於本載具免疫等級的法術時，該法術對其依然生效，該武器施展高於其免疫等級的招式，技能時，該招式，技能依然有效。同時，正常的武器使用心智系能量啓動的情況下，不受本免疫效果影響。</li>
<li>但本載具的攻擊不會導致對手對其施展的飛行術失效，也不會使對手由該能力而改變的體積，屬性，速度等失效，也不能擋下爆裂火球對其隊友造成的傷害。</li>
</ul>
