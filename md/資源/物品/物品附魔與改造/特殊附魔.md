# 能量附魔

**本質**：魔幻本質

**分類**：特殊 附魔

**花費**：第一級爲 500 ，第二級起每級比前一級多 500 ，當升級至三，六，九級分別需要 D ， DD ， C 級支線，其餘等級依然無需支線，上限爲 10 級。

**能量池**

<ul>
<li>購買時選擇火焰，冰霜，雷電其中之一作爲額外的能量傷害附加到你的武器上，當武器成功的命中了敵人並起碼造成了 1 點傷害後，將會額外造成等於附魔等級 \*2 的對應能量的嚴重傷害。</li>
<li>當到達三級時，你可以修改一次能量類型，並且額外可以選擇腐蝕。</li>
<li>當到達六級時，你可以修改一次能量類型，並且額外可以選擇音波。</li>
<li>當到達九級時，你可以修改一次能量類型，並且額外可以選擇力場。</li>
<li>本附魔不兼容其他的附魔，但是其可以兼容自身，你可以多次購買並選擇多個能量傷害進行附魔（每種能量同時只能存在一個），但是每個附魔單獨計算附魔等級，若選擇多個能量，則分別計算。</li>
</ul>

**例**：購買了火焰和冰霜，則火焰和冰霜爲兩次傷害，針對這些傷害，能量抗力，傷害吸收等類似能力可以分別生效。

# 鐵鷂子

**本質**：魔幻本質

**價格**：D+500

**分類**：特殊附魔

**描述**：“有平夏騎兵，謂之‘鐵鷂子’者，百里而走，千里而期，最能倏往忽來，若電擊雲飛。每於平原馳騁之處遇敵，則多用鐵鷂子以爲衝冒奔突之兵”。以鐵騎爲前軍，乘善馬，重甲，刺斫不入；用鉤索絞聯，雖死馬上不墜。遇戰則先出鐵騎突陣，陣亂則衝擊之；步兵挾騎以進。主神復刻並魔改了該兵種的一項技術，將騎手的重甲與坐騎的馬鎧進行連接，不僅是外在的裝甲連接，並將內部的特性也一併連接。

**價格**：D+500

**其他標籤**

**使用前置**：你穿着重甲，坐騎穿着馬鎧，你騎乘在坐騎上

**同體**：騎手重甲上的特性疊加在馬鎧上，可疊加的特性爲：盔甲防禦，封閉，傷害吸收，傷害減免，能量抗力，防彈，防能量武器，盔甲減值，若原本馬鎧上有重複的特性則取高。

**鎖定**：該強化與坐騎身上的馬鎧綁定，更換另一件馬鎧則該強化無法作用於新馬鎧上。由於騎手身上的重甲與馬鎧相連，所以你想要激活 / 解除“同體”特性都需要花費 1 分鐘的時間等待身上的重甲與馬鎧相連 / 解除，否則除非你自願，哪怕你死，重甲與馬鎧都不會分開。

**特效附魔**：每次附魔，你可以選擇一個沒有選擇過的附魔效果獲得。

**衰老**：對目標造成相當於受到傷害的衰老點數，強韌豁免。當點數累計超過體質時，目標視爲衰老一個年齡層並獲得相應的生理屬性減值。此能力最多隻能讓目標衰減三個年齡層（每多 5 篇樂章額外增加一個年齡層上限）。

**遲緩**：對目標造成相當於受到傷害的糾纏點數，強韌豁免。

**昏暗**：對目標造成相當於受到傷害的目盲點數，強韌豁免。

**疲倦**：對目標造成相當於受到傷害的疲乏點數，強韌豁免。

**僞象**：對目標造成相當於受到傷害的精神束縛點數，意志豁免。

**破法**：獲得相當於樂章篇數的破魔值。對目標的魔力池損耗相當於受到傷害的點數，意志豁免，如果目標不具備魔力池，則不會受到損耗。

**湮甲**：獲得相當於樂章篇數的破甲值，且當持有者攻擊物體時，無視一半硬度。

**戰鬥特化**

<ul>

<li>\1. 被附魔的武器其破甲值提升2點。</li>
<li>\2. 被附魔的武器其高速優勢提升2點。</li>
</ul>

**魔導器附加**：每支魔導器所能安裝的插件數量等於其體積。這些插件可以重複購買，每購買一次都視作一個新的槍械插件，並且效果疊加。

# 苦修

**本質**：魔幻本質

**價格**：B+6000

**分類**：特殊附魔

**描述**：精神的極限，肉體的極限，苦修者在追尋人的極限時無意間摸索到了肉體與精神的邊界，此時，靈與肉的界限已經模糊，只有如此才能體會更強大的境界。

**價格**：B+6000

**其他標籤**

**近戰神兵**：苦修者需選定一柄近戰非神兵的武器作爲苦修道具，被選中爲苦修道具的武器獲得【神兵】特性。

**艱苦修行**：你選中的武器被額外增加等同於你滿額負重的重量（這不計算該物品本身的體積），你的負重任何時候都視爲滿載，哪怕你的負重能力在之後獲得了提升。因此佩戴該武器以及任何裝備和物品都會讓你超重，獲得負重減值。

**武器增強**

<ul>
<li>作爲苦修道具的武器，武器傷害獲得相當於你的力量附加成功的提升，體積獲得相當於力量附加成功 /2 的提升，若你的苦修武器體積大於等於你的體積，你的武器獲得【格擋】特性。附魔後的武器，再計算其支線時，用其原本的支線等級與本附魔等級取高。</li>
<li>苦修武器額外獲得【崩飛】【壓制】【痛苦源於自身】【力量武器】【苦修成功】特性。</li>
</ul>

**崩飛**：當你 I 使用本武器進行攻擊時，若你成功造成傷害，則目標需要進行一次力量 + 運動（平衡感）的檢定， DC= 所受最終傷害。如果失敗，則會往後移動失敗差額米。如果中途撞倒障礙物，則對兩者造成剩餘距離米數的衝擊傷害。如果你主動降低對敵人造成的傷害，可以讓 DC 獲得等額提升，每降低 1 點，則 DC 增加 2 點。你使用武器造成的任何傷害都會觸發這個效果，你無法壓制這個效果。

**壓制**：你使用苦修武器進行的每個動作都會給你帶來等同於武器體積的疲乏點數，若是以武器進行格擋，每次成功格擋都會受到等同於武器體積不可避免的衝擊傷害。

**痛苦源於自身**

<ul>
<li>苦修中你不可坐臥，只能保持最低限度的飲水和進食，通常來說，這會使你進入疲乏，飢渴狀態，並因不可坐臥獲得等同於你力量上的附加成功 - 你耐力上的附加成功的劇痛點數。</li>
<li>你需要隨時握着苦修武器，否則視爲苦修失敗，苦修時間的計算從新開始。（若因不可抗力例如瀕死和昏迷引起武器不在手中，可以進行 1 天的祈禱和冥想消耗 3 意志來從新進入苦修）</li>
</ul>

**力量武器**：因爲極度的重量，苦修武器無法以敏捷作爲主屬性進行攻擊，也無法運用需要敏捷的技巧。

**苦修成功**

<ul>
<li>在隨時手持苦修武器三年或通過三部影片後，並且支付 56 點 XP 之後，視爲苦修成功，該武器獲得以下變化：</li>
<li>苦修武器失去“壓制”以及“痛苦源於自身”特性。</li>
<li>你在任何與力量，耐力相關的檢定上獲得等同於你武器額外體積的 DP 加值，這是修行加值。</li>
<li>你“崩飛”特性中的“若你成功造成傷害，則目標需要進行一次力量 + 運動（平衡感）的檢定”描述變爲“若你成功造成傷害，則你可以令目標需要進行一次力量 + 運動（平衡感）的檢定”。</li>
<li>同時，你的苦修武器在攻擊體積小於武器體積的敵人時獲得體積差的附加成功，同時獲得體積差的 DP 器械減值。</li>
<li>持有者在進行強韌檢定時可以獲得等同於你力量上附加成功的附加成功。</li>
<li>持有者在意志檢定時可以獲得等同於你耐力上附加成功的附加成功。</li>
<li>持有者在進行反射檢定時可以以力量替換敏捷。</li>
</ul>
