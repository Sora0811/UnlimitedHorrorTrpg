# 服侍訓練

> 來源：`資源/稱號/盧恩米德加茲冒險者/武僧路線`

## C 級

**技能樹**：無

**特性**：魔力掌握，天使之護，天使之擊，移花接木（雙特性），反應過人（雙特性），信仰導向（負特性）

**特殊**：由於沒有技能樹，額外獲得 1 個特性。

**其他標籤**

**魔力掌握**：服侍訓練使你掌握了魔力，你獲得魔力池和相當於稱號等級的施法者等級，可以用來學習和使用通用魔法。

**天使之護**：以魔力作爲溝通神力的渠道，服侍能依靠感知神啓來躲避傷害，當你受到攻擊或需要進行反射檢定時，你可以消耗 3 點魔力，以智力代替敏捷來決定基礎防禦，或以感知代替敏捷來決定反射檢定。

**天使之擊**：以魔力作爲溝通神力的渠道，服侍能依靠神力的指引來攻擊對手，當你進行基於力量或敏捷的肉搏攻擊檢定時，你可以用感知代替力量/敏捷進行檢定。

**移花接木**：你能活用自身具備的能量抵消傷害，當你受到傷害時，你消耗一個反射動作支付 3 點任意通用能量，可以抵消至多 5 點傷害。

**反應過人**：你現在免疫相當於你稱號等級的措手不及效果。

**信仰導向**：此爲北歐神系信仰導向能力，與北歐神系以外的信仰導向能力衝突
