# 馴獸師

> 來源：`資源/稱號/技巧類/馴獸師`

## D 級

**其他標籤**

**戰鬥流派**：你屬於特別善於指揮動物進行戰鬥的一類人。當你在操縱你的動物夥伴進行戰鬥時，其所有檢定，包括防禦獲得額外加值，加值爲你馴獸技能上的附加成功 + 稱號等級，加值類型爲士氣加值。

**治癒流派**：馴獸師中擁有治療的一類人。當你在每遭遇結束之後可以爲等於你稱號等級數量的動物夥伴回覆傷害，你馴獸技能上每有 1 個自動成功數則獲得 3 點治療點數，每點治療點數可以恢復 1 點衝擊傷害或者嚴重傷害， 4 點治療點數可以恢復 1 點惡性傷害。

**進化流派**

<ul>
<li>馴獸師中擁有能讓動物成長更快的一類人。當你每場影片結束的時候可以讓自己的動物夥伴額外獲得相當於你馴獸技能附加成功數 + 你稱號等級的經驗。</li>
<li>你可以選擇對一個動物夥伴下令，或者選擇對多個動物夥伴下令，但是你每一次下令都是一個迅捷動作。對如果不下令的話，你的動物夥伴會繼續執行上一個命令或者原地待著不動（動物夥伴只聽從主人的命令）。</li>
<li>你的動物夥伴每回合如同玩家一樣有自己的迅捷動作，移動動作和標準動作。</li>
</ul>


**正文**

現在花分不得製造人造人，若之前已經制造人造人，則無法購買此稱號。只能用以製作動物爲目標。

你現在製作的動物上限變爲你的馴獸等級附加成功數 + 稱號等級。同時，你進入恐怖片時，你可以不爲你製造的這些動物花費一個 D ，他們也可以在主神空間並不跟隨你進入恐怖片世界。

## C 級

**其他標籤**

**戰鬥流派**：你力量上每有 1 點附加成功，則你在 D 級的士氣加值再額外 +1.

**治癒流派**：你風度上每有 1 點附加成功，則你額外獲得 3 點治療點數。

**進化流派**：你每有智力上的一點附加成功，則你的動物夥伴在影片結束時可以額外獲得 1 點經驗。


**正文**

每場影片結束時，你可以把自己所獲得的經驗分給自己的寵物夥伴。同時你可以如常給你的動物夥伴兌換稱號，技藝，改造（以人類爲基準的無法兌換，如變種人），瞳術（若其有眼），能量池。但是無論如何，你無法給其兌換血統，物品，魔導書。

## B 級

**其他標籤**

**戰鬥流派**：當你下命令的時候，你可以進行一個操控+動物溝通（馴獸）的檢定，在這次檢定中你每獲得一個成功數，則該動物夥伴在下一次執行你的命令的時候，額外獲得1DP的表現加值。

**治癒流派**：現在 D 級的描述變爲從每遭遇結束之後改爲每場遭遇。此時你回覆傷害是一個標準動作。

**進化流派**：你現在基因庫甚至可以記錄其經驗所兌換的專長以及技能。但是不會記錄用經驗購買的自創技能和屬性。


**正文**

現在你的每個動物夥伴都會有自己的一個基因庫。

當其花費支線以及分數兌換某種能力時，將記錄入該基因庫，若其死亡，則你可以在主神空間調用其基因庫然後安放在一個新的動物夥伴中。（新的動物夥伴是指新制造且沒有經過任何兌換的）。

該基因庫不會向前追溯，只會記錄以後所得。

## A 級

**其他標籤**

**戰鬥流派**：每場景一次，如果你即將受到致命一擊（包括但不限於物理，魔法，範圍等），那麼你的動物夥伴可以不顧一切來爲你襠下這一擊，如果你使用這一能力，視爲你在承受這一擊之前，你的神奇寶貝以不可思議的速度或者角度來擋在你的身前，你不會承受本次傷害，但是你的動物夥伴將不可避免的死去。只有跟隨你超過 3 場恐怖片的動物夥伴纔可以使用此能力。

**治癒流派**：每場景一次，當你的一隻動物夥伴受到致命傷害時（包括但不限於物理，魔法，範圍等），你可以免除本次傷害。

**進化流派**

<ul>
<li>每場景一次，當你主動開啓某技能時，動物夥伴可以無視前提同樣獲得該技能，持續時間與你相同，這無法讓動物夥伴獲得持續時間爲永久的技能。（這種技能包括狼人變身，某些以自身爲目標的法術，肌肉支配者等）</li>
<li>技能樹</li>
<li>D+1000+10XP 不會倒下</li>
<li>當你與你的動物夥伴在同場景下行動時，你自動獲得等同於稱號等級的死硬與鋼鐵意志專長帶來的效果。</li>
<li>D+500+5XP 戰鬥吧！夥伴！</li>
<li>當你與你的動物夥伴一同作戰時，你自動獲得你方場上你的動物夥伴數量的掩蔽加值。</li>
<li>C+100+5XP 讓我們上吧！</li>
<li>你可以對你的動物夥伴使用鼓舞士氣專長，專長等級與你的稱號等級相同。到達 B 級時，你可以將專長中“整輪動作”變爲“標準動作”，到達 A 級時，修改爲“移動動作”。</li>
</ul>


**正文**

當你的動物夥伴在行動時，你可以支付 1 意志點，使你的動物夥伴行動增加 DP 或增加目標的防禦，如同神奇寶貝自身支付了意志點一樣，並且它依然可以再次支付意志，兩者的加值疊加。

### C+1000+5XP 我知道如何保護自己

**前提**

<ul>
<li>戰鬥吧！寶可夢</li>
<li>當你與你的動物夥伴一同作戰時，你自動獲得你方場上動物夥伴數量 X2 的掩蔽加值。取代 D 級的效果。</li>
<li>B+2000+10XP 你不是我的主人！</li>
<li>你的動物夥伴免疫魅惑效果，在對抗心靈類效果時額外獲得等同於你的馴獸技能附加成功 + 稱號等級的 DP 加值。</li>
</ul>

### A+4000+15XP 人多力量大

**前提**

<ul>
<li>我們是一家人。</li>
<li>當你做任何主動判定時，你的動物夥伴會協助你，你可以將他們相關屬性上帶來的附加成功作爲 DP 來加入到你的判定之中。</li>
<li>並且在作戰時，你可以通過一個 DC 爲 5 的調查判定來發現敵人的弱點從而讓動物夥伴的攻擊更加強大。判定結果每超過 DC1 點則所有神奇寶貝的戰鬥判定增加 1DP 。</li>
</ul>

### A+4000+15XP 心神鏈接

**前提**

<ul>
<li>你不是我的主人</li>
<li>你的動物夥伴現在免疫任何魅惑，脅迫，奴役等類似技能。對抗心靈類效果上再額外加上該動物夥伴的支線等級。你與你的動物夥伴之間視爲有精神力技能――心靈鏈接。但這並不視爲你具備精神力能力池，這是一個超自然能力。</li>
</ul>

**正文**

主神空間崇尚以個人的實力去戰鬥，但是總有一些人採用馴養其他生物作爲其謀生的手段。雖然主神並不崇尚這種方式，但是爲了保證主神空間的多樣性，所以主神經過篩選，最終收錄了這樣的一種能力。
