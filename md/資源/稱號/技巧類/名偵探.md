# 名偵探 B 級

> 來源：`資源/稱號/技巧類/名偵探`

## 災星降世

**其他標籤**

**例子**：一名小偷要偷竊你隊友的物品，則盜竊判定 +2 自動成功；一個殺手以狙擊槍射擊被你們保護的劇情人物，該次攻擊 +2 自動成功。


**正文**

名偵探心靈的一角永遠是孤獨的，因爲他們會在不自覺間呼喚出身邊人的死兆星。

與你同處一場景內的角色機運骰自動失敗。如果在非戰鬥狀態下可能引出 [ 案件 ] ，則該判定 +2 自動成功。

**其他標籤**

**可以學習技能**

<ul>
<li>偵探智慧。</li>
<li>在進行與一個特定案件有關的判定時，名偵探可用 [ 偵探智慧 ] 來代替搜索、政治外的所有精神系技能。</li>
<li>線索發現</li>
<li>名偵探的武器就是 [ 線索 ] ！你對與案件有關的事物特別在意，如果你忽略了某些地方，使用本技能後可得到 ST 小窗提示。每個場景可用 1 次。</li>
<li>邏輯和推理</li>
<li>使用武器的方法就是 [ 邏輯 ] 和 [ 推理 ] ！你可將得到的線索以邏輯的方法聯繫在一起，再輔以嚴密的推理。</li>
<li>進行一次智力 + 偵探智慧判定，每個成功可將一條相關線索融合（ [ 邏輯 ] ），或以該線索爲起點得到另一條 ST 給予的提示（ [ 推理 ] ）。如果成功數可將所有線索融合並完成推理， ST 給直接給予其最終結果――犯人爲誰。</li>
<li>兇手就在我們當中</li>
<li>名偵探的當家法寶。在發現犯罪人就在身邊後，你虎軀一震高聲斷喝並用手點指兇手，兇手將被你的氣勢震懾，直到你向衆人解釋犯人的手法和動機完畢爲止。如果你的證據足夠充分，他會震懾一輪，並受到 5 點無法減免的精神束縛。或者你也可先揍犯人一頓，然後再講解，這樣他會受到 20 點精神束縛。</li>
</ul>


**正文**

你命中註定成爲名偵探，毫無顧及的展現着縝密的邏輯和大膽的推理。

在進行搜索和任何與 [ 線索 ] 有關的判定時都 +2DP 。
