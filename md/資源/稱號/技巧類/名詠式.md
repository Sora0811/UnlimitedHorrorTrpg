# 名詠式

> 來源：`資源/稱號/技巧類/名詠式`

**前提**

<ul>
<li>風度 4+ 、表達（名詠） 3</li>
<li>使用和召喚對象相同顏色的「觸媒」以及歌頌對象名字的「贊來歌」召喚物體的技術。被召喚的對象會從幻想之地「瑟拉菲諾」穿越名詠使的「名詠門」出現。名詠式依照顏色分爲紅、藍兩個系統。</li>
</ul>

**價格**：此技藝每級價格等同稱號模板，每次購買必須在兩個系統中擇一，且你只能使用你會的顏色系統。同系統必須從低到高順序購買纔可使用同級名詠。但你可以越階名詠，但這時候 DC 會變爲原來的三倍，你只能越1級。

**例**

<ul>
<li>你花費 D+1000 購買紅色名詠式，則你可以使用 D 級：第四音階名詠。接下來你只能購買更高級紅色名詠式並使用，或購買其他顏色的 D 級名詠式並使用。</li>
<li>特殊的，從現在開始，你獲得子技能，表達-明詠，你提升表達-名詠的等級只需要花費一半的 XP，向上取整，在進行表達（無需子技能）的檢定時，無法使用表達-名詠的等級進行檢定，並且表達-名詠的提升不會爲你帶來經驗減免。</li>
</ul>

**特殊**：所有召喚物默認最長存在一個場景。若召喚物爲生物，每回合只有一個你的召喚物獲得一輪動作，在你的回合開始前，先執行召喚生物的一輪，接着才輪到你，且所有召喚物沒有自主意識，只會被動接受你的指示。

## 贊來 DC ：特殊

**效果**：你可以名詠出任何物品，名詠出來的物品不具有任何能力，只有單純的外觀。名詠物品每有 1 點體積，贊來 DC+1( 起始爲 0 ，最少爲 1) ，名詠出來的物體通體爲你的系統顏色 ( 紅、藍 ) 。

**其他標籤**

**贊來語**：無

**對象**：羽毛、花瓣、或者任何小對象

**系統**：對應的顏色


## 贊來 DC ： 3

**效果**：名詠光芒乍現，接着出現無數羽毛或花瓣在你方圓一公尺內，一分鐘或 10 輪內，它們會緩緩在你四周飄落，但不影響視線。這會讓你在風度檢定上獲得 +3DP 的環境加值。每超過 DC3 個成功，可以增加距離 1 公尺並使加值提升 3DP 。當名詠物消失後加值也隨之消失。若你使用這些東西作爲觸媒，這不是爲後罪，名詠成功後這些東西就會消失。

**其他標籤**

**贊來語**：無

**對象**：紅藍色馱精

**系統**：對應的顏色


## 贊來 DC ： 3

**效果**

<li>他只明白簡單的搬移指令，且只要結構值還存在，你可以指揮他搬運或背起所需力量不超過此次成功數的東西。</li>
</ul>

<ul>

<li>C 級：第三音階名詠（ Prime Aria ）</li>
</ul>

接觸處產生一道與系統同色的光芒，對象會從你接觸的地方出現然後產生效果。若失敗，則冒出一陣等同系統顏色的煙霧，並且沒有任何效果。
