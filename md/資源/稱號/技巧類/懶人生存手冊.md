# 懶人生存手冊

> 來源：`資源/稱號/技巧類/懶人生存手冊`

**本質**

<ul>
<li>特異本質</li>
<li>作爲一個足夠慵懶節能的人，你力求能隨時隨地慵懶的活下去。然而在恐怖片的世界裏，真的有人能慵懶的活下去嗎？</li>
</ul>

## D 級

### 清晨的回籠覺

**價格**：D+1000

**特性**：節能模式（雙特性）、放我下來、睡的好飽

**特殊**：沒有能量池額外獲得 1 個特性

**價格**：D+1000

**其他標籤**

**節能模式**

<ul>
<li>這麼寶貴的時間，不用來睡一覺實在可惜。</li>
<li>精通如何以最舒服姿勢休息的你可以隨時隨地的睡上一覺。無論是在緊張的備戰時，奔馳的馬背上，還是連天的炮火聲中，哪怕正被緊縛着倒吊起來，只要沒人叫你起來，你都能睡的安穩自如。</li>
<li>在任何超過半個小時無需你進行任何操作的場景中，你可以聲明自己進入“節能模式”。此狀態下，你無視任何環境影響進入睡眠狀態，在此過程中，你的隊友可以以一個反射動作大聲呼喊 / 用力搖晃來叫醒你。在此狀態下，你可以進行冥想或者打坐等操作。節能模式的時間算作長休息，每進入節能模式半小時視爲長休息一小時，恢復的能量也會視爲一小時的恢復量，但冥想等類似操作無法累計時間進行，同時節能模式狀態下你無需飲食甚至連呼吸也不是必須的</li>
</ul>

**放我下來**

<ul>
<li>懶人是很難在這個世界上生存的――除非他有一個能把他扛着到處跑的朋友。</li>
<li>若你的隊友的體積不小於你，且力量不小於你的體積值，則其可以攜帶你並且不計入負重。特殊的他將你拿起來僅需要消耗一個迅捷動作</li>
</ul>

**睡的好飽**：你如果在當天使用過節能模式，那麼你可以完全免疫令你陷入睡眠的心靈影響能力。


## C 級

### 午間小憩

**價格**：C+2000

**特性**：路人存在感（雙特性）、這不是拖延症

**特殊**：無

**價格**：C+2000

**其他標籤**

**路人存在感**

<ul>
<li>“討厭視線，不想被人盯着，儘量保持不被人看着的狀態，想要悄然地活着。被當作焦點什麼的，最糟糕不過了。如果可以的話，我希望在自己的人生中也不要當主角。”</li>
<li>你獲得特異本質的 C 級反偵測手段。表現形式上，你的形象淡化爲一個作者懶得上色，沒有五官的線稿路人角色，在潛行上你獲得 6 DP的表現加值</li>
</ul>

**這不是拖延症**

<ul>
<li>我等一會就寫這個特性的描述</li>
<li>如果你沒有懶惰惡德，那麼你將獲得這個惡德。若你已有懶惰惡德，則觸發時你可以再回復1點意志力。</li>
</ul>


## B 級

### 迷迷糊糊的下午

**價格**：B+2000

**特性**：絕妙的慵懶感、下次會努力的（雙特性）

**特殊**：無

**價格**：B+2000

**其他標籤**

**絕妙的慵懶感**

<ul>
<li>慵懶是有感染力的，就像打哈欠會傳染一樣，慵懶也會傳染給別人的。</li>
<li>每場景一次，用標準動作擺出一懶洋洋的姿勢，如鹹魚趴、葛優癱，使風度 / 米內所有看到你的生物受到等同你風度值的疲乏點數（向上取整），意志豁免。若要使用該能力，本回合你不能使用意志力的標準用法。這個能力對每個單位只能生效一次。</li>
</ul>

**下次會努力的**

<ul>
<li>所以這次就先稍微放鬆一下吧。</li>
<li>指定一個攻擊方式，用標準動作進行這個攻擊的關鍵屬性和關鍵技能（如果這次攻擊有多個關鍵屬性，則選擇其中一個，關鍵技能同理）檢定，那麼下一回合之前在你進行這種攻擊時，你獲得等同於檢定成功數的技藝加值。</li>
</ul>


## A 級

### 天黑早入眠

**價格**：A+4000

**特性**：夢遊（雙特性）、 WAKE UP!

**特殊**：無

**價格**：A+4000

**其他標籤**

**夢遊**

<ul>
<li>zzz~~~~ 你不會因爲 A 級以下的昏迷、睡眠、震懾和無助狀態而喪失行動力。表現爲，你處於這種狀態下，但你的任何行動都不受影響。在別人看來，這是你的身體本能在夢遊中做出的行爲。</li>
<li>WAKE UP! ：幹完這個就能休息了麼？還是不行？</li>
<li>每場景一次，你集中精神，全力達成目標。自由動作支付 1 點意志，本一輪你的每項行動上獲得 9DP 的表現加值，同時在防禦上也獲得 9 點表現加值。</li>
</ul>
