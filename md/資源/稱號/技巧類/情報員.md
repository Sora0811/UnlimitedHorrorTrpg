# B 級，倒計時的壞彈

> 來源：`資源/稱號/技巧類/情報員`

**稱號**

<ul>
<li>情報員</li>
<li>與大多稱號不同，情報員並不會讓人在戰鬥中得到實質性的提高。但是作爲補償，他們能夠對主神的情報進行小規模的操作，以實現迷惑敵人與完成佈局的目的。真正的佈局還是需要大腦，但是沒有充分的條件任何佈局也只是空談，因此，主神主動願意爲你提供條件。或者說，主神也想用謊言來讓自己娛樂一下。</li>
</ul>

## D 級

**其他標籤**

**稀薄的存在感**：存在感對情報員來說是一個很敏感的詞，因爲太強的存在感會不利於自己的工作。因此主神給他們創造了這樣的天賦，通過腦內暗示讓人在思考中產生盲點。如果行動者有可以選擇的機會，那麼他進行某個行動的對象必然不會先考慮你。比如在攻擊中你與一個同伴相臨並在攻擊範圍內，那麼攻擊者的目標必然是你的同伴。在治療時如果你與同伴都受傷，如果沒有主動提醒，那麼必先治療你的同伴。但是，如果你主動造成傷害或者造成敵意行爲，包括但不限於威嚇，說服，給隊友上BUFF，給目標上DEBUFF等行爲，你對該目標失去這個特性的獎勵。這將持續一天的時間。

**無雲之雨**：你對受攻擊者進行腦內暗示，加上主神爲你提供感官效果，你可以進行一次完美的“騙局”。你在進行攻擊時，在傷害檢定後，你可以選擇讓這次攻擊無效。這樣不會帶來任何效果，但是你依然對其失去“稀薄的存在感”的獎勵，同時誰都能清楚地看見這次攻擊產生的彈孔，血跡，傷痕和其他類似造成傷害時應有的視覺效果。但是即使如此，也不會造成任何傷害，受攻擊者不會有任何感覺，不會發生任何改變（如子彈沒有發出還是沒有發出，因攻擊而損壞的武器根本沒有損壞等），並且本應由這次攻擊而帶來的效果也被判定爲無效。

## C 級

**其他標籤**

**虛假之盾**：主神爲你提供視覺效果，讓你成爲如同無所披靡的存在。但實際上，你還是承受着應有的傷痛。在你受到任何傷害或懲罰或不良效果時，你可以讓主神爲你進行一場“騙局”：誰都會清楚地看到這次傷害被無效掉，子彈被身體彈開，光束如同打在力場上，刀刃本應打在身上卻被揮空等等。但實際上你還是如同正常受到攻擊一般受到傷害，只不過這個傷害的感官表現被主神“替換”掉了，但是你還是會有受到傷害的感覺。如果你的傷害被填滿，你依然會倒下昏迷死亡。你還是會受到不良效果影響，比如雖然纏繞全身的蔓藤因爲視覺效果而被“燒掉”，但是你依然還是無法行動。

**無劍的戰士**：除了你本身以外，你所觸摸的物體也可以用情報處理的方法進行“整形”，以達到計劃的目標。你可以將 1 件體積不大於你原始體積的物品變成與原物品體積相同的另一個物品。新的物品無需與原物品有任何聯繫，只需體積與原本物品相同（比如你可以把一把長劍變成一個木棒，把一個皮鞭變成一個釣竿，但你不能把一把巨斧變成一個錢包）。但是這個變形後的物品只能以它變形前的方式使用。一旦使用方式違背了原本的方式或會造成傷害和死亡（如把一件武器變成衣服後穿上，或將一個炸彈變成食物讓人喫下）。那麼在使用者使用前它就立刻被主神還原，會因這個行動而受到任何影響的生物都會立刻發現這個還原，沒有任何行動能快過這個還原。你每次只能改變一個物品。你的情報員稱號等級沒比 C 高 1 級，可以多改變 1 個。


**正文**

在達到 C 級後，主神將會給你一些新的權限來幫助你實現佈局。儘管無法對周圍的環境造成任何的改變，但是你已經基本可以“修改”你自己和你所持有的物品的外在。同時，主神也會開始會給你機會領悟一小部分主神相關的知識，如果能夠領悟出來，你就能進行一些平常輪迴隊員根本無法觸及的行動。購買 C 級情報員後，可以獲得下列能力：

## B 級

**其他標籤**

**虛假的真實**：即使你根本沒有成功，但是在主神的“幫助”下，你在別人面前展示了自己的“成功”。你進行任何檢定時，如果檢定失敗，你可以把它變爲“成功”。比如入侵網絡失敗但是別人卻能讓看見它跳進了管理員的界面，天上掉下的石頭本應砸到你卻最後落在你的身邊，你對手銬開鎖失敗別人卻看到手銬已被撬開，或者生死賭博中你喝下毒酒但是你卻好象喝下正常的一樣。但是這種“成功”只要一經檢驗就會立即還原。在上面的事例上，只要別人一碰鼠標或鍵盤，界面立刻變成入侵失敗的提示。儘管沒砸到你或好象喝到正常的酒，但是你還是要承受這個傷害或不良效果（如同虛假之盾一樣）。雖然手銬被撬開但是“無形的手銬”還是限制了你的行動。這個特性帶來的失敗與“成功”由 ST 決定它的“成功”時的狀況與真實效果。如果這個效果失敗會造成死亡，那麼你失敗的話不能改變爲成功。如果有人對結果報以懷疑，他必須主動要求進行智力 + 理解對抗你的智力 + 掩飾來辨別真相。但是 ST 不會提示 PC 進行檢定。

**真實的虛假**：與虛假的真實相反，你的行動成功了，但是別人看來你卻“失敗”了。你進行任何檢定時，如果檢定成功，你可以把它變爲“失敗”。比如你在網絡上用銀行洗錢成功了，但是顯示器上卻對你進行警告，天下掉下的巨石本應從你身邊擦過，但是別人卻看到砸到了你的頭上。你已經完成了門的撬鎖，但是誰都無法打開這個門，就好象還是鎖着一樣。或者在生死賭博中你喝下正常的酒，但是別人卻以爲你喝下毒酒。這種“失敗”按照你的意願可以持續任意的時間，直到你告訴主神“遊戲”已經玩完爲止，同時這種“失敗”可以給自己帶來痛覺，但是卻不會造成任何傷害。在上面的事例上，儘管警報不斷作響，但是錢還是不斷流入你的戶口。儘管巨石把你完全壓住，但是隻要你想起身，它可以輕易地被滾走。別人無論怎樣都撬不開鎖時，你輕輕一推門就打開。別人一邊嘲笑着痛苦的你一邊喝下“正常”的酒，然後立刻撲街。如果有人對結果報以懷疑，他必須主動要求進行智力 + 理解對抗你的智力 + 掩飾來辨別真相。但是 ST 不會提示 PC 進行檢定。


**正文**

## A 級

**特殊**：稱號能力只有擁有情報員稱號，並滿足 C 級稱號能力的前提與限制時主神纔會提示這個稱號擁有這些稱號能力。即只有情報員才能知道他們的稱號能力是什麼，其他人無從所知。

**限制**：情報員的稱號能力只有在你的稱號只有情報員時才能擁有。但你通過兌換的方式獲得其他的稱號或在擁有情報員前便已擁有其他通過兌換獲得的稱號時，你永久失去情報員的稱號能力，即使你已經購買。同時，你無法通過任何方法將這些稱號能力告訴別人。
