# Rank D

> 來源：`資源/稱號/技巧類/記憶獵人`

**稱號**：記憶獵人

**本質**：特異本質

**描述**

<ul>
<li>2084 年的新巴黎，虛擬現實與記憶控制掌控着人類。人類可以數字化、販售、購買或交換個人記憶，人類的性行爲活動已消失，只是處在一個社交網絡與地理定位技術的簡單社會體。這一被稱爲“監視社會”的社會系統已被居民接受，這是一個沒人考慮挑戰的世界。</li>
<li>以這樣的世界爲舞臺，一羣自稱“義勇軍”的犯罪分子以掌控這個世界的龐大商業組織「記憶之眼」爲敵人而活躍着。他們通過名爲「記憶手套」的非法工具，隨意破壞、奪取他人的記憶，而其中的佼佼者更是能肆意篡改他人的記憶，重塑他人的人生……這樣的犯罪者被平民和政府畏懼地稱爲「記憶獵人」。</li>
</ul>

## D 級

**特性**：記憶共享，數據流

**技能樹**：記憶獵人 D 級技能樹

**其他標籤**

**記憶共享**：通過一次接觸（一般使用接觸攻擊檢定），你可以向目標傳輸一段你擁有的記憶，或者從目標處獲得一段其自願提供的記憶。共享的記憶長度沒有限制，但無論如何必定爲共享者認爲是真實的，且以第一人稱的形式存放在被共享者的腦海中，但是可以與原本的記憶明確區分開來。

**數據流**：你裝備了“記憶手套”的手的觸及範圍提升 10 ＋ 1 米 / 意志，在額外的範圍中，你不能使用“記憶獵人”的能力以外的行動。


## C 級

**特性**：記憶竊取，意志爆破

**技能樹**：記憶獵人 C 級技能樹

**其他標籤**

**記憶竊取**：通過一次接觸，你可以對目標發起一次意志對抗，若你勝出，則可讀取目標任意由你指定的時間段內的記憶，最長時長爲 1 分鐘 / 勝出數。無論成功或者失敗，目標不會意識到你讀取了他的記憶。

**意志爆破**：每當你在針對一個敵人的行動中使用了意志（如攻擊，施法等），並且該次檢定成功造成效果，則目標失去 1 點意志。


## B 級

**特性**：記憶破壞，記憶超載

**技能樹**：記憶獵人 B 級技能樹

**其他標籤**

**記憶破壞**：通過一次接觸，你可以對目標發起一次意志對抗，若你勝出，則可消除目標任意由你指定的時間段內的記憶，最長時長爲 1 分鐘 / 勝出數。你可以在同一次接觸中使用「記憶竊取」，若如此做，則兩者共享判定和指定的時間，表現爲你將記憶從目標腦海中剝離到了自己腦海中。記憶的丟失只會讓目標受到一些劇情效果，不會讓目標以往其任何學會的技能和技藝，同時若目標得到提醒，則可以回想其這部分記憶。（本效果由 ST 擁有最終解釋權）

**記憶超載**

<ul>
<li>每當你“使用記憶手套”的手進行肉搏攻擊並對目標造成傷害的時候，你可以選擇減少任意數量的傷害，改爲對減少敵人等量的意志。每輪可造成的最高上限爲當前稱號等級 x2 。</li>
<li>---------------------------------------------------------------------</li>
</ul>

## D 級

**動作**：標準

**射程**：觸及範圍內

**持續**：立即

**效果**：通過向目標發送大量坈餘的垃圾數據流，使其過載，運行數據強制修改爲 0 和 1 ，即“是”與“否”，從而可以通過一次接觸隨意開啓 / 關閉支線等級不超過稱號等級的“機關”，包括但不限於“門”和“鎖”等。

**價格**：D+500

### 數據脈衝－結構破壞

**價格**：D+500

**動作**：標準

**射程**：觸及範圍內

**持續**：立即

**效果**：針對構造物的結構數據的破壞，編入這個程序之後，每當你對於具有一定結構的構造物（由 st 判定，槍械、機器人、魔偶等顯然具有結構，但是長刀等物品卻一般不視爲具有結構的物體……）造成傷害時，可以選擇不造成傷害，轉化爲等量的該構造物的使用 / 運作時的 dp 受到相同的器械減值，該減值可疊加，但是每 1 輪迴復 1 點。若是固定功能式的器械則改爲每輪有 x ％的幾率失效（ x 爲原本的傷害數值， d100 決定），同樣可以疊加且每輪迴復 1 點。

**價格**：D+500

### 記憶接口 - 僞裝

**價格**：D+500

**動作**：標準

**目標**：自身

**持續**：一個場景

**效果**

<ul>
<li>選擇你擁有的一段記憶，使用整輪動作將該記憶的持有者的數據覆蓋在自身的外表，使自己的外形轉變爲該對象。這個效果會讓你從視覺到觸感都會變成與對象一樣，用以其僞裝進行交涉類檢定是獲得 4DP 表現加值。你無法模擬與你體型相差超過 2 的的單位，模擬而來的各種器官不會賦予你原本沒有的能力。你也無法用目標的指紋或者虹膜等類似的效果打開某些“機關”。</li>
<li>這是一個 C 級幻術效果。</li>
</ul>

**價格**：D+500

## C 級

### 記憶接口－暴怒

**價格**：C+1000

**動作**：迅捷

**消耗**：2 點意志

**目標**：自身

**持續**：三輪

**描述**：將大量的記憶殘片包裹在記憶手套上，從而對敵人進行精神層面的打擊。

**效果**：迅捷動作開啓，花費 2 點意志，持續期間你每次攻擊若對敵人造成傷害，則目標會直接失去 1 點意志，若該次攻擊中有惡性傷害，則失去 2 點。本效果每場景最多使用一次。

**價格**：C+1000

### 邏輯炸彈

**價格**：C+1000

**動作**：迅捷

**消耗**：3 點意志

**範圍**：半徑 50 米

**持續**：立即

**效果**：花費 3 點意志和一個迅捷動作進行一次意志檢定，隨後製造一枚邏輯炸彈，它會在你行動結束時爆炸，對半徑 50 米範圍內的所有單位造成等同你檢定成功 /2 的嚴重精神傷害，反射減免。每受到 3 點來自邏輯炸彈的傷害，會同時失去 1 點意志，失去的意志上限爲你的稱號等級 +1 。你也可以以一個標準動作將其投擲出去，進行一次敏捷 + 運動（輕投擲武器）檢定，投擲距離至多爲 1 米 / 成功。也可以以一個標準動作和一次接觸檢定將其安置到目標身上，若接觸成功，則對方以反射檢定對抗你的肉搏檢定，若目標失敗，目標無法進行反射。每場景只能製造一枚邏輯炸彈。

**價格**：C+1000

## B 級

### 記憶接口－ D.o.S

**價格**：B+4000

**動作**：整輪動作

**消耗**：3 點意志

**範圍**：10+1m/ 意志

**持續**：立即

**描述**：通過攻擊目標神經網絡的缺陷，讓目標的記憶系統無法提供正常的功能，使目標的神經網絡停止響應甚至崩潰，從而陷入無法行動的狀態。

**效果**：花費 3 點意志和一個整輪動作，對周圍 10+1 米 / 意志範圍內的敵人發起一次意志對抗，對方每有一個在決心或沉着上的附加成功，則在此次對抗中額外得到 3DP ，所有失敗的敵人直到你下次行動結束陷入震懾狀態。每 5 個失敗數會使該敵人額外震懾 1 輪。每場景只能發動一次該能力。

**價格**：B+4000

### 鏽蝕碎片

**價格**：B+4000

**動作**：整輪動作

**消耗**：2 點意志

**射程**：觸及範圍內

**持續**：立即

**效果**：通過對機械識別系統和原則程序的干擾，使其轉變立場。選擇一個支線等級不超過稱號等級 -1 的機械 / 構裝體單位，其必須是使用邏輯模塊而非人腦思考的，擁有一定自律能力的。支付 2 點意志，通過一次成功的接觸，改變其程序。若其具有戰鬥能力，則其會盡一切可能攻擊其感知範圍內的、與你敵對的單位，在其感知範圍內沒有這些單位時，其會自動自我銷燬。若是沒有戰鬥能力的單位則其會立刻自我銷燬。該能力一場景只能使用一次。

**價格**：B+4000

### 記憶接口－重現

**價格**：A+4000

**動作**：整輪動作

**射程**：觸及範圍內

**消耗**：5 點意志

**持續**：立即

**描述**：這是將你從他人處獲得的記憶的重新再現，模擬其技術的能力。

**效果**：使用一個整輪動作立刻讀取你所擁有的一段記憶，讀取之後這段記憶立刻開始消散，這段記憶每有 1 分鐘，則可以消散 1 輪。與此同時這段記憶的主人當時的能力會開始被你讀取，在消散期間，你可以使用其當時擁有的技藝如同你擁有一樣，但是這些技藝無論如何不會給你帶來新的能量池，且若你沒有滿足這些技藝的前提也無法使用這些技藝，最後，你所能使用的技藝不能超過稱號等級 -1 。一旦開始讀取就無法停止這段記憶的消散。

**價格**：A+4000
