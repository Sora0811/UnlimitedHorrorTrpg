# 植物師

> 來源：`資源/稱號/技巧類/植物師`

**本質**：特異本質

**前提**：手藝 - 園丁 2 ，科學 1 （植物學）

**描述**：植物師，顧名思義，種植植物的人，在一個神奇的植物與喪屍爭鬥的世界大放異彩的職業，傳說第一個植物師已經成了瘋子，開着一輛卡車到處亂跑，教導着新生的植物師。

## D 級

**能量池**：無

**技能樹**：開啓 D 級植物師技能樹

**特性**：禪境花園，戰鬥植物，贈送植物（雙特性）

**其他標籤**

**禪境花園**

<ul>
<li>培育植物需要空間，放置植物也一樣需要，你開闢了一個特殊的花園，在這裏只能放置本稱號下的戰鬥植物，當你購買了本稱號下的戰鬥植物後，其將自動放置在這裏。</li>
<li>禪境花園是一個特殊的個人空間，你無法在這裏保存除了栽種植物所需的工具和植物以外的物品。</li>
<li>禪境花園可以積累陽光，當你在太陽下被照射一小時可以獲得 1 點陽光，它的上限是 20\* 稱號等級數，召喚戰鬥植物則需要消耗陽光。</li>
<li>在戰鬥後你以自由動作回收植物進入禪境花園，它們將在禪境花園回覆，在禪境花園裏，它們將獲得再生 1 ，並且可以以 1/4 的速度回覆惡性傷害。</li>
</ul>

**戰鬥植物**

<ul>
<li>只是種點花花草草有什麼意思？現在，讓我們把你精心培育的植物放上戰場，是時候讓它們打打怪了！</li>
<li>當你需要的時候你可以用一個標準動作，消耗召喚戰鬥植物所需的陽光並把存放在禪境花園裏的一個戰鬥植物取出並擺放在以你爲圓心，距離爲（稱號等級 + 科學技能等級） \*10 的範圍內你可以看到或者感知到的任意位置。</li>
<li>一般來說，植物的攻擊是自動攻擊最近的敵方目標而不會有其他動作，你無法控制你召喚出來的植物，所有戰鬥植物將在你的輪結束時開始行動，戰鬥植物每輪若沒有特殊說明，則只有一個攻擊動作。</li>
</ul>

**贈送植物**：你獲得本稱號等級技能樹下的一個 D 級戰鬥植物。


## C 級

**技能樹**：開啓 C 級植物師技能樹

**特性**：上帝視覺，高速拜訪（雙特性），植物收容

**其他標籤**

**上帝視覺**

<ul>
<li>就算你躲在屋裏，你依舊可以指揮植物戰鬥。</li>
<li>你種的植物以精神連接的方式和你共享視覺。</li>
<li>你現在消耗一個迅捷動作，可以操控你的任意個植物讓其攻擊你想要攻擊的目標。</li>
</ul>

**高速擺放**

<ul>
<li>怪物越來越多了，所以你的手速也跟着增加。</li>
<li>當你本稱號等級是 C 級時，你召喚戰鬥植物的動作下降爲移動，若本稱號等級是 B 級，則你召喚戰鬥植物的動作下降爲迅捷。</li>
</ul>

**植物收容**

<ul>
<li>在無限的世界中，有更多的植物等待你發現。</li>
<li>你可以嘗試收容並培育在劇情世界中遇到的植物，這需要你的科學技能等級與稱號等級均高於該植物價值的支線等級，並且該植物每價值一個 D 支線需要你花費 5XP 以學習培育方式，若 ST 判定該植物培育難度高但可培育，則該植物視同陽光植物，需要重複購買。</li>
<li>ST 有權禁止本能力，若禁止本能力則你獲得以下能力進行替代：</li>
<li>你的手藝 - 園丁的相關檢定獲得【 9 加骰】。</li>
</ul>


## B 級

**技能樹**：開啓 B 級植物師技能樹

**特性**：高度智能，完全遮蔽（雙特性），植物復活

**其他標籤**

**高度智能**：你的植物視爲完全具有心智與社交屬性，數值相當於你數值的一半，這代表着其也會受到心靈影響。

**完全遮蔽**：小小的植物可以完全遮擋住你的身形。只要面前的地上種植植物（持有植物或者抱着花盆等類似的行爲都不行），植物師就在針對遠程實體攻擊時，獲得全掩蔽效果。

**植物復活**：你現在當你的植物死後（引爆後），你可以在原地拾取它的種子，花費 24 小時重新培育。


**正文**

所有標註爲戰鬥植物的皆爲種子，當植物死亡時，則你失去該植物（除非你通過 B 級的能力重新復活該植物），每顆種子只能種植一顆植物。

所有戰鬥植物皆可以重複購買，購買的皆爲種子。

所有戰鬥植物的生物分類皆爲植物，所有植物無法自主移動。

戰鬥植物的攻擊檢定的DP皆爲基礎DP，其可以與其他加值類型的DP疊加。

戰鬥植物的防禦皆爲天生防禦。

戰鬥植物只有敏感範圍，沒有模糊範圍。

若沒有特殊說明，植物遠程實彈射擊攻擊造成的皆爲穿刺傷害，植物遠程投擲攻擊造成的皆爲鈍擊傷害。

### 櫻桃炸彈

**價格**：D+500

**描述**：“我要爆了！”，櫻桃一號說。“不！我們還是慢慢引燃吧”，他的兄弟，櫻桃二號道。稍適爭吵，這兩個傢伙決定即刻引爆。

**其他標籤**

**召喚所消耗的陽光**：3

**引爆**

<ul>
<li>櫻桃炸彈一共有以下四種方式引爆：</li>
<li>\1. 具現後進行投擲攻擊引爆，如同手雷。</li>
<li>\2. 將其放置在某一個位置，然後1輪後引爆。</li>
<li>\3. 將其放置在某一個位置，然後當被任何物體碰觸，即可引爆。</li>

</ul>

**瞬間爆炸**：若你以方法1引爆，則投擲者進行一個敏捷+運動（輕投擲武器）的檢定，每有一個成功數，則目標的反射檢定失去1DP。若你以方法3引爆，則碰觸櫻桃炸彈的目標無法進行反射豁免。
