# 太吾傳人

> 來源：`資源/稱號/技巧類/太吾傳人`

**本質**：特異本質

**前提**：人物國籍爲中國，需求醫學技能等級3

**總描述**：十世鑄一劍，一劍傳十世，十世異人，亦或者，十世一人？

**特殊**

<ul>
<li>同一隊輪迴小隊中，最多隻有1人可兌換本稱號的A級。</li>
<li>此外，本稱號下所提及的“攻擊”與其檢定不包括使用法術、槍械、分類爲“炮”的武器所進行的遠程攻擊在內。</li>
</ul>

## D 級　無名小卒

**能量池**：內力

**技能樹**：開啓D級太吾傳人技能樹

**特性**：氣聚丹田（四特性）

**特殊**：無

**描述**：在兌換本稱號後，你獲得了一塊灰不溜丟的小鐵塊，它看起來只有你的巴掌大小，雖然沒有任何作用，但卻無論如何也無法將其破壞，即使將其丟棄，它也會在幾小時內重新出現在你身上，在你第一次接觸它的時候，你墜入了一個奇異的夢境中，在那裏面有一個偌大的江湖，而你不過是枚乏人問津的無名小卒……南柯一夢過後，你彷彿記下了些什麼，又像是什麼都沒得到，無論你之後怎麼擺弄那小鐵塊，也無法再次回到那片江湖中。

**其他標籤**

**氣聚丹田**

<ul>
<li>你可以花費一個移動動作降低自己X點內力上限，隨後獲得X點“本源真氣”點數，恢復以此法減少的內力上限是一個移動動作，你僅能以此法恢復因此減少的內力上限，並且在恢復之前你無法再通過本能力降低自己的內力上限，X最多爲本稱號等級\*15點，一旦你的內力上限回覆，則你因此獲得的“本源真氣”立即失去。</li>
<li>你可以花費一個整輪動作將“本源真氣”分配到“摧破”、“輕靈”、“護體”與“奇竅”這四類真氣上，你每朝其中一類真氣分配N點“本源真氣”，該類真氣便會增加1點，N等同於該類真氣當前的點數，修改已分配的“本源真氣”同樣是一個整輪動作，這會爲你帶來不同的收益，具體如下：</li>
</ul>

**摧破**：你每有1點“摧破真氣”，你的攻擊便能夠忽略目標任意1點基礎防禦，當你的“摧破真氣”點數達到5點時，通過此法可忽略的基礎防禦數值額外增加3點。

**輕靈**：你每有1點“輕靈真氣”，你的基礎移動速度便能夠增加2米，當你的“輕靈真氣”達到5點時，你的基礎移動速度再增加10米。

**護體**：你每有1點“護體真氣”，你便在防禦上獲得1點閃避防禦，當你的“護體真氣”點數達到5點時，該閃避防禦再增加3點。

**奇竅**：你每有1點“奇竅真氣”，則在你進行一次15分鐘的短休息後便能夠使你額外針對自己身上1項不良狀態點數獲得一次豁免的機會，當你的“奇竅真氣”點數達到5點時，你在對抗和豁免不良狀態點數的相關檢定上獲得2個附加成功。

## C 級　江湖浪客

**技能樹**：開啓C級太吾傳人技能樹

**特性**：洞若觀火（雙特性），義結金蘭（雙特性）

**特殊**：無

**描述**：你在兌換本級稱號後，你在觸碰那小鐵片時又再次回到了那奇異的江湖中，此時的你在江湖已慢慢闖出了些許名氣，在這個過程中，有不少人在你初見他時不過是萍水相逢，卻又在種種機緣巧合之下與你結爲莫逆之交。

**其他標籤**

**洞若觀火**

<ul>
<li>當你進行特定部位攻擊時，若你該次攻擊成功造成傷害，目標對應的部位會出現一層“破綻”，“破綻”持續時間爲一個場景。無論是否由你造成的，目標同一個部位同時只能擁有不超過本稱號等級+1層“破綻”，在“破綻”持續期間，你針對目標對應部位進行攻擊時，該次攻擊的傷害上限提升等同於“破綻”層數\*1點，並且可以獲得等額的附加成功。</li>
<li>但是，視爲同一次攻擊的能力即使在該次行動中進行了多次攻擊，該次行動最多也僅能對目標該部位造成1層“破綻”。</li>
</ul>

**義結金蘭**：你能夠花費三個整輪動作與一名除自己以外的自願單位結爲“好友”。這會使你和對方皆能夠無視前提獲得並能夠使用“守護戰士”專長第4級的效果，但該效果只能以對方爲目標，並且使用次數改爲每場景一次。“好友”的數量最多等同於本稱號等級\*1名，在結爲“好友”後，只有在“好友”死亡後才能夠解除“好友”關係。

## A 級　太吾傳人

**技能樹**：開啓A級太吾傳人技能樹

**特性**：伏虞劍柄，太吾傳承（雙特性），太吾氏

**特殊**：無

**描述**：江湖中的你接過那劍柄後，你從主神空間的房間中醒來了，歷代太吾傳人的過去如潮水般犁過你的腦海，曾經灰不溜丟的小鐵片逐漸呈現出其本來的面貌――伏虞劍柄。

**其他標籤**

**伏虞劍柄**

<ul>
<li>在兌換本級稱號後，你會獲得一把“伏虞劍柄”，其大小約等同於你的手掌，體積視爲1且具備【認主】特性，該物品無法以任何方式摧毀，即便遺失或被奪走，也會在24小時內重新出現在你身上，其本身沒有任何作用，也無法視作武器使用，僅僅是你作爲太吾傳人身份的信物。</li>
<li>你可以花費一個標準動作向所有能感知到你的單位展示伏虞劍柄，這會使對方知道你擁有A級太吾傳人稱號強化，隨後若其當前對你的初始友善度不低於警惕，則提升至友好，若已爲友好則提升至親切，該效果對同一單位僅能起效一次，並且你依舊可能因爲交涉不當或其他行爲導致對方的友善度下降，在劇情上表現爲對方被伏虞劍柄中世代傳承、對抗相樞的偉大精神所影響，從而對你的印象大幅改善。</li>
</ul>

**太吾傳承**

<ul>
<li>在你死亡時，你可以選擇將“伏虞劍柄”交給一名位於你模糊範圍內且自願接受它的單位，這無需動作，隨後該單位除血統、改造與瞳術以外的所有強化都會被洗去，而你能夠選擇讓對方繼承你除血統、改造、瞳術以外的所有強化，若對方當前強化與其繼承的強化有衝突，則對方不會繼承會發生衝突的強化和以該強化爲前提的後續兌換（例如已有黑暗生物血統的單位不能繼承聖武士稱號，擁有改造給予的魔力池則無法繼承混元劍經與其技能樹下的能力等）。特殊的，如果你擁有造人，則無論該造人是否位於你的模糊範圍內，你都能直接將“伏虞劍柄”轉交給對方，這會使造人不會隨你的死亡被抹殺，並且能夠立刻獲得輪迴隊員手錶並加入你死亡時所在的輪迴小隊。</li>
<li>在這之後你視作失去所有繼承給對方的強化，並且無法以任何方式復活。</li>
</ul>

**太吾氏**：你可以選定一位“好友”的一項技能，一旦選定不可更改，隨後只要該“好友”在該項技能上的等級低於你，其在花費XP提升該技能等級時所需支付的XP便降低等同於你在該項技能上的附加成功數+2點，最低降至1點，這無需動作，即使你已經死亡，你的“好友”也能夠獲得本特性帶來的好處，但每一位好友只能在一項技能上獲得該好處。
