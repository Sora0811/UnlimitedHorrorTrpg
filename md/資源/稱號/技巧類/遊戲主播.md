# 遊戲主播

> 來源：`資源/稱號/技巧類/遊戲主播`

**本質**：特異本質

**前提**：角色有較爲豐富的電子遊戲經歷，需求風度 3 或操控 3 以上，擁有專長鼓舞士氣 1 級或幽默大師 1 級

## D 級　普通主播

**能量池**：無

**技能樹**：開啓 D 級遊戲主播技能樹

**特性**：電腦使用，業餘主播，專業眼光，專業表達，摸了！

**特殊**：由於沒有能量池，額外獲得 1 個特性。

**描述**：立志成爲遊戲主播的你，現在纔剛剛摸到門檻，距離形成自己的風格還很遙遠。

**可選**：當你歷經一個場景且你在該場景內沒有做出任何動作後，你的外形會變爲一頭帶着紅領巾的狗頭人，這是一個 D 級特異本質的幻象效果，除外形改變外不會帶來任何影響，該效果持續至你作出任何動作爲止。

**其他標籤**

**電腦使用**：你的電腦技能提升 1 級，最高提升至 5 級。

**業餘主播**：你的表達 - 演講技能提升 1 級，最高提升至 5 級。

**專業眼光**

<ul>
<li>以一個移動動作選定你敏感範圍內一名單位，通過一個智力 + 調查（偵查）檢定與對方的操控 + 掩飾（僞裝）檢定進行對抗，若你勝出則可以選擇並得知以下一項信息：</li>
<li>\1. 獲知目標某一項指定技能數值，包括在該技能上的專業。</li>
<li>\2. 獲知目標當前生命值狀況，包括上限和已受到傷害。</li>
<li>\3. 獲知目標當前意志值狀況，包括上限和此刻剩餘的意志力。</li>
</ul>

**專業表達**

<ul>
<li>從以下能力選擇一項獲得：</li>
<li>\1. 鼓舞士氣提升至 2 級。</li>
<li>\2. 幽默大師提升至 2 級。</li>
</ul>

**摸了！**

<ul>
<li>你開啓一個特殊的刻度，名爲摸魚，該刻度上限爲本稱號等級 \*10 點，但每部影片開始時都會自動清零。</li>
<li>當你歷經一個場景且你在該場景內沒有做出任何動作（此處指任何會消耗動作的行爲，包括但不限於移動，格擋，說話等。）時，你可以獲得等同於本稱號等級 +1 點摸魚點數，當你擁有至少 10 點摸魚點數時，你可以花費整輪動作進入“爽到”狀態，在該狀態下你每輪行動開始時都會失去 1 點摸魚點數，但你在攻擊與防禦檢定上可以獲得等同於當前剩餘摸魚點數一半的修行加值，“爽到”狀態持續至摸魚點數耗盡或是你以一個移動動作主動解除該狀態。</li>
</ul>

## C 級　專業主播

**技能樹**：開啓 C 級遊戲主播技能樹

**特性**：自信宣言，流暢表達，摸魚奧義（雙特性）

**特殊**：無

**描述**：“專業解說看這種局面還看不懂啊？這種情況下你怎麼輸你告訴我，直接 A 臉都贏了，怎麼可能輸 RUA 。”

**其他標籤**

**自信宣言**

<ul>
<li>在任意戰鬥結束前，你可以選擇你看好的一方，並以周圍的人都能聽見的音量將你看好的一方大聲說出來，被你看好的一方將在本場戰鬥中在攻擊檢定或防禦 ( 在你每輪開始時決定 ) 上獲得等同於你稱號等級 -1 的附加成功，若你本人也處於被看好的一方中，在本場戰鬥中你在攻擊檢定或防禦 ( 在你每輪開始時決定 ) 上會獲得等於稱號等級的洞察加值。</li>
<li>如果被你看好的一方最終在戰鬥中被擊敗或逃離戰鬥，則戰鬥結束後你需要過一個意志檢定， DC 爲你的意志值，若檢定未通過，你會獲得差值的沮喪點數。</li>
</ul>

**流暢表達**

<ul>
<li>你在以下能力選擇一項獲得：</li>
<li>\1. 你在發動鼓舞士氣爲目標恢復意志力時，可額外恢復等於稱號等級的意志力，這不會計入本專長的恢復上限中。</li>
<li>\2. 現在你在使用幽默大師 2 級的能力時，該目標透過此法所能獲得的完美加值加值提高等同於你表達 - 演講技能 \*1 點。</li>
</ul>

**摸魚奧義**

<ul>
<li>你的基礎移動速度增加等同於摸魚點數 \*1 米，同時僅限於判斷你是否能獲得摸魚點數時，你說話和使用移動動作進行移動不會視作在一個場景中作出了動作。</li>
<li>此外，你現在只需要花費一個標準動作便能進入“爽到”狀態，同時在該狀態下你還會在對抗性檢定上獲得等同於當前摸魚點數一半的修行加值。</li>
</ul>
