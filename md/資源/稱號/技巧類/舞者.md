# 舞者

> 來源：`資源/稱號/技巧類/舞者`

**本質**：魔幻本質

**描述**

<ul>
<li>這能力在華夏衆多神奇的技藝中原本並不起眼，直到一名傳奇的東方舞者卡莉，執起舞扇。</li>
<li>天下大勢分久必合合久必分，中華大地遭受的戰亂連綿數千年。卡莉的族羣爲了躲避戰亂在荒廢的地方藏了起來，他們封閉世上所有事情全心全意開闢他們自己的生活。</li>
<li>但荒涼的土地上生活非常艱難。</li>
<li>當他們差不多忘記這個世界的時候。</li>
<li>世界也快遺忘他們的時候。</li>
<li>有一個來自華夏的異鄉人到了他們的村子。這異鄉人帶來了這世界終將毀滅的預言，並帶來了操控靈魂的關鍵技巧。爲了應對這無法避免的災禍，他們將這技藝融合進舞蹈之中。</li>
<li>災禍發生後，卡莉的族羣遭受滅頂之災，唯一的倖存者卡莉嚥下淚水，命運的殘酷讓她踏入人們的視野之中，並尋機復仇。</li>
<li>她不再執着於與靈魂的共鳴，而是專注於更有效率的戰鬥技能開發，在那艱難的歲月裏，卡莉把她的舞藝精髓、靈魂操控與對敵戰術完美的結合起來，形成了全新的舞蹈風景。</li>
<li>據說西行寺幽幽子也喜歡這種舞蹈（大霧）。</li>
</ul>

**特殊**

<ul>
<li>本稱號下所有技能皆只能以妖力、魔力、靈力或道力作爲能耗驅動。以靈力作爲能耗時，直接積累等同於能耗數量的靈感疲勞。</li>
<li>在兌換舞者稱號時，你必須在刀鋒舞者與魔靈舞者之間選定一條路線，選定後不可更改，你只能學習本稱號下的通用技能與對應路線的技能。</li>
</ul>

## D 級　舞者

**能量池**：無

**特性**：羅襪生塵（雙特性），北方有佳人

**技能樹**：開啓D級舞者技能樹

**特殊**：無能量池，額外獲得1個特性。

**描述**

<ul>
<li>《周禮·樂師》，注：“謂以年幼少時教之舞，內則曰：十三舞勺。”</li>
<li>作爲基礎的周代六個著名的祭祀舞蹈：《幢舞》、《羽舞》、《皇舞》、《旎舞》、《幹舞》、《人舞》。卡莉將其合而爲一，融入戰術體系中，其中一種具代表性的通靈舞蹈爲——《亡我舞》 。臨波微步，羅襪生塵。動無常則，若危若安。</li>
</ul>

**其他標籤**

**羅襪生塵**：你的基礎移動速度增加10米，你獲得3點閃避防禦。

**北方有佳人**：你的表達-舞蹈上提升1級，最高到5.
