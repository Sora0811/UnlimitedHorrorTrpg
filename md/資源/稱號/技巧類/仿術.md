<ul>

</ul>

## 雕刻【魂印】：

**例**

<ul>
<li>你研究了一張破敗的椅子，你希望蓋上魂印後變爲全新的、高級的椅子。當雕刻完成後，在該物品上蓋上【魂印】，則物品會變成所想的樣子，但這並不會改變物品的本質，垃圾依然是垃圾。這會使所有人對這個物品的認知遭到改變，只有觀察力極爲強大的人或同爲仿師的人才會看見【魂印】的印章來識破這個物品。</li>
<li>也就是說蓋上【魂印】並不會改變物品的外貌本質（從一個人變成另外一個人，從洗衣機變成電冰箱），同時也無法真正的修復一個物品（這不會恢復物品的結構值），也無法恢復生物的生命值。這僅僅是一個假象。</li>
<li>蓋上【魂印】的物品我們稱之爲【贗品】，要看破【贗品】需要通過該【魂印】的看破 DC，檢定爲感知+調查/學識取高 ，這會在雕刻完時決定，若看破者爲仿師的話則看破 DC 減半。</li>
<li>雕刻【魂印】是一個週期爲小時的延長動作，持續 3 個小時，雕刻【魂印】只使用智力做判定，每次至少需要使用 3 點魔力，初始 DC 爲 0 ，每次檢定成功，每有一個成功數， DC+1 ，你依然可以消耗 1 點魔力在判定中增加 1DP ，當雕刻結束，此時的 DC 就是這枚魂印看破的 DC 。</li>
<li>每一枚【魂印】只會紀錄一種改變，但你可以爲一個物品雕刻多枚【魂印】。</li>
</ul>

**正文**

當你研讀完後，纔可對該物品雕刻一枚【魂印】，依據物品等級不同，選擇不同品質的魂玉作爲材料。

雕刻時，需要專心想着希望改變的樣子，通常是指外觀、質地上的改變，而不是形狀。

**其他標籤**

**特殊的**：你可以在研讀判定中使用魔力，每消耗 1 點魔力可以增加 1DP 。

**無支線**：10 分


**正文**

仿術是仿師的獨門絕技，但是完整的仿術傳承早已遺失，就連主神都無法復原。仿術，當你仔細瞭解一樣東西過去歷史和現在的一切，你可以針對他製作一個專屬的印章，並透過將魔力灌注於雕刻印章的過程，產生足以改變物質形體的力量，技術頂尖的仿師甚至可以用仿術重新塑造一個人。

要雕刻一枚【魂印】，需先對物品進行等同研讀圖紙的研究動作 ( 使用智力 + 手藝 - 仿術 ) ，這並不需要購買圖紙，只要持有該物品或可以直接觀察到物品即可。
