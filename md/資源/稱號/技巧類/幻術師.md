# 幻術師

> 來源：`資源/稱號/技巧類/幻術師`

**本質**：特異本質

**前提**：需求掩飾技能 3 級，不擁有“正義”美德

**特殊**：本稱號下的所有技能以及能力皆爲相當於該對應支線等級的影響心靈與幻覺效果，目標只要擁有1種對應的免疫能力就可以免疫。

## D 級　基本級幻術使用

**價格**：D+ 1000

**技能樹**：開啓D級幻術師技能樹

**特性**：幻術檢定、讓我看看你的心、用幻術對付幻術（雙特性）、偵查加成（負特性）

**特殊**：無。

**價格**：D+1000

**其他標籤**

**幻術檢定**：角色施展幻術時，需要進行操控 + 掩飾（唬騙）的檢定這在下文統稱爲“幻術檢定”，幻術檢定所能獲得的成功數上限爲你的操控值+掩飾+稱號等級\*2。

**讓我看看你的心**：催眠洗腦的第一步，就是尋找對方內心的弱點。只要是角色施展的幻術效果，並且那個幻術效果擁有改變視覺畫面的效果，角色就總是可以獲知受影響者看到的畫面。

**用幻術對付幻術**

<ul>
<li>用魔法對付魔法，用幻術對付幻術。</li>
<li>當角色受到心靈效果或幻覺效果時，如果那個效果可以使用意志進行豁免，則角色可以使用操控 + 掩飾（唬騙）代替意志進行豁免。</li>
</ul>

**偵查加成**：其他角色在針對你使用的本稱號下的幻術進行對抗性檢定（包括下文的看破對抗與理解對抗）時，根據其擁有的最高支線等級的偵測能力，在檢定中獲得對應的完美加值： D 級 3DP ， C 級 6DP ， B 級 12DP ， A 級 24DP ， S 級 48DP 。

<li>這是一個“迷陣”效果。</li>
</ul>

**價格**：D+500

### 掩眼法

**價格**：D+500

**動作**：全回合動作

**能耗**：無

**射程**：敏感範圍

**目標**：一個體積不超過掩飾技能值的物品

**範圍**：無

**持續**：操控值 /輪

**效果**

<ul>
<li>你將目標物品的外觀替換爲同體積一個類似外形的物品（是否類似由 ST 定義）。</li>
<li>你只能影響低於你稱號等級的物品。</li>
<li>你進行幻術檢定，記錄成功數。所有在你啓動本能力後想使用該物品的目標以意志豁免，若你成功，則你可以根據變化的差異選擇下列中的一個效果生效：</li>
<li>變爲類似相似時 （如將“長劍”變爲“刀”），此種情況下，目標失去對應原本武器的對應專業加值，無法使用對應武器的招式技能，也無法獲得新的專業加值，也無法使用新武器的招式技能，同時承受4DP無名減值。</li>
<li>變爲差異較大時（如將“匕首”變爲“礦泉水瓶”），則該目標因爲眼中所見不是該物品，所以其無法使用該物品。</li>
<li>目標也可以在其輪花費一個標準動作再次以意志豁免，將成功數累積，若最終累計的結果超過你的幻術檢定成功數，則目標本場景皆不會再受本效果影響。</li>
</ul>

**價格**：D+500

</ul>

**價格**：D+5
