# 老惡棍

> 來源：`資源/稱號/刺客類/老惡棍`

**本質**：特異本質

## D 級

**能量池**：無

**技能樹**：開啓D級老惡棍技能樹

**特性**：隨身攜帶，交涉-物理，心藏刀劍（雙特性），蝴蝶刀掌握

**特殊**：由於沒有能量池，額外獲得1個特性。

**其他標籤**

**隨身攜帶**

<ul>
<li>“你說的啊，我身上有啥就算我的卡有啥。我看看……蝴蝶刀、爪刀、甩棍、開信筆，哦，還有一把眼翳刀。”“……你是怎麼上的地鐵？”</li>
<li>在對抗偵查你身上是否有武器的檢定中，若這些武器的體積皆不大於2，你便在相關檢定中獲得3DP的修行加值。</li>
<li>交涉-物理：“我這個人，”蝴蝶刀劃過一個漂亮的圓弧，“講究以德服人。”</li>
<li>當你使用威嚇檢定時，若你手持武器，則你可以選擇使用白刃（對應武器專業）技能替換脅迫（威嚇）技能進行檢定。</li>
</ul>

**心藏刀劍**

<ul>
<li>“刀劍纔是男人心中的浪漫，你們不懂”。</li>
<li>你的白刃技能提高一級，最高到5，並且白刃技能專業帶來的專業加值提升至3DP。</li>
</ul>

**蝴蝶刀掌握**：你在使用分類具備“匕首”的武器進行攻擊時，你該次攻擊增加3點【高速優勢】。

### 唯快不破

**價格**：C+1000

**射程**：無

**目標**：無

**範圍**：無

**持續**：立即

**描述**：“天下武功，唯快不破。”

**效果**：你進行該次近戰白刃攻擊時，可以與被攻擊目標進行一次敏捷檢定對抗，如果你勝出，則你在該次攻擊檢定中獲得勝出數\*1DP招式加值，且目標對這次攻擊視爲措手不及，這是一個B級措手不及效果。

### 削弱式攻擊

**價格**：C+1000

**動作**：被動

**描述**：“碰見那種想一力降十會的，你就慢慢一刀一刀劃死他吧”

**效果**：你進行近戰白刃攻擊時，若成功對目標造成傷害，則你可以選擇不造成實際傷害，而是將該次攻擊造成的傷害值轉爲等額的流血，劇痛或疲乏點數其中一項，目標皆以強韌檢定豁免，以此法造成的不良狀態點數可疊加。

**價格**：C+1000

## B 級

**技能樹**：開啓B級老惡棍技能樹

**特性**：暴擊專攻，蝴蝶刀掌握，天運，刀劍收藏癖

**特殊**：無

**其他標籤**

**暴擊專攻**

<ul>
<li>“老子上去就是一個D20！”</li>
<li>選擇一項你在白刃技能上具備對應專業的白刃武器分類，之後你在持用該武器時，該武器的加骰提升1級，最高提升至【8加骰】，如果該武器已具備【8加骰】，則你在使用該武器進行攻擊時獲得3個附加成功。</li>
<li>提升-蝴蝶刀掌握：你在使用分類具備“匕首”的武器進行攻擊時，你可以使你該次攻擊中的【高速優勢】優先減少目標的基礎防禦，若目標的基礎防禦因此降低至0，則其視爲措手不及，這是B級措手不及效果。</li>
</ul>

**天運**

<ul>
<li>“天投37，你多餘玩風度人啊……”BY星光絕滅。</li>
<li>當你在進行基因鎖檢定時，你的解鎖結果提升2點。</li>
</ul>

**刀劍收藏癖**：你購買支線不超過本稱號等級白刃武器時，可以額外支付等同於武器支線等級（D1C2B3，雙支線視同單支線，無支線視爲0.5）\*250分，隨後使該武器獲得【認主】特性，此能力無法應用於擁有【神兵】特性及可升級物品。
