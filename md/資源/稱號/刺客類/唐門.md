# 唐門

> 來源：`資源/稱號/刺客類/唐門`

**本質**：特異本質

**前提**：需求敏捷4以上，運動技能3以上

**描述**

<ul>
<li>蜀中唐門是一個家族式的江湖門派，飲譽武林的暗器家族，唐門人在江湖上行事詭祕，行爲飄忽，給人一種亦正亦邪、琢磨不透的感覺。</li>
<li>唐門以用毒手法與暗器聞名天下，善於設計、發明和使用各種暗器，並精於弄毒。據說唐門暗器共七種，江湖上常可見到的是針、蒺藜和斷魂砂。</li>
</ul>

**特殊**：如無特殊說明，本稱號下所提及的毒藥皆僅指分類僅有且皆有“毒藥”與“消耗品”兩項分類的物品。
