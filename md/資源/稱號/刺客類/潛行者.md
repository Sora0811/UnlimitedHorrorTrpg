# 潛行者

> 來源：`資源/稱號/刺客類/潛行者`

**本質**：特異本質

**前提**

<ul>
<li>需求敏捷3，需求躲藏技能等級2</li>
<li>在茫茫多的世界中，有這麼一個職業，他們隱入黑夜，匿入暗影，遁入死角，於最難以想象的角度，用最難以防禦的方式，結果自己的敵人，他們被稱爲――潛行者。割取頭顱，刺穿心臟，掏空臟腑，吮淨鮮血，奪取生命的方法千千萬萬，而潛行者之所以爲潛行者，是因爲他們總能在敵人找到自己之前消滅對方。</li>
</ul>

## D 級

**價格**：D+1000

**能量池**：無

**技能樹**：開啓D級潛行者技能樹

**特性**：隱匿精通，刺殺本能，神速消失（雙特性），高速

**特殊**：由於沒有能量池，額外獲得1個特性。

**描述**：即使敵人發現了你，你也只需要晃晃腳步，便如同幻覺般消失在黑暗中。

**價格**：D+1000

**其他標籤**

**隱匿精通**：你的躲藏技能提升1級並獲得“潛行”專業，最高提升至4級。

**刺殺本能**：當你進行特定部位攻擊時，你可以忽略3點特定部位攻擊減值。

**神速消失**：每次在進行先攻檢定時，你可以消耗一個反射動作進行潛行檢定，如果成功，視爲你開始戰鬥時處於潛行狀態。

**高速**：當你進行潛行時，你的基礎移動速度不會再因此下降，也無須因此承受潛行檢定成功數減半的懲罰。


### 奇襲

**價格**：D+500

**動作**：被動

**描述**：來自於黑暗中的攻擊,總是最致命的。

**效果**：你在攻擊時可以進行一個敏捷+躲藏（潛行）檢定，受到攻擊的目標需要以感知+調查（偵查）檢定進行對抗，若你勝出，則針對本次攻擊，目標視爲措手不及，這是一個等同於本稱號等級的措手不及效果。

**價格**：D+500

### 目標鎖定

**價格**：D+1000

**動作**：被動

**效果**：如果你對一個目標使用了任何標記能力（獵人印記、堅定不移、誓仇弓等），則在該標記能力持續期間，你在針對該目標的攻擊以及對抗性檢定中獲得相當於你傳奇沉着與傳奇決心之和的表現加值。

**價格**：D+1000

## C 級

**價格**：C+2000

**技能樹**：開啓C級潛行者技能樹

**特性**：提升-刺殺本能，毒藥精通，躲藏高手，突刺

**特殊**：無

**描述**

<ul>
<li>你的技術和手法只能以魔技和藝術來形容了，現在你可以展開你的刺殺能力以及盜竊能力來奪取他人的生命以及他人口袋中的財物。</li>
<li>提升-刺殺本能：當你針對目標進行特定部位攻擊時，目標的僅在豁免你該次特定部位攻擊影響的檢定上需承受相當於你本次攻擊傷害值一半的無名減值。</li>
</ul>

**價格**：C+2000

**其他標籤**

**毒藥精通**：你淬毒時DC下降稱號等級/點，並且當你製作毒藥時，你可以選擇支付3倍的製作分數並使毒藥的使用次數減半，若你這麼做，則該毒藥造成的不良狀態點數和毒素傷害會提升你的傳奇智力+2點（請注意，這是指毒藥本身對應的效果提升X點，而非對方豁免後所需承受的不良點數與傷害提升X點）。

**躲藏高手**：你在躲藏技能相關檢定上獲得【9加骰】。

**突刺**：若你的敏捷值比目標當前的敏捷或者感知高，則你的攻擊若成功命中，則額外對目標造成相當於你傳奇敏捷的嚴重物理傷害。

**價格**：C+1000

### 盜賊的浪漫/刺客的宣言

**價格**：C+1000

**動作**：整輪動作

**射程**：見下

**目標**：一個目標/物品

**範圍**：無

**持續**：見下

**效果**

<ul>
<li>首先你需要指定一件物品或者目標。（形容必須具體，不能是“敵方輪迴小隊最強武器”之類的籠統說法“）</li>
<li>之後，你要通知該物品或目標的擁有者，你將在某個時間點（如後天下午2點至3點間）取走/殺死/摧毀它，方法不拘，該時間點與你通知擁有者時的時間最多隻能相差48小時。</li>
<li>在你通知擁有者並經過至少24小時後，你在執行整個偷竊/刺殺相關行動的時候，針對目標（針對目標的偷竊，攻擊，隱藏，潛行，掩飾，調查檢定）你的所有檢定加骰上升1級，上限8加骰。</li>
<li>若你成功在你宣言的時間點達成目標，則你回覆全部意志力。</li>
<li>若你沒能在該時間點前達成目標，則你上述技能失去全部加骰，並且你投出10時也無法獲得加骰。持續一場影片。</li>
<li>這是一個標記能力。指定過程中不得指定其他目標，並且若你處於失敗的持續時間之內，你也無法指定其他目標。</li>
</ul>

**價格**：C+1000

## B 級

**技能樹**：開啓B級潛行者技能樹

**特性**：陰影跳躍，精準，不存在之法（雙特性）

**特殊**：無

**描述**：現在，陰影不止是讓你藏匿的位置，也成了讓你傳送的座標。

**其他標籤**

**陰影跳躍**：如果你處在潛行狀態中並位於黑暗環境下，你可以花費一個移動動作傳送不超你躲藏技能等級\*10米的距離，但傳送的位置必須同樣位於黑暗環境下。

**精準**：當你針對陷入措手不及的單位進行攻擊時，你該次攻擊獲得B級接觸攻擊的效果。

**不存在之法**

<ul>
<li>現在當你針對一個或多個目標進行潛行，併成功潛行時，對方必須能夠免疫B級以下的影響心靈效果才能夠對你進行精確定位，否則最多隻能對你模糊定位，持續至你脫離該潛行狀態爲止。</li>
<li>此外，即使你正在被目標關注，你也可以如常針對該目標進行潛行。</li>
</ul>


### 擾亂

**價格**：B+2000

**動作**：被動

**效果**

<ul>

</ul>

### 窒息之刃

**價格**：B+2000

**動作**：標準動作

**射程**：觸及

**目標**：一個目標

**範圍**：無

**持續**：立即

**效果**

<ul>
<li>你對目標進行一次近戰白刃攻擊，若成功造成傷害時，則目標需要通過1個DC爲你該次攻擊傷害值的意志豁免檢定，若其檢定未通過，則根據目標的意志檢定與DC相比，承受不同的效果：</li>
<li>\1.若目標的意志檢定成功數低於DC但未低於DC的一半，則目標下輪失去所有迅捷動作（若目標下輪本來就沒有迅捷動作，則改爲失去移動動作）。</li>
<li>\2.若目標的意志檢定成功數低於DC一半，則目標下輪失去所有移動動作（若目標下輪本來就沒有迅捷動作，則改爲失去標準動作）。</li>
<li>\3.若目標的意志檢定成功數低於DC的1/3，則目標下輪失去所有標準動作（若目標下輪本來就沒有標準動作，則改爲失去下一輪所有動作）。</li>
</ul>

**價格**：B+2000
