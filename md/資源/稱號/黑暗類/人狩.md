# 稱號――人狩

> 來源：`資源/稱號/黑暗類/人狩`

**本質**：魔幻本質

**描述**

<ul>
<li>人類者，萬物之靈是也，自然分陰陽，人亦分陰陽，自然有五行，人類有五臟.....故人類的形態，也是最好的修煉形態，可以最大程度的契合入自然當中，</li>
<li>因此以人型修煉，事半功倍，以人爲食，可延年益壽！“欲狩捕人類，必先惑其眼，亂其行，迷其耳，斷其嗅，識其僞......”</li>
</ul>

**特殊**：本能力下所消耗的通用能量，針對一次消耗，必須爲同一能量池下。（如一次消耗，爲3點通用能量，你可以選擇消耗3點魔力或者3點內力，但是不能選擇消耗2點魔力1點內力這種消耗方式。）

## D 級　皮毛篇

**價格**：D+1000

**技能樹**：開啓人狩D級技能樹

**特性**：狩獵印記（四特性）、黑暗生物（負特性）

**價格**：D+1000

**其他標籤**

**狩獵印記**

<ul>
<li>你可以以一個迅捷動作，標記敏感範圍內，你可以準確定位的一個人形生物，標記持續時間爲永久。</li>
<li>之後，只要標記存在，當目標進入你的模糊範圍內，你可以立即得知，這個印記最多同時存在稱號等級（D1C2B3）個。</li>
</ul>

**獵**：針對被你所標記的目標，你可以以自由動作對其進行分析，然後你對其進行一次不附帶任何招式的攻擊檢定，這次檢定如常受到傷害上限影響，然後將成功數以6:1的比例兌換爲高速，這個高速僅針對被你所標記的獵物。

**黑暗生物**：你變爲黑暗生物。

**特性**：殺七留三、獵、血蘸、陰噬

**陰噬**

<ul>
<li>來源於你的每一縷能量都凝結了無數人形生物的鮮血和怨恨，他們憎恨你，也憎恨所有還活着的人。當你使用消耗通用能量的技能攻擊人形生物時，本次攻擊每消耗1點能量，你本次攻擊的攻擊檢定獲得2DP能量加值。</li>
<li>人狩D級技能樹</li>
</ul>
