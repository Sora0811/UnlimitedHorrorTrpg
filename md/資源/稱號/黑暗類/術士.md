# 術士

> 來源：`資源/稱號/黑暗類/術士`

## D 級

**正文**

在獲得稱號的同時，你開啓了術士的 D 級技能樹，並且你必須選擇痛苦，惡魔，毀滅天賦中的一種，選擇後不可更改。並獲得該天賦中的一個 D 級法術。

同時，你還可以召喚惡魔爲自己效力， D 級時只能召喚到小鬼，隨着血統等級的提升，每等級可以召喚到更強大的惡魔 (C 級時可以得到魅魔或者虛空行者中的一個 ,B 級時可以獲得地獄犬或地獄火中的一個 ,A 級時獲得惡魔守衛和末日守衛中的一個 ) 。

從獲得了稱號起，你被視爲黑暗生物。

購買本稱號後你可以購買通用法術，你的施法者等級等於你的稱號等級。

**其他標籤**
