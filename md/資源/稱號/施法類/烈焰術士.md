# 烈焰術士

> 來源：`資源/稱號/施法類/烈焰術士`

**本質**：魔幻本質

**描述**

<ul>
<li>「縝密沒什麼好處～至少我從來不在乎這一點。」</li>
<li>烈焰術士自信滿盈，熱情似火，桀驁不馴，她的專長就是烈焰：火焰咒語，火焰，以及更猛的火焰。</li>
</ul>

## D 級　火花招焰

**能量池**：魔力

**特性**：火焰法師，焚化

**技能樹**：開啓D級烈焰法術技能樹

**描述**

<ul>
<li>「上百萬生靈中，只會有一人生來便具有成爲鵬洛客的火花。而能意識到自己身藏此無限潛力的人則更爲稀少。點燃火花的你已然躋身強力精英法師之列，但跟你一般強大的，不僅只有朋友……還有敵人。」</li>
<li>在上千萬個生靈中，只會有一個具有「火花」，這難以言喻的本質讓此生靈有機會成爲鵬洛客。而在生來便具有「火花」的人之中，又只有極少數纔有機會將它「點燃」，並藉此瞭解自己穿越時空的潛力。許多鵬洛客點燃火花的時機都是在面臨巨大危機或創傷時，但每個人的覺醒過程都各有不同。瀕死經驗也許能點燃火花，但改變生命的頓悟或是出神冥思也可能讓法師掌握到超凡的真理。</li>
<li>點燃了鵬洛客火花之後，通常會爲自己的生命設定一個目標，不論它是什麼。它將會成爲你新的角色特性。</li>
<li>火焰術士的火花會被好奇、憤怒、熱忱點燃，這會使你獲得紅色的烈焰魔力。</li>
</ul>

**其他標籤**

**火焰法師**：你獲得本稱號等級的施法者等級。

**焚化**：被你施展的帶有【火】關鍵字的法術殺死的單位無法透過任何低於你稱號等級+1級的復活能力復活。

## C 級　惹事人

**特性**：烈火斷層（雙特性）

**技能樹**：開啓C級烈焰法術技能樹

**描述**：「誰會想一個個點火？」 「生體自燃只是個迷思，如果你全身冒火，那是有人要你冒火！」

**其他標籤**

**烈火斷層**：當你施展本體系下的法術且帶有【火】關鍵字，能夠造成傷害且目標僅爲一個目標的法術時，你能夠對以該目標爲中心半徑20米的球形範圍內的所有單位造成等同於目標所受傷害數的火焰嚴重傷害，目標本身不會受到此傷害，而範圍內受影響的單位以反射檢定進行豁免。當你施展本體系下的法術且帶有【火】關鍵字且造成範圍傷害的法術時，你可以選擇不超過你決心附加成功數的目標不受到影響。

## B 級　烈焰奇才

**特性**：精巧火術，肆虐火光

**技能樹**：開啓B級烈焰法術技能樹

**描述**：「茜卓的天賦使她孑然獨立，使他人着火燃燒。」 「隨着時間流逝，連火焰修行僧的技藝也比不上茜卓了。」

**其他標籤**

**精巧火術**：僅限於你所施展的法術等級高於B級且帶有【火】關鍵字的法術，在其作用於目標前，目標無法主動針對該法術使用反射動作，即便其擁有免疫措手不及的能力也一樣。

**肆虐火光**：你在施展帶有【火】關鍵字的法術時可以額外支付5點魔力，使該法術同時造成等同於施法檢定成功數的燃燒點數，若該法術本身便會造成燃燒點數，則兩者可以疊加計算。

## A 級　火焰大師

**特性**：爆烈衝動，怒火報復

**技能樹**：開啓A級烈焰法術技能樹

**描述**

<ul>
<li>「好吧，這失控了。」 「這纔是我一直想見到的茜卓。」</li>
<li>在你使用火焰法術之後，來自烈焰的力量會不受控制的從你身體中溢出，將你點燃。</li>
</ul>

**其他標籤**

**爆烈衝動**

<ul>
<li>在你施展帶有【火】關鍵字的法術後，你可以獲得等同於你所掌握的，帶有【火】關鍵字的法術數量\*1點燃燒點數，燃燒點數不會對你造成傷害。當你受到燃燒點數時，你可以以一個自由動作驅散自己身上所有的燃燒點數。同時，所有在以你爲中心半徑5米範圍內的單位每輪都會受到等同於你所掌握的，帶有【火】關鍵字的法術數量\*1點火焰嚴重傷害。</li>
<li>你可以花費1分鐘壓制該特性，之後直到你再次施展帶有【火】關鍵字的法術前該特性皆不會生效。</li>
</ul>

**怒火報復**：當你受到傷害時，你下一次以對你造成該傷害的單位爲目標施展帶有【火】關鍵字的法術時，你在施法檢定上獲得4點附加成功。若爲範圍傷害，則只要目標中包含該目標，則即可獲得附加成功。若範圍中包含多個，則可以累積獲得附加成功。（如範圍中有3個符合要求的，則你施法檢定獲得12點附加成功）
