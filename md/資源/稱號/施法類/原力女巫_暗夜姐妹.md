# 原力女巫 / 暗夜姐妹（ Nightsister ）

> 來源：`資源/稱號/施法類/原力女巫\_暗夜姐妹`

**本質**：特異本質

**描述**

<ul>
<li>暗夜姐妹又被稱之爲原力女巫或西斯女巫，她們是一羣生活在達索米爾星球的原力使用者，她們通過施法――原力一種表現形式――來產生如同魔法一般的效果。</li>
<li>原始的原力女巫們信仰達索米爾星傳說中的神祗――“兒子”與“女兒”。</li>
<li>女巫們並非絕地、亦非西斯，雖然是一個宗教團體，但她們沒有嚴格的信條和教義，只是讓原力隨自己的心意而施展。</li>
</ul>

**特殊**

<ul>
<li>在任何形式的原力感知上，女巫都視爲黑暗原力的使用者，但原力女巫的原力並不會轉化爲黑暗原力。</li>
<li>如果絕地武士成爲原力女巫，或原力女巫成爲絕地武士，則同時視爲光明原力和黑暗原力的使用者，可以同時學習光明原力和黑暗原力的招式。</li>
<li>必須是女性才能成爲原力女巫，並且每個輪迴小隊只能有 1 名原力女巫。</li>
</ul>

## D 級　教員

**能量池**：原力

**特性**：，原力激化，原力法師（雙特性）， 達索米爾鍊金術

**技能樹**：開啓絕地武士一層技能樹。

**描述**：無

**其他標籤**

**原力激化**：當你目前承受的與情緒異常相關的不良狀態點數高於或等於你的決心或沉着值取低者的一半，你在施展法術時便會自動增幅等同於本稱號等級 \*1 次，但這會計入增幅上限，也無法增幅你目前尚未能進行增幅的法術。

**原力法師**：你獲得魔力能量池，並且獲得學習和購買通用法術的權利，並獲得等同於本稱號等級的施法者等級。

**達索米爾鍊金術**：你自動獲得手藝 - 鍊金術子技能，並且 你在進行手藝 - 鍊金術技能相關檢定時獲得等同於本稱號等級/DP修行加值 。


## C 級　助理

**特性**：煉製生命之水（雙特性）， 提升 - 原力法師（雙特性）

**技能樹**：開啓絕地武士二層技能樹。

**描述**：無

**其他標籤**

**煉製生命之水**

<ul>
<li>你獲得煉製生命之水的能力。同時，你的手藝-鍊金術技能相關檢定獲得9加骰。</li>
<li>要煉製生命之水，你需要先施展一個你已掌握的，不超過本稱號等級的通用法術，該法術不會產生任何效果，也無法進行增幅，它會被儲存在你體內，之後你需要在施展該法術之後的 8 小時內收集等同於該法術支線等級（ D1S5 ，雙支線視作單支線） \*1 份源自達索米爾的原材料，該材料每份需要花費 50 分在主神空間購買，但如果 PC 進入的影片背景合適， ST 也可以允許 PC 在影片世界中自行獲取該材料，你支付等同於該法術能耗的原力並花費 1 個小時與等同於該法術支線等級 \*1 份材料，進行一次 DC 等同於該法術支線等級 \*3 的感知 + 手藝 - 鍊金術檢定，若中途被打斷則該次檢定自動失敗，已支付的原力和材料不會返還，你儲存在體內的法術也會自動消散，若檢定通過，則你儲存在體內法術會被消耗並煉製爲一瓶生命之水，在你消耗掉儲存於體內的法術前，你無法往體內儲存更多的法術，你每天只能製造不超過本稱號等級 \*1 瓶生命之水，生命之水具體屬性如下：</li>
</ul>


# 生命之水

**本質**：特異本質

**分類**：藥水，消耗品

**體積**：1

**描述**：無

## B 級　輔祭

**特性**：提升 - 原力學習（雙特性），達索米爾鍊金術（雙特性）

**技能樹**：開啓絕地武士三層技能樹。

**描述**

<ul>
<li>無</li>
<li>提升 - 原力法師：當你目前承受的與情緒異常相關的不良狀態點數高於或等於你的決心或沉着值取高者時，由“原力激化”特性帶來的自動增幅將不會計入增幅上限。</li>
</ul>

**其他標籤**

**達索米爾祕儀**：本特性效果等同於“ A 級法術恆定術”，但特殊的是你只能選擇一個你掌握的 B 級或以下的法術，之後需要花費 1 天並支付等同於該法術支線等級（ D1C3B5 ） \*4 點 XP 才能將其恆定在一個自願的單位身上，若中途被打斷則照常消耗 XP ，該單位可以花費自由動作永久解除恆定在其身上的法術，之後除非該生物身上以此法恆定的法術被永久解除，否則你無法再使用本特性，除此之外皆與 A 級法術恆定術相同。


**其他標籤**

**法術封存**：該生命之水中封存着你製造時所選擇的法術，使用者可以如同親自施展該法術一般使用該生命之水，但使用者無須支付施展該法術所需的能耗。

**保質期**

<ul>
<li>生命之水最多隻能保持儲存在內的法術的支線等級（ D1S5 ，雙支線視作單支線） \*24 小時。</li>
<li>提升 - 原力法師：位於本稱號的施法者職能體系下的法術及其產生的效果皆視作特異本質而非魔幻本質。</li>
</ul>
