# 魔法工程師

> 來源：`資源/稱號/施法類/魔法工程師`

**本質**：魔幻本質

**前提**

<ul>
<li>智力4，神祕學3，學識、科學和手藝中至少有一個3</li>
<li>“我的家鄉是將魔法視爲‘一般科學’來研究的世界，元素的運行、詭祕的符文、強大的術式，都可以用數學公式和經驗參數來推理、量化。唯一不研究的就是人心。話說回來，你們那邊世界的物理學纔算是匪夷所思吧。”</li>
</ul>

##  級　――某個位面間的旅人

**價格**：C+2000

**能量池**：魔力

**技能樹**：魔法工藝技能樹

**特性**：工匠（雙特性），快速成形，施法

**描述**：“一一得一，一二得二……九九八十一。”初學的魔法世界數學是如此的枯燥、乏味和小兒科，但你卻發現加減乘除都可以對應到元素屬性的奧祕。

**價格**：C+2000

**其他標籤**

**工匠**：你現在可以製造魔幻本質物品，並能夠如同學習科技本質的手藝一般學習魔幻本質手藝（除了丹道和仙工）。

**快速成形**：僅僅通過一個整輪動作，你就可以完成一次任意物品的製造（如常滿足條件以及足夠的材料），但仍需正常進行延長檢定，同時額外並支付相當於物品製造DC+延長檢定輪數/點魔力。製造出的道具在本場景使用結束後，必須立即花費正常的時間重新制作，否則將不可避免的立即損毀。

**施法職能**

<ul>
<li>你獲得C級的施法者等級，你可以學習和使用通用魔法。</li>
<li>魔法工藝技能樹</li>
</ul>


### 侵蝕的熱度

**關鍵字**：【火】

**專業**：變化

**威力值**：4

**價格**：C+1000

**動作**：標準動作

**能耗**：3點魔力

**成分**：語言，姿勢

**射程**：無

**範圍**：自身

**持續**：一個場景

**描述**：崇尚攻擊的炎/光法師，會在所有能造成負面效果的魔法中融入兇暴的高溫能量。

**效果**：持續時間內，你施展的所有造成傷害的法術，若成功造成傷害，則對目標額外再造成4點火焰嚴重傷害，同時目標的裝甲值或者天生防禦值下降威力值/點，不可疊加，持續智力值/輪。

**增幅**

<ul>
<li>若你擁有2點傳奇智力，則你在施展本法術時，可以額外花費2點魔力，此時，本法術的增益效果將不侷限於法術，而是改爲所有造成傷害的攻擊與法術。</li>
<li>你每擁有1點神祕學等級帶來的附加成功，則你可以額外花費1點魔力使本法術造成的傷害無視目標1點傷害減免或吸收，由你選擇。</li>
</ul>

**價格**：C+1000

### 不竭的泉流

**能耗**：3點魔力

**射程**：無

**範圍**：自身

**持續**：一個場景

**描述**：溫柔神祕的法師，會讓自己的每一束魔力都化作清澈的希望之露。

**效果**

<ul>
<li>你進行一個施法檢定，每有1點成功數，則你獲得1治療點數。</li>
<li>當你有治療點數時，你可以花費一個自由動作，對觸及範圍內的目標恢復傷勢。</li>
<li>衝擊傷害需要1治療點數，嚴重傷害需要3治療點數，惡性傷害需要9治療點數。你還可以使用治療點數恢復目標的不良狀態點數，每點不良狀態點數需要2點治療點數。</li>
</ul>

**價格**：C+1000
