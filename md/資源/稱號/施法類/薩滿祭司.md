# 薩滿祭司

> 來源：`資源/稱號/施法類/薩滿祭司`

**本質**：魔幻本質

**前提**：神祕學技能等級3級，

**描述**

<ul>
<li>薩滿是氏族與部落的精神領袖。他們和靈魂溝通，有預知未來的能力，並在黑暗的年代裏指引他們的人民渡過難關。許多人將他們的智慧和平靜誤解爲和平主義者的天性。事實上，當受到挑戰的時候，薩滿擁有強大的能力來對付擾亂自然秩序的傢伙。</li>
<li>作爲風火水土四種元素的溝通者和維護者而存在，同時薩滿要尊重先祖和元素的尊嚴。不能侮辱他們同時也因爲在艾澤拉斯有了一套很明確的規定也不用擔心遭到惡用。</li>
</ul>

<li>當你處於安穩的環境，並且該場景內存在該元素時</li>
<li>以一個整輪動作進行一個神祕學檢定，與一種元素溝通，DC如下，建立起聯繫：</li>
</ul>

**微量元素**：dc8

**少量元素**：dc4

**大量元素**

<ul>
<li>dc2</li>
<li>溝通成功後，你獲得對應的效果，持續時間爲一個世界，同一時間只能有一種聯繫生效，除非你重新與其它元素建立聯繫，那會使得你之前溝通的元素效果失效</li>
</ul>

**地**：只要你站立在大地上，天生防禦增加4點。

**水**：你獲得3點偏斜防禦。

**火**：你獲得2點火焰抗力。

**氣**：你的基礎移動速度增加5米，先攻增加3點。

**施法者**：你獲得相當於本稱號等級的施法者等級，你可以學習並使用通用魔法。

**製作圖騰**

<ul>
<li>你獲得技能手藝-圖騰製作，並提升1級。</li>
<li>當你符合條件（木頭，製作工具，安靜的環境，顏料）時，</li>
<li>你可以通過智力+手藝進行一個週期爲小時，DC爲5的檢定製作圖騰</li>
</ul>

**圖騰**

<ul>
<li>它是一根硬度爲2，結構值爲5，1。2m高，體積3，頂端帶有花紋裝飾的木棍。</li>
<li>放置圖騰是一個標準動作，你將攜帶着的圖騰取下，插進地面（或是用支架使其豎立在堅硬或不平整的地面上）。</li>
<li>請注意，插入圖騰僅僅是一個畫面效果，這不會使被插的平面收到任何傷害和造成任何影響。(如將圖騰插在載具上不會對載具造成傷害，更不會造成缺口)</li>
<li>圖騰不能插在生物身上。</li>
<li>\- 圖騰可以被攻擊。</li>
<li>\- 圖騰是固定的，不會跟隨你移動。</li>
<li>\- 圖騰放置好之後，你才能施法激活它。</li>
<li>\- 除非特殊說明，不然每一個圖騰上只能激活一種圖騰能力，激活第二種能力時則自動抵消第一種，同時只有放置好的圖騰才能觸發圖騰能力</li>
<li>\- 如果沒受到任何損害，則一個圖騰可以多次使用。</li>
<li>\- 在同一時刻，施展帶有關鍵詞的圖騰時，你只能使用每種圖騰類型中的一種。例如，你可以立刻施放4種圖騰；地系圖騰，火系圖騰，水系圖騰以及氣系圖騰各一個。如果你施放了一個火系圖騰，那麼再施放一個其它的火系圖騰將會取消掉第一個。</li>
</ul>

**派系選擇**：你再習得薩滿祭司時，必須在路線中選擇一條，不得變更。

**威力值**：6

**價格**：B+3000

**動作**：標準

**能耗**：5

**成分**：語言，姿勢

**射程**：智力值\*10米

**目標**：X個自願目標

**範圍**：無

**持續**：威力值/輪

**描述**：恢復系薩滿的奧義！靈魂的相連一榮共榮一損同損！

**效果**

<ul>
<li>雖然名爲圖騰，但是本能力並非圖騰能力。</li>
<li>你選擇所有處於你射程範圍內符合要求的目標，你將所有目標的靈魂鏈接起來。</li>
<li>鏈接起來之後，當其中一個目標受到傷害時，將傷害平分爲X份，每個目標受到不可避免的對應傷害。如果無法平分，則多出來的部分由直接受到該傷害的目標承擔。</li>
<li>X爲神祕學等級帶來個附加成功數。</li>
</ul>
