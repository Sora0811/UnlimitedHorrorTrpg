# 拔刀師

> 來源：`資源/稱號/戰士類/拔刀師`

**本質**：自然本質

**前提**：需求白刃技能 3 ，

**描述**

<ul>
<li>出劍時似山崩地裂，收劍時如明鏡止水。電光火石間所展現的正是劍之極藝。</li>
<li>所謂的拔刀術是一種非常特殊的劍技，它的特點是劍不出鞘，在拔刀的那一剎那瞬間集中力道，將全部的精、氣、神納入一擊之中。</li>
<li>拔刀師即是醉心與此道的一羣人，他們從自然間領悟天地至理，不動則已，一動，則必以風林火山之勢瞬間斬殺敵人。</li>
</ul>

**特殊**：如無特殊說明，本稱號（包括技能樹）所提及的“武器”僅指細長且體積不大於人物自身體積 -2 點的曲刃劍（如武士刀、脅差、軍刀、馬刀、阿拉伯彎刀等，具體由 ST 裁定），不包括不符合該條件的武器在內，同時只有在持用符合該條件的武器時，本稱號下的特性與技能才能夠起效。

## D 級　浪客

**能量池**：無

**特性**：居合（雙特性），縮地（雙特性），先發

**技能樹**：開啓 D 級拔刀師技能樹與專屬物品購買權

**特殊**：由於沒有能量池，額外獲得 1 個特性。

**描述**

<ul>
<li>所謂居合，更通俗的說法就是拔刀術，也就是揮刀斬人的技術。當拔劍出鞘的瞬間，它的速度和威力都是無法想象的。</li>
<li>同時，準確而快速地站在最佳位置出手是拔刀師最重要也是最基本的能力。</li>
</ul>

**其他標籤**

**居合**

<ul>
<li>只有在你沒有持用、攜帶盾牌並且沒有身穿任何盔甲時本特性才能夠生效。</li>
<li>你能夠無須任何動作便拔出一把收於刀鞘內的武器，但這必須結合在一次近戰白刃攻擊中，若你這麼做，則你該次近戰白刃攻擊必須使用你拔出的武器進行攻擊，並且這次近戰白刃攻擊可以攀附其他招式或能力，這稱之爲一次“拔刀術攻擊”。注意，如果你沒有任何收於刀鞘內的武器，你將無法發動“拔刀術攻擊”。</li>
<li>你在“拔刀術攻擊”中獲得等同於你傳奇力量與傳奇敏捷取高的速度加值。當你掌握“拔刀術”後，你在“拔刀術檢定”上也可以獲得等額的速度加值。</li>
</ul>

**縮地**：每輪一次，在你進行一次“拔刀術攻擊”之前或之後，你可以花費 1 個自由動作移動最多不超過你白刃技能等級 \*1 米。此外，你的基礎陸行速度增加 10 米。

**先發**：你的先攻增加 3 點。


## C 級　劍豪

**特性**：先發，洞明（雙特性），殺意感知

**技能樹**：開啓 C 級拔刀師技能樹

**描述**：拔刀師擅長於通過冷靜地觀察來尋找出敵人的弱點，或者是攻擊軌跡的預測，又或者是極爲微小的破綻。

**其他標籤**

**先發**：你的先攻增加 6 點。

**洞明**：每次你進行先攻檢定後，你可以選擇自身敏感範圍內不超過你傳奇智力 +1 個目標，這無須動作，之後僅針對你選定的目標，你在近戰白刃攻擊檢定與防禦上分別獲得等同於你傳奇智力與傳奇感知之和的洞察加值，持續一個場景。每輪一次，你可以花費一個迅捷動作重新選定一次目標。

**殺意感知**：你獲得相當於你敏感範圍的盲感。


## B 級　劍聖

**特性**：守勢（雙特性），氣合斬，拔刀精通

**技能樹**：開啓 B 級拔刀師技能樹

**描述**：拔刀師的出手速度已經達到了心動即身動的境界。同時，正因爲居合的要義全在出鞘後的第一斬之上，所以不能隨意的發動攻擊，因此在進攻之前的防禦也是被拔刀師們所看重的。

**其他標籤**

**守勢**：你能夠以一個自由動作將任意把武器收入刀鞘，當你將武器收入刀鞘時，你在防禦上獲得等同於你傳奇智力的附加成功以及等同於你白刃技能等級的閃避加值。

**氣合斬**：若你已掌握“拔刀術”，則你可以將“拔刀術檢定”的成功數計入“拔刀術攻擊”的傷害上限中。

**拔刀精通**：當你使用拔刀術攻擊時，忽略相當於你傳奇風度的傷害減免或者傷害吸收。


## A 級　免許皆傳

**特性**：連殺（雙特性），提升 - 氣合斬，不屈無畏

**技能樹**：開啓 A 級拔刀師技能樹

**描述**：拔刀師已經達到能夠利用拔刀的慣性完成連續的連斬的境界。

**其他標籤**

**連殺**

<ul>
<li>當你使用“拔刀術攻擊”擊殺敵方單位後，你可以立刻將該武器收入刀鞘並對你觸及範圍內的其他敵方單位進行一次“拔刀術攻擊”，該次攻擊無須動作，可無限次觸發。若你一次攻擊擊殺了多名敵人，也只能連擊一次。</li>
<li>你每用“拔刀術攻擊”殺死一名敵方單位，你便能在“拔刀術攻擊”中額外獲得 1 個附加成功，並使“拔刀術攻擊”的傷害上限提升 1 點，以此獲得的附加成功與傷害上限在切換場景後會自動清零。</li>
<li>提升 - 氣合斬：若你已掌握“拔刀術”，則現在你在進行“拔刀術檢定”時可以將白刃技能加入檢定中（即原本以風度值爲拔刀術檢定 DP 的改爲風度 + 白刃檢定，以決心值爲拔刀術檢定 DP 的改爲決心 + 白刃檢定）。</li>
</ul>

**不屈無畏**

<ul>
<li>你增加相當於你風度值的閃避防禦。</li>
