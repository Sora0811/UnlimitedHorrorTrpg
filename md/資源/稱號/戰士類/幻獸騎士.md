# 幻獸盔甲

> 來源：`資源/稱號/戰士類/幻獸騎士`

**稱號**：幻獸騎士

**介紹**：與擁有超自然力量的生命定下契約，藉助它們的力量而戰。 你可乘騎着飛龍與獅鷲，藉助它們的力量獲得昇華，從而超越凡俗。 請注意，一個已經簽訂了契約的生物無法同時簽訂其他契約，例如剛達爾夫之契、英靈契約等；同時，你也無法與無法長期存在於你身邊的生物（比如召喚生物）簽訂此契約。成爲某個人契約夥伴的生物，無法強化此能力。

**前提**

<ul>
<li>操控 3+ ，技能：動物溝通 3+ ，駕駛 3+</li>
<li>D 級：學徒 幻獸契約： 你可以和某個生物載具定下契約，之後你們精神和生命鏈接在了一起，榮辱共存。在下文中，與你簽訂契約的生物坐騎被稱爲你的契約夥伴。</li>
<li>你可以簽訂契約的對象上限數量同等於你的動物溝通等級上的附加成功。 建立契約後，你可以得到如下好處： 坐騎的智力值因此會得到提高，原本爲空屬性的坐騎載具現在會提高到 1 。這意味着只要你下令，它就可以使用它獨立的動作進行戰鬥。他可以由你操控，進行作戰，並且他的先攻你可以在投擲時選擇其單獨結算，還是與你的先攻相同。 只要你與至少一個對象簽訂了契約，你就可以學習不超過你稱號等級的、技能樹中的技能。</li>
</ul>

**技能樹**：強力衝鋒

**價格**

<ul>
<li>D+500</li>
<li>C+1000</li>
<li>C+2000 描述將你的體內依附的契約夥伴化爲武器，你獲得了最強的裝備。</li>
</ul>

**描述**

<ul>
<li>更大體型意味着更強衝擊力，披着全身盔甲的騎士，可以撞開地獄的大門。</li>
<li>你的契約夥伴可以對你進行援助，使你避開某些危機。</li>
</ul>

**效果**

<ul>
<li>你在乘騎着坐騎進行衝鋒時，可以同時選擇造成傷害和進行衝撞。 此次衝撞判定中，坐騎依舊使用力量 + 肉搏進行判定，你自身則是以力量 + 白刃進行衝撞判定，結果兩次衝撞中較高者。 同時，在這次衝撞檢定中，你和你的坐騎可以獲得等同於本稱號等級（ D1~A4 ）的技藝加值。 提振精神</li>
<li>在你進行一次豁免後，如果你對這次檢定的結果不滿，你可以以一個反射動作選擇一個附身於你體內的契約夥伴，以其本身的屬性代替你再次進行這次豁免檢定。 你必須接受第二次豁免檢定的結果，即使它比第一次檢定更低。 每次長休息前，你體內依附的每個生物載具只能代替你進行一次判定。 幻獸武器</li>
</ul>

**分類**：見下

**價格**：D+500

## 幻獸盔甲

**價格**：C+2000

**描述**：描述將你的體內依附的契約夥伴化爲盔甲，你獲得了最強的裝備。 輕甲：你可以選擇獲得輕甲，則獲得 2/2 盔甲防禦。

**價格**：C+2000

**其他標籤**

**重甲**：你可以選擇獲得重甲，則獲得 3/3 盔甲防禦，以及 1 點盔甲防禦減值。

**盔甲化**：你的盔甲防禦增加相當於契約夥伴的天生防禦，並且獲得對應的效果如【防彈】【防能量武器】【傷害減免】【傷害吸收】【能量抗力】等。同時，契約夥伴每有 1 級支線等級，則重甲獲得 2 點法術抗力（ D1,C2,B3,A4,S5 ）


**其他標籤**

**精通騎士衝鋒**

<ul>
<li>當你駕馭和你的契約夥伴處於騎乘狀態，然後進行衝鋒時，坐騎衝鋒帶來的好處會和你進行共享，但是同時扣除防禦，你能獲得的衝鋒 DP 上限不變。由於你和坐騎並非共同行動，則坐騎帶給你的衝鋒加值，在你輪時，你必須先以一個標準動作進行一次普通攻擊來使用，否則失去該加值。 C 級：騎士 提升幻獸契約（ C 級）： 你可以簽訂契約的對象上限再次得到增加，其數量同等於你操控附加成功與馴獸附加成功之和。 你和你契約夥伴之間的羈絆比原本更加深刻，只要你自身還未死去，和你簽訂契約的生物載具便不會徹底死亡。 被殺以後，它們會以惡性傷害槽被填滿狀態，變成靈體依附於你的體內，處於這種狀態的生物載具無法被召喚，你也無法藉助它們任何能力，直到它們通過自然恢復所有生命值 ―― 你無法以復活以外的任何能力加速這個過程。 你的思維與生物載具共享，你可以無需繁複指令和訓練就能直接指揮它作戰。這效果被視爲一種精神鏈接，只要在同一個世界便可生效。 你可以使和你簽訂契約生物載具化身爲靈體附身在你的體內，在你需要時候再進行召喚，此時進行召喚 / 附身需要一個整輪動作。</li>
<li>此外，你簽訂契約生物載具會得到同等於自身基礎速度的飛行能力，機動性普通。</li>
</ul>

**冷兵器**：你可以選擇一種基礎近戰冷兵器模板，本武器獲得對應的全部效果。

**契約召喚**：你可以用整輪動作召喚依附於你體內的契約夥伴化爲武器或是盔甲，契約夥伴可以長期維持這種狀態，這種能力會佔據相應裝備位。 武器化：該武器的“武器基本屬性”中的武器傷害，破甲，破魔，高速，觸及，加骰等效果以及“武器特殊屬性”和“特性”全部獲得該契約夥伴天生武器的效果。
