# 港漫強者

> 來源：`資源/稱號/戰士類/港漫強者`

**本質**：特異本質

**前提**：肉搏技能等級3以上、白刃技能等級3以上，運動技能等級3以上，威嚇技能等級1以上，並且在白刃技能以及肉搏技能上擁有一個專業，習得一種D級以上的能力，該技能必須要求以內力、氣、鬥氣、龍氣、劍氣、電磁力之一進行推動。

**描述**

<ul>
<li>在港漫當中，永遠活躍着那麼一羣人：</li>
<li>他們擁有常人無法企及的力量，思考模式更是有着區別的差異；他們從來不會估計尋常人等的眼光，只有足夠“強”的生物才能獲得他們的認同；戰鬥對於他們來說就如呼吸一般重要，將強大的對手轟敗便讓他們感到無上喜悅；他們遇強則強，就算老天爺擋在他們面前，他們也只會用一雙鐵拳悍・然・逆・天。</li>
<li>――這羣傢伙或許有着各式各樣的綽號與異名。</li>
<li>但如果要用一個詞語來概括這類人，那麼便是――強者！</li>
<li>雖然港漫裏強者的力量來源稀奇古怪，從古武乃至生化病毒，不過發展到最後都會莫名其妙的演變成武學招式對轟。</li>
</ul>

## D 級　初武・萬里長城平地起

**價格**：D+1000

**能量池**：無

**特性**：強者威嚴（雙特性），武者之心，超凡入聖（雙特性）

**技能樹**：開啓D級港漫強者技能樹

**特殊**：由於沒有能量池，額外獲得一個特性

**描述**：如果要找個參照物的話，這個水準的你，只比現實世界的武術大師們略強一點。在任何武俠世界裏都屬於雜兵之流。

**價格**：D+1000

**其他標籤**

**強者威嚴**：你的脅迫等級提升一級（最高到4），你可以自由控制威嚇（力量/風度+脅迫）的幅度，這意味着你在威嚇中可以進行留手規則。並且，現在你的威嚇是一種自由的流露，這並不是你對別人進行了威嚇，而是強者氣勢所帶來的效果，所以不會因威嚇失敗帶來負面效果。

**武者之心**

<ul>
<li>不屈！不泣！不退！不悔！不降！不敗！身爲一名武者，你必須要有身爲強者的自信和自傲。如果前面是山，便轟穿那山；如果前面是海，就焚盡那海；如果前面是天，那・便・逆・天！你的意志值獲得增加，數值爲稱號的等級（D1～A4）。</li>
<li>但同時，你不可以做出以下有辱你武者身份的行爲。</li>
<li>・在一場對你發起的挑戰中逃離或投降（意外狀況中斷不算，另外你也可以拒絕挑戰――只要理由ST認可）</li>
<li>・在一對一的對決中主動投降或逃離（切磋或者交流練手不算，和對手有着絕對實力差距的也不算――那叫找死）</li>
<li>・面對你應對範圍內的困境或是挑戰，選擇逃避。</li>
<li>如果你違反了以上中的任何一條，你都會喪失掉武者之心帶來的一切好處（包括後面XX之心繫列）。只有達成以下條件，則會恢復“武者之心”帶來的一切好處（包括後面XX之心繫列）。</li>
<li>・擊敗向你發起挑戰的傢伙。如果目標已經不在，必須擊敗一名和他同一水準的強者。</li>
<li>・找到那名敵人，在一對一的戰鬥中擊敗他――就算對方要羣毆你，你也只能靠自己來迎戰。</li>
<li>・主動去迎接相同或者類似的挑戰與困境，並且通過</li>
</ul>

**超凡入聖**：身爲一名靠身體喫飯的武力測人士，強悍的肉體是一切的根本。在運行在你體內的能量和每日的鍛鍊緩慢的強化着你的肉體。你的天生防禦和天生武器傷害獲得了稱號等級（D1～A4）的永久提升，你現在的天生武器可以造成嚴重傷害。


### 加持

**價格**：D+500

**動作**：移動動作

**能耗**：見下

**射程**：無

**目標**：自身

**範圍**：無

**持續**：見下

**描述**：內功有成的武者，即使是隨處可見的飛花落葉在他們手中也會變成可怕的兇器，這是因爲他們將自己的能量加持在物體上，暫時性的改變其性質。通過這種技巧的加持，薄軟的紙張能夠斬肉切骨，輕薄的布匹可以抵擋掃射的子彈！

**效果**

<ul>
<li>你學會使用體內運行的能量強化你接觸到的武器\\天生武器/物體。</li>
<li>每消耗1點能量，你的天生武器或者手持的武器，其武器傷害提升1點。</li>
<li>每消耗1點能量，你的天生防禦或者穿着盔甲的盔甲防禦，提升1點。</li>
<li>在加持的持續時間內，被加持的物體暫時視爲本稱號等級的物品，在面對【摧毀XX等級之下的物品/XX等級之下的防具無效】時，獲得相應的抗力。</li>
<li>你同時最多消耗相當於你傳奇耐力/點能量。</li>
<li>本能力最多持續你消耗的能量/輪。</li>
</ul>

**特殊**：當本稱號到達C級時，兩種增幅方式分別計算消耗的能量上限。

**增幅**

<ul>
<li>當本稱號到達B級時，當加持天生武器或者手持的武器時，其還會等額提升破甲值。</li>
<li>當本稱號到達A級時，若加持的武器或者盔甲消耗的能量大於其體積，則該武器或者盔甲獲得【神兵】特性。</li>
</ul>

**價格**：D+500

### 催谷

**價格**：D+500

**動作**：迅捷動作

**射程**：無

**目標**：自身

**範圍**：無

**持續**：立即

**描述**：寧死不屈，百戰不撓――哪怕身體已經油燈枯盡，你也可以燃燒生命力來出招。

**效果**

<ul>
<li>你可以通過催谷承受任意數量的傷害，壓榨出生理系的能量。</li>
<li>你可以選擇暫時降低自己1點生命值上限（優先降低生命值最好的生命值）。</li>
<li>若降低的上限爲完好生命值，則回覆該能量池4點能量。</li>
<li>若降低的上限爲衝擊傷害，則回覆該能量池2點能量。</li>
<li>若降低的上限爲衝擊傷害，則回覆該能量池1點能量。</li>
<li>若降低的上限爲惡性傷害，每2點則回覆該能量池1點能量。</li>
<li>使用此法一次只能恢復一個能量池，你可以選擇對自己造成多種傷害，來恢復能量。</li>
<li>如你擁有內力和氣，你一次只能選擇恢復內力或者氣。</li>
<li>如你可以對自己造成1點衝擊傷害，1點嚴重傷害，來恢復3點能量。</li>
<li>降低的生命值上限可以通過一個8小時的長休息恢復。</li>
</ul>

**價格**：D+500
