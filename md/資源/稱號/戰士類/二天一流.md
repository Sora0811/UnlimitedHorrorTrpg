# 二天一流

> 來源：`資源/稱號/戰士類/二天一流`

**稱號**：二天一流 江戶初期著名劍士新免武蔵藤原玄信（宮本武藏）晩年在熊本縣創立的劍術理念。 他在著作《五輪書》中對這一理念進行了闡述。宮本武蔵的父親新免無二（宮本無二之助藤原一真·宮本無二斎藤原一真）隸屬於包含實手、二刀流等技法的當理流。 宮本武藏將其發展，並將其命名爲円（ yuan, 二聲，古同“圓”）明流。 晩年捨棄了一刀、二刀、實手等多種形式，歸納爲右手握太刀、左手握小太刀的兩刀法，面向五個方向。 並將這一劍術理念寫入了《五輪書》中。《五輪書》中對這一流派有二刀一流、二天一流兩種稱法。最終定型爲二天一流。 二天一流中所謂“二天”就是指“二天曬日”（“曬”同“曬”，《五方之太刀道序》）之意，指的是太陽和月亮：即陰與陽，也就是象徵對立的事物。世界一切都是由相對事物組成，由這些相對事物相互浸透而使所有事物發展統一，產生新的事物。二刀的技法簡單的講就是統一左右兩手手上大小二刀的動作，由此達到戰勝對手這一目的。 特殊的，本稱號下不同等級帶來的洞察加值可以互相疊加。 D 級 懸待一致

**需求**：右手持握長劍 / 彎刀 / 重劍、左手握突刺劍 / 短劍，需求白刃技能 3 。

<ul>

## C 級　C+1000

**正文**

四戒 劍道最禁忌的心病有四。就是恐、懼、疑、惑。 比賽中如有這四種心情發生，精神就無法統一，動作無法快如閃電，縱然發現對方有虛隙亦無法如意攻打。 例如看到對方身體強壯而恐慌緊張就是恐。 看到對方技術高強而懼怕不安，就是懼。對方的竹刀一動就猜疑是否要攻曲“面”，這是疑。 看到對方右手有虛隙可攻，但又覺得好像是故意設陷阱就是惑。 因爲劍道可以進攻的機會是一瞬即消失。如果心理稍生動搖，該千載一遇的進攻機會就無法抓住。這四種心病可以說是進攻的最大障礙。 被動 - 進行這戒律的修行，會讓你變得更加的敏銳，你在進行感知屬性相關檢定時，獲得 +4DP 洞察加值的有利。 你可以使用一個標準動作啓用，進入這無我狀態，這會使效果非常顯著，你因此獲得免疫 B 級作用於心靈的異常狀態，持續一個場景。 逆輪 手持雙刀輪圓，左曲、右回，這是受到攻擊後的二連擊反擊技巧。 使用標準動作，指定一個本輪中對你攻擊過的目標（如果你夠得着該目標的話…），你並不退縮反而藉着他攻擊的勢頭和運動軌跡發動更具侵略性的二連擊！ 你對目標的這次攻擊視爲已經攻擊過 1 次，並在攻擊上有 +6dp 的技藝加值。 若對方進行了格擋或全防禦，你造成的傷害數還會使其失去相同數值的格擋點數和全防禦點數（指其因此獲得的閃避加值），持續一輪。 若其格擋點數或全防禦點數被削減至 0 ，則其在這一輪失去格擋效果或全防禦效果。 雙重扇形斬 左手握着短劍 / 小太刀向上挑起瓦解敵人的防禦，並依靠全身迴旋所帶來的慣性跟重量全部灌注入右手的長劍 / 太刀上，由左上往下砍去。 全回合動作發動，你以白刃攻擊檢定進行虛招檢定，若你成功，則你立即對目標發動一次白刃攻擊，你對目標的這次攻擊視爲已經攻擊過 1 次。 你進行的這次攻擊在攻擊上有 +3dp 的技藝加值。這次攻擊發生後，你在防禦上有 +2 洞察加值，這持續一個場景，此效果可以與其他洞察防禦疊加，但是不得與本技能帶來的洞察防禦疊加。

## B 級　B+2000

**正文**

先先之先 因雙方都有先攻的意念。察知對方有搶先進攻的意念，吾制其先。搶先一步進攻的機會，謂先先之先。此時對方的先攻動作尚未表露，而吾制先搶攻。所以須預先察知對方的意念，屬高度技巧。 宮本武藏的遺著“兵法三十五條”中稱之爲“我懸敵之先”。經多年的練習，自然由對方的動態可以察知其搶先的意念。人的大腦如決定要作進攻隨即通知雙手舉劍，右腳踏出，作進攻動作。 在此瞬間如受攻擊，大腦甚難立即變更命令，再通知手腳改作防禦動作。所以對方有進攻的意識而開始動作的發招前一剎那，因其心理、生理解剖學上無法及時做出防禦反應動作，屬一種虛隙，自然爲吾方攻打的絕佳機會。如躍入擊面法屬此。 使用標準動作，你以感知 + 白刃進行檢定，目標以智力 + 掩飾 / 隱藏進行對抗，若你勝出，則你立即對目標進行一次白刃攻擊。同時目標進入措手不及，持續 1 輪，在計算等級時，本措手不及視爲 B 級的措手不及 你的這次攻擊有 +6dp 技藝加值的有利。這次攻擊發生後，你在防禦上獲得 +5 洞察加值，持續一個場景，此效果可以與其他洞察防禦疊加，但是不得與本技能帶來的洞察防禦疊加。

先之先 吾尚無先攻的意念，對方制先發招。而待其竹刀快要擊中尚未擊中之前，吾隨即發生進攻的意念，而反攻制勝的機會。宮本武藏的遺著“兵法三十五條”稱之爲“敵懸來時之先”。此時對方的攻擊動作正在進行中，生理解剖學上甚難變更動作，而對吾方的突發攻擊作防禦。所以此時亦爲絕佳的攻擊機會。例如“撥胴”等屬此。 當有目標在向你的觸及範圍內進行攻擊時，使用反射動作，消耗 2 點意志，你可以在其攻擊前使用普通白刃攻擊（不帶技能）先斬一刀。若其因此而死亡，則其攻擊動作自動失效。

後之先 對方搶先攻進來時，吾方將其竹刀折上、撥開、迎託、掃開等，以因應刀法制勝的機會謂後之先。宮本武藏遺著“兵法三十五條”稱之爲“我懸敵懸時之先”。此時不無漏接敵刀之可能，所以需要沉着的膽量及高度的技巧，爲高段劍士所用的招式。 斬子彈、斬火球、斬激光，都不在話下！ 被動 - 你的移動速度增加稱號等級 /10 米。 使用整輪動作，存儲你的這次攻擊機會，在你指定的敵人（必須提前聲明）發動攻擊時，在你能移動到的地方，移動過去對任意需要視覺線才能產生效果的單體攻擊嘗試阻斷，如果你實力足夠強，甚至能讓敵人的這次攻擊消弭於無形。 骰你的攻擊骰與對方的攻擊骰相對抗，若你勝出，則對方的這次攻擊失效。 如果你無法取得勝出點數，那麼對方在攻擊 DP 上會失去相當於你成功數的成功數，再對其原本攻擊的目標正常計算 DP 數。 該敵人並未攻擊（這包括其攻擊線路不在你的移動範圍內），則你白白浪費這一輪。 有效時間爲一輪。
