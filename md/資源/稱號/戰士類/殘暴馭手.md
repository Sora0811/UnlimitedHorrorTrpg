# 稱號 殘暴馭手

> 來源：`資源/稱號/戰士類/殘暴馭手`

## D 級

**注**

<ul>
<li>狂暴馭手在購買本稱號的同時，選擇一個騎獸作爲自己的坐騎。若該坐騎死亡，則下一次購買的騎獸自動變爲自己的坐騎。所有狂暴馭手的效果都僅僅與自身的坐騎生效。</li>
<li>D 級技能樹： D+500</li>
</ul>

**其他標籤**

**兇殘坐騎**：殘暴馭手的坐騎比一般的坐騎更高大威猛，坐騎體積增加 1 點，力量獲得 2 點加值，但是敏捷獲得 2 點減值。如果敏捷無法繼續下降（已經到 1 ），那麼力量也無法繼續提升。這個能力同一時間只能影響一個目標。由殘暴馭手自身指定。

**踐踏**：你在坐騎上移動時（包括衝鋒或任何使自身發生位置移動的的狀態），可以使用坐騎以迅捷動作越過一個目標，以你坐騎的力量對抗對方的敏捷或力量。較大的一方會獲得等於體型差的加值。如果你成功，則你將越過目標後，並且目標會被你的坐騎撞倒，同時你的坐騎可以馬上使用標準動作對其進行一次蹄擊，因爲對方倒地，所以這次攻擊會有 +2 的加值。若你擁有專長――騎乘戰鬥 4 的專長時，則動作下降爲自由動作，並且每回合穿越的次數變爲 D1-A4 人。


**正文**

你在坐騎上使用長柄武器或者雙手武器時，獲得等於稱號等級的的環境加值。

同時該武器的力量需求降低 1 點。

你的坐騎增加等於你稱號等級的天生防禦。並且獲得【防彈】特性，當你的稱號到達 B 級時再獲得【防能量武器】特性。

你的左手出現了一個封印，這個封印代表了你與你坐騎鏈接在一起的決心！

你或者你的坐騎現在獲得任何臨時性質的增益效果時，另一個共享這些增益效果。如同圓桌騎士的神賜坐騎一般，但是這個效果是雙向的。

一般而言，這些BUFF都不能是以自身爲目標的，比如戰鬥之歌，狼人變身。

一般而言，這些BUFF都是臨時性質的，若持續時間爲一場景或者一場恐怖片，甚至N/A，雖然他們也有持續時間，但是並不視爲臨時效果。

一般而言，若你由於開啓了某種能力臨時獲得了某些加值，或者能力，這些也無法共享。如：基因鎖。

一般而言，修行加值，內在加值，器械加值，無法疊加。這包括裝備，毒品，稱號，血統等增幅效果無法共享。

一般而言，這些BUFF都不能是以目標有限制的，比如召喚物專用等。

你與你的坐騎針對同一個效果無法重複計算。例：你獲得了5點屬性，然後你的坐騎由於你獲得了5點屬性而獲得了1點屬性，這是一個臨時的效果，但是這1點屬性你不會再次獲得。

同時你與你的坐騎之間建立 B 級心靈鏈接，感官爲視覺。

並且你現在可以將你的坐騎存放在封印中，封印中自動提供給充足的水和食物，以及自動清理糞便。你可以以一個整輪動作呼喚你的坐騎現身，將坐騎再次放回封印也是一個整輪動作。

針對你的坐騎，你在每個屬性上的每點附加成功，則可以對應你的坐騎在該屬性上獲得 1 點屬性加值。

你現在讓坐騎進行衝鋒攻擊時，你不會損失防禦，並且坐騎扣掉的防禦如常增加你和坐騎的下一次攻擊檢定上。這是一個被動能力。

你現在若穿戴盔甲或者盾牌，則其爲你的坐騎等額提供盔甲防禦加值以及盾牌防禦加值。並且若你的盔甲或者盾牌正在爲你提供傷害減免或者傷害吸收以及能量抗力的能力，你的坐騎也獲得這些能力。

### C

**其他標籤**

**橫衝直撞**：你在進行闖越時，對方需以力量 / 敏捷取低進行對抗檢定，且若其擁有任何回合外移動的能力也不可發動來避開你的闖越。同時，你的坐騎在進行攻擊或者使用特殊能力進行判定時（就算並不是進行闖越）獲得 3DP 和 1 個自動成功。


### C 級技能樹： C+1000

**其他標籤**

**一鼓作氣**：每當你在坐騎上攻擊目標時，若你或你的坐騎成功命中，則你和你的坐騎在針對該目標的攻擊檢定上獲得 +1DP 士氣加值。每次命中這一目標時，加值都會疊加，上限爲你的決心值，持續一個場景。

**二連擊**：當你與你的坐騎在本回合攻擊同一個目標時，第二次攻擊時，目標的防禦獲得第一下攻擊傷害數的減值。若坐騎或你擁有多次攻擊能力，則計算防禦減值時只計算第一次攻擊中造成傷害最高的一次。


### B

**其他標籤**

**殘暴面容**：殘暴馭手在騎乘時便能散播恐懼。只要殘暴馭手處在騎乘狀態下，所有看到他的敵人就會在對抗恐懼時承受他風度一半的罰值。

**恐懼馭手**

<ul>
<li>每輪一次，以一個自由動作，殘暴馭手可以進行一個威嚇檢定來挫敗他在騎乘中踐踏過的目標。給對方造成勝出點的戰慄點數。可以累積爲驚懼。</li>
<li>B 級技能樹： B+2000</li>
</ul>


### A

**其他標籤**

**致命橫行**：殘暴馭手的坐騎在闖越後蹄擊一個生物之後後，殘暴馭手可以馬上對該目標再進行一次單獨的近戰攻擊。

**恐怖**

<ul>
<li>殘暴馭手以一個標準動作策動坐騎後腿直立，向他的敵人宣告恐怖的到來。所有看到殘暴馭手的敵人必須進行一次意志豁免。以意志對抗殘暴馭手的風度 + 威嚇。這次對抗中，殘暴馭手可以加上其坐騎的風度的一半，並且敵人受到 B 級的減值。如果敵人失敗，會立刻進入驚懼。進入驚懼狀態的敵人會停止動作，全力遠離殘暴馭手，持續 3 輪。如果在 3 輪中受到殘暴馭手以外的攻擊，驚懼狀態立刻終止，會反擊攻擊者。成功通過豁免的生物在一個場景內免疫這項能力。這個能力無法被其他效果免疫。</li>
<li>A 級技能樹： A+4000</li>
</ul>


**正文**

殘暴馭手騎乘一隻野獸般的、僅有他才能駕馭的了的坐騎。他將敵人踐踏在腳下，在蹄印後留下扭曲的肢體，所到之處，恐懼橫行。殘暴馭手是爲騎手所準備的稱號，對於部分特殊的形態（比如人馬）無法使用。
