# 死神稱號（ 來源：BLEACH ）

> 來源：`資源/稱號/戰士類/死神稱號`

**本質**：魔幻本質

**作者**：赤鳴

**描述**：死神通常在現世及屍魂界中出現。作爲靈子濃度極高的生命體，死神擁有超過人類的能力，也可以與虛戰鬥。因爲身體內靈子濃度高，因此，死神同時是虛最喜愛的食物。死神肩負着保衛人類，引導及淨化“虛”、使之回到屍魂界的職責，維持兩邊世界的平衡，以免世界失穩而滅亡；並且是屍魂界的主宰。

**特性**：斬拳走鬼訓練（雙特性），靈絡，靈力技能

**描述**：真央靈術院是屍魂界的死神培育機構。由山本元柳斎重國在兩千年前所設立的培育未來鬼道衆、隱祕機動隊以及護廷十三隊的教育機構。授課從死神的基本戰鬥技藝“斬拳走鬼”四大技能的訓練到在現世的魂葬實習等等。課程雖然有6年，不過優秀學生可以在跳級在更短的時間內畢業。大門隨時敞開，就算是出身流魂街，只要通過考試就可以入學。事實上，流魂街出身的死神幾乎都是學院的畢業生。爲了獲得通往未來的福音，你也選擇加入了這座歷史悠久的學院，並朝着一名正式的死神而努力。

**價格**：D+1000

**其他標籤**

**斬拳走鬼**

<ul>
<li>這是死神四大戰技的總稱，也是真央靈術院學員的必修課程，是護廷十三隊成員所必須掌握的基本技能。</li>
<li>你從以下四項訓練中選擇一項並獲得之。</li>
</ul>

**斬**：“斬”即劍道，是指死神用刀攻擊敵人的技術。你的白刃技能提升1級，最高到5級；你的近戰白刃攻擊獲得相當於白刃技能等級帶來的附加成功/點高速。

**拳**：“拳”即白打，是指死神空手攻擊敵人的技術，其意義相當於肉搏。你的手和腿現在視爲武器傷害2L，具有【魔法】特性的天生武器。

**走**：“走”即瞬步，瞬步是快速瞬間移動身體的技能，能以對方看不到的速度移動到對方身邊或者更遠的地方，類似於瞬間移動的步法。每輪一次，你可以以迅捷動作進行一次移動，這次移動的距離不超過你的傳奇沉着\*3米。

**鬼**：你現在在攻擊不死生物，虛體和靈體生物時，會對目標造成傷害等額的恐懼點數，恐懼點數意志豁免，不可疊加。

**靈絡**：這是死神擁有的將靈氣視覺化來進行偵察的方法，受觀察的對象，靈氣會身邊具現化爲多條飄動的布絹。你獲得靈感視覺。

**靈力技能**：你現在可以使用和習得相當於你稱號等級的通用靈力技能。
