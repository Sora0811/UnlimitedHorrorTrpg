# 稱號 - 戰士

> 來源：`資源/稱號/戰士類/戰士`

## D 級

**能量池**：怒火

**技能樹**：開啓 D 級和 C 級防護戰技能樹， D 級戰士通用技能樹

**特性**：移動格擋，強力格擋，盾牌嫺熟（雙特性）

**描述**：防護戰士是最堅強的守衛，最可靠的堡壘，盾牌對他們來說既是安心的屏障，又是最強的武器。

**其他標籤**

**移動格擋**：防護戰在用移動動作進行白刃格擋時，可以以半速移動，但不能衝鋒，這視爲一個融合動作，不另外佔用動作。

**強力格擋**：防護戰進行格擋時額外獲得自己傳奇力量的格擋加值。

**盾牌嫺熟**：防護戰在白刃格擋時，他針對範圍傷害的豁免檢定也獲得相當於盾牌加值的掩蔽加值


**正文**

戰士需要選擇他的作戰風格，在獲得戰士訓練時，他必須在路線中選擇一條，不得變更。他所選擇的路線會影響到技能樹。

##  級　武器戰

**能量池**：怒火

**技能樹**：開啓 D 級和 C 級武器戰技能樹， D 級戰士通用技能樹

**特性**：武器大師（雙特性），精通衝鋒

**描述**：武器戰士是技巧的大師，是衝鋒的刺刀，他們的攻擊老練而兇狠，手武器的他們是敵人的噩夢。武器戰士的劣勢技能是狂暴。

**其他標籤**

**武器大師**：當一名武器戰士雙手握持一把近戰武器進行攻擊時，其獲得相當於武器體積一半的 DP 器械加值，並且武器傷害提升相當於稱號等級 / 點。

**精通衝鋒**：武器戰在衝鋒時可以忽略等同於稱號等級 \*2 的防禦減值。


##  級　狂暴戰

**能量池**：怒火

**技能樹**：開啓 D 級和 C 級狂暴戰技能樹， D 級戰士通用技能樹

**特性**：雙持武器（雙特性），狂野姿態（雙特性）

**描述**：狂暴戰士是狂野的兇徒，揮舞的兩件武器的他們在戰場上是死亡的旋風。狂暴戰士的劣勢技能是防護。

**其他標籤**

**雙持武器**：狂暴戰無視【雙手】特性，同時其雙武器戰鬥專長提升 1 級。

**狂野姿態**

<ul>
<li>狂暴戰以一個自由動作，指定視野範圍內的一個敵人成爲目標，該目標必須本場景內對戰士造成過傷害，或者戰士對該目標造成過傷害。之後，戰士對該目標的攻擊，防禦和對抗檢定獲得 3DP 士氣加值，成功殺死目標可以使人物額外獲得一點怒火。狂暴戰可以選擇放棄該目標，但宣佈放棄則會失去 1 點怒火。戰士同時只能與一個目標進入狂野姿態。</li>
<li>C 級：根據道路不同，戰士的能力會提升不同。</li>
</ul>


##  級　防護戰

**技能樹**：開啓 B 級防護戰技能樹， C 級戰士通用技能樹， D 級武器戰技能樹

**特性**：盾牌衝鋒，加強防護，超級格擋，身經百戰

**其他標籤**

**盾牌衝鋒**：防護戰處於格擋狀態下時，可以以“移動格擋”帶來的移動速度結合一個標準動作進行衝鋒攻擊。

**加強防護**：防護戰獲得相當於自身傳奇耐力 \*2 點的抵破甲。

**超級格擋**：防護戰在進行白刃格擋時，白刃技能上每有 1 點附加成功，則獲得 1 點防禦附加成功。

**身經百戰**：防護戰免疫多次攻擊減值。


##  級　武器戰

**技能樹**：開啓 B 級武器戰技能樹， C 級戰士通用技能樹， D 級狂暴戰技能樹

**特性**：超量武器（雙特性），全壘打，武器大師

**其他標籤**

**超量武器**：當你雙手握持一把近戰武器時，該武器自動獲得“重量級”武器改造效果，持續到你停止雙手握持爲止。若該武器已經有物品改造，則無法觸發本效果。

**全壘打**：武器戰士在全力攻擊時，在攻擊的同時可以進行一次衝撞對抗，若你成功，則目標受到差值的嚴重傷害。

**武器大師**：當戰士使用具有對應專業的武器進行攻擊時，本次攻擊額外獲得 3 點附加成功。


##  級　狂暴戰

**技能樹**：開啓 B 級狂暴戰技能樹， C 級戰士通用技能樹， D 級防護戰技能樹

**特性**：渴血狂怒，狂暴姿態（雙特性），撕裂傷口

**其他標籤**

**渴血狂怒**：當狂暴戰進行近戰攻擊時，若目標沒有完好生命值，則攻擊檢定獲得 12DP 增強加值。

**狂暴姿態**：針對目標，若目標處於你的模糊範圍內，你獲得盲感，並且你現在可以同時選擇最多不超過你傳奇感知的目標。

**撕裂傷口**

<ul>
<li>狂暴戰進行近戰攻擊併成功造成傷害時，可以選擇不造成傷害，而是造成等額的劇痛點數以及流血點數，分別進行強韌豁免。</li>
<li>戰士技能樹分爲三條路線：防護，武器，狂暴。</li>
<li>根據戰士的風格不同，學習技能需要的級別也不一樣</li>
<li>除此之外，所有路線的戰士都可以學習通用技能。</li>
</ul>

**正文**

天堂向左，戰士向右。就算敵人無可匹敵，就算我們寡不敵衆，我寧願死在衝鋒的路上！

法師躲在象牙塔裏發抖，牧師跪在懺悔室中禱告，只有我們！死戰到底！只因我們是戰士！只會戰鬥也只願戰鬥！

列盾！衝鋒！！

戰鬥在戰鬥中學會控制自己的憤怒定點爆發，憤怒越劇烈戰士越強大。

當獲得 D 級戰士稱號時，自動獲得“怒火”池。

怒火是一個特殊能量池。

該能量池沒有上限。

戰士可以通過以下方式獲得怒火（或 ST 判斷合理的方式）：

人物額外獲得惡德 - 憤怒，並且因爲憤怒惡德恢復意志力時，可以同時獲得一點怒火

人物進行一次攻擊併成功造成傷害，獲得一點怒火

人物擊殺一個敵人的時候，獲得一點怒火

人物被攻擊並受到傷害時，獲得一點怒火

（玩家不可通過刻意自殘或者對自身造成傷害的行爲獲得怒火）
