# 鬥破蒼穹

> 來源：`資源/稱號/戰士類/鬥破蒼穹`

**本質**：特異本質

**總描述**

<ul>
<li>鬥氣的世界，沒有花俏豔麗的魔法，有的，僅僅是繁衍到巔峯的鬥氣！</li>
<li>在這一階段，你的實力只有鬥之力一段，你每次循本稱號的修煉體系擴大自身的鬥氣容量時，都會讓你的實力上升一段，只有擴大八次併成爲鬥之力九段後，才能夠成爲鬥者。</li>
</ul>

**特殊**

<ul>
<li>購買本稱號前，你必須先支付3XP，這會使你開啓鬥氣池，但以此法開啓的鬥氣池不具備鬥氣的基本用法，若你已有鬥氣池，則無法也無須以此法支付3XP開啓鬥氣池。</li>
<li>隨後，你能夠以每2XP一點的價格購買鬥氣池能量上限，你最多隻能以此法購買8次鬥氣池能量上限，當你購買8次後，你的鬥氣池能量上限再提升5點，只有在以此法購買8次鬥氣池能量上限後，你才能夠兌換本稱號的D級。</li>
</ul>

**選開**：本稱號本質爲一種修煉體系，因此ST可以允許PC在影片內直接花費XP對本稱號主幹進行提升。

## D 級　鬥者

**價格**：D+1000

**能量池**：無

**技能樹**：開啓D級鬥破蒼穹技能樹

**特性**：鬥之力（四特性），鬥氣修煉

**特殊**：由於沒有能量池，額外獲得1個特性。

**描述**：現在你是名一星斗者了，你每次循本稱號的修煉體系加快自己速度時，都會讓你提升一星，在提升至九星斗者後，你便能夠晉升爲一名鬥師。

**價格**：D+1000

**其他標籤**

**鬥之力**：若你的鬥氣池未具備基本用法，則你現在可以使用鬥氣池的基本用法，若已具備基本用法，則你的鬥氣池能量上限增加2點。此外，只要你在一次攻擊中運用了鬥氣的基本用法，你在該次攻擊檢定上便獲得6DP修行加值。

**鬥氣修煉**

<ul>
<li>你能夠以每2XP三點的價格購買基礎移動速度，你最多隻能以此法購買8次基礎移動速度，當你購買8次後，你的基礎移動速度再提升3米。</li>
<li>在以此法購買8次基礎移動速度後，本級稱號更名爲“鬥師”，在這之後你才能夠兌換本稱號的下一級。</li>
<li>特殊的，當你可以兌換本稱號的下一級時，你能夠以每個特性數D+500的價格購買下一級稱號除“鬥氣修煉”以外的特性，若你這麼做，之後你能夠以補足差價的方式獲得完整的C級稱號。若你以此法購買本級稱號的高級特性，則本級稱號的名字也會發生變化，每購買1個高級特性，稱號名字就會提升3星。</li>
</ul>

**例子**：玩家李小曼購買D級鬥者稱號並完成8次鬥氣修煉後，能夠支付D+500購買本稱號C級的“鬥氣充盈”特性，從而使本級稱號名字改爲“三星斗師”，在一部影片後，她再支付DD+1000購買C級的“鬥氣護體”特性，則稱號更名爲“九星斗師”，之後她可以花費500分補足差價，將本稱號提升至C級的“大斗師”。
