# 兵聖

> 來源：`資源/稱號/戰士類/兵聖`

**本質**：特異本質

**前提**：白刃技能等級3以上

**總描述**

<ul>
<li>“哎，那江南棋聖先不提，今個兒我們就講講這兵聖。”</li>
<li>“有道是，月棍，年刀，一輩子槍，寶劍他隨身藏，而今江湖上，這練甚的都有。然而這就有這麼一個奇人，他是個什麼奇法呢？”</li>
<li>說書的悠悠的拿着扇子晃了一晃，遮在嘴前，等吊足了周圍人的胃口才繼續說。</li>
<li>“他呀，看上去和其他習武之人也沒多大區別，人送外號，兵聖。這個兵不是士卒的那個兵，乃是兵器的兵。”</li>
<li>“別人用熟的兵器，他轉手就奪過來，耍了幾下，眼見他就用熟了，嘿，還玩出花來了！”</li>
<li>“沒有人知道他從哪來，會用多少兵器，上回他奪了奪魂毒爪的雙爪，這不，前幾日的功夫他又打了江南棋聖！恁的是膽大包天！”</li>
<li>看熱鬧的人羣倒吸一口冷氣，議論紛紛。</li>
<li>“對了，他用的正是那無相身！且說那棋聖。。。。”</li>
</ul>

## D 級

**價格**：D+1000

**技能樹**：開啓D級兵聖技能樹

**特性**：百器皆通（四特性）、兵武庫

**特殊**：由於沒有能量池，額外獲得1個特性

**描述**

<ul>
<li>所有兵器在你手裏都是一樣的。 百器皆通：你在持有沒有專業的武器時，你可以使用該武器3輪後完全掌控並永久獲得這個武器所需要的的對應專業，當然，你仍需要滿足使用這個武器的要求才能使用它。</li>
<li>你的白刃提升1級，最多到5，並且你在使用白刃武器時其破甲和破魔獲得稱號等級的提升。</li>
<li>並且 你在進行肉搏攻擊時可以用白刃技能代替肉搏技能進行判定，不會受到無專業減值，並且造成揮砍/穿刺/鈍擊傷害中的一種。</li>
</ul>

**價格**：D+1000

**其他標籤**

**兵武庫**：可以將任何體積小於5的白刃武器視爲體積2攜帶並隱藏在身上，且只有原來十分之一的重量。當你需要時，可以用迅捷動作抽出武器。


### 縱躍

**價格**：D+500

**動作**：被動

**描述**：縱身一躍，瞬息百步，進可攻，退可守。

**效果**：你的移動可以用跳躍來代替，你的跳躍距離可以直接取你的移動速度，跳高則爲一半。

**研發**

<ul>
<li>你花費4XP，習得“合縱”。</li>
<li>此時，你可以在衝鋒的時候忽視低於你跳躍高度/10米的障礙物。</li>
<li>你花費8XP，習得“連橫”。</li>
<li>你可以在空中連踏數次以產生借力的效果，如果這樣做你可以再向上跳躍等同你跳高距離一半的距離，並且可以在衝鋒時變換方向，改變方向每次最多傳奇敏捷/次。</li>
<li>你花費13XP，習得“無形”。</li>
<li>繩繩兮不可名復歸於無物，是謂無狀之狀無象之象是謂忽恍。</li>
<li>你免疫墜落傷害。</li>
</ul>

**價格**：D+500

### 鬥勢

**價格**：D+500

**動作**：移動動作

**能耗**：1點意志力

**射程**：無

**目標**：自身

**範圍**：無

**持續**：一個場景

**描述**

<ul>
<li>在數年之前，一位兵聖看遍千山萬水之後，於天涯海角處留下了一道刻痕，而後他縱身一躍―――</li>
<li>世人只以爲他厭了塵世，他卻將身子一晃，衝向那黑暗未名之處，劃出道銀白的星河。</li>
</ul>

**效果**

<ul>
<li>鬥勢是一種精，氣，神的凝聚，會佔用防具概念武裝位，但它並不是概念武裝，而是可以被稱爲神魂的東西。</li>
<li>啓動後，你凝結鬥勢，所有生理屬性獲得2點增強加值。</li>
<li>並且你的鬥勢視爲擁有D級被偵查能力的影像，影像外形自行構造。（也就是說，除非你有高於D級的反偵查能力，否則其他單位可以直接通過你的鬥勢影像觀察到你。）</li>
<li>並且，當你被震懾時，你進行一個DC等於你自身意志值的意志豁免檢定，若你失敗，則鬥勢被擊破，原本的震懾時間\*10，並且之後24小時內無法再次凝結鬥勢。</li>
</ul>

**價格**：D+500

## C 級

**價格**：C+2000

**技能樹**：開啓C級兵聖技能樹 特性：武器精通（雙特性），破招，武學表現

**價格**：C+2000

**其他標籤**

**武器精通**：你使用任何白刃武器都視爲已經擁有對應專業和最低技能等級要求，並且其武器傷害增加你的白刃等級帶來的附加成功數，同時獲得【格擋】特性。

**破招**

<ul>
<li>兵聖實際上更擅長破除對手的招式。</li>
<li>當你進行一次單體的攻擊檢定時，若目標進行格擋，則你可以立即消耗一點意志力對其進行一次智力+白刃/肉搏檢定，DC爲目標的格擋防禦，若你成功，則你可以宣言下一次攻擊是破招，那麼你對其進行的本次攻擊，目標陷入相當於兵聖稱號等級的措手不及。</li>
</ul>

**武學表現**：兵聖在攻擊時獲得合乎當前場景的武俠式視覺效果，並且攻擊檢定獲得6DP表現加值。

### 無相身（身法）

**價格**：B+2000

**前提**：縱躍・無形

**動作**：移動動作

**能耗**：3點意志力

**射程**：無

**目標**：自身

**範圍**：無

**持續**：傳奇敏捷/輪

**描述**

<ul>
<li>所謂色相、聲相、香相、味相、觸相、生住壞相、男相、女相，是名十相，無如是相，故名無相。</li>
<li>兵聖的起源是護法武僧，最初善用棍杖因此後來也多善用長兵器，而小無相身則是由一位迴歸佛教的兵聖在看了金剛經“凡所有相，皆是虛妄。若見諸相非相，即見如來”後悟道之作，雖然在外人看來是一種古怪異常的步法，但實際上，它遵循的是一種無相之相，不讓心滯留在聲音，感知和任何事物上。</li>
<li>你的移動在他人看來完全沒有規律，和世間萬物皆無相似之處，你如同清晨的雲霧般透明，如同水底的游魚般靈動，如同繚繞山崗的風一般自由。你的移動在他人看來極度扭曲卻又符合常理</li>
</ul>

**效果**

<ul>
<li>啓動後，攻擊你的特殊部位時需要額外承受你的敏捷值的減值。</li>
<li>每點敏捷可以額外增加3M基礎移動速度，你能站立在任何液體表面上，站在垂直的山崖上，甚至站在敵人的刀劍，風中的落葉上，你獲得蛛行術。</li>
<li>你可以自由調整你的重量，上限爲自身重量，你可以與敵人佔用同一格而不受到任何懲罰，這視爲你站在其身上。</li>
<li>若你移動至少1米，則你在本輪內獲得等同傳奇敏捷\*2點閃避防禦，並在對抗範圍效果上也有等額加值。</li>
<li>當對方對你發動單體攻擊時，你可以消耗3點意志力以及一個反射動作進行一次敏捷+運動（逃脫）檢定，DC爲對方本次攻擊造成的最終傷害，若你成功則閃避此次攻擊，這意味着你不受到本次攻擊造成的傷害。</li>
</ul>

**價格**：B+2000
