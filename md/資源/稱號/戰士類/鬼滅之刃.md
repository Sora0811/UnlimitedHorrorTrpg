# 鬼滅之刃

> 來源：`資源/稱號/戰士類/鬼滅之刃`

**本質**：魔幻本質

**前提**：需求白刃技能3以上，耐力6以上

**描述**：鬼殺隊是未被政府認可卻已經存在許久的古老組織，自古被稱爲“獵鬼人”。在接受分散各地的培育師訓練後，通過“最終選拔”——在囚禁着鬼的藤襲山7日間生還，即可入隊。

**特殊**

<ul>
<li>本稱號可反覆購買，但反覆購買本稱號只能夠獲得“呼吸法”特性帶來的好處，這意味着你反覆購買本稱號時可以再選擇一項你未獲得的呼吸法獲得，若你買了多個稱號，則其“呼吸法”後續需要如常購買升級，當你有多項呼吸法時，你能夠以一個自由動作同時啓動所有你已掌握的呼吸法並獲得對應的效果，不同呼吸法提供的修行加值可以疊加計算。</li>
<li>此外，本稱號技能樹下部分技能名字帶有如“水之呼吸”，“炎之呼吸”等前綴，對於這一類技能，你必須在購買本稱號本體時選擇了對應的呼吸法後才能夠購買和兌換該招式，並且你必須在開啓了對應呼吸法的狀態下才能夠施展該類招式。</li>
</ul>

## D 級　最下階——葵

**價格**：D+1000

**能量池**：無

**特性**：斬鬼士（三特性），呼吸法（三特性），人類限定（負特性）

**技能樹**：開啓D級鬼殺隊劍士技能樹

**特殊**：由於沒有能量池，額外獲得一個特性

**描述**

<ul>
<li>你開始掌握了呼吸法與型，通過了“最終選拔”。呼吸法強調的是“集中呼吸”，也就是讓呼吸更加強烈，充滿自己身體所有的血液和細胞，這樣就能提升自己全身的身體能力，還有提升治癒效果的功效。</li>
<li>只有使用日輪刀來斬下鬼的頭顱才能真正的殺死鬼，只是斬斷肢體的話很快就會再生，你習慣於於鬼進行戰鬥，只有刀刀朝着要害而去才能活下去。</li>
</ul>

**價格**：D+1000

**其他標籤**

**斬鬼士**：你可以忽略3點特定部位攻擊減值，並在針對黑暗生物的對抗性檢定上獲得1個附加成功。

**呼吸法**

<ul>
<li>如無特殊說明，你必須花費一個自由動作進行呼吸後才能夠獲得呼吸法帶來的好處，每次以此法進行一次呼吸，都能夠使呼吸法帶來的好處持續你的傳奇耐力\*1輪，該持續時間無法疊加，但每次以此法進行呼吸都會重置持續時間。當你沒有維持呼吸（包括但不限於屏息或窒息，以及你壓根無需呼吸等）時，則無法啓動呼吸法，而且你將無法獲得呼吸法所帶來的所有好處，同時也無法使用本稱號技能樹下的技能。</li>
<li>此外，在呼吸法持續期間施展本稱號技能樹下的技能時，都會爲你帶來與呼吸法相同屬性的特效，但這特效只會被擁有超自然能力的角色看見，如：當你使用炎之呼吸·五之型 炎虎時，一隻燃燒着火焰的猛虎會代替你的斬擊來撕咬敵人並灼燒周圍的一切，但這實際上不會造成任何能量傷害，這會讓看到你施展劍技的人覺得你很帥，但這真的只是特效。</li>
</ul>

</ul>

**人類限定**：你的血統必須屬於人類分類，同時身體結構上也必須與人類相同纔可兌換和獲得本稱號帶來的所有好處。
