# 一拳超人稱號

> 來源：`資源/稱號/戰士類/一拳超人`

**描述**

<ul>
<li>生物由於物種、個體之間的肉身差異，存在着不管付出多少努力都不能消除的極限。該極限的存在意義在於，讓各種生物在不失去本物種的生存意識和理性的範疇內成長，這個成長限制就被稱爲限制器。</li>
<li>一拳超人訓練，就是由雖然只是個過着平凡生活，普通體質的普通人，但卻通過不懈的努力以及挑戰生命極限的戰鬥而突破界限之門，打破物種應有的限制器的一拳超人琦玉所曾經進行過的修煉。</li>
</ul>

## D 級

**特性**：堅持不懈，健康飲食，天天長跑，百折不撓，打怪練級（雙特性），英雄到來，人類限定（雙負特性），能量壓縮（負特性）

**特殊**：由於沒有能量池，額外獲得1個特性。

**其他標籤**

**堅持不懈**：一拳超人的強大，其根本來自於堅持高難度的訓練。每天堅持的俯臥撐、仰臥起坐和下蹲讓你的力量 獲得2點 修行加值。

**健康飲食**：爲了變強，當然一日三餐不能馬虎，早餐喫香蕉也可以。你的 耐力獲得2點 修行加值。

**天天長跑**：哪怕再累，哪怕練到吐血，也要每天堅持長跑十公里。你的敏捷 獲得2點 修行加值.

**百折不撓**：不管被怪人打飛幾次都要繼續站起來，這纔是英雄。你的生命 上限增加1點 。爲了磨練意志力，無論冬夏都不用空調是公認的方法。你的 意志值上限增加1點。

**打怪練級**：一拳超人強大的真正祕密其實在於每天都把長跑時遇到的怪人揍趴下，挑戰自己生命的極限。每次在影片結束後獲得經驗時，如同傳奇智力1的效果一樣，你可以得到額外的經驗。這個特性和傳奇智力疊加，並且一拳超人的天生武器可以造成嚴重傷害。

**英雄到來**：爲了打倒在每天10公里長跑中遇到的每個怪物而不浪費太多時間，你習慣快速進行戰鬥並結束它。如果還沒有的話，你獲得精通先攻 專長提升1級 。


## C 級

**特性**：提升――堅持不懈，提升――健康飲食，提升――天天長跑，提升――百折不撓，英雄不死（雙特性），人類限定（雙負特性），能量壓縮（負特性）

**特殊**：無

**其他標籤**

**堅持不懈**：你的力量 再獲得3點 修行加值。

**健康飲食**：你的 耐力再獲得3點 修行加值。

**天天長跑**：你的敏捷 再獲得3點 修行加值.

**百折不撓**：你的生命 上限再增加3點 。你的 意志值上限再增加3點。

**英雄不死**：英雄是不會死的。 若你現在擁有快速醫療，則你可以以1/4的速度來恢復惡性傷害。


## B 級

**特性**：提升――堅持不懈，提升――健康飲食，提升――天天長跑，提升――百折不撓，鋼鐵之軀（雙特性），人類限定（雙負特性），能量壓縮（負特性）

**特殊**：無

**其他標籤**

**堅持不懈**：你的力量 再獲得4點 修行加值。

**健康飲食**：你的 耐力再獲得4點 修行加值。

**天天長跑**：你的敏捷 再獲得4點 修行加值.

**百折不撓**：你的生命 上限再增加4點 。你的 意志值上限再增加4點。

**英雄不死**：英雄是不會死的。如果還沒有的話，你獲得死硬專長 1 級，2級，3級，4級，5級。

**鋼鐵之軀**：你的身體強度開始超乎常理。你得到等同於你耐力附加成功+決心附加成功數的DR/-。


## A 級

**特性**：提升――堅持不懈，提升――健康飲食，提升――天天長跑，提升――百折不撓，提升――鋼鐵之軀，一拳超人（雙特性），禿頭（負特性），人類限定（雙負特性），能量壓縮（負特性）

**特殊**：無

**其他標籤**

**堅持不懈**：你的力量 再獲得6點 修行加值。

**健康飲食**：你的 耐力再獲得6點 修行加值。

**天天長跑**：你的敏捷 再獲得6點 修行加值.

**百折不撓**：你的生命 上限再增加6點 。你的 意志值上限再增加6點。

**禿頭**：漫長而艱苦的修煉已經持續一年半了，你變強了，但你的頭也禿了。你得到負向的傾城之貌專長。換言之，你在外貌容易取得優勢的社交判定上獲得-1DP減值和-2附加成功，而且你對敵人造成魅惑點數時，前5點都會被自動抵消。

**鋼鐵之軀**：你在B級時獲得的DR現在視爲全傷害吸收，但在遇到忽視全傷害吸收的攻擊時，它又被視爲DR，按有利判。在對抗攻擊內部的攻擊時，你視同體表被攻擊般照常防禦。

**一拳超人**：你的第一次攻擊往往就是戰鬥結束的宣言。每場遭遇一次，你在進行第一次近戰攻擊時，這一次攻擊的骰子全部自動取10，但不會因此加骰。


## S 級

**特性**：提升――堅持不懈，健康飲食，天天長跑（雙特性），提升――百折不撓，提升――英雄不死，提升―認真一拳（雙特性）， 強過頭了的男人（正負特性） ，人類限定（雙負特性），能量壓縮（負特性），無敵

**特殊**

<ul>
<li>無</li>
<li>堅持不懈， 健康飲食， 天天長跑 ：你的力量 再獲得8點 修行加值。 你的 耐力再獲得8點 修行加值。 你的敏捷 再獲得8點 修行加值.</li>
</ul>

**注**：若目標免疫因果律能力，則意味着一拳超人攻擊時目標依然有防禦，其他特性一拳超人依然獲得。

**其他標籤**

**百折不撓**：你的生命 上限再增加8點 。你的 意志值上限再增加8點。

**英雄不死**：最強的英雄是真的不會死的。每部影片一次，當你死亡時，你原地復活並清空所受到的所有不良狀態、所有生命槽，如果你有能量槽的話也全部恢復，並且你立刻得到一個整輪動作 ，這個整輪動作可以無視前提發動“一拳超人”特性 。

**強過頭了的男人**：突破物種的界限是需要付出代價，你所付出的代價就是失去頭髮以及無止境的寂寞感。你從現在開始無法受到來源於S級及以下的影響心靈的效果影響，無論正負面。

**認真一拳**：你的第一次攻擊往往就是戰鬥結束的宣言。每場遭遇一次，你在進行第一次近戰攻擊時，這一次攻擊的骰子全部自動取10，但不會因此加骰。並且該次攻擊忽略對方一切防禦能力，包括但不限於基礎防禦，力場防禦，洞察防禦以及在防禦上的全部加值等以及傷害抵消，傷害減免，傷害吸收能力等能力，除非對方有基於S級以上影響因果律的防禦或閃避能力，並且該次攻擊沒有傷害上限，本次攻擊無法附帶任何招式，因爲這只是普通一拳。

**無敵**：一拳受到的所有傷害降低1級，最低爲衝擊傷害。


## 子項目

### 光頭披風服（專屬物品）

**本質**：特異本質

**價格**：500

**分類**：輕甲和披風

**描述**：這是一件帶白色斗篷和黑色腰帶的黃色英雄制服，只有進行過一拳超人訓練的人纔可以購買和穿着 。

**盔甲基本屬性**：盔甲防禦4/4

**盔甲特殊屬性**：無

**注**：本能力在購買時，一直在B以下時，都視爲普通人類。

**其他標籤**

**不會破壞**：只要你還沒被殺死，這套衣服就不會因爲任何原因被破壞。即使你被殺死了，這套衣服也必然會有標誌性的碎片殘留下來。


**其他標籤**

**能量壓縮**：該訓練會將修煉者所有的能量高壓縮進體內，這個訓練的修煉者永遠無法將任何能量放出體外，哪怕一毫米也不行，也就是說任何使用後獲得射程這個屬性的技能，招式全部無法使用，但是物品可以使用，你也無法將能量灌注物品之中。

**人類限定**

<ul>
<li>玩命地鍛鍊自己到禿頭的程度，這就是變強的唯一方法，憑自己的力量改變纔是人類的強大之處，人體改造、基因調製，超自然的人絕對無法到達這個高度。</li>
<li>一拳超人訓練無法與任何改造和血統兼容，哪怕一些血統和改造購買後不視爲購買了血統和改造也不兼容。</li>
<li>一拳超人訓練也無法與任何改變人類本質的兌換兼容，如變成黑暗生物，光明生物等能力兼容。</li>
</ul>
