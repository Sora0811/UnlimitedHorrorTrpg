# 獵人稱號（來源：全職獵人）

> 來源：`資源/稱號/戰士類/獵人稱號`

**本質**：特異本質

**作者**

<ul>
<li>赤鳴</li>
<li>所謂“獵人”即是探尋重要文化遺產及稀少的動植物並加以保護，還要抓出重大嫌疑犯的人，既是職業也是階級。獵人設有執照制度，由獵人協會每年舉行嚴格的考試，合格的人才會得到獵人牌照，然後可依自己的意思使用牌照，他們有各種權利（如免費使用95 %的各國公共設施），不過也必須選擇做自己想要種類的獵人，盡該盡的義務，例如：旅遊在世界各地尋求美味食材的美食獵人、受僱於人的私家獵人、經過嚴格測驗之追求金銀財寶的尋寶獵人、去尋找發現許多不爲人知幻獸的幻獸獵人、追捕通揖犯或違規獵人的獎金獵人等。</li>
<li>獵人必須遵守十條規章制度</li>
<li>其之一 獵人必須擁有狩獵目標。</li>
<li>其之二 獵人必須具備最低限度的武之心得，所謂的最低限度即是念的修行。</li>
<li>其之三 擁有獵人執照之人無論任何理由，均不作廢，同時無論任何理由執照亦不會再度發行。</li>
<li>其之四 獵人不得將同胞的獵人視作獵物，但進行極惡犯罪的獵人不受此條保護。</li>
<li>其之五 在特定領域留下豐功偉業的獵人，授予其一星。</li>
<li>其之六 滿足第五條並擔任高管的前輩獵人，其培育的後輩獵人獲得星級榮譽時，授予其二星。</li>
<li>其之七 滿足第六條並在複數領域留下豐功偉業的獵人，授予其三星。</li>
<li>其之八 獵人最高負責人，需要獲得最低限度的信任，方有資格擔任此責。最低限度的信任，即是半數以上的支持率。會長之席空位之時，需迅速選出下任會長。下任會長決定之前，會長行權交由副席掌管。</li>
<li>其之九 新同胞的入會選拔方法的決定權由會長掌管，但方法大幅變更時，需要半數以上的同胞的信任方可實施。</li>
<li>其之十 此次未記載的一切事項均由會長和副席以及參謀團通過會議表決；副席及參謀團的挑選由會長掌管。</li>
</ul>

## D 級　獵人考生

**價格**：D+1000

**能量池**：念能力

**技能樹**：開啓D級獵人技能樹

**特性**：試煉之旅（雙特性），四大行修習（雙特性）

**描述**：要成爲真正有執照的正式獵人，只有通過獵人考試纔可以。獵人考試不設定必死或死亡概率過高的考驗，但考試過程不保證考生生命安全，獵人考試也沒有道德和品性要求，只要考官說出了“合格”兩個字，哪怕是惡魔也一樣可以成爲獵人。

**價格**：D+1000

**其他標籤**

**試煉之旅**：獵人的考試內容當然每年都會改變，因爲考試的內容太過嚴苛，所以也有許多人再也回不了故鄉，可說是全世界最危險的考試。考覈不僅僅是一種資質的考察和認可的過程，獵人的考試本身就是一種最艱辛的試煉。你的決心相關檢定增加1DP修行加值；你的意志力上限增加3點。

**四大行修習**：“纏”、“煉”、“絕”、“發”，合稱爲念，是"昇華心智，鍛鍊心智"，所有格鬥技的基礎即爲四大行。換句話說，是增強自我意志過程的修行。念能力是所有正式獵人所必然掌握的一項基礎能力，爲了成爲一名合格的獵人，你也必須在艱苦的訓練中掌握念能力的精髓。你立即獲得一個D級別的念能力應用技。

# 念氣（念能力）

**本質**

<ul>
<li>特異本質</li>
<li>念氣池又被稱爲念能力的池，念氣池是一個東西方皆有的通用能量池。</li>
<li>念能力的關鍵屬性爲決心+沉着。</li>
<li>念能力的 基本用法：當你進行決心或者沉着相關檢定時，你可以無需動作，消耗1點念氣，使此次檢定獲得2DP表現加值。</li>
</ul>

## 特質系

**例**：PC誓言每一次的戰鬥都絕對不會撤退或者做出任何逃避類的舉動，一定會戰鬥至敵人全部死亡及潰逃或者自身死亡爲止，ST可以給予其攻擊檢定以4DP表演加值；若PC在某場戰鬥中不是因爲不可抗力（不可抗力通常是指PC被控制而非出於自願）而主動脫離戰鬥，則ST可以給予PC的意志檢定以永久性的8DP的完美減值。

**其他標籤**

**ST酌情選開此規則**：念能力是源於內心的力量，定下的制約和誓約便會增加“念”的力量，制定規則，並在內心起誓，並加以堅守，越是艱難的規則和殘酷的覺悟，所發爆出來的威力就越是強大。若是把平時的念能力比作加法的話，那遵守規則的念能力就是乘法，力量會乘倍增加，對自己定下的條件越苛刻力量就越強大。制約和誓約是不穩定的雙刃劍，違背誓言會因爲反噬而可能失去唸能力甚至是直接死亡。若PC以最深的覺悟對自己制下最殘酷的制約和誓言，則ST可以根據誓言的制約程度酌情給予一定念能力的表演加值；但是同樣的，若PC違背了自己的誓言，ST也可以根據誓約的內容給予對應的懲罰。


**正文**

不屬於以上五系的念能力皆分爲此類。特質系的能力神祕難測，如庫洛洛能盜取他人的念能力，派克諾妲的記憶讀取和射出，妮翁的預言能力，以及亞路加的實現願望能力，都歸在特質系。

**正文**

“發”是念能力之集大成者，對自己的氣進行自由的操縱和運用。必殺技式的能力，每個人的能力因人而異。

如果使用非本系的念能力應用技，會受到DP減值。念能力相性爲強化系、變化系、具現化系、特質系、操作系、放出系、強化系，以下循環。如使用臨近一位系別的念能力應用技的話，所有能力承受2DP無名減值，如果使用距離兩位系別的念能力應用技的話，所有能力承受5DP無名減值，而距離三位系別的念能力應用技，所有能力承受10DP無名減值。

（“發”的種類繁多，以下的技能只是原作角色使用的能力。念能力者也可以根據角色特性自行設計自己的“發”，由ST判定是否可用，並且按照原作設定進行系別分類。）
