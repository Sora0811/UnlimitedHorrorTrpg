# 槍械師

> 來源：`資源/稱號/遠程類/槍械師`

**本質**：科技本質

**前提**：需求槍械技能等級4，並擁有最少3個專業，專長：狙擊大師、火力手、雙槍射擊與重甲大師1級以上。

**總描述**

<ul>
<li>有時我們能見到這樣一種人，他們在戰略地圖上與其他軍團一樣單獨擁有一個小模型，並且喫着同樣數量的補給。雖然官方名義上多半使用某個軍隊編號稱呼他們，不過私底下我們稱其爲槍械師。</li>
<li>他們手持着你能想象到的最重型的武器，站在最穩固的支點上，實行着火力最大化的原則――將手中的槍械發揮出數十倍於常人的威力就是槍械師的職責，除此之外的一切都是不必要的。</li>
</ul>

**特殊**：本稱號下提及的“重武器”是指所有體積達到3以上的槍械武器以及發射類武器。載具和器械上的武器只要符合條件並且能夠手動操作，通常都算作重武器，例如坦克上的機槍或的軌道炮，具體可由ST裁定。

## D 級

**價格**：D+1000

**能量池**：無

**技能樹**：開啓D級槍械師技能樹

**特性**：重武器專攻（三特性）、槍械專精、重武器精準

**特殊**：由於沒有能量池，額外獲得1個特性。

**描述**：別人總是覺得很莫名其妙爲什麼同樣武器到了槍械師手裏就突然變得如此威猛，你告訴他們那是幻覺。 重武器專攻：當你持用重武器時，其武器傷害與【破甲】分別提升3點。 槍械專精：你的槍械技能提升1級，最高到5級。 重武器精準：當你使用重武器進行遠程槍械攻擊時，若受到任何帶有[目標體積每比X小Y點就要承受Z點減值]及類似描述的效果所影響，你可以忽略等同於自身槍械技能等級一半的該類減值。

**價格**：D+1000

### 重武器拔擊

**價格**：D+500

**動作**：迅捷動作

**能耗**：無

**射程**：觸及

**目標**：一個目標

**範圍**：無

**持續**：立即

**描述**：每當被捲入肉搏戰時，槍械師們總會用貿然衝向自己的笨蛋給觀衆們上一堂生動的實驗課：六千五百磅重的火炮砸在人身上的威力絕不比一把刺刀差。這只是許多槍械師拔出武器時的習慣動作，但是經常被認爲是一種惡毒的攻擊。

**被動效果**：你能夠將重武器作爲分類爲“長棍”，武器傷害3L，能夠造成鈍擊嚴重傷害的白刃武器使用。

**效果**：每輪1次，當你拔出一把重武器時，你可以用迅捷動作施展本招式，隨後使用該武器對目標進行一次近戰白刃攻擊，該次攻擊不會造成傷害，但目標需要通過1個DC爲你該次檢定成功數的強韌檢定，若其檢定未通過則會被擊退差值\*1米。

**研發**：支付12XP進行研發，隨後你在施展本招式時可以宣言將目標朝空中垂直擊退，若你這麼做則每將目標擊退1米便能使目標失去1點基礎防禦，目標最多因此失去8點基礎防禦，持續1輪。

**價格**：D+500

### 軍火商

**價格**：D+500分

**動作**：被動

**描述**：黑客帝國1里尼奧掀開風衣的鏡頭看過了嗎？那個不行，完全不行。

**效果**

<ul>
<li>僅在判斷物品攜帶狀況時，你攜帶的所有重武器體積值視爲原本的一半，向下取整，至少爲1。</li>
<li>這意味着槍械師能夠從夾克衫裏抽出狙擊步槍，將40毫米機關炮藏在大衣之下――並且不只一把。</li>
</ul>

**價格**：D+500

### 人形地堡

**前提**：專長：重甲大師2級以上

**價格**：D+500分

**動作**：移動動作

**能耗**：無

**射程**：無

**目標**：自身

**範圍**：無

**持續**：見下

**描述**：你知道如何最有效的利用環境爲自己取得優勢，當你站定時，你就是一個地堡般穩定而又難以攻陷的火力平臺。

**效果**

<ul>
<li>只要腳踏實地（包括置身於大型飛行器內和海洋上，以站穩爲準），你便可以花費1個移動動作進入“站定”狀態，在該狀態下，你在會擊倒或強制你移動的效果的對抗與豁免檢定上，以及防禦上分別獲得4點掩蔽加值。</li>
<li>該效果持續至你進行移動，被強制移動或倒地爲止。</li>
</ul>

**價格**：D+500

### 豪腕

**價格**：D+500分

**動作**：被動

**描述**：槍械師長手的原因就是爲了持槍。

**效果**

<ul>
<li>在判斷你持用重武器的力量需求時，你的力量視爲比原本高4點。</li>
<li>此外，只要你的力量達到了重武器力量需求的1.5倍，你便可以無視雙槍射擊專長對武器體積的要求來使用重武器應用該專長。</li>
</ul>

**價格**：D+500

### 一人小組

**前提**：掌握豪腕

**價格**：500分

**動作**：被動

**描述**：你一個人就能編成火力支援小組，平常需要兩個人共同攜行，用沙袋固定才能開火的重武器，你可以提在手中自如使用。如果每個師團的炮兵連都是這樣的傢伙，想必國家的軍事開銷會節省許多。

**效果**：當你持用重武器時，其獲得【支架】特性，並且始終視爲處於架設狀態。

**升級**

<ul>
<li>支付D+500將本能力升級爲“一人小組”，獲得以下能力：僅在操作必須多人合作使用的重武器時，你每輪獲得一個額外的整輪動作，這些動作僅能用於對重武器的裝填、校準及復位調整類行爲。</li>
<li>支付C+1000將本能力升級爲“一人連隊”，隨後“一人小組”提供的額外整輪動作再增加3個。</li>
<li>支付B+2000將“一人連隊”升級爲“一人軍團”，隨後在“一人連隊”能力基礎上提供整輪動作再額外增加9個。</li>
</ul>

### 彈藥專家

**價格**：D+1000分

**動作**：被動

**描述**：只有外行人才僅僅看重槍械，子彈的力量一樣重要。

**效果**：你可以無視因使用特種彈藥而帶來的器械減值、武器傷害降低與【破甲】降低效果，但每項分別只能無視4點。

**價格**：D+1000

## C 級

**價格**：C+2000

**技能樹**：開啓C級槍械師技能樹

**特性**：重武器專精（三特性），重武器嫺熟

**特殊**：無。

**描述**：熟知每一種重武器的性能――然後學會用手中的槍械去思考。

**價格**：C+2000

**其他標籤**

**重武器專精**：當你持用重武器時，其武器傷害再提升4點，並獲得【火力壓制】【眩暈】與【貫穿】特性。

**重武器嫺熟**

<ul>
<li>如何使用一把大槍轟翻對手？首先你需要把它亮出來。</li>
<li>這表現爲只要重武器不是被置於難以收取的位置（如上了十把大鎖的箱子裏），你便只需要花費1個自由動作就可取出或收起最多2把重武器。</li>
</ul>


### 人形要塞

**前提**：人形地堡

**價格**：C+1000分

**動作**：被動

**描述**：要塞不僅意味着最強的防禦力，還意味着最強勁的火力。

**效果**：“站定”狀態提供的掩蔽加值再增加4點，並且在該狀態下，你持用的重武器只要沒有射擊間隔或者其只能單發，則其速射等級便提升2級（單發－短點射－長點射－連射）。

**價格**：C+1000

### 強制重武器拔擊

**前提**：重武器拔擊

**價格**：C+2000

**動作**：反射動作

**能耗**：無

**射程**：觸及

**目標**：一個目標

**範圍**：無

**持續**：立即

**描述**：無

**效果**：當你受到攻擊且攻擊放位於你觸及範圍內，又或是任意單位進入你的觸及範圍時，你可以花費反射動作拔出一把重武器並對該目標施展一次“重武器拔擊”，該次行動視作在目標攻擊之前，但不會打斷對方的動作（這意味着如果你在對方移動過程中施展本能力，則只要對方在被擊退後仍有足夠的移動距離，其還是可以繼續進行移動），如果對方在攻擊時因此被你擊退至無法觸及你的距離，則視同你與被攻擊者移出了對方的攻擊範圍。

**價格**：C+2000
