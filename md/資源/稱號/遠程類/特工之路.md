# 特工之路

> 來源：`資源/稱號/遠程類/特工之路`

**本質**：特異本質

**前提**：需求風度與智力3以上，槍械技能等級、白刃技能等級、運動技能等級與肉搏技能等級1以上

**總描述**

<ul>
<li>在茫茫的平行世界中，總是有這麼一羣人，他們被大家稱爲“主角”</li>
<li>也許最開始他們只是一個普通的片警，但是經歷的各種狗血事件使他們快速成長，最終成爲一名可以拯救世界的超級特工</li>
<li>“Welcome to the club” ――里昂</li>
</ul>

## D 級

**價格**：D+1000

**能量池**：無

**技能樹**：開啓D級特工技能樹

**特性**：墜崖不死（三特性），百毒不侵，基本素養

**特殊**：由於沒有能量池，額外獲得1個特性。

**描述**：沒有主角會摔死！也沒有主角會被毒死！

**價格**：D+1000

**其他標籤**

**墜崖不死**：你免疫墜落傷害。

**百毒不侵**：你免疫D級毒素效果，並且僅針對毒素效果，你在對抗性檢定上獲得1DP修行加值。

**基本素養**：在槍械、白刃和肉搏技能中選定一項，選定後不可更改，隨後該技能提升1級，最高提升至4級。


### 風度翩翩

**價格**：D+500

**動作**：被動

**描述**：頭可斷，髮型不能亂！

**效果**

<ul>
<li>只要你願意，無論發生什麼情況，你的髮型都不會發生任何變化，你的身體和衣服也不會染上任何污漬（包括灰塵、血液、細菌等）和出現褶皺與老化（但你還是會如常受到衰老效果的影響，衣物被摧毀時也還是會消失），這是一個D級因果律效果。</li>
<li>此外，當你向其他單位提出春風一度的邀請時，僅針對該次邀請，對方對你的友善度視作比原本高1級。</li>
</ul>

**價格**：D+500

### 迎面一腳

**價格**：D+500

**動作**：被動

**描述**：這平淡無奇，破綻大露的一腳，卻總是能將敵人打得硬直或暈頭轉向。

**效果**

<ul>
<li>當你使用腿作爲天生武器進行近戰肉搏攻擊時，該次攻擊獲得【眩暈】特性，並會使目標陷入D級措手不及狀態。</li>
<li>特殊的，PC可以將本技能更名爲“當頭一棒”，隨後本技能效果改爲使用能夠造成鈍擊傷害的白刃武器進行近戰白刃攻擊時，該次攻擊獲得【眩暈】特性，並會使目標陷入D級措手不及狀態。</li>
</ul>

**價格**：D+500

### 威力射擊

**價格**：D+500

**動作**：標準動作

**能耗**：無

**射程**：等同於武器的射程

**目標**：傳奇敏捷/個目標

**範圍**：無

**持續**：立即

**描述**：你使用華麗的動作連開數槍將身邊的敵人全部擊退。

**效果**：你可以花費標準動作使用你當前持用的一把槍械武器對射程內不超過你傳奇敏捷/名單位分別進行一次遠程槍械攻擊，若成功造成傷害，則目標需要通過1個DC爲該次攻擊傷害值的強韌檢定，若檢定未通過則會被擊退差值的米數。

**價格**：D+500

## C 級

**價格**：C+2000

**技能樹**：開啓C級特工技能樹

**特性**：墜機不亡，快速醫療，嘴炮無敵（雙特性）

**特殊**：無。

**描述**：即使技術已經到達巔峯，但你仍然需要進步。看看雪莉，再看看里昂吧！

**價格**：C+2000

**其他標籤**

**墜機不亡**：每部影片1次，當你搭乘的載具在飛行過程中因任何原因墜落或爆炸時，若你會因此受到傷害，且該傷害會導致你死亡，則你可以使自己免疫該次傷害，若你這麼做則會不可避免地昏迷等同於該次傷害值\*10分鐘，此期間你無法以任何方式清醒過來。

**快速醫療**：你獲得1點快速醫療。

**嘴炮無敵**：你獲得互動系技能上的所有專業，並在所有表達與交際技能相關檢定上獲得1個附加成功與2DP修行加值。


### 最後一擊

**價格**：C+1000

**動作**：被動

**描述**：你的彈夾中的最後一發子彈總是能起到意想不到的效果，即使之前被你命中N槍依舊活蹦亂跳的boss，在中了這一槍之後也會被打得飆血。

**效果**

<ul>
<li>本能力對具備無限彈藥效果的槍械與攻擊無法起效。</li>
<li>每場景一次，當你手持的槍械武器只剩下1發彈藥時，你在使用該武器進行的遠程槍械攻擊檢定上獲得2個附加成功，並且本次攻擊傷害上限增加6點。若你對該次攻擊的結果不滿意，可以重投1次該次攻擊，取較好的一次作爲結果。</li>
</ul>

**價格**：C+1000
