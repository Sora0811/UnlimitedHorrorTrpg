# 老兵傳奇

> 來源：`資源/稱號/遠程類/老兵傳奇`

**本質**：科技本質

**前提**：槍械技能等級3，需求力量4，需求敏捷4

**總描述**

<ul>
<li>人類的歷史，就是一部戰爭史。從骨矛，到青銅武器，到鐵質武器，再到熱武器。從羅馬的重標槍，到阿拉伯彎刀，中國的鬼頭刀，日本的武士刀。無數武器在歷史上譜寫了它們的傳奇，然後從輝煌中漸漸隱入幕後。</li>
<li>而士兵，在所有時代都存在的單位，士兵是一個國家的根本，是不可缺少的一種單位。當戰爭發生，士兵扛着槍不猶豫的前往戰場，爲自己的信念奉獻自己的生命。爲了守護自己要守護的東西奉獻自己的生命。士兵，塑造了一個又一個的傳奇。現在，士兵又要繼續塑造屬於自己的傳奇。</li>
</ul>

## D 級　菜鳥

**價格**：D+1000

**能量池**：無

**技能樹**：開啓D級老兵技能樹

**特性**：魔鬼訓練（雙特性），Double tap，槍械熟練（雙特性）

**特殊**：由於沒有能量池，額外獲得1個特性。

**描述**：哪怕是老兵，也有還是新兵蛋子的一天。進入軍營後的魔鬼訓練會淘汰一大部分意志不堅定的人，艱苦的訓練會讓自己成爲真正的士兵，傳奇，從這裏開始。

**價格**：D+1000

**其他標籤**

**魔鬼訓練**

<ul>
<li>你的意志檢定獲得稱號等級\*1DP修行加值，並且你現在不會因爲傷勢昏迷。</li>
<li>Double tap：由【短點射】【長點射】與【連射】特性帶來的DP加值增加2點。</li>
</ul>

**槍械熟練**：你獲得槍械技能上的所有專業，並且槍械技能上的專業加值變爲3點。


### Danger close

**價格**：D+500

**動作**：被動

**效果**：當你使用爆炸物的“爆炸”特性造成傷害時，該傷害與其【破甲】額外增加本稱號等級\*1點，同時目標針對該傷害的反射檢定需要額外承受相當於本稱號等級/點無名減值。

**價格**：D+500

### Sitrep

**價格**：D+500

**動作**：被動

**描述**：你可以輕易的發現各種陷阱及爆炸物。

**效果**：僅針對與搜索陷阱及爆炸物，你在調查（偵查）檢定上獲得等同於稱號等級的附加成功。並且你在針對陷阱和爆炸物造成的影響進行豁免時，你在該次豁免檢定上獲得等同於稱號等級的附加成功。

**價格**：D+500

### 強壯

**價格**：D+500

**動作**：被動

**效果**：你現在只需要4小時便能完成一次長休息，同時你獲得等同於稱號等級\*2點的天生防禦。

**價格**：D+500

## C 級　大兵

**價格**：C+2000

**技能樹**：開啓C級老兵技能樹

**特性**：提升-魔鬼訓練，武器暴走，戰場保護，Light weight

**特殊**：無。

**描述**

<ul>
<li>現在你已經是一名真正的士兵，執行過高危險的任務並且完美的執行成功。你現在是敵人聞風喪膽的噩夢。</li>
<li>提升-魔鬼訓練：你的生命值上限增加6點。</li>
</ul>

**價格**：C+2000

**其他標籤**

**武器暴走**：當你身穿盔甲時，你當前持握的槍械武器增加等同於你傳奇力量與傳奇敏捷取高\*1點武器傷害。

**戰場保護**

<ul>
<li>當你身穿盔甲時，你增加相當於你傳奇敏捷的閃避防禦。同時你的意志力池上限增加3點。</li>
<li>Light weight：你在運動技能相關檢定上獲得2個附加成功。</li>
</ul>


### 最後一顆子彈

**價格**：C+1000

**動作**：反射動作

**能耗**：1點意志力

**射程**：無

**目標**：自身

**範圍**：無

**持續**：立即

**效果**：每場景一次，當你生命槽中沒有完好生命值也沒有衝擊傷害時，你可以消耗1個反射動作支付1點意志力，隨後立即獲得一個標準動作，該標準動作必須立刻使用，並且只能用來使用你當前持用的槍械武器進行一次遠程槍械攻擊，你在該次攻擊檢定上獲得8DP士氣加值。

**增幅**：施展本能力時，你可以額外支付不超過本稱號等級\*1點意志力，每以此法額外支付1點意志力，你該次攻擊檢定變再獲得3DP士氣加值與1個附加成功。

**價格**：C+1000

### 槍械加強

**價格**：C+1000

**動作**：迅捷動作

**能耗**：1點意志力

**射程**：無

**目標**：自身

**範圍**：無

**持續**：1輪

**效果**：效果持續期間，你當前持握的槍械武器基礎射程增加200米，獲得【魔法】特性並增加3點【破甲】與【破魔】。

**價格**：C+1000

### 強行突破

**價格**：C+1000

**動作**：自由動作

**能耗**：1點意志力

**射程**：無

**目標**：自身

**範圍**：無

**持續**：1輪

**效果**：效果持續期間，你使用當前持握的槍械武器進行遠程槍械攻擊時，本次攻擊無視目標任意4點傷害降低類能力（傷害抵消，傷害忽略，傷害減免，傷害吸收），具體無視哪一項由你決定。

**價格**：C+1000

## B 級　老兵

**價格**：B+4000

**技能樹**：開啓B級老兵技能樹

**特性**：提升-魔鬼訓練（雙特性），Commando（雙特性）

**特殊**：無。

**描述**

<ul>
<li>“爲了勝利，向我開炮！”</li>
<li>英雄的英靈似乎附着在這把槍上，偶爾，你能聽到當時的吶喊。你不是一個人在戰鬥，你不是一個人！</li>
<li>提升-魔鬼訓練：你免疫B級的負面心靈影響效果。此外，你在槍械技能相關檢定上的加骰提升1級，最高提升至9加骰。</li>
</ul>

**價格**：B+4000

**其他標籤**

**Commando**：你可以花費1個反射動作移動不超過自身基礎移動速度一半的距離，同時你免疫墜落傷害。


### 堅定不移

**價格**：B+2000

**動作**：被動

**效果**：當你使用意志力的基礎用法時，你可以額外再花費一點意志力。

**價格**：B+2000

### Cold blood

**價格**：B+2000

**動作**：移動動作

**能耗**：3點意志力

**射程**：無

**目標**：自身

**範圍**：無

**持續**：一個場景

**描述**：由於戰場紛亂無比，你獲得偷偷靠近目標的能力。

**效果**

<ul>
<li>效果持續期間，你獲得“隱身”，這並非真正意義上的隱身，只是由於戰場上的其他目標疲於關注其他對手而忽視對你的關注，這是一個B級特異本質的反偵測效果，同時你在躲藏技能相關檢定上獲得相當於你稱號等級的附加成功。</li>
<li>在該狀態下進行攻擊時，如果被攻擊的目標無法定位你，則僅針對你該次攻擊，受影響目標會陷入措手不及狀態，這是B級措手不及效果，若你這次攻擊是範圍傷害且允許豁免，則所有受影響目標在該次豁免檢定中失去一半成功數。該次攻擊結束後，本能力持續時間立刻結束。</li>
<li>你無法在沒有隊友的情況下或者非戰鬥場景下使用本能力。</li>
</ul>

**價格**：B+2000

### 老兵傳奇

**價格**：B+2000

**動作**：24小時

**能耗**：見下

**射程**：觸及

**目標**：你持用的一把槍械武器

**範圍**：無

**持續**：永久

**描述**：你手上的槍，是那些傳奇人物當年用過的槍，而你，將繼續塑造傳奇。

**效果**：選擇一把你持用的槍械武器並花費24小時，隨後你在本能力持續期間失去6點意志力上限，使該武器獲得【神兵】【認主】特性，武器傷害提升4點，破甲提升3點，當你使用該武器進行遠程槍械攻擊檢定時，你可以投2次骰子，選擇較好的一次作爲結果，你同一時間只能對1把武器施展本能力，解除本能力的持續時間是1個自由動作。

**價格**：B+2000
