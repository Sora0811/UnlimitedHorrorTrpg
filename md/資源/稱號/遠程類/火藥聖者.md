# 火藥聖者

> 來源：`資源/稱號/遠程類/火藥聖者`

**本質**：特異本質

**前提**：擁有一個關鍵屬性包含感知在內的心智系能量池，槍械技能等級1

**總描述**

<ul>
<li>「聖者」</li>
<li>所謂聖者，是對能夠操縱超常力量的戰士們的總稱。這個世界僅有不到八十名的聖者，而且毫無例外聖者清一色皆爲女性，其血液對於兇魔來說是猛毒。</li>
<li>據說聖者與掌管着萬物之理的神同爲一體。她們藉助寄宿在體內的神力，獲得超越人類的能力。與一位神祗對應的聖者，只能有一個。當聖者死亡之後，聖者的力量將被奉還於神處，然後等待其他的某個人再被選爲聖者，繼承這種能力。</li>
<li>「火藥聖者」</li>
<li>自人類發明火藥以來，這項極具有殺傷力的發明便出現在各種戰爭之中。</li>
<li>而正因爲如此，也誕生了新的聖者――「火藥」的聖者。</li>
</ul>

**注**：聖者的能力已經被主神改造適應性，不一定需要女性纔可以獲得聖者的能力。

**特殊**

<ul>
<li>本稱號下提及的火槍，均爲發射結構上獨自包含擊發藥和單一彈頭，並且擊發藥通過高速燃燒作爲發射動力的槍械，具體哪些武器符合要求可由ST裁定。火藥的聖者必須要使用火槍才能施展和獲得本稱號下所有正面效果。</li>
<li>此外，你無法使用任何具備無限彈藥效果的槍械，使用該類槍械時，無論如何你都無法發射出彈藥。</li>
<li>在兌換本稱號時，你需要選擇一個關鍵屬性包含感知在內的心智系能量池作爲本稱號下所有能力的能耗，選定後不可更改。</li>
</ul>
