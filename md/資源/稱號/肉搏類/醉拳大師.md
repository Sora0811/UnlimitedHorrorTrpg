# 醉拳大師

> 來源：`資源/稱號/肉搏類/醉拳大師`

**本質**：特異本質

**前提**：肉搏技能等級4以上

**描述**

<ul>
<li>我顛顛又倒倒好似浪濤，有萬種的委屈付之一笑，我一下低我一下高，搖搖晃晃不肯倒，酒裏乾坤我最知道。</li>
<li>壺裏乾坤大，杯中日月長，人類燦爛的釀酒史讓這種神奇的液體充分融入了人類文化的各個角落，真的，各個角落。</li>
</ul>

## D 級

**能量池**：內力

**技能樹**：開啓D級醉拳大師技能樹

**特性**：醉飲、豪飲、端杯拳（雙特性）

**特殊**：無

**描述**：或許你不甚愛那杯中之物，但當你入了醉拳門派後，你註定要與它爲伍。

**其他標籤**

**醉飲**

<ul>
<li>你獲得了一個特殊的刻度槽“醉意”，醉意刻度槽的上限爲你的耐力值，醉拳大師下的所有能力都必須在你有“醉意”的情況下纔可以使用。每分鐘你的“醉意”自動下降1點。</li>
<li>你可以通過飲用起碼100毫升的酒類來獲得1點醉意。</li>
</ul>

**豪飲**：你已是酒中老餮，杯裏仙人，鯨吞酒液對你來說是再輕鬆不過的事情了，你只需要一個迅捷動作便可飲下一劑（500ml）酒類，一個移動動作可額外飲下等同於你傳奇耐力\*500ml的酒類，一個標準動作可以讓開懷暢飲，將醉意槽填滿（但你仍需要足夠的酒類和足夠的胃容量）。

**端杯拳**：雙手食指與拇指相對，其餘三指握緊，如端空杯，爲醉拳的基礎拳式，你的天生武器變爲2L，且視爲適合擒抱和卸除武器的天生武器，攻擊檢定獲得等同於醉拳大師等級的DP修行加值，在攻擊類型上視爲鈍擊或穿刺（可同時享有指法和拳法的好處）。

### 醉酒雲霧

**價格**：D+500

**動作**：標準動作

**射程**：以自己爲中心

**目標**：所有目標

**範圍**：耐力值/米半徑120度錐形範圍

**持續**：見下

**描述**：噗~~~~~！！

**效果**

<ul>
<li>習得本能力後，你可以在體內存儲酒液，你每1點體積值和1點傳奇耐力可以讓你存儲1劑量的酒液（1劑量爲500ml）。</li>
<li>使用本能力，你消耗1劑量的酒液，對對方進行一次噴吐的接觸攻擊，攻擊檢定爲耐力+運動（噴吐），目標反射豁免。</li>
<li>若你成功，則目標獲得差值的浸酒點數，以及眩暈點數和目眩點數，不良狀態點數無法疊加，目標強韌豁免。</li>
<li>浸酒點數並非不良狀態點數，只是計算一些特定情況時使用的一種刻度，浸酒點數每輪下降1點，並且可以疊加。</li>
<li>當目標受到火焰傷害時，則其立即失去所有浸酒點數，改爲額外受到等額的火焰嚴重傷害以及燃燒點數，燃燒點數可以疊加，反射豁免。</li>
<li>若目標處於正在燃燒的狀態下時，則目標受到浸酒點數則立即改爲獲得等額的火焰嚴重傷害，以及等額的燃燒點數，可以疊加，反射豁免。</li>
</ul>

**價格**：D+500

## C 級

**技能樹**：開啓C級醉拳大師技能樹

**特性**：惡飲、回魂酒、 倒地

**特殊**：無

**描述**

<ul>
<li>桃花馬，千金裘，一併送去換美酒，與爾同銷萬古愁。</li>
<li>桃花仙人種桃樹，又拿桃花換酒錢。</li>
<li>那武二郎雙腿連環踢出，如穿花蝴蝶，只幾腳便將那蔣門神踢的口吐鮮血。</li>
</ul>

**價格**：C+1000

**動作**：移動動作

**能耗**：見下

**射程**：觸及

**目標**：一個目標

**範圍**：無

**持續**：立即

**被動效果**：你的踢擊可以如同順勢斬那樣連射，攻擊你近戰觸及內的多個敵人且不用承受任何減值。

**效果**：當你將任何敵人擊退\\擊飛後，消耗3點醉意以及3點內力，你啓動本能力，選擇其中的一名敵人，然後對該目標追加一次近戰攻擊，若目標計算擊飛\\擊退米數不在你的觸及範圍內，則你可以進行行一次衝鋒來對對方進行這次攻擊（本次衝鋒的距離不得超過你本輪移動的總距離），若是擊飛，你需要進行一次跳躍檢定來確定自己能達到的高度，若成功使目標可以進入你的觸及範圍內可以進行這次攻擊。

**價格**：C+1000

**其他標籤**

**惡飲**：你的血管中流淌的不是血，而是濃郁的酒精，你以一個自由動作可以消耗最多等同於你傳奇耐力/點醉意，可以將等額的衝擊傷害轉爲完好，一半的嚴重傷害轉爲衝擊傷害。

**回魂酒**：你每飲下一劑（500ml）酒類，便獲得1點臨時生命，上限爲你傳奇耐力，可以反覆獲得，但是無法疊加。

**倒地**：你在倒地時不承受對近戰攻擊防禦的減值，反而獲得對應的加值。同時，你從倒地起身也只需要一個自由動作。
