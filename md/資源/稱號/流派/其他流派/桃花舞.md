# 桃花舞

> 來源：`資源/稱號/流派/其他流派/桃花舞`

**本質**：特異本質

**前提**：擁有內力或真氣能量池，擁有至少1級表達-舞蹈或表達-演奏技能。

**描述**：桃花塢主人流傳下來的獨門心法和武學，花影繚亂，繽紛絢爛，讓人心醉神怡不可自拔。

**特殊**

<ul>
<li>購買桃花舞總綱後，選擇你的內力池或真氣池進行綁定，綁定後，本技藝下的所有能力所消耗的能量皆爲綁定的能量池。</li>
<li>此外，本流派下所有“表達”僅指在表達-舞蹈與表達-演奏技能之間取高者計算。</li>
</ul>

**選開**：ST可以允許PC綁定任意符合武俠畫風的東方能量池。
