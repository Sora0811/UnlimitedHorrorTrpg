# 流派

> 來源：`資源/稱號/流派/遠程流派/魔彈射手`

**本質**：魔幻本質

**前提**：槍械技能等級1，需求智力4

**總描述**

<ul>
<li>“衆生萬物，一律平等。我的魔彈，對誰也是一視同仁。”</li>
<li>魔彈射手是將槍械當作生命，將子彈視爲靈魂一般珍惜的神槍手。</li>
<li>對他們來說，子彈比起任何技術都要重要。</li>
<li>因爲他們將靈魂融入了子彈之中，所以他們的子彈，就彷彿自己的手腳一般的聽從指揮。</li>
<li>他們的子彈有着特殊的功能，可以在瞬間穿透很多人的心臟，又或者是在飛行中不斷的變化軌跡，絕對能命中目標。</li>
<li>對他們來說，只要有一發子彈，就可以征服世界。</li>
</ul>

**特殊**：魔彈射手的魔彈，只有在使用單髮式的步槍發射結構上獨自包含擊發藥和單一彈頭，並且擊發藥通過高速燃燒作爲發射動力的子彈時才能使用，具體由ST裁定哪些槍械符合要求。

**選開**：魔彈射手在使用魔彈時必須說出“衆生萬物，一律平等。我的魔彈，對誰也是一視同仁。”的臺詞，否則在檢定上承受-4DP的士氣減值。如果她一邊說出臺詞一邊射擊，那麼獲得+1DP的加值。

##  級　總綱

**價格**：D+1000

**能量池**：魔力

**技能樹**：開啓魔彈射手技能樹

**特性**：強化魔彈（四特性）

**特殊**：無。

**描述**

<ul>
<li>所謂魔彈射手，既是以魔力強化、操控子彈的魔術師。</li>
<li>魔彈射手的基礎在於通過將魔力滲透火藥，從而使彈頭帶上魔力，即便是普通的子彈，在魔彈射手的手中，也能發揮出驚人的威力。</li>
</ul>

**價格**：D+1000

**其他標籤**

**強化魔彈**

<ul>
<li>當你進行遠程槍械攻擊時，可以額外支付1點魔力，隨後你該次攻擊發射的彈藥視爲+4彈藥，並且在該次攻擊中你每應用了1個本流派技能樹下的能力，該彈藥的附魔等級便提升1級，最高提升至6級。應用了本流派技能樹下能力的攻擊所發射的彈藥被稱爲“魔彈”。</li>
<li>你每天最多隻能發射6發“魔彈”，若你當天發射的魔彈超過6發，則每一發的魔彈都會在你該次攻擊結束後以相同的攻擊效果與DP對你進行攻擊，如果你這次攻擊同時將目標與自己作爲攻擊目標一般。“魔彈”的使用次數會在每天0點時重置爲0。</li>
<li>使用“魔彈”時，你只能選擇單發，並且只能以實體彈藥爲彈藥的槍械纔可以發射“魔彈”。</li>
</ul>


### 穿刺魔彈

**價格**：D+500

**動作**：結合在一次遠程槍械攻擊中

**能耗**：1點魔力

**射程**：等同於武器的射程

**目標**：無

**範圍**：無

**持續**：立即

**描述**：無

**效果**：你該次攻擊獲得【貫穿】特性並增加3點【破甲】。

**增幅**：你每有1點傳奇智力，便可以額外支付1點魔力並使該次攻擊增加1點【破甲】。

**研發**：支付12XP進行研發，隨後你該次攻擊因【貫穿】特性所需減去的DP數值減半。

**價格**：D+500

**能耗**：1點魔力

**增幅**：你每有1點傳奇智力，便可以額外支付1點魔力並使該次攻擊額外再瞄準1輪。

**範圍**：無

### 死亡魔彈

**價格**：C+2000

**動作**：結合在一次遠程槍械攻擊中

**能耗**：15點魔力

**射程**：等同於武器的射程

**目標**：無

**範圍**：無

**持續**：立即

**描述**：無

**效果**

<ul>
<li>你該次攻擊若成功命中目標，則目標需要通過一個DC爲5的意志檢定，若其意志檢定通過則需要通過一個DC爲10的強韌檢定，若其意志檢定未通過則該強韌檢定的DC提升5點。</li>
<li>若目標沒有通過該次強韌檢定且強韌檢定成功數不低於DC的一半，則該次攻擊造成的傷害提升1級；若目標沒有通過該次強韌檢定且強韌檢定成功數低於DC的一半，則會立刻死亡，這是一個B級即死效果。</li>
<li>施展本能力後，你當天可使用的魔彈發數會直接歸零，此前每有1發未使用的魔彈次數，上述DC便全部提升1點。</li>
</ul>

**價格**：C+2000
