# 超鏈者

> 來源：`資源/稱號/流派/心智流派/超鏈者`

**本質**：特異本質

**前提**：沉着 3 ，電腦 3

**描述**

<ul>
<li>超鏈者是擁有神奇力量（如果這尚不屬於神祕領域的話）的一羣人。她們能在不借助其他科技產品的情況下連接到矩陣並操控它。她們不僅有這種看起來十分超自然的天資，也可以做到任何一臺電腦都做不到，或者根本不可能做到的事情。科學家和魔法研究者尚未查明超鏈者能力的原理，但他們都一致認爲其既不屬於科學範疇，也不屬於魔法。顯而易見，這一項未知的能力讓許多人對超鏈者的存在感到恐慌。事實上，一大部分人（尤其是跨國巨頭公司所屬的矩陣工程師們）認爲，“切開超鏈者的腦子看看”是一件很有趣的事情，她們對超鏈者的偏見由此可見一斑。</li>
<li>超鏈者生活在一個與我們不同的世界裏，那裏充滿了數據潮的起起伏伏。她們感受數據的流動，與圖標（ icon ）融爲一體。矩陣不過是她們生活的世界裏的一部分，她們在矩陣裏遨遊，正如普通人們在街上散步一般平常。即使是超鏈者她們自己，也不完全瞭解自己的原理――她們只是這樣做了，並得到了相應的結果。</li>
<li>憑藉她們天生的對電腦與矩陣的掌控力，幾乎所有的超鏈者都是程序員界的天才。在公衆眼裏，超鏈者們又詭異又反常。超鏈者們在一念之間就能通過矩陣聯絡（人們會說：以期破壞矩陣），這讓社會普遍懷疑超鏈者們可能正在策劃一項全球範圍的陰謀。每當矩陣裏有什麼地方出了岔子，尤其是出現大災難甚至死傷者的時候，“超鏈者威脅論”的幽靈就開始在各大新聞媒體發佈渠道再次出現。 GOD （ Grid Overwatch Division ，網域監管單位）追蹤超鏈者的代價比追蹤一個諜客（ Decker ）要高得多，於是正因爲此，一旦有事件被查明有超鏈者介入其中，它們絕不會姑息縱容。</li>
<li>諜客（未來的黑客）可能會被當做是一個水肺潛水員，用各種裝備潛入矩陣之中，再引領矩陣走向她們的期望；而超鏈者則更像魷魚之類的水生生物。矩陣就是她們天生適應的生活環境，她們運用矩陣也只是一種反射性的、直覺一般的行爲。她們不需要確定帶對了裝備，也不需在意裝備是否正確地被打開、連接到矩陣，更不用管它們運轉得是否正常。她們只是想做些什麼事，然後投身到周圍的數據流裏面去，最後完成它。僅此而已。</li>
</ul>

## D 級　超鏈者

**能量池**：無

**技能樹**：開啓 D 級共鳴詞庫

**特性**：血肉之軀（負特性），共鳴，衰褪（負特性），活體（三特性），超鏈感知（三特性）

**特殊**：由於沒有能量池，額外獲得 1 個特性。

**描述**

<ul>
<li>超鏈者掌握了同時處理現實世界與她們周身始終環繞着的數據流的能力。她們瞭解在信息高峯時保護自己免於被數據壓倒的方法；她們明白如何在干擾區或弱信號區防止自己受到壓抑或被強制退出；她們也懂得如何讓大腦成爲她們自己的操作系統，還在裏面集成了瀏覽器。只要有一個接入點，她們就能找到她們需要的一切，同時還能防止其他不需要的玩意，比如歌詞、股票價格、明星八卦等垃圾訊息進去把她們的腦子攪成漿糊。哦，當然，二百萬份的可愛小貓視頻（譯註： Videos of Kittens ，人類的愛好真是多種多樣）也進不去。</li>
<li>超鏈者的腦子究竟幹了些什麼――無數研究者都對這個課題趨之若鶩。事實上，她們的大腦掌握了基礎的矩陣協議和算法，所以她們看到矩陣裏的圖標的方式與那些使用裝備的用戶是一樣的。這對她們而言像是學習一門語言。一旦掌握了它，超鏈者們就很難想象沒有這種“詞彙表”的世界了。這種“語言”讓她們能看到圖標和疊加在真實物體上的 ARO （增強現實物體），也能讓她們墜入只屬於超鏈者的 VR 模式的一種失神狀態之中。</li>
</ul>

**注**：電子設備包括但不限於手機，電腦，伺服骷髏甚至是哈羅，具體可由 ST 裁定。

**其他標籤**

**血肉之軀**：雖說“機械不朽，血肉終腐”，但是意識上傳的本質不過是一場自殺。你無法進行任何機械類改造（包括但不限於蒼色騎士，人機改，機械戰警等，具體由 ST 裁定），否則你會立刻失去本稱號下的所有能力並且不可再次兌換本稱號。

**共鳴**：你在進行任何智力 + 電腦檢定時，你可以用沉着代替智力進行該次檢定。

**衰褪**：你每次施展超鏈者技能樹下的能力時，如果該能力需要進行檢定，則你在施展該能力後還需要進行一次 DC 爲該能力這次檢定成功數的意志檢定，若檢定未通過且成功數低於你的沉着值，則你會不可避免地受到差值的嚴重傷害，若檢定未通過但成功數高於你的沉着值，則你會不可避免地受到差值的衝擊傷害。

**活體**

<ul>
<li>你獲得一臺無形的虛擬計算機，可投射出全息界面進行操作而不用再攜帶常規計算機。此虛擬機實際上就是你的大腦，因此硬件能力取決於你的大腦開發程序，它能夠視作一臺支線等級 D 級的超越現代科技的電腦來使用和滿足一些前提。此虛擬機時刻與主神保持無線網絡連接，並可通過特異本質的電磁波與其他科技裝置進行有線或無線連接（可能需要投射出接口界面）。雖然它投射出的窗口及虛擬鍵盤等是無形的，但卻匪夷所思的可被所有者觸碰、點擊或拖動。虛擬機默認只接受你一人的操作。</li>
<li>你在電腦技能上獲得全部專業。當你成功使用“黑客入侵”行動入侵了一臺電子設備後，你每輪都可以花費標準動作進行一次沉着 + 電腦（黑客）檢定與該設備當前操控者的智力 + 電腦（防火牆）檢定進行對抗，如果該設備無人操控，則你需要通過一個 DC 等同於該電子設備支線等級（無支線算作 0.5 ，雙支線算作單支線） \*5 的沉着 + 電腦檢定，若你勝出或檢定通過，則可以對該設備造成差值的“矩陣傷害”，“矩陣傷害”是一種特殊的異常點數，該點數可疊加，每輪自動降低 1 點，一旦該點數超過了設備的結構值，設備就會暫時被“磚化”，持續至“矩陣傷害”低於其結構值，被磚化的設備會變成沒有任何作用的裝飾品。</li>
</ul>

**超鏈感知**：你能夠知道到所有位於你敏感範圍內的電子設備的具體位置，這是一個無支線特異本質的偵測能力，你在電腦技能上每有一個附加成功，便能使該偵測能力提升 1 級。你現在進行“黑客入侵”行動所需的時間減半，並且只要一臺電子設備仍有足夠的電量且沒有被破壞（通常指結構值耗盡，具體由 ST 裁定），即使該電子設備並沒有與你進行連接也沒有連接到網絡，你也可以對該設備進行“黑客入侵”（詳見技能說明）。

**設備**：在某片網絡中內置的裝備，負責某種功能的運行。它的範圍是可聯接網絡的，可接受信號指令並執行某種行動的裝置。比如手機，電腦等常見的設備，比如槍械上的未來火控系統，無人機上面的網絡功能，某些科技載具上的可連入網絡系統如導航儀等。再比如信息處理器，人機改的電子腦……等等，凡是可連入網絡並接收信息的物品，都可算得上是設備。

**衰褪**：超鏈者確實十分強力，但她們的力量並不是無窮無盡的。共鳴能力會消耗使用者的精神和肉體，濫用的話甚至會遭受崩潰一般的可怕後果。超鏈者們把這種耗竭稱作衰褪。

**共鳴詞庫**：超鏈者們創建自己的複合程序，然後共享它們（也有的傢伙不這麼幹）。最常見和常用的複合程序已經被編寫進了一個名爲共鳴詞庫的文件裏，這個文件在超鏈者們之間廣爲流傳。

**磚化**

<ul>
<li>如果一個設備的矩陣 CM 被完全填滿，這個設備就會停止運作。這便叫作設備的磚化。被磚化的設備決不會默默壞掉，相反，在整個磚化的過程中，它會冒煙、爆出火花和爆炸聲、嘶嘶作響、散發出難聞的焦糊味，偶爾還能看到小火苗跳出來。如果你正在使用意識接入網絡，而你意識替找的電腦卻被磚化，你就會被甩出矩陣並且遭受甩致休克。磚化的設備在被修好之前，一直是壞掉的狀態。</li>
<li>如果設備被磚化，它就會停止工作：電池被耗竭、零件被熔接在一起等。注意，並非所有設備都會在磚化後完全變成廢物。振動劍（ Vibrosword ）依舊鋒利，滑降地面的旋翼無人機（ roto-drone ）的自轉旋翼正常發揮作用，鎖着的鎖還是鎖着。突擊步槍上的撞針可能不起作用，但它的刺刀依然足以把正沾沾自喜的黑客刺個對穿。而且顯而易見，你不能黑掉一柄打刀，對吧？最後，如果你的豪華座駕被磚化了，它還有希望――如果你認識一個好技師的話。</li>
<li>超鏈者是如何運用他們能力的這件事依舊迷霧重重。儘管沒有公司能夠估計出他們的確切人數（因爲他們中許多選擇留在地下而不暴露他們的天賦），但普遍認爲超鏈者比施法者還要少見。</li>
<li>因爲對超鏈者的瞭解極爲淺薄，世界上很多人懼怕他們和他們的才能。在流行文化中，他們的能力被誇張到極致（比如謠傳他們能關閉數個街區內的每個電子器械），有些團體懸賞他們的人頭。許多公司想要研究超鏈者，進行實驗勾勒出他們的才能，發現更好地理解甚至複製他們能力的方法。其他團體只是想要他們死。超鏈者的法律權利模糊不清、模棱兩可，很多時候是有意爲此。對超鏈者來說， 2075 年的世界充斥着敵對的態度，有時還會非常危險。許多超鏈者帶着電子板的仿製品來冒充傳統的碟客。他們通常爲了保護祕密不被發現而什麼事都敢做。</li>
</ul>
