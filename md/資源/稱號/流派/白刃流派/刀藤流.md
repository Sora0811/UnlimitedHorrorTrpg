# 刀藤流

> 來源：`資源/稱號/流派/白刃流派/刀藤流`

**本質**：特異本質

**作者**：刀藤綺凜

**描述**：刀藤流作爲近代流派，專注於一對一決鬥的特化，有着“宛如折鶴”的美名，亦即如同摺紙鶴般準確順序的連續揮劍，其奧義“連鶴”便是那種精隨的體現。以四十九種連技組成的無限連斬奧義“連鶴”，號稱沒有終點、沒有極限，無論對方如何防禦如何閃躲都能夠持續出招追擊對手，並非以一招定勝負，而是以無間隙無間斷的連續追擊直到戰勝對方爲止。

##  級　刀藤流總綱

**價格**：B+2000

**能量池**：星辰力

**技能樹**：開啓刀藤流劍技

**特性**：從容不迫，洞悉萬明（雙特性），急速閃刃

**特殊**：無

**價格**：B+2000

**其他標籤**

**從容不迫**：無論遇到什麼樣的戰況，刀藤流的傳承者總能在第一時間做出最好的應對。你進行近戰白刃攻擊時，從宣言你所選中的攻擊目標開始到你此次攻擊的傷害結算完畢爲止，在此期間你不會被來自敵人的反射動作插入你的行動。

**洞悉萬明**：隨着戰鬥的進行，敵人的動作會被一點點的看破。當從你進入戰鬥時，每回合開始，你的攻擊檢定和防禦便增加你傳奇感知/點洞察加值，最高不超過18點。當戰鬥結束，這些加值會立即失去。

**急速閃刃**

<ul>
<li>刀藤流的所有招式，都有着令人難以應對的速度。你在進行近戰白刃攻擊時，會獲得18點高速效果，若你原本便具備等額或者更高的高速，則改爲你的高速增加9點。</li>
<li>刀藤流劍技</li>
</ul>


### 刀藤流拔刀術——『折羽』

**價格**：B+2000

**動作**：標準

**能耗**：5點星辰力

**射程**：觸及

**目標**：一個目標

**範圍**：無

**持續**：立即

**描述**：刀收入鞘中才能使用的居合斬，會使敵人產生幻覺想象，明明沒有拔刀，卻令敵人認爲已經拔刀，而後真正出鞘，劃出劍閃，對敵一擊必殺。不過它的本質在於以視線、呼吸或預備動作等身體姿勢引誘對手。而窮究這一本質的劍技就是刀藤流拔刀術——明明沒有拔刀，卻讓對手以爲拔刀的虛像之劍。

**效果**

<ul>
<li>你必須使用細長且體積不大於人物自身體積-2點的曲刃劍（如武士刀、脅差、軍刀、馬刀、阿拉伯彎刀等，具體由ST裁定）才能使用本技能。</li>
<li>你進行一次近戰白刃攻擊，在此次攻擊檢定之前，你先進行一次敏捷+白刃檢定，並將檢定成功數作爲招式加值增加到這次攻擊檢定中；並且你可以再選擇消耗一個迅捷動作用敏捷屬性代替智力屬性進行一次虛招；這次攻擊你無法使用傳奇操控的重骰或者其他同類別能力，你必須接受攻擊檢定結果，但是你可以額外獲得等同自身傳奇沉着/個附加成功。</li>
</ul>

**價格**：B+2000

### 千里眼

**價格**：B+2000

**動作**：反射動作

**能耗**：5點星辰力

**射程**：無

**目標**：自身

**範圍**：無

**持續**：耐力值/輪

**描述**：集中精力，排除一切雜念，以極大的星辰力消耗與對眼睛的損耗爲代價，感受生命力與星辰力流向，從而預判對手的行動軌跡予以反擊。

**效果**

<ul>
<li>你強化自己的眼瞳，在持續時間內，你的攻擊檢定和防禦分別獲得12DP無名加值；</li>
<li>你獲得B級別的免疫措手不及能力；</li>
<li>當你受到近戰攻擊時，並且攻擊你的敵人處於你觸及範圍內，你可以消耗反射動作和5點星辰力，立即對敵人發動一次不能附帶任何技能或者招式的白刃攻擊。</li>
</ul>

**價格**：B+2000

### 嘴食

**價格**：B+2000

**動作**：見下

**能耗**：5點星辰力

**射程**：敏捷值\*20米

**目標**：單體

**範圍**：無

**持續**：立即

**描述**：用投槍姿勢將日本刀投擲出去，隨後通過快速的移動接近敵人再拿起武器對其進行狂風暴雨般的攻擊，爲了剋制遠程攻擊類型的敵人而使用的先擾亂對方再迅速接近的方法。

**效果**

<ul>
<li>你以標準動作進行一次投擲武器攻擊檢定，這次攻擊不會造成任何傷害，但是會使目標的防禦降低此次攻擊檢定成功數/點，按照基本防禦、閃避防禦、格擋防禦的順序依次降低，最低到0，持續一輪，若目標的防禦因此降低到0，則你可以宣言對其的下一次攻擊是一次致命攻擊；</li>
<li>之後，你以移動動作進行一次移動，這次移動只能沿着直線移動，但是你可以移動正常移動距離兩倍的距離，若你此次移動成功進入到近戰白刃攻擊觸及範圍，則你可以無需任何動作立即接住自己的武器並且對其進行一次攻擊，這次攻擊你獲得16DP招式加值。</li>
<li>注意，若你的武器不具備回力特性，且你未能接住自己的武器（如被其他目標接走），這可能會導致你遺失自己的武器。</li>
</ul>

**價格**：B+2000

### 刀藤流奧義—— 『連鶴』

**價格**：A+4000

**動作**：標準動作

**能耗**：7點星辰力

**射程**：觸及

**目標**：一個目標

**範圍**：無

**持續**：立即

**描述**：刀藤流奧義。擁有四十九種的連續技，完全不給對方喘息的機會，不停連續斬擊，透過呼吸與間距、視線等細微引導，封住對手的反擊，創造壓制對手的情況，直到擊敗對方。四十九種技能分別爲「拾餌」、「釣船」、「妙妙」、「妹背山」、「八橋」、「昔男」、「樂樂波」、「迦陵頻」、「芙蓉」、「熊谷」、「風車」 、「村雲」、「吳竹」、「夢經路」、「久萬里」、「布曬」、「四衣袖」、「衝羽翅」、「青海波」、「澤瀉」、「比翼」、「瓢簞町」、「鶴鴒」、「三巴」、「雛戲」、「鼎」、「寄木」、「花橘」、「蓬萊」、「花見車」、「鳴子」、「花菱」、「百鶴」、「早乙女」、「三分一」、「蕣」、「橫雲」、「莊子」、「巢籠」、「相生」、「風蘭」、「葭原雀」、「春曙」、「龍膽車」、「蟻塔」、「野幹平」、「杜若」、「瓜蔓」、「稻妻」。沒有終點、沒有極限，無論對方如何防禦如何閃躲都能夠持續出招追擊對手，並非以一招定勝負，而是以無間隙無間斷的連續追擊直到戰勝對方爲止。

**效果**

<ul>
<li>你進行一次近戰白刃攻擊，在這次攻擊之前，視爲你已經分別使用36種不同的劍技進行了一次攻擊，對於該次攻擊，目標無法使用防禦上的附加成功；並且會忽略目標的一切防禦上的洞察和招式加值。若目標的基本防禦、閃避防禦和格擋防禦因此被降低到0或以下，則這次攻擊是一次致命攻擊。</li>
<li>若你攻擊的單位免疫多次攻擊減值，則你以敏捷+白刃（彎刀）對抗目標的感知+白刃（白刃格擋），若你成功，則你可以無視目標的免疫多次攻擊減值的能力。</li>
</ul>

**研發**：連鶴的攻擊比肩隨踵，沒有窮盡之時，在一次次的精研和練習之中，你愈加的精煉自己的技藝。每投入2XP，你使用連鶴就視爲多進行了一次攻擊；當你的連鶴的追擊次數超過49次之後，你的攻擊會附帶等同自身敏捷屬性/點高速。

**價格**：A+4000

### 連鶴·新

**價格**：A+4000

**動作**：被動

**描述**：將“連鶴”與“千里眼”結合，連對手的行動都算入了連續攻擊的順序中，不論對手嘗試如何反擊或閃躲，都能立即對應，化爲“連鶴”的一部分。

**效果**：當你處於“千里眼”狀態下，發動招式“連鶴”時，你的“連鶴”額外獲得36點招式加值；並且你以連鶴成功造成傷害後，你的目標的攻擊檢定失去你造成傷害數/點DP，並且防禦降低等額於此次傷害數/點，按照基本防禦、閃避防禦、格擋防禦的順序依次失去，持續一輪。

**價格**：A+4000

**其他標籤**

**強化前提**：學會“連鶴”和“千里眼”
