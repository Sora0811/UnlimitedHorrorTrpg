# 流派――塵埃劍典

> 來源：`資源/稱號/流派/白刃流派/塵埃劍典`

**本質**：特異本質

**前提**：需求白刃技能3，沒有劍氣能量池，擁有任意生理能量池，使用本劍典下的所有技能時，必須使用不超過自己體積的長劍，重劍，突刺劍。

**描述**

<ul>
<li>此劍本是塵埃劍，因君名天下</li>
<li>一簇塵埃憑空凝形，如你手中之劍，只爲削平世間，只爲削平你心中這不平之事。</li>
</ul>

**特殊**

<ul>
<li>本劍典爲落於塵埃中人的絕戾之劍與劍修不可共存</li>
<li>無</li>
</ul>

**價格**：C+1000

**能量池**：無

**技能樹**：開啓塵埃劍典技能樹

**特性**：平生榮顯落塵埃， 秋蟬先覺（雙特性），破敵

**價格**：C+1000

## 困龍淺談私恨生

**價格**：D+500

**動作**：被動

**描述**：塵劍如龍，淺灘私恨，魚蝦撕咬，榮辱兩難

**效果**：當你使用“平生榮顯落塵埃”時，能耗變爲3點，並且若使用本招式對敵人造成至少1點傷害時，會在敵人體內埋下一分“怨毒”，“怨毒”在你回合結束時爆發，使敵人再受到等同於你白刃等級帶來的附加成功數/點褻瀆傷害。

**增幅**：你每額外支付1點能量可以令你的攻擊增加2高速、2破甲或者2點破魔（三選一），支付上限爲你的白刃等級帶來的附加成功數+1。

**價格**：D+500

## 逆行剝鱗斷撕血

**前提**：“困龍淺談私恨生”

**價格**：C+1000

**動作**：被動

**描述**：斷血剝鱗生新肌，白骨覆肉入人間

**效果**

<ul>
<li>當你使用“平生榮顯落塵埃”時，能耗變爲5點，並且若使用本招式對敵人造成至少1點傷害時，你獲得1點血肉精華。每場景你能獲得的血肉精華上限爲白刃等級帶來的附加成功數\*2，切換場景時未使用的精華則直接消散。</li>
<li>你有兩種方法可以使用血肉精華：</li>
<li>\1.無需動作，消耗1點血肉精華使自己的1點傷害轉爲完好。</li>
<li>\2.使用塵埃劍典的技能增幅時使用血肉精華來進行增幅，每使用1點血肉精華則獲得2點生理系能量池的增幅效果，但是每點血肉精華只佔用1點增幅上限。</li>
</ul>

**價格**：C+1000

## 黃泉路上挑君行

**前提**：“逆行剝鱗斷撕血”

**價格**：B+2000

**動作**：被動

**描述**：黃泉路上明月夜，攜君同歸望鄉臺，曾落塵埃拜君手，還君五衰墜三花。

**效果**

<ul>
<li>當你使用“平生榮顯落塵埃”時，能耗變爲7點，此時，你在攻擊時你可以選擇每對自己造成1點不可避免的嚴重傷害，使本次攻擊獲得3DP的表現加值，對自己造成傷害的上限爲你的白刃等級。</li>
<li>你可以選擇對自己造成更多嚴重傷害來在本次攻擊中換取更多表現加值。當你對自己造成的嚴重傷害超出你的白刃等級時，你每對自己造成2點嚴重傷害，便能使本次攻擊獲得3DP的表現加值；當你對自己造成的嚴重傷害超出你的白刃等級的2倍時，則你每對自己3點嚴重傷害，便能在本次攻擊中獲得3DP的表現加值，以此類推。</li>
<li>若你對自己造成的傷害超過白刃等級，則針對本次攻擊，目標陷入A級措手不及。</li>
<li>若你對自己造成傷害超過白刃等級的兩倍，則你可以再額外進行一次的白刃攻擊，這不視爲同一次攻擊。</li>
</ul>

**價格**：B+2000

## 過去莊嚴劫

**前提**：習得“黃泉路上挑君行”

**價格**：B+2000

**動作**：被動

**能耗**：5點生理系能量

**效果**

<ul>
<li>當你使用“平生榮顯落塵埃”時，你可以發動本能力。</li>
<li>此時， 你本次攻擊可以直接攻擊敵人的過去身，你最多可以攻擊他前X輪內的過去身（X爲你的 白刃等級帶來的附加成功數 ）。</li>
<li>其過去身防禦維持在他前X輪的防禦（即你在第二輪時攻擊其第一輪的過去身，則第二輪時他的buff不會生效）。</li>
<li>過去身可以使用反射動作，但前提是他所在的前X輪仍有剩餘的反射動作，過去身所受的傷害和消耗的能量會1：1映射到現在身上，若過去身在前X輪用反射動作使用了buff，那麼這個buff若持續時間足夠也會出現在現在身上。</li>
</ul>

**特殊**：由於本能力計算起來特別麻煩，所以ST有權禁止PC使用和兌換本能力。若禁止使用或者兌換，則“塵埃大破滅”的前提中，不包括本技能。

**效果**

</ul>

**其他標籤**

**平生榮顯落塵埃**：你使用1點生理系能量，花費1個標準動作，對你本次攻擊關鍵屬性\*10米的一個目標進行一次白刃攻擊。

**秋蟬先覺**：當你持握對應的武器時，你獲得C級魔幻本質的偵查能力，並且你可以用塵埃劍典的攻擊檢定代替偵查檢定。

**破敵**：當你以塵埃劍典進行攻擊檢定後，你可以選擇每消耗兩點成功數，忽略一點敵人的減傷能力（傷害吸收、傷害減免、傷害抵消、傷害忽略）。
