# 流派

> 來源：`資源/稱號/流派/白刃流派/疾風劍術`

**本質**：魔幻本質

**前提**：需求敏捷6以上，白刃技能3以上

**描述**

<ul>
<li>“且隨疾風前行，身後亦需留心。”――亞索</li>
<li>疾風劍術是來自瓦羅蘭大陸一種精絕的劍術，修習者會獲得風的力量</li>
</ul>

**特殊**：你必須使用體積不大於2，分類爲“劍”或“刀”（包括但不限於長劍，短劍，彎刀等）才能施展和獲得本流派下所有能力的效果，你的體積每比5高5點，可應用於本流派的武器體積上限便提升1點。

##  級　浪客之道

**價格**：C+2000

**技能樹**：開啓疾風劍術技能樹

**特性**：疾風劍客、劍術大成、百折不撓（雙特性）

**特殊**：無

**描述**：長路漫漫，唯劍作伴。

**價格**：C+2000

**其他標籤**

**疾風劍客**：疾風之道使你的速度出類拔萃，你的先攻檢定增加6點。

**劍術大成**：你的白刃技能提升1級，上限爲7.

**百折不撓**：你開啓一個特殊的刻度，名爲劍意槽，劍意槽的上限等同於你的傳奇敏捷\*2點。你每累計主動移動50米的距離，便可增加劍意槽上限/4點劍意（向上取整），劍意達到刻度上限後，當你受到傷害時劍意槽會被清空，隨後你獲得等同於劍意槽上限\*1點臨時生命，該臨時生命值視作在你受到該次傷害前獲得，並且可反覆獲得，但其每輪自動減少1點，在該臨時生命被耗盡之前你無法再通過移動的方式來獲得劍意。


### 斬鋼閃

**價格**：D+1000

**動作**：標準動作

**能耗**：無

**射程**：見下

**目標**：一個目標

**範圍**：無

**持續**：立即

**描述**：此劍之勢，愈斬愈烈。

**效果**

<ul>
<li>你對你武器觸及範圍內一名單位進行一次近戰白刃攻擊，該次攻擊具備【貫穿】特性，並且該次攻擊只要成功命中任意一個目標，你便可以獲得1層“旋風烈斬”，“旋風烈斬”最多隻能擁有2層，持續2輪，獲得“旋風烈斬”層數時會重置其持續時間。</li>
<li>若你已擁有2層“旋風烈斬”，當你施展本招式時，你會自動消耗2層“旋風烈斬”，隨後該次攻擊的觸及範圍提升你的傳奇敏捷\*3米，若你該次攻擊成功命中目標，目標還會被朝空中垂直擊飛1米，被擊飛的目標需要通過一個DC爲你該次攻擊傷害值的力量+運動（平衡感）檢定，其體積每比5高1點便可以在該次檢定中獲得1個附加成功，若其檢定未通過且不具備懸浮能力或飛行能力，則會陷入“浮空”狀態，持續1輪。</li>
</ul>

**價格**：D+1000

### 踏前斬

**價格**：C+1000

**動作**：迅捷或反射動作

**能耗**：1點意志力

**射程**：傳奇敏捷\*5米

**目標**：一個目標

**範圍**：無

**持續**：立即

**描述**：不可久留於一處。

**效果**：你選擇一名位於觸及內的目標，隨後立刻移動至與其鄰接的格子並對其造成等同於你傳奇敏捷/點物理衝擊傷害，該傷害具備【魔法】特性，若其爲友方目標，則不會對其造成傷害；在通過此法移動的過程中，你可以隨時施展本流派下的“斬鋼閃”（你必須在回合外擁有可以透支標準動作的能力纔可以透支標準施展本能力），若你如此做，則你該次“斬鋼閃”失去【貫穿】特性，但目標改爲你觸及範圍內的所有敵方目標，這意味着你該次“斬鋼閃”可以對觸及範圍內的敵方目標分別進行一次攻擊。

**價格**：C+1000

### 風之障壁

**價格**：B+2000

**動作**：標準動作

**能耗**：無

**射程**：觸及

**目標**：無

**範圍**：見下

**持續**：1輪

**描述**：形成一個氣流之牆，可以阻擋敵方的所有遠程攻擊。

**效果**

<ul>
<li>你可以在射程內的任意一個位置製作一面風牆，風牆的長度與高度皆爲3米，厚1米。僅針對敵方目標的遠程攻擊，風牆視同能夠提供完全掩蔽效果的掩蔽物。</li>
<li>你可以花費反射動作並額外支付3點意志力來施展本能力。</li>
<li>施展本能力後，你需要再經過3個回合才能再次施展本能力。</li>
</ul>

**價格**：B+2000

### 狂風絕息斬

**價格**：B+2000

**動作**：標準動作

**能耗**：無

**射程**：敏捷\*50米

**目標**：一個目標

**範圍**：見下

**持續**：立即

**描述**：不是你死，就是我亡。

**效果**

<ul>
<li>本招式僅能對位於空中的單位施展，並且在施展後你需要再經過5個回合才能再次施展本招式。</li>
<li>你立刻傳送至與目標鄰接的位置並對其進行一次近戰白刃攻擊，若成功造成傷害，則額外對目標造成等同於該次攻擊傷害值的失速點數，目標以強韌檢定豁免。</li>
<li>隨後，你獲得2層“旋風烈斬”並立刻填滿劍意槽，同時進入“絕息”狀態。</li>
<li>當你位於“絕息”狀態下時，你的近戰白刃攻擊在計算破甲值之前，可以視同已擊破目標當前一半的硬度、盔甲防禦、天生防禦與盾牌防禦，如同你該次攻擊已擁有這麼多的破甲一般，“絕息”狀態持續2輪。</li>
<li>特殊的，如果你通過“斬鋼閃”將目標擊飛，則你可以立刻花費一個移動動作對該目標施展本招式。</li>
</ul>

**價格**：B+2000
