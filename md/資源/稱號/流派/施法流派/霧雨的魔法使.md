# 霧雨的魔法使

> 來源：`資源/稱號/流派/施法流派/霧雨的魔法使`

**本質**：魔幻本質

**描述**

<ul>
<li>幻想鄉人間之裏的霧雨魔理沙的職業。</li>
<li>這個魔法使本身並不算特別優秀，但其中包含了那名住在幾乎不會有人類到訪的魔法森林中，終日埋頭研究魔法的普通的魔法使所開發出的魔法體系。其特徵是擅長光和熱的魔法，以及用蘑菇進行的鍊金術。不止十分華麗而且火力強大，在破壞力上少有弱點，在效果上偶爾也能誕生出不可思議的奇蹟。</li>
</ul>

## D 級

**能量池**：魔力

**特性**：魔法使之血（雙特性），彈幕射擊，蘑菇鍊金

**技能樹**：開啓專有法術

**特殊**：無

**其他標籤**

**魔法使之血**：霧雨家代代流傳的魔法使血統讓你獲得了魔法力體質，你可以學習本稱號技能數下的所有法術，但是必須遵循魔法力體質學習法術的前提要求。

**彈幕射擊**：彈幕遊戲就是由幻想鄉的少女們所創造的。你獲得 D 級能量射擊術，能量綁定爲魔力。

**蘑菇鍊金**

<ul>
<li>霧雨的魔法使的魔法的原料是各種各樣的蘑菇。經過獨方調配的煮熬，煮成湯汁。湯汁再加幾種材料調配，曬乾成固體。將固體物加熱，變回山之水後，進行各種實驗，有時能發動十分稀罕的魔法。</li>
<li>你現在可以向主神購買材料，並且如同製造科技物品一般製造魔幻本質藥水，神油和毒藥類的消耗品。需要正常研讀圖紙，解讀圖紙需要神祕學（鍊金），你獲得手藝 - 鍊金子技能。</li>
</ul>

**魔理沙的魔法冊**：霧雨的魔法使的魔法實驗都會被詳細地記錄成冊，以作日後的改進更正。


### D 級法術：

**威力值**：2

**消耗**：1

**專業**：塑能

**成分**：語言，姿勢

**動作**：標準

**射程**：10 米錐形

**持續**：立即

**描述**：向前方亂射出大量七彩繽紛的星形魔力散彈進行攻擊。

**效果**：區域內的所有目標受到威力值 + 神祕學等級的光能嚴重傷害，反射豁免，你進行施法檢定，每有一個成功數，則目標的反射檢定失去 1DP 。

**增幅**：當血統等級在 C 級時，你可以選擇額外支付 1 點魔力，將魔力散彈的掃射維持到下一輪你的行動開始時。任何在此期間進入你法術範圍的生物也會受到傷害。

**消耗**：3

**成分**：語言，姿勢，器材（魔法掃帚）

**動作**：整輪

**射程**：智力 \*10 米

**持續**：立即

**描述**：以魔力強化掃帚，並將魔力從掃帚尾部噴射加速的突進攻擊法術。

**效果**

<ul>
<li>這視爲一次衝鋒攻擊，本次衝鋒你獲得的額外 DP 上限不由力量而是由敏捷來決定，而且你用施法檢定取代近戰攻擊檢定來進行這次攻擊。同時，你每因衝鋒獲得 1DP ，本次攻擊提升 1 高速，至多提升 5 高速。</li>
<li>你的敵人受到你檢定成功數的穿刺或光能傷害可由你自行選擇，而且必須與你造成的傷害進行反射豁免對抗，如果失敗則會被擊飛。擊飛距離爲你在這次對抗中的成功數 / 米，每被擊飛一米會讓他在他的下一次行動之前，減少同樣數量的基礎防禦。</li>
<li>除非擁有免疫倒地的能力，否則被擊飛會讓敵人倒地。</li>
<li>這個法術結束之後，你會自動被彈開，遠離敵人檢定成功數 / 米。</li>
</ul>
