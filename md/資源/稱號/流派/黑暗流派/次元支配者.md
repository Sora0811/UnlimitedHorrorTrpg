# 暗撫-次元 支配者

> 來源：`資源/稱號/流派/黑暗流派/次元支配者`

**本質**：特異本質

**價格**：C+2000

**能量池**：妖力

**技能樹**：開啓 暗撫-次元 支配者技能樹

**特性**：黑暗生物（負特性），妖魔技能，次元支配（四特性）

**描述**：可以用妖力造成次元變異，位移，震盪，相轉，凍結等等各種效果。

**價格**：C+2000

**價格**：D+500

## 無間之道

**價格**：D+500

**動作**：移動動作

**能耗**：1點妖力

**射程**：敏感範圍中的一個點

**目標**：所有目標

**範圍**：邊長爲風度值/米的正方形

**持續**：耐力值/輪

**描述**：操作次元變異，使實際距離拉長或縮短的能力

**效果**

<ul>
<li>你進行一次智力+神祕學（空間）檢定，並選擇拉長或縮短的效果，所有範圍內生物的移動速度都會下降或提升相當於你判定結果/米，效果必須在施展時確定，之後不可改變。這不會增加該生物的基礎移動速度，而且增加當前該生物移動方式的移動速度。</li>
<li>若該空間的中心點處於你的敏感範圍內，則你可以花費1個移動動作來改變該空間的位置。</li>
<li>你同時可以製造相當於你傳奇耐力/個“無間之道”。</li>
</ul>

**價格**：D+500

## 幽影手

**價格**：C+1000

**動作**：迅捷動作

**能耗**：3點妖力

**射程**：敏感範圍

**目標**：見下

**範圍**：見下

**持續**：1輪

**描述**：你可以將應用於你移動的次元摺疊方式應用到你的肢體上。

**效果**

<ul>
<li>你將手伸入次元摺疊中，直接出現在射程範圍內一點的位置上。</li>
<li>你必須能以某種方式觀察着手出現的位置，若你進行需要手的活動，活動的原點爲你手出現的位置，若你能直接以視覺看到你的手，用它進行行動時相關檢定承受5DP無名減值，若你以其他方式觀察，則改爲承受10DP無名減值。</li>
<li>當你在本場景第一次使用本能力時，若你使用本能力後直接對目標以該手進行攻擊，則目標必須進行一次感知+調查（偵查）檢定來對抗你的敏捷+隱藏（躲藏），如果目標失敗，則本次攻擊目標陷入B級措手不及。</li>
<li>施展本能力後，你選擇傳送出去的手會出現在對應的位置上，所以在持續時間內，你無法用傳送出去的手對周邊的情況進行相關行動。</li>
<li>你在施展時，可以選擇傳送1隻手或者2隻手。</li>
</ul>

**價格**：C+1000

## 次元斷離

**價格**：C+1000

**動作**：整輪動作

**能耗**：3點妖力

**射程**：敏感範圍

**目標**：見下

**範圍**：無

**持續**：立即

**描述**：在已經存在的物質上引發偏差，從而粉碎物質結構的能力。

**效果**

<ul>
<li>對於任何有活動能力的事物而言，都會由於偏差的引發點無法計算而無法使用這個能力（例如生物，正在被使用的物品載具等），但對於無法活動的物體或在固定範圍內無須使用者維持就持續性生效的能力（如多數結界，以及持續性範圍傷害等）而言則是天敵。</li>
<li>當你以無法移動（行動）的物品爲目標時，你以智力+神祕學（空間）作爲遠程攻擊檢定，本次攻擊無視物品的硬度，直接對物品的結構值造成傷害。</li>
<li>當你以無法移動（行動）的結界，持續性效果爲目標時，你以智力+神祕學（空間）對抗施展該結界或者持續效果目標的施展檢定，若目標沒有施展檢定則用目標的意志。若目標失敗，則該效果立即被你解除。</li>
<li>請注意，本效果的目標爲無法移動的，若此時一臺正在作戰的載具陷入無法行動的狀態中，或者一個有持續性效果的生物保持不動，則也可以對其施展本效果。</li>
<li>無論如何，你無法對活物施展本效果。</li>
</ul>

**價格**：C+1000

## 次元錨

**價格**：B+2000

**動作**：標準動作

**能耗**：5點妖力

**射程**：以自己爲中心

**目標**：除你以外所有目標

**範圍**：模糊範圍

**持續**：1小時

**描述**：鎖定你可傳送範圍之內的所有次元。

**效果**

<ul>
<li>啓動後，任何試圖以傳送形式進行移動的移動方式在進入範圍內或者在範圍內移動時，該能力的使用者必須以意志豁免檢定對抗你的智力+神祕學（空間）。若你成功，則外界進入的傳送會被強制停在次元錨的邊緣，內部進行的移動則會失敗。並且該次移動的動作，能耗等皆不返還。</li>
<li>無論這次對抗的成敗，你都會意識到有人試圖使用空間傳送移動能力，以及傳送的起點和落點（如果落點在你次元錨的範圍內）。 你最多同一時間創造出相當於你傳奇風度/個次元錨。</li>
<li>這是一個B級空間能力。</li>
</ul>

**增幅**：你每有1點傳奇耐力，則可以額外支付1點妖力，令本能力多維持1個小時。

**價格**：B+2000

## 惡意轉移

**價格**：B+2000

**動作**：標準動作

**能耗**：5點妖力

**射程**：見下

**目標**：一個目標

**範圍**：無

**持續**：立即

**描述**：操作次元發生位移，使目標強制移動的能力。

**效果**

<ul>
<li>本能力有兩種用法：</li>
<li>\1. 你進行一次智力+神祕學（空間）檢定，目標進行意志豁免對抗。若你成功，則你可以將目標傳送在你模糊範圍內的任何一個位置。若目標自願，則無需對抗。傳送的目標地點與你必須有效果線。</li>
<li>\2. 你選擇你敏感範圍內的兩個目標，你進行一次智力+神祕學（空間）檢定，兩個目標分別進行意志豁免對抗。若你全部成功，則你可以令兩名目標交換位置。若成功的以此應對攻擊，攻擊的目標將變爲新的目標，除非攻擊本身具有追蹤能力。若目標自願，則無需對抗。傳送的兩個目標以及與你之間必須有效果線。</li>
<li>這是一個B級空間能力。</li>
</ul>

**增幅**

<ul>
<li>若你採用第一種用法，則你每擁有1點傳奇風度，則你可以在施展本能力時額外花費5點妖力，額外傳送一個目標。</li>
<li>若你採用第二種用法，則你可以在施展時額外花費3點意志力，以反射動作啓動本能力。</li>
</ul>

**價格**：B+2000

## 次元凍結

**價格**：B+2000

**動作**：全回合動作

**能耗**：5點妖力

**射程**：以自己爲中心

**目標**：除自己以外所有目標

**範圍**：敏感範圍

**持續**：1輪

**效果**

<ul>
<li>啓動後，範圍內的所有空間和時間遭遇凍結。</li>
<li>只有你能夠如常行動。</li>
<li>任何單位（包括你自己）不能做出任何需要選定此次元中目標（如單體攻擊）或選定目標地點（如範圍攻擊）的行動，除非目標爲你自身或目標地點爲你所在位置。但由於次元的凍結你即使做出以自身爲範圍的範圍攻擊，除了對你自身的結果之外，對其他人的結果要到解凍之後才計算，次元凍結的輪數中所有其他效果都不計算持續時間。</li>
<li>這是一個B級空間和時間（時間停止）的效果。只要有一個免疫即可無視本能力。</li>
</ul>

**增幅**：你每同時擁有1點傳奇耐力和傳奇風度，則施展本能力時，可以額外花費1點意志力，每額外花費1點意志力，則施展本能力的動作下降1級（全回合動作――整輪動作――標準動作――移動動作――迅捷動作――自由動作）。

**價格**：B+2000
