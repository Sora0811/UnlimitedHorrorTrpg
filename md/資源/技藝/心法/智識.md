# 智識 10 XP

> 來源：`資源/技藝/心法/智識`

**動作**：迅捷

**類別**

<ul>
<li>心法</li>
<li>探尋敵人弱點的方法是獲勝的法門。你獲得了以自身的修爲去尋找敵人所畏懼之物的法門。只要你能夠看到敵人，就可以使用這一能力，但每一場景對每一敵人只能使用一次。用【智力＋白刃】的一半作爲 DP ，不同的成功會獲得不同等級的信息。此外，若你明確知道對方的弱點，並針對弱點攻擊，則你可以將智識判定的成功數加在攻擊判定上，這是洞察加值，這一效果持續一個場景。</li>
</ul>

**特殊**：智識的檢定無法使用意志力的基礎用法。

## 成功數 效果

**其他標籤**

**進化技**

<ul>
<li>七曜之氛</li>
<li>12XP</li>
<li>以一個迅捷動作，消耗 3 點能量，你可以使一個 5 米 / 感知值內的隊友與你共享“智識”帶來的好處。</li>
</ul>


**正文**

1 人所共知的弱點（人被砍下頭或刺穿心臟就會死）（你不需要知道目標是人類就可判斷出這一弱點

3 比較著名的弱點（吸血鬼怕陽光、心臟被木樁刺穿會死、狼人怕銀）（你不需要知道目標是吸血鬼或狼人）

5 一般的弱點（擊破對方 DR 的方法、對方能力抗力所不能抵抗的能量、身上不具備防彈特性的部位等）

8 較難攻破的個體化的弱點（看出阿基利斯的弱點在跟腱、齊格弗裏德的弱點是後心葉痕、紫龍的弱點是龍紋的右爪）

**其他標籤**

**消耗能量**：2 或 DC2


**正文**

武學的修爲亦是無上的智慧，擁有看破敵人之弱點的能力，體弱者亦能獲勝。
