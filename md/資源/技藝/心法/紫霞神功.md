# 紫霞神功（心法）

> 來源：`資源/技藝/心法/紫霞神功`

**介紹**：武林中盛稱的華山派“紫霞功”，這門內功初發時若有若無，綿如雲霞，然而蓄勁極韌，到後來更鋪天蓋地，勢不可當，“紫霞”二字由此而來。

**價格**

<ul>
<li>C+1200</li>
<li>習得此功法必須先具有高深內功修爲，修行者至少需要具有一門等級 C 內功強化，來滿足紫霞神功消耗。</li>
<li>紫霞神功可以用化解體內的異常狀態，以一個迅捷動作運行真氣，你可以重新對身上異常狀態進行一次豁免檢定，並且在此檢定上獲得如同你內力等級附加成功。</li>
<li>這種用法消耗如同你內力等級相當的內力。</li>
<li>你也可以運起紫霞神功對自己某些行動進行基於生理屬性或感知屬性的一個判定增強。這種用法需要一個迅捷動作啓動，維持是一個自由動作，每輪消耗如同你內力等級 + 維持輪數的內力值，可使你在此回合相關判定上獲得本輪紫霞神功所消耗內力相同附加成功數。</li>
<li>此用法可持續的輪數不能超過你的內力關鍵屬性中較低那個，或是你的內力耗盡之時，維持最多不能超過一個場景。</li>
<li>修煉成紫霞神功會使你的外表年齡變得年輕，並從此駐顏有術，自然壽命得到小幅度的延長。當你運起紫霞神功時，你的臉上會佈滿紫氣，這個特徵正式紫霞神功名字緣由之一。</li>
</ul>

**價格**：C+1200
