# 太玄鑲華劍譜 D+600

> 來源：`資源/技藝/劍法\_刀法/太玄鑲華劍譜`

**要求**：白刃 3 ，專業 ( 劍 )

**特性**：武器嫺熟（劍）

**技能**：開啓太玄鑲華劍法技能樹

**特殊**

<ul>
<li>若你的白刃技能爲 3 則提升到 4 。</li>
<li>你必須使用帶鞘的長劍武器來使用太玄鑲華劍譜招式。</li>
<li>你不能在連續的兩輪中使用一樣的太玄鑲華劍譜招式。</li>
<li>此技能需花費一整輪。</li>
<li>潤於枯瀆，三日射谷，激發內力，快速劃出一道金色 " 太玄劍網 " 包圍自己。</li>
<li>作爲終結技此技能每場戰鬥只能使用一次</li>
</ul>

**花費**

<ul>
<li>1 內力</li>
<li>1 內力</li>
<li>1 內力</li>
<li>1 內力</li>
<li>1 內力 + 增幅</li>
<li>1 內力</li>
<li>無</li>
</ul>

**說明**

<ul>
<li>對目標進行一次白刃攻擊，並附帶（此技能級數 + 等於你 " 太玄 " 層數）的破甲。擊中目標時，獲得一層 " 太玄 " 狀態。</li>
<li>對（每一級數 1 米）範圍內的所有人（包含隊友）進行白刃攻擊。每擊中一個目標，獲得一層 " 太玄 " 狀態。</li>
<li>以白刃攻擊發射劍氣對目標造成衝擊傷害，並使對方受到每成功數 1 暈眩的不良狀態（可疊加），強韌豁免，持續（每一級一輪），當受影響目標行動結束後可以進行一次強韌判定，並解除等同成功數的暈眩狀態。擊中目標時，獲得一層 " 太玄 " 狀態。</li>
<li>對目標進行白刃攻擊，若成功命中，則你獲得一層 " 太玄 " 狀態。若其有通用能量池，則使其使用通用能量池時能耗增加你本技能等級/點，持續你本能力級數/輪。擊中目標時，獲得一層 " 太玄 " 狀態。</li>
<li>選擇一個方向直線衝刺，對路線上的每個目標進行附加（此技能級數 \*2 ）高速的白刃攻擊，衝刺距離最多等於你速度的一半，這會同時消耗你的移動動作。每擊中一個目標獲得一層 " 太玄 " 狀態。</li>
<li>對你正前方 5\*5 米內所有敵人進行多次白刃攻擊，其次數等於（ 1+ 你的太玄層數 / 敵人數量，小數點向下取整）。技能結束後，將清除所有太玄層數。</li>
</ul>

**升級**

<ul>
<li>花費目前級數 \*2 的 XP 提升此技能一級，每提升兩級，內力花費 +1 。</li>
<li>【終莫受施】《一級》：</li>
<li>蛇伏於泥，終莫受施，壓低身姿，以極快的速度進行迴旋斬擊。</li>
<li>花費目前級數 \*2 的 XP 提升此技能一級，每提升兩級，內力花費 +1 。</li>
<li>【物各乖離】《一級》：</li>
<li>陽氣孚微，物各乖離，平舉劍身，積蓄太玄光華，向目標飛射一道金色劍氣。</li>
<li>花費目前級數 \*2 的 XP 提升此技能一級，每提升兩級，內力花費 +1 。</li>
<li>【閒門以終】《一級》：</li>
<li>閒門以虛，終不可實，針對目標的穴位進行攻擊，並將太玄光華注入對方穴位，使其運用內力受阻。</li>
<li>花費目前級數 \*2 的 XP 提升此技能一級，每提升兩級，內力花費 +1 。</li>
<li>【三日射谷】《一級》：</li>
<li>花費目前級數 \*5 的 XP 提升此技能一級。</li>
<li>【月闕其摶】《一級》：</li>
<li>月闕其摶，日正於天，你消失在原地並留下一道人形光影，再次出現時，你已經在他背後。</li>
<li>花費目前級數 \*2 的 XP 提升此技能一級，每提升兩級，內力花費 +1 。</li>
<li>【終˙龍戰玄黃】：</li>
<li>神戰於玄，其陳陰陽，龍出於中，舞劍飛斬，你以旁人無法看清的速度穿梭斬擊敵人，太玄光華殘留在你移動的軌跡，最後你回到原本的位置，直到此時，敵人才發現身上的劍傷。</li>
</ul>

**增幅**：每兩點內力可以增幅 1 次，你不能增幅超過（級數 \*2 ）次。

**其他標籤**

**提純**：花費目前太玄階數 \*5XP 來使你的 " 太玄 " 提升一階，變得更加純粹和凌厲，最高五階。

**太玄奧祕**

<ul>
<li>當你的太玄達到三級或以上，並且學會全部技能之後，你在使用劍譜上的技能時，可以敏捷代替力量進行白刃攻擊傷害上限的判定。</li>
<li>【赤子扶扶】《一級》：</li>
<li>赤子扶扶，元貞有終，將太玄光華聚集於劍的尖端，刺向目標。</li>
</ul>

**太玄劍網**：劍網的強度等於 1+ 增幅次數，每點強度可以抵銷（每級數 1 ）點傷害，每次抵銷扣除相應強度。當你穿過劍網，你獲得等同強度的 " 太玄 " 層數，同時劍網消失。劍網最多存在至你下一輪行動結束。


**正文**

此劍譜爲“七妙神君”梅山民在研讀太玄經時參悟出的劍法，施展的時候劍身會發出金色的光芒，並留下金光殘影。

太玄鑲華劍技《一級》每招需要花費 D+600 來學習，或是一次性花費 CC+3000 來學會整套七招技能《三級》。

下列技能等同花費一個標準動作進行攻擊。

" 太玄 " 《一階》：

每層太玄狀態可以使你在使用太玄鑲華劍技時增加等同階層數的 DP （一階 +1DP ，二階 +2DP ，類推），同時這是使用劍技時殘影拖曳的長度，每層太玄增加殘影 0.1 米。此狀態在一場遭遇結束後消失。
