# 末日劍法（武學・劍招） Ｄ＋１０００

> 來源：`資源/技藝/劍法\_刀法/末日劍法`

**使用**

<ul>
<li>進行一次虛招，未能成功的話判定中每個失敗對自己造成１點衝擊傷害，視爲由自己手上的劍造成，因此附加劍上所有特性。以此方法裝（ zuo ）死，每點傷害＋１ＤＰ表現加值。</li>
<li>表演這門劍法，判定結果一個成功也沒有會造成失敗數的衝擊傷害，視爲由自己手上的劍造成，因此附加劍上所有特性。</li>
<li>進行一次＋２ＤＰ招式加值的白刃攻擊，看起來是這麼回事，只是未能成功擊中對方時（被ＤＲ減少傷害不算）須再進行一次＋２附加成功的白刃攻擊，結果得出的每個成功數對自己造成１點嚴重傷害。</li>
</ul>

**正文**

帶來末日的劍法――爲自己帶來末日的劍法。

這門劍法，無人看得透……人物在武術學識（劍法）２＋／白刃（劍）４＋時能夠進行一次智力／感知＋相關技能的判定――有１個成功能夠察覺不對勁，３個成功知道劍法威力，５個成功會真正識破末日劍法的“真正效用”。
