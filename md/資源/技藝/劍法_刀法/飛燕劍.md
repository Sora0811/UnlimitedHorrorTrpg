# 飛燕劍

> 來源：`資源/技藝/劍法\_刀法/飛燕劍`

**前提**

<ul>
<li>擁有能量池，</li>
<li>人物擁有多種能量池時，則在第一次購買此技能樹時，選擇使用一種能量池，不可更改。選擇能量池的一種關鍵屬性作爲飛燕劍技法的關鍵屬性，你必須依照如下優先級順序從高到低選擇：決心，智力，敏捷，耐力，沉着，力量，感知，風度，操控。</li>
<li>購買者可以選擇意志池作爲飛燕劍技法的關鍵能量池。若他如此做，需要支付能量時改爲支付意志力，判定能量池關鍵屬性時採用決心</li>
</ul>

## LV1 弧舞飛燕劍 D+1000

**注**

<ul>
<li>由於使用者可能有用其他屬性代替攻擊檢定的屬性能力，如魔人，武器嫺熟等，此時該力量+白刃的檢定中的屬性部分改爲對應屬性。</li>
<li>LV2 真理飛燕劍 C+2000</li>
<li>你學會了一類飛燕劍技法。</li>
<li>你在“高速連擊”檢定上可以加上你的風度。</li>
<li>LV3 沙綾飛燕劍 B+4000</li>
<li>你學會了一類飛燕劍技法。</li>
<li>你在“高速連擊”檢定上可以加上你的敏捷。</li>
<li>LV4 樞孔飛燕劍 A+8000</li>
<li>你學會了一類飛燕劍技法。</li>
<li>你在“高速連擊”檢定上可以加上你的先攻。</li>
<li>LV5 飛燕劍·免許皆傳 S+16000</li>
</ul>

**其他標籤**

**你學會了招式**

<ul>
<li>飛燕劍。你學會了一類飛燕劍技法。</li>
<li>飛燕劍默認適用於細長的直刃劍（例如突刺劍、西洋劍、長劍）武器，但不能雙持武器使用。</li>
<li>使用飛燕劍招式是一次附加了一個飛燕劍技法的標準白刃攻擊。你可以在攻擊前先進行一次“高速連擊”檢定，檢定結束後正式決定此次飛燕劍攻擊的數值和性質。“高速連擊”檢定規則爲你的力量+白刃檢定對抗敵人的敏捷 + 感知，若你勝出可以減去勝出數再進行一次對抗，重複直至失敗爲止。你每勝出一次可以在此次的飛燕劍招式中額外附加一個不同的飛燕劍技法，上限爲飛燕劍等級。如果附加的飛燕劍技法會提升動作，則此次飛燕劍招式的動作取最高，若你此時沒有動作來施展，則無法附加。</li>
</ul>


## 你習得 奧義·飛燕姬神恍舞

**其他標籤**

**飛燕劍技法**

<ul>
<li>飛燕劍技法分爲妖、斬、舞和魔劍技·雷光四大類和最終奧義。</li>
<li>你獲得和提升飛燕劍等級時可學會一類飛燕劍技法，直到 LV4 全部學會爲止。</li>
<li>飛燕劍技法增幅上限爲飛燕劍等級 \*2 ，不受其他增加上限的能力影響，增幅能力必須先增幅上面的然後纔可以增幅下面的。</li>
<li>飛燕劍的技法分爲普通效果和增幅效果。</li>
<li>如無特別說明，飛燕劍技法的加值爲招式加值，特殊的，來自於飛燕劍技法的招式加值可以疊加。</li>
<li>飛燕劍的技法無法重複疊加，例如你“高速連擊”獲得了2次對抗勝利，但是你無法選擇身妖舞2次，只能選擇 身妖舞和 蓬妖舞各一次。</li>
<li>“高速連擊”可以讓你額外附加一個招式，如“高速連擊”你獲勝2次，則你可以同時附加 身妖舞和 蓬妖各一次，這次白刃攻擊中就會獲得該普通效果。</li>
<li>然後由於你的飛燕劍技法是D級，你最多增幅2次，那你可以選擇 增幅 - 真理身妖舞和 增幅 - 沙綾身妖舞2次，或者 增幅 - 真理身妖舞和 增幅 - 真理蓬妖舞各一次。</li>
</ul>


## 飛燕劍· 妖

**其他標籤**

**身妖舞**

<ul>
<li>+3 高速</li>
<li>增幅 - 真理身妖舞：若你在此技法上支付了 3 能量，且此次攻擊的高速值在計算完目標的基礎防禦，閃避防禦和格擋防禦後還有剩餘，則你可以將剩餘的一半數值加在攻擊 DP 上。</li>
<li>增幅 - 沙綾身妖舞：若你在此技法上支付了 5 能量，你可以將飛燕劍動作提升爲一個整輪動作。你在“高速連擊”檢定中每勝出一次，可追加一次攻擊，追加次數上限爲飛燕劍等級。追加攻擊與本次飛燕劍招式中的第一次攻擊數據和性質相同，但共用傷害上限。</li>
</ul>

**蓬妖舞**

<ul>
<li>+3破魔</li>
<li>增幅 - 樞孔蓬妖舞：若你在此技法上支付了 7 能量，且你的先攻檢定高於被攻擊者，則對方在你飛燕劍攻擊結束前無法做出反射動作。</li>
</ul>


## 飛燕劍·斬

**其他標籤**

**殲鋼斬**

<ul>
<li>+3 破甲</li>
<li>增幅 - 滅鋼斬：若你在此技法上支付了 3 能量，且此次攻擊的破甲值在計算完目標的盔甲防禦，盾牌防禦，天生防禦後還有剩餘，則你可以將剩餘的一半數值加在攻擊 DP 上。</li>
<li>增幅 - 殲鋼雙肢亂：若你在此技法上支付了 5 能量，則你可以令此次攻擊成爲接觸攻擊，無視對方的護甲和天生防禦值</li>
</ul>

**舞華斬**

<ul>
<li>+3 穿透傷害減免</li>
<li>增幅 - 地裂斬：若你在此技法上支付了 5 能量，此次攻擊中的飛燕劍提供的穿透傷害能力可以在傷害減免 / 吸收 / 能量抗力中任意選擇。</li>
<li>增幅 - 紅燐舞華斬：若你在此技法上支付了 7 能量，攻擊時可以進行一次額外的對抗，你以自己的攻擊判定對抗對方的格擋，如果勝出，則對方失去格擋和遮蔽 / 掩蔽帶來的防禦加值</li>
</ul>


## 飛燕劍·舞

**其他標籤**

**圓舞劍**

<ul>
<li>你可以選擇在攻擊前後額外進行一次普通移動。若你擁有多次攻擊的能力，也可選擇在多次攻擊之間移動，你可以在移動後改變攻擊目標。</li>
<li>增幅 - 真理圓舞劍：若你在此技法上支付了 3 能量，你在“高速連擊”檢定中每勝出一次，可額外進行一次普通移動</li>
<li>增幅 - 樞孔圓舞劍：若你在此技法上支付了 7 能量，攻擊時可以進行一次額外的對抗，你以自己的攻擊判定（白刃攻擊關鍵屬性 + 白刃 + 武器傷害 + 其他加值）對抗對方的偵查，如果勝出，則對方對你失去敏捷和感知上帶來的防禦加值以及洞察加值</li>
</ul>

**紅燐劍**

<ul>
<li>攻擊半徑增加 3 米 / 能量池關鍵屬性。且你在攻擊時可以額外對攻擊方向上、不超過攻擊距離的錐狀範圍內的所有生物造成白刃等級的範圍傷害，反射規避。你可以使範圍內最多不超過自身操控值一半的目標不受傷害。</li>
<li>增幅 - 弧舞紅燐劍：若你在此技法上支付了 3 能量，你可以將飛燕劍動作提升爲一個整輪動作，白刃攻擊改爲對攻擊方向上、不超過攻擊距離的錐狀範圍內的所有生物造成範圍傷害，反射規避。你可以使範圍內最多不超過自身操控值一半的目標不受傷害。</li>
<li>增幅 - 樞孔紅燐劍：若你在此技法上支付了 7 能量，你可以放棄此次的飛燕劍招式攻擊來蓄力，下一次你攻擊時獲得三分之一普通白刃攻擊骰成功數的加值，可以疊加。若你蓄力後經過該技法支付能量的輪數還未攻擊則該加值失效。</li>
</ul>


## 魔劍技·雷光

**其他標籤**

**雷光滅鋼斬**

<ul>
<li>你在攻擊時可以額外造成白刃和神祕學上的附加成功數的電擊傷害和麻痹點數，麻痹點數每輪下降一點，可以疊加。這個效果會升級爲重度後果和毀滅性後果。</li>
<li>增幅 - 雷光地裂斬：若你在此技法上支付了 3 能量，你可以將飛燕劍動作提升爲一個整輪動作，此時造成的傷害中一半會轉化爲電擊傷害和麻痹點數，可以疊加，麻痹點數每輪下降一點。這個效果會升級爲重度後果和毀滅性後果。</li>
<li>增幅 - 雷光紅磷劍：若你在此技法上支付了 5 能量，你可以將飛燕劍動作提升爲一個整輪動作，攻擊時可以額外以你的施法骰智力 + 神祕學對抗對方的意志值，造成三分之一勝出數的電擊傷害和劇痛點數，可以疊加，劇痛點數每輪下降一點。這個效果會升級爲重度後果和毀滅性後果。</li>
</ul>

**雷光身妖舞**

<ul>
<li>你可以將飛燕劍動作提升爲一個整輪動作，攻擊時進行一次額外的對抗，你以自己的攻擊判定（白刃攻擊關鍵屬性 + 白刃 + 武器傷害 + 其他加值）對抗對方的偵查，如果勝出，則在你下一輪開始前，你對對方進行攻擊時獲得勝出數的洞察加值。</li>
<li>增幅 - 雷光舞華斬：若你在此技法上支付了 5 能量，且你勝出，你在攻擊時可以額外獲得一半勝出數的加值</li>
<li>增幅 - 閃光翼：若你在此技法上支付了 7 能量，該技法判定額外獲得一半施法骰智力 + 神祕學判定成功數的加值。</li>
</ul>

**奧義·飛燕姬神恍舞**：“高速連擊”檢定的勝出次數 +1 。這一技法始終生效，不需附加。

飛燕劍出自某個存在着古神、現神與機工女神的世界。飛燕劍本只是一種普通的劍技，但某個流浪劍士將此發揚光大。人們敬畏的稱其爲“赤き髪の神殺し”。
