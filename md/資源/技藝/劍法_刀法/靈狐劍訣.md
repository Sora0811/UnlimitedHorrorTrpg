# 靈狐劍訣

> 來源：`資源/技藝/劍法\_刀法/靈狐劍訣`

## 靈狐貫甲 D+500

**先決**

<ul>
<li>劍擊 4 白刃 4+</li>
<li>當你使用貫甲時，你可以額外移動白刃等級的距離。</li>
</ul>

## 靈狐突刺 D+500

**先決**

<ul>
<li>白刃 4+</li>
<li>整輪動作，選擇一個在基礎速度一半內的目標，對其發起一次衝撞 , 用近戰白刃攻擊判定替代力量 + 肉搏。</li>
</ul>

## 靈狐之速 D+500

**先決**

<ul>
<li>風度 4+ 白刃 4+</li>
<li>你在進行近戰白刃攻擊判定時，可以花費一個移動動作，用你的風度 + 掩飾對抗目標的感知 + 沉着。你每勝出 2 ，則獲得 1 點高速。</li>
<li>靈狐貫甲</li>
<li>當你使用貫甲時，破甲值上升你的白刃等級。同時移動距離變爲你的兩倍白刃等級的距離。</li>
<li>靈狐突刺</li>
<li>在你發動靈狐突刺後，若對方被你擊倒或者擊退超過其體積值後，你可以馬上對其再發動一次近戰白刃普通攻擊，這次攻擊無法附帶任何技能和招式，同時你將失去下個回合的移動動作。</li>
<li>靈狐之速</li>
<li>現在你靈狐之速的對抗再加上你的白刃等級，同時你每勝出數 1 ，則獲得 1 點高速加值，而非勝出 2 點。</li>
<li>玄狐決：突</li>
<li>當你使用貫甲時，你額外造成等於你風度附加成功數的嚴重傷害，這部分傷害不計算在傷害上限內，同時無視傷害減免與傷害吸收。並且你現在發動貫甲可正常移動</li>
<li>玄狐決：亂</li>
<li>你現在發動靈狐突刺後，若選擇擊退，並且成功連擊後，則可以繼續發動靈狐突刺，不過這次的傷害要減去等於上一次追擊的成功數的 DP 。若選擇擊退，並且成功連擊（該次連擊受到同額減值）後，則可以繼續發動靈狐突刺，並且這次的傷害要減去第一次追擊的成功數的 DP 和第二次追擊成功的 DP ，以此類推。</li>
<li>玄狐決 : 影</li>
<li>現在你靈狐之速的對抗每勝出 1 ，則對方減少 1 點基礎防禦。若對方的基礎防禦因此減少到 0 ，則對方失去全部的防禦附加成功（包括盔甲，魔法等來源），並且視爲措手不及，你可以發動某些措手不及的對應能力。</li>
</ul>
