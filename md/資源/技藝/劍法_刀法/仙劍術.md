# 仙劍術

> 來源：`資源/技藝/劍法\_刀法/仙劍術`

**本質**：魔幻本質

**描述**：煉氣九層功夫胎動，入竅，感應，凝煞，煉罡，丹成，道基，脫劫，溫養！若是平常，每一層功夫在劍術上便有一種變化。劍修若沒有領悟劍術，就往往屈居人下，但是若領悟了上等劍術，一劍在手，足以破盡萬法。

**前提**：擁有真氣能量池，白刃技能3以上

**特殊**：本技藝必須由D級開始按順序購買，即便你有任何能使你無視前提直接強化後續招式的能力也必須按順序購買。

## 傷敵十步・馭劍百步

**價格**：D+1000

**動作**：見下

**描述**：入竅的修爲，便能在劍刃上附着一層劍氣，十步傷敵。

**效果**

<ul>
<li>被動-你在使用分類爲“劍”的武器進行近戰白刃攻擊時，你的觸及範圍增加你的感知或決心上的附加成功數取高\*5米（最低爲5）。</li>
<li>同時，你在使用分類爲“劍”的武器進行近戰白刃攻擊時，你可以以一個迅捷動作支付真氣額外增加你的觸及範圍，每爲此支付1點真氣，你的觸及範圍便提升5米，持續時間等同於你投入的真氣值\*1輪，你總共可在此法上投入的真氣值上限爲你已掌握的“仙劍術”技藝數量+1點。</li>
</ul>

**價格**：D+1000

## 劍氣生煞・劍光化虹

**價格**：C+2000

**動作**：見下

**描述**：到了凝練煞氣的境界，便能在飛劍上附着一層煞氣，等閒的旁門衆人煉就的污穢法物，就再也不能損了道門正宗的飛劍，再也不畏邪污。到了煉氣成罡的境界一口飛劍便能虹化，使你可以御劍飛行，當你以此法飛行時腳下會出現你手中長劍的虛影。

**效果**

<ul>
<li>你在使用分類爲“劍”的武器進行近戰白刃攻擊時，你可以以一個迅捷動作支付真氣強化該武器，你每爲此支付1點真氣，便能使該武器額外獲得3點破甲或3點破魔，持續時間等同於你投入的真氣值\*1輪，你總共可在此法上投入的真氣值上限爲你已掌握的“仙劍術”技藝數量+1點。</li>
<li>被動-你獲得等同於你基礎移動速度的飛行速度，機動性爲完美。</li>
</ul>

**價格**：C+2000

## 煉劍成絲・劍氣雷音

**價格**：B+4000

**動作**：被動

**描述**：金丹大成之後，劍光反而凝聚，以一劍破萬法,能把飛劍練成遊絲，出劍的方位神妙莫測。你的劍的速度甚至超過了聲速，導致突破音障發出的聲音也成爲你的攻擊的一部分。

**效果**

<ul>
<li>你在使用分類爲“劍”的武器進行近戰白刃攻擊時，第一次受到你攻擊的敵人會陷入措手不及，這是一個B級措手不及效果。</li>
<li>此外，你在使用分類爲“劍”的武器進行近戰白刃攻擊時，你可以忽視對方6點任意加值的防禦，在攻擊前自行選擇一種防禦類型，你還可以將傷害類型轉換爲音波傷害，若你如此做，你該次攻擊增加4點【高速優勢】，並能夠對目標造成等同於該次檢定成功數的暈眩點數，目標以強韌豁免。</li>
</ul>

**價格**：B+4000

## 瞬劍術・劍光分化

**價格**：A+8000

**動作**：被動

**描述**：在數尺間挪移,瞬劍術和劍光分化並列，同被視爲劍術中至高絕傳。再進一步金丹破碎，鑄就道基，這才能夠把劍光分化，一口飛劍化成數十百口光華,以劍氣和劍光模擬百般武技與武器形態，號稱一劍生萬法。

**效果**

<ul>
<li>當你在白刃上擁有對應專業時，你可以用分類爲“劍”的武器演化爲該武器分類，使你可以施展相應分類的技藝，並將你握持的劍視爲該專業的武器（一般而言，在施展其他武器分類的技藝時，視覺效果上視作你手持長劍並激蕩真氣幻化出該武器的形態進行攻擊，但具體是否可行仍需由ST裁定，例如你想使用光劍施展拔刀術時，你可能需要爲其找一個劍鞘。），你可以演化的武器分類有：棍、錘、刀、斧、矛、鞭、鐮刀。</li>
<li>此外，你在使用分類爲“劍”的武器進行近戰攻擊時，你可以獲得等同於你感知或決心值取高的表現加值。</li>
<li>你在使用分類爲“劍”的武器進行近戰白刃攻擊時，你可以以一個自由動作在該次攻擊中附帶“順勢斬”專長的效果，即便你不具備該專長，這次順勢斬不會因攻擊多個目標而承受減值，且不會佔用你的動作，你也可以照常在這次攻擊中附帶招式。</li>
</ul>

**價格**：A+8000
