# 三劍三刀

> 來源：`資源/技藝/劍法\_刀法/三劍三刀`

## 一劍藏空 C+2000 （招式）

**消耗**：3 內力

**動作**

<ul>
<li>標準動作</li>
<li>玄天邪帝所創“三刀三劍”中的劍招第一式。原爲“一劍藏”，劍招雖是迅疾無倫，但是無法藏住自身空門，於是改良成“一劍藏空”，快疾致勝，同時帶起如龍捲的螺旋劍氣，攻中帶守藏起空門。</li>
</ul>

**效果**：對感知 / 米內的敵人刺出一劍，進行正常白刃攻擊的同時，捲起的螺旋劍氣會在你周身形成一層防護。在施展此招的當輪內，你的防禦會獲得白刃等級的偏斜加值。

**增幅**

<ul>
<li>消耗每提高一倍，你的射程就擴大一倍，同時消耗的每點能量都能提供 1 點額外偏斜加值。</li>
<li>額外消耗的能量每超出你的體質值一點，就會讓你受到 1 點不可減免的嚴重傷害。</li>
<li>如果消耗一整輪來施展這個劍招，那麼“一劍藏空”將轉變爲範圍攻擊。你可以刺出一道巨大的劍氣虛影，你附近長 3\* 消耗能量 / 米、寬 2\* 消耗能量 / 米內的敵人都會承受一次範圍攻擊，傷害爲你的攻擊骰成功數。</li>
</ul>

**特殊**：兩種增幅可以同時使用。

**進化**：支付 12XP 之後，你在施展“一劍藏空”時（標準或者一整輪），可以做出一次不超出你移動距離的衝鋒，並且可以正常獲得衝鋒的 DP 加值和防禦減值。途中進入你攻擊範圍的敵人都會承受你的劍招攻擊，

## 千刀不盡 C+2000 （招式）

**消耗**：3 內力

**動作**

<ul>
<li>標準動作</li>
<li>玄天邪帝所創“三刀三劍”中的刀招第一式。原爲獨孤星夜所創的“十刀不盡”，後由邪帝藉由百年修爲成功改良至”千刀不盡”。刀勢一刀接着一刀的無限延伸，不死不休！</li>
</ul>

**效果**

<ul>
<li>以快絕無比的刀勢揮出無數刀罡氣勁，攻擊 2\* 消耗能量 / 米內的一名敵人。</li>
<li>假如第一輪未命中的話，第二輪再使用“千刀不盡”時，上一輪白刃帶來的 DP 值可以加入本次攻擊中。</li>
<li>假如第一輪命中的話，第二輪再使用“千刀不盡”時，可以將上一輪失敗的骰子加入到本次攻擊中，最多不超出你的白刃等級 + 專業・刀總和。</li>
<li>只有連續使用本招，才能牽引上一輪未消耗的刀罡一起斬向敵人。中間有間隔的話，那麼將無法獲得以上兩種增益。</li>
</ul>

**增幅**

<ul>
<li>消耗每提高一倍，你的攻擊距離在基礎上就再擴大一倍。同時消耗的每 3 點能量都能額外提供 4 點額外 DP 加值。</li>
<li>額外消耗的能量每超出你的體質值一點，就會讓你受到 1 點不可減免的嚴重傷害。</li>
<li>如果消耗一整輪來施展這個刀招，那麼“千刀不盡”將轉變爲一次範圍攻擊。你可以攻擊前方扇形 2\* 消耗能量 / 米內，或者身邊半徑消耗能量數 / 米內的敵人，傷害爲你攻擊骰的成功數。對方可以用敏捷 + 運動進行迴避，但如果你下一輪繼續消耗一整輪使用“千刀不盡”的話，那麼可以將對方迴避掉的傷害總額作爲 DP 加值加到你的攻擊骰判定中，最多不超過最多不超出你的白刃等級總和。</li>
</ul>

**特殊**：兩種增幅可以同時進行。

**進化**：支付 12XP 之後，你在施展“千刀不盡”時（標準或者一整輪），可以做出一次不超出你移動距離的衝鋒，並且可以正常獲得衝鋒的 DP 加值和防禦減值。途中進入你攻擊範圍的敵人都會承受你的刀招攻擊，

## 百劍無終 B+4000 （招式）

**消耗**：5 內力

**動作**

<ul>
<li>標準</li>
<li>玄天邪帝所創“三刀三劍”中的劍招第二式。原爲迅速刺出十劍的“十劍終”。但攻勢容易中斷且威力固定；改良”百劍無終”成劍氣奇正相生，在兩者激盪中產生越級提升的勁力。</li>
</ul>

**效果**：在施展此招之前，先進行一次白刃判定，然後你可以將判定成功結果作爲自動成功，或者將其以 1 ： 3 的比例換算成 DP 值加入攻擊骰中，攻擊身邊半徑攻擊骰成功數 \*2 米內的敵人。若是將劍氣收束，攻擊範圍變爲攻擊骰成功數 \*3 米的扇形面積。可以攻擊的敵人數目爲感知與白刃等級兩者間較高者。

**增幅**

<ul>
<li>消耗每提高一倍，攻擊範圍就擴大一倍。同時消耗的每 5 點能量都能提供 6DP 的招式加值。</li>
<li>額外消耗的能量每超出你的體質值一點，就會讓你受到 1 點不可減免的嚴重傷害。</li>
<li>如果消耗一整輪來施展這個劍招，那麼將不再有捕捉敵人數量的限制，劍招殘留的無形劍氣會潛伏在攻擊過的空間內，直到你下一輪行動之前，凡是進入你本輪以“百劍無終”攻擊範圍內的敵人，都會承受一次你白刃攻擊。</li>
</ul>

## 十刀破極 B+4000 （招式）

**消耗**：5內力 / 一道刀氣

**動作**

<ul>
<li>標準</li>
<li>將分散的刀罡集中，化作十道刀氣奔走。招式一出刀氣就不斷巨大化！刀勢有如脫繮野馬延伸數百丈遠！力量、速度、距離的極限，都在這十刀中不再存在！</li>
</ul>

**效果**

<ul>
<li>你在出招時進行一次攻擊判定，一刀揮出數道不斷延伸而出的巨大刀氣，每道刀氣需要消耗5點內力，最多揮出 10 道。刀氣的前進方向由你決定，它們可以衝向同一個方向，也可以分散向各處。</li>
<li>衝向同一個方向時，針對該範圍內的目標每有一道刀氣則視爲受到一次範圍傷害。</li>
<li>每道刀氣造成你攻擊判定成功數的範圍傷害，波及長攻擊判定成功數 \*1 米、寬攻擊判定成功數 \*0.3 米的區域，反射豁免。</li>
</ul>

## 萬劍歸元 A+8000 （招式）

**消耗**：7 內力

**動作**

<ul>
<li>標準</li>
<li>把劍訣”除劍之外 別無所有”發揮到極致的招式。出手時萬劍齊發，劍氣如潮彷彿鯤鵬展翅天河倒卷，除劍之外在也容不下其他。</li>
</ul>

**效果**：在出招之前，先進行一次敏捷 + 白刃的檢定，然後再進行一次攻擊判定。在攻擊判定成功數 \*3 米的扇形範圍內，或身邊半徑攻擊判定成功數 \*2 米範圍內的敵人都會承受你一次近戰普通攻擊，在結算傷害前，目標視爲已經被攻擊了等同於你第一次檢定成功數的次數，並承受相應的防禦減值。如果對方的基礎防禦因此被減少到 0 ，則每剩餘 1 檢定成功數，攻擊骰就額外獲得一個附加成功，最多不超出你的白刃等級。

**增幅**

<ul>
<li>每額外消耗 1 點內力，你的攻擊範圍判定上就視爲多 1 個成功數。額外消耗內力若是超出了你的體質值，每超出 1 點便會讓你受到 1 點不可避免的嚴重傷害。</li>
<li>如果你以一整輪動作來施展“萬劍歸元”，那麼你可以做出一次不超出你移動距離的衝鋒，並且可以正常獲得衝鋒的 DP 加值和防禦減值。途中進入你攻擊範圍的敵人都會承受你的劍招攻擊，</li>
<li>如果你以一整輪動作來施展“萬劍歸元”，同時將攻擊範圍縮減到體魄 / 米內，並且將攻擊目標限定爲一個的話，那麼可以將“沉着”屬性作爲 DP 加值額外加入攻擊骰中。這是一個神聖加值。</li>
</ul>

## 一刀絕空 A+8000 （招式）

**消耗**：7 內力

**動作**

<ul>
<li>標準</li>
<li>劍走輕靈，刀重剛猛，大拙反璞，一刀足矣！將刀訣”大拙反璞 一刀足矣”發揮到極致之招。刀的霸道何須好幾刀？只需化繁爲簡的一刀！</li>
</ul>

**效果**：你在施展此招時，首先進行一次意志檢定，斬出由刀意氣勁凝聚而成的一道刀罡虛影，攻擊判定成功數 /2 米扇形範圍內或者身邊半徑成功數 / 米內的全部敵人。這是一次接觸攻擊，可以忽略意志檢定成功數的任意來源傷害減免（包括但不限於 DR 、傷害吸收、力場效果的護盾）。若對方的傷害減免因此被抵消到 0 ，那麼你額外每有 1 個檢定成功數，就能將本次攻擊製造的 1 點嚴重傷害轉變爲惡性。

**增幅**

<ul>
<li>每額外消耗 1 點內力，你的攻擊範圍判定就視爲多 1 個成功數。額外消耗內力若是超出了你的體質值，每超出 1 點便會讓你受到 1 點不可避免的嚴重傷害。</li>
<li>如果你以一整輪動作來施展“一刀絕空”，同時將攻擊範圍縮減到體魄 / 米內，並且將攻擊目標限定爲一個的話，那麼可以將“決心”屬性作爲 DP 加值額外加入攻擊骰中。這是一個神聖加值。</li>
</ul>

**特殊**

<ul>
<li>若你習得了全部的招式，則藉由本套招式所附帶的武道昇華，使你具有一種近似於“概念斬擊”的特殊效果。就如同力量大能的破天擊可以以點破面一般，你在使用“萬劍歸元”或者“一刀絕空”時可以忽視體積影響，只要傷害足夠，你便可以用一把裁紙刀將帝國大廈切成兩截，甚至表演用手刀斬斷珠峯。</li>
<li>除此以外，你還可以憑此去破壞可以接觸到的超自然神祕效果，包括但不限於飛來的火球、護盾、結界、地上描繪的法陣、法術製造的鎖鏈等等或類似的效果，就如同法術裏的“解除魔法”一般。以攻擊骰取代施法判定與對方的成功數進行對抗。對方效果等級每比 B 高一級，攻擊檢定就受 -3 減值。你的意志檢定成功數可以抵消這一減值，如果抵消完之後還有剩餘，那麼對方會反過來將承受剩餘數的減值。</li>
<li>若對抗勝出，則該效果立刻解消。</li>
</ul>

**正文**

玄天邪帝花費百年光陰，將一身武學總結出三式刀招與三式劍招，，分別是由簡入繁的劍法一劍藏空、百劍無終和萬劍歸元，以及由繁入簡的刀法萬千不盡、十刀破極和一刀絕空。刀法劍法進展方向相反，劍法到了最後，隨手就是萬道劍氣跟隨，彷彿鯤鵬展翅天河倒卷，劍氣如潮不可抵擋。而刀法的至境卻是返璞歸真，全部功力凝聚在一刀之中，不管面前是什麼，統統一刀砍斷。

本招式無需按順序購買。
