# 百分百被空手接白刃

> 來源：`資源/技藝/劍法\_刀法/百分百被空手接白刃`

**本質**：特異本質 價格： C+1000

**分類**：技藝

**前提**：手中持有短劍，突刺劍，長劍，重劍，彎刀，刀中的任意一個。

**描述**

<ul>
<li>取自《十萬個冷笑話》李靖的設定，最初是被動技能，裝備任何名字帶有劍的武器即可發動，發動效果爲，每次劈出劍後，必定有人會來空手接白刃。「呔！妖孽看劍！」 這是氣勢如虹的一劍，這是天崩地裂的一劍！至少你是這麼想的！ 「爲什麼？！爲什麼只要是個人都能接住我這一劍啊！！」</li>
<li>你大喊一聲，使用標準動作花俏無比的往前方空氣揮出一劍。你進行風度 + 表達檢定，所有在敏感範圍內有你並且你還處於其移動範圍內的一個敵方目標，以沉着 + 感受進行對抗，同時本次對抗對方會額外獲得對方手中物品數的附加成功。若你勝出，且對方能移動到你攻擊範圍，他將被迫耗費一個反射動作移動過來穩穩的接住你這一劍！並且他將失去其下一輪中的一個移動動作。 如果他已經失去了移動動作或反射動作，那麼他如果手中有物品，將無豁免掉落。 你每使出這招一次，你都感到莫大的羞恥感（恥力 +1 ），因此受到內傷吐血而受到 1 點不可避免的嚴重傷害。</li>
</ul>
