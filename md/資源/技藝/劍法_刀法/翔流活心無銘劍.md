# 翔流活心無銘劍

> 來源：`資源/技藝/劍法\_刀法/翔流活心無銘劍`

**效果**

<ul>
<li>當你使用月華時，你可以選擇支付 2 點意志，將招式升級爲十六夜月華。在使用十六夜月華時，你所造成的範圍攻擊傷害上限提升爲等於你的白刃攻擊傷害上限，並且你不會傷到你不想傷害的目標。你可以額外再支付 1 點意志力，使你的攻擊可以忽略對方至多等於你拔刀術檢定成功數的傷害吸收 / 減免效果。</li>
<li>這個技能每天可以使用的次數爲 3+ 你在沉着上的附加成功數，之後每次使用都需要再額外消耗 1 點意志力。</li>
<li>翔流活心無銘劍·納刀技法：沒有特別說明每個都是 D+500 或 8XP ，部分招式可以通過自行支付 XP 獲得進化</li>
</ul>

## 翔流活心無銘劍·翔流五勢 D+1000

**前提**

<ul>
<li>白刃技能 3+ 、力量 3+ 、敏捷 3+ 、智力 3+ 、感知 3+ 、白刃專業：劍或刀、專長：即時備戰</li>
<li>翔流活心無銘劍的五種基本架勢，分別是力量型的擔刀勢、速度型的引刀勢、技巧型的架刀勢、防禦型的逸刀勢以及攻擊型的納刀勢。基本上，能活用這五種架勢，就能夠戰勝任何敵人。</li>
<li>在進行先攻檢定的同時，人物可以以自由動作啓動一個架勢，這會持續到戰鬥結束，或者人物主動以移動動作切換架勢爲止。如果在一場戰鬥中，人物的先攻值因爲任何原因而產生了變化，或者重新進行了先攻檢定，那麼他可以以自由動作切換架勢。</li>
<li>人物必須在使用肋差、小太刀、太刀、野太刀或 ST 認可的其他武器（例如軍刀和阿拉伯彎刀或許可以）時才能使用翔流五勢，如果失去了武器，那麼架勢也會隨之結束。</li>
<li>擔刀勢</li>
<li>將刀直豎立於耳側，劍鄂與肩齊高，是介於上段和中段之間的架勢，同時也是翔流劍客最常用的架勢。</li>
<li>在這個架勢下，人物可以主動提升使用武器所需的力量值，每增加 1 點力量需求，他在白刃攻擊檢定上就能獲得 +1DP 的加值。增加的力量需求，不能超過武器的體積值或人物的體積值，取低。如果增加的力量需求超過了 2 點，那麼在攻擊格擋或全力防禦狀態下的目標時，可以額外獲得 +1DP 。</li>
<li>引刀勢</li>
<li>單手持刀置於身側，另一手橫置於胸前，是借離心力和刀身長度提高揮刀速度的架勢。</li>
<li>在這個架勢下，人物若是以力量進行白刃攻擊檢定的，那麼他的力量值可以視爲比原本要高一點。若他是以敏捷進行白刃攻擊檢定的，那麼他可以在攻擊上獲得高速優勢，其數值等於武器的體積值，但至多不超過 4 點。</li>
<li>架刀勢</li>
<li>雙手持刀，以前臂爲支架，將刀身置於其上，是極端強化突刺速度的架勢。</li>
<li>在這個架勢下，人物可以以敏捷取代力量作爲白刃攻擊的關鍵屬性，就好像他具有武器嫺熟專長一樣。如果一把武器的體積超過了武器嫺熟專長的限制，那麼每高一點，人物會在攻擊檢定和防禦上受到 -1 減值。如果武器的體積超過了人物自身的體積，那麼此架勢不會產生效果。</li>
<li>逸刀勢</li>
<li>雙手持刀，自然垂於身側，是可以輕鬆收刀防守的架勢。</li>
<li>在這個架勢下，人物可以以迅捷動作進行白刃格擋。如果他這麼做，那麼本回合內，他的近戰攻擊檢定會受到 -2 減值。如果他主動在格擋防禦上承受 -2 減值，那麼他可以忽略對方等於武器體積的破甲值，但至多不超過 4 點。</li>
<li>納刀勢</li>
<li>將刀收回鞘中的架勢，是專門爲了施展居合術而準備的特殊架勢。</li>
<li>在這個架勢下，人物將出鞘的武器歸鞘所需的動作下降一級，如果下降到自由動作的話，那麼連出鞘也可以是一個自由動作。沒有刀鞘的話，就不能使用這個架勢。</li>
<li>翔流活心無銘劍·通用技法：沒有特別說明每個都是 D+500 或 8XP ，部分招式可以通過自行支付 XP 獲得進化</li>
</ul>

## 步月

**先決**：翔流五勢

**加成**：先攻 +1

**類別**：身法

**效果**：以一個迅捷動作，你立刻移動不超過自身速度一半的距離。若你立於穩固的地面上，則你可以立刻進行一次跳躍，此時你的跳躍距離額外增加等於你敏捷值的距離，或等於你力量值的高度，最多不超過你自身速度的一半或你的體積值，取低。

**進化**：支付 16 點 XP ，你可以以移動動作使用步月，同時進行白刃格擋。

**正文**

消失在敵人眼中的同時，在他意想不到的角度再次出現。

## 瞬塵

**先決**：翔流五勢

**加成**：基礎移動速度 +2

**類別**：身法

**效果**：以一個標準動作，你進行一次衝鋒攻擊。在這次衝鋒攻擊中，你只能移動不超過自身速度一半的距離，並且你不會獲得攻擊上的衝鋒加值，但仍然要承受防禦上的衝鋒減值。若你移動的距離超過了自身的體積，那麼每超過 2 米，你的攻擊再承受 -1DP 的減值。

**進化**：支付 14 點 XP ，你不再因爲使用瞬塵而受到攻擊上的減值。

**正文**

拋棄無用的動作，瞬間縮短雙方的距離，從而發出電光火石的一擊。

## 天地

**先決**：翔流五勢

**加成**：拌摔的接觸攻擊檢定獲得 +2DP

**類別**：招式

**效果**：以一個標準動作，對一個觸及範圍內的目標發動一次拌摔。若你成功勝出，則你每勝出兩個成功數，你就能將對方拋出一米的距離，並且對目標造成一點衝擊傷害。

**進化**

<ul>
<li>支付 16 點 XP ，你可以對對方造成嚴重傷害。</li>
<li>支付 16 點 XP ，你可以在使用步月時，以移動動作使用天地。</li>
<li>支付 16 點 XP ，你可以在使用瞬塵時，以天地替換攻擊動作。</li>
</ul>

**其他標籤**

**·強化**

<ul>
<li>若人物處於擔刀勢下，並且他主動將武器的力量需求提升超過了 2 點，那麼他在使用天地時，可以額外造成二點衝擊傷害。</li>
<li>若人物處於引刀勢下，並且他使用力量進行攻擊檢定，則在進行拌摔檢定時他的力量值可以視爲比原本的要高二點。</li>
<li>若人物處於架刀勢下，那麼他可以選擇不將對方投擲出去，而是摔倒在原地，同時每三個勝出數對對方造成二點衝擊傷害。</li>
<li>若人物處於逸刀勢下，那麼他可以選擇不對目標造成傷害，而是使目標的基礎防禦承受等於傷害值一半的減值，持續到人物下回合行動結束。</li>
<li>若人物處於納刀勢下，那麼他可以將目標額外投擲出一倍的距離。</li>
</ul>


**正文**

置換敵人的重心將敵人拋出，是一種簡單的柔術技巧。

## 虛空殺

**先決**：翔流五勢、力量或敏捷 5+

**加成**：無

**類別**：招式

**效果**

<ul>
<li>以一個整輪動作，對觸及範圍內的一個目標發動一次衝撞。你以白刃攻擊檢定與對方進行一次衝撞對抗，並且你只能選擇將目標擊退。你每將對方擊退一米的距離，就能對其造成一點嚴重傷害。若將對方擊退的距離超過了他的體積，那麼每擊退一米，將對對方造成二點傷害。</li>
<li>本技能如常受到白刃攻擊上限的影響。</li>
</ul>

**特殊**：當敵人從高處（例如從上方落下）發動攻擊時，支付一點意志，可以以反射動作使用此技能應對攻擊，此時雙方都視爲對方沒有行動。如果這麼做，人物會失去下一輪的動作。

**其他標籤**

**·強化**

<ul>
<li>若人物處於擔刀勢下，那麼他可以以標準動作使用虛空殺，但虛空殺的傷害減少爲一半。</li>
<li>若人物處於引刀勢下，並且他使用敏捷進行白刃攻擊檢定，則他可以將目標額外擊退四米距離，但這四米距離不會造成傷害。</li>
<li>若人物處於架刀勢下，那麼他只要 2 個勝出數就能將目標擊退一米。</li>
<li>若人物處於逸刀勢下，那麼他可以在使用虛空殺的同時，以迅捷動作進行白刃格擋並且不用承受減值。</li>
<li>若人物處於納刀勢下，那麼他的攻擊獲得『眩暈』特性。</li>
</ul>


**正文**

從下向上發動快速而強力的刺擊，產生的風壓甚至可以將人體擊飛。

## 翔尾閃

**先決**：翔流五勢、白刃 5+

**加成**：先攻 +1

**類別**：招式

**特殊**

<ul>
<li>只有處於擔刀勢下，才能使用此技能。</li>
<li>如果觸及範圍內沒有堅固的障礙物（例如地面、樹幹、牆壁），那麼無法使用這個技能。</li>
</ul>

**效果**：以一個整輪動作，對觸及範圍內的一個目標發動兩次白刃攻擊檢定。第一次攻擊並不會造成傷害，但是你每因此而獲得三個成功數，你的第二次攻擊檢定就可以獲得 +1DP 的速度加值。你每因此而獲得 +5DP 的速度加值，你就能選擇再獲得一個附加成功，但每因此而獲得一個附加成功，你在防禦上就要承受 -2 減值，並且每多一個再額外 -1 （例如一個是 -2 ，二個是 -5 ，三個是 -9 ，類推），持續一輪。你在使用此招式之前或之後，可以以自由動作移動不超過自身體積值的距離。

**進化**

<ul>
<li>支付 16 點 XP ，你可以在引刀勢下使用此技能。</li>
<li>支付 16 點 XP ，你可以在逸刀勢下使用此技能。</li>
<li>支付 16 點 XP ，你可以自行領悟此招式的進化形態：翔尾旋</li>
</ul>

**正文**

以強力斬擊打向地面，借反彈之勢實現雙重加速，是極爲兇狠的招式。

## 翔尾旋

**效果**：以一個整輪動作，你對目標發動一次白刃攻擊檢定，並且若成功命中，則你可以立刻對與其相鄰的另一個目標發動另一次白刃攻擊。你在第一次攻擊中每獲得三個成功數，你的第二次攻擊檢定就可以獲得 +1DP 的速度加值，並且你每因此而獲得 +5DP 的速度加值，你就能選擇再獲得一個附加成功，但每因此而獲得一個附加成功，你在防禦上就要承受 -2 減值，並且每多一個再額外 -1 （例如一個是 -2 ，二個是 -5 ，三個是 -9 ，類推），持續一輪。你在使用此招式之前或之後，可以以自由動作移動不超過自身體積值的距離。但若你在發動第一次攻擊之前並沒有進行過移動，那麼你可以在攻擊之後，以自由動作移動到另一個目標身旁再發動第二次攻擊。若你這麼做，那麼你每移動 1 米，你所獲得的速度加值就減少 1 點。

這是戰國末期，一名無名的天才劍士所獨創的劍術流派。

據說這名劍士曾經系統的學習了包括劍術、居合術、氣合術、柔術、槍術等在內的各種武術，並將其糅合在一起，從而形成了這門劍術流派。其基本技巧和通常意義上的劍術並沒有什麼不同，但擁有各種不同的持刀架勢，即便是相同的技巧，在不同的架勢下也能轉化出不同的招式，根據對手的不同，可以以不同的技巧針對性的予以剋制。
