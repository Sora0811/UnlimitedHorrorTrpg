# 飛龍探雲手

> 來源：`資源/技藝/特殊招式/飛龍探雲手`

**描述**

<ul>
<li>“飛龍探雲手”是仙劍奇俠傳系列中相當受歡迎的仙術，此技能通過消少量的 [ 氣 ] ，有一定幾率能偷竊敵人身上的物品或金錢。哪怕對方是正面看着你……</li>
<li>仙家的事，能叫偷麼？</li>
<li>※特殊地，任何 ST 都有權以諸如可能破壞劇情的理由禁止強化這項技藝，哪怕通過了這項技藝的強化，亦有隨時禁止這項技藝不可對某些 NPC 使用的權利。</li>
<li>※特殊地，補充一句，這個技藝的原名應該叫【龍捲脫 bra 術】。隨便說說，不要當真。</li>
</ul>

**效果**

<ul>
<li>可以像擊落武器一般，卸除對方的鎧甲。首先你需以肉搏攻擊對對方進行一次接觸攻擊檢定，若成功，則以敏捷 + 肉搏 / 偷竊（專業：卸甲）進行檢定，且承受 5 點減值；對方以敏捷 / 力量 + 肉搏 / 運動取高對抗。若你勝出，則可以卸除對手的一件盔甲 / 衣物，隨機決定。不過此時被脫掉的道具會丟在地上，任何人都可以以一個移動動作撿起。</li>
<li>顯然的，對手無論如何都會發現你正在【偷竊】他。哪怕你是隱形的，使用這個技藝後也會令對方立刻模糊定位你。</li>
<li>此外，如果敵人是多重着甲，你可以指定直接卸除內甲（這意味着，你可以在不脫掉外衣的情況下把 bra 取出）。</li>
<li>熟能生巧，你使用飛龍探雲手的時候不再需要承受減值，且卸掉的物品不會丟在地上，而是出現在你的手中。同時，你可以偷取到對方未使用的、在身上放置的體積 2 以下的其他物品，例如飾品、小件消耗品等。偷取到哪件物品由 ST 隨機決定。</li>
<li>現在你可以遠程使用飛龍探雲手，距離是感知 \*5 米 \* 層數，第一回合，你需要使用標準動作卸掉物品，第二回合使用一個標準動作維持，拿到卸掉的物品。如果第二回合沒有維持，或者是中間被人打斷，則物品掉在地上。此外，你可以將技藝層數，加到卸甲術的檢定中。</li>
<li>你可以“偷竊”敵方的所有持有或未持有的物品，但偷取到哪件物品仍由 ST 隨機決定。</li>
<li>飛龍探雲手現在不需要第二回合標準動作的維持，卸掉的物品會直接出現在你的手上。發動飛龍探雲手的時候，你可以指定對方身上的物品。</li>
<li>此時，你可以偷竊的東西甚至包括對方空間袋中的物品。</li>
</ul>

**說明**

<ul>
<li>飛龍探雲手現在由自然本質變爲了特異本質，正式進入“仙家技藝”的大門。</li>
<li>從蜜蜂身上偷蜜，從毒蛇身上偷毒蛇卵，從鳳凰身上偷羽毛，從鳥身上找到引路蜂。看上去並沒有什麼不對嘛！</li>
</ul>
