# 天龍吼 BB+5000

> 來源：`資源/技藝/特殊招式/天龍吼`

**增幅**：發招前，可以額外投入能量來強化射程與傷害。每投入 1 點能量，你在體魄 + 運動的檢定上就獲得 2DP 的加值，可投入的能量最多不超出體魄上自動成功數。

**特殊**

<ul>
<li>以基礎消耗時發招時，視覺效果只有掃平一切的佛光衝擊波，蓄力發招的話，消耗的能量越多，發招時越會出現驚人的異象，諸如背後浮現出怒吼的龍首、佛光凝聚爲轟向敵人的八部天龍、漫天灑落金色花瓣、從不知名處響起 BGM 等等。</li>
<li>異象可以由 PC 自己設計。</li>
</ul>

**其他標籤**

**特別**

<ul>
<li>如果出招時喊出“呵～天龍吼～～～”，判定傷害 +1DP ，這是個表演加值。</li>
<li>如果再額外唸誦詩號“世事～如棋～乾坤～莫測，笑盡～～英雄～～～啊～～”，再額外加 1DP ，同爲表演價值。</li>
<li>如果同時播放梵天一頁書的武戲 BGM 《一氣動山河》，那麼再額外獲得 1 自動成功。</li>
</ul>


**正文**

出自霹靂布袋戲，佛門大能・百世經綸一頁書的絕學之一，威力喪心病狂，無數邪道強人被此招生生吼爆，一度被武林人士冠以“千里碎腦神音”之異名。

此招與同類武學如來神掌中的“佛問珈藍”孰強孰弱，一直是無限空間中武力側人士津津樂道的話題。

施展此招時，消耗一整輪動作和 5 點能量，凝氣匯元，繼而化作至極玄音吼出。音波與浩瀚佛元形成炫目金光。梵音開路，破雲裂地，不僅令山河動搖，更能震盪神魂，超度一切邪能！

招式消耗能量數 /20 米的錐形範圍內敵人都會承受一次接觸攻擊，攻擊骰關鍵屬性爲體質 + 運動。這次傷害是物理 + 音波 + 光能的三重混合傷害，具有“魔法”、“幽冥”、“高速 8 ”與“神聖”特性，並且只有同時具有物理、音波與光能類型的抗力（或能量抗力）纔可以抵抗此傷害。然後，他們還會承受一次範圍傷害，數值是上一次體魄 + 運動的檢定成功數，你還可以將力量上的自動成功加入其中。敵人在進行敏捷 + 運動的閃避之外，還必須要用體魄 + 神祕（若沒有可選用爲意志）來進行一次檢定， DC 爲所受傷害數。如果未通過的話，敵人將受到差額的意志傷害。你可以令其承受一種或者數種不良狀態點數，不良狀態點數總和 = 其所受意志傷害，類型由你從噁心、耳鳴、精神束縛中指定。

如果意志傷害累計超過其意志，敵人則進入震懾狀態。

如果敵人是靈體、黑暗生物或者擁有邪惡能量，那麼還可以將其所受傷害轉化爲惡性傷害，轉化上限爲單次所受意志傷害。
