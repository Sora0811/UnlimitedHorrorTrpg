# 左右互搏之術

> 來源：`資源/技藝/特殊招式/左右互搏之術`

**價格**：dd 級 +2000

**前提**

<ul>
<li>沉着值高於智力值</li>
<li>由老頑童周伯通所創造的技巧，從左手畫圓右手畫方開始，最終可用兩隻手使用不同的招式。</li>
<li>這門技藝唯有性格單純的人才能學會，習得此技巧必須有高於自身智力值的沉着值。</li>
<li>使用此技巧後，你可用雙手進行兩次攻擊，並且可以在這兩次攻擊中使用不同的 d 級招式 （ dd 級被視爲 d 級），其動作爲兩個招式中所需的時間最長的動作。（比如搭配一個整輪和標準動作的招式所需時間爲一個整輪動作。）</li>
<li>當你選擇使用的攻擊方式之後（肉搏 / 白刃），若目標的對應技能低於你，那麼使用這個技巧他將因爲陷入措手不及。若你分別選擇白刃和肉搏，則其針對低於你對應技能的攻擊將陷入措手不及</li>
<li>另外使用這種技法會降低你基礎攻擊判定（相關屬性 + 相關技能 + 相關專業） DP 數，數值相當於一半，向下取整。然後單獨計算你雙手持有不同武器的傷害值。比如你有一把傷害爲 3L 長劍，可以通過右手持劍揮砍，使用劍的傷害值，左手用拳頭進行打擊，使用你天生武器的傷害值；</li>
<li>你無法使用雙手的招式或者武器，這意味着，你無法通過左右互搏進行兩次弓箭射擊，因爲使用弓箭需要兩隻手。因此你也無法通過把兩次能量射擊，除非你有兩種不同能量池提供能量的能量射擊。</li>
</ul>

**進化**

<ul>
<li>花費 16xp 後，你能同時運用的招式上限等級爲 C 級。同時措手不及上升至 C 級效果。</li>
<li>花費 36xp 後，你能同時運用的招式上限爲 B 級。同時措手不及上升至 B 級效果。</li>
<li>花費 64xp 後，你可同時運用的招式上限等級爲 A 級。同時措手不及上升至 A 級效果。</li>
</ul>

**特殊**：本能力下的DP下降是最終的攻擊DP，也就是經過所有加值和減值，再計算下降後的DP數，然後計算目標的防禦。

**其他標籤**

**類型**：技藝


**正文**

假如擁有更多可持有武器的肢體，亦或者是更多種天生武器。 st 可以允許將每次攻擊的 dp 下降爲更多分之一，進行更多次打擊。這意味着擁有更多肢體的前提下，你可以將左右互搏運用在需要雙手的武器上。

比如一隻六臂蛇魔持有六把長劍時，可以用單次攻擊 dp 下降爲六分之一爲代價，同時使用六次不同的招式；持有三把弓箭的情況下，以攻擊 dp 爲三分之一爲代價，使用三種不同的魔弓術。一隻怪力可以用四臂，以單次攻擊 dp 下降爲四分之一爲代價，使用四種不同的招式。
