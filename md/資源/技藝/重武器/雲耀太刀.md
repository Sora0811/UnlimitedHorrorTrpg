# 雲耀の太刀 CC+3000

> 來源：`資源/技藝/重武器/雲耀太刀`

**前提**

<ul>
<li>雙手持握體積不小於你自身體積 -2 的武器</li>
<li>“沒有我斬艦刀斬不斷的東西！”</li>
<li>曾伽 - 宗博魯特之成名絕技，以一刀兩斷聞名於世，是瞬間以一招唐竹將對手從頭到腳一刀兩斷的超級劍技。</li>
<li>這是一個招式，你可以在衝鋒和全力時使用本招式。</li>
<li>使用時，攻擊獲得 +3 招式加值和 +3 速度加值，攻擊任何體積比武器大的目標，再忽略武器體積的硬度。攻擊比體積小的目標時，忽略武器體積的格擋防禦。</li>
</ul>
