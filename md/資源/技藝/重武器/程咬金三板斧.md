# 程咬金三板斧 ( 技藝 )

> 來源：`資源/技藝/重武器/程咬金三板斧`

**正文**

混世魔王程咬金，在某些平行世界中說程咬金曾在瓦崗寨建立政權，國號大魔，年號大德，所以被後世稱爲大德天子混世魔王，其三板斧相當厲害。

其實斧法有三十六路，不過一般對敵的時候，僅僅只用三招。

如果三招下去仍未建功，程咬金就會拍馬溜走。

因爲該斧法能夠成爲技藝的僅僅只有三招，所以主神收錄了這三板斧作爲一套連貫的招式。

切西瓜（ 1000 ）

勢大力沉的一斧從上方直劈而下。

這招。。。沒什麼其他的效果，當你施展時，你的攻擊 DP 可以獲得 +1 的速度加值。並且本次攻擊獲得效果。

特殊的，這招之後，你的下一次攻擊可以獲得 +1 速度加值，這個可以不斷疊加，但是上限只有 3 。

小鬼剔牙（ D+1000 ）

在直劈之後讓手腕急速抖動，向着頭部橫劈。

僅僅在你使用這個招式，你的攻擊獲得【威猛 3 】與【高速 3 】，如果你上一輪大吼了“切西瓜”並使用斧頭攻擊，你的攻擊除了獲得切西瓜的速度加值之外，額外再獲得 +3DP 速度加值。

掏耳朵（ DD+1500 ）

在橫劈之後利用身體的迴旋力，斜劈脖子，一般來說，這會是一個斬殺效果。

你獲得 +3 附加成功

如果你上上一輪大吼了“切西瓜”上一輪你大吼了“小鬼剔牙”並使用斧頭攻擊。則你可以獲得上面的全部速度加值與特殊效果。而且你可以大喊“掏耳朵”並強行調整你的一個骰子變爲 8 （可以被防禦上的附加成功抵消，但是 DR 與全傷害吸收以及傷害抵消能力不能把這個骰子帶來的傷害抵消）。

這三套板斧超越了凡人的技藝，達到了無限的領域。

因此，可以選擇用 xp 或者點數來進化這三板斧。

支付 26XP 或者 C2000

你的切西瓜進化爲天旋地轉。

神力爆發，雙斧隨身體疾轉，罡氣旋射，割臉生痛，有開山裂石之威，

在保留切西瓜的效果的同時你的近戰攻擊骰可以造成相同點數的範圍傷害，但是一場遭遇只能用一次。

支付 26XP 或者 C2000 ，你的小鬼剔牙進化爲雷霆怒劈。

產生雷霆閃光，可比傳說中的天神雷公，氣勢無可比擬。

在保留小鬼剔牙的同時，你可以選擇消耗任意點數的東方能量（內力，靈力）或者鬥氣 .

來爲你的這一次攻擊增加等量的 DP （上限爲 20 ），加值爲能量加值，每消耗 5 能量還額外會加一個雷電傷害的附加成功。

支付 40XP 或者 B4000 ，你的掏耳朵進化爲狂風暴砍。

以雙斧施展，能瞬間劈出 108 擊，將對方化爲肉醬

消耗五點能量，在保留掏耳朵的基礎上，你可以在近戰攻擊的同時，迅捷動作附加一次天旋地轉，並在對方的反射鑑定上減少你的近戰攻擊檢定成功數的 DP 。
