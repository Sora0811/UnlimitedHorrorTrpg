# 斧技・魚龍大活殺

> 來源：`資源/技藝/重武器/魚龍大活殺`

**效果**

<ul>
<li>消耗 1 點鬥氣和一個標準動作，你揮動斧刃，進行一次力量檢定。你可以製造出傷害等於你檢定結果、範圍爲你（白刃技能上附加成功 +1 ）米的一次範圍傷害，反射減免。若敵人在這次傷害中受傷，會額外獲得等同於受到傷害數的束縛點數。</li>
<li>在這個招式結束後，需要等待至少 1 輪才能再次使用這個招式。</li>
<li>你只能對失去基礎防禦，或措手不及的對手使用本招式（因此，你無法宣言因爲本招式附帶了大於對手基礎防禦的高速來直接使用本招式）。消耗 1 點鬥氣和一個標準動作，進行一次肉搏檢定。施展此技能時獲得 1L 傷害的天生武器手刀或者你本身的取高。若本次攻擊造成了傷害，你可以立刻對其進行一次衝撞，但只能選擇向後擊退。</li>
<li>在這個招式結束後，需要等待至少 2 輪才能再次使用這個招式。</li>
<li>消耗至少 1 點鬥氣和一個整輪動作，對一個活着的類人生物、或者死亡不超過 4 個小時的類人生物屍體進行一次肉搏攻擊。在這次攻擊後已死亡的生物，會在至少 1 輪後產生劇烈的爆炸，造成傷害等同於你的肉搏等級 + 鬥氣等級、範圍爲 10 米、類型爲穿刺的範圍嚴重傷害，反射減免。</li>
<li>你可以自由決定爆炸延遲的時間，最少爲 1 輪，最多不超過你的肉搏技能等級。</li>
<li>此外，多變的鬥氣使用方式可以令本招式變得更加強勁。每多注入 1 點鬥氣，你皆可以在以下效果中選擇一項：</li>
<li>\- 增加 1L 的爆炸傷害；</li>
<li>\- 增加 5 米的爆炸範圍；</li>
<li>\- 令爆炸時間延長最多 1 小時，在此期間，屍體的狀態會停留在你對其施展此技能的狀態；</li>
<li>\- 在爆炸時間內設置“當具有魔力或鬥氣的人觸摸此屍體時纔會爆炸”的條件。</li>
<li>以上效果可以重複選擇，但額外注入的鬥氣不可超過你的鬥氣等級 +1 。</li>
<li>消耗 1 點鬥氣和一個標準動作，你雙手持斧，以耐力檢定進行一次蓄力檢定；在蓄力之後，你可以以一個標準動作猛力擲出手斧，進行一次投擲攻擊檢定，但以力量 + 白刃代替敏捷 + 運動進行檢定，並將蓄力檢定的結果作爲招式加值加在你的這次攻擊 DP 中。這次攻擊若造成了至少 1 點傷害，你可以令手斧掉落在對方所在的位置（若並未造成傷害，一般來說會飛至本次攻擊的基礎投擲距離的、離投擲距離最近的整數倍上限；特殊情況例如被攔截、被二指真空把等，由 ST 自行判斷）。</li>
<li>在這個招式結束後，需要等待至少 3 輪才能再次使用這個招式。</li>
<li>以一個整輪動作發動。你如衝鋒般進行一次移動，在移動後以力量 + 肉搏 + 天生武器傷害進行一次攻擊檢定，施展此技能時獲得 1L 傷害的天生武器手刀或者你本身的取高。在本次攻擊中正常獲得衝鋒的好處和壞處；在攻擊後，你可以一個自由動作，以腳將手斧挑回手中。</li>
<li>在這個招式結束後，需要等待至少 3 輪才能再次使用這個招式。</li>
<li>你只能對正在空中飛行、飄浮、跳躍或滑翔的目標使用這個招式。支付 1 點鬥氣，以一個標準動作進行一次投擲攻擊。在這次投擲中，你不會因爲攻擊基礎投擲距離× 3 以內的目標承受距離減值，且你投擲的手斧視爲具有“重投擲武器”特性。在這次攻擊中，你具有額外的【破甲】 2 。</li>
<li>在這個招式結束後，需要等待至少 2 輪才能再次使用這個招式。</li>
<li>你只能對正在空中飛行、飄浮、跳躍或滑翔的目標使用這個招式。支付 1 點鬥氣，以一個標準動作進行一次投擲攻擊。在這次投擲中，你需以敏捷 + 白刃作爲攻擊的關鍵屬性和關鍵技能。在這次攻擊中，你具有額外的【威猛】 2 ，且攻擊的武器視同具有“回飛”特性。</li>
<li>特殊地，哪怕是在你的攻擊範圍內沒有飛行的目標，你也可以空放這個招式。目睹這個招式的敵人若白刃等級在 3 以上，則會產生“聖光啊這個敵人值得一戰！”或類似的想法――但並沒有其他的用處。</li>
<li>在這個招式結束後，需要等待至少 2 輪才能再次使用這個招式。</li>
<li>本技能沒有主動用法。在習得本技能後，你以“魚龍大活殺”招式進行的攻擊，皆可自由留手，甚至可以選擇本次攻擊只造成衝擊傷害，若你如此做，智力等於或高於 2 的目標皆會清楚地知道“你在這次攻擊中手下留情了”。</li>
<li>此外，在你進行任何以“魚龍大活殺”招式進行的攻擊後，你可以再支付 1 點鬥氣，以反射動作收回手斧並令本次攻擊及其附帶的效果無效（因此，你可以選擇在造成傷害前或後使用這個招式）。但以智力 + 白刃（而非掩飾）進行一次虛招檢定。以這種用法使用“返雷”後，需要等待至少 1 輪才能再次使用這個招式。</li>
<li>特殊地，若敵人以反射動作應對了你的攻擊，但受到“返雷”影響，且對方未通過虛招的對抗檢定，你可以選擇本次虛招不產生通常的效果，而是令對方在你的虛招檢定結果 / 輪內無法使用反射動作。</li>
<li>你只能在上回合或本回合使用了其他“魚龍大活殺”招式去攻擊對手但沒有造成任何傷害後纔可使用本招式。支付 3 點鬥氣，以一個標準動作，選擇一個等同於你以手斧進行投擲的基礎射程× 3 米內的對手，首先以你攻擊的對手爲中心製造一次“浪旋陣”，之後進行一次白刃攻擊，但關鍵屬性爲你的力量 / 敏捷取高。若對手以反射減免了“浪旋陣”的傷害，則在這之後的白刃攻擊中失去包括基礎防禦在內的所有閃避防禦；對手亦可以選擇不減免“浪旋陣”的傷害，但保留自己的閃避防禦。對手會本能地知道做出這兩種選擇的後果。</li>
<li>在表現上，你的對手剛剛爲躲過了你的攻擊沾沾自喜時，你不知何時擲出的手斧已經打着旋飛回，在他身後當頭劈下；與此同時，你雙手合攏，如浪潮般的鬥氣從四周向他湧去，封死了一切可以閃避的空間――除了手斧劈下的那一點位置。</li>
<li>在這個招式結束後，需要等待至少 4 輪才能再次使用這個招式。</li>
<li>支付 3 點鬥氣，以一個標準動作，選擇一個在你基礎速度× 2/ 米內的對手，進行一次投擲攻擊，但關鍵屬性與技能使用力量 + 白刃；同時進行一次移動，在這次移動中，你可以移動最多等同於你基礎速度× 2 的距離，無須直線。</li>
<li>這次投擲攻擊若造成了至少 1 點傷害，你可以令手斧掉落在對方所在的位置；若你移動後停留在你投擲的目標身邊，你可以接住手斧。</li>
<li>特殊地，哪怕你手中沒有手斧，也可以使用本招式。此時，當你移動的路徑中，你的觸及範圍內有無主的手斧，你可以一個自由動作將其抓在手中。</li>
<li>在這個招式結束後，需要等待至少 4 輪才能再次使用這個招式。</li>
<li>支付 5 點鬥氣，以一個整輪動作使用。選擇一個在你鬥氣等級 /10 米內的敵人，將手中的手斧擲出、或者以鬥氣操控在你感知 / 米範圍內的手斧，進行一次力量 + 白刃 + 鬥氣等級的檢定，你可以忽視等同於檢定結果的、基於某種能量產生的防禦數；在這之後，以力量 + 肉搏 + 天生武器傷害進行一次攻擊檢定，施展此技能時獲得 4L 傷害的天生武器手刀或者你本身的取高。</li>
<li>特殊地，當你受到一次依託某種能量的攻擊（即攻擊主體是由能量擔任的，包括但不限於：以魔法推動的射線、小天星指射出的劍氣、能量射擊的任何形式，但長劍上纏繞着雷電能量並不算）時，可以以反射動作施展本招式。此時，以力量 + 白刃 + 鬥氣等級的檢定對抗對方的攻擊 DP 檢定。若你勝利，對方的本次攻擊無效，但也無須在防禦上受到任何減值。之後，你仍以力量 + 肉搏 + 天生武器傷害進行一次攻擊檢定，施展此技能時獲得 4L 傷害的天生武器手刀或者你本身的取高。</li>
<li>在你以反射動作使用這個招式後，跳過你下一輪的標準動作。</li>
<li>在劇情表現上，你擲出的手斧與對方所發出的能量相遇時，突然以斧的尾端爲中心旋轉開來，硬是在能量波中撕開了一個口子，而且越來越大。十六發手刀所發出的霸海濤鬥氣從口子中通過，直取敵人首級。</li>
<li>在這個招式結束後，需要等待至少 4 輪才能再次使用這個招式。</li>
</ul>

**前提**

<ul>
<li>要使用此招式，你選擇的目標需滿足可衝鋒的標準，且在不高於你肉搏等級 / 米範圍內必須有一柄無主的手斧。（注：也許有的 ST 會判定將手裏的東西丟棄是一個自由動作，但扔到指定位置一定是一個以標準動作的投擲）</li>
<li>已學習“浪旋陣”。</li>
<li>將手斧離手後，以鬥氣控制手斧藏在鬥氣浪潮中，如同鬼鯊一般在出乎預料之時，一擊斃殺對手。</li>
</ul>

**其他標籤**

**變體**：在這個技藝中提到的，使用肉搏檢定的部分，肉搏技能等級皆可使用（白刃技能 /2 ）代替，附加成功按照新的技能等級計算。

**強化前提**

<ul>
<li>力量 5 及以上、敏捷 5 及以上、白刃 5 及以上並具有專業：手斧；具有鬥氣。</li>
<li>你只能使用體積等於或低於你的體積 -2 的單手手斧，使用下面的【招式】及【架勢】。</li>
<li>【架勢】： C+2000 可以買齊全部四種架勢</li>
<li>這些架勢皆爲搭配招式使用，且本身也具有一定的附加效果。所有的架勢皆佔用身法位。你每次使用“魚龍大活殺”的招式後，皆可使用一個迅捷動作，啓動或切換一種架勢。你只能同時維持一種架勢。這種架勢會持續生效，直到你下次切換架勢或場景結束，看哪個先到來。</li>
<li>此外，某些招式無法在指定架勢下使用。</li>
<li>已購買魚龍大活殺的其他所有招式和架勢。</li>
</ul>

**疾風掠影**

<ul>
<li>身體前傾、狂飆突進的架勢。</li>
<li>啓動這個架勢後，你的移動速度會增加，相當於你掌握的“魚龍大活殺”招式數 / 米。</li>
<li>當你進行衝鋒時，你在攻擊後可以沿着你的衝鋒方向繼續移動，但移動的距離仍不可超過本次衝鋒可以移動距離的上限；在攻擊後的這次移動中，你可以對你碰觸到的、不超過你掌握的“魚龍大活殺”招式數量的目標進行一次衝撞，但你只能選擇令其移動，方向需與你移動的方向相同；若你具有在衝鋒過程中改變方向的能力，該能力亦可作用於這衝鋒後的移動中。</li>
</ul>

**烽火無垠**

<ul>
<li>虛藏鋒刃、伺機攻擊的架勢。</li>
<li>啓動這個架勢後，每當你進行格擋防禦，你的下一次攻擊 DP 就會 +1 招式加值，可以和“魚龍大活殺”招式中提供的招式加值疊加，上限爲你掌握的“魚龍大活殺”招式數。這些招式加值會持續一個場景，切換架勢並不會導致這些加值失去。</li>
</ul>

**林止萬森**

<ul>
<li>平衡身心，攻、守、速平均分配的架勢。</li>
<li>啓動這個架勢後，你無法在攻擊或防禦中消耗意志力來獲得攻擊或者防禦上的加值。每次你使用“魚龍大活殺”的主動招式前皆可扣除攻擊 DP 或基礎防禦上較高者，在較低者上獲得同等數量的加值，你以此法調整的數量最高不超過二者數值之差，或者你的白刃技能中的較低者。這個用法不佔用動作。若你的某次攻擊 DP （在計算對方防禦值之前）與你的防禦值相同，你可以在直到你下一輪攻擊前，意志、反射和強韌檢定上額外獲得 +2DP 和 1 附加的完美加值。這個調整產生的效果會持續到你的下一次調整或架勢切換，視哪個先到來。</li>
</ul>

**金山不動**

<ul>
<li>原地不動、全力以赴的架勢</li>
<li>這個架勢只能在地面啓動。啓動這個架勢後，你的雙腳紮成堅實的馬步，對抗衝撞、擒抱、拌摔時獲得 +5DP 的招式加值，並在防禦上獲得 +3 招式加值。但若你進行了移動（不管是主動還是被動的）都會立刻失去這個架勢的效果。在這個架勢下使用的“魚龍大活殺”招式時，視爲你持用的手斧具有“回飛”效果。</li>
</ul>

**連續技**

<ul>
<li>若你在上個回合切換了架勢，你可以一個反射動作使用這個招式。</li>
<li>若你在上個回合使用了招式“幼龍初吟”，對方的反射檢定會受到等同於“幼龍初吟”造成傷害的減值。</li>
<li>若你在本回合切換了架勢，你可以以一個移動動作使用這個招式。</li>
<li>若你在進行蓄力的上回合使用了“返天宴”或“七月皎夜”，則“斬浪破濤”的蓄力變爲一個移動動作。</li>
<li>若你上個回合使用了招式“斬浪破濤”，你可以以智力 + 肉搏（而非掩飾）進行這次虛招檢定。</li>
<li>若你上個回合使用了招式“浪旋陣”，額外獲得等同於你本次攻擊中附帶【破甲】的【破魔】。</li>
<li>在你使用招式“幻海擊巖”之後，直到你下回合結束，你可以以反射動作使用這個招式。</li>
</ul>

**幻海擊巖**
