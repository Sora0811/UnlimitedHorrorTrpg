# 皇璽劍印

> 來源：`資源/技藝/風姿物語/皇璽劍印`

## D 級

**價格**：D+800

**需求**：天魔功?心法（ D 級）

**效果**

<ul>
<li>\1. 如果你之前沒有，那麼現在獲得肉搏技能上的專業：指法。如果已有，則專業加成提高 1DP 。並且你可以使用敏捷而非力量來作爲指法攻擊的調整值。</li>
<li>\2. 習得招式：皇璽劍印。消耗 1 點天魔勁與一個標準動作進行一次敏捷＋肉搏（指法）的肉搏攻擊，你以指射出一道黑色劍氣。這視爲一次遠程的近戰穿刺攻擊，射程單位爲 10 米。</li>
<li>\3. 在這次攻擊中，你可以獲得當前天魔功心法等級數的招式加值 DP 。</li>
</ul>

**價格**：D+800

## C 級

**價格**：C+1600

**效果**

<ul>
<li>\1. 只要你的天魔勁不空，你的天生武器（指）提升相當於皇璽劍印等級的傷害。</li>
<li>\2. 射程單位提升到肉搏等級× 10 米。</li>
<li>\3. 在你使用招式“皇璽劍印”時，若將基礎消耗提升至 3 點，在對敵人造成傷害後，可以</li>
<li>――讓對方立刻進行一次強韌或者意志檢定（取高）， DC= 你造成的傷害。如果檢定失敗，其生理屬性檢定將承受失敗差額的減值，不可疊加。這視爲一個原理爲【能量】的封鎖效果。對方每輪都可以進行一次強韌檢定，累積到 DC 之前，效果不會消失。對方可以通過消耗關鍵屬性爲生理屬性的能量來提高加值。每 1 點能量 +1DP 。不過無論檢定通過與否，消耗的能量都不會返還。</li>
</ul>

**增幅**：每額外消耗 1 點天魔勁，皇璽劍印額外獲得 1DP 加值。可消耗的天魔勁上限爲肉搏技能上的附加成功。

**價格**：C+1600

## B 級

**價格**：B+3200

**效果**

<ul>
<li>\1. 只要你的天魔勁不空，你每習得一種天魔勁進階，你的肉搏攻擊就可以額外忽視 1 點任意的傷害減免。</li>
<li>\2. 使用肉搏攻擊時獲得 9 加骰。如果已有，提升到 8 加骰。</li>
<li>\3. 射程單位提升到肉搏等級× 20 米。</li>
<li>\3. 使用招式“皇璽劍印”可以結成劍印，製造出一片無形的領域。領域中的空間連同內部的一切統統被鎮壓凝固。這是一個全回合動作，並且消耗 5 點天魔勁。雙掌合印，你照常進行一次【皇璽劍印】的攻擊，但是不會造成傷害。無形的波動 透體而出，在半徑攻擊判定成功數 / 米的範圍內製造出一片凝固空間領域。這個領域有以下效果</li>
<li>――位於領域內部並被你指定的單位必須要進行一次反射 / 強韌 / 意志檢定（目標選擇其中一種），對抗你的領域製作成功數。對方可以將體積作爲 DP 加值加入到對抗當中。如果對抗失敗，則直接進入【定身】狀態；即使對抗成功，也會受到領域製作成功數的糾纏點數，必須從領域當中脫離才能消除。這視爲一個原理爲【空間】的糾纏效果。</li>
<li>――位於領域外的單位進入領域內同樣要進行對抗判定。</li>
<li>――領域持續到你下一次行動開始。期間你必須專注引導，如果進行任何防禦之外的動作，劍印領域自動解除</li>
<li>――如果想要用解除魔法或者干涉空間的能力來破除你的劍印領域，那麼需要對抗你的領域製作成功數。</li>
</ul>

**價格**：B+3200

## A 級

**價格**：A+7000

**效果**

<ul>
<li>\1. 皇璽劍印的射程提升至肉搏等級× 50 米</li>
<li>\2. 皇璽劍印在 C 級的基礎上，你從以下效果中選擇一種生效：</li>
<li>――若成功命中對方，選定對方一種能量池，凍結造成傷害點。對方每輪都可以進行一次強韌 / 意志檢定，對方可以通過消耗關鍵屬性爲生理屬性的能量來提高加值。每 1 點能量 +1DP 。不過無論檢定通過與否，消耗的能量都不會返還。在檢定通過之後，凍結的能量才能正常使用。</li>
<li>――若成功命中對方，凍結對方的快速醫療 / 再生，持續 1 輪 / 你造成的傷害數。</li>
<li>\3. 施展【皇璽劍印?鎮壓空間】時，如果將消耗提升至 7 點，則施展和維持所需動作可以降低到一個標準動作。領域可以在製作出的地方維持，直到你下次行動開始；也可以跟隨着你一起移動。</li>
</ul>

**價格**：A+7000

**正文**

魔界皇族無上祕籍《天魔功》的外門絕學之一。與尋常劍氣、指法不同，皇璽劍印是以小指與無名指催發劍氣，並且側重的並非一般劍氣的“穿刺”與“切割”，而是“封鎖”與鎮壓。此門武學練至高段甚至可以製造出一片凝固空間的無形領域，封住敵人的一切行動後，從容擊殺。
