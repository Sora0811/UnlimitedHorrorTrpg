# 天魔功（心法?魔道武學）

> 來源：`資源/技藝/風姿物語/天魔功（心法）`

**簡介**

<ul>
<li>天魔功是自成一套體系的強化功法，不過作爲其核心的，便是以吸蝕特性而着稱的奇特真氣。只要能量不夠凝實，那麼在天魔勁前只會一觸即潰，然後被吸收同化，平白讓天魔勁更加壯大。基於這種特性，天魔功的使用者更是無懼天下絕大多數的暗算手段，只要將天魔功運轉一個周天，體內一切毒素、暗勁、詛咒、乃至其他入侵能量都會被吸收的一乾二淨。</li>
<li>某名高位的武力側輪迴士在閒暇之餘，將《風姿物語》中魔界皇族武學與《天子傳奇》中原始天魔功合二爲一，去蕪存菁，重新整合爲一部全新的武學典籍。因爲可以按部就班的系統學習，故被主神收錄入強化當中。</li>
<li>本武學雖然被歸類爲魔道功法，但是本質上，乃是以“無情、無思、無我”爲中心，令自身存在嵌合冥冥天道，從而生出大威力、大滅絕；但若修習者不明無情真意，流於殘忍好殺，失去清明心境，則永無望進窺最高境界。</li>
</ul>

## D 級

**價格**：D+1000

**前提**：非光明生物。

**價格**：D+1000

### ――――――――――――

**說明**

<ul>
<li>\1. 天魔勁視爲標準內力的變體，關鍵屬性與恢復方式皆相同，但是沒有標準內力的用法。</li>
<li>\2. 天魔勁被視爲內力的通用能量，但無法被除了天魔功本身之外的任何強化能量池的方法強化；如果用其推動其他武學招式，那麼可以將天魔勁本身包含的特效一起算入招式的加成當中</li>
<li>\3. 本級別的天魔勁雖然不足以外放吸蝕，但是已經具備了初步的吸引效果，並且可以作用於體內。</li>
<li>\4. 有些能力雖然可以通過額外消耗天魔勁來獲得更多效果，但是連同增幅與搭載的進階在內，一次內所能消耗掉的天魔勁總和不能超出你的肉搏技能等級。每超出 1 點，會讓你獲得 1 點墮落值（見上文）。</li>
<li>\5. 天魔功在 C 級時，消耗天魔勁發動的攻擊獲得【魔法】；在 B 級時獲得【幽冥】，在 A 級時獲得【神兵】。</li>
<li>\1. 每輪使用吸納的次數不限，但是可丟的總 DP 上限不能超出當前剩餘的天魔勁數量，由你自由分配到每一次當中。</li>
<li>\2. 【吸納】的作用時機爲計算完傷害吸收與減免之後。</li>
<li>\3. 本動作具有【武學推演】關鍵字，並同時佔據【護身勁】位置。</li>
<li>\4. 只能吸收物理傷害。</li>
</ul>

**其他標籤**

**天魔勁**：你開啓了能量池――【天魔勁】。

**吸納**：在遭受攻擊時，可以以自由動作進行一次 DP 相當於你當前所剩天魔勁的檢定，然後將成功數按照 2 ： 1 的比例抵消掉等量傷害；每抵消一點傷害，你就需耗費一點天魔勁。

**正文**

同爲魔龍皇拳三大極式之一的天魔大滅絕，與轟雷赤帝衝有相似的作用，一者憑靠衝擊，一者憑靠渦旋，輔助使用者將轟出去的力量高度集中，減少流失，只要天心意識配合得當，甚至能爆發出平時兩到三倍的強橫力量。

消耗一整輪動作與 10 點天魔勁，依然以“天崩”的架勢起手，但是全身天魔勁萬馬奔騰般竄走，遠遠超越“天崩”發動之時 ，連帶影響着你周遭方圓十里的空間，牽動九天風雲，高速旋轉，越轉越快。扯下的雲氣在旋動中不斷被天魔勁渲染上如墨的漆黑，天地元氣前所有爲的凝聚，激增着威力，最終化成一個以你爲中心，巨大的黑色漏斗雲渦。此時進行一次體魄檢定，檢定結果爲雲渦的結構（生命）值。你可以將黑色的雲渦貼在身邊，也可以擴散出去，籠罩半徑消耗天魔勁數 / 米的範圍。黑色雲渦擁有天魔功等級的全傷害吸收，硬度相當於本招消耗的天魔勁總數。被困在雲渦內的單位如果發動攻擊，那麼會被雲渦立刻吸收，劇情表現上爲被四周的魔氣迅速分解吞噬。在完全破壞這層雲渦之前，內部的單位無法移動到雲渦之外。第二輪，你可以照常發動一次【天崩】，而且在 B 級的基礎上有以下提升。

――攻擊骰獲得一定能量加值的 DP ，數值等於當前雲渦剩餘的結構值。

――你在技能對抗時獲得一定速度加值的 DP ，數值等於當前雲渦剩餘的結構值。

――對方如果對抗失敗，還會視爲措手不及。

――衝鋒的距離提升到陸行速度的 2 倍。

<ul>
