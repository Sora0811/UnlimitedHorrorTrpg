# 技藝――BGM（背景音樂）

> 來源：`資源/技藝/其他能力/BGM`

<ul>
<li>特異本質</li>
<li>科技本質</li>
</ul>

**價格**

<ul>
<li>C+2000</li>
<li>1</li>
</ul>

**特性**：絕對唯一，BGM，調音師，

**請注意**

<ul>
<li>你無法自己產生BGM，你必須依靠以下能力或者道具才能發動BGM：</li>
<li>自身演奏能 力：當你自身可以演奏音樂的時候可以自帶BGM。</li>
</ul>

**分類**：道具，裝置

**價格**：C+2000

**其他標籤**

**絕對唯一**：同一場景內只允許一個BGM播放，當有一個BGM已經播放時，若有另外一個BGM開始播放，則雙方進行意志對抗，後面發動BGM的單位爲主動發起方，勝出者可以開始自己的BGM，失敗者的BGM立即停止。

**調音師**：你現在可以購買調音師專長，這是輪迴小隊專長。

**BGM**：以一個整輪動作，花費1點意志，使用道具來播放BGM，播放後獲得對應的效果，持續一個場景，每場景只能啓動一次。

**不畏艱險**：持續時間內，你無視困難地形，以及相當於你BGM點數的環境減值。

**英雄無敵**：持續時間內，你的對抗性檢定獲得相當於你BGM點數的士氣加值。

**輕靈快捷**：持續時間內，你的基礎移動速度增加相當於你BGM點數/米。

**決意之志**：持續時間內，你的延長判定中的一次檢定獲得相當於BGM點數的附加成功。

**孤睾勇士**：持續時間內，若你可以造成負面點數狀態，並且該點數可以豁免，則目標的豁免檢定失去BGM點數的成功。

**雙倍自信**：持續時間內，你獲得相當於BGM點數的附加成功，你可以分配在你想分配的任意檢定或者防禦上，本BGM無法切換與被切換。

**艹你爸爸**：你釋放這種帶感的bgm時，所有可以聽到該BGM的目標以意志豁免，DC爲你的BGM點數，你每點勝出都會令目標受到1點腿部肢體妨礙（抖腿），這個狀態點數可以累積成爲嚴重後果，但無法累積成毀滅性後果，bgm停止後立即回覆所有肢體妨礙。

**音樂播放器**：可以發動BGM能力，切換歌曲是一個移動動作。

**耗電**：每播放24小時需要1枚標準能量電池。


**正文**

當你播放BGM時，你的獲得相當於你決心附加成功數+表達附加成功數的BGM點數，該點數用於某些效果。

\1. 你擁有產生音樂的能力（如樂師等），你可以在演奏樂師的同時發動BGM，這無需動作，但是一旦該能力停止，則BGM立即結束，同時你無法切換歌曲。

\2. 你通過自然本質的能力自己演奏音樂，此時，你每輪需要花費一個標準動作來維持，並且切換歌曲無需動作。

移動音樂設備（錄音機，隨聲聽，手機等現實世界存在可以播放音樂的東西）

# 應景樂隊

**本質**：特異本質

**價格**：D+500

**分類**：道具，裝置

**描述**：哆啦A夢的神奇道具之一，本體是數個微小的機器樂師。

**價格**：D+500

**其他標籤**

**黑子本質**：他們和黑子有異曲同工之妙，他們不會被敵人攻擊，也不會受任何AOE，BUFF或陷阱的效果，場景內他們視爲不存在。

**音樂樂隊**：可以發動BGM能力，切換歌曲是一個自由動作。

**演奏升級**：你的BGM點數再增加相當於你操控附加成功數的點數。
