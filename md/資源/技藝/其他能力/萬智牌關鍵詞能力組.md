# 萬智牌關鍵詞能力組

> 來源：`資源/技藝/其他能力/萬智牌關鍵詞能力組`

**本質**：魔幻本質

**描述**：來自於卡牌遊戲《萬智牌》中的各種關鍵詞異能。

**特殊**：各種關鍵詞可以分開購買亦可以重複購買，每種關鍵詞有自己特定的附着對象，每次購買可以選擇一個符合描述的對象附結該關鍵詞，一個關鍵詞只能附結一個對象，同時一個對象身上每個種類的關鍵詞也只能有一個，你須在購買時選擇一個自願對象進行附結。

## 暗碼

**價格**：A+4000

**動作**：被動

**效果**

<ul>
<li>本關鍵詞附結於自身的一個法術上，該法術的施展動作不得超過一個整輪動作。</li>
<li>你失去被附結的法術，並需將它賦碼於一個自願單位身上。每回合一次，當該單位在進行一次攻擊檢定並命中之後可以立刻施展一次被附結的法術，如同該單位親自施展該法術一般。但無需消耗動作與支付基礎魔力消耗，若該法術需要消耗其他材料或能量（包括但不限於意志力、施法材料、 XP 等）則該單位必須如常支付。但是如果該單位要使用這個法術的增幅效果或是進行超魔則仍需爲此額外支付魔力。</li>
<li>這不會使被賦予該法術的單位掌握該法術，因此該單位只能夠透過進行一次攻擊檢定併成功命中的方式來施展該法術，無法以正常的方式來施展該法術。</li>
<li>暗碼無法附結在有使用次數的法術上。</li>
</ul>

**價格**：A+4000

## 變身

**價格**：D+500

**動作**：見下

**效果**

<ul>
<li>本關鍵詞附結於一個生物上。</li>
<li>所附結生物可以花費一個整輪動作變身爲所在世界常規意義上的“普通人”，所有屬性與技能取“普通人”的平均值，且不保留已有的強化和能力，持續至以移動動作解除變身狀態（如在地球上，該單位就會變成一個全屬性 2 ，全技能 1 ～ 2 的人類，具體可參考怪物圖鑑。），這視爲一個 C 級的變形效果。</li>
<li>ST 有權禁用該關鍵詞。</li>
</ul>

**價格**：D+500

## 不息

**價格**：B+4000

**動作**：被動

**效果**

<ul>
<li>本關鍵詞附結於一個生物上。</li>
<li>每部影片一次，所附結單位死亡後，會在其下一輪行動開始時復活，生命值全部回覆至完好，除此之外目標其他狀態（包括但不限於能量池，擁有的不良狀態點數等）與死亡當輪完全相同，這意味着如果他是在昏迷中死去（但若是在睡夢中死去則會被驚醒，除非他是被超自然來源的能力所催眠，具體由 ST 裁定），復活後仍會處於這個狀態中。</li>
<li>本次復活不佔用復活次數，每個目標被本技藝復活的次數沒有限制。</li>
</ul>

**價格**：B+4000

## 超載

**價格**：D+500

**動作**：被動

**效果**：本關鍵詞附結於自身的一個不超過C級，以一個目標（不能爲自身）爲目標的能力（包括但 不限於法術，技藝，招式，血統技能樹下的技能），使附結的技能的以下內容發生變化：

**射程**：原本射程中的一個點

**目標**：最多不超過你最高傳奇屬性/個目標

**範圍**：以該點爲中心，5米爲半徑的範圍 這可能會導致被附結的法術無法升階。 若原本的目標有限制，如自願目標，召喚物，友方目標等，使用本能力後並不會讓目標失去限制。 若原本的目標不允許包括自己，也使用本能力後若範圍內包括自己，自己也無法享受本效果。

**升級**：某項技能上結附了本關鍵詞的生物可以分別支付 DD+500/CC+1000/BB+2000 的價格對本關鍵詞進行升級，每次升級可以修改一次本關鍵詞附結的能力，同時能夠附結的能力支線等級上限提升至 B/A/S 級。

**價格**：D+500

## 打包

**價格**：B+2000

**動作**：被動

**效果**

<ul>
<li>本關鍵詞附結於自身的一個法術上，該法術須要有兩種以上施展方式（例如“冰凍咒文 夏達可”）。</li>
<li>在施展附結了本關鍵詞的法術時，可以將該法術的能耗提升一倍，之後使該法術其中兩種施展方式同時生效，如同人物分別施展了兩次該法術一般，這意味着該法術可能造成兩次傷害，如果要對法術進行增幅或是超魔，則需要分別爲兩種用法額外支付相應能耗。</li>
</ul>

**價格**：B+2000

## 覆誦

**價格**：A+4000

**動作**：被動

**效果**

<ul>
<li>本關鍵詞附結於自身的一個法術上，該法術的施展動作不能超過一個整輪。</li>
<li>當你施展該法術時，可以額外支付同等的能耗並再額外施展一次該法術，可以重新選擇目標，無需消耗動作，兩次法術共享增幅與超魔效果，無須分別爲兩次法術支付增幅與超魔所需的額外能耗。</li>
</ul>

**價格**：A+4000

## 警戒

**價格**：D+500

**動作**：被動

**效果**

<ul>
<li>本關鍵詞附結於一個生物上。</li>
<li>附結了本關鍵詞的生物獲得 D 級免疫措手不及的能力，同時在承受防禦上的減值時（包括但不限於全力一擊、衝鋒、不良狀態點數的影響等，但顯然不包括破甲與破魔等）可以在計算減值前先將該減值降低 4 點。</li>
</ul>

**升級**：結附了本關鍵詞的生物可以分別支付 DD+500/CC+1000/BB+2000/AA+4000 的價格對本關鍵詞進行升級，將免疫措手不及的能力提升至 C/B/A/S 級，在承受防禦上的減值時可降低的減值提升至 8/12/20/32 點。

**價格**：D+500

## 歷傳

**價格**：D+500

**動作**：被動

**效果**

<ul>
<li>本關鍵詞附結於自身的一個法術上。</li>
<li>該法術的擁有者者將無法再使用被本關鍵詞附結的法術，但是他可以消耗一個整輪動作並支付相應的基礎能耗來製作一張該法術的法術卡片。</li>
<li>任何人可以通過消耗一張法術卡片來發動對應法術，卡片的使用動作等同於施展該法術所需的動作，並且需要消耗對應的成分（即語言、姿勢、施法材料等），但無需魔力消耗。</li>
<li>法術卡最多隻能同時存在該法術的擁有者的神祕學技能上的附加成功數 \*1 張。在達到這個上限後，每一張新製作出來的法術卡都會使第最早被製作出來的那張法術卡消失。</li>
<li>如果該法術可以增幅，則使用者必須在使用法術卡的時候支付增幅所需的能耗才能獲得其增幅效果。</li>
<li>歷傳無法附結在有使用次數的法術上。</li>
<li>歷傳無法 附結在使用目標爲“自身”的法術上。</li>
<li>若你擁有2個 歷傳則分別計算擁有的上限，哪怕其針對的是同一個法術。</li>
<li>歷傳的使用者爲製作卡片的施法者。</li>
</ul>

**價格**：D+500

## 連擊

**價格**：A+4000

**動作**：被動

**效果**

<ul>
<li>本關鍵詞附結於一個生物上。</li>
<li>附結了本關鍵詞的生物在其每輪行動結束後可以額外獲得一個標準動作，該標準動作只能用來進行近戰攻擊，但可以攀附招式或其他能力，並且該次攻擊會使被攻擊的目標陷入措手不及，這是一個 A 級措手不及效果。</li>
</ul>

**價格**：A+4000

## 敏捷

**價格**：B+4000

**動作**：被動

**效果**

<ul>
<li>本關鍵詞附結於一個生物上。</li>
<li>附結了本關鍵詞的生物在每次進入戰鬥場景並計算完敵我雙方的先攻後，可以立刻獲得一個突襲輪，若該戰鬥場景內有單位免疫突襲，則在該突襲輪內使用那些“指定 X 個目標 / 指定範圍內 X 個目標”的法術或能力時無法以該單位作爲目標。</li>
</ul>

**價格**：B+4000

## 敲詐

**價格**：C+1000

**動作**：被動

**效果**

<ul>
<li>本關鍵詞附結於自身的一個法術上。</li>
<li>每當你施展該法術時，每有一個單位受到該法術影響，你便可以額外支付 3 點魔力，使每個受到該次法術影響的單位各受到 1 點物理嚴重傷害，同時每成功造成 1 點物理嚴重傷害，則你選擇等量的生命值恢復至完好，每場景以此法恢復的惡性傷害最多不得超過人物智力上的附加成功數，但以此法恢復的衝擊與嚴重傷害則無上限。</li>
</ul>

**價格**：C+1000

## 閃現

**價格**：B+2000

**動作**：被動

**效果**

<ul>
<li>本關鍵詞附結於自身的一個不超過 B 級的能力（包括但不限於法術，技藝，招式，血統技能樹下的技能）上，該能力的施展動作不得超過一個標準動作。</li>
<li>使附結的能力的施展動作可以改爲一個反射動作。</li>
<li>這可能會導致被附結的法術無法升階。</li>
</ul>

**價格**：B+2000

## 忍術

**價格**：B+2000

**動作**：見效果

**效果**

<ul>
<li>本關鍵詞附結於一個生物上。</li>
<li>每輪一次，附結了本關鍵詞的生物可以在其視距範圍內的友方輪迴者進行一次攻擊時支付 3 點意志並以反射動作啓動本關鍵詞，之後終止該友方輪迴者的攻擊動作與其回合，並與該友方輪迴者互換位置與先攻順位（這不會使你立刻獲得新的回合，並可能會對一些與先攻順位有關的能力造成影響。），同時立刻獲得一個只能用來進行近戰攻擊的標準動作，該次近戰攻擊可以使用招式。</li>
</ul>

**價格**：B+2000

## 替身甲

**價格**：D+500

**動作**：被動

**效果**

<ul>
<li>本關鍵詞附結於一個生物上。</li>
<li>每部影片一次，當任一攻擊或即死效果將會把附結了本關鍵詞的生物的生命值嚴重打滿時，或者將其直接殺死時，其可以免疫這次傷害，同時直到其下一輪行動結束前都不會再受到任何傷害，但這次傷害附帶的其他效果（包括但不限於不良狀態點數，擊倒等）不會被一併吸收抵消。</li>
<li>若該生物身上有類似於替身甲的效果（如護命玉佩、致命抵禦），則會優先觸發替身甲的效果。</li>
</ul>

**注意**：針對不可避免的傷害或者效果時，替身甲不會起效。

**價格**：D+500

## 武士道

**價格**：D+1000

**動作**：被動

**效果**

<ul>
<li>本關鍵詞附結於一個生物上。</li>
<li>若附結了本關鍵詞的生物的敏感範圍內不存在任何友方單位（包括但不限於輪迴者、召喚物、 NPC 等），同時其敏感範圍內只有一名敵方單位（包括但不限於輪迴者、召喚物、 NPC 等）時，附結了本關鍵詞的生物在攻擊檢定、三豁免檢定與防禦上獲得等同於自身最高支線等級 + 敵方單位最高支線等級（ D1C2B3A4S5 ） DP 表現加值。</li>
</ul>

**價格**：D+1000

## 渲色

**價格**：D+500

**動作**：被動

**效果**

<ul>
<li>本關鍵詞附結於一個能力（包括但不限於法術，技藝，招式，血統技能樹下的技能）上。</li>
<li>若附結的能力施展時可以進行檢定，則該能力的擁有者每有一個能量池（包括通用和特殊能量池），便使該能力施展時的相關檢定增加 1DP 能量加值，若該能力需要進行多次檢定，則這幾次檢定都可以獲得本關鍵詞帶來的加值。</li>
</ul>

**價格**：D+500

## 戰嚎

**價格**：C+1000

**動作**：被動

**效果**

<ul>
<li>本關鍵詞附結於一個生物上。</li>
<li>附結了本關鍵詞的生物每進行一次攻擊（無論是否命中）便能使能夠觀察或感知到該生物的友方單位（不包括自身）在攻擊檢定上獲得 2DP 士氣加值，持續一輪。每個單位可由此法獲得的士氣加值上限爲附結了本關鍵詞的生物的風度值。</li>
</ul>

**價格**：C+1000
