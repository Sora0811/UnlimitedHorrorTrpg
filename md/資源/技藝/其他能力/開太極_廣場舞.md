# 古譜 - 開太極 C+4000

> 來源：`資源/技藝/其他能力/開太極\_廣場舞`

**消耗**

<ul>
<li>使用前必須在上個回合消耗一個整輪動作進行行禮。</li>
<li>開分太極，挪移乾乾，虛空璇引，消耗一個整輪動作，你開始進行一輪的太極拳的演武，你進行一個風度 + 表達（演武）的檢定，所有可以看到你的目標（不分敵我），以意志進行對抗，若其失敗，會不可避免地隨着你的動作一起演武，這是一種特殊的精神控制，意味着你周圍五米內的人暫時喪失身體身份自主權失去整輪動作，持續到你停止或者目標受到任何傷害或者不良狀態，或者 DEBUFF 爲止。</li>
</ul>

## 今法 - 廣場舞 C+4000

**消耗**

<ul>
<li>使用前必須在上個回合消耗一個整輪動作進行行禮。</li>
<li>蹦跳旋轉，扭腰轉身隨着激盪節奏而盡現釋放，消耗一個整輪動作，你開始進行一輪的廣場舞的表演，你進行一個風度 + 表達（廣場舞）的檢定，所有可以看到你的目標（不分敵我），以意志進行對抗，若其失敗，會不可避免地隨着你的動作一起表演， 這是一種特殊的精神控制，意味着你周圍五米內的人暫時喪失身體身份自主權失去整輪動作，持續到你停止或者目標受到任何傷害或者不良狀態，或者 DEBUFF 爲止。</li>
</ul>

**特殊**

<ul>
<li>若你可以選擇【小蘋果】或者【最炫民族風】或其他歌曲進行搭配公放，你的表達（廣場舞）檢定獲得 +3DP 表演加值。</li>
<li>在某些高齡男性輪迴者的手中，這套廣場舞可以成爲公園太極拳。</li>
</ul>
