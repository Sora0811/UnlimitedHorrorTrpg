# 霸氣

> 來源：`資源/技藝/其他能力/霸氣`

**本質**：特異本質

**分類**：技藝

**描述**：霸氣是ONE PIECE世界中所有人類都擁有的潛在力量，這種力量是與生俱來的能力，和“氣勢”、“威懾力”相同，就像本能一樣存在着；但是，絕大部份的人都不能意識到這種力量，或是終其一生也無法發揮出來。

## D 級

**價格**：D+500

**動作**：迅捷

**能耗**：無

**射程**：無

**目標**：自身

**範圍**：無

**持續**：見下

**效果**

<ul>
<li>你獲得了使用武裝色霸氣的能力，啓動時，你進行一次耐力＋決心的檢定，可維持成功數/輪，每次戰鬥中，你可發動武裝色霸氣的次數爲你傳奇決心+1/次。</li>
<li>在發動武裝色霸氣的期間，你的攻擊檢定獲得4DP增強加值並額外增加4點傷害上限，同時你的攻擊獲得【魔法】特性。</li>
</ul>

**價格**：D+500

### 見聞色霸氣

**描述**：能強烈感受四周氣息的力量，可感應到視線外的敵人或進一步預知對手動作，在空島被稱爲“心網”，是一種讀心術，也可以說是“聽的力量”。只要人還活着，身體就可以發出特殊的聲音，藉由這些聲音可以預測對手下一步的動作與位置，只要經過鍛鍊就能讓範圍變大。更高等的“見聞色霸氣”擁有者，可藉着此能力聽到他人的心聲，甚至對他人進行演說。

## D 級

**價格**：D+500

**動作**：迅捷

**能耗**：無

**射程**：無

**目標**：自身

**範圍**：無

**持續**：見下

**效果**

<ul>
<li>你獲得了使用武裝色霸氣的能力，啓動時，你進行一次感知＋決心的檢定，可維持成功數/輪，每次戰鬥中，你可發動見聞色霸氣的次數爲你傳奇決心+1/次。</li>
<li>在發動見聞色霸氣的期間，你的攻擊檢定與防禦獲得4點洞察加值。</li>
<li>你現在可以通過見聞色霸氣來得知目標的傷勢情況。你的感知範圍爲你的敏感範圍。</li>
</ul>

**價格**：D+500

**其他標籤**

**・毫髮無損**：生物沒有受傷。

**・輕微受傷**：將生物所受的所有傷害折算成衝擊傷害（1點嚴重=2點衝擊，1點惡性=3點）後，沒有超過目標的生命值。

**・中度受傷**：將生物所受的所有傷害折算成衝擊傷害（1點嚴重=2點衝擊，1點惡性=3點）後，沒有超過目標的生命值的兩倍。

**・嚴重受傷**：將生物所受的所有傷害折算成衝擊傷害（1點嚴重=2點衝擊，1點惡性=3點）後，沒有超過目標的生命值的三倍。

**・死亡**：生物已經死亡。

### 霸王色霸氣

**價格**：S+8000

**前提**：A級見聞色霸氣與A級武裝色霸氣

**描述**：可以靠着自身“氣魄”震攝或嚇昏敵人，但如果控制不好，會使周遭的人一併受牽連；相反，假如霸氣達到上級境界，則可達到威壓效果。這是數百萬人之中只有一人才有的天選之人的“霸氣”，即是擁有立於人之上的“王的資質”，和前兩者不同的是，“霸王色”即使可以控制自如，卻無法靠着鍛鍊來加強，只有靠使用者本人自身的成長才能強化。

**被動**

<ul>
<li>現在你可以以一個迅捷動作開啓霸王色霸氣，你進行一個耐力+感知+決心的檢定，可維持成功數/輪，每次戰鬥中，你可發動霸王色霸氣的次數爲你傳奇決心+1次。</li>
<li>啓動後視爲同時開啓武裝色霸氣和見聞色霸氣，並且在啓動的瞬間你獲得如下效果：</li>
<li>所有處於你風度\*50米範圍內的任意可選對象，若你的傳奇決心高於其最高傳奇屬性，其在差值輪內陷入無法豁免的震懾狀態，若差值超過3點，則直接陷入昏迷，持續差值\*10分鐘。</li>
<li>每場景同一目標只會受到本效果影響一次。</li>
<li>同樣具有霸王色霸氣的目標直接免疫本能力。</li>
<li>在發動霸王色霸氣的期間，武裝色霸氣和見聞色霸氣中的數值部分全部翻倍（從D級到A級）。見聞色的免疫措手不及等級提升至S級。</li>
</ul>

**價格**：S+8000

## 武裝色霸氣

**描述**：提升個人的防禦力，作用猶如看不見的盔甲；更可演化爲攻擊力，進而與惡魔果實能力者抗衡，甚至可以觸碰到“自然系”果實能力者的實體。據羅賓所述，武裝色霸氣只能抓住能力者實體，卻無法像“海樓石”那樣奪走能力者的能力，除了身體，武裝色霸氣甚至可以纏在武器上加強攻擊力道。
