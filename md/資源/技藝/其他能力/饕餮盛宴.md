# 技藝

> 來源：`資源/技藝/其他能力/饕餮盛宴`

**價格**：D+500

**本質**：特異本質

**技能**：開啓技能樹，本技藝下的技能無須按順序購買，可直接購買C級或更高級的技能

**描述**

<ul>
<li>購買本技藝後，你會獲得一本食譜大全，這是一本充滿神奇力量的食譜大全。</li>
<li>通過學習,你可以逐漸掌握其中的各道美食,並且這些完成後的美味料理還附帶着各種無法解釋的魔力,喫完它的人通常都能得到一些能力（料理之間效果不疊加）。由於透過此食譜上的烹調方式做出的料理已經不能用常理來解釋,所以所有的料理都是特異本質。</li>
</ul>

**特性**：烹飪大師 嘗百草

**價格**：D+500

## 漢堡

**價格**：D+500

**動作**：1分鐘

**能耗**：任意1點生理系能量

**射程**：無

**目標**：無

**範圍**：無

**持續**：立即

**描述**：“它的價值遠超垃圾。”

**效果**

<ul>
<li>你可以購買價值20分的食材進行加工，或運用能量將任何體積小於1，屬於你或無主的肉類（包括但不限於生物屍體、斷肢、普通的食材等）消毒、煮熟，這會祛除該肉類蘊含的細菌以及D級或以下的自然與超自然毒素。之後你能夠對該肉類進行快速加工，投擲 智力+手藝-廚藝（烹飪），若至少有一個成功數，則你可以將該肉類烹調爲一份漢堡扒，若有7個以上的成功數，則可以將該肉類烹調爲三份漢堡扒。</li>
<li>每十份漢堡扒視爲1體積，食用漢堡扒是一個標準動作，食用後每3輪可以恢復1點嚴重傷害或2點衝擊傷害，持續15輪。（食用漢堡的當回合不恢復生命值）</li>
</ul>

**價格**：D+500
