# 褻瀆靈氣

> 來源：`資源/技藝/其他能力/黑暗之力`

**前提**：黑暗生物

**價格**

<ul>
<li>c+1200</li>
<li>對於光明生物來說你就是一堆移動的不可回收的垃圾堆，異常的噁心。</li>
<li>整輪動作開啓，在以你爲中心風度值 / 米的範圍內，當生物進入這個範圍會得到相當於你耐力值的噁心點數，這個能力可以耐力 + 生存或決心 + 生存抵消。光明生物在對抗時兩者取低。</li>
<li>此能力造成的噁心點數不可疊加，生物遠離你十分鐘後，噁心點數會以每輪 1 點的速度恢復。</li>
</ul>

**價格**：C+1200

## 淫邪之視

**前提**：黑暗生物

**價格**

<ul>
<li>d+600</li>
<li>你的通過心靈之窗的對視傳遞你污穢的思想，使人覺得似乎被污穢的觸手捆綁、玷污。</li>
<li>通過一個標準動作，你進行一個操作 + 表達檢定，對你視線之類一個目標造成如同成功數的精神束縛點，以意志檢定進行抵消。對於光明生物來說，他們的身體會本能反抗這個效果，同時對其造成等同點數的疲乏點數，強韌（耐力 + 生存）抵消。</li>
</ul>

**價格**：D+600

## 墮天之傲慢

**前提**：黑暗生物

**價格**

<ul>
<li>b+3600</li>
<li>“誰讓你俯視本王的，給我跪下！”</li>
<li>你扭曲病態的思想絕不能容忍，有象徵着光明的“鳥人”從你頭頂飛過。</li>
<li>每場景一次，以自由動作做出以上老馬王的宣言。進入你視線內的飛行生物，進行一個敏捷 + 運動的判定， DC 等於你的風度值。若你成功，則你飛行機動性下降一級，並且速度下降 1/3 或者你的決心值，兩者取高，若降爲 0 ，則失速掉下，持續一場景。若那是光明生物，則 DC 可以額外的加上決心值屬性，機動性下降 2 級，並且速度下降 2/3 或者決心值 + 風度值 / 米。</li>
</ul>

**價格**：B+3600

## 穢惡之舞

**前提**：黑暗生物

**價格**

<ul>
<li>c+1200</li>
<li>你用一個整輪動作，進行一個風度 + 表達的檢定，跳出象徵着穢惡本質的舞步。</li>
<li>看到你的舞蹈的凡人會得到如同你表演成功數的亢奮點數，可以用意志檢定進行抵消。看見你的舞蹈的光明生物會意識到你的舞蹈所暗示糟糕含義，他們必須進行一個 dc 爲表演成功數的意志檢定，若失敗，則受到失敗點數的沮喪點數。</li>
</ul>

**價格**：C+1200
