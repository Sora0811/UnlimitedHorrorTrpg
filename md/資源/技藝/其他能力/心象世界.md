# 心象世界

> 來源：`資源/技藝/其他能力/心象世界`

**本質**

<ul>
<li>特異本質</li>
<li>所爲心相世界就是以精神侵蝕物質，以思維取代現世的一門技藝，事實上凡是修行進入一定境界的強者都會對這門能力無師自通，或稱爲領域，或稱爲固有結界，或稱爲心相世界，其本質無非在於改變環境使其適合於自身發揮，而如今主神劍走偏鋒推演出一門不需強大實力就可以發揮部分能力技藝，該能力技藝等級爲本身支線與人物最高強化取高</li>
</ul>

## D 級　催眠之境

**價格**：D+500

**描述**：通過自我催眠而解放人體最大的潛能，相信自己如神魔般偉岸，以此鍛鍊精神便是這門技藝最初始的能力。

**效果**

<ul>
<li>在這一階段你獲得以下能力：</li>
<li>\1. 簡單的自我暗示，花費 1 點意志力，你可以在任何基於生理屬性的檢定上獲得等同於你傳奇決心與傳奇沉着之和的士氣加值。</li>
<li>\2. 當你使用意志力的基礎用法時，只需要說出符合一些中二病特質的語言（例如“不好！居然陷入了第七機關的審判天使陷阱！”，或者“這是怎麼回事！深淵界的領袖爲何會降臨人間！”之類的話。正常情況下無需動作，並且可以在非自己回合進行），就可以使得該完美加值提升 3 點。</li>
</ul>

**價格**：D+500

## C 級　能量幻形

**價格**：C+1000

**描述**：僅僅精神並不足以形成領域，能量的運用也必不可少。

**效果**

<ul>
<li>在這一階段，你可以用能量結合精神加以運作，你獲得了新的用法：</li>
<li>\1. 當你面對影響心靈效果時，若可以對抗，則你可以消耗 1 點意志力，獲得等同於你傳奇決心與傳奇沉着之和的附加成功。</li>
<li>\2. 當你使用“ D 級獲得第二個用法時”你額外再獲得 2 個附加成功。</li>
</ul>

**價格**：C+1000

## B 級　侵蝕現世

**價格**：B+2000

**描述**

<ul>
<li>現在你終於可以僅憑意志與能量對現世進行一些改變了。</li>
<li>你現在可以詠唱“咒文”：“爆裂吧現實！粉碎吧精神！放逐這個世界！”（以上爲範例，可以自己原創，但是必須中二）。詠唱完畢後，你將開啓屬於自己的固有結界。在你固有結界範圍內的環境，無論原本爲何，都會被替換爲特殊場景（你可以將心中一個戰鬥場景路線出來：例如天空懸掛着一輪青月古堡、憑空生起的鋼鐵叢林、巨大的冰海平面等等。 ST 可以自己根據 PC 性格決定其形象。），</li>
<li>你在屬於自己的戰場中戰鬥，將會獲得最大限度的增幅。當無形的雙眼重合起來，在戰鬥中，你便將看到全新的視界。</li>
</ul>

**價格**：B+2000

<li>你在你的固有結界（心象世界）內時，你獲得幻象祕技能力：</li>
</ul>

**價格**：A+4000

**其他標籤**

**幻想祕技**

<ul>
<li>隨性心想世界的誕生，隨之而來的一定是那個人物的成名絕技，或者是隱藏的最深的超級必殺。</li>
<li>例如壓箱底的“二段變身”、“第三強化階段”、例如邪王真眼的“阿瓦隆粉碎擊”、例如黑炎烈焰使的“魔神槍”、或者是雷神之錘的“雷霆之錘”……諸如此類的。</li>
<li>選定一個你已經擁有的 A 級以下的技能，動作不得超過標準動作，一旦選擇不可改變，然後若你在固有結界（心象世界）內使用，則其獲得以下改變：</li>
<li>\1. 如果這個能力不需要消耗能量，那麼使用它會對人物造成生命槽一半的衝擊傷害；如果這個能力需要消耗能量或意志力，那麼消耗翻倍。</li>
<li>\2. 如果這個能力未能命中目標，人物需要在該場景中的所有檢定中均承受 4 點士氣減值。</li>
<li>\3. 所需動作爲提升一個級別，如反射動作提升爲迅捷動作，移動動作提升到標準動作，爲標準動作的變爲整輪動作。</li>
<li>\4. 人物可以爲這個能力使用意志力的基礎用法時，再額外花費 1 點。</li>
<li>\5. 若有檢定，則加骰提升一級，最高爲 8</li>
<li>\6. 如果這個能力不是範圍能力且目標不爲自身，那麼人物還可以指定一名角色作爲第二目標；如果這個能力已是範圍能力，那麼其範圍翻倍；</li>
<li>\7. 如果這個能力不是遠程能力，那麼人物使用感知 \*5 米作爲其觸及；如果這個能力已是遠程能力，那麼其射程翻倍；</li>
<li>\8. 如果這個能力有一個持續時間，那麼持續時間翻倍。</li>
<li>特殊的，人物可以爲這個能力更改一個名稱；此外，這個能力的表現效果也會發現改變。列如，“和風” - “滅世風暴”；“唱歌” - “女妖之嚎”，此外，人物可以在主神空間更換選定的能力。</li>
</ul>


## 你現在可以開啓固有結界（心象世界）：

**關鍵字**：【結界】

**能耗**：3 點意志力

**動作**：整輪動作

**範圍**：敏感範圍

**目標**：所有目標

**射程**：以自己爲中心

**持續**：傳奇決心與傳奇沉着之和 / 輪

**效果**

<ul>
<li>在結界內，你獲得盲視，範圍爲你的整個結界範圍。</li>

</ul>

**注意**：免疫的環境本質皆爲自然本質，若爲超自然能力製造出來的則無法免疫。

**其他標籤**

**高溫地獄**：選擇你的一項屬性，所有你選擇的目標每回合受到相當於你選擇屬性的傳奇屬性的火焰嚴重傷害。

**寒冰地獄**：選擇你的一項屬性，所有你選擇的目標每回合受到相當於你選擇屬性的傳奇屬性的冰霜嚴重傷害。

**風吼地獄**：選擇你的一項屬性，所有你選擇的目標每回合受到相當於你選擇屬性的傳奇屬性的穿刺嚴重傷害。

**宇宙空間**：此空間獲得真空特性（對除你以外所有目標生效）。

**深海恐懼**：此空間獲得深海特性（對除你以外所有目標生效）。

**祝福天堂**：選擇你的一項屬性，所有你選擇的目標的 5 項檢定獲得受到相當於你選擇屬性的傳奇屬性的士氣加值。

**不敗頌歌**：選擇你的一項屬性，所有你選擇的目標每回合得到你選擇該屬性的傳奇屬性 / 點臨時生命，每回合新的將覆蓋原有的。

**無限劍制**：所有你選擇的目標可以以一個移動動作，拾取任何一把基礎冷兵器，該冷兵器獲得【魔法】特性，並且選擇你的一項屬性，這把武器的武器傷害獲得你選擇屬的傳奇屬性提升（對除你以外所有目標生效）。
