# TWO-HAND MODE

> 來源：`資源/技藝/槍械技藝/TWO-HAND MODE`

**要求**

<ul>
<li>敏捷 6 ，力量 4 ，槍械 4，雙槍射擊4 。必須手持兩把槍械進行射擊。</li>
<li>兩挺拳銃是地下世界的人們對於使用雙槍潑灑死亡的人的尊稱。只有少數頂尖的雙槍使用者可以獲得這一榮譽。主神吸收了這類戰鬥風格加以改良，形成了獨有的技能。</li>
<li>喂喂，那邊的臭小子，你不會真以爲會用兩把槍胡亂射擊兩下就可以被叫做“兩挺拳銃”了吧？</li>
<li>讓老孃教給你什麼叫做“射擊”吧！</li>
<li>你攻擊任何目標都會如同你已經瞄準了其 3 輪一般。</li>
<li>此外，你可以以常人肉眼難及的速度爲槍械上子彈。你換彈夾（或爲左輪槍上子彈）只需要花一個自由動作，並且只需要一隻手就可以完成。</li>
<li>當你使用兩把槍械進行連射的時候，你的連射額外 +3DP，並且不會因爲連射額外目標而受到減值 。</li>
</ul>

**其他標籤**

**特別**

<ul>
<li>作爲一名 TWO-HAND ，你就得把那些娘娘腔的射擊習慣塞進香港佬的雞眼裏。 TWO-HAND 出現的地方就是鉛彈頭的降價大賣場！使用 TWO-HAND MODE 進行射擊時，你必須掃射。在任何場合，你若進行單發射擊，則永遠失去一切基於 TWO-HAND MODE 的好處。</li>
<li>（可選）作爲一名地下槍手，你必須適當地表現出地下文化的侵染，如暴躁，粗野等，甚至對殺戮的熱衷。</li>
</ul>
