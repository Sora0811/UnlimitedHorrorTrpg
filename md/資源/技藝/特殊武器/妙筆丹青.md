# 妙筆丹青

> 來源：`資源/技藝/特殊武器/妙筆丹青`

**專業**：繪畫

**描述**

<ul>
<li>“尤善丹青，圖寫特妙。” ――《晉書・文苑傳・顧愷之》</li>
<li>妙筆丹青乃修習仙術和繪畫才能上均有大天賦之人才能習得。</li>
<li>修行之後，善於妙筆生花，無需載體，可在瞬時以丹青和畫筆繪出栩栩如生的畫作。再以能量催動，擴散而出。</li>
</ul>

**本質**：魔幻本質

**前提**：擁有東方能量池

**特殊**

<ul>
<li>本技藝下的技能無須按順序購買，可直接購買 C 級或更高級的技能。購買第一個技能後，選擇你的一個東方通用能量池進行綁定，綁定後，本技藝下的所有技能所消耗的能量皆爲綁定的能量池。</li>
<li>若你手中的武器擁有“筆”分類，則所有技能中的風度 + 表達 - 丹青的攻擊檢定變爲風度 + 表達 - 丹青 + 武器傷害，同時可以獲得該武器的所有特性，並且傷害上限變爲表達 - 丹青 \*2+ 武器傷害。</li>
</ul>
