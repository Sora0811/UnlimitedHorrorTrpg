# 宮天梳

> 來源：`資源/技藝/特殊武器/宮天梳`

**其他標籤**

**小撥手**

<ul>
<li>以一個標準動作，你發動小撥手，這視爲你進行了全防禦和白刃格擋。 大撥手：若你在前一個回合發動過小撥手，你在本回閤中可以以自由動作進行一次近戰白刃攻擊，使用敏捷 + 白刃（宮天梳）進行，若你使用天生武器來進行大撥手，視爲天生武器傷害的一半的武器，也不會獲得任何其他特性。但若該天生武器具有鞭類用法（包括但不限於鞭刀，尾巴，頭髮等），不但能應用完整傷害，還能應用天生武器的完整特性（如破甲等）。若你使用衣物進行，武器傷害視爲等同於盔甲加值，若盔甲原本能擬態武器進行攻擊或爲攻擊提供額外效果，應用同樣的效果特性（因此液態金屬甲是 4L2 破甲的武器，而白子之龍同樣忽略對手來自體型的天防，若盔甲加值遠近不同，取較低者） 特殊的，當你發動小撥手時若受到攻擊，你可以在攻擊結算後立刻發動一次大撥手進行還擊，這不消耗任何動作，如此發動大撥手會結束你小撥手的全防格擋狀態，並且在大撥手的攻擊中獲得額外的加值，相當於你來自全防禦的閃避加值和你來自白刃格擋的格擋加值之和的一半。</li>

</ul>


**正文**

宮天梳招式 D+1000 宮天梳是一種對應於同名武器的奇門武術。它以防禦爲主，並需要有較長的衣物綴飾或頭髮，因此一般爲女性所用。 宮天梳主要依靠身形的旋轉產生的離心力來完成小撥手中的卸力和旋格以及大撥手中的鞭撻和撩撥。由於使用時的旋舞顯得婀娜多姿，更兼使用者或有長髮或有衣裝飄帶甚至兼而有之，舞動時令人眼花繚亂，因此宮天梳在表演套路時可以作爲舞蹈來欣賞，此時以白刃技能（宮天梳）代替表達技能（舞蹈）進行判定，但屬性不變。 使用宮天梳中的小撥手需要雙手持用宮天梳，大撥手需要天生武器能造成嚴重傷害，或者穿着提供盔甲加值的輕裝甲，衣物位裝備，對衣物進行附魔（例如法師護甲，物品強化），概念武裝化（例如靈魔武鎧）等提供盔甲加值時也可以用於發動。
