# 原典來自俠客風雲傳

> 來源：`資源/技藝/身法/逍遙劍法`

## 總綱

**前提**：擁有內力

**價格**：dd+1000

**效果**

<ul>
<li>花費 2 點內力啓動，以自由動作啓動劍法總綱的效果，這是一個身法。每點內力消耗2分鐘。</li>
<li>只有在持續時間內，你可以施展逍遙劍法。</li>
<li>在持續時間內施展逍遙劍法時可以敏捷作爲近戰白刃武器傷害判定。</li>
<li>並且每次攻擊之前你可以花費2點內力，然後進行一次反射檢定。你將此檢定成功數加在逍遙劍法的命中上，這是招式加值，上限爲你的白刃等級，你在白刃上每有1點附加成功，則上限再加1。</li>
</ul>

**價格**：DD+1000

## 招式 - 月射寒江

**前提**：擁有內力，習得總綱

**價格**：d+500

**效果**

<ul>
<li>此劍式將帶動着內力運轉，引動外界之力，你的傷勢在這個過程被逐步治癒。</li>
<li>消耗 1 內力以標準動作進行一次白刃攻擊，若命中，則會治癒 1 點自身的嚴重和衝擊傷害。</li>
</ul>

**增幅**

<ul>
<li>當你擁有了 d 級以上的內力時，你可以在此劍式上投入更多的內力點數，回覆更多的嚴重和衝擊傷害。你最多可在此劍式中投入的內力不能超過內力的支線等級（ d1 …… A4 ）。</li>
<li>當驅動此劍式的內力上升至 A 級時，此劍式將可等比例治癒惡性傷害。</li>
</ul>

**價格**：D+500

## 招式 - 瀟湘水雲

**前提**：擁有內力，習得總綱，

**價格**：d+500

**效果**

<ul>
<li>消耗 1 點內力，你朝着前方射出無數道凌厲的劍氣，射程五米以內的目標都被劍氣的所貫穿。</li>
<li>以一個標準動作對範圍內的目標進行一次白刃接觸攻擊，此次攻擊視爲擁有高速 8 ，如果命中可造成同等於消耗的內力點數 + 所持武器的傷害，同時附帶武器的全部效果。</li>
</ul>

**價格**：D+500

**正文**

逍遙劍法

介紹

逍遙劍法劍式輕靈，步法自在，不疾不徐，宛若神仙。

若要將此劍法的威力發揮到極致，非得要有好的輕功不可。

逍遙劍法分別有兩式，分別是月射寒江與瀟湘水雲。
