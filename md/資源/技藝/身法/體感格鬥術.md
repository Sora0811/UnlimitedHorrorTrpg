# 體感格鬥術

> 來源：`資源/技藝/身法/體感格鬥術`

## 身法

**強化**

<ul>
<li>氣機查知</li>
<li>動如脫兔</li>
<li>靜若處子</li>
<li>直覺閃避</li>
<li>無影身法</li>
</ul>

**效果**

<ul>
<li>當你消耗意志力以換取反射和意志加值時，額外獲得等同於你體感格鬥術等級的加值。</li>
<li>C+1500</li>
<li>當你使用“運動閃避”時，你在防禦和反射上額外獲得 +4 的閃避加值。</li>
<li>只要你穿戴輕甲或不穿甲，並至少裸露出一部分皮膚，你在防禦和反射上獲得 +2 附加成功的洞察加值，取代 D 級效果。</li>
<li>當任何生物對你進行瞄準攻擊時，他每瞄準兩輪才能收到一輪的效果。此外，你可以通過一個被動的偵察判定，發現任何在 100 米 \* 感知值的範圍內瞄準你的人。</li>
<li>若你進行反射判定並且成功豁免了所有可以豁免的效果，則你可以立即以一個自由動作移動至多不超過你敏捷值一半米數的距離。</li>
<li>當你需要進行一次反射判定時，用一個反射動作，你可以立即移動不超過你敏捷值一半的距離。每移動 3 米，你的反射判定獲得 +1DP 的加值。如果你移動到需要你反射判定的效果範圍之外，你不受這次效果的影響。</li>
<li>B+3500</li>
<li>當你使用“運動閃避”時，你在防禦和反射上額外獲得 +6 的閃避加值，取代低級效果。</li>
<li>只要你穿戴輕甲或不穿甲，並至少裸露出一部分皮膚，你在防禦和反射上獲得 +3 附加成功的洞察加值，取代 C 級效果。</li>
<li>即使措手不及或面對隱形的對手，只要你穿戴輕甲或不穿甲並至少裸露一部分皮膚，以及你能夠活動，則你保有全部防禦。</li>
<li>你在對抗擒抱、壓制、衝撞時，如果使用敏捷作爲關鍵屬性，獲得 XDP 的加值。 X= 你的體感格鬥術等級 + 感知上的附加成功。</li>
<li>任何時候，若你未使用“運動閃避”，你可以用一個反射動作開啓它。若你如此做，你失去下輪的移動動作。</li>
<li>A+6000</li>
<li>當你使用“運動閃避”時，你在防禦和反射上額外獲得 +8 的閃避加值，取代低級效果。</li>
<li>只要你穿戴輕甲或不穿甲，並至少裸露一部分皮膚，你忽略感知和敏捷附加成功之和的高速。</li>
<li>只要你穿戴輕甲或不穿甲，並至少裸露出一部分皮膚，你在防禦和反射上獲得 +4 附加成功的洞察加值，取代低級效果。</li>
<li>若你針對一個範圍傷害效果時，你的反射檢定失敗，則你也只受到該範圍傷害的一半傷害。（這個能力在計算你的傷害減免，傷害吸收能力之前生效）</li>
<li>AA+10000</li>
<li>當你使用“運動閃避”時，你在防禦和反射上額外獲得 +10 的閃避加值，取代低級效果。</li>
<li>只要你穿戴輕甲或不穿甲，並至少裸露一部分皮膚，你在防禦和反射上獲得 +5 附加成功的洞察加值，取代低級效果。</li>
<li>只要你使用“運動閃避”，每次受到攻擊時，其中的 5 點傷害降低一級，這表現爲你閃避了大部分正面攻擊。這和其他防彈及防能量武器效果疊加。</li>
</ul>

**其他標籤**

**你獲得了新的防禦方式**

<ul>
<li>運動閃避。每輪你使用一個移動動作，並進行不超過自己速度一半的移動，並將你的“運動”技能的附加成功等級作爲閃避加值加在防禦上，直到你下一輪開始。原地晃動不算移動，但左右橫跳、連續折返並且最終位置偏離你的初始位置至少 1 米是可以的。</li>
<li>只要你穿戴輕甲或不穿甲，並且至少裸露出部分皮膚，則在防禦和反射上獲得 +1 附加成功加值。這是洞察加值。</li>
<li>當考慮多次攻擊對你造成的防禦減值時，忽略前 X 次攻擊， X 爲你的體感格鬥術等級的兩倍。</li>
</ul>

**正文**

體感格鬥術是一種依賴使用者的全身感覺來強化防禦力的格鬥術，通過聽覺、觸覺感知氣流和殺意，查知敵人的攻擊意圖和方位並加以閃避的高超技術。從如月劍次到峯島由宇，甚至包括露恩・巴洛特 - 加龍省，輪迴者們曾拜訪各個世界中精於此道的強者，而現在這套體感格鬥術就是集大成者。

在涉及“體感格鬥術等級”時， D 級視爲 1 ， AA 級視爲 5.

你可以消耗經驗，對體感格鬥術進行強化。每個以經驗購買的強化都是獨立的，並沒有順承關係；其所標註所在的等級僅表示你可以在何種等級或以上購買這些強化，而不涉及先決條件。
