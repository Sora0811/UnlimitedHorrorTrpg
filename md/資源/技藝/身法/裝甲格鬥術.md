# 裝甲格鬥術

> 來源：`資源/技藝/身法/裝甲格鬥術`

## 身法

**強化**

<ul>
<li>橡樹堅韌</li>
<li>靈貓優雅</li>
<li>牡鹿闊步</li>
<li>野牛反抵</li>
<li>雄獅掃蕩</li>

**效果**

<ul>
<li>當消耗意志力以換取防禦加值時，額外獲得等同於你裝甲格鬥術等級的附加成功加值。</li>
<li>C+1500</li>
<li>當你進行白刃格擋時，額外獲得 +4 格擋防禦招式加值。這取代 D 級的數值。</li>
<li>只要穿戴重型鎧甲，則在防禦上額外獲得 +2 閃避加值。這取代 D 級的數值。</li>
<li>當任何生物對你進行瞄準攻擊時，其承受的攻擊檢定減值增加等同於你裝甲格鬥術等級的數值。</li>
<li>若任一對手以白刃或肉搏技能攻擊你且並未獲得任何成功，則你可以立即以一個反射動作移動至多不超過你體型值米數的距離。</li>
<li>若任一對手以白刃或肉搏技能攻擊你時，只要其並未因成功數而造成傷害，你就可以以自由動作移動，且移動距離增加至多不超過你裝甲格鬥術等級的米數。</li>
<li>B+3500</li>
<li>當你進行白刃格擋時，額外獲得 +8 格擋防禦招式加值。這取代 C 級的數值。</li>
<li>只要穿戴重型鎧甲，則在防禦上額外獲得 +4 閃避加值。這取代 C 級的數值。</li>
<li>你可以在以移動動作進行格擋的同時，立刻移動不超過自身敏捷值 + 體型值米數的距離。</li>
<li>若任一對手以白刃或肉搏技能攻擊你且並未獲得任何成功，則你在下一次對其進行的白刃攻擊中獲得 DP 洞察加值，其數值爲你的裝甲格鬥術等級與你在白刃技能上的附加成功數之和。你必須在你的下一回合結束前做出此攻擊，否則此加值失效。</li>
<li>你不會因爲承受多次攻擊而在格擋防禦上承受減值。</li>
<li>當你以移動動作進行格擋並移動時，你可以額外移動等同於你力量值米數的距離。</li>
<li>A+6000</li>
<li>當你進行白刃格擋時，額外獲得 +16 格擋防禦招式加值。這取代 B 級的數值。</li>
<li>當你進行白刃格擋時，你在對抗範圍攻擊的反射檢定上也獲得等同於你的白刃技能值的 DP 加值。</li>
<li>只要穿戴重型鎧甲，則在防禦上額外獲得 +6 閃避加值。這取代 B 級的數值。</li>
<li>若任一對手以白刃或肉搏技能攻擊你且並未獲得任何成功，則你可以立即以一個反射動作對其進行一次基礎近戰攻擊。你可以將此能力與 C 級裝甲格鬥術的能力相結合，以一個反射動作先進行移動，再進行攻擊。</li>
<li>若任一對手以白刃或肉搏技能攻擊你且並未獲得任何成功，則你在下一次對其進行的白刃攻擊中獲得等同於你裝甲格鬥術等級的破甲值加值與附加成功加值，並且所獲得的洞察 DP 再提升等同於裝甲格鬥術等級的數值。你必須在你的下一回合結束前做出此攻擊，否則此加值失效。</li>
<li>AA+10000</li>
<li>當你進行白刃格擋時，你在防禦上額外獲得等同於白刃技能值的附加成功招式加值。</li>
<li>只要穿戴重型鎧甲，則在防禦上額外獲得 +12 閃避加值。這取代 A 級的數值。</li>
<li>在穿戴重型鎧甲時，對手以白刃或肉搏技能攻擊你時，若其破甲值無法使你的盔甲防禦降爲 0 ，則所造成的傷害降低 1 級，最低爲衝擊。</li>
<li>若任一對手以近戰武器或肉搏攻擊你且並未獲得任何成功，則他視爲措手不及直到他的下一回合開始時。</li>
<li>若任一對手以白刃或肉搏技能攻擊你且並未獲得任何成功，且你並未以反射動作對其進行攻擊，則你可以立即支付 1 點意志力，以一個自由動作對其進行一次基礎近戰攻擊。</li>
</ul>

**正文**

裝甲格鬥術乃是西歐的騎士和傭兵們在殘酷的戰場上總結出的防禦技巧。通過不斷地移動和格擋來保證攻守的平衡，最大限度地利用自己身上的厚重鎧甲抵消對方的攻擊，並抓住對方攻擊所產生的任何一個漏洞使自己獲得優勢――乃至勝勢，這就構成了這套甚至沒有特殊的名稱卻無比實用的技術。

在涉及“裝甲格鬥術等級”時， D 級視爲 1 ， C 級視爲 2 ， B 級視爲 3 ， A 級視爲 4 ， AA 級視爲 5 。

你可以消耗經驗，對裝甲格鬥術進行強化。每個以經驗購買的強化都是獨立的，並沒有順承關係；其所標註所在的等級僅表示你可以在何種等級或以上購買這些強化，而不涉及先決條件。
