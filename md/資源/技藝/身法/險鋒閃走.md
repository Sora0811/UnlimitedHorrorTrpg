# 險鋒閃走（身法）

> 來源：`資源/技藝/身法/險鋒閃走`

## D 級　+1000

**先決**：運動 3+ 、運動專業：自我保護、敏捷 4+ 、感知 4+ 、專長：輕靈戰士 2 、精通先攻

**正文**

・僅在身穿輕甲或不穿甲，未使用盾牌並且使用近戰武器的情況下，人物可以將智力值作爲閃避加值加到基礎防禦中，但不能超過身法等級的二倍。如果處於措手不及狀態或因其他任何因素失去了全部的基礎防禦，則此加值也失效。人物在運動技能上所擁有的每個附加成功可以使此上限增加 1 點。

・被近戰攻擊時，若對方未獲得任何成功，則人物可以立刻以一個自由動作移動不超過人物體形值的距離。因此效果觸發的移動總距離不能超過你本輪剩餘的移動距離上限。例如人物本身移動總距離爲 30 米，在輪到自己行動前因此效果而移動了 15 米，則在輪到自己時最多隻能移動 15 米。

・若人物在運動技能上至少擁有一附加成功，則人物可以在使用移動動作進行格擋的同時移動不超過人物的體形值的距離，最高不超過人物的敏捷值。

## C 級　+3000

**先決**：先攻6 + ，基礎防禦5 + ，運動 4+ ，沉着 4+

**正文**

・僅在身穿輕甲或不穿甲，未使用盾牌並且使用近戰武器的情況下，人物可以將智力上的附加成功數作爲洞察加值加到防禦值和防禦上的附加成功中，但不能超過身法等級 -1 。如果處於措手不及狀態或因其他任何因素失去了全部的基礎防禦，則此加值也失效。人物在運動技能上所擁有的每個附加成功可以使此上限增加 1 點。

・被攻擊時，若對方使用了任何降低攻擊 DP 增加攻擊上的附加成功或相反的能力，那麼對你來說，他失去那些獎勵，但仍然要承受相應的減值。

・被近戰攻擊時，若對方未獲得任何成功，則人物可以立刻以一個自由動作移動不超過人物體形值 + 運動技能等級的距離。取代 D 級數據。

## B 級　+6000

**先決**：先攻12 + ，基礎防禦8 + ，運動 5+ ，沉着 6+

**正文**

・僅在身穿輕甲或不穿甲，未使用盾牌並且使用近戰武器的情況下，人物可以在進行全防禦時將運動技能等級加到基礎防禦中，並將運動技能上的附加成功數加到防禦上的附加成功中。

・現在人物可以在使用移動動作進行格擋的同時移動不超過人物基礎移動速度一半的距離，最大不超過人物的敏捷值。取代 D 級效果。

・被近戰攻擊時，若對方未獲得任何成功，則人物可以立即以一個反射動作對其進行一次不附帶招式、能量和特殊能力的普通近戰攻擊。

・人物可以在進行任何近戰攻擊之後，以一個自由動作移動不超過自身敏捷值的距離。

## A 級　+10000

**先決**：先攻16 + ，基礎防禦 12+ ，沉着6 + ，智力6 +

**正文**

・僅在身穿輕甲或不穿甲，未使用盾牌並且使用近戰武器的情況下，人物可以以敏捷和感知中的較高者來決定基礎防禦，並且始終保留由較低者提供的附加成功。

・現在人物可以在使用移動動作進行格擋的同時移動不超過自己基礎速度的距離。取代 B 級效果。

・被攻擊時，若對方在攻擊之前移動了超過其體積的距離，那麼每多移動一米會使其受到攻擊 DP-1 ，防禦值 -1 的懲罰。對方受到的罰值不會使其 DP 和基礎防禦降低到 0 以下，並且最多不會超過你的運動技能等級。你在運動技能上的每個附加成功使此上限 +1 。這個效果持續一輪時間 , 只對你有效。

・被近戰攻擊時，若對方未獲得任何成功，並且在不超過對方體積的距離內有另一個敵人存在時，人物可以以一個反射動作將該次攻擊偏轉到另一個敵人身上。攻擊者按正常攻擊擲骰，而被他攻擊的目標被視爲措手不及。

## AA 級　+20000

**先決**：先攻22 + ，基礎防禦 16+ ，沉着8 + ，智力8 +

**正文**

・僅在身穿輕甲或不穿甲，未使用盾牌並且使用近戰武器的情況下，人物可以將敏捷和感知中較低者的附加成功數作爲洞察加值加到防禦值中，和 C 級效果累加，但不能超過身法等級 -1 。人物在運動技能上所擁有的每個附加成功可以使此上限增加 1 點。

・被攻擊時，若敵人因防禦降低而提升了攻擊，則對你，他失去在攻擊上的獎勵，但防禦上的懲罰照常計算。

・被攻擊時，若對方擲出的 1 總數高於擲出的 10 總數，則你可以將此次攻擊視爲滿足了“若對方未獲得任何成功”的條件來使用某些能力，但仍然要照常承受傷害。

・被攻擊時，若是對方在攻擊上的附加成功數低於你在防禦上的附加成功數，則你可以在對其的防禦上獲得等額的獎勵，並在下一次對其發動的近戰攻擊上獲得等額的附加成功。你必須在你的下一回合結束前做出此攻擊，否則此加值失效。

**正文**

擊劍手的身上絕對找不到沉重的護甲，他們不需要。就像這套無數擊劍大師在生死邊緣總結出的身法的統稱――“險鋒閃走”所詮釋的那樣，在敵人的劍鋒邊緣遊走卻不損分毫。這套身法強調回旋移動、靈活閃避、借力偏轉、沾離貼打以及對敵人行動的快速反映，擅長於在如疾風般的攻擊和如流水般的防禦中找出微小的空隙並藉此累積優勢。無論是在一對一的決鬥中還是一對多的混戰中都相當實用的身法。

沉重的盔甲會降低身法的靈動性，使閃避動作變形並且使人對護甲抱有期望，因此只有身穿輕甲或不穿甲時才能使用這套身法。在使用這套身法時，你所受到的每一點盔甲減值都會使你在攻擊 DP 和防禦上再額外受到 1 點減值。

啓動險鋒閃走是一個標準動作，但對於擊劍高手來說哪怕是片刻的先機也值得爭取，因此若人物願意支付 2 點意志則可以改爲以一個反射動作啓動。每次戰鬥你可以使用這套身法不超過 [ 你的體魄值 + 你在體魄上的附加成功數 ] 的輪數，但若以反射動作啓動則減半。
