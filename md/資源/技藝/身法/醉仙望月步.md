# 醉仙望月步

> 來源：`資源/技藝/身法/醉仙望月步`

**前提**

<ul>
<li>擁有一個通用東方能量池。需求運動 3 級。</li>
<li>習得本身法後，你選擇你所擁有的一個通用東方能量池，然後與其綁定，綁定後，本身法所消耗的所有能耗，皆爲該能量池。</li>
</ul>

## D 級

**價格**：D+500

**消耗**：1 點能量

**動作**：自由動作

**目標**：自身

**射程**：無

**範圍**：無

**持續**：5 輪

**效果**：啓動後，你現在衝鋒並不一定非要沿直線纔可以發動，只要你在移動前可以看見目標即可。你從倒地站起來只需要一個自由動作。

**價格**：D+500

## C 級

**價格**：C+1000

**消耗**：3 點能量

**動作**：自由動作

**目標**：自身

**射程**：無

**範圍**：無

**持續**：5 輪

**效果**：啓動後，除了 D 級的效果外，你現在學會了如何在攻防中前後迂迴，左右搖擺來躲避攻擊。你的基礎防禦獲得相當於你傳奇敏捷 \*2 的提升。並且你還學會了泄勁來抵消傷害，當你受到傷害時，你可以消耗 X 點能量，抵消 X 點傷害。 X 的上限爲本技藝的等級。

**價格**：C+1000

## B 級

**價格**：B+2000

**消耗**：5 點能量

**動作**：自由動作

**目標**：自身

**射程**：無

**範圍**：無

**持續**：5 輪

**效果**：啓動後，除了 D 級和 C 級的效果外，你可以以一個迅捷動作發動虛招。並且你現在進行衝鋒攻擊時，不會降低你的防禦，但是獲得增強加值的上限變爲你的防禦，而不再受到力量影響。同時，你 現在的基礎防禦變爲敏捷與感知取高，而非取低。 並且你在衝鋒後，若成功命中，則 還可以進行一次衝撞檢定。

**價格**：B+2000

**其他標籤**

**特殊可選**：啓動該技能必須先喝酒纔可以啓動。


**正文**

作爲酒劍仙所使用的步法，以行蹤飄忽詭異見稱，將位置的搶佔和攻防的變換融入看似毫無意義的移動之中。
