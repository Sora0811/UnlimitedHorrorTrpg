# 修羅不死身（護身勁） B+4000

> 來源：`資源/技藝/護身勁/修羅不死身`

**前提**

<ul>
<li>電磁力</li>
<li>修羅道之護身力量，以力量護住全身所有薄弱點，更特殊之處在於可配合對手力量性質而作出改變，將傷害減至最低。</li>
<li>反射動作可以啓動， 5 點電磁力量可維持 10 輪。獲得4 /- 的 DR ，並且所有對身體特殊位置的攻擊不產生特殊效果（比如對頭的攻擊不再直接造成惡性傷害）。同時對各種能量都開始有相當高的抵抗力，獲得 4 點能量抗力。</li>
<li>每額外支付2點電磁力量，可以在當輪對某種形式或器材的武器多獲得4點 DR （在鈍擊 / 揮砍 / 穿刺 / 魔法 / 銀 / 精金中選擇），上限爲你的電磁力等級，並且該DR可以與本技能的DR/-疊加。</li>
</ul>
