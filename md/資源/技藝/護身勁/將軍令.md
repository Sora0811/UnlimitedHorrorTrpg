# 將軍令（武學·護身勁）

> 來源：`資源/技藝/護身勁/將軍令`

## 銅鎧甲 Ｄ＋１０００

**其他標籤**

**破功**

<ul>
<li>受到一次性傷害高於耐力值便會破功，需要重新支付內力獲得功法好處。</li>
<li>銅鎧甲維持期間，進行強韌判定和力量爲主要屬性的近戰判定時，立即支付１點內力換取１個附加成功、破功時計算的耐力視爲要高１點，不會因此獲得新的附加成功。這被視爲一個內力基礎用法，只要學習了內功，就能在【身體強化】使用時支付１點內力維持上述強化。</li>
</ul>


**正文**

第一階級，武者可以運氣在體表一吋形成雄渾護體勁。

１點內力，標準動作，護體真氣使人物得到２／１能量防禦，並且爲身上原有護甲帶來２點破甲忽略和能量抗力（內力）；如果沒有護甲，因應人物意願可以視爲穿上了重甲，持續１０分鐘。

## 銀戰袍 Ｃ＋２０００

**其他標籤**

**破功**

<ul>
<li>在耐力值之上的計算＋５。</li>
<li>銀戰袍維持期間，進行反射判定和敏捷爲主要屬性的近戰判定時＋３ＤＰ內力加值，破功時計算的傷害視爲減少１點。這被視爲一個內力基礎用法，只要學習了內功，就能在【身體強化】使用時支付１點內力維持上述強化。</li>
<li>銀戰袍可以單獨使用，支付內力是１。這樣做會失去Ｄ級一切效果。</li>
</ul>


**正文**

第二階級，護體氣勁至兩吋。不只剛強，同時堅韌。

現在支付２點內力能夠自由動作運行護身法，防禦提高至４／２。陰柔的護體真氣還會剋制一切剛猛力度，對此得到ＤＲ５／柔勁（暗勁）、傳奇，２點內傷吸收。

## 金縷衣 Ｂ＋４０００

**被動**：只要人物保持光明磊落、大將之風，不論立場正邪，護體真氣使人物風度翩翩。風度＋１，銀戰袍的內力加值再＋２ＤＰ內力加值。

**主動**

<ul>
<li>支付５點內力，Ｃ級內傷吸收＋１，得到全傷害吸收３。金縷衣也能夠單獨使用，支付內力是３。</li>
<li>當人物並不是於一個無法動彈的狀態，全傷害吸收生效時可以向任意方向進行一次不大於１ｘ敏捷與耐力上自動之和＋運動等級（米）的移動。每有一點傷害吸收，進行反射判定和迴避範圍傷害時＋２ＤＰ。</li>
<li>這種移動方式可以往上進行跳躍，但是之後要一個可供立足的落點。</li>
<li>無論有否受到傷害，移動後都會使全傷害吸收數值－１，在人物的回合支付每點內力補充１點，這是個自由動作。</li>
</ul>

**其他標籤**

**莫惜**：護身勁受到擊潰時，１點意志，反射動作舍掉其中一層功力抵受破功的發生，這樣做會把當前受到的１點傷勢下降一級／抵消１點【內傷】（舍掉兩層是３點，全捨棄是５），還能夠觸發上述方式移動。


**正文**

第三階級，護體氣勁入體五吋。氣如錦衣，貼身御勁。

## 黃袍身 Ａ＋８０００

**先決**：內力池總量不下４０點

## 被動——

**主動**

<ul>
<li>三層護體勁凝練不發，聚而不散，散而不息。破功的計算得到耐力自動成功四倍的提升。只要內力池尚餘一半，Ｄ，Ｃ，Ｂ級的主動效果一直維持，無需動作打開和消耗，金縷衣（Ｂ級）的全傷害吸收還會每輪自行填充。</li>
<li>如果爲每一層功力支付５點內力的話會得到強化（一次性支付總計１５），無論是護甲、ＤＲ、傷害吸收……只要是數值的部份都會＋２，其中ＤＲ的部份只會被神兵和陰柔勁忽略，不再是傳奇。</li>
<li>黃袍加身，萬邪不侵：受到內傷、中毒和武學造成的精神影響對抗時，支付４點內力進行內力關鍵屬性較低一方進行４次判定，結果會在對抗的場合得到每成功骰１ＤＰ內力加值；如果是【內傷】，每個成功骰直接抵消１點。</li>
<li>失去意識的狀態下無法使出。</li>
</ul>

**其他標籤**

**天子威**：氣度不凡，人物風度再＋１。忽略風度自動成功＋武學等級／點殺氣，氣場一類造成的不良影響，可以是不良狀態或士氣減值／加值，如果是震攝一類無數值效果則減低對抗時的ＤＣ，ＤＣ減至０則無判定通過。


## 蓋天裳 Ｓ + ２４０００

**先決**：內力１２０＋

**其他標籤**

**蓋天闢地**：反射動作，給予１米／當前內力池半徑範圍內指定生物護身勁的效果。如果造成傷害，你可以主動承受最多１０點任意傷害，這種傷害的類型視爲內力的【勁】。

**三皇法**：有三皇授法，能開明，御百毒，破八卦遁術。

**·開明**：只要受到傷害，就能立即進行一次ＤＣ＝（Ｄ６，Ｃ１２，Ｂ１８，Ａ２４，Ｓ３０）的【武學推演】判定，只要通過就能解析攻過的來的招式，再次面對的時候，對方的判定上得到５個成功骰扣除（或５點狀態，自行分配），判定的成功骰能夠每次累積，除非是由對象以外施展（即使是同一招式）。同時，面對那些具備【穴道攻擊】能力的攻擊，你視爲已經對穴位進行了防禦，忽略減值的效果折半。

**·御百毒**：Ａ級的效果能夠支付１２點內力，一共進行１２次判定，且取關鍵屬性較高的一方。如果是毒，得到的加值爲附加成功，而不是ＤＰ。

**·破八卦遁術**：【黃袍加身·萬邪不侵】的效果能夠對地域性的幻術和困陣效果有用，不過作用爲看破，而不是解除。

**五帝功**

<ul>
<li>有五帝傳功，治五行之氣。</li>
<li>當內力至少有１０點的時候，就能夠推動那些消耗真氣的術法，並且能夠用自由動作順序轉換五行的屬性（金，水，木，火，土），以移動動作進行轉換可以不用順序。</li>
<li>·攻擊判定時從功法得到的附加成功會得到當前五行屬性的性質，自帶火焰、洪水等沒用的氣勢。</li>
<li>·面對相剋屬性真氣時，能夠將５點傷害去除本來屬性，視爲純能量攻擊。</li>
<li>·五行相生，只要每維持１０點內力分配在五種屬性中保留（即５０點內力），前三層功力效果＋１。</li>
</ul>


**正文**

新着龍虎門中羅剎教“千變棍妖”摩下三大怪人所修練的內功，修習者能夠在體表形成護體氣甲，抵禦各種攻擊。
