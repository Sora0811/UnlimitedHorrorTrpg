# 太平拳

> 來源：`資源/技藝/肉搏技藝/太平拳`

**前提**：肉搏 1 ，街頭智慧 3

**其他標籤**

**太平拳**

<ul>
<li>B+8000</li>
<li>別人打架，在旁趁機打幾下冷拳，因不易爲人發覺，故稱“太平拳”。《紅樓夢》第九回：“衆頑童也有幫着打太平拳助樂的，也有膽小藏過一邊的，也有立在桌上拍着手亂笑、喝着聲兒叫打的。”</li>
</ul>

**拳怕少壯**：俗話說，三歲一個代溝。而肉體更甚心靈，年齡是無法逾越的差距，哪怕功夫再高，涵養再好的武師，都會有垂垂老矣皮垮筋松之時。對方的年齡每比使用者大三歲，使用者在進行肉搏攻擊時就獲得 1DP 無名加值，上限 3DP 。

**亂拳打死老師父**

<ul>
<li>正所謂好漢敵不過人多，蟻多咬死象。招式精妙從來就不是打羣架的重點，藉助各方人脈，做到在單挑時讓對方一個挑己方一羣，羣毆時己方一羣毆打對方一個，纔是太平拳的制勝法寶。統計同場景中敵我雙方的參戰人數，己方每比對方人數多 1 ，你的肉搏攻擊就能獲得 1DP 士氣加值，上限爲你的街頭智慧技能等級。如果在該輪中，你的同伴與你攻擊相同的目標，則每個同伴能再給你的肉搏攻擊帶來 1DP 士氣加值。上限爲你的街頭智慧技能等級。</li>
<li>武功再高，一磚撂倒：廢鋼管、晾衣杆、皮帶、折凳、板磚……只要你能夠一手握住的東西，你就能毫不猶豫的遞出黑手！在持握原本不做武器用途的物品作爲臨時武器時，你可以將這臨時武器的傷害作爲增強加值加入你的肉搏攻擊之中。如果玩家擁有及時備戰專長，在拿起臨時武器後發動的第一次攻擊，對方必須以感知 + 搜查對抗我方敏捷 + 隱藏 + 肉搏自動成功，若失敗則視爲措手不及。</li>
<li>什麼？你問槍械刀劍爲啥不想？廢話，太平拳是拳！</li>
</ul>

**我是打醬油的！**

<ul>
<li>一個真正合格的太平拳打手，不僅僅要學會如何在最關鍵的適合伸出黑手，更要了解怎樣才能在危機四伏的戰場中將自己僞裝成毫不相干的無關羣衆。對方攻擊時，若範圍內不止你一個敵對目標，則你不會被優先攻擊。</li>
<li>而且，當有敵意對象以你爲目標發動單體肉搏攻擊時，你可以以反射動作消耗 1 意志力，雙手捂臉，大聲說出“我什麼都不知道！”“路過！”“我只是出來打醬油的！”等相關臺詞。以你的掩飾 + 操控對抗對方感知 + 理解，若勝出，對此次攻擊你可以免費獲得一個全力防禦或格擋防禦效果，且該效果與你本輪做過的同類動作效果疊加。該能力每遭遇對同一目標只能使用一次</li>
</ul>
