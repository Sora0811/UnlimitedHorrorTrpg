# 木葉體術 C+3000

> 來源：`資源/技藝/肉搏技藝/木葉體術（忍術）`

**升級**

<ul>
<li>花費 7XP 可以升級爲木葉烈風，伴隨着上段踢之後就是迎面而來的下段踢。</li>
<li>當使用木葉旋風進行攻擊時，成功數超過對手的體積，每超過 3 ，對手被擊退一米。</li>
</ul>

## 木葉大旋風 D+1000

**前提**

<ul>
<li>木葉旋風</li>
<li>強力的掃踢，在周圍踢起旋風攻擊敵人</li>
<li>花費 1 點能量。整輪動作進行一次肉搏攻擊，本次攻擊可以額外使用木葉旋風。可以攻擊兩個目標。你在肉搏上的每 1 點附加成功可以再額外攻擊一個目標。</li>
<li>影舞葉 C+1500</li>
<li>下端上踢，踢對方下把，把對方踢飛。</li>
<li>花費 3 點能量。進行一次肉搏攻擊，本次攻擊爲攻擊特定位置，減值固定爲 5. 如果傷害數對超過了對方的耐力或體積中較高者的話，對方的身體則會被擊飛。擊飛距離爲傷害數。如果超過對方的耐力或體積中較高者的二倍，對方進入浮空狀態，無法移動，速度爲 0 ，失去基礎防禦，無法閃避和格擋。浮空效果持續到下一輪你行動結束之前。</li>
<li>爆發式登場 DD+1000</li>
<li>用一記飛踢的方式切入戰場。</li>
<li>戰鬥中自己做出的第一個動作是此技能，此技能才生效。</li>
<li>整輪動作使用此技能，用一個帥氣的飛踢作爲自己的開場白。</li>
<li>飛踢的距離不可超過自身基礎移動速度的一半，所有看到此技能的友方隊員（包括自己）防禦攻擊各 +1DP 士氣加值，持續一場戰鬥或者你失去意識。</li>
<li>此技能可以在使用時進行攻擊，如同一次正常的肉搏攻擊。</li>
<li>獅子連彈 C+1500</li>
<li>在空中對敵人進行連續攻擊，如獅子般迅猛。</li>
<li>此技能必須在對方處於浮空狀態時纔可以使用。以一個迅捷動作啓動，在空中對敵人進行一次急速的連擊，如同一次肉搏攻擊，並最後一下將敵人從高空踢下，造成下落距離的墜落傷害，不可用敏捷 + 運動豁免。以及同樣多的眩暈點數，可以豁免。使用後目標結束浮空狀態，視爲倒地。</li>
</ul>

## 表蓮華 B+3000

**前提**

<ul>
<li>開啓開門</li>
<li>此奧義必須在開門狀態下纔可以使用。花費 5 點能量啓動，使用一個整輪動作，首先進行一次攻擊判定（視爲一次肉搏攻擊），若成功命中，則與對方進行摔絆對抗，若勝出，則你將目標踢上空中，每超出 1 成功數則擊飛 1 米。然後馬上進行一次擒抱檢定，本次檢定額外獲得摔絆檢定中超過對方的成功數的 DP 。若成功，則你在空中扭轉身形，大頭朝下旋轉落下，進行一次攻擊判定，本次攻擊無視對方 DR ，基礎防禦，你攻擊中的附加成功部分轉化爲惡性，並且額外造成等同於下落距離的嚴重傷害。</li>
</ul>

## 裏蓮華 B+3000

**前提**

<ul>
<li>生啓休門</li>
<li>此奧義必須在休門狀態下纔可以使用。花費 5 點能量啓動，使用一個整輪動作，首先進行一次攻擊判定（視爲一次肉搏攻擊），若成功命中，則與對方進行摔絆對抗，若勝出，則你將目標踢上空中，每超出 1 成功數則擊飛 1 米。如果傷害數對超過了對方的耐力或體積中較高者的話，則進入浮空狀態，失去所有基礎防禦。之後立刻在空中連續擊打對方，敏捷上每有一個附加成功則可以多攻擊一次，但是這幾次攻擊不能使用任何招式與技能，同時這些攻擊視爲一次攻擊。之後你抓住該單位的任何可以抓的地方（脖子，衣服等），然後藉助衝力和重力，全力攻擊敵人，並與敵人一起墜向地面。本次攻擊無視對方的基礎防禦，你攻擊中附加成功部分轉化爲惡性，並且額外獲得下落距離的附加成功與破甲，同時你受到下落距離的嚴重傷害。</li>
</ul>

**正文**

你可以使用你的敏捷或者力量進行肉搏判定。並且當你用其中一項來進行肉搏判定時，你可以將另外一項的附加成功加入到判定 DP 上。

你現在肉搏可以造成嚴重傷害。

你可以忽略你敏捷和感知附加成功數的高速。

你可以購買或者領悟木葉體術中的招式。

木葉旋風 500

在空中旋轉幾周，利用旋轉的力道，進行一次強有力的上段踢

花費 1 點能量。進行肉搏攻擊時，可以選擇減少攻擊 DP 來換取附加成功，每 2DP 換取一點附加成功，換取的附加成功上限爲敏捷 / 力量附加成功數取高。
