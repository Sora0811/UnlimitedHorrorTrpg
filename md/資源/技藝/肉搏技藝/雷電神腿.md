# 雷電神腿（武學・身法） Ｃ＋３０００

> 來源：`資源/技藝/肉搏技藝/雷電神腿`

**增幅**：人物內力等級每比Ｃ要高一等級即能夠增幅一次，每次額外消耗 1 點內力獲得＋２ＤＰ速度加值。

**技能樹**：以下所有招式必須在開啓身法的情況下纔可以使用。

## 電光初現（招式） Ｄ＋１０００

**消耗**

<ul>
<li>１點內力。</li>
<li>標準動作進行一次肉搏攻擊，出招時所得到的【高速優勢】翻倍。</li>
</ul>

## 雷電橫空（招式） Ｄ＋１０００

**消耗**

<ul>
<li>３點內力。</li>
<li>標準動作，這是一個衝鋒攻擊，衝鋒的距離爲你肉搏技能ｘ３米的距離，這段距離不需要立足點，可觸發雷電神腿的高速效果。</li>
</ul>

**其他標籤**

**連招**：可以在蛇行電步後使出，令該段衝鋒也無需直線。


**正文**

人腿猶如橫空噼下的一道迅雷，急迅而至――

## 雷動九天（招式） ＤＤ＋１５００

**消耗**

<ul>
<li>支付 2 點內力。</li>
<li>標準動作使用，需要立足在平面上發招，發招同時進行一次跳躍檢定，若跳躍後目標在你的攻擊範圍內，則你可以進行一次踢擊，並且該次攻擊＋ 1 附加成功招式加值，攻擊上方（飛行）的敵人再額外＋ 1 附加成功招式加值。</li>
</ul>

## 蛇行電步 Ｃ＋２０００

**消耗**

<ul>
<li>支付２點內力。</li>
<li>移動或反射使出。立即退開自身體積距離，如果當前一輪移動沒有超出雷電神腿增幅過後的距離，那麼這些未用距離可以在使出蛇行電步時計入退避距離。</li>
<li>使用後反射檢定和基礎防禦＋ 2 附加成功。</li>
<li>蛇行電步需要進行過移動才能得到加值。</li>
<li>沒有相關腿法使出的話，其消耗爲原來數值的兩倍。</li>
<li>２１ＸＰ進化―雷電分飛（招式）：人物身法瞬間提升至一個極快的地步，一分爲二產生出兩道身影。</li>
<li>消耗３點內力。</li>
<li>上述加值再＋２附加成功。使用蛇行電步時反射使出，進行一次虛招判定，成功會讓受到攻擊有５０％失手。</li>
<li>――或者主動此招掠陣，迅捷動作虛招對手，對方格擋還會得到你判定成功骰的減值。</li>
<li>擁有氣機感應、武學推演或真氣探知等能力者可以通過一個感知＋相關技能對抗你的敏捷 + 肉搏，勝出會無視這個技能影響。</li>
</ul>

## 春雷乍響（招式） Ｃ＋２０００

**消耗**

<ul>
<li>３點內力。</li>
<li>進行一次肉搏踢擊，命中後額外造成 2 點傷害，這 2 點傷害無視傷害吸收和傷害減免效果。傷害抵消能力只能將該傷害下降 1 級。</li>
<li>本招式具有【爆破武學】特性。</li>
<li>若成功造成傷害，則能夠進行衝撞判定，造成的每點傷害可以減去對方 1 點 DP 。</li>
</ul>

**增幅**：人物內力等級每比Ｃ要高一等級即能夠增幅一次，每次額外消耗 1 點內力額外造成 2 點傷害。

**正文**

腿勁瞬間爆發，產生亟震，令人難以抵卸。

## 雷霆萬鈞（招式） Ｂ＋３０００

**消耗**

<ul>
<li>５點內力。</li>
<li>使用時肉搏＋６ＤＰ招式加值，得到【連射】特性。</li>
<li>命中後，給目標身體內加入埋勁，上限最多等於雷霆萬鈞的招式加值。直至你的下一輪開始目標在力量和敏捷相關判定－１ＤＰ，基礎防禦也會因而減少１點。這些餘勁自然恢復視同衝擊傷害，但是以快速醫療治癒，其效果減半（快速醫療 1 不會恢復這種傷害）。</li>
<li>對象可以支付內力消除，每點內力消除 1 點埋勁。</li>
</ul>

**增幅**：人物內力等級每比Ｃ要高一等級即能夠增幅一次，每次額外消耗 1 點內力額外增加 2 點招式加值。

**其他標籤**

**連招**：若下一回合再度使用本招數則消耗減半。


**正文**

一力化作萬千勁，腿招如雷霆風暴壓制對方。

## 電光毒龍鑽（招式） Ａ＋４０００

**消耗**

<ul>
<li>１０點內力。</li>
<li>以一個整輪動作使用，人物進行一次＋８附加成功的肉搏攻擊，本次攻擊破甲提升 8 點，命中後以成功骰作爲 DP 再進行檢定，然後再把二次判定中的成功骰作爲ＤＰ進行判定，直至沒有成功爲止。</li>
<li>第二擊會追加１個附加成功，第三擊是２個，第四擊是３個，如此類推。</li>
<li>該武學無法與任何降低附加成功增加 DP 的技能和必中類技能一同使用。</li>
</ul>

**正文**

集腿勁真氣於一點旋轉踢出，一擊貫入對方體內攪碎。

**正文**

由龍虎門三皇之首王小虎改良王家絕學降龍腿所創，雷電神腿集合了快、狠二字，以速度和爆發制勝，攻人不備。

移動動作，支付３點陽性內力開啓，每次持續 5 輪，持續時間結束後可以花費自由動作支持 3 點陽性內力以維持。

在此狀態下，使用雷電神腿招式或以蹴踢進行肉搏攻擊時＋３ＤＰ速度加值，陸上基礎移動速度增加一倍。

如果攻擊對象在５米 / 肉搏等級的距離內，那麼人物的肉搏攻擊還會追加【高速優勢３】，內力修爲同樣達至Ｂ級時提升至【高速優勢５】。
