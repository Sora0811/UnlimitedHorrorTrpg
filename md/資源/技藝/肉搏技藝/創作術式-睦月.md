# 創作術式-睦月

> 來源：`資源/技藝/肉搏技藝/創作術式-睦月`

**本質**：特異本質

**價格**：D+500

**前提**：肉搏技能等級5，神祕學技能等級3

**描述**

<ul>
<li>由“勞動者”野挽創作的特殊術式，整個術式由三次打擊構成，前兩次攻擊作爲奉納來提高第三次打擊的效果。“經過兩次奉納的我，沒有揍不下去的東西！”</li>
<li>購買時需與一種能量池綁定，可選範圍爲“內力”“魔力”“氣”“查克拉”“元氣”</li>
</ul>

**價格**：D+500

## 彌生月

**動作**：標準動作

**能耗**：1點能量

**射程**：觸及

**目標**：一個目標 範圍：無

**持續**：一個場景

**效果**：你進行一次近戰肉搏攻擊，若成功命中，則該次攻擊不造成任何傷害，對目標造成等同於成功數的“彌生月點數”，上限等同於你的攻擊上限。對同一個目標多次使用彌生月不會疊加“彌生月點數”，僅取高。

## 如月

**動作**：見下

**能耗**：1點能量

**射程**：觸及

**目標**：一個目標 範圍：無

**持續**：一個場景

**效果**

<ul>
<li>本能力僅可對本場景內被“彌生月”攻擊過的目標使用（無論是否名字）。你以一個移動動作對目標進行一次近戰接觸肉搏攻擊，如果你的目標本輪內被“彌生月”攻擊過則動作下降爲迅捷動作。</li>
<li>若成功命中，則該次攻擊不造成任何傷害，對目標造成等同於你肉搏技能帶來的附加成功數+傳奇力量/傳奇敏捷取高/點如月點數。對同一個目標多次使用如月不會疊加“如月點數”，僅取高。</li>
</ul>

## 睦月

**動作**：結合在一次近戰肉搏攻擊中

**能耗**：1點能量

**射程**：見下

**目標**：見下 範圍：見下

**持續**：一個場景

**效果**

<ul>
<li>當你攻擊時，若目標身上有“彌生月點數”則其防禦受到相當於該點數的完美減值。若目標身上有“如月點數”，則其傷害吸收，傷害減免，傷害抵消能力受到等額減值，由你選擇。</li>
<li>本次攻擊結束後，清除目標身上的“彌生月點數”和“如月點數”。</li>
</ul>

**增幅**：每額外支付3點能量，睦月的攻擊檢定獲得1點附加成功，額外的附加成功上限爲目標身上的“如月點數”。
