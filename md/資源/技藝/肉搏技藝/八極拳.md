# 八極拳

> 來源：`資源/技藝/肉搏技藝/八極拳`

## 纏

**其他標籤**

**八極拳初步**

<ul>
<li>所有技能都爲 C+1000</li>
<li>聽勁</li>
<li>八極拳師的感官超於常人，即使面對不可見的攻擊，仍能在受到攻擊的瞬間用身體感知對方來勢做出反應。</li>
<li>你不會陷入措手不及，並且你在先攻上獲得 +4 有利。</li>
<li>活步</li>
<li>活步是一種雙腳貼地，無需作勢的步法，能在無聲無息間靠近對手。</li>
<li>若你腳踏實地並且一輪中已經做出過移動，那麼你可以用迅捷動作再進行一次移動，可移動的距離不能超過你當輪已經移動過的距離，並且這次移動無需再做潛行判定。</li>
</ul>


**正文**

纏是鎖身的技巧，小纏纏腕，大纏纏臂，迫使對方難於行動和迴避。

若你在肉搏格擋狀態下受到近戰攻擊，你可以在你下一次對攻擊者的攻擊中無視對手一定數量的閃避防禦，相當於你肉搏技能上的自動成功數，並且你的肉搏武器被視爲適於擒抱的武器。

## 寸勁

**其他標籤**

**八極拳小成**：所有技能都爲 B+2000


**正文**

寸勁是將呼吸，步法，體勢合一，於零距離爆發全力的技巧。

以一個標準動作進行一次肉搏攻擊，若你的攻擊對對手至少造成了 1 點傷害，你能以同樣的形式再攻擊一次，這是兩次攻擊。

## 六力合一

**先決**

<ul>
<li>六大開全部技法</li>
<li>在將六大開全部融會貫通後，你學會了使這些發力法彼此影響來使效果進一步提高的技巧。</li>
</ul>

**其他標籤**

**頂**：你在以頂發動的衝撞對抗上獲得 +6DP 的加值。

**抱**：你在肉搏技能上的每個自動成功能抵消 1 點因抱而受到的減值。

**擔**：現在你還能在攻擊中獲得額外的自動成功數，相當於擔所能擊破的傷害減免值。

**提**：現在提對同一次攻擊中發動的衝撞或摔絆也有效。

**挎**：現在你可以將較低屬性上的自動成功作爲 DP 加值加入衝撞判定中。

**纏**：現在若你能發動纏，你可以立即對目標發起一次擒抱（仍然需要接觸攻擊判定）。


## 疾步

**先決**

<ul>
<li>活步</li>
<li>疾步是一種藉助蹬地以小跳形式躍進的步法，其原理與火箭揹包跳躍相似，缺點也同樣相似，其落地的衝擊力無法被抵消。</li>
<li>當你在固體表面上進行移動時（如果你有能將液體或氣體視爲固體來移動的能力，例如凌空行走或者電磁吸附等，也可以生效），你可以移動至多兩倍的距離，但超出正常移動距離的每 5 米使你承受 1 點不可吸收減免的衝擊傷害。</li>
</ul>

## 疊勁

**先決**

<ul>
<li>寸勁</li>
<li>疊勁是通過微調體勢，連續發出寸勁的技法。</li>
<li>當你在寸勁成功發動後，你可以進一步追加攻擊，第一次後續攻擊使用寸勁結算時的 DP 的一半並且失去所有攻擊上的自動成功，以後每次再減少一半 DP （向下取整），直到剩餘 DP 爲 0 或者某次擲骰沒有獲得任何成功數爲止，這些攻擊分別視爲一次攻擊。</li>
</ul>

**其他標籤**

**八極拳大成**：八極拳大成並沒有什麼特別的技藝，各種招式，例如金剛八式等，只是對於基本技巧的混合應用，因此八極拳大成中允許選擇的 A 級技能替換爲總和至多 BB 級的八極拳技能。


**其他標籤**

**八極拳入門**：所有技能均爲 D+500


**正文**

自古有云，文有太極安天下，武有八極定乾坤。

若視太極爲靜之極致，以柔克剛，那麼八極就是動之極致，以力破巧。

八極拳聞名於其剛猛暴烈的拳風，同時也聞名於其進身靠打的招式。

猛起硬落、硬開對方之門，連連進發是八極拳技擊中的最大特色。

各等級同同級太極拳。每級技能發動消耗內力， D 級爲 1 點， C 級爲 3 點， B 級爲 5 點。

六大開是指“頂、抱、擔、提、挎、纏”六種基本方法，每種方法都需要作爲一項技能獨立購買。

頂

頂是上領、下沉、左頂、右拉四面八方勁發力的十字整力

若你以肉搏技能進行的近戰攻擊對對手造成了至少 1 點傷害，你可以以自由動作追加一次往任意方向的衝撞，並將你造成的傷害作爲該次衝撞對抗上的加值。

抱

抱是緊縮一團，枕戈待發，寓攻於防，防中有攻的技法

你在以肉搏技能進行的近戰攻擊之前，可以在防禦上承受一定數量的減值加到攻擊上，或是反過來，在攻擊上承受一定的減值加到防禦上，這個數值不能超過你的肉搏技能。

這個數值一旦決定，將持續到你下一輪行動開始，或你下一次以肉搏技能進行近戰攻擊爲止，視哪個情況先到來。

擔

擔是以拳輪爲力點，硬開硬打的發力法

你在以肉搏技能進行近戰攻擊時，可以獲得額外的破甲值，相當於你肉搏技能上的自動成功數，並且可以無視該值一半的非超自然來源的傷害減免。

提

提是腿法的變化，八極拳講究“行步如趟泥，提腳不過膝”。以極低的攻擊點破壞對手腳下重心，使其體勢崩潰。

若你以肉搏技能進行的近戰攻擊對對手造成了至少 1 點傷害並且對手腳踏實地，你可以使該對手在下一次對抗摔絆或衝撞時受到減值，相當於你造成的傷害值。

挎

挎是彎臂短擊法，勁如崩弓，發如炸雷，勢動神隨，以速度帶來力量。

你在發動衝撞時，所使用的屬性可以在力量和敏捷中取高，並且可以同時選擇造成擊退和擊倒效果，你的肉搏武器被視爲適於衝撞的武器。若目標同時被擊退和擊倒，按墜落傷害規則判斷其是否會承受墜落傷害。
