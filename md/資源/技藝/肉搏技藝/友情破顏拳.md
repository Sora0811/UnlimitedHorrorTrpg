# 友情破顏拳

> 來源：`資源/技藝/肉搏技藝/友情破顏拳`

**前提**：道德值爲 7

**效果**

<ul>
<li>友情破顏拳具備以下特性：</li>
<li>雖然是一種需要主動使用的技藝，但友情破顏拳可以和其他技藝招式搭配使用，達成比如北斗友情破顏拳的變體。</li>
<li>對於絕世高手“神淨討魔”來說，他人對其的映像更多體現爲認爲“不幸的避雷針”或是“把妹手”等和絕世武藝無關特徵，這視爲一個與拳法支線等級相同的迴避偵測能力。（第一層：無支線，第二層視爲 d 級支線，第三層視爲 d 級支線……最高境界視爲 aa 支線。）此特性會在實際交手或者是觀看施展的武藝後失效。</li>
<li>第一層（ 500 點）：</li>
<li>這門拳法是慈悲的武學，本應導致使用者死亡的攻擊現在僅僅會使人昏迷。</li>
<li>使用這門拳法，依靠的是信念而非蠻力，你可以選擇用決心屬性代替力量作爲肉搏檢定的關鍵屬性。如果你還沒在肉搏技能上受訓，那麼現在你將會視爲已經受訓，並獲得專業 - 拳。</li>
<li>第二層（ d+1000 ）</li>
<li>此拳法乃是慈悲的武學，目的是使人悔悟，而非殺生。</li>
<li>運用此拳法進行肉搏攻擊，若攻擊成功，則你可以取消傷害，對對方造成等同於傷害值的眩暈點數，強韌豁免。</li>
<li>在視覺效果上，遭受此拳法攻擊的人必定會被打中面部，並導致面部紅腫或變形。</li>
<li>第三層（ d+1500 ）</li>
<li>友情破顏拳具有強大無比的衝擊力，當擊中敵人的面部時，可選擇以自由動作對其進行一次衝撞檢定。</li>
<li>在此次衝撞檢定中，你能同時選擇擊退和擊倒效果。</li>
<li>第四層（ c+2000 ）</li>
<li>學會友情破顏拳的人，運用此拳法使人悔悟時，將會有不可思議的行動力。</li>
<li>此次遭遇內，你曾經用友情破顏拳擊中對手，那麼只要你的視線範圍，無論對方怎樣逃離或者製造出怎麼樣障礙，你都可用一個衝鋒攻擊對他使用友情破顏拳。</li>
<li>第五層（ c+2500 ）：</li>
<li>以愛與正義驅動的友情破顏拳可無視各種障礙的阻擋。</li>
<li>學會這門拳法的人會提升拳法層數 -1 的破甲值、高速值、破魔值，並且可以無視如同其肉搏附加成功的傷害減免。</li>
<li>第六層（ b+3000 ）</li>
<li>習得此層拳法使，你就初步領悟了友情破顏拳的真諦，你的每次打擊都將動搖敵人的內心。</li>
<li>每當你用友情破顏拳擊中對手，你都可以用一個自由動作對其進行交涉檢定（嘴炮），這次交涉檢定中你將得到本遭遇中層使用友情破顏次數的附加成功。</li>
<li>在視覺效果上，對於你的每次嘴炮，敵人都會給予回應，但如果你的嘴炮不到家，很可能是類似……呵呵呵之類沒有營養的臺詞。</li>
<li>第七層（ b+4000 ）</li>
<li>習得這層拳法後，你的友情破顏拳將使敵人陷入回憶殺。</li>
<li>被擊中的敵人必須通過一個 dc 如同你決心值的意志檢定，否則他會回想起變成這副模樣的原因，直到你下次行動時他都會陷入震懾狀態。</li>
<li>第八層（ a+5000 ）</li>
<li>你的友情破顏拳距離最高境界只有一紙之隔。</li>
<li>使用友情破顏拳時，你可以把自己的力量和決心值同時運用在肉搏檢定上。</li>
<li>第九層（ a+6000 ）</li>
<li>此層乃友情破顏拳的最高奧義，習得這層的可以使任何頑固不化的惡人悔悟。</li>
<li>現在使用友情破顏拳進行交涉（嘴炮）時，每個成功數都會給予同時都會不可豁免的魅惑點數。這是一個影響心靈的效果。</li>
<li>運用這個能力帶來的毀滅性後果，並非迷情而是洗白。他在精神上會重新變成一個對社會有益的好人，他會不惜一切代價償還自己曾經犯下的罪孽，即時會傷害自己也不例外。</li>
</ul>

**正文**

類似這種武學的法門，還有佛門的當頭棒喝。

因此如果 st 允許，可選擇將攻擊武器改爲棍棒，以白刃進行攻擊。

另外其最高奧義造成的毀滅性效果不是洗白，而是皈依佛門。這種效果不會使人的記憶或者心智受到影響，但是他的三觀會重建爲符合佛教宗旨的三觀。
