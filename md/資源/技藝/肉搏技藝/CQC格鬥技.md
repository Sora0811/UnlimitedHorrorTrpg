# CQC 格鬥技 -1000 分

> 來源：`資源/技藝/肉搏技藝/CQC格鬥技`

**正文**

――就在山貓和他的部隊輕鬆地將 SNAKE 捕獲時， SNAKE 乘他們不備迅速做出了反應，不過幾秒時間，山貓和他的手下被他那樸素的格鬥技全部放倒。

這套格鬥技是由傳說中的戰士 THE BOSS 和她的弟子 JACK （ BIG BOSS ）一起研究出來的。這套格鬥技主要用於潛行和防身，儘管與其他招式相比它沒有強大的殺傷力，但是在牽制對象上能夠起到一定的作用

・由於這個格鬥技巧在軍隊廣泛使用，你可以用 6 點 XP 來學習這個格鬥技。

・如果你肉搏爲 0 ，那麼你的肉搏提升到 1

・現在你持有單手持用的槍械時你能用另一隻手進行肉搏或者體積不超過 1 的白刃或天生武器攻擊和空手格擋，這還是一個標準動作，但你可以應用雙武器優點使你一手開槍一手格鬥。受到副手 -2 的影響。

・如果你持有雙手用的槍你可以用你的槍進行肉搏攻擊。此時你的拳頭的傷害和上限加上你槍械的體積，但是這個傷害只能是衝擊。

・現在你可以以標準動作進行擒抱。你所有擒抱對抗 +3DP

・一個標準動作，進行一個徒手接觸檢定。一旦成功，進行一個 [ 力量 + 肉搏 ] 檢定，對象進行一個 [ 力量 ] 檢定， DC 爲對象的 [ 體積 + 力量檢定的成功數 ] 。如果成功，對象立刻倒地。如果對象處於措手不及狀態，他不能進行力量檢定。

完美 CQC 格鬥― C+1000

―― 吊橋上，站在 SNAKE 對面 THE BOSS 向 SNAKE 伸出了手按住了手槍， SNAKE 疑惑地看着他的老師到底在幹什麼，當她鬆開手時， SNAKE 的槍錘已經失蹤了。接着 THE BOSS 向 SNAKE 打出一拳，輕輕一扭，隨着 SNAKE 的慘叫，他的左手瞬間廢掉了……

“隨波逐流吧……” SNAKE 掉下吊橋， THE BOSS 留下最後一句話。

JACK 所學到的 CQC 不過是一點皮毛工夫，傳說中的戰士 THE BOSS 纔是將這個格鬥技用得出神入化。這個技能不能通過經驗值學習，你只有學會了 CQC 後才能學習這個技能。

・如果你肉搏沒到 3 ，那麼立刻提升至 3 ，並獲得專業：拌摔，擒抱或格鬥的其中一個

・ 當你對對象進行肉搏的部位傷害後你可以用 [ 力量 + 肉搏 ] 對抗對象 [ 體魄 + 求生 ] ，一旦成功，你立刻將對象骨折，對象所有這個部位的生理檢定 -3DP 。如果骨折的是腳，對象不能奔跑，如果是雙手，對手所有用手的檢定失去 1 個自動成功，如果是身體，對象基本防禦 -2 ，如果是頭，那麼可以將 2 點傷害轉爲惡性。每個部位只能骨折一次。骨折只能用 [ 智力 + 醫學 ] 治療， DC 爲 5 。戰鬥中治療 DP-10

・當你拌摔成功後你立刻用 [ 敏捷 + 肉搏 ] 對抗對象 [ 敏捷 + 運動 ] ，對象一旦失敗，他手上的武器被你拿走。如果你拿到的是槍械，同時你的槍械在 5 以上，手藝在 3 以上，你可以立刻將武器拆分掉丟在四周。對象必須站起才能拾取零件。拾取零件是一個全回合動作，重新拼裝是一個標準動作，必須進行一個 [ 智力 + 手藝 ] 的 DC 爲 5 的檢定，戰鬥中受到 -10 的環境懲罰。

・ 如果你的槍械在 5 以上，手藝在 3 以上，你可以對對象持有的槍械進行部位肉搏攻擊，視爲攻擊頭部，槍械防禦爲 [ 對手的基本防禦 + 槍械體積 ] ， DC 爲槍械的體積。一旦成功，你立刻將對手的槍械拆分。對手拾取零件是移動動作，裝上是標準動作，進行一個 [ 智力 + 手藝 ] 的 DC 爲 5 的檢定，戰鬥中受到 -10 的環境懲罰，如果你是拾取後立刻裝上，懲罰再 -5 。
