# 聖堂防身術

> 來源：`資源/技藝/肉搏技藝/聖堂防身術`

## D+1000 分

**先決**：格鬥 3 、敏捷 3 、感知 3

**加成**：基礎防禦 +1

**進化**

<ul>
<li>支付 1 靈感點，你在使用此招式時，即使沒有腳踏實地也能發動。</li>
<li>聖堂防身術 -1</li>
</ul>

**其他標籤**

**招式效果**：啓動“聖堂防身術 -0 ”是一個移動動作，並且需要腳踏實地才能發動，視爲你發動了肉搏格擋，並獲得相應的好處和壞處。此時，在受到等同你格鬥技能等級的攻擊次數前，你不會因多次被攻擊而受到防禦減值。啓動此招式的同時，你可以選擇在攻擊 DP 上減少不超過你格鬥技能等級的數值，直到你下一回合行動前，你在防禦上獲得等額的格擋加值。如果你在格鬥技能上有附加成功，那麼你可以抵消對方攻擊上等額的附加成功，最多不超過你在攻擊 DP 上減少的數值。啓動零式視爲你同時使用了身法和招式。


**正文**

你收攏手臂，調整重心，將全身心置於最佳狀態。表面上你只是在消極防禦，然而只要你願意，你隨時都能發出雷霆一擊。

## D+1000 分

**先決**：聖堂防身術 -0 、沉着 4 、敏捷 4

**加成**：肉搏格擋防禦 +1

**其他標籤**

**招式效果**：進行一次全力防禦，但你並不獲得額外的閃避加值，取而代之的是你進行一次敏捷 + 格鬥的判定。被攻擊時，你在該判定中獲得的每個成功數都可以抵消對方的一個附加成功。如果對方的附加成功因此而被減少到 0 ，則你在下一次對其進行的肉搏攻擊中獲得 +4DP 的洞察加值。你必須在你下一次行動結束前作出此攻擊，否則此加值失效。你可以對多個目標獲得這個效果，只要你剩餘的成功數足以將其附加成功減少到 0 。

**連續技**

<ul>
<li>如果在前一輪或本輪內使用過聖堂防身術 -0 、 13 或 21 ，那麼你在使用此招式時將額外獲得 3/ 神兵的傷害減免。</li>
<li>聖堂防身術 -5</li>
</ul>


**正文**

謹慎的移動腳步，小心判斷敵人的攻擊方位。將攻擊架開的同時，你在對方的攻勢中製造出及其微小的破綻。

## D+1000 分

**先決**：聖堂防身術 -0 、格鬥 4 、力量 4 、敏捷 4

**加成**：擒抱和拌摔判定 +1

**其他標籤**

**招式效果**：當你成功的以擒抱抓住對手時，你可以立刻發動此招數來將敵人投擲出去。進行一次拌摔判定，你所勝出的每一點都能將對方投擲出一米的距離，並且倒在落點。對方被投擲的距離若超過自身體積兩倍，那麼超過的每一米都會使其在落地時受到 1 點衝擊傷害。

**連續技**

<ul>
<li>如果在前一輪或本輪內使用過聖堂防身術 -0 或 54 ，那麼此招式造成的傷害中有最多 3 點將被提升爲嚴重傷害。</li>
<li>聖堂防身術 -7</li>
</ul>


**正文**

在抓住對手的瞬間，你順勢將他舉了起來，然後一口氣拋了出去。

**其他標籤**

**招式效果**

<ul>
<li>進行一次智力 + 格鬥判定，每 2 個成功數允許你在攻擊物體時擊破 1 點硬度（你仍然需要克服硬度帶來的傷害減免），或每 3 個成功數允許你在攻擊生物時忽略 1 點天生或護甲防禦。若物體的硬度被擊破到 0 ，則物體立刻被毀壞。</li>
<li>要使用此招式，你必須先在防禦值上降低一定的數值，最多不能超過你的格鬥技能等級的兩倍。每因此而降低二點，你就能在防禦上獲得一個附加成功（例如，草稚剛有格鬥 5 ，因此他可以選擇在防禦值上降低最多 10 點，並在防禦上獲得最多 5 個附加成功）。接着，若任一對手對你發動近戰攻擊且並未獲得任何成功，那麼你可以立刻以一個反射動作對其發動一次普通肉搏攻擊。</li>
<li>進行一次跳躍判定，若你獲得的成功數高於對方的基礎防禦，那麼你可以在攻擊時，額外獲得等於勝出數的附加成功，最多不超過你的體積。若你擁有飛行能力，那麼你可以在跳躍判定上根據機動性而獲得一定加值（笨拙 +0 、不良 +1 、普通 +3 、良好 +5 、完美 +10 ）。若對方也具有飛行能力並且飛在空中，那麼你的判定結果會減去等額的成功數。若你對飛在空中的敵人造成大於其體積的傷害，則他必須以敏捷 + 運動對抗你造成的傷害，每失敗 1 點都會使其失速 1 點。</li>
<li>你的肉搏攻擊獲得『眩暈』特性，並將攻擊上的附加成功計入武器傷害中。若原本就已經擁有眩暈特性，則可以忽略擊暈的體積 / 耐力限制。</li>
<li>你發動一次衝鋒攻擊，但你只能移動不超過你移動速度一半的距離。你以俯低身體、連續縱躍的方式移動，因此你在這次衝鋒中可以進行最多 90 度的轉向，並且可以在一般無法衝鋒的地形衝鋒，甚至可以在牆壁、天花板上移動。當你進行攻擊時，你的敵人若用偵查對抗你的潛行失敗，則視爲措手不及。</li>
<li>進行一次感知 + 格鬥的判定，對抗對方的沉着，你每勝出一點，那麼在你下次行動前，目標的基礎防禦上就有 -1 罰值，如同他受到了多次攻擊一般。此減值對他人攻擊也有效。</li>
<li>進行一次肉搏攻擊判定，分別對抗攻擊範圍內所有敵人的防禦。若至少受到一點傷害，則目標必須選擇以力量 + 運動對抗你的力量 + 格鬥。若你勝出，則你可以將對方擊退 1 米，每 3 個勝出數可以再將他擊退 1 米。若他被擊退的距離大於自身體積，那麼他還會被擊倒。</li>
<li>以一個整輪動作，你對一個目標發動三次攻擊。這三次攻擊分別針對頭部、咽喉和胸部發動，因此你會受到相應的罰值。三次攻擊幾乎在同時發動，因此在你攻擊時不會獲得特別的好處，但在攻擊結束之後，對方視爲被攻擊了三次。若你三次攻擊都擊中了目標，則目標必須以力量 + 運動對抗你的力量 + 格鬥，若你勝出，則你可以將對方擊退 1 米，每 3 個勝出數可以再將他擊退 1 米。若他被擊退的距離大於自身體積，那麼他還會被擊倒。使用這一招時，造成的傷害爲三次攻擊中取得的最高的成功數，並且將另外兩次（如果命中）攻擊的附加成功數加入傷害中。你只能將可以附帶在每次攻擊中的附加成功數以此方法疊加。你在使用這一招時視爲使用全力攻擊，但不獲得全力攻擊的 DP 加值。</li>
</ul>

**其他標籤**

**變體**

<ul>
<li>對於那些比較偏好使用武器戰鬥或想要扮演某些特殊人物的玩家來說，可以考慮將聖堂防身術與某些特殊的武器（例如銃劍）相結合，以白刃代替格鬥，來使這套格鬥術成爲強攻型的白刃技巧。</li>
<li>聖堂防身術 -0</li>
</ul>


**正文**

據說這是聖堂教會爲了時常行走於荒野之中的傳教士們不至於喪命於盜匪野獸而特地開發的防身技術。話雖如此，雖然掛以“防身術”之名，招數卻主要以投技和關節技爲主，擁有極強的殺傷力，總之是與傳教士給人的通常印象完全不同的格鬥術。

當學會聖堂防身術 -0 之後（只有學會了零式才能學習進一步的技巧），在戰鬥開始的第一回合，你可以以一個標準動作進入一種特殊的精神集中狀態。投感知 + 沉着，每個成功數允許你保持精神集中狀態一輪時間，但最多不超過你的沉着值。你必須處在精神集中狀態下才能使用聖堂防身術的技巧，同時一場戰鬥中你無法多次進入精神集中狀態。當你處於精神集中狀態時，你的意志判定會獲得 +2 洞察加值，若你在意志判定上至少擁有一個附加成功，那麼此加值提升爲 +4 。
