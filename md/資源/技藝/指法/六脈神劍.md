# 六脈神劍經 ( 武學招式 ) BB+6000

> 來源：`資源/技藝/指法/六脈神劍`

**先決**：B 級內力、智力 5+ 、敏捷 5+ 、耐力 5+ 、醫學 ( 穴道 )5+ 、肉搏 ( 指 )5+ 、白刃 ( 劍 )5+ 六脈神劍，並非真劍，乃以渾厚內力的指力發出六種內力，含於指尖的內力隔空激發出去，使其以極高速在空中運動的一門技術，做架簡單，功效卓著，感應強烈，均爲首屈一指，久習可得奇效。達到指劍的境界，即指力所能及的地方，有如有一柄無形的劍，無論是橫掃或虛指，均可傷敵，劍氣有質無形，出劍時急如電閃，迅猛絕倫，交叉運用，以氣走劍殺人於無形，異常神奇，堪稱劍中無敵，可稱無形氣劍。 每學習一個劍招都會使六脈劍氣 +2L ，基礎爲 3L ，學會 4 個時加骰降低 1 級。 花費 1 點內力可以在指上形成六脈劍氣，人物可以將劍氣當作真正的長劍使用，它擁有 [ 破甲 3] ，肉搏和白刃上每點自動都能夠忽略 1 點指定部位減值，能夠使用劍招。 六脈神劍的劍招全部習得時視爲 A 級武學招式和擁有 [ 神兵 ] 特性。 免費獲得以下 1 種六脈劍招。 以下技能可以單獨購買，使用條件如上，但不會獲得增幅效果和六脈神劍經帶來的好處。 六脈神劍的招式都是能量武器，擁有 8 點高速優勢，可以正常攻擊靈體。 如無說明，射程都是每點內力 \*10 米 ( 將增幅所消耗的內力計算在內 ) 。 右手劍 : 六脈神劍之少商劍 B+2000 右手拇指－少商劍〈特點：劍路雄勁，頗有石破天驚，風雨大至之勢〉。 花費 5 點內力使用，作出一次白刃 ( 劍 ) 或肉搏 ( 指 ) 攻擊檢定，由於少商劍的內力屬性雄渾有力，因此只能用力量作爲關鍵屬性。 少商劍不會使這次攻擊帶來實質的加值，但會額外獲得 6 點破甲和破魔。 白刃和肉搏上同時有 1 點自動成功同時忽略 1 點 DR 、力場、遮掩和環境減值。
