# 藏劍術

> 來源：`資源/技藝/任意武器/藏劍術`

**前提**

<ul>
<li>擁有任意能量池</li>
<li>這是來自東方的一種奇術。</li>
<li>通過將武器與己身的能量契合，把物質分解爲靈子，藏於自己體內的一種技術。</li>
<li>由於轉化爲靈子的武器會完全與己身的能量脈動混爲一體，所以是不會被科技探測手段找出來的，因此在賞金獵人中是廣泛受到歡迎的能力。</li>
<li>儘管很便利，但亦有種種缺點。例如無論如何取出武器都需要花費一定的時間，在爭分奪秒的戰鬥中算的上是一個致命傷。</li>
<li>購買此技能之後，選擇一個你所具有的能量池，併爲想要契合的武器支付 3 點 XP ，你同時只能將一把武器與自己契合。並且當你將武器納入體內時，你的該能量池會暫時失去 5 點上限。</li>
<li>與武器契合是一個整輪動作，而將武器彈出體外則是一個標準動作，如果你爲此而支付 7 點 XP ，則改爲一個移動動作。彈出體外的武器會自動出現在你的手心，若你的雙手沒有空閒，則掉落在你的腳邊。</li>
</ul>
