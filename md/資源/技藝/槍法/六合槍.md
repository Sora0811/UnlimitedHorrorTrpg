# 六合槍

> 來源：`資源/技藝/槍法/六合槍`

**效果**

<ul>
<li>白刃等級 +1 ，上限 5 ，使用槍 / 矛 / 戟類武器戰鬥時，攻擊得到 +1 表現加值，攻擊距離 +1 ，並得到一個分類屬於：槍 / 矛 / 戟的武器專業</li>
<li>反射動作發動後，每過一輪，當你使用槍 / 矛 / 戟類武器戰鬥時，攻擊自動就加一，此能力額外提升的攻擊自動不得超過力量上的自動數。持續到遭遇結束爲止</li>
<li>反射動作發動後，每過一輪，當你使用槍 / 矛 / 戟類武器戰鬥時，防禦自動就加一，此能力額外提升的防禦自動不得超過防禦關鍵屬性上的自動數。持續到遭遇結束爲止</li>
<li>一次基本近戰攻擊無視對手因護身勁帶來的任意 DR2 點，任意防禦 6 點</li>
<li>全力攻擊發動，但基礎防禦減 10 ，對單一目標發動的絕強三連突，以基本近戰攻擊連突目標 3 次，每次攻擊 DP 減 5 ，若全部命中，則在第三擊的傷害計算時，把等於白刃等級的數值 \*3 。若第一擊落空，第二擊裏白刃帶來的 DP 效果加倍，若第二擊依然落空，第三擊忽略對手基於閃避的防禦。但此時就算命中也沒有之前的傷害獎勵</li>
<li>標準動作發動，發動一次基本近戰攻擊，在造成傷害之餘，將你的力量 + 白刃對抗對手的體魄 + 體積，若你勝出，對手被麻痹無法移動，他基於閃避類型的防禦值減半，持續時間等於你的勝出數的一半輪 +1 ，若你失敗，則他的基礎防禦僅僅 -2 ，持續到你下一次行動結束爲止</li>
<li>對視野內不超過白刃等級的目標發動連續的突刺，射程爲武器攻距 +1/ 白刃，其他規則如同掃射。</li>
<li>以其他任意 C 或以下級近戰招勢發動，因此受傷的目標在等於傷害點數輪裏，每輪受到一點不可避免的嚴重傷害，機械，無血液者免疫該效果。因此效果而受傷害的目標在等於傷害點數輪裏受到每輪 1 點可累計的攻防懲罰。</li>
<li>以其他任意 C 或以下級近戰招勢發動，因此受傷的目標若體積比你大，則把兩者的差值轉爲惡性傷害，機械類或無惡性傷害的目標，將兩者的差值轉爲加倍傷害。</li>
<li>以其他任意 C 或以下級近戰招勢發動，這一擊附帶貫穿效果，貫穿距離爲武器攻距離 +3+1/ 白刃，除原始攻擊目標以外，每多貫穿一個目標，你的下一擊就得到一個自動並可以忽略一個目標等於貫穿數的基礎防禦。</li>
<li>這次基本近戰攻得到 3 的 DP 加值，若你因此傷害了一個目標，以傷害點對抗目標的體魄，每勝出一點則造成一點額外的火焰自動傷害。</li>
<li>當你使用槍 / 矛 / 戟類武器戰鬥時，攻防各得 +2 內在加值，速度 +3 ，並如同擁有：心眼真和心眼僞</li>
</ul>

**正文**

這套戰技集西楚項羽，三國姜維，趙雲，隋唐羅成，北宋高世繼，楊延昭六人之槍術之大成，隨着他們的傳奇在民間流傳，人們的信念將六合槍的力量增副，強化，使其超越了現實武技的範疇而成爲超自然的力量。因此這套戰技可以使用任何基於體魄 / 感知 / 決心 / 風度的能量推動。學習這套槍法的武者其心，氣，膽，手，步，眼得到高度的磨練，從而擁有了匹馬單槍，傲視千軍的實力和氣魄。以下技能於坐騎上使用時攻擊判定可以得到一個額外自動成功，若使用者擁有類坐騎形態也有效果。
