# 龍王槍術第一章『怪奇談』 C ＋ 4000

> 來源：`資源/技藝/槍法/龍王槍術『怪奇談』`

## 6XP

**動作**：附加在一個多次攻擊不同目標的單體攻擊動作中

**類別**

<ul>
<li>特殊</li>
<li>進化技・狂</li>
<li>5X</li>
<li>數勁合一，你將幻惑的槍法作爲打破對手平衡性的武器。在攻擊時，只投 1 次攻擊判定，並且在攻擊中減去目標的堅毅或耐力值之高者。你的成功數不會造成傷害值，而是使對方在接下來 3 輪中在所有身體技能判定上受到成功數的減值。這是基於視覺的幻象效果。</li>
<li>霧雨</li>
<li>無名之龍創造了這一招，對付那些防備嚴密的敵人。槍勢細微綿密，既如濃霧，又如細雨，防無可防。</li>
</ul>

**其他標籤**

**消耗能量**：2 點或 4 點 DC


## 8XP

**動作**：整輪動作

**類別**

<ul>
<li>招式</li>
<li>你將千百次微弱打擊的力道半凝半散，發放於外，打出一道破空勁力。這道勁力看上去像是一束緋紅的光芒，成爲最遠 1 米 / 感知（若你用內力）或風度（若你用妖力）或沉着（若你用靈力）的一次接觸攻擊，但依然使用你的白刃攻擊判定和相關特性，並具有貫穿屬性。</li>
<li>你使用這一招時視爲使用全力攻擊，但不獲得全力攻擊的 DP 加值。</li>
<li>進化技・星塵狂歡</li>
<li>6XP</li>
<li>勁力由千化一，復由一化千，如漫天星光落雨。你必須儘可能多地攻擊同一定點，才能發揮出這一招式，因此你必須使用你能夠攻擊次數最多的攻擊方式。但就算你只攻擊一次，也會耗去你這一輪的動作。你的槍勁凝化五彩流星灑下，成爲射程 1 米 / 感知值的錐形範圍攻擊，傷害值爲你多次攻擊中取得的最高的成功數（包括附加成功），並且帶有你正常攻擊的所有性質。你的攻擊次數每多一次，就可將攻擊範圍延伸 1 米，並且將一次攻擊的附加成功數加入傷害中。你只能將可以附帶在每次攻擊中的附加成功數以此方法疊加。</li>
<li>即望</li>
<li>化繁爲簡的槍勁，有如既望之圓月，恆久不變、毋庸置疑。</li>
</ul>

**其他標籤**

**消耗能量**：3 或 DC5


## 8XP

**動作**：迅捷啓動，移動維持，最多 3 輪 / 敏捷

**類別**

<ul>
<li>身法</li>
<li>槍勁的存在已經超越了時間與空間，成爲必然的存在。你在處於“即望”之中時，你可以爲每一擊支付 3 能量，使這一記的槍擊如同槍械般忽視 5 點基本防禦</li>
<li>你在維持此身法時，可以同時以你自身所具有的移動能力進行移動。你無法使用從道具（如大天使、綠魔滑板）中獲得的移動能力。</li>
<li>進化技・殺人木偶</li>
<li>6XP</li>
<li>你在進行“即望”的攻擊時，可以進行一次連射，這是一個消耗能量的招式。你可以消耗 1 能量進行三擊連射，或 4 能量進行中速連射，或 8 能量進行連射。你進行的依然是近戰攻擊，但遵守連射規則的好處。你不會因爲這種連射而波及目標之外的生物。</li>
</ul>

**其他標籤**

**消耗能量**：3 或 DC5


**正文**

幻想之龍王擁有無可匹敵的妖力與智慧，意在以武道追求世間唯一且絕對的真理。爲了達到真正的至強，他不惜以元神凝化身外身，而將真身煉化成一條無堅不摧的長槍，並以此創建了這套槍法

這套槍法消耗的能量爲妖力、內力或靈力。

你買到的槍法將作爲不可複述的知識進入你的心智之中，你必須花費時間和精力去領悟它，這需要你耗費經驗值。

使用龍王槍術必須持有槍，長矛分類的白刃武器

月兔

無名之龍創造的第一式槍法爲月兔。槍意舒緩空靈，有如月中白兔，只在眼前，不在手中
