# 無限恐怖 TRPG 規則庫 (Unlimited Horror TRPG)
基於經典無限恐怖世界觀的 TRPG 規則庫與版本管理系統。本專案旨在提供清晰、模組化、具備多維標籤與版本差異對照的現代化 TRPG 規則體驗。
## 專案特色
- **結構化規則**：將繁雜的 CHM/HTML 說明書轉化為清晰易讀的 Markdown 格式。
- **多維度標籤 (Tags)**：支援系統分類、定位、消耗與擴充來源檢索。
- **版本差異管理 (Version Control)**：透過 Git 與補丁機制，輕鬆對比 v2.32、v2.34 及自定義私規補丁。
- **開放 API 友善**：可作為其他 App、角色卡或 AI 裁判機器人的知識庫來源。
## 目錄結構
- `docs/` - 核心規則與角色創建流程
- `rules/` - 血統、技能與裝備資源庫
- `patches/` - 規則修訂與版本對照
