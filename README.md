## 1. 這個 repo 是什麼

Unlimited Horror TRPG 2.34 正式版規則書，原為 CHM 格式。目前已完成：CHM 解包、UTF-8 轉碼、簡轉繁、**規則／資源結構拆分**、**每條目一資料夾重整**、入口網站。

**規則書內容尚未轉換成任何結構化資料**（`rules.yaml` 之類），這是後續 App 開發的前置工作。

## 2. 目錄結構【觀察】

```
Resource/

├─ dtree.js / dtree.css / img/            導航資產

└─ _chm源檔/                              CHM 編譯產物與 .hhc/.hhk（僅供追溯）
```

### 每條目一個資料夾【決定】

**結構 = 完整分類路徑 + 條目資料夾，內容一律命名為 `index.html`。**

```
Resource/資源/血統/人類/特異本質/禍神血脈/index.html
Resource/資源/物品/科技本質/D級系列武器/D級手槍系列/index.html
Resource/規則/ST幫助/巨龍/index.html
```

這個設計的目的是**支撐分支與補丁**：一個條目的所有版本與附屬資料放同一個資料夾。

```
Resource/資源/血統/人類/特異本質/禍神血脈/
├─ index.html              現行版本（2.34）
├─ patch-2.35.yml          日後：補丁
├─ variant-私規.html       日後：私規變體
└─ notes.md                日後：修訂筆記
```

優點【觀察】：
- **撞名歸零**。同一標題（如「D級武器」）在科技本質／特異本質／魔幻本質各有一份，靠完整路徑自然區分。
- **路徑長度安全**。最長 124 字元，遠低於 Windows 260 上限。
- **網址即語意**。`/資源/血統/人類/特異本質/禍神血脈/` 自帶完整分類資訊。

### 顯示順序【決定】

顯示順序由 `gen_nav_fs.py` 的 `ORDER` dict 決定，**與資料夾名稱無關**。要調順序改這裡，不要改資料夾名。

- 規則：本書說明 → 序 → 遊戲玩法 → 建立人物卡來參與遊戲 → 戰鬥相關 → 其他相關 → 特殊規則部分 → 關鍵字速查 → 傳奇輪迴者 → **ST幫助（最後）**
- 資源：總綱 → 血統 → 改造 → 瞳術 → 稱號 → 流派 → 技藝 → 修真 → 魔導書 → 能量池 → 物品 → 專長

## 5. 頁面特徵【觀察】

- 1172 個 `index.html` 全為有效 UTF-8。頁面**幾乎沒有語義 HTML**：沒有 `h1–h6`、`ul/ol/li`、`img`，主要是 `<p>` 與 `<span>`，37 頁含 `<table>`。
- 頁與頁之間幾乎沒有超連結：全站只有 1 個條目（橡膠果實）含外部連結。導航樹是唯一把條目串起來的東西。
- 條目結構以**文字標籤**呈現（`描述：`、`特殊：`、`本質：`、`特性：`、`價格：`、`技能樹：`、`前提：`⋯⋯各出現在約 400–700 頁）。【假設】這些是欄位，其意義與適用範圍尚未驗證。

## 8. 建置腳本

```bash
python build/gen_nav_fs.py        # 掃描實體結構，重建 left.htm（日常唯一會用到的）
python build/verify_site.py       # 對本機伺服器驗證全站連結（需先跑 http.server）
```

以下為**歷史遷移腳本**，只支援特定階段的輸入狀態，不可重複執行：

```bash
python build/parse_hhc.py         # 解析 .hhc → 頁面/章節對照（需 Resource/234/）
python build/restructure.py       # 規則／資源拆分（需 Resource/234/）
python build/plan_entry_folders.py # 每條目一資料夾（需拆分後的平鋪結構）
python build/plan_rename.py       # 檔名＝標題對照表
```

**目前 repo 已在最終結構。** 要重跑遷移腳本請先 `git checkout <commit> -- Resource`。

## 9. 給 AI／協作者的使用說明

- **取得完整內容**：`git clone https://github.com/Sora0811/UnlimitedHorrorTrpg.git`。只能讀網頁的工具可能被 GitHub 頁面擋下（robots），公開網站的導航與內容位於 iframe 內，也不易被抓取。
- **原則**：不得以一般 RPG 的常見結構推論 UH 的結構；原文沒寫的就是【未知】；引用請附**完整路徑**（例如 `資源/血統/人類/特異本質/禍神血脈/`），標題會重複，不可單獨使用。
- **不要手改 `left.htm`**，改 `gen_nav_fs.py` 的 `ORDER` 或資料夾結構後重跑。
