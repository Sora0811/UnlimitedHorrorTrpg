## 1. 這個 repo 是什麼

Unlimited Horror TRPG 2.34 正式版規則書，原為 CHM 格式。目前已完成：CHM 解包、編碼轉 UTF-8、簡轉繁、**規則／資源結構拆分**、入口網站。

**規則書內容尚未轉換成任何結構化資料**（`rules.yaml` 之類），這是後續 App 開發的前置工作。

## 5. 頁面特徵【觀察】

- 1172 個 `.htm` 全為有效 UTF-8。頁面**幾乎沒有語義 HTML**：沒有 `h1–h6`、`ul/ol/li`、`img`，主要是 `<p>` 與 `<span>`，37 頁含 `<table>`。
- 頁與頁之間幾乎沒有超連結：全站只有 1 頁（`橡胶果实1.htm`）含外部連結。導航樹是唯一把頁面串起來的東西。
- 條目結構以**文字標籤**呈現（`描述：`、`特殊：`、`本質：`、`特性：`、`價格：`、`技能樹：`、`前提：`⋯⋯各出現在約 400–700 頁）。【假設】這些是欄位，其意義與適用範圍尚未驗證。
- **檔名與內容不符的情況存在**：`新建项目.htm` 實為「屬性概述」、`战！战！战！.htm` 實為「戰鬥規則」、`核心规则部分.htm` 實為「遊戲玩法」。**導航標題才是權威，檔名不可信。**

## 7. 已知問題與待決事項

1. **字元遺失（作者端，原始 CHM 即有）**【觀察】
   - 29 頁、共 333 處「中文字夾 `?`」，例如 `绝刀?铇`、`阿特拉克?纳克亚`、`?壹之型`、`战斗风格?【疾】`；導航標題也有（例如「魔銃?ベルヴェルク」）。
   - 原始 CHM 的位元組本身就是 `0x3F`，無法機械還原；我們的轉換流程沒有造成任何額外遺失（CHM 與現行 repo 的 `?` 總數同為 653，逐頁吻合）。
   - 維護者說明：原檔編碼為 GB2312，這些 `?` 應為日文字元。【假設】多數是中點或項目符號類符號，**不可據此自動替換**。
   - 【決定】**目前保持原狀**，待之後逐檔施工時再修。
2. 【未知】「未開放」章節各條目的完成度與預定整併位置。
3. 【未知】文字標籤所代表的欄位語意與條目類型，需與維護者共同確認後才能定義。
4. 【待決】`資源/總綱/洗点.htm` 名為「洗點」，內容實為資源章總綱（購買順序、版本說明），標題應修正。

## 8. 建置腳本

```bash
python build/parse_hhc.py      # 解析 .hhc，輸出頁面→章節對照表
python build/restructure.py    # 產生搬移計畫（dry-run）；加 --apply 實際搬移
python build/gen_nav.py        # 由搬移結果生成 left.htm
python build/verify_nav.py     # 驗證導航連結完整性（應為 0 失效 / 0 孤兒）
```

**這些腳本只支援從「拆分前」狀態執行。** 目前的 repo 已在拆分後狀態，重跑 `restructure.py` 會找不到 `Resource/234/`。若需重跑，先 `git checkout aca6893 -- Resource`。

## 9. 給 AI／協作者的使用說明

- **取得完整內容**：`git clone https://github.com/Sora0811/UnlimitedHorrorTrpg.git`。只能讀網頁的工具可能被 GitHub 頁面擋下（robots），公開網站 `https://sora0811.github.io/UnlimitedHorrorTrpg/Resource/index.html` 的導航與內容位於 iframe 內，也不易被抓取。
- **原則**：不得以一般 RPG 的常見結構推論 UH 的結構；原文沒寫的就是【未知】；引用請附**檔名**（與必要時的 commit），不要只寫標題（標題會重複）。
- 導航結構以拆分前的 `left.htm` 為準（現存於 git 歷史 `aca6893`）；`.hhc` 為作者原始目錄，衝突時以 `.hhc` 的層級為準。
