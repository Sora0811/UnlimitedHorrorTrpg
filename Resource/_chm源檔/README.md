## 7. 已知問題與待決事項

1. **字元遺失（作者端，原始 CHM 即有）**【觀察】
   - 29 頁、共 333 處「中文字夾 `?`」，例如 `绝刀?铇`、`阿特拉克?纳克亚`、`?壹之型`、`战斗风格?【疾】`；導航標題也有（例如節點 1166「魔銃?ベルヴェルク」）。
   - 原始 CHM 的位元組本身就是 `0x3F`，無法機械還原；我們的轉換流程沒有造成任何額外遺失（CHM 與現行 repo 的 `?` 總數同為 653，逐頁吻合）。
   - 維護者說明：原檔編碼為 GB2312，這些 `?` 應為日文字元。【假設】多數是中點或項目符號類符號，**不可據此自動替換**。
   - 【決定】**目前保持原狀**，待之後逐檔施工時再修。
2. 【未知】「暫不開放」章節的內容定位、111 個 `$$unsavedpage` 節點是否純為分組。
3. 【未知】文字標籤所代表的欄位語意與條目類型，需與維護者共同確認後才能定義。
